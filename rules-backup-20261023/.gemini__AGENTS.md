## Decision Ladder (Ponytail YAGNI)
Before implementing, check from simplest:
1. HTML native? (<input>, <dialog>, <details>, <select>)
2. CSS only? (visibility, transform, :has())
3. One function? (<20 lines, built-in APIs)
4. Existing library? (already in package.json)
5. New library? (small, focused)
6. Custom solution? (only if all above fail)

NEVER remove: validation, error handling, security, accessibility.
