# TEMPLATE PROMPT TERBAIK (copy-paste, isi titik-titik)

BAIK (untuk hasil maksimal, 5 baris saja):

Tugas: ...
Hasil yang saya mau: ...
Contoh / gaya yang saya suka: ...
Yang TIDAK saya mau: ...
File terkait (kalau ada): ...

CONTOH JADI:

Tugas: buatkan landing page kopi
Hasil yang saya mau: 1 file HTML, ada katalog + tombol WA
Contoh: gaya minimalis kayak Starbucks
Yang TIDAK saya mau: tanpa backend, tanpa ribet
File terkait: -

MODE SUPER MALAS (1 baris, tetap jalan karena prompt-booster):

[Tugas] + untuk [tujuan] + gaya [X] + jangan [Y]

Contoh: buatkan poster untuk jualan kopi gaya minimalis jangan norak

PANTAUAN SAYA: kalau kamu ketik 1 baris, saya otomatis kembangkan
jadi format BAIK di atas tanpa kamu sadari. Jadi santai saja.
