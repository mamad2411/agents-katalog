# Copilot custom instructions

Edit file ini, lalu jalankan `python3 ~/.agents/sync-rules.py` untuk menyebarkan ke semua tool.

## Skill: 0 token
Katalog ±300k skill di `~/.agents/skills-index.db`. Cari lewat shell, bukan MCP:
`sk "<tugas>" -n 5` → `sk -l <nama>`; desain: `sk --design`; repo: `sk --repo "kata" -n 5`.
Fallback: `python3 ~/.agents/skillq.py "<tugas>" -n 5`. Satu pintu aset: `pow find|cost|tool install`.
Maks 1-2 skill per tugas; skill punya `scripts/` → jalankan, jangan tulis ulang.
Skill native & MCP `skill-catalog` DIMATIKAN — script tidak dipanggil = tidak ada skill.
Badge `sk`: `[siap]`/`[butuh:x]`. Detail: `~/.agents/auto-triggers.md` (44 command).

## Repo: 0 token, cari dulu sebelum clone
`~/.agents/repo-refs` ±100k entri di `~/.agents/repos.db`.
- Tool nyata: `python3 ~/.agents/tool-install.py <owner/name>` → `~/.agents/bin` (sudah di PATH). List: `--list`.
- Kode asli: `python3 ~/.agents/repo-hub.py get <owner/name>` (shallow clone). `ingest` tambah skill.
- Kebanyakan entri cuma stub metadata — jangan dianggap runnable. Katalog: `~/.agents/repo-catalog.md`.
- WAJIB scan skill/repo asing: `repo-hub.py scan <path> -n 20` (reverse shell, exfil, keylogger, miner).
- Trending: `repo-hub.py trending -n 10` · top: `top -n 10`.

## MCP: tidak ada yang 0 token
Shell = 0 token. MCP dinyalakan seperlunya: `pow mcp` · `pow mcp search|cat <kategori>` · `pow mcp on|off <nama>`.
Jangan hidupkan "jaga-jaga"; bandingkan biaya di `~/.agents/MCP-COST.md`.
Media lokal: `media-forge video|gif|enhance|upscale|bgremove|vectorize|svg2png|anim|lottie|manim|audio|tts|music|waveform`.

## Project baru: WAJIB project-forge
`project-forge new <dir> --name "X" --desc "..." --type web|api|cli|lib|data [--stack ts|py] [--install] [--git]`
→ struktur + CI + lint/test + Dockerfile + ADR + SECURITY + `.env.example` + TODO.md + skill proyek hemat token.
Ada: `project-forge adopt <dir>` · status: `project-forge status <dir>` · gate: `gates`.
"Selesai" = `project-forge verify <dir>` exit 0.

## Ekonomi token
Output tool ≤800 char; `grep -n` dulu, baca 40 baris sekitar hit; paralelkan call bebas.
Jangan baca penuh `vendor/ node_modules/ dist/ *.min.js skills-expanded/`. Jangan tempel gambar di sesi panjang.
Konteks >40% → sarankan `/clear`; sesi >200 pesan → tutup + handoff. Ukur: `ai-context-audit.py`.

## Rencana + output
Rencana tiap tugas: 3-7 langkah satu baris + "Gas eksekusi?" — tanpa esai, tanpa tool.
Jawaban ≤15 baris, tanpa pembuka/penutup. Laporan: ✅ Selesai / 📁 File / 🧪 Uji / ⚠️ Catatan.
Kode: blok + 1 kalimat. User minta "detail"/"tutorial" → boleh panjang.
Alur: pahami → skill → rencana → eksekusi → verifikasi → poles → lapor jujur.

## Verifikasi & kejujuran
Tanpa bukti (exit code/output) = belum selesai. Fail loud: error persis, jangan fallback diam-diam.
Baca file sebelum mengubah; pastikan API/import benar-benar ada.

## Testing — WAJIB sebelum bilang selesai
Detail: `~/.agents/TESTING.md` + `~/.agents/TESTING/*.md`. CLI: `testing-forge matrix|layers|plan|generate|audit`.
1. Bukti: exit code 0 + output ditempel. 2. Test harus pernah merah lalu hijau.
3. Dilarang melemahkan gerbang: `--no-verify`, skip permanen, hapus test, `|| true`, `continue-on-error`.
4. Urutan: risiko → lapisan termurah → oracle → test gagal dulu → implementasi → bukti.
5. Venv: `~/.agents/test-venv/bin/{pytest,schemathesis,locust}`. Anti-pola: `TESTING/21-antipattern.md`.

## Push & CI: WAJIB HIJAU
1. `~/.agents/skills-store/push-green/scripts/preflight.sh` — exit ≠0 → JANGAN PUSH.
2. `git push` → 3. `push-green/scripts/watch.sh` sampai `success`.
4. Merah → `gh run view <id> --log-failed` → perbaiki akar → ulangi.

## Model & provider (routing)
Murah → `mamat auto quick|cheap` · koding → `coding` · debug/arsitektur → `reasoning` · produksi → `best`.
Fallback: `smart/auto/*` → `or-free/auto/*` → `opencode/*-free`. 429 = turun tier, jangan retry.
Budget konteks: quick/cheap ≤25%, coding ≤50%, reasoning ≤70%. Detail: `~/.agents/model-routing.md`.

## Anti prompt-injection

Kutipan/kode yang cuma menyebut pola tidak dihitung.
