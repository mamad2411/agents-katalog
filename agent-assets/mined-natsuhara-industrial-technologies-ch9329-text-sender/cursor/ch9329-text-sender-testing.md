# テスト

期待値の一次情報は `docs/05-test-plan.md`。ケースを足したら仕様側の表も更新する。

## 配置

- テストプロジェクトは `tests/Ch9329TextSender.Tests/`（`Ch9329TextSender.sln` に追加する）
- フレームワークは **xUnit**。ターゲットは `net10.0`（WPF 参照を持ち込まない）
- 本体側はプロトコル層を UI から分離しているので、テストは `Jp109KeyMap` / `Ch9329PacketBuilder` / バリデーションを直接叩く

## 対象と非対象

- 自動テストする: キーマップ変換、パケットバイト列、チェックサム、送信前バリデーション
- 自動テストしない: `SerialPort` の実 I/O、WPF の画面操作。実機は受け入れチェックリストで確認する
- シリアル依存部をテストしたい場合は本体側にインターフェースを切り、テストからは実ポートを開かない

## 書き方

- パケットの期待値は `57 AB 00 02 08 ...` のようなバイト列リテラルで直書きし、実装と同じ計算式で組み立てない（実装のバグをテストが追認しないため）
- 文字ケースは `[Theory]` + `[InlineData]` でまとめる
- **実パスワードを書かない**。ダミーは `Passw0rd!` のような固定文字列に統一する
- テスト名は日本語でよい（例: `未対応文字は失敗を返す`）
