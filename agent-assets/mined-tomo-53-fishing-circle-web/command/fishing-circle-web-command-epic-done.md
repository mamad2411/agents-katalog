直近に完了した作業の知識を案件ノートへ昇格します。対象（任意）: `$ARGUMENTS`

`epic-knowledge` スキルの「知識の昇格」に従って進めてください。

手順:
1. **対象特定**: 現在の `feature/` ブランチ名から該当する `.claude/epics/<slug>/_epic.md` を特定する（不明なら確認）。
2. **抽出**: 直近の会話と `git diff` から「決定事項・前提・学び・未解決事項」を抜き出す。
3. **昇格**: `_epic.md` の該当セクションへ追記する（既存と統合し、覆った決定は更新）。
4. **履歴**: 「タスク履歴」に日付＋要点を1行記録する。
5. **整理**: 完了した `tasks/NNN-*.md` は要点を昇格済みであることを確認のうえ削除する。
6. **報告**: 昇格した内容の要約と、残った未解決事項を示す。

重要な知識を昇格せずにタスクを消すのは禁止。機密は書かないこと（`.claude/rules/security.md`）。
