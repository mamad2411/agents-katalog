次にやるべきタスクを提案します。対象（任意）: `$ARGUMENTS`

`epic-knowledge` スキルの「次タスクの提案」に従ってください。

手順:
1. **読み込み**: 現在の `feature/` ブランチに対応する `.claude/epics/<slug>/_epic.md`（特に「未解決事項」）と、現状（`git status` / `git diff`）を読む。
2. **配膳**: 文脈を踏まえ、**次にやるべきことを 1 つだけ**、小さく実行可能な単位で具体的に提案する。理由（なぜ今これか）を一言添える。
3. **待機**: ユーザーが「やる/OK」と返したら着手する。違う指示なら従う。
4. **完了後**: 着手したタスクが終わったら `/epic-done` 相当の知識昇格を行う。

提案は一度に1つ。あれもこれも並べない（思考停止で消化できる体験を保つ）。
