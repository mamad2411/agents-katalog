# HGI-BO (High Grade Iron-Blooded Orphans) — curation hints

Covers mobile suits from the 2015-2017 *Mobile Suit Gundam: Iron-Blooded
Orphans* anime at 1/144 scale. Flat — one directory, one file per kit, no
further nesting, no `variants` sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — 42 of 63 kits (67%) have a
documented lineup number, same flat-naming exception as every other
sub-line so far.

## Sourcing

Same `allpages&apprefix=HGI-BO ` + `redirects=1` method as
[`../hguc/CLAUDE.md`](../hguc/CLAUDE.md) — 120 raw pages resolved to 63
real targets, no `/Variants` navigational subpages, no unreleased/
canceled kits found. Cleanest research pass of any HG sub-line so far —
zero keyword false positives to chase down.

**Images**: 62 of 63 kits had a usable infobox `image`; one
(`V03-0907 Oltlinde`, a Bandai Hobby Online Shop exclusive) has no
`Gallery` section at all on its own wiki page — genuinely no image
available, stays imageless.
