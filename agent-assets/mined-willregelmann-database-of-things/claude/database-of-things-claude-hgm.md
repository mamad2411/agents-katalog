# HGM (High Grade Mechanics) — curation hints

A High Grade prefix for large mobile armors and other non-mobile-suit
mechanics from Mobile Suit Gundam 0083: Stardust Memory
(`Classification = High Grade Mechanics` in the infobox), built at a
smaller non-standard scale to keep an oversized subject at a manageable
kit size — a sibling pattern to
[`../CLAUDE.md`](../CLAUDE.md)'s note about verifying scale per kit
rather than assuming a grade's typical scale always applies. Flat — one
directory, one file per kit, no further nesting, no `variants`
sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — the sole kit has no documented
lineup number, same MG/RG/EG/PG/SD/HG*-flat-naming exception.

## Sourcing

Same `allpages&apprefix=HGM ` + `redirects=1` method as
[`../hguc/CLAUDE.md`](../hguc/CLAUDE.md) — 1 raw page, 1 real kit,
`AMX-002 Neue Ziel`, at a genuinely non-standard `1/550` scale (verify per
kit, don't assume `1/144`).

**Images**: the one kit had a usable infobox `image`, verified HTTP 200.
