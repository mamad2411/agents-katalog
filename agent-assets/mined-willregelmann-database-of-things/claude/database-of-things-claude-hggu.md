# HGGU (High Grade Gundam Wing Dual Story G-Unit) — curation hints

The High Grade prefix for the G-Unit manga spin-off of Mobile Suit Gundam
Wing (`Classification = High Grade Gundam Wing Dual Story G-Unit Series`
in the infobox) — distinct from [`../hgac/CLAUDE.md`](../hgac/CLAUDE.md)'s
After Colony/Wing TV-series prefix. Flat — one directory, one file per
kit, no further nesting, no `variants` sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — the sole kit has a documented
lineup number, kept unprefixed for consistency with every other HG
sub-line's flat-naming exception.
