# HGGB (High Grade Gunpla Builders) — curation hints

The High Grade prefix tied to "Model Suit Gunpla Senshi Gunpla Builders
Beginning G", a precursor media property to Gundam Build Fighters
(`Classification = High Grade Gunpla Builders` in the infobox — the
directory name "HGGB" is a wiki title-prefix convention, not an
abbreviation of "Beginning-Forever" as might be guessed from the kit
names alone). Flat — one directory, one file per kit, no further nesting,
no `variants` sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).
