# HGCC (High Grade Correct Century) — curation hints

The High Grade prefix for Turn A Gundam's timeline (its official
in-universe era name, "Correct Century"). Flat — one directory, one file
per kit, no further nesting, no `variants` sub-entities, same reasoning
as [`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — the sole kit has a documented
lineup number, kept unprefixed for consistency with every other HG
sub-line's flat-naming exception.

## Sourcing

Same `allpages&apprefix=HGCC ` + `redirects=1` method as
[`../hguc/CLAUDE.md`](../hguc/CLAUDE.md) — 3 raw pages (two are
alternate-title redirects) resolved to a single real kit,
`SYSTEM ∀-99 ∀ Gundam` (the ∀ is the character's actual in-universe
symbol, kept as-is in `name`; the slug drops it to plain ASCII, same
non-ASCII-in-slug handling as every other sub-line).

**This kit's `Classification` field lists both HGCC and HGUC** (`High
Grade Correct Century, High Grade Universal Century;High Grade Universal
Century (Part of the lineup)`) and it carries a real `Lineup no. = 177` —
but it is **not** already filed under [`../hguc/CLAUDE.md`](../hguc/CLAUDE.md)
(confirmed by search), and both the page's own title and its opening
prose call it an HGCC kit unambiguously ("The High Grade Correct Century
(HGCC) 'SYSTEM ∀-99 ∀ Gundam' ..."). Filed here, under its primary
HGCC prefix, not duplicated into HGUC.
