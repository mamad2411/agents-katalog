# HGFC (High Grade Future Century) — curation hints

The High Grade prefix for Mobile Fighter G Gundam's Future Century
timeline. Flat — one directory, one file per kit, no further nesting, no
`variants` sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — only 5 of 11 kits (45%) have a
documented lineup number, same MG/RG/EG/PG/SD/HG*-flat-naming exception.

## Sourcing

Same `allpages&apprefix=HGFC ` + `redirects=1` method as
[`../hguc/CLAUDE.md`](../hguc/CLAUDE.md) — 26 raw pages resolved to only 11
real unique kits, the heaviest redirect-dedup ratio of any HG sub-line so
far (58%). Most of the dedup came from alternate title spellings pointing
at the same page (`Burning Gundam`/`God Gundam` are both the fighting-form
name for `GF13-017NJII God Gundam`; `Nobel Gundam`/`Noble Gundam` are a
spelling-variant pair; `Dark Army`/`Death Army` likewise), not from
`/Variants` navigational subpages (none found here).

**One real combo-boxed item**: `God Gundam vs Master Gundam - School of
Toho Fuhai Hyper Mode Set` bundles two mobile suits (`Model of` lists
both) as a single JAN'd release — filed as one item per the standard
"one distinctly-boxed release, one item" rule, not split into its
components.

**Bare "unreleased" keyword hit was a false positive, same lesson as every
prior sub-line** — `GF13-050NSW Nobel Gundam`'s page mentions an
"unreleased Master Grade" version in its Notes & Trivia section, referring
to a different grade's kit entirely, not this HGFC one (which has a real
`Lineup no. = 119` and `Release Date = January 9, 2011`).

**Four kits deferred `Release Date` to a `==Release Dates==` section**
(`[[...#Release Dates|See below]]`) — read by hand: `Death Beast` (July
2020 First Batch), `Gundam Maxter` (November 2023), `Gundam Rose` (March
2023), `Mandor Gundam` (November 2025 First Batch, second batch January
2026 — recorded first-release date only).

**Images**: 11 of 11 kits had a usable infobox `image`, all verified HTTP
200.
