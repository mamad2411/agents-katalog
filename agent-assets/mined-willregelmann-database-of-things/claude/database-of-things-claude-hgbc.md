# HGBC (High Grade Build Custom) — curation hints

A High Grade prefix for **add-on weapon and accessory sets** used to
customize other HG kits, tied to Gunpla Battle-themed media (Build
Fighters, Build Divers) — a sibling pattern to
[`../hgiba/CLAUDE.md`](../hgiba/CLAUDE.md)'s Iron-Blooded Arms sets. Each
set is sold as its own boxed, JAN'd, HG-classified kit
(`Classification = High Grade Build Custom`), a legitimate item per
[`../../../../CLAUDE.md`](../../../../CLAUDE.md) even though it's not a
full mobile suit. Flat — one directory, one file per kit, no further
nesting, no `variants` sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — 10 of 11 kits have a documented
lineup number, same MG/RG/EG/PG/SD/HG*-flat-naming exception.

## Sourcing

Same `allpages&apprefix=HGBC ` + `redirects=1` method as
[`../hguc/CLAUDE.md`](../hguc/CLAUDE.md) — 11 raw pages resolved to 11
real unique kits (no redirect dedup at all this time), no
unreleased/`{{Canceled}}` kits found.

**One kit is genuinely non-scale (`1/1`)**: `Build Custom GP Base` is a
display base/prop, not a scaled mobile-suit model — recorded as `1/1`
rather than the sub-line's usual `1/144`, same "verify per kit, don't
assume the grade's typical scale" rule as
[`../../CLAUDE.md`](../../CLAUDE.md).

**A release date can be typed into the wrong infobox field entirely** —
`Diver Ace Unit`'s infobox has a blank `Release Date =` but a literal date
(`May 11, 2018`) sitting in the unrelated `Need paint? =` field (which
should hold Yes/No) — an editor's copy-paste/fat-finger error, not a
missing value. Recovered by reading the misplaced field rather than
treating the kit as an undated gap; worth checking adjacent Yes/No-typed
fields for a stray date before giving up on a blank `Release Date`.

**Images**: 11 of 11 kits had a usable infobox `image`, all verified HTTP
200 (one transient 503 on first pass, resolved on retry).
