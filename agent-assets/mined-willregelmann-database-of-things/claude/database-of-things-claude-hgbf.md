# HGBF (High Grade Build Fighters) — curation hints

Covers mobile suits from the 2013-2015 *Gundam Build Fighters* anime at
1/144 scale. Flat — one directory, one file per kit, no further nesting,
no `variants` sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — 28 of 38 kits (74%) have a
documented lineup number, same flat-naming exception as every other
sub-line so far.

## Sourcing

Same `allpages&apprefix=HGBF ` + `redirects=1` method as
[`../hguc/CLAUDE.md`](../hguc/CLAUDE.md) — 65 raw pages resolved to 39
real targets. One (`KUMA-03 Beargguy III/Variants`) is a `/Variants`
navigational subpage, excluded — its links surfaced 8 new candidate
titles this time (unlike most sub-lines, which found none), all
confirmed genuine redlinks with no page written yet, deferred rather
than fabricated.

**A sixth infobox template variant found: `{{B-Club_Infobox}}`** — the
base `KUMA-03 Beargguy III` kit itself (not a variant, the real numbered
kit that the `/Variants` subpage belongs to) uses this instead of any of
the `Plamo`/`Gunpla`-prefixed forms documented elsewhere. "B-Club" is
Bandai's limited/garage-kit sub-brand name — worth grepping for on any
future sub-line that returns a page with no infobox under the usual
patterns.

**Images**: all 38 kits had a usable infobox `image` — no fallback
photos needed. 32 of 38 have a date; 6 defer to "See below" sections.
