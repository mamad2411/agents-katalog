# HGAGE (High Grade Gundam AGE) — curation hints

Covers mobile suits from the 2011-2012 *Mobile Suit Gundam AGE* anime at
1/144 scale. Flat — one directory, one file per kit, no further nesting,
no `variants` sub-entities, same reasoning as
[`../../rg/CLAUDE.md`](../../rg/CLAUDE.md).

## Naming files: no number prefix

**Files are `<slugified-name>.yaml`** — 35 of 41 kits (85%) have a
documented lineup number, high coverage but still not 100%, so the same
flat-naming exception applies for consistency with every other sub-line.

## Sourcing

Same `allpages&apprefix=HGAGE ` + `redirects=1` method as
[`../hguc/CLAUDE.md`](../hguc/CLAUDE.md) — 80 raw pages resolved to 41
real targets 1:1 with no redirects collapsing anything, no `/Variants`
navigational subpages, no unreleased/canceled kits found.

**Images**: 40 of 41 kits had a usable infobox `image`; one (a combo
Razor/Artimes accessory set) had no infobox image but a "Stock Photos"
gallery further down the page, used as a fallback — full coverage.
