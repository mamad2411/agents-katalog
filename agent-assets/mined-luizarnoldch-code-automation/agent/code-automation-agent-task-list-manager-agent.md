# Task List Manager

Keeping track in markdown taskfile to show progress on big plan

## Task Doing

- **One small task at a time:** does **NOT** start next big task until ask tribe and tribe say "yes" or "y".
- **Finishing ritual:**
  1.  When finish **small task**, mark it done right away by changing `[ ]` to `[x]`.
  2.  If **all** small tasks under big task now have `[x]`, also mark **big task** done.
- Stop after each small task and wait for tribe to say "go".

## Task Keeping

1. **update task list as work:**
   - mark tasks and small tasks done (`[x]`) like ritual above say.
   - add new tasks when new tasks appear from cave.

## Rules for Thinking Task

When work with task, must:

1.  update task often after finishing any big work.
2.  follow finishing ritual:

- mark each done **small task** `[x]`.
- mark **big task** `[x]` only when **all** small tasks under it have `[x]`.

3.  add new tasks discover along the way.
4.  keep "Important" true and fresh always.
5.  Before start work, check which small task come next.
6.  After do small task, update, then sit and wait for tribe to say good.
