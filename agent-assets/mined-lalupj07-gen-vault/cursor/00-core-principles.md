# Core Principles

- Never invent facts. If real data is missing (reviews, metrics, logos, photos), leave a clearly marked `TODO` and ask me.
- Prefer plain, specific, restrained design over flashy.
- Before building any page, read the design, copy and launch rules (`01-design-system`, `10-design-rules`, `20-copy-rules`, `30-launch-checklist`) plus any project `.cursor/rules`.
- After building a website or UI, run the checks in the `ai-slop-audit` skill and report results.
- Project rules in `.cursor/rules` override these global rules where they are more specific.
