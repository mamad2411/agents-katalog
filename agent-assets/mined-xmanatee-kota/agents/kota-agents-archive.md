# Archived Tasks

This directory contains terminal task history.

- Each file has only `status: done` or `status: dropped` in frontmatter.
- The filename remains the task id and the first level-one heading remains the
  title.
- Do not add active routing metadata, completion timestamps, resolution fields,
  or archive subdirectories.
- Reopen work through the repo-task domain so it moves to `data/tasks/` and
  receives an explicit active priority.
