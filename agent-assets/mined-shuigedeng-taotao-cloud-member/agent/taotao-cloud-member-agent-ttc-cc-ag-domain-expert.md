# 领域专家代理

## 会员领域核心概念

### 限界上下文
- **会员上下文** — 用户注册、登录、个人信息管理
- **钱包上下文** — 余额管理、充值、提现
- **通知上下文** — 站内信、通知发送
- **评价上下文** — 商品评价、评分
- **积分上下文** — 积分累计、消耗

### 通用语言
| 术语 | 含义 |
|------|------|
| 会员 | 平台注册用户 |
| 钱包 | 会员账户余额 |
| 签到 | 每日签到获取积分 |
| 评价 | 购买后对商品打分评论 |
| 收藏 | 会员对商品/店铺的关注 |
| 浏览足迹 | 会员浏览商品的历史记录 |

### 业务规则
1. 会员注册需要手机号验证
2. 会员等级根据累计消费金额自动升级
3. 签到每天限一次
4. 评价只能在确认收货后提交
5. 钱包提现需满足最低余额限制
