# Skills Directory

Skills organized by domain.

## Contents

| Directory | Purpose |
|-----------|---------|
| `foundation/` | Core skills that load with every mode |

## Foundation Skills

Skills in `foundation/` are ALWAYS active:
- `asking-users/` - AskUserQuestion protocol

## Adding Skills

1. Create directory: `skills/domain/skill-name/`
2. Add `SKILL.md` following template
3. Reference in mode YAML

See `templates/skill.md.template` for the skill template.
