# Foundation Skills

Core skills that load with EVERY mode.

| Skill | Purpose |
|-------|---------|

## Foundation Status

These skills are PARAMOUNT. They cannot be disabled by any mode.

Mode-specific skills stack on top of foundation, they never replace it.

## Adding Foundation Skills

Foundation skills should be:
- Essential for all workflows
- Low token cost
- Non-optional safety gates
