# Cline Rules

このプロジェクトの開発・メンテナンスに関するルールです。

## シーン追加時のルール

1. **READMEの更新**
   - 新しいシーンを追加した際は、必ずREADMEの「実装済みシーン一覧」セクションに追加したシーンの情報を記載してください
   - 記載する内容は以下の形式に従ってください：
     ```
     ## N. シーン名（日本語名）
     - **概要**: シーンの簡潔な説明
     - **特徴**:
       - 特徴1
       - 特徴2
       - ...
     - **主要パラメータ**:
       - パラメータ名: 説明（値の範囲）
       - ...
     ```

2. **index.htmlの更新**
   - 新しいシーンのJavaScriptファイルを`docs/js/scenes/`ディレクトリに追加した後、必ず`docs/index.html`にscriptタグを追加してください

## コミュニケーションのルール

1. **attempt_completionは簡潔に**
   - ユーザーはgit diffの出力を読む習慣があります
   - タスク完了時のメッセージは冗長にせず、簡潔に記述してください
   - 実施した内容を箇条書きで簡潔に列挙する程度で十分です
   - 不必要な説明や重複する情報は避けてください

2. **コードの変更点は明確に**
   - コードを変更した場合は、変更した内容を明確に説明してください
   - 大きな変更の場合は、変更前と変更後の違いを簡潔に説明してください


## 動作確認

- 完成後は、openコマンドでユーザーに内容をチェックしてもらうのではなく、エージェントがブラウザアクションをつかって中身をチェックします
- ビジュアルを確認して批評してください。既存のCGアートの歴史を参照して、新たな提案やアドバイスもしてみてください。
