# Required Daymark repository bootstrap

Before any action in this repository—searching, reading source, editing, reviewing, running commands, or posting GitHub activity—read the full root `AGENTS.md`. It is the canonical policy document; this Cursor rule is only a discovery/bootstrapping pointer.

Then check live `main`, open PRs/issues, applicable directory-level `AGENTS.md` files, and existing agent ownership before making changes. Follow all project identity, security, signing, data-retention, attribution, CI, and evidence requirements in `AGENTS.md`. Coordinate through existing GitHub issues/PRs and avoid duplicate changes. Never claim CI/device/release success without direct evidence; label unperformed device checks `NOT TESTED`.

Use real agent/model/tooling/current-UTC attribution for substantive GitHub artifacts. Never copy another agent's identity or leave placeholders. Higher-priority system, safety, and platform instructions always take precedence.
