# Three-question UI

Every page and major panel must answer these immediately:

1. **What is happening?** — current state in plain language (not a decorative eyebrow).
2. **What should I do next?** — one primary action, contextual and obvious.
3. **Where do I go for more?** — clear path to detail / history / settings. Never make users hunt.

## Rules

- Nothing exists because it was easy. Every element must earn its place.
- Prefer one primary CTA over button clusters.
- Do not stretch labels with heavy letter-spacing uppercase chrome.
- Live/operational data stays above the fold; analytics live in expandable / secondary areas.
- If the user would wonder “where is X?”, rename, regroup, or add an explicit link — don’t add clutter.

## Pattern

```text
[Status sentence]     ← happening
[Primary action]      ← next
[Essential metrics]   ← support the decision
[More / Explorer]     ← deeper info on demand
```

## Bad vs good

```text
❌ "Driver OS 4.0" + three equally weighted buttons + six cramped cards
✅ "Off shift · Lunch rush" + [Start shift] + four readable cards + Explorer for the rest
```
