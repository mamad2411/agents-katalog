# Dotfiles

Personal dotfiles. Each top-level directory is a GNU stow package stowed into `$HOME` by `stowall.sh` (uses `--no-folding`). `NOTES/` holds research notes, `NOT_STOW/` holds unstowed material.

## Agent skills

### Issue tracker

Issues and specs live as local markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels plus a terminal `resolved` label. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context. See `docs/agents/domain.md`.
