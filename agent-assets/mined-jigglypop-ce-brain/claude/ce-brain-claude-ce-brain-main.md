# CE 작업 지침

## 세션 시작 (먼저)
- `ledger/STATE.md` 한 파일만 먼저 읽는다. 공리 상태, 지도, 결함 목록(D번호), 작업 대기열이 거기 있다
- `prd/`, 논문 전체, 옛 산출물은 다시 읽지 않는다. STATE.md가 가리키는 파일:줄과 논문 §만 연다
- 작업이 끝나면 STATE.md의 결함·대기열·탐색·로그를 고치고 `python -m tools.sync_readme`를 돌린다
- 기존 결과 JSON과 원장 줄은 고치지 않는다. 기준이나 방법이 바뀌면 새 단계(재판정 r 또는 새 번호)로 만든다

## 핵심 전제
- 우리가 CE-BRAIN에서 하려는 것은 “고정된 뉴런들의 전기적 상호작용과 과거 흔적이, 어떻게 기억·학습·현재의 세계모델을 만들어 내는가”를 하나의 공통 구조로 설명하는 것
- 뉴런은 고정된 점이고, 변하는 것은 그 점의 상태와 관계다
- 뇌의 현재 상태에는 과거의 흔적이 포함된다
- 기능적 거리와 변화 비용은 리만 계량으로 표현한다
- 계량과 신호의 방향성은 구분한다
- 학습과 기억을 활동 이력에 따른 관계·계량 변화로 연결한다
- 해마를 기억의 주소 지정·검색 구조로 볼 수 있는가
- 여러 가능한 표현 중 하나가 ‘지금 여기의 세계’로 선택된다

## 문서와 연구
- 반드시 생물학적 논문값 혹은 근거와 맞아야 하고, 맞는 식이 기준이 된다
- 정확도가 높은 식을 기준으로 세우고 역증명으로 헤결하며, 아이디어를 제공 시 구체화해본다
- 결과지향적으로 식 완성해가며, maleCNS에서 패턴을 찾아내서 공리를 확립한다
