# case-type-guide: 类案办理指南 Skill

## 概述

基于《上海法院类案办案要件指南》（8册46类案件）的专业法律办案指引工具，为律师等专业法律从业者提供：
- 案件类型智能识别
- 要件式审判清单生成
- 双向视角分析（原告/被告）
- 案件材料智能补强建议
- 知识图谱可视化

## 适用场景

1. **案件类型查询**：了解特定案件类型的六段式审判框架
2. **案情分析**：根据案情描述识别案件类型并生成要件清单
3. **材料补强**：分析现有案件材料，提出补强建议
4. **双向视角**：从原告或被告视角分析案件策略
5. **知识图谱**：生成案件类型的可视化思维导图

## 核心方法论：上海法院六段式审判框架

```
第一部分：总体情况概述
├── 审理情况（案件数量、趋势）
├── 案件特点（争议焦点、难点）
└── 审判原则（法律适用原则）

第二部分：立案审查
├── 主管审查
├── 管辖审查
└── 当事人主体审查

第三部分：原告诉请的审查
└── 各项诉讼请求的审查要点

第四部分：被告抗辩的审查
└── 各类抗辩理由的审查要点

第五部分：要件事实审查和裁判规则
├── 核心法律关系的认定
├── 各要件事实的审查要点
└── 证据规则

第六部分：知识图谱
└── 核心要点可视化总结
```

## 使用方式

### 模式一：案件类型查询

```
用户："民间借贷纠纷案件如何办理？"

输出：
- 完整的六段式审判框架
- 审查要点、注意事项、法律依据
- 典型案例参考
```

### 模式二：案情描述分析

```
用户："我借给朋友10万元，有借条，通过微信转账5万元、现金交付5万元，
现在他一直不还，我该怎么办？"

输出：
1. 案件类型识别：民间借贷纠纷（置信度）
2. 要件清单：
   - 借贷合意（借条审查）
   - 资金交付（转账凭证+现金交付证明）
   - 利息约定（如有）
   - 还款事实
3. 证据清单：必需证据、重要证据、补充证据
4. 补强建议：现金交付部分需要补强证据
5. 下一步建议：收集证据 → 协商/发函 → 起诉
```

### 模式三：材料补强分析

```
用户：[上传起诉状和部分证据材料]

输出：
1. 材料分析：
   - ✅ 已具备材料清单
   - ❌ 缺失材料清单
2. 补强建议：
   - 🔴 优先级1（致命缺失，必须补强）
   - 🟡 优先级2（重要缺失，建议补强）
   - 🟢 优先级3（补充缺失，可后置）
3. 胜诉概率评估：
   - 当前要件完成度：X%
   - 补强后预计完成度：Y%
```

### 模式四：双向视角分析

```
用户："我是被告，这笔钱已经还了一部分，该怎么抗辩？"

输出（被告视角）：
1. 抗辩策略：
   - 已还款抗辩
   - 证据要求：还款凭证、收条
   - 法律依据：民法典第563条
2. 反证清单：
   - 必需：还款凭证
   - 重要：借款合同中关于还款的约定
3. 原告主张薄弱点分析
4. 预期效果评估
```

## 输出风格要求

### 专业性
- ✅ 使用法言法语
- ✅ 引用具体法律条文（法律名称+条款）
- ✅ 强调法律依据、司法解释、裁判规则
- ✅ 引用上海法院指南中的典型案例

### 实务性
- ✅ 提供可操作的办案指引
- ✅ 明确证据清单（必需/重要/补充）
- ✅ 标注注意事项和易错点
- ✅ 给出具体的补强建议

### 结构化
- ✅ 使用六段式框架
- ✅ 要件式、要素式表述
- ✅ 清晰的层级结构
- ✅ 可视化知识图谱（Mermaid格式）

## 技术实现

### 核心模块

#### 1. 案件类型识别 (`core/case_identifier.py`)
- 关键词匹配（快速路径）
- 语义相似度匹配（兜底）
- 输出：案件类型 + 置信度 + Top-3候选

#### 2. 要件清单生成 (`core/checklist_generator.py`)
- 基于六段式框架
- 根据用户角色筛选（原告/被告/中立）
- 生成可检核的checkbox清单

#### 3. 双向分析引擎 (`core/bidirectional_analyzer.py`)
- 原告视角：优势/劣势/证据缺失/诉请建议
- 被告视角：抗辩策略/反证清单/薄弱点分析

#### 4. 材料补强建议 (`core/reinforcement_advisor.py`)
- 识别缺失要素
- 匹配补强建议模板
- 按优先级排序（1-5级）

#### 5. 知识图谱生成 (`core/graph_generator.py`)
- Mermaid思维导图（要件层级）
- Mermaid流程图（办案流程）
- Mermaid雷达图（完成度评估）

### 数据结构

#### SQLite数据库
- `case_types`：案件类型主表
- `case_frameworks`：六段式框架表
- `review_points`：审查要点表
- `evidence_checklists`：证据清单表
- `reinforcement_templates`：补强建议模板表

#### 向量索引
- 案件类型描述embedding（384维）
- 典型案例embedding
