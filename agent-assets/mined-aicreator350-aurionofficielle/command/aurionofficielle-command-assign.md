Assigner une nouvelle tâche à un agent existant.

## Usage
`/agents:assign [agent-id] [nouvelle tâche]`

## Instructions

1. Vérifier que l'agent existe et est disponible (idle ou done)
2. Sauvegarder son état précédent
3. Charger le contexte pour la nouvelle tâche
4. Assigner et lancer la nouvelle tâche
5. Confirmer l'assignation
