Demander une review du code écrit pendant la session de pair.

## Usage
`/pair:review`

## Instructions

1. Collecter tous les changements de la session
2. Exécuter une review multi-dimensions :
   - TypeScript strict compliance
   - Sécurité (CSRF, sanitization)
   - Performance (renders, queries)
   - Patterns Aurion (design system, conventions)
3. Calculer le truth-score global
4. Proposer les améliorations si score < 0.95
5. Approuver si score ≥ 0.95
