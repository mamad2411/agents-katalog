Changer les rôles driver/navigator pendant une session de pair.

## Usage
`/pair:switch`

## Instructions

1. Sauvegarder l'état actuel de la session
2. Inverser les rôles :
   - Si driver → passer en navigator
   - Si navigator → passer en driver
3. Transférer le contexte au nouveau rôle
4. Résumer ce qui a été fait jusqu'ici
5. Confirmer le nouveau rôle et continuer
