Analyse profonde avant de toucher au code.

Avant d'écrire UNE SEULE LIGNE de code :

1. Lis le CLAUDE.md du répertoire courant
2. Lis docs/gaps.md pour le contexte global
3. Lis TOUS les fichiers qui seront impactés par le changement
4. Identifie les dépendances et effets de bord
5. Propose 3 approches différentes avec pour chacune :
   - Description en 2-3 phrases
   - Fichiers modifiés
   - Risques et effets de bord
   - Estimation de complexité (1-5)
6. Recommande la meilleure approche avec justification
7. Attends confirmation avant de coder

Utilise le niveau de réflexion maximum. Prends ton temps.
Le but est d'éviter de casser quelque chose en croyant le corriger.
