# Stat Card Component

Statistics display card for dashboard metrics with icon and trend.

## Files

| File                       | What                                       | When to read                 |
| -------------------------- | ------------------------------------------ | ---------------------------- |
| `stat-card.component.ts`   | Stat card rendering, variant styling       | Modifying stat card behavior |
| `stat-card.component.html` | Stat card template with value, label, icon | Changing stat card layout    |
| `stat-card.types.ts`       | Stat card variant type definitions         | Type definitions             |
