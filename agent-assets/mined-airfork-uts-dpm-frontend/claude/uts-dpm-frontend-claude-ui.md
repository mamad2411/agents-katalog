# UI Component Library

Reusable standalone Angular components using signals architecture and Tailwind CSS.

## Directories

| Directory       | What                                                                | When to read                   |
| --------------- | ------------------------------------------------------------------- | ------------------------------ |
| `button/`       | Button component with variants (primary, secondary, ghost, outline) | Adding buttons, button styling |
| `card/`         | Card component with variants (default, elevated, outlined)          | Card layouts                   |
| `modal/`        | Modal dialog with sizes (sm, md, lg, xl)                            | Modal dialogs, overlays        |
| `badge/`        | Badge component with status variants                                | Status indicators              |
| `avatar/`       | Avatar component with gradient and ring variants                    | User avatars                   |
| `stat-card/`    | Statistics card for metrics display                                 | Dashboard stats                |
| `data-table/`   | Paginated table with sorting                                        | Data tables, pagination        |
| `tabs/`         | Tabbed interface with keyboard navigation                           | Tab navigation                 |
| `date-picker/`  | Date picker wrapping PrimeNG                                        | Date selection                 |
| `autocomplete/` | Autocomplete input wrapping PrimeNG                                 | Search/select inputs           |
| `collapsible/`  | Collapsible content panel                                           | Expandable sections            |
| `confirm-box/`  | Confirmation dialog for destructive actions                         | Delete confirmations           |
| `form-field/`   | Form input with validation and ControlValueAccessor                 | Form inputs                    |
| `page-header/`  | Page header with icon and title                                     | Page headers                   |
| `empty-state/`  | Empty/zero state display                                            | No data states                 |
| `navbar/`       | Application navigation bar                                          | Navigation                     |
| `skeleton/`     | Loading skeleton placeholders for perceived performance             | Adding loading states          |
