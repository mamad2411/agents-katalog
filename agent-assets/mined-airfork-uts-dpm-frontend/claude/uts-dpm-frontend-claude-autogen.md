# Autogen Component

Auto-generation tool for bulk DPM creation with file upload.

## Files

| File                     | What                                             | When to read               |
| ------------------------ | ------------------------------------------------ | -------------------------- |
| `autogen.component.ts`   | Auto-generation logic, file parsing, submission  | Modifying autogen behavior |
| `autogen.component.html` | File upload form, preview table, submit controls | Changing autogen UI        |
