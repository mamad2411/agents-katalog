# Avatar Component

User avatar with initials, gradient backgrounds, and optional ring styles.

## Files

| File                    | What                                                | When to read              |
| ----------------------- | --------------------------------------------------- | ------------------------- |
| `avatar.component.ts`   | Avatar rendering, variant styling, size computation | Modifying avatar behavior |
| `avatar.component.html` | Avatar template with initials display               | Changing avatar layout    |
| `avatar.types.ts`       | Avatar variant and size type definitions            | Type definitions          |
