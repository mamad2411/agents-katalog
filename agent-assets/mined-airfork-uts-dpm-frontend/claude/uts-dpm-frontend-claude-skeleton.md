# Skeleton Components

Loading placeholder components that match content layout for perceived performance.

## Files

| File                           | What                                                      | When to read                          |
| ------------------------------ | --------------------------------------------------------- | ------------------------------------- |
| `index.ts`                     | Barrel exports for all skeleton components                | Importing skeleton components         |
| `skeleton.component.ts`        | Base skeleton with configurable width, height, rounded    | Creating simple loading placeholders  |
| `table-skeleton.component.ts`  | Table skeleton with rows, columns, optional header/avatar | Adding loading state to tables        |
| `card-skeleton.component.ts`   | Mobile card skeleton with count and avatar options        | Adding loading state to card lists    |
| `select-skeleton.component.ts` | Form select skeleton with optional label                  | Adding loading state to select inputs |
