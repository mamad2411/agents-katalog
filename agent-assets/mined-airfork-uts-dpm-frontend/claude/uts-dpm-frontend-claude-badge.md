# Badge Component

Status badge with variant colors for success, error, warning states.

## Files

| File                   | What                                    | When to read             |
| ---------------------- | --------------------------------------- | ------------------------ |
| `badge.component.ts`   | Badge styling logic, variant classes    | Modifying badge behavior |
| `badge.component.html` | Badge template with icon and text slots | Changing badge layout    |
| `badge.types.ts`       | Badge variant type definitions          | Type definitions         |
