## Files

| File                   | What                                              | When to read                   |
| ---------------------- | ------------------------------------------------- | ------------------------------ |
| `login.component.ts`   | Login form state, validation, authentication call | Modifying login behavior       |
| `login.component.html` | Login form with username/password fields          | Changing login UI, form layout |
