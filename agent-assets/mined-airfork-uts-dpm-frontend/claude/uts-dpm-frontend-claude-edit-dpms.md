# Edit DPM Types Component

Drag-and-drop editor for DPM type groups and individual DPM configurations.

## Index

| File                          | Contents (WHAT)                                            | Read When (WHEN)                                   |
| ----------------------------- | ---------------------------------------------------------- | -------------------------------------------------- |
| `edit-dpms.component.ts`      | DPM groups state, drag-drop logic, color modal, save logic | Modifying DPM type editor, fixing drag-drop issues |
| `edit-dpms.component.html`    | Group cards, sticky save bar, color swatch modal           | Changing editor layout, updating visual design     |
| `edit-dpms.component.css`     | Drag placeholder styling, sticky save bar positioning      | Fixing drag-drop feedback, adjusting save bar      |
| `edit-dpms.component.spec.ts` | Component unit tests                                       | Writing tests, debugging test failures             |
