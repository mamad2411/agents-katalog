# Pipes

Custom Angular pipes for data transformation and display formatting.

## Files

| File                     | What                                 | When to read              |
| ------------------------ | ------------------------------------ | ------------------------- |
| `PointsPipe.ts`          | Formats point values with +/- prefix | Points display formatting |
| `BlockPipe.ts`           | Formats block/shift names            | Block name display        |
| `NamePipe.ts`            | Formats user names from driver ID    | Name display from ID      |
| `color-by-id.pipe.ts`    | Gets color hex code by DPM type ID   | DPM color display         |
| `points-display.pipe.ts` | Alternative points formatting        | Points display            |
