# DPM Page Component

Main DPM creation page with tabbed interface for create and edit modes.

## Files

| File                         | What                                          | When to read                |
| ---------------------------- | --------------------------------------------- | --------------------------- |
| `dpm-page.component.ts`      | Tab state, route handling, DPM groups loading | Modifying DPM page behavior |
| `dpm-page.component.html`    | Tabs for create/edit, role-based visibility   | Changing page layout        |
| `dpm-page.component.css`     | Page-specific styles                          | Adjusting styling           |
| `dpm-page.component.spec.ts` | Component unit tests                          | Testing, debugging tests    |
