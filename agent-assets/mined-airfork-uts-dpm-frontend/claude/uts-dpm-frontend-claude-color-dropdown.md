# Color Dropdown Component

Color picker dropdown for DPM type color selection.

## Files

| File                            | What                                  | When to read                    |
| ------------------------------- | ------------------------------------- | ------------------------------- |
| `color-dropdown.component.ts`   | Color selection logic, dropdown state | Modifying color picker behavior |
| `color-dropdown.component.html` | Color swatch grid dropdown            | Changing color picker UI        |
| `color-dropdown.component.css`  | Color dropdown styling                | Adjusting color picker styles   |
