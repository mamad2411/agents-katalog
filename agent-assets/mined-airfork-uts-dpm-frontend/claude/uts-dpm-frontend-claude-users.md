# Users Module

User management features including listing, viewing details, and CRUD operations.

## Directories

| Directory      | What                               | When to read             |
| -------------- | ---------------------------------- | ------------------------ |
| `users/`       | Users wrapper component            | User section layout      |
| `users-list/`  | Paginated user table               | User listing, pagination |
| `user-detail/` | User profile with DPM history tabs | Viewing user details     |
| `user-form/`   | User create/edit form              | User CRUD operations     |
| `shared/`      | Shared user types and utilities    | Reusable user logic      |
