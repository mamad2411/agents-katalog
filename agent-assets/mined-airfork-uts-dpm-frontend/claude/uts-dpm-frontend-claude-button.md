# Button Component

Reusable button with primary, secondary, ghost, and outline variants.

## Files

| File                    | What                                                  | When to read              |
| ----------------------- | ----------------------------------------------------- | ------------------------- |
| `button.component.ts`   | Button styling logic, variant classes, disabled state | Modifying button behavior |
| `button.component.html` | Button template with content projection               | Changing button layout    |
| `button.types.ts`       | Button variant and size type definitions              | Type definitions          |
