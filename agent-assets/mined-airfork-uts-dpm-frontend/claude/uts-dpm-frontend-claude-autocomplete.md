# Autocomplete Component

Typeahead input wrapping PrimeNG autocomplete with ControlValueAccessor.

## Files

| File                          | What                                                | When to read                    |
| ----------------------------- | --------------------------------------------------- | ------------------------------- |
| `autocomplete.component.ts`   | Autocomplete logic, filtering, ControlValueAccessor | Modifying autocomplete behavior |
| `autocomplete.component.html` | PrimeNG autocomplete template with styling          | Changing autocomplete UI        |
| `autocomplete.types.ts`       | Autocomplete option type definition                 | Type definitions                |
