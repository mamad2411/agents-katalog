# Error Pages

Error handling UI components for HTTP errors and navigation failures.

## Directories

| Directory     | What                         | When to read           |
| ------------- | ---------------------------- | ---------------------- |
| `error-page/` | Generic error page component | Reusable error display |
| `forbidden/`  | 403 Forbidden error page     | Access denied handling |
| `not-found/`  | 404 Not Found error page     | Missing page handling  |
