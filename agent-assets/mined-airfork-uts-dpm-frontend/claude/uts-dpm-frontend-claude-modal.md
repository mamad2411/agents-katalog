# Modal Component

Dialog modal with size variants (sm, md, lg, xl) and header/body/footer slots.

## Files

| File                      | What                                             | When to read             |
| ------------------------- | ------------------------------------------------ | ------------------------ |
| `modal.component.ts`      | Modal state, open/close logic, backdrop handling | Modifying modal behavior |
| `modal.component.html`    | Modal template with header, body, footer slots   | Changing modal layout    |
| `modal.component.spec.ts` | Modal unit tests                                 | Testing, debugging tests |
| `modal.types.ts`          | Modal size type definitions                      | Type definitions         |
