# Error Page Component

Generic error page component for reusable error display.

## Files

| File                        | What                                           | When to read            |
| --------------------------- | ---------------------------------------------- | ----------------------- |
| `error-page.component.ts`   | Error page with configurable title and message | Modifying error display |
| `error-page.component.html` | Error page template with icon and text         | Changing error layout   |
