# Approvals Component

DPM approval queue for managers with approval/denial workflow.

## Files

| File                       | What                                                   | When to read                |
| -------------------------- | ------------------------------------------------------ | --------------------------- |
| `approvals.component.ts`   | Approval list state, approve/deny actions, modal state | Modifying approval workflow |
| `approvals.component.html` | Approval table, detail modal, approve/deny buttons     | Changing approval UI        |
| `approvals.component.css`  | Component-specific styles                              | Adjusting approval styling  |
