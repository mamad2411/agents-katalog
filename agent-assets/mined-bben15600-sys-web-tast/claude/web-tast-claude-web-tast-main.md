# Claude Code

This repo uses [Claude Code](https://claude.com/claude-code).

## Available skills

The `/build-aurora` skill in `.claude/commands/build-aurora.md` orchestrates the full build of a customized Hebrew RTL Life OS dashboard from this template.

When you `Use this template` to create a new repo from this one, run `/build-aurora` in your new project's Claude Code session to walk through the customization phase-by-phase.

## Architecture reference

`docs/AURORA_BUILD_SKILL.md` is the deep architectural reference (~1,700 lines) covering every design decision, integration, and gotcha discovered during the original build. Read it before making non-trivial changes.
