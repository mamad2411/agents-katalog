# Project Rules

## General

- Never invent facts.
- Never assume missing information.
- If information is missing, ask first.
- Preserve existing architecture unless explicitly instructed.
- Do not remove code unless requested.
- Prefer minimal, isolated changes.
- Keep functions small and readable.

## Code Quality

- Write type-safe Python.
- Prefer pathlib over os.path.
- Use logging instead of print().
- Follow existing project structure.
- Do not introduce new dependencies without approval.
- Keep comments concise.

## Atomizer

- Never fabricate content atoms.
- Preserve source references.
- Do not change factual meaning.
- Deduplicate only when semantic equivalence is proven.
- Keep atom metadata intact.

## YouTube Pipeline

- Never invent news or facts.
- Preserve chronology.
- Keep generated content traceable to source atoms.
- Separate extraction from generation.

## Output

- Explain why changes are made.
- List modified files.
- Do not rewrite unrelated code.
- description: A description of your rule
