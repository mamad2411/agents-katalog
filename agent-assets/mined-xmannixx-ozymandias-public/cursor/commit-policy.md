# Commit Policy

- Commits sind verpflichtend, wenn Implementierungsarbeit abgeschlossen ist.
- Commits so granular wie moeglich schneiden (klein, thematisch sauber, klarer Scope).
- Keine Sammel-Commits fuer mehrere unabhaengige Aenderungen.
- Vor jedem Commit die Standard-Checks des betroffenen Stacks laufen lassen.
- Commit-Message klar und praezise nach Zweck formulieren.
