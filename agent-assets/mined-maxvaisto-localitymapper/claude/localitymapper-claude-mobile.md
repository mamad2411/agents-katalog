# mobile

Expo + React Native app. Plain JavaScript.

## Commands

| Task | Command |
|---|---|
| Install deps | `pnpm install` (from repo root) |
| Start dev server | `pnpm start` |
| Run on Android | `pnpm android` |
| Run tests | `pnpm test` |

## Notes

- iOS builds require a Mac or EAS Build. Use Android emulator or Expo Go on device for Windows dev.
- Unit tests run with Jest only — no device required.

## TDD

New code starts with a failing test. Use `/tdd` for any new feature area.
