This repo is for a browser-based character creator for the Mongoose Traveller 2nd Edition tabletop RPG, hosted on GitHub Pages.


General advice:
* Try and avoid using em-dashes (—)
* Extracts of the rules can be found in `docs/rules/` if you need to reference them.
  - `Skills.md` clarifies rules around skills and specialties, and has a quick reference table
  - `Skills List.md` Gives detailed descriptions of each skill and speciality and how they're used in gameplay
  - `Characteristics.md` describes the six characteristics and the rules concerning them
  - `Creation Summary.md` High-level overview of the character creation process with YAML flowchart
  - `Aging.md` describes the rules for aging, anagathics and aging crisis mechanic
  - `Injuries Table.md` Markdown containing the 'injuries table'
  - `Life Events Table.md` Markdown containing the 'life events table'
  - `Medical Bills and Debt.md` rules concerning medical bills, restoring injuries and debt
