# mushanghai-participant-log/AGENTS.md

> Two modes for participants: Daily Log and Recruitment Night. See `../AGENTS.md` for family-level conventions.

## Modes

| Letter | Name | Trigger | Primary Output Path |
|---|---|---|---|
| A | Daily log entry | log my day, today's log, daily reflection | filled markdown log |
| B | BioBloom Recruitment Night | join a BioBloom project, Recruitment Night, evaluate a pitch | participant join decision notes |

## Local Layout

- `SKILL.md` - participant-only router and logging sequence.
- `references/biobloom-recruitment-night.md` - Mode B 4-step join decision process.
- `assets/daily-log-template.md` - Mode A daily entry template.
- `assets/mid-experiment-reflection.md` - optional mid-run reflection.
- `assets/final-reflection.md` - optional final reflection and demo summary.

## Where to Look

| Task | Location | Notes |
|---|---|---|
| Log a day | `assets/daily-log-template.md` | Capture adherence, observation, anomaly, mood. |
| Decide whether to join | `references/biobloom-recruitment-night.md` | Participant evaluation, not proposal drafting. |
| Check mid-run commitment | `assets/mid-experiment-reflection.md` | Use only when asked. |
| Prepare final participant summary | `assets/final-reflection.md` | Use only when asked. |
| Route proposal work away | `SKILL.md` | Hand proposal drafting to EL skill. |

## Local Conventions

- Proof of Living participants opt in before any public posting.
- Private logs remain private, even inside Proof of Living.
- Missed days are logged honestly, never repaired in prose.

## Anti-Patterns (this skill)

- Posting participant data publicly without explicit consent.
- Faking, smoothing, or backfilling a missed day.
- Routing proposal drafting or TL review through participant logging.
- Publishing identifiable raw health data or other people's data.

## Hand-Offs

- Mode B leads to May 17 Recruitment Night enrollment.
- After enrollment, hand to `mushanghai-experiment-leader` Mode A for proposal bootstrap if the participant becomes an EL.
