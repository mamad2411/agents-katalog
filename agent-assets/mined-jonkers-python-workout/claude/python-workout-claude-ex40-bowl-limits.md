# Exercise 40: Bowl Limits

## Requirements

- Extend the work completed in exercise 39: add a class attribute `max_scoops` that functions like a constant that limits the number of Scoops that can be added to a Bowl instance.
- A Bowl can have less than or equal to `max_scoops` Scoops. Further Scoops are ignored.
- Use Pythonic conventions.

## Exercise Notes

- Define the maximum on the class, rather than the instance.
