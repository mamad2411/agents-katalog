# Exercise 32: Flip a dict exercise

## Requirements

- Create a function `flip_dict()` that takes a dict of any size and 'flips' it, i.e., exchanges its keys and values.
- Example:
  - Input: {'a':1, 'b':2, 'c':3}
  - Output: {1:'a', 2:'b', 3:'c'}
- Use Pythonic conventions.

## Exercise Notes

- Use of dict comprehensions is likely to help.
