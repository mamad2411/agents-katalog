# Exercise 44: Cages

## Requirements

- Create a `Cage` class in order to house `Animal` instances introduced in exercise 43.
- Each Cage houses one or more Animals.
- When a Cage is created, a user provides an ID number to discriminate between instances.
- Define a repr method that displays the Cage IDs and the animals in the Cage.
- Example:
  - c1 = Cage(1)
  - c1.add_animals(wolf, sheep)
- Use Pythonic conventions.

## Exercise Notes

- Consider use of the splat operator on parameters provided to add_animals.
- Consider directly extending the code in exercise 43.
