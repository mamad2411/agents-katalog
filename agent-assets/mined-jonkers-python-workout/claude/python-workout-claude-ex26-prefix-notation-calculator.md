# Project: Prefix Notation Calculator Exercise

## IMPORTANT

This CLAUDE.md file is within a subdirectory of the main project. Please see the CLAUDE.md file in the source root directory for overarching context about this Python project.

The relative path of the source root directory is: ../.. (the directory is called python_workout).

## Exercise requirements
- Write a function - calc() - that expects a single argument, a string containing a simple maths expression in prefix notation, with an operator and two parameters.
- The function will parse the input and product the appropriate output.
- It's enough to handle the basic arithmetic operators: addition, subtraction, multiplication, division, modulus (%) and exponentiation (**).
- Normal Python maths rules should work: division results in a floating-point number.
- Use Pythonic conventions.

## Exercise notes
- Implement each of the operations as a separate function. Don't use an 'if' statement to decide which function to run.
- Look at the Python operator module to see how it implements operations.
