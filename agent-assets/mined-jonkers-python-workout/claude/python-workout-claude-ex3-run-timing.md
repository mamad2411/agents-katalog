# Project: Run Timing Exercise

## IMPORTANT

This CLAUDE.md file is within a subdirectory of the main project. Please see the CLAUDE.md file in the source root directory for overarching context about this Python project.

The relative path of the source root directory is: ../.. (the directory is called python_workout).

## Exercise requirements
- Write a function (run_timing) that asks how long it took for you to run 10km (in minutes).
- The function continues to ask how long it took for additional runs, until the user just presses Enter without a value.
- The function calculates and displays the average time that the 10km runs took, then exits.
- Numeric inputs and outputs should all be floating-point values.
- Use Pythonic conventions.

## Exercise notes
- Empty strings can be considered as false in a boolean expression.
- Consider use of try..except for managing invalid input from users.
- Take care with arithmetic operations involving floats due to accuracy issues.
