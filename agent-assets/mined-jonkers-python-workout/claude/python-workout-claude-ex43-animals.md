# Exercise 43: Animals

## Requirements

- You are the director of IT at a zoo.
- The zoo contains several different types of animals, some of which need to be housed together for budget reasons.
- Distinct species of animals are represented as Python classes.
- You can retrieve information about an animal by querying class attributes: colour, species and number of legs.
- Create classes for four different species of animals: Sheep, Wolf, Snake, Parrot.
- If I convert the animal to a string using str or print, I'll get a string back containing its details (species, colour, legs).
- Use Pythonic conventions.

## Exercise Notes

- __init__, __str__, and __name__ are likely to be useful.
- Consider an Animal superclass for common attributes.
