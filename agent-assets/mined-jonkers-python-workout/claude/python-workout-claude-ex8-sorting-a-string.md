## Exercise requirements
- Write a Python function (strsort) that takes a single string as its input and returns a string.
- The returned characters should contain the same characters as the input string, but sorted in order from lowest Unicode value to highest Unicode value.
- Example: 'cba' becomes 'abc'.
- Use Pythonic conventions.

## Exercise notes
- Remember that Python strings are sequences.
- The built-in function sorted() will take an iterable and returns its elements in a sorted list. Note that it returns a list, not a string.
- Recall the use of str.join() to join strings together.
