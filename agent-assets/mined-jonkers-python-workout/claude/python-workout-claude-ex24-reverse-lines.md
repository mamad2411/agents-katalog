## Exercise requirements
- Write a function - reverse_lines() - that reverses all characters (except newline) on a line.
- The function should take two parameters: an input file and an output file.
- Example:
  - For input...
  ```
  abc def
  ghi jkl
  ```
  - ... you get output:
  ```
  fed cba
  lkj ihg
  ```
- Use Pythonic conventions.

## Exercise notes
- Work with more than one object at a time in a with statement.
- Consider using Python's slice syntax to reverse the line (consider negative step sizes). Take care with the newline at the end of the input lines.
