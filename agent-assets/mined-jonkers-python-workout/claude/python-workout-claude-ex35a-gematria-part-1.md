# Exercise 35a: Gematria, part 1

## Requirements

- Create a function `gematria`, that creates a dict whose keys are the letters of the English alphabet and who values are the numbers ranging from 1 to 26 respectively.
- Use a dict comprehension to create the dict.
- Use Pythonic conventions.

## Exercise Notes

- Consider using string.ascii_lowercase to create a string of lowercase letters.
- Consider using enumerate, using indexes in a novel way.
