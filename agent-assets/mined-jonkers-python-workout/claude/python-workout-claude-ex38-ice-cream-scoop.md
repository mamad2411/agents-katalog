# Exercise 38: Ice Cream Scoop

## Requirements

- Define a class `Scoop` that represents a single scoop of ice cream.
- Each Scoop should have a single attribute - `flavour` - that you can initialise when you create the instance of scoop.
- After creating the class, write a function `create_scoops` that creates three Scoop instances, each of which has a different flavour. Put these instances into a list called `scoops`.
- Finally, iterate over the `scoops` list, printing the flavour of each Scoop.
- Use Pythonic conventions.

## Exercise Notes

- Define an __init__ method for the Scoop class that initialises its attributes.
