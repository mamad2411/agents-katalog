## Exercise requirements
- Assume that your Python program contains a list of interesting integers.
- We want to print the number of different integers contained within that list.
- Write a function - how_many_different_numbers() - that takes a single list of integers and returns the number of different integers it contains.
- Example:
  - Consider the following list: numbers = [1, 2, 3, 1, 2, 3, 4, 1]
  - Running len(numbers) will give 7.
  - Running how_many_different_numbers(numbers) will give 4.
- Use Pythonic conventions.
