# Exercise 39: Ice Cream Bowl

## Requirements

- Extend what was created in exercise 38 by defining a class `Bowl` that represents a bowl of ice cream.
- Bowl has a method called `add_scoops` to add one or more Scoops to a bowl.
- Running `print` on an instance of bowl should print out the ice cream flavours in the Bowl (separated by newlines).
- Use Pythonic conventions.

## Exercise Notes
