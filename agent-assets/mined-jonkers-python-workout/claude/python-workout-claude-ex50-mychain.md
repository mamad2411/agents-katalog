# Exercise 50: MyChain

## Requirements

- Reimplement itertools.chain: implement a generator function called `mychain` that takes any number of arguments, each of which is an iterable.
- With each iteration, it should return the next element from the current iterable or the first element from the subsequent iterable. At the end of the last element of the last iterable, the function should exit.
- Use Pythonic conventions.

## Exercise Notes

- The itertools module contains tools to support easy creation of many types of iterators.
- Remember the splat operator.
