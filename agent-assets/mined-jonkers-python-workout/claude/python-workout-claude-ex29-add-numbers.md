## Exercise requirements
- Write a function - add_numbers() - takes a string as an argument and returns the sum of numbers presented.
- The function filters out whitespaced tokens in the string that can't be turned into integers. The function will ignore any word that contains non-digits.
- Example:
  - Input: 10 abc 20 de44 30 55fg 40
  - Output 100
- Use Pythonic conventions.

## Exercise notes
- Use the filtering capability of list comprehensions to ignore tokens containing non-digits.
