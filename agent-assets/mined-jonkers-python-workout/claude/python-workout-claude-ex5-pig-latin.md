## Exercise requirements
- Write a Python function (pig_latin) that converts an assumed English word into Pig Latin.
- In Pig Latin, if the word begins with an English vowel (a, e, i, o, u), add 'way' to the end of the word (e.g., 'eat' becomes 'eatway'). In all other cases, take the first letter, put it at the end of the word and add 'ay' (e.g., 'ball' becomes 'allbay').
- Use Pythonic conventions.

## Exercise notes
- Assume the input word includes no capital letters or punctuation.
- Python sees a string as a sequence. Consider using the built-in in() function to assist with finding vowels.
- Also consider how Python slices can be best applied to the problem.
