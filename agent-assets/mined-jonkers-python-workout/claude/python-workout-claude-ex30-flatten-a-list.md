# Exercise 30: Flatten a List

## Requirements

- Write a function `flatten()` that takes a list of lists (just one element deep) and returns a flat, one-dimensional version of the list.
- Example:
  - Input: `[[1, 2], [3, 4]]`
  - Output: `[1, 2, 3, 4]`
- Use Pythonic conventions.

## Exercise Notes

- The intention of this exercise is to learn how to unravel complex data structures into simpler structures.
- There are multiple ways to solve the exercise. In this exercise, solve it using list comprehensions. Consider the use of multiple loops in a single comprehension.
