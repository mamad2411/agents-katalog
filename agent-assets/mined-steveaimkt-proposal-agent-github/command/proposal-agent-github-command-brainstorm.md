`output/$ARGUMENTS/` 에 캠페인 브레인스토밍을 실행합니다. `brainstorm` 스킬을 사용하세요.

## 절차

### 1. 개별 브레인스토밍 (병렬)

3인 전문가 에이전트가 **서로 보지 않고** 독립적으로 안을 냅니다.

| 에이전트 | 관점 |
|---------|------|
| **전략가** | 시장 포지셔닝, 경쟁 우위, 메시지 구조 |
| **크리에이터** | 컨셉, 비주얼 훅, 실행 아이디어 |
| **데이터 분석가** | 타겟 세그먼트, 채널 효율, KPI 설계 |

### 2. 크로스리뷰 토론

각 안을 나머지 둘이 비평합니다. 비평은 **구체적 근거**를 달아야 합니다.
"약하다"가 아니라 "타겟 20대 여성 기준 채널 도달률이 X% 부족하다".

### 3. 최적안 도출

크로스리뷰를 반영해 **하나의 안**으로 수렴시킵니다.
탈락한 안의 좋은 요소는 흡수하되, 무엇을 왜 버렸는지 기록합니다.

### 4. campaign_brief.md 작성

`output/$ARGUMENTS/campaign_brief.md` 로 저장. 포함 항목:

- 캠페인 컨셉 + 한 줄 정의
- 타겟 정의 (1차/2차)
- 핵심 메시지 3개 → Win Theme 후보
- 채널 전략 + 예산 배분
- KPI + 산출근거
- 탈락안 기록 (무엇을 왜 버렸는가)

## 후속

완료 후 `/p $ARGUMENTS` 로 제안서 파이프라인에 연계합니다.
`campaign_brief.md` 가 있으면 스마트 시작이 **Step 1·2를 건너뛰고 Step 3부터** 시작합니다
(`.claude/rules/smart-start.md` 4순위).
