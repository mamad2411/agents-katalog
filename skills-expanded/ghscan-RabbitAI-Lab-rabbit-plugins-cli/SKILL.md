# nanoid-cli

Generate NanoIDs

## When to Activate

- Installing or setting up **nanoid-cli**
- Running `nanoid` from the command line
- Automating Utilities workflows that nanoid-cli supports

## Installation

Use the bundled installer:

```bash
bash scripts/install.sh
```

or install directly:

```bash
npm install -g nanoid-cli
```

## Verification

```bash
nanoid --version
```

## Usage

Run `nanoid --help` to see available commands and options.

## Details

- **Package**: `nanoid-cli`
- **Category**: Utilities
- **Priority**: Optional
- **Platforms**: Windows / macOS
