# 条件筛选 Skill

## 何时使用

用户需要按条件筛选股票时激活：

- "帮我找 PE 低于 15 的银行股"
- "ROE 大于 20% 的消费股有哪些"
- "找一些低估值高分红的股票"

用户询问市场主线时也激活：

- "怎么找当前主线行情"
- "主线方向是什么"
- "当前强势股有哪些"

## 工作流程

1. **识别意图**：先判断是“条件筛选”还是“主线识别”
2. **条件筛选路径** → `stock_screen`
   - 支持字段：pe, pb, roe, revenue_yoy, profit_yoy
   - 支持行业/板块筛选
3. **主线识别路径** → `market_mainline`
   - 返回：市场阶段、主线方向、主线板块、强势股
   - 可选参数：sector_top_n, strong_limit
   - 用户只问"当前主线和强势股"时，不主动调用 `sync_news`；仅当用户明确要求新闻催化/政策驱动分析时再调用 `stock_news`
4. **结果呈现**：
   - 条件筛选：表格展示（代码、名称、行业、关键指标）
   - 主线识别：先给主线方向，再给主线板块与强势股列表
   - 明确说明使用的数据口径与返回数量
   - 主线回答必须补充“计算口径说明”（板块接口口径 / 行业聚合口径 / 降级推断口径）
   - 未调用 `stock_news` 时，禁止使用“结合最新资讯/新闻催化”等表述

## 条件映射示例

- "低估值" → PE < 15 AND PB < 2
- "高成长" → revenue_yoy > 20 AND profit_yoy > 20
- "高分红" → 需要配合基本面数据判断

## 主线识别输出模板

1. 市场阶段：主升 / 震荡偏强 / 分化震荡 / 震荡偏弱 / 退潮
2. 主线方向：主线前 3 个板块
3. 主线板块：板块名称、涨幅、龙头股、强度标签
4. 强势个股：代码、名称、涨幅、趋势阶段、量比、九转信号
