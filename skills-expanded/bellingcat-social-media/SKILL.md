# Bellingcat Social Media Investigation Tools

Tools for investigating accounts, content, and activity across social media platforms. Covers platform-specific tools and cross-platform username/email search.

## Choosing Tools

- Choose a platform-specific tool when the platform is known; use multi-platform tools to connect usernames or public activity across services.
- Record URLs, timestamps, and account identifiers, and cross-check platform results because search coverage changes frequently.

## Investigation Tips

- Start with cross-platform username search (Sherlock, WhatsMyName, Blackbird) to find accounts across platforms
- For Telegram: use Telegago/Intelligence X for content search, TGStat/Telemetrio for channel analytics
- For Twitter/X: use Advanced Search and Location Search to filter by date, location, and user
- For TikTok: use Bellingcat's TikTok Date Extract and Hashtag Analysis tools for metadata
- For Discord: search public servers via Disboard and use Discord Chat Exporter for archiving
- 4CAT can collect and analyze datasets from multiple social media platforms at scale
