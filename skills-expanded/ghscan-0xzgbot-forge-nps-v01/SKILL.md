# Master Creative Director Skill

This skill acts as the "Brain" of the entire production pipeline. It does not perform mechanical tasks (like generating an image) but instead manages the **expansion** of a concept into a multi-channel reality.

## The Expansion Engine (Multi-Directional Flow)

When given a single idea, the Master Creative Director executes the following expansion paths:

### 1. Visual Identity Path (The "Look")
*   **Goal:** Establish the visual DNA.
*   **Action:** Triggers `brand-consistency-protocol` to define colors, lighting, and textures.
*   **Output:** A "Brand Bible" that feeds into all subsequent generation agents.

### 2. Static Media Path (The "Photos")
*   **Goal:** High-fidelity imagery for web/social.
*   **Action:** Orchestrates `visual-prompt-engineering-master-agent` $\rightarrow$ `image-generation-polish-agent`.
*   **Output:** A library of professional-grade, brand-consistent still images.

### 3. Motion Media Path (The "Videos")
*   **Goal:** Cinematic and high-engagement video content.
*   **Action:** Orchestrates `video-director-ltx25-specialist-agent` $\rightarrow$ `post-production-editing-agent`.
*   **Output:** Broadcast-ready LTX 2.3 videos with cinematic grading and sound design.

### 4. Narrative & Social Path (The "Voice")
*   **Goal:** Platform-native engagement.
*   **Action:** Orchestrates `copywriting-god-agent` $\rightarrow$ `cross-platform-optimization-agent`.
*   **Output:** X threads, Instagram carousels, and YouTube scripts that sound like a single cohesive personality.

### 5. Technical/Abstract Path (The "Animations")
*   **Goal:** Explainer or aesthetic motion graphics.
*   **Action:** Triggers `manim-video` (technical) or `p5js` (generative art).
*   **Output:** High-end mathematical animations or interactive visual experiences.

## Operational Workflow: "Concept to Ecosystem"

1.  **Ingestion:** Receive the core idea/concept.
2.  **Strategic Mapping:** Use `marketing-strategist-agent` to define the target audience and platform priority.
3.  **Brand Initialization:** Run the `brand-consistency-protocol`.
4.  **Parallel Execution:** Dispatch subagents (via `delegate_task`) to work on all paths simultaneously.
5.  **Unified QA:** Use `quality-assurance-iteration-agent` to ensure the video, the photo, and the tweet all feel like they belong to the same universe.

## Pitfalls to Avoid
- **Siloed Creation:** Creating a great video that has no connection to the brand's social media voice.
- **Linear Thinking:** Only thinking "Post $\rightarrow$ Image" instead of "Concept $\rightarrow$ Ecosystem."
- **Complexity Overload:** Trying to do everything at once without first establishing the Brand DNA.
