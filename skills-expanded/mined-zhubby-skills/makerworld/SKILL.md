# MakerWorld 中国站

在 [MakerWorld 中国站](https://makerworld.com.cn/zh) 查找或发布模型。
用户写作 makeworld 或 markworld 时，按 MakerWorld 理解。

先按用户意图选择流程：

- 查找、比较、推荐：读取 [查找流程](references/search.md)。
- 上传、发布、补充发布资料：读取 [上传流程](references/upload.md)。

仅操作本次任务授权的功能。
查找不隐含上传，上传不隐含启动打印。
本技能不提供下载和启动打印流程。
不执行无关的收藏、点赞或评论。

## 接入与需求

复用当前环境中已连接的浏览器工具。
沿用用户指定的浏览器及已登录资料。
不新建隔离会话替代已有登录状态。
不读取或保存密码、Cookie、Token。

先检查中国站页面的登录标志。
“我的”“浏览历史”“收藏”等入口可辅助核验。
若页面要求登录，请用户完成登录后继续。
若工具未连接该浏览器，说明需要连接的资料。
不要把未登录访问报告为已登录核验。
使用当前环境的浏览器工具及其文件选择器。
不以 Cookie 导出、隐藏接口或直连请求代替登录态操作。

## 上传与发布

上传任务按 [中国站上传流程](references/upload.md) 执行。

用户提供有效 Bambu Studio 3MF 时，默认准备首个打印配置。
核对完整成品、切片参数和实打证据。
证据齐全时随模型发布，或追加到已有作品。
证据不足时保存配置草稿，说明缺口。

1. 确认本次发布对象、素材来源及授权范围。
   用户指定另一会话或目录时，读取其最新版本证据。
   区分成品、试装块、参考设备和私人附件。
   检查待公开文件及照片，保留原件。
2. 核对实拍与模型版本，再核对打印配置。
   用户已确认照片为本模型实打时，复用该事实和照片。
   几何一致不代表配色、表面和配置一致。
   本次整理或修订配置时，说明改动和验证范围。
   不默认要求重新打印，也不声称修订参数已经实打。
   明确差异未解决时，保存草稿并说明具体差异。
   源模型可单独发布，参考 3MF 不申报实打配置。
   参考 3MF 必须写明未验证项及重新切片要求。
3. 在同一草稿上传文件并填写模型信息。
   已公开作品从详情页追加配置，复用已有配置草稿。
   核对封面、实物三视图和独立模型图片列表。
   补充用途、参数、五金、装配与验证边界。
   发布配置时，核对实打照片及兼容机型。
4. 核对源文件可下载设置和版权许可证。
   网站默认项与“开源”勾选不代表用户选定许可。
   用户已经明确选择时沿用，不重复询问。
   尚未选择时，先完成可审阅草稿再询问。
   协议接受动作遵循当前工具的确认要求。
5. 保存草稿，核对文件处理完成及内容持久化。
   切换路线、回退或重入后，重新检查附件和正文。
   用户已授权发布且所需决定齐全时，继续发布。
6. 核验实际结果，提供作品或草稿链接。
   分别报告源模型与打印配置的状态。
   分清已公开、已提交审核、已保存和发布失败。
   状态不明时核对原作品，避免重复创建或提交。

最终说明实际状态、发布文件范围和剩余限制。
按浏览器工具要求保留页面并提供结果截图。
没有公开成功证据时，不声称模型已经公开。

## 查找需求

提取用途，以及用户已给出的硬约束：

- 尺寸、设备型号或安装位置。
- 打印机、喷嘴、材料和颜色条件。
- 时长、重量、支撑、装配与五金要求。
- 商用或改编需求。

只询问会改变筛选或推荐的缺失信息。
未给出机型时，先按用途找候选。
将打印适配标为“未确认”，不默认 A1 mini。

## 查找与核验

首次操作或控件变化时，读取 [中国站查找流程](references/search.md)。

1. 用核心用途或产品型号搜索，选择“模型”结果。
   按需求选择排序、时间、分类及筛选。
   修改后核对当前关键词和生效条件。
2. 按模型 ID 去重，排除广告与收藏夹卡片。
   搜索会返回低相关结果，逐项检查用途。
3. 打开有希望的模型详情。
   检查尺寸、支撑、装配和外购零件。
   区分整件、单个零件和二次创作版本。
4. 打开具体打印配置，核验机型适配。
   记录配置链接、材料、喷嘴、盘数、耗时和重量。
   每组数据绑定同一个配置及机型条件。
   不混用作者正文和不同配置的数据。
5. 核对许可证及近期适用版本的评论。
   免费下载不代表允许商用。
   区分作者上传文件与配置自动生成的 STL。

页面跳转或筛选后，等待目标内容并读取新状态。
旧页面仍在显示时，不重复提交或沿用旧元素索引。
使用当前可见控件定位，不固定坐标或标签 ID。

已有足够合格候选时停止搜索。
结果不足时，尝试与用途直接相关的同义词。
只调整非硬约束，并在结果中说明调整。
没有合格结果时，如实报告检索范围和缺口。
未确认的硬约束不能记为已满足。
页面受阻时，说明未完成的核验项，不编造结果。

## 返回结果

默认给出最多三个已核验候选，并指出首选。
先说明推荐结论，再用表格或短列表比较。
每个候选提供：

- 模型名称、作者和中国站详情链接。
- 用途匹配、尺寸及打印机适配情况。
- 所选配置的名称与链接；有 ID 时保留 `#profileId-…`。
- 同一配置的材料、喷嘴、盘数、耗时和重量。
- 许可证、商用限制及源文件情况。
- 推荐理由、装配要求和评论中的主要限制。

页面缺失的字段写“未确认”。
来源冲突时分别标明，不合成一个确定值。
没有适配配置时，说明仍需切片或尺寸验证。
只引用实际打开核验的页面作为推荐依据。
