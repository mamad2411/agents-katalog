# BELLE

## A LaTeX pentesting report creator

An Encryptor and Decryptor for files and folders for Windows, written in Python.

> [!NOTE]
> Disclaimer: This is only a tool for creating reports; it does not use or implement LLM, Synthetic, or AI (yet).

*Some report examples using BELLE:*

[Doc](https://drive.google.com/file/d/1AUxPmv_p5vBa8ajfXQF_-snrgrmgg8Ly/view?usp=sharing)

[Vulnversity](https://drive.google.com/file/d/1gkD94lRSYaorLr0cYcpJn_2-CPHzUlEO/view?usp=sharing)

![UI](https://i.ibb.co/xctLMMJ/r1.png)

## Version
**BELLE V1.0**

### Features

- Add, remove or rename phases.
- Add images, tables, code blocks and url.
- Export to Latex, markdown and PDF.
- Adds Cover, Text and Confidential Text.

**IMPORTANT TO READ ALL**

## 📦 Requirements Required*
**TeXLive or MiKTeX**

**Pandoc**

**Go**

**Wails**

**Node.js**

**A dragon shark mascot**

## 💻 Installation
Execute the commands according to your case (Win or Linux)

Clone or Download this Repository
```   
git clone git@github.com:aiskoa/BELLE.git
```   

Change Directory
```   
cd BELLE
```   

Install dependencies
```   
npm install
```   

Compile
```   
wails build
```   

---

`If you encounter any errors, you may not have installed a Latex compiler yet.`

Note: Install Pandoc
