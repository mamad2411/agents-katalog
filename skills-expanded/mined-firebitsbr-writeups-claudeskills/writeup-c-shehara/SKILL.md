# Pentest Labs and Notes
This repo is a hands-on log of my lab work including step-by-step notes, writeups, scripts and  reports.

Folders are project-focused and are as follows,
- `/setup`                — how I set up VMs and snapshots
- `/recon-and-osint`      — nmap runs, gobuster notes, quick OSINT tips
- `/web-assessments`      — DVWA / JuiceShop labs, PoCs and fixes
- `/network-exploitation` — VulnHub-style full box writeups
- `/active-directory`     — AD maps, BloodHound exports, Kerberoast notes
- `/automation`           — small scripts (nmap/zap parsers, helpers)
- `/reports`              — full report PDFs + exec slides
- `/social-and-physical`  — safe assessment plans only
- `/notes`                — short cheat sheets and MITRE links

How to use this repo?
1. Open `/reports` for a full report and a 1–2 slide executive summary.
2. Check `/web-assessments` and `/network-exploitation` for the raw commands and PoCs.
3. Look at `/automation` if you want to see scripts I use to speed things up.

Everything is simply explained - what I did, why I did it and what to do next.
