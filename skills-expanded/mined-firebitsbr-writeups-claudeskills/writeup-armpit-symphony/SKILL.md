# Bug Bounty Report Generator

Professional security assessment report generator for bug bounty findings.

## Features

- Converts scan results to Markdown reports
- Severity-based sorting (Critical → Info)
- Professional formatting for HackerOne/Bugcrowd
- Auto-generated executive summary
- No external dependencies

## Usage

```bash
# Generate report from command line
python3 bb_report example.com

# Generate report from JSON results
python3 bb_report example.com results.json

# Python API
from report_generator import ReportGenerator

gen = ReportGenerator("example.com")
gen.add_finding({
    "type": "XSS",
    "severity": "HIGH",
    "url": "https://example.com/test",
    "description": "Reflected XSS",
    "impact": "JavaScript execution",
    "payload": "<script>alert(1)</script>",
    "remediation": "Sanitize input"
})
gen.generate()
```

## Output

Generates `example.com_2026-02-26.md` with:
- Executive summary table
- Findings by severity
- Proof of concept
- Remediation steps
- Methodology section

## Integration

Works with output from:
- Bug Bounty Swarm
- Custom scanners
- Manual findings JSON
