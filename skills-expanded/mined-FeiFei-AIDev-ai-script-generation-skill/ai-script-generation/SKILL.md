# AI-script-generation

基于用户提供的参考素材和创作主题，结合框架库和热点话题，生成多角度、可直接拍摄的30-40秒短视频脚本。精通短视频内容结构、心理钩子设计，以及小红书平台的流量密码。

## 背景信息

- **账号定位**：AI教程、AI提效技巧
- **目标受众**：职场人士、各领域AI入门学习者
- **视频时长**：30-40秒（1分钟以内）
- **内容调性**：以干货专业风为主，同时探索其他风格（轻松吐槽、故事共情、悬念反转等）

## Instructions

### Step 1: 获取用户提供的参考素材和主题

**首先，明确创作主题：**
- 如用户未明确提供主题，主动询问："请告诉我你想创作的视频主题是什么？"
- 提取用户想要创作的视频主题和核心内容

**其次，询问是否有参考素材：**
- 如用户未主动提供参考素材，询问："你有想参考的脚本或案例吗？如果有的话可以分享给我，我会分析其结构和亮点"
- 从用户对话中提取以下信息：
  - **参考素材**：用户提供的参考脚本、案例或示例（如有）
  - **特殊要求**：用户指定的角度、风格或重点（如有）

**如果用户提供了参考素材，分析以下要素：**
- 框架结构（开头钩子→痛点/价值→核心内容→收尾引导）
- 心理触发点与心理学原理（好奇心缺口、损失厌恶、社会认同等）
- 有效原因分析
- 可复用的表达方式和句式

**如果用户没有参考素材，直接进入下一步**

### Step 2: 匹配框架库
从框架库 [.codex/skills/AI-script-generation/references/framework.md](references/framework.md) 中筛选适合本次创作的框架，考虑：
- 与参考素材结构的契合度
- 与创作主题和受众痛点的匹配度
- 30-40秒时长的适配性

### Step 3: 结合热点话题
从热点库 [.codex/skills/AI-script-generation/references/hot.md](references/hot.md) 中提取近期热点话题，分析：
- 哪些热点与创作主题可以结合
- 热点的时效性和话题热度
- 潜在的切入角度

### Step 4: 生成5个多角度脚本
基于用户提供的主题和参考素材，生成5个不同角度的视频脚本，要求：

  ### 角度分配建议
  1. **干货效率型**：直接输出实用技巧，节奏快、信息密度高
  2. **痛点共鸣型**：从职场痛点切入，引发"说的就是我"的共鸣
  3. **悬念反转型**：开头抛出反常识观点或悬念，结尾反转
  4. **对比冲击型**：用before/after或新手vs高手的对比制造冲击
  5. **热点借势型**：紧跟当前热点，自然植入AI技巧

  ### 每个脚本必须包含

  **【脚本标题】**
  吸引点击的标题（带数字/疑问/痛点关键词）

  **【核心卖点】**
  一句话说明这个脚本的核心价值

  **【使用框架】**
  标注采用了哪个框架结构

  **【结合热点】**
  标注结合了哪个热点（如有）

  **【心理钩子】**
  使用了哪些心理触发点

  **【完整脚本】**
  [开头钩子 3-5秒]
  具体台词...

  [痛点/价值 5-8秒]
  具体台词...

  [核心内容 15-25秒]
  具体台词（分点呈现）...

  [收尾引导 3-5秒]
  具体台词...

  **【画面建议】**
  简要说明每段配合什么画面/素材

  **【预估时长】**
  精确到秒

  **【难度评估】**
  制作难度（低/中/高）+ 所需准备

  ## Constraints

  1. 每个脚本总时长严格控制在30-45秒口播时长
  2. 语言风格：口语化、接地气，避免书面语和专业术语堆砌
  3. 开头5秒内必须有明确钩子，阻止划走
  4. 每个脚本的核心干货点不超过3个（信息过载会流失观众）
  5. 结尾必须有互动引导（点赞/收藏/评论/关注）
  6. 避免敏感词和违规内容

## 工作流程

1. **确认创作主题**：如用户未明确提供主题，主动询问"请告诉我你想创作的视频主题是什么？"
2. **询问参考素材**：如用户未主动提供参考素材，询问"你有想参考的脚本或案例吗？如果有的话可以分享给我，我会分析其结构和亮点"
3. **分析参考素材**：如用户提供了参考脚本或案例，分析其结构、心理触发点和有效原因
4. **加载参考资源**：读取框架库 [framework.md](references/framework.md) 和热点库 [hot.md](references/hot.md)，必要时参考 [styles.md](references/styles.md) 和 [triggers.md](references/triggers.md)
5. **生成脚本**：基于主题和参考素材（如有），生成5个不同角度的视频脚本
6. **输出结果**：按输出格式组织，包含分析摘要、5个脚本和创作建议
7. **保存脚本**：将生成的脚本保存为Markdown文件
   - 如用户未指定保存位置，询问用户希望保存在哪里
   - 建议保存路径：skill 包外的工作目录（如 `drafts/` 或用户指定的目录）
   - 文件命名格式：`YYYYMMDD_脚本_主题.md`（例如：`20260120_脚本_Claude写代码.md`）

- 结合AI教程的常见框架结构
- 应用心理触发点设计钩子

- 基于参考脚本的框架，结合新主题生成5个变体脚本
- 保留参考脚本中的有效心理触发点
