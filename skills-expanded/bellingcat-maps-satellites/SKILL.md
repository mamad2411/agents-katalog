# Bellingcat Maps & Satellites Investigation Tools

Tools for geospatial analysis including web maps, satellite imagery platforms, and street view services. Cross-reference multiple sources to verify locations and track changes over time.

## Choosing Tools

- Use map and street-view services to inspect a location; use satellite platforms when you need imagery, dates, or change over time.
- Compare at least two sources when coverage, imagery date, or geographic detail may affect the finding.

## Investigation Tips

- Cross-reference locations across multiple map services (Google, Yandex, Baidu, Tencent) for areas where coverage varies
- Use satellite imagery time-series (Copernicus Browser, NASA Worldview, Google Earth Engine) to identify changes over time
- Combine street view platforms (Google Street View, Mapillary, KartaView, Yandex) for wider coverage
- Use Overpass Turbo and OpenStreetMap Search to find specific features near a location
- Shadow analysis tools (SunCalc, ShadowMap, ShadeMap) help verify photo/video timestamps and locations
