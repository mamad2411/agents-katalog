# 灯槽 · 暗藏灯带构件库

> 唯一职责：**灯槽这个构件怎么做、怎么出错、怎么写进提示词**。
> **边界（强制）**：色温 K、主光/补光、光比 —— 归 `interior-styles` 的「光指纹」列，本文件**不复述**。本文件只交接「灯槽作为光源本体，它的几何与出光方式」。

---

## 〇、与主 SKILL 硬规则 3 的关系（最容易踩的一条）

主 SKILL 硬规则 3：**AI 生图提示词禁止具体数字尺寸**。

所以本文件所有毫米数分两层，出词时**只取提示词层**：

| 层 | 用途 | 能否进提示词 |
|---|---|---|
| **施工值层** | 给人看的设计 / 施工参考 | ❌ 禁止 |
| **提示词层** | 相对词（窄、深、宽、明显高于、足够距离） | ✅ 只写这一层 |

直接把 `150mm` 抄进提示词 = 违规。

## 一、术语对照（出词必须用正式名）

| 口语说法 | 正式术语 | 英文 |
|---|---|---|
| 吊顶边上那种灯 | **灯槽** / **反光灯槽** / **暗藏灯带** | cove lighting |
| 四周走一圈 | **回形灯槽** / **周边灯槽** | perimeter cove |
| 有高低差的那种 | **跌级吊顶 + 灯槽** | stepped ceiling cove |
| 整片天花浮起来 | **悬浮吊顶** / **悬浮顶灯带** | floating ceiling |
| 专门照墙面 | **洗墙灯槽** / **洗墙灯带** | wall-washer cove |
| 窗帘位置 | **窗帘盒反光灯槽** | curtain-box cove |
| 行业口头语 | **"见光不见灯"** | — |

⚠️ 三组最容易混的叫法，出词前必须分清：**回形**（四周一圈）≠ **跌级**（有高低差）≠ **悬浮**（整片留缝）。

## 二、六种做法

| # | 做法 | 适用 | 天花形态 |
|---|---|---|---|
| 1 | **整体平吊顶包梁** | 梁不高、要平整天花 | 天花平整连续，梁不可见，无灯槽 |
| 2 | **回形灯槽** | 普通层高、要一圈柔光收边 | 平顶 + 四周一圈出光口 |
| 3 | **跌级吊顶 + 灯槽** | **梁较大较宽（本文件主推）** | 高低差两级，灯槽藏在落差里 |
| 4 | **悬浮吊顶** | 要"天花浮起来"的轻感 | 整片天花与墙之间留一圈缝，缝内出光 |
| 5 | **洗墙灯槽** | 要照画/照背景墙/照床头 | 靠墙的窄槽，光洗墙面 |
| 6 | **窗帘盒反光灯槽** | 窗帘位 | 与窗帘盒合一 |

> 主 SKILL 的「结构矛盾消解」在横梁场景下，默认取 **#3 跌级吊顶 + 灯槽**；梁不高则退 #1。

## 三、几何尺寸

### 3.1 施工值（给人看，禁止进提示词）

| 参数 | 国内施工值 | 国际参考 |
|---|---|---|
| 槽宽 | 100–150mm（下限 ≥80） | ledge width 75–150mm |
| 槽深 | 100–120mm（下限 ≥80） | pocket depth 60–80mm |
| 挡板高（遮光边） | 60–80mm（下限 ≥40，**须比灯带高 20–30mm**） | lip 低于楼板 150–220mm |
| 灯带退让（距挡板） | — | 30–75mm（≥50） |
| 灯带距顶（投射距离） | ≥50mm，常用 80–120mm | 150–250mm |
| 灯槽总高 | ≥200mm | — |
| 灯带距墙 | 100–150mm | — |
| 层高门槛 | **<2.6m 不建议做** | 距天花 ≥460mm、距地 ≥2030mm |
| 窗帘盒 | 平台 50mm / 槽宽 150mm / 灯带贴平台边缘 20mm | — |

### 3.2 关键关系：灯带离顶间隙 → 灯带密度

这是「露灯珠」的唯一根因变量，出词时按间隙反推密度：

| 灯带距顶间隙 | 灯带密度要求 |
|---|---|
| <25–50mm | **必须 COB**，或 120–240 灯珠/m |
| 50–100mm | 约 120 灯珠/m |
| >100mm | 60–120 灯珠/m 即可 |

### 3.3 提示词相对词（出词只用这一层）

| 施工参数 | 提示词写法 |
|---|---|
| 槽宽 100–150mm | `窄而规整的出光口` |
| 槽深 100–120mm | `槽体进深明显大于出光口宽度` |
| 挡板 60–80mm | `挡板明显高出灯带表面，完全遮住光源本体` |
| 灯带退让 | `灯带贴靠在槽内靠墙一侧，远离出光口` |
| 投射距离 ≥50mm | `灯带与平顶之间留有足够的反射距离` |
| 灯带距墙 100–150mm | `灯带平行于墙面并保持一段距离` |
| 层高 <2.6m | **不出灯槽**，改用平吊顶 + 筒射灯 |

## 四、灯带选型

| 项 | 要求 | 理由 |
|---|---|---|
| 类型 | **COB 高密**（优先）> 120 灯珠/m + 铝型材柔光罩 | 普通 SMD 贴片必露珠 |
| 电压 | **24V** 低压 | 可跑约 10m；12V 只有约 5m。超 6m 须中间补电，否则头亮尾暗 |
| 显色 | **Ra ≥ 90** | 低于 90 木材发灰、织物失真 |
| 亮度 | 住宅天花洗光 **200–400 lm/m**；商业 400–800 | 灯槽内吸光 **30–50%**，选型按此折损放大 |
| 功率 | 氛围 8–10W/m；辅助主照 12–16W/m | — |
| 驱动 | 留 **20–30%** 余量，通风可检修 | — |
| 散热 | 必须装**铝槽** | 裸贴会加速光衰 |
| 固定 | 卡扣 30cm 一个（部分做法 50–60cm） | 不拉直 = 锯齿光 |
| 眩光 | UGR 约 13–15 属正常区间 | 更深槽 + 更远退让可降低 |

## 五、三大翻车（出词负面词的直接来源）

| 现象 | 物理成因 | 解法 |
|---|---|---|
| **锯齿光 / 狗牙光** | 灯带裸贴、没拉直、槽沿不平 | 铝型材 + 柔光罩（45° V 型槽）；卡扣拉直；槽沿打磨平整 |
| **截止光 / 刀切线** | 挡板不足，或灯带太靠前 | 灯带平行贴近挡板；45° 斜装；出光面高于挡板 |
| **点状光斑 / 颗粒感** | 用了 SMD 贴片，或灯带离顶太近 | 换 COB 高密；按 §3.2 提高密度 |
| **出光不均** | 槽内未刷白、腻子堆边挡光、木屑未清 | 槽内刷白乳胶漆、清理干净、反射面平整 |
| **光斑外溢** | 槽内漏光、接缝未封 | 90° 直角拼接，接缝铝箔胶带密封，内部做防漏光 |

## 六、AI 出词模板

### 6.1 正向段（**折进【灯光】段，不新开段落**）

```text
天花为跌级吊顶，梁体被吊顶完整包住；吊顶边缘设反光灯槽，灯带暗藏于槽内不外露，
挡板明显高出灯带表面并完全遮住光源本体，灯带贴靠在槽内靠墙一侧、远离出光口，
灯带与平顶之间留有足够的反射距离；光线自槽内斜向上打到平顶，再向下漫射进室内；
平顶表面形成柔和均匀的光晕，看不到灯珠，没有明暗截止线，没有锯齿状光边；
出光口边缘干净利落，槽内壁刷白，反射面平整
```

### 6.2 负面词（三层体系的 L4，与主 SKILL 分工）

```text
可见灯珠，点状光斑，锯齿状光边，明暗截止线，生硬切线，灯带外露，光斑不均，漏光
```

### 6.3 三条写死规则

1. **写了灯槽就必须写光路**：`槽内 → 向上反打平顶 → 漫射下来`。漏这句 = "平天花却出槽光"。
2. **不写数字**：全部换成 §3.3 的相对词。
3. **色温不写在这里**：从 `interior-styles` 对应风格的光指纹列取，接在光路段末尾。
