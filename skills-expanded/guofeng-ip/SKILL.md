# 国风 IP as Logo

用中国传统视觉语汇创造"一眼记住"的极简吉祥物：一个在 `32 × 32` 下仍可辨认的圆润角色，而不是一幅国风插画。

本技能继承 [ip-as-logo-skill](https://github.com/s1dashu/ip-as-logo-skill) 的核心框架（复杂度预算、三色纪律、方向提案工作流），并将题材库与色彩系统替换为中文语境下的高熟悉度集合。

## 题材库：中文熟悉度清单

原版规则要求"广泛讨喜的动物"，本技能将其本地化。默认只从**高熟悉度**题材中提案：

- **生肖十二兽**：鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪（全系列默认可用）
- **瑞兽**：锦鲤（好运）、貔貅（招财）、麒麟（祥瑞）、玉兔（灵动）、金蟾（财富）、仙鹤（健康）、蝙蝠（福，需简化到不惊悚）
- **祥物植物/器物**：葫芦（福禄）、竹（坚韧）、莲花（纯净）、灯笼（喜庆）

中熟悉度题材（白泽、年兽、玄武、饕餮）仅在产品气质明确契合时提案，且每次至多一个方向。

每个提案必须绑定一条产品属性或品牌承诺：`锦鲤 — 抽奖产品的"好运"心智 — 圆润鱼身 + 一片上翘的尾鳍`。禁止返回三个没有理由的国风元素堆砌。

## 工作流

1. 解析请求中的显式题材与产品上下文。不主动让用户选择色彩模式。
2. 若当前工作区是产品仓库，先只读检查 README、落地页文案、manifest 与设计令牌。**充分性判据**：产品用途、目标人群、期望气质三问都能从只读上下文得到可信答案即为充分；任何一问存疑即进入第 3 步。
3. 上下文不足时，只做一轮合并式提问（做什么、服务谁、想要什么感觉）。得到回答后不再追问第二轮。
4. 提出三个简洁方向并提议一次性生成六张独立候选图，经用户同意后再生成（除非用户已明确授权六张输出）。
5. 用户接受全部三个方向时，每方向两张独立变体，标注 `A1 A2 B1 B2 C1 C2`；单选一方向时生成该方向的六个受控变体 `A1–A6`。奇数号从左下探出，偶数号从右下探出，保证三左三右。
6. 用户否决数量或分布时，以用户的替代指令为准，不为默认方案辩护。

## 构图

- 默认沿用左右下角构图：角色直立、从指定下角探出，占画布约 `85–95%`，禁止居中与底部居中。
- **印章模式（可选）**：用户明确提出"印章感 / 对称 / 团扇"时切换为正圆居中对称构图，角色占画布 `70–80%`，背景为纯色正方。此模式仍保持三色纪律。
- 成对特征（双角、双耳、双鳍）必须完整出现在画面内。
- 保持画面端正，除非用户要求不得倾斜画布。

## 复杂度预算

- 用大约 `4–7` 个大型基本几何形状构成唯一连续主导轮廓；不承载身份、表情或辨识度的形状一律合并或删除。
- 至多一个物种定义特征：一片上翘的锦鲤尾鳍、一对圆化的鹿角、一枚饱满的兔耳组。
- 至多两个宽大的内部色区对应两个 IP 主色；脸部只有两只眼睛，仅在有助于表情时加一张极小的嘴。
- 禁止：鳞片排列、羽毛重复、飘带、火焰纹样、云海背景、任何形式的汉字文字——图像模型无法可靠书写汉字，任何情况下都不得要求生成文字。
- **传统元素符号化**：允许且仅允许一个融入轮廓的传统符号点缀——如意云头弧线、圆化铜钱轮廓、福袋形肚皮、竹节分段——它必须参与剪影本身，而不是贴上去的装饰，且不引入第三种语义色。

## 中国传统色系统

- 全图严格三色：恰好两个 IP 主色 + 恰好一个背景色。面部细节复用主色，不引入新色。
- 背景色从**具名中国传统色**中选择并以中文名直接写入生成提示词，例如：朱砂、胭脂、缃黄、月白、天青、黛蓝、竹青、藕荷、驼灰、玄青。模型对具名色彩的响应显著优于十六进制值。
- 用户未提供配色时，背景按原版纪律轻微降饱和：仍是明确的彩色、干净且有意图，而非艳丽、发灰或浑浊。
- **新春特例**：用户明示春节 / 新年主题时，允许放弃降饱和处理：背景固定为朱砂，两个 IP 主色中至多一个取哑光鎏金（暖调金黄，非金属光泽），全图仍须恰好三色。鎏金不在常规具名清单内，仅在本特例中可用。
- 用户提供的调色板一律视为背景候选；两个 IP 主色由你根据题材、身份与期望性格独立选定，并在批量内部刻意变化策略，避免六张全是同一对中性色。
- 历史示例调色板只是灵感，绝不是许可清单或强制默认。

## 图形语言

- 在原版"厚、圆、重"的基础上，允许两种国风弧线：如意云头的内收弧、上挑但末端必须钝圆收尾的弧线。
- 一切尖端可见地钝圆化：龙角、鹤顶、鳍尖、竹叶端点均以圆头结束。
- 简化、可爱、幼态亲和是决定性品质：大头、紧凑比例、柔软腮部、间距宽松的简单眼睛、平和友善的表情。

## 尺寸与画布

- 直接生成 `1:1` 正方形、直角外边框，请求约 `1536 × 1536`；服务上限为原生 `1254 × 1254` 时接受并保留，不得为凑数重采样。
- 背景为具名实底色填满整张方图，无纹理、无晕影、无光效变化。
- 生成提示词中不得出现 `透明`、`alpha`、`抠图` 等图像模式词汇。

## 提示词骨架

先判断可用图像模型及其真实工具参数，凭运行时元数据、已配置供应商文档或用户明确说明，不得猜测模型或虚构不支持的能力。对现代指令跟随模型（GPT Image 2、Nano Banana Pro/2、Seedance 5.0 Pro 等），把少量排除项写成主提示词末尾的自然语言 `约束：` 行；仅当旧模型暴露独立 `negative_prompt` 参数时才走专用通道，并从主提示词删去 `约束：` 行以免双重排除。在生成报告中记录模型名、约束通道与最终提示词。

生成提示词只描述这张图本身。绝不告诉图像模型这是 logo、品牌标识、图标素材，也不得前置暴露用途的元信息——一旦模型知道是 Logo，就会画出带卡片感的标志而不是自由饱满的角色。（此规则只约束生成提示词；与用户的对话和技能名称不受限。）

中文骨架（面向豆包 Seedance 等中文优先模型；英文优先模型可整体意译，语义不变）：

```text
创作一张完整的满幅 1:1 正方形图像。
背景：整个正方形填充纯粹的实色<背景·中国传统色名>，所有开放区域与未被占据的角落都保持<背景色>；指定的探出角落由角色占据。
主体：在背景上绘制一只极度简化的可爱<题材>吉祥物，国潮风格，归纳为一个柔和圆润的连续剪影和一个定义性特征。
复杂度：只用 4–7 个大型基本形状和至多两个宽大内部色区。两只简单眼睛，仅在有助于表情时加一张极小的嘴。去除一切非必要线条、轮廓线、解剖细节、纹理和装饰，保证 32×32 下依然可辨认。
色彩行为：全图恰好三种语义色——恰好两个 IP 主色加背景色。主色依据题材与语境组织成宽大色块并复用于面部。<背景色>独立选择，轻微降饱和，温和克制但不发灰。保持角色、面部细节与背景清晰分离。
构图：角色端正，从指定的左下角/右下角探出，约占画布 85–95%。允许在底边或指定侧裁切以强化探出感。成对特征必须完整保留。禁止居中与底部居中。
风格：简化、可爱、幼态亲和是最强特质。大型柔软形体、紧凑比例、厚圆轮廓、超干净的图形化处理。加入极其极其轻微、几乎不可察觉的新拟物式深度感。
约束：不要任何文字和水印。不加边框、相框、卡片或展示遮罩。只出现一个角色，没有额外主体和场景。不用脆弱细线、尖锐尖端、多余描边、微小细节和装饰纹样。不做写实材质、强浮雕、光泽高光、深凹陷、挤压立体、强烈三维渲染和外投阴影。背景保持均匀实色，无纹理、无晕影、无光照变化。
```

## 交付行为

- 把每一次生成当作随机创作抽取，不是合格性考试。
- 请求多少候选就独立生成多少次，原样保留并交付每一张返回结果。
- 不检查透明度，不因背景、颜色、构图、渐变、阴影或立体感拦截、评级或自动重试任何结果。
- 不做后处理修补。用户看过整批后点名要求换方向或补抽时，才生成新的独立候选。
- 交付时报告每个标签对应的题材方向与理由、探出角、保存路径、提示词与配色映射、尺寸。
