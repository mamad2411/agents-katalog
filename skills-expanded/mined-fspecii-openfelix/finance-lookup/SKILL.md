# Finance Lookup

Real-time prices for stocks, currencies, commodities and crypto using Yahoo Finance and Frankfurter.

## Supported queries

- **Currency**: "1 dollar in lei", "100 EUR to USD", "GBP to RON"
- **Commodities**: "gold price in EUR", "1 gram of gold in euros", "silver per oz in GBP", "oil price"
- **Stocks**: "AAPL", "Tesla stock", "NVDA price"
- **Crypto**: "bitcoin price", "ethereum in EUR"

## No API key required.
