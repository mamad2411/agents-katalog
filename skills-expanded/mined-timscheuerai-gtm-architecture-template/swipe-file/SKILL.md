# Swipe file

One inspiration database for every format, so taste compounds instead of living in chat. The default home is a Notion database (ids in `strategy/notion-schema.md`); any table works if it keeps the same fields.

## Fields

`Name`, `Format` (Thumbnail, Title, Ad, Short, Long-form, Post, Graphic, Film, Landing page), `Published` (recent beats old), `Mechanism` (the move, for example Before and after, Real dashboard, Giant logo, Hidden number), `Steal` (1 line), `Numbers` (views, subscribers, views over subscribers when measurable), `Verdict` (Love, Steal this, Not us, with a note), `Source` (Author or Scout), `Inspo for` (the content card it serves), `Media`.

## Add what the author shares

1. **Find the original.** A screenshot cannot be uploaded from chat, so find the source: a YouTube thumbnail by its title, a post by its URL, an ad in the public ad libraries. If it cannot be found, ask for the link.
2. **Measure it** when it is on YouTube (views, subscribers, views over subscribers, the channel's median); other platforms take the numbers the post shows, or none.
3. **Name the move:** the format, 1 or 2 mechanisms, and the steal line in 2 halves: what they do, then how it would look for you with your real numbers only.
4. **Create the row** with Verdict Love when the author shared it, linked to the card in production when it is for that piece. Attach the image.
5. Tell the author in 1 line what was filed and the move it stands for.

Scouted references from `youtube-thumbnail-outlier-research` land here with Source Scout.

## Pull from it (every design skill)

Before concepts for any format, read the swipe file and name the rows a concept borrows from: first the card's own inspo rows, then rows of the same format marked Love or Steal this, then the author's own picks, then scouted rows by views over subscribers. Look at the top 3 to 5 images before drafting. Treat every Not us note as a rule.

| Skill | Format it reads |
| --- | --- |
| youtube-thumbnail | Thumbnail, plus the card's inspo rows |
| shorts-edit, shortform-platform-copy | Short |
| graphics-designer, flowchart | Graphic, Post |
| linkedin-copywriter, x-copywriter | Post |

## Rules

Third-party work is reference only: never in your assets, never committed as media, never posted. Take the move, not the pixels, face or layout. Fold recurring verdicts into the brand's taste rules.
