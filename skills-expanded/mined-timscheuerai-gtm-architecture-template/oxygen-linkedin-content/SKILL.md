# Write content that earns the next step

Read the author's context and [the runtime contract](../../../docs/runtime-contract.md). This skill writes drafts; [oxygen-publishing](../oxygen-publishing/SKILL.md) owns scheduling and approval. Use `linkedin-copywriter` in this kit for the actual grounded draft when the author's voice lives in `context/`.

## 1. Ground

Read the index, then retrieve only relevant pages: `oxygen knowledge index --json`, `oxygen context canonical get --type voice --json`, `oxygen knowledge search "content pillars" --json`, plus owned-post analytics for the selected author. A placeholder page is absent context; never blend co-authors' identities.

## 2. Select ideas

Every idea passes six gates: a traceable real receipt, the author's credible stake, use to the ICP, specificity, fit with the adopted pillars, and public safety (no invented metric, no uncleared customer detail). Return pass, repair (with the proof needed) or reject. Numbers need a definition, unit, period and source.

## 3. Write for the channel

LinkedIn and X are separate registers; rewrite from the shared evidence rather than shortening one into the other. Vary the hook family from recent posts. Use a graphic when it carries the idea; never invent a logo.

## 4. Review and save

Show the exact copy and media, with sources, pillar, funnel job and withheld claims outside the copy. Save it as an unapproved draft and read it back. Scheduling and approval go through Publishing.

## 5. Connect to a next step

Engagement is a Signal, not fit. Capture of engagers is separate from auto-enrollment; a standing outreach grant names the cohort, destination Sequence, limits and stop conditions. Existing-thread replies belong to [Unibox](../oxygen-unibox/SKILL.md).
