# LinkedIn Content Calendar

One week, five posts, five lanes. This skill sets the slate so every post proves a competence the buyer actually pays for, with enough variety that the feed never feels like the same post twice.

## Inputs
- The week's theme or the proof on hand, plus which lane needs weight: $ARGUMENTS
- The brief (lanes, voice profile, offer, pains, and what has run recently) loads automatically.

## Do this
1. Assign one post to each of the five revenue lanes: Get Found, Get Chosen, Get the Meeting, Close the Deal, Operating System.
2. Apply the locked variety mix across the five, one type each: a deep operator-playbook post, an ultra-short screenshot-and-share, a second deep post, a proof / business-case post, a punchy mid-length opinion.
3. Pick five DIFFERENT hook formulas, one per post. No formula repeats inside the week.
4. Check the last six weeks. Do not repeat a framework angle that has run in that window. If the theme forces a repeat, rotate the angle or swap the proof.
5. For each post, set the comment keyword (one word, easy to type, tied to the lane's lead magnet or follow-up).

## Output
A five-row table with columns: Day, Type, Lane, Hook formula, Angle (one line), Keyword. Then one line naming the through-line that ties the five posts into a single week.

## Rules
- Every post must prove a competence the buyer buys. If a post only entertains, cut it and reassign the lane.
- No angle and no hook formula repeated inside the week; no framework angle repeated inside six weeks.
- This skill plans only. It does not write the posts. Hand each row to the drafting skills, then run /linkedin-humanizer on the drafts before anything is scheduled.
- No em-dashes.
