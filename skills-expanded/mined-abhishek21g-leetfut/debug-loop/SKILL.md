# Debug Loop

Use this skill when the user asks to fix a bug, failing test, runtime error, or broken behavior.

## Steps

1. Reproduce or locate the failure.
2. Read the relevant code before editing.
3. Identify the smallest likely cause.
4. Patch the smallest surface area.
5. Run the most relevant verification.
6. Summarize cause, fix, and checks.

## Guardrails

- Do not guess from symptoms alone.
- Do not rewrite unrelated code.
- If reproduction is impossible, state what evidence was available.
