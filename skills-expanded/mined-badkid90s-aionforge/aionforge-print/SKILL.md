# 阶段 1：印花提取、正反面分析与左胸核心元素（print）

本流程负责把原始印花图案转化为**达到工厂印刷级工艺的高清 4K 干净透明底主印花**、**背面配套的左胸核心小图标**，以及经用户确认的**正反面位置计划（`facts.print.placements`）**。
关于 T 恤实拍底色冲突调整与成衣合成，交由下一阶段 `aionforge-product` 按具体 T 恤颜色执行。

未加载入口时先读 `../aionforge/SKILL.md`。工具只按名称引用，参数见工具卡；本文件不写命令。

## 输入与输出

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| **输入** | 一张或多张印花稿（`print`）、用户正反面或位置偏好（可选） | 平面白底稿、透明稿或实拍印花均可 |
| **输出文件** | `refs/<product>-print.png`、`refs/<product>-core.png`（背面主印花必配） | 均为 **高清 4K（长边 ≥ 3000px，300 DPI 工厂直印级）** RGBA 透明底 PNG，封闭区透底干净 |
| **输出事实** | `facts.print` 中的 `source` / `palette` / `elements` / `analysis` / `placements` | 字段规范见 [contracts/facts.md](../aionforge/references/contracts/facts.md) |

## 四步闭环执行流程

### 第一步：思考（Think —— 清点、4K印刷指标测量、封闭区拓扑与正反面分析）

1. **客观指标与 4K 印刷级体检**：
   - 对输入的印花稿调用 [print metrics](../aionforge/references/tools/print-metrics.md)，获取尺寸、宽高比、主色调色板、边缘细节密度、平均笔画粗细与透明孔洞数。
   - **4K 印刷级分辨率评估**：评估印花长边是否达到 3000px–4096px（服装厂成衣直喷与丝网制版 300 DPI 工业标准）；若低于 3000px，必须规划高清超分或矢量级保真提取，严禁粗糙拉伸产生马赛克、毛边或模糊。
2. **封闭区（Enclosed Regions / 孔洞）格外仔细的识别与分类**：
   - 细致扫描印花中所有闭合结构：
     - **字母与数字内腔（Counters）**：如 A, B, D, O, P, Q, R, 0, 4, 6, 8, 9 的内孔；
     - **汉字闭合腔体**：如「回、口、日、田、国」及各类繁复部首死腔；
     - **几何/插画镂空区域**：线条闭合环绕形成的内部留白。
   - **严格执行双向拓扑判定**：
     - **必须彻底掏空透明的封闭区**：属于外围底色渗透进字母/图形内腔的孔洞，必须 100% 掏空透气，确保成衣底色自然穿透，绝无残留发白底块；
     - **必须强制完整保留的设计白色**：属于印花原本设计的元素（如卡通人物眼白、白色字体本身、图案内置的白色徽章填色、高光点），必须锁定保留其实体不透明度，严禁误判扣穿变透明。
3. **正反面适用性分析**（完整标准位置与评分规范见 [print/placement.md](../aionforge/references/print/placement.md)）：
   - **适合 T 恤正面胸前正中（`chest_center`）**：单一视觉焦点、构图紧凑、细节密度低、色数少（≤3 色）、笔画粗，固定采用成人 `28–32cm` 标准（距领口下 7–9cm）缩印后文字与结构依然清晰。
   - **适合 T 恤背面大幅展示（`back_center`）**：多元素插画、涂鸦、泼墨/渐变、细节密度高、色数多、包含大量依赖大面积阅读的小字或纵向大构图，固定采用成人 `28–32cm × 35cm` 标准（距后领线下 2–5cm）。
4. **背面主印花的左胸小印花思考**（规则见 [print/element.md](../aionforge/references/print/element.md)）：
   - **硬规则**：凡判定为**背面主印花**，正面左胸（`left_chest`）必须配套一枚**核心元素小印花（徽章）**，固定采用 `8–12cm` 标准落在正面平铺图右侧（穿着者左胸，距左肩缝 5.5–8cm、中线 4–6cm），绝不能把整张复杂背面大图直接缩小贴在左胸。
   - 从主印花中挑选 **1 个轮廓闭合、语义独立、不与长串文字粘连的核心图标**（如靶心、动物头像、标志性符号、花朵主体），构思 10–25 字的语义提取描述（只写图形名词与特征，不写坐标）。
   - 若整张印花是纯文字或无法拆出独立图标，必须向用户提出三选一：跳过左胸小标 / 换稿 / 仅提取简短主字标。

### 第二步：事实锁定（Lock —— 写入分析草案、封闭区方案并确认门槛）

1. 初始化或打开商品工作区（[product init](../aionforge/references/tools/product-init.md)）。
2. 将分析结论整理成清晰表格呈现给用户确认：
   - 印花分辨率规格与工艺目标（锁定 4K 印刷级长边尺寸与透明通道）。
   - **封闭区处理方案**：明确列出哪些字母/腔体需完全镂空穿透成衣底色，哪些内部白色块属于本体设计必须保留。
   - 每张印花的**正面 / 背面建议**、评分理由、固定 `region`（`chest_center` / `back_center`）及对应行业标准尺寸。
   - 背面主印花对应的**左胸核心小图标选型**（提取哪个元素，固定 `region: "left_chest"`）。
   - 提醒用户：背面主印花在下一阶段合成时，需要提供对应颜色的**背面 T 恤实拍图**。
3. **确认门槛**：用户确认正反面方案、封闭区处理策略与左胸图标选型后，将 `analysis` 与 `placements` 锁定写入 `facts.json`。**用户确认前严禁进入下一阶段合成。**

### 第三步：生成（Generate —— 4K 高保真提取透明主印花与左胸核心图标）

1. **提取透明主印花（4K 工厂级工艺执行）**：
   - 调用 [cutout](../aionforge/references/tools/cutout.md)，输出 `refs/<product>-print.png`。
   - 对包含封闭孔洞（如文字、镂空线条）的图稿启用封闭白区精细处理；若图案内有设计白字或眼白，则锁定主体保留设计白色，确保封闭孔洞透底干净而主体色块完好。
   - 对边缘执行微像素去噪，滤除孤立脏点碎屑，保持 4K 矢量级平滑边缘。
2. **提取左胸核心小图标（当主印花在背面时）**：
   - 调用 [extract-core-element](../aionforge/references/tools/extract-core-element.md)，传入主印花与第一步构思的核心元素语义描述，输出透明底图标 `refs/<product>-core.png`。
   - 对提取出的左胸小图标跑一次 [print metrics](../aionforge/references/tools/print-metrics.md) 确认色数与笔画粗细。

### 第四步：检查（Verify —— 增加多底板质检环境与封闭区专项质检流程）

1. **客观硬指标校验**：
   - 对 `refs/<product>-print.png` 和 `refs/<product>-core.png` 分别调用 [verify](../aionforge/references/tools/verify.md) 的印花质量与 4K 印刷检查模式。
   - **4K 尺寸检验**：长边必须达到 3000px 以上，满足工厂 300 DPI 印刷标准。
   - **Alpha 通道检验**：必须带有效 RGBA 透明通道，且透明阶过渡自然。
   - **边缘与噪点**：边界近白比例收紧至 ≤ 10%，无小于 4px 的孤立噪点碎块。
   - **左胸核心图标完整性**：必须满足 `complete: true` 且四周留白比例 `margin_ratio ≥ 0.02`。
2. **多底板模拟打光质检环境（工厂级关键质检流程）**：
   将生成的透明印花分别置于三种极端环境底板上进行 100% 逐像素目视质检：
   - **纯黑底板（#000000）环境**：重点检查印花外轮廓与字母内孔。严查是否存在半透明白色光晕、白毛边、锯齿残渣或未掏空的闭合白底死腔；
   - **纯白底板（#FFFFFF）环境**：重点检查印花内部原有设计白色。核对人物眼白、白字高光或浅色装饰是否完好，严防被误扣成镂空漏洞；
   - **中性灰底板（#808080）环境**：检查整体色彩保真度，确保专色色值纯正无偏灰、无压暗。
3. **封闭区逐项核对清单**：
   - 逐字核对所有含孔字母（如 A/B/D/O/P/R/0/8）及汉字内腔，确认 100% 干净通透，无半透明发灰结块。
   - 主印花文字逐字完整、无重绘变形、无镜像、无素材站水印。
   - 左胸小图标独立干净，没有混入多余杂字或被裁断边缘。
4. **回写交接**：检查全部通过后，更新 `facts.print.source`、`facts.print.elements` 和 `facts.print.placements`，交接给 `aionforge-product` 进行 T 恤实拍撞色适配与合成。

## 失败路由

| 现象 | 处置 |
| --- | --- |
| 分辨率未达 4K 印刷标准（长边 < 3000px） | 更换高清矢量/大图底稿，或执行高保真超分增强后再行抠图 |
| 字母内孔或封闭区残留白色底块 | 开启封闭白区处理重跑 [cutout](../aionforge/references/tools/cutout.md)，精细掏空内孔 |
| 设计本体白色（如眼白/白色字标）被误扣镂空 | 关闭全局扣白，改用局部语义提取保护内部设计白色 |
| 印花边缘有白边毛刺或噪点 | 调小容差或加大去噪参数重跑 [cutout](../aionforge/references/tools/cutout.md) |
| 核心图标 `complete: false` 或带入杂字 | 修改语义描述（明确点名图形、强调不要文字）重跑一次 [extract-core-element](../aionforge/references/tools/extract-core-element.md)；仍失败则请用户指定 |
| 原稿带素材站水印 | 停止出成品，提示用户更换无水印源文件 |
