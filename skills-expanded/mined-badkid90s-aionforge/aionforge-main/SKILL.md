# 阶段 3：模特锁脸换衣与多姿势主图（main）

本流程将阶段 2 通过质检的 T 恤实拍合成图（`bg_white` 正面与背面）穿到指定模特身上：**锁五官与眼神、锁 T 恤版型与印花、锁场景光影**，先出锚点主图（`hero`），再派生多姿势主图。

未加载入口时先读 `../aionforge/SKILL.md`。工具只按名称引用，参数见工具卡；本文件不写命令。Prompt 模板见 [tryon.md](../aionforge/references/prompts/tryon.md) 与 [vary.md](../aionforge/references/prompts/vary.md)。

## 输入与输出

| 方向 | 内容 | 说明 |
| --- | --- | --- |
| **输入** | 正面合成商品图 `bg_white`（`garment`）、背面合成商品图 `bg_white_back`（`garment_back`，有背面印花时必填）、模特参考图（`model`）、透明印花（`print`，防糊字辅助） | `bg_white` 是衣服尺寸比例（长宽/宽松度）与袖口做工细节的唯一物理标准；未生成时必须先跑 `aionforge-product` |
| **输出文件** | 锚点主图 `main/<product>-<color>-hero.png`、多姿势主图 `main/<product>-<color>-<pose>.png` | 默认输出所有已合成颜色；前胸+后背双面印花款必须同时输出正面与背面（`*-back.png`）主图；用户点名某色则只跑该色 |
| **输出事实** | `facts.model`、`colors[].hero`、`colors[].anchor`、`canonical.anchor` | 供阶段 4 详情图复用同一模特形象 |

## 四步闭环执行流程

### 第一步：思考（Think —— 解析模特特征、成衣尺寸比例与做工细节、正背面姿势规划）

1. **解析模特与环境特征**：
   - 仔细观察模特图，提取：脸型、五官比例、眼型、瞳色、双眼皮、眼神光位置、发型发色、肤色（若模特图是手机挡脸对镜自拍，记录遮挡物位置，后续保持挡脸不强行补全五官）。
   - 提取模特图原有的下装（牛仔裤/休闲裤/半裙）、鞋包配饰、房间陈设与主光方向色温。
2. **深度解析成衣白底图的尺寸比例与做工细节（核心参考源）**：
   - **尺寸比例对照**：仔细比对 `bg_white` 商品实拍白底图的物理长宽比例：肩线落肩深度（如微落肩 / 大落肩五分袖）、胸围与腰围宽松量（宽松直筒 / 常规合身）、衣长相对腰臀比例（常规及髋 / 中长盖臀）、袖长相对手肘的覆盖位置（如盖过大臂 3/4 接近肘部）。
   - **做工结构细节**：细查商品实拍白底图的做工工艺：袖口（平口双车线 / 罗纹收口 / 卷边 / 袖筒围度）、领口（罗纹密度 / 领深 / 双针压线）、下摆（直筒双车线折边），必须在 Prompt 中写死，严禁模型自行泛化。
3. **识别模特原上衣彻底废弃清单（严禁沿用旧衣款式与尺寸）**：
   - 模特原身穿的上衣其**款式、版型、尺寸紧度、领型、袖长、衣长全部彻底作废**；
   - 坚决杜绝把新印花当贴纸贴在模特旧衣服上，严禁让商品图去迁就迎合模特原图旧衣服的紧绷轮廓或版型尺寸；
   - 找出模特原上衣与商品白底图不符的一切结构（如原旧衣的紧身剪裁、旧领型、长袖、抽绳、口袋、旧图案），作为「必须彻底抹除项」明确写入 Prompt。
4. **正反面印花与姿势联动思考（双面印花正面与背面双展示铁律）**：
   - **只有正面印花**：从 [shots-womenswear.md](../aionforge/references/shots-womenswear.md) 与 `catalog/looks.json` 挑选正面/微侧姿势套餐（如 `studio`、`mirror`、`outdoor`、`cafe`、`walk`）。
   - **前胸+后背印花（如背面主印花+前胸/左胸小标）**：**生成的主图必须同时包含正面展示与背面展示**，缺一不可！
     - **正面展示图（至少 1 张，如 `*-hero`）**：平视或微侧机位，正面居中清晰展示前胸印花/左胸精致小标、领口做工与正面上身版型；
     - **背面展示图（至少 1 张，如 `*-back`）**：**模特姿势支持多元化呈现**（可采用过肩自然回眸、向前迈步漫步背影、单手轻撩耳发/拨发、倚靠窗台/吧台侧背、歇重心松弛插兜背影或背影微坐等多样态动作），大角度背对或微侧背视角（110°–180°），绑定 `garment_back`，完整展示后背大幅核心图案，发丝拨至肩前或扎起，绝无手部或道具遮挡后背印花；**严禁出现“拿手机回头自拍后背”或把前胸印花画到后背的画面**。
4. **多颜色与多模特图匹配策略思考（SKU 图由合成白底图承接）**：
   - **SKU 图原则**：各颜色的电商 SKU 规格图统一直接采用阶段 2 合成后的正面白底图（`bg_white/<product>-<color>.png`），确保各色成衣纯净无偏色、版型标准对齐。
   - 当存在多种成衣颜色（如黑/白/灰）与多张参考模特图（`model_1`, `model_2`, ...）时，明确两种搭配模式：
     - **模式 A（默认推荐：单颜色匹配全部模特图）**：指定单一主推颜色（如主打黑色或主推色），分别换穿到所有不同的模特图上，集中展示该主推色在不同模特、机位与场景下的完整穿搭效果与动态。
     - **模式 B（备选：多颜色循环轮换模特图）**：不同颜色的 T 恤依次循环轮换匹配不同的模特图（如黑色→模特图1、白色→模特图2、灰色→模特图3；若颜色多于模特图则取模循环），体现多色多元穿搭。

### 第二步：事实锁定（Lock —— 锁定 `facts.model`、颜色模特映射与主图拍摄计划）

1. 将模特五官、发型、下装、光线及 `uncertain` 写入 `facts.model`。
2. **确认颜色与模特图匹配方案（主动询问用户，默认推荐单色全匹配）**：
   - 若存在多款颜色与多张模特图，**在事实锁定时主动向用户确认偏好**：
     > 「检测到当前有 [N] 种衣服颜色和 [M] 张参考模特图（SKU 图统一使用合成后的正面白底图）：
     > • **选项 1（默认推荐）**：**单色匹配全部模特图**（指定单一主推颜色穿到所有模特图上，集中展现主打色多姿态场景）
     > • **选项 2**：**多色循环轮换模特图**（不同颜色衣服依次轮换穿到不同模特图上）
     > 默认将按【选项 1 单色匹配全部模特图（主推 [颜色]）】推进，请确认是否按默认执行或切换方案？」
   - 用户确认后，将每个颜色绑定的模特图对应写入 `facts.colors[].model_ref`。
3. 锁定主图生成计划：
   - **第 1 张（锚点 `hero`）**：复刻对应模特图姿势、机位与场景，仅将上衣整件替换为该颜色正面 `bg_white`。
   - **后续派生姿势（双面印花必含背面）**：明确每张姿势的 `shot-id` 与参考图角色组合；**凡属前胸+后背双面印花款式，派生姿势中必须强制规划背面展示镜头（`*-back`）**，传 `source=hero` + `garment_back=背面bg_white`，其余正面/微侧姿势传 `source=hero` + `garment=正面bg_white`；含文字印花时加传 `print=透明印花` 辅助核对字形。

### 第三步：生成（Generate —— 先出锚点，再派生多姿势）

1. **生成各颜色锚点主图（`hero`）**：
   - 按 [tryon.md](../aionforge/references/prompts/tryon.md) 编写 `<product_dir>/prompts/main/<product>-<color>-hero.txt`，写死：
     - **衣服尺寸比例**：落肩幅度、胸围宽松余量、衣长覆盖位置、袖长相对肘部位置，强制与成衣实拍白底图 1:1 对齐；
     - **结构与做工细节**：袖口做工（如平口双车线、折边宽度）、领口罗纹粗细及领深、下摆双车线；
     - 底色 6 位 Hex 色号，以及正面印花/左胸小标位置与文字原文。
   - 调用 [prompt check](../aionforge/references/tools/prompt-check.md) 做静态检查（严禁出现「图1/图2」序号，一律用「成衣图/模特图」角色名）。
   - 调用 [generate](../aionforge/references/tools/generate.md) 生成 `main/<product>-<color>-hero.png`，先跑第四步质检；**只有锚点通过质检后，才能继续派生其余姿势**。
2. **从锚点派生多机位/多姿势主图**：
   - 按 [vary.md](../aionforge/references/prompts/vary.md) 与 `looks.json` 对应 shot 编写每张姿势的 Prompt，强调「五官眼神锁定同一人，头颈随身体动作自然转动；衣服尺寸长宽比例与袖口/领口细节始终与成衣白底图一致」。
   - 背面展示镜头在 Prompt 中明确写死：「本张展示后背，后背图案以背面成衣图为准，只出现背面主印花，严禁把左胸小图标画到后背；长发拨至肩前或扎起。若锚点为对镜自拍，背面图必须去掉手机与镜框，双手自然垂放或插兜，严禁出现拿手机回头自拍或扭头看镜头的反人体工学动作」。
   - 逐张跑 [prompt check](../aionforge/references/tools/prompt-check.md) 后调用 [generate](../aionforge/references/tools/generate.md)。

### 第四步：检查（Verify —— 客观校验与锁脸/锁衣视觉质检）

1. **客观检查**：调用 [verify](../aionforge/references/tools/verify.md) 校验图片尺寸与目标画幅比例（如 `1:1` 或 `3:4`）。
2. **看图质检清单**：
   - **杜绝沿用旧衣款式与尺寸（彻底换衣核验）**：核对模特身上的衣服是否已 100% 替换为商品白底图（`bg_white`）的款式与尺寸。坚决杜绝沿用模特原图旧衣的版型、尺寸紧度、领型或袖长（如模特原穿紧身/短款，生成的 T 恤绝不能变成紧身/短款；模特原穿长袖，生成的 T 恤绝不能残留长袖结构；绝对禁止把印花当贴纸贴在模特旧衣服上）。若发现残留旧衣款式或尺寸特征，直接判定为 **FAIL** 并驳回重做！
   - **衣服尺寸比例对齐质检（对照白底图）**：与 `bg_white` 实拍白底图并排严格比对，模特身穿的衣服整体尺寸比例（胸围宽松度、肩线落肩深度、下摆覆盖位置、袖长相对手肘位置）必须与白底图的长宽尺寸比例完全吻合；严禁将宽松版型画成贴身紧身款，严禁私自缩短衣长或缩小袖长。
   - **袖口与做工结构 1:1 一致性质检**：核对袖口做工（如平口双车线、折边宽窄、无多余缩口或罗纹）、袖筒宽松度、领口做工与下摆车线，必须与商品实拍白底图 100% 保持一致，无虚假结构变形。
   - **身份与头颈自然度**：五官、眼型、眼神光与原模特为同一人；侧身、行走、背面视角时头颈转向自然，无「后背贴正脸」或「拿手机回头后背自拍」的违和/反人体工学画面。
   - **T 恤颜色与印花 100% 还原**：T 恤颜色与 `bg_white` 完全一致，无模特旧衣残留；正面左胸小标与背面大印花位置、大小、颜色（含阶段 2 适配后的颜色）准确无误，正背面绝不串位。
   - **双面印花正反双展示核对**：属于前胸+后背款式的，必须核实 `main/` 产出中正面展示图（突出前胸印花/左胸小标）与背面展示图（完整呈现后背大印花）均已生成且通过质检。
   - **画幅饱满**：画面铺满，无白边、黑边或 letterbox。
3. **回写交接**：将通过质检的锚点图写入 `colors[].hero` / `anchor` 与 `canonical.anchor`，交接给 `aionforge-detail` 生成详情图。

## 失败路由

| 现象 | 处置 |
| --- | --- |
| 沿用了模特原图旧衣的款式、领型或紧绷尺寸 | 明确在 Prompt【主体】写死模特旧衣整件彻底销毁，强行锁定商品白底图的宽松剪裁与物理尺寸重跑 |
| 衣服尺寸比例被改动（变紧、缩短、袖长缩水） | 在 Prompt 中强行锁定成衣图长宽比例与落肩/下摆覆盖位置，严禁缩紧版型后重跑 |
| 袖口做工细节与白底图不一致（如误出罗纹或卷边） | 在 Prompt【主体】与【约束】写死成衣白底图的袖口类型（如平口双车线、无罗纹），重跑该张 |
| 五官漂移或眼神改变 | 在 Prompt【主体】细化眼型、瞳色、双眼皮与脸型特征，同一名称重跑一次 |
| 身体转了但脸还死板正对镜头 | 在 Prompt 强调「头颈随身体转向，侧身看 3/4 脸，背面看后脑或自然侧后轮廓，禁止正脸贴背」 |
| 背面图出现持手机回头自拍或镜框 | 改用第三人称纯背面/微侧背视角（110°–180°），在 Prompt 明确去掉手机与镜面、双手自然垂放、严禁回头自拍后重跑 |
| 背面图出现了正面左胸小标 | 检查是否误传了正面 `garment`，改为传入 `garment_back` 并在约束中禁止左胸徽章出现在背部 |
| 换姿势后印花文字变糊 | 额外传入透明印花作为 `print` 角色参考，写明「核对图案形状与逐字写法」 |
| 模特旧上衣结构残留 | 将残留部位（如帽衫领、旧袖口）明确加入 Prompt 的「必须去掉」列表重跑 |
