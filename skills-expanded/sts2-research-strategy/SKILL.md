# STS2 strategy research workflow

Use this skill when the task is to **resolve strategic uncertainty with outside evidence**.

## What this skill owns

- web research for matchup, archetype, route, reward, or economy questions
- comparing multiple sources instead of copying the first one
- translating general advice into the actual run state
- surfacing notes that are worth preserving in future reviews

## Research loop

1. Define the narrow question
   - examples: "Is this Ironclad Act 1 deck strong enough for an early elite?" or "How should Brand change early reward priorities?"

2. Gather evidence from more than one source
   - prefer guides, discussion threads, or analyses that explain the tradeoffs
   - avoid treating one flashy line as authoritative

3. Reconcile the advice with the run in front of you
   - deck
   - relics
   - HP
   - gold
   - map
   - potions

4. Return a decision-oriented answer
   - say what the best line is now
   - say what assumption would make that line wrong

5. Preserve anything durable
   - if the finding is temporary, put it into the current playbook at [../../sts2-memory/current-playbook.md](../../sts2-memory/current-playbook.md)
   - if it generalizes, hand it off to `sts2-review-run` so it can be written into [../../sts2-memory/lesson-ledger.md](../../sts2-memory/lesson-ledger.md)

## Constraints

- Do not paste generic advice without adaptation
- Prefer evidence-backed heuristics over one-off anecdotes
- Keep the output concise and actionable
