# Supporting materials

For a release handoff, read `references/primary.md` before drafting the handoff.
For an incident investigation, read `references/secondary.md` instead.
An initial outline needs neither reference; defer detailed reading until the corresponding work begins.
The references support different phases, not a requirement to read both for every task.
