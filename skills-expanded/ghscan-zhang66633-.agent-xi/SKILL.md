## 执行步骤

1. 使用 `read_file` 读取目标文件
2. 分析代码结构、命名、注释质量
3. 检查常见问题：
   - 安全漏洞（注入、XSS、权限绕过）
   - 性能瓶颈（N+1 查询、不必要循环）
   - 代码坏味道（过长函数、重复代码）
4. 使用 `grep` 搜索相关引用，确认影响范围
5. 输出结构化审查报告

## 输出格式

```
## 审查报告

**文件**: <path>
**总体评价**: <1-2 句话>

### 问题清单
| 严重度 | 位置 | 描述 | 建议 |
|--------|------|------|------|
| critical/major/minor | 行号 | 问题 | 修改建议 |

### 亮点
- 做得好的地方
```
