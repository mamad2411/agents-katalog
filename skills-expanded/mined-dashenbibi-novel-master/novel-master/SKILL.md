# 长篇小说创作大师

专为创作数百万字长篇小说设计的系统化技能。

## 🎯 核心能力

| 能力           | 说明                                    |
| -------------- | --------------------------------------- |
| **整体规划**   | 三幕式/英雄之旅大纲，分卷设计，章节规划 |
| **角色管理**   | 角色档案、关系图、成长弧线、出场追踪    |
| **世界观构建** | 地理、历史、规则、文化、经济系统        |
| **章节写作**   | 根据大纲生成内容，保持文风统一          |
| **一致性检查** | 剧情矛盾、人物行为、时间线、设定冲突    |
| **伏笔追踪**   | 记录所有线索和回收状态                  |

## ✅ 裁决分层与优先级体系（Style Resolution）

在创作中，表达与规则遵循严格的逐层裁决原则，通用技能绝不越俎代庖：

**当前用户明确要求 > 本书 rules.md 与设定事实 > 本书 active 角色档案 > 题材情绪模型 > 本技能通用建议**

- **框架只管语言物理规律（怎么写像真人）**：严控正文解释性破折号、杜绝动词膨胀（如“暴雨砸下来/撕裂夜幕”）、禁止过度解释（Show, Don't Explain，放开深层利弊推演）、禁止章末总结升华、纯净正文解耦架构。
- **项目完全掌控戏剧人格（写什么样的人）**：角色的精神状态、心理描写深度、情绪起伏、对话风格（无论是毒舌反讽、清醒反杀，还是隐忍苟道、沉郁悲悯、甚至惊悚恐惧），100% 由作者在本书的 `rules.md`、世界观和角色档案中自由定义，本技能绝不强制绑定“爽文反骨”或任何单一性格模板。
- **篇幅与节奏**：用户要求的篇幅优先；没有要求时可参考 2500–3500 字。正文服务本章目的，保持事实连贯与因果闭合，严禁残留模板占位符。

## 🗂️ 工作区优先模式

若用户已经在一个长篇小说工作区内创作，优先遵循工作区文件，而不是泛化想象：

- 按任务读取已有的 rules.md、总览、相关角色、世界设定、卷纲和追踪表；续写时还要读最近相关正文及被引用的前文章节。只加载影响本次工作的内容。
- 若工作区已存在专用术语表、称谓表、追踪表，必须先读取后再写正文
- 若项目已有章节格式，继续沿用现有格式，不要强行替换为新模板
- 若工作区存在“记忆更新清单”“本章备注”“伏笔追踪”等机制，写入章节后按实际变化同步维护；只检查时不修改文件。
- 若项目规则与本技能默认值冲突，以项目规则为准

## 🧭 推荐工作流

将长篇创作拆成两个层面：项目搭建与章节生产。

### 项目搭建顺序

1. 明确方向：题材、风格、核心卖点、主线目标
2. 搭建结构：创建总览、角色、世界观、卷纲、章节、追踪文件
3. 生成专属规则：只写本书特有的文风、称谓、术语和禁忌
4. 建立角色档案：补全身份、行为模式、声线、关系网络、转折条件
5. 建立世界观：每条规则写清限制、代价、破坏后果
6. 制定卷纲：卷主题、阶段目标、章节表、高潮、伏笔表

### 章节生产顺序

1. 确定范围：区分规划、写正文、润色和只检查；仅完成用户请求的范围。续写未指定数量时默认写下一章。记下用户指定的字数、必发生与禁止发生的事件、时间和停笔位置。
2. 骨架：根据需要梳理标题、视角、冲突、剧情节点
3. 正文：按当前骨架扩写，不擅自改主走向。
4. 润色和质检：按本书文风检查表达与连续性，交付前核对用户的明确约束。
5. 同步：只记录本章实际发生的角色状态、设定、目标和伏笔变化；区分计划与已发生事实。

### 适用场景

- 用户要快速出稿：允许一轮完成“骨架 → 正文 → 润色 → 质检 → 同步”
- 用户要强控结构：拆成多个阶段逐步确认
- 用户只要检查：只输出问题与建议，不改正文

## 📜 项目规则生成规范

为单个项目生成 rules.md 时，优先只写“本书特有、可执行、能约束正文”的规则，不重复通用写作常识。

rules.md 至少覆盖以下模块：

1. 文风与节奏
2. 对话与心理描写纪律
3. 抗机味硬性禁令与检查清单
4. 称谓与用语统一
5. 错别字、语法与逻辑检查
6. 正文纯净与追踪解耦原则

### 1. 文风与节奏基准

- 明确文风基调定位（如冷硬、明快、压迫、诗性、惊悚、黑色幽默等）
- **句式呼吸感与因戏赋形**：
  - 宏观参考 2:4:4 黄金节拍（20% 长句勾勒环境地势机制、40% 中句承接行动因果逻辑、40% 短句动作爆发与对白机锋），作为全书宏观节拍参考，非单段机械指标。
  - 根据戏剧场景“因戏赋形”：生死刺杀、冲突爆发时短句可占大半以制造窒息感；环境铺陈、谋定推演时长中句自然增多。避免通篇单一长度句式（既防止长句臃肿，也防止通篇碎句提纲化）。
- **段落颗粒度标准（常态 3 至 5 句，允许高潮单句重音）**：
  - 常态叙事保持 3-5 句一自然段，兼顾逻辑承接与移动端阅读的舒适呼吸感。避免一句话一段连排几十行的营销号碎读感，亦避免通篇不分段的致密砖头块。
  - 在生死决胜、情绪暴扣、重大反转等高潮节点，**允许且鼓励单句成段作为重音击打**（如“刀落。人分。”），制造强烈的视觉停顿。
- **章末收束钩子**：必须落在具体的动作、证据发现或局面受阻等物理节点上，严禁用大道理总结或空泛哲理感叹收尾。

### 2. 视角与镜头纪律（镜头锁定与场景聚焦）

- **单场次镜头聚焦（防乱飘 Head-hopping）**：
  - 单个场景或戏剧交锋中，叙事镜头严格限制在主视点角色的感官极限之内（仅限其亲眼所见、亲耳所闻、亲身所感以及当下做出的决断）。
  - 严禁在同场对话或搏杀中随地跳进对手脑内窥探内心独白。对手与同伴的意图只能通过其微动作、神色变化、重心移动、语调停顿或对白潜台词，由视点人物推测。
- **合规变焦与切镜机制（拒绝死锁）**：
  - **广角起幅（Establishing Shot）**：允许在开篇或转场时用客观中立广角写天地大势、环境气象或宗门社会，推近到人物博弈时再启动深度聚焦。
  - **跨场次切镜（Scene / POV Shift）**：允许通过分节符（`* * *`）或换章，切换至配角、反派或旁观者视点，推动双线博弈与宏观推进。
  - **借道视角**：允许借用第三方旁观者之眼侧面烘托主角的威慑力与手段，增强叙事留白与张力。
  - 用户未明确要求全知视角时，新项目默认以有限第三人称推进。
- **题材与角色自由**：角色的情绪波动、精神状态、心理活动深度由本书题材决定，技能不做单一性格预设。
- **台词真实性与潜台词**：台词必须服务于角色当下的动机（试探、隐瞒、争执、索取筹码或情感流露），严禁角色沦为向读者生硬搬运世界观的工具人。重要信息避免直白吐露，允许根据角色性格保留留白、沉默或话里藏刀。

### 3. 抗机味硬性禁令与检查清单

- **严控正文叙述破折号（“——”）**：
  - 严禁在正文叙述中滥用破折号进行**解释性补充**、**教师爷说教**或**虚浮哲理感叹**（如“他握紧了刀——这是他最后的底牌”）。
  - 允许在对白中用于**突发暴力打断、猝然击毙或剧烈声响截断**（如“小心，刀上有——”话音未落，箭已穿喉）。
- **严禁动词用力过猛与动词膨胀**：禁止无脑拉满暴力动词（如“暴雨砸下来”、“雷光撕裂夜幕”、“狠狠一划”、“死死扣住”、“整个人彻底凝固”），环境与动作描写注重自然呼吸感与真实物理白描。
- **禁止过度解释（Show, Don't Explain，放开深层利弊博弈）**：
  - 动作做完立刻推进剧情，严禁在事后用多句心理自白向读者当教师爷反复解释动机。
  - **允许并鼓励**角色在面临死局、关键抉择时，基于有限线索展开深层心理盘算、利益权衡与智斗推演。
- **核心阻力与危机的严肃性保护**：故事的核心危机、法则约束、社会制度或权威压迫，是支撑故事张力的最高维度不可抗力。严禁在叙事中以轻浮调侃、破坏第四面墙的元叙事或游戏化概念进行轻率解构，避免消解读者的生死沉浸感与紧迫感。
- **时代语境与题材词汇纯度**：叙事与台词用语严格受限于当前世界观的时代背景与科技/文化水平。严防脱离世界观语境的现代技术术语、网络热梗或开发术语无意识渗透进非现代题材中。
- **禁止无意义的双引号强调**：不要用引号包装普通词汇做假术语（如所谓的“机会”、完成“蜕变”）。
- **禁止叠加式描写**：避免把同一个动作拆成发生层、感知层、反应层连续写三遍，应自然揉进连续正文中。
- **禁止章末总结体**：禁止以“他不知道的是……”、“这一刻注定……”、“命运的齿轮……”等哲理感叹收尾。

### 4. 称谓与用语统一

- 可使用三层称谓：叙事层 / 对话层 / 元数据层
- 为项目专属术语建立最小术语表，防止章节里出现同义混写
- 若称谓规则与角色档案冲突，先指出冲突源，再决定保留哪一处

### 5. 错别字、语法与逻辑检查

- 明确项目中的高风险同音字、常见误写术语、因果链漏洞与时间空间锚点要求
- 规则一旦落到正文，必须能被验证、阻拦、追责或反噬，不能只当背景介绍

### 6. 正文纯净与追踪解耦原则

- **正文纯净原则**：`04-chapters/` 目录下所有章节文件**仅保留纯净小说正文**（一级标题章名 + 二级标题正文），严禁在正文末尾附带记忆清单、本章自检或开发备注。交付即是成品，方便作者一键复制到平台发布。
- **三维独立追踪看板体系**：
  1. `05-tracker/context.md`：即时上下文与角色状态机看板（记录最新位置、角色状态、近期事件速记）。
  2. `05-tracker/capabilities.md`：能力边界与资源/战力追踪看板（记录能级梯队、关键道具、资产、越级反杀因果，防止后期战力与数值膨胀崩坏）。
  3. `05-tracker/foreshadowing.md`：全书伏笔追踪矩阵（线索编号、埋设、触发、回收状态闭环）。
- **历史兼容**：若旧项目历史上已采用单文件三段式且明确要求维持，允许兼容；但新项目默认严格执行正文纯净解耦。

## 👤 角色档案规范

角色档案应优先维护为“可执行档案”，不是人物简介。每个角色至少包含以下 7 组信息：

### 1. 基本信息

- 姓名
- 别名 / 乳名 / 代号
- 性别
- 年龄
- 外貌特征（只留辨识度最高的 2-3 个）
- 身份 / 职业
- 阵营
- 社会位置（在权力结构中的层级，手上筹码）

### 2. 性格与行为

- 核心性格（2-3 个关键词）
- 行为模式（压力 / 背叛 / 被示好时的条件反射）
- 动机（当前最强驱动力）
- 价值观底线（绝不会做什么）
- 盲区 / 认知偏差（误判如何驱动剧情）
- 情感弱点（什么人或事能让他失去理性）

### 3. 声线与说话风格

- 语气基调
- 口头禅 / 高频词
- 句长倾向
- 称谓习惯
- 不会说的话（反面约束）

### 4. 能力与装备

- 当前境界 / 等级
- 核心能力
- 武器 / 关键道具
- 弱点 / 限制（条件、风险、消耗）
- 战斗风格
- 成长潜力（隐藏能力、觉醒条件）

### 5. 关系网络

- 与主角关系
- 与其他角色关系（性质 + 信任度 + 利益绑定或冲突）
- 情感锚点
- 欠债关系
- 秘密（隐瞒了什么，暴露后会发生什么）

### 6. 角色弧线与剧情定位

- 叙事功能
- 出场状态
- 核心矛盾
- 转折条件
- 预期终局方向
- 关键事件经历
- 伏笔 / 悬念

### 7. 当前状态

- 出场章节
- 当前状态（活 / 死 / 失踪 / 变化中）
- 已完成的变化
- 待解决的问题

### 角色档案执行规则

- 角色能力必须符合世界观上限，不得超纲
- 关系网络必须双向一致，修改 A 对 B 的关系时同步检查 B 对 A
- 新角色创建后，应同步登记到总览中的角色清单
- 若章节导致角色状态、关系或阶段位置变化，应回写档案

## 🧱 章节输出格式

正文严格执行纯净交付原则。新项目的正文以自然叙事呈现时间、地点、视角、目标、行动与后果；不在正文插入“开场锚点”“推进点”“钩子”等制作标签，末尾绝不附带记忆清单或开发草稿备注。章节产生的记忆更新与状态变动，统一解耦并更新至 `05-tracker/context.md`。

## 📚 分卷大纲规范

分卷大纲优先采用可检索、可核对、可同步的结构。工业级长篇推荐覆盖以下 7 组 18 项参考矩阵（核心必保 5 大支柱：卷核心冲突、阶段三递进目标、核心人物关系跃迁、卷高潮与代价、伏笔流转；其余细项根据作品规模自适应裁剪，避免为了填表虚构假大空套话）：

### 一、卷元信息

1. 卷标题与主题
2. 时间跨度
3. 主要地点
4. 章数规划（章节号必须与全书连续）

### 二、目标与冲突

5. 核心冲突
6. 卷内阶段目标（开端 / 发展 / 高潮三个递进目标）
7. 主线定位
8. 卷末主问题

### 三、角色规划

9. 关系变化目标
10. 认知变化目标
11. 本卷新增角色表（角色 / 性别 / 外貌 / 身份 / 首登章节）
12. 本卷固定配角与关系类型表（角色 / 关系类型 / 卷内功能）
13. 角色弧线节拍（关键角色跨章情绪 / 行为轨迹，落到具体章节）

### 四、章节列表

14. 章节表（章节 / 标题 / 状态 / 字数 / 概要）

### 五、事件与高潮

15. 本卷重要事件（编号并标注章节）
16. 卷高潮设计（高潮事件 + 代价 + 未解问题）

### 六、世界观落地

17. 卷内规则定义（本卷涉及的规则参数、等级上限、资源消耗、封控级别等）

### 七、伏笔布局

18. 本卷伏笔表（编号 / 内容 / 类型 / 触发方式 / 显隐 / 章节 / 状态 / 回收章节）

### 卷纲执行建议

- 按作品规模规划卷主题、目标、章节、高潮和卷末衔接。
- 检查主线、配角、感情线和跨卷伏笔的节奏；出现频率由题材和项目决定。

## ⚡ 黄金开头与黄金三章工业节拍

商业小说的核心在于预期管理——快速验证“内容是否与期待一致”，前 500 字决定读者去留，前 3 章（约 1 万字）决定签约与追读留存。

### 1. 黄金开头（首章前 500–1000 字生死线）

#### 必达硬性指标

- **300 字内**：主角必须登场，确立**人设基点**与当下所处环境，绝不从旁观者或路人废话起笔。
- **1000 字内**：必须爆发打破日常平衡的核心切入点事件（Inciting Incident），让读者感知到明确的戏剧冲突或利益期待。
- **开局处境三选一**：主角开场必须处于以下状态之一，严禁平淡日常：
  1. *身处即时危机*（生死受制、遭人算计、大难临头）；
  2. *面临重大抉择*（利益冲突、身份错位、秘密暴露）；
  3. *被置入极端环境*（规则严酷的新世界、凶险未知的封闭绝地）。
- **信息释放优先级法则**：开篇信息必须严格遵循 **即时危机 > 核心人设 > 破局筹码暗示 > 宏观世界观背景**，严禁倒置。

#### 六大绝对劝退禁令

- 🚫 **严禁大段世界观倾倒（No Infodump）**：开篇严禁连写三段历史变迁、体系分级或大陆地理；背景必须像盐溶于水，在人物动作与生存压力中自然带出。
- 🚫 **严禁无机质苏醒与无效日常**：严禁以“主角从昏睡中醒来，茫然看着陌生天花板，脑海一阵刺痛”开场。
- 🚫 **严禁动词用力过猛**：杜绝“暴雨是酉时三刻砸下来的”、“雷光撕裂苍穹”等舞台剧式膨胀描写，以沉静扎实的物理白描落地。
- 🚫 **严禁首章出场 3 个以上有名角色**：防止认知过载，前千字只聚焦视点角色与核心对立面。
- 🚫 **严禁序章、楔子与无关插叙**：严禁写脱离主线的前传或宏大旁白，必须直接从主线爆发点正叙切入。
- 🚫 **严禁世界观详细解说**：世界观底层逻辑与复杂机制至少等到首轮危机化解后再逐步展开。

### 2. 黄金三章核心三大基点

前 3 章必须全部立住三大支柱，构建完整的读者期待链：

1. **人设基点（第 1 章）**：展现主角的生存底色、行动动机与核心性格，建立读者的情感代入与共鸣。
2. **切入点基点（第 1 章）**：遭遇不可逆转的重大事件，日常秩序彻底打破，切断退路。
3. **破局筹码基点（前 3 章内）**：展现主角独有的破局资本或差异化机制（信息差、特殊技能、秘宝、契约或特殊外挂），制造反转期待。

### 3. 黄金三章节拍律（跨题材推进模型）

$$\text{定调} = \text{令人不安的处境} + \text{亟待提升的地位} + \text{充满希望的破局筹码} + \text{能被展望的美好未来}$$

- **第 1 章：立身与爆点入局（Anchor & Inciting Incident）**
  - 确立主角人设与底层生存痛点；引爆核心事件，退路被断，被迫或主动入局。章末钩子：危机压顶，生死悬念。
- **第 2 章：筹码与暗流涌动（Leverage & Deepening Stakes）**
  - 展现专属破局筹码与特殊机制；与敌对力量或严酷环境展开第一轮间接博弈/试探；揭示危机冰山一角，压迫进一步升级。章末钩子：筹码准备就绪，行动触发在即。
- **第 3 章：小胜破局与立誓出征（First Payoff & Main Goal）**
  - 完成第一场局部冲突的漂亮反击或惊险化解（验证筹码机制的有效性与代价闭环）；化解燃眉之急，确立第一阶段明确、紧迫的主线目标（如逃离、反杀、夺牌、复仇）；读者获得首轮情绪正反馈与强烈的追读渴望。

## 🧭 视角与声线纪律

- **单场次镜头聚焦（防乱飘 Head-hopping）**：
  - 单个场景或戏剧交锋中，叙事镜头严格限制在主视点角色（POV）的感官极限之内（仅写其亲眼所见、亲耳所闻、亲身所感以及当下做出的决断）。
  - 严禁在同场对话或搏杀中随地跳进对手脑内窥探内心独白。对手与同伴的意图只能通过其微动作、神色变化、重心移动、语调停顿或对白潜台词，由视点角色观察推测，保留博弈张力。
- **合规变焦与切镜机制（拒绝死锁）**：
  - **广角起幅（Establishing Shot）**：允许在开篇或转场时用客观中立广角写天地大势、环境气象或社会背景，推近到人物博弈时再启动深度聚焦。
  - **跨场次切镜（Scene / POV Shift）**：允许通过分节符（`* * *`）或换章，切换至配角、反派或旁观者视点，推动双线博弈与宏观推进。
  - **借道视角**：允许借用第三方旁观者之眼侧面烘托主角的威慑力与手段，增强叙事留白。
- **声线区隔**：根据角色身份、立场、动机与处境区分声线，允许随情绪与关系自然演进，避免千人一面。
- **对话因果**：对话必须承载实际动机、博弈潜台词或推进情节，避免无意义寒暄与信息空转。

## ✍️ 文本颗粒度与节奏律

- **句式呼吸感与因戏赋形**：
  - 宏观参考 2:4:4 黄金节拍（长句描景建构、中句承接行动因果、短句动作爆发），作为全书宏观节拍参考，非单段机械指标。
  - 根据戏剧场景“因戏赋形”：生死刺杀、冲突爆发时短句可占大半以制造窒息感；环境铺陈、谋定推演时长中句自然增多。避免通篇单一长度句式（既防止长句臃肿，也防止通篇碎句提纲化）。
- **段落颗粒度标准（常态 3 至 5 句，允许高潮单句重音）**：
  - 常态叙事保持 3-5 句一自然段，兼顾逻辑承接与移动端阅读的舒适呼吸感。杜绝全篇一句话一段的短视频脚本体；杜绝大半屏不分段的说明文式密不透风排版。
  - 在生死决胜、情绪暴扣、重大反转等高潮节点，**允许且鼓励单句成段作为重音击打**（如“刀落。人分。”），制造强烈的视觉停顿。

## 🌐 规则严肃性与语境纯洁度

- **核心规则严肃性保护**：世界观设定的底层法则、资源边界、权力机制或生死代价，是故事最高维度的不可抗力与危机根源。严禁在非特定反讽或荒谬设定的正剧中，用戏谑、调侃或打破第四面墙的方式轻浮消解核心规则与严峻危机。
- **时代与语境词汇纯洁度**：叙述语体与角色对白必须严格符合作品所属的历史背景、科技阶段与社会语境。严禁现代流行网络黑话、研发术语或跨题材概念在非对应背景中无意识渗透。

## 🧮 一致性检查细则

按严重度输出问题点、具体位置及证据、影响和修正建议；区分确定矛盾与资料不足的疑点，说明检查范围与未能核实的内容。只检查时不修改文件。

必查项：

- 动机与行为冲突
- 能力成长速度不合理
- 时间跨度与地理距离不匹配
- 社会规则与经济逻辑自相矛盾
- 设定被忽略或被改写
- 人称称谓与亲属关系一致
- 物品稀缺性与行为动机一致
- 权力边界与角色反应一致
- 伤势与行动能力一致
- 关键信息揭示节奏一致
- 境界差距与胜负结果一致
- 重复段落与重复句式已清理
- 主线阶段目标连续
- 支线是否长期悬置，是否需要推进或收束
- 角色动机变化是否有合理铺垫
- 配角出场频率与主线推进相关
- 配角行为动机与利益关系一致
- 感情线推进与主线事件因果一致
- 情感变化有明确触发事件与代价
- 关键角色行为必须与角色档案一致，若违背必须给出可追溯的动机变化与代价
- 角色能力提升或战斗强度跃迁需有明确铺垫与代价，不得跨章直接拔高

## 🔍 专项质检清单

除通用一致性检查外，支持以下专项审查：

- 规则文件审查：检查 rules.md 是否完整、可执行、与世界观和总览一致
- 角色档案审查：检查信息完整性、关系双向一致、能力与设定匹配
- 世界观审查：检查规则完整性、术语统一、代价是否落地
- 卷纲审查：检查章节编号、高潮节拍、伏笔布局、跨卷衔接
- 跨域一致性审查：世界观 × 角色 × 卷纲 × 章节 × 伏笔的交叉核验
- 风格漂移审查：抽样多章比对句长、对话占比、角色声线、结尾方式

输出时优先给问题、证据、严重度与修正建议，不要先写泛泛总结。

## 📈 揭示节奏与能力边界

- 按大纲控制重大信息揭示，区分角色已知和读者已知；检查关键线索与结果是否有因果衔接。
- 涉及能力体系时，检查胜负、成长与已设定的限制和代价。高潮与阶段收束依作品节奏安排。
- **反弱胜强与冲突破解因果支撑库**（跨题材通用原则：面对跨阶位强敌、重大生死逆境时，破局必须具备严密的因果依据，严禁无铺垫爆种或主角光环锁血。重大对决建议综合以下要素，日常交锋满足 2-3 项即可形成自洽闭环）：
  1. **信息差与弱点洞察**：洞悉对手未公开的旧疾、破绽、逻辑盲区或关键情报。
  2. **机制与资源克制**：持有属性相克、专业反制工具、特定杀伤手段或利用对方机制的固有缺陷。
  3. **借势与外部变量**：借用地形天候、第三方力量牵制、环境变数、规则限制或时间窗口。
  4. **代价闭环与果决执行**：破局需承担对应成本（生理创伤、关键资源损耗、底牌暴露、后遗症），行动果断利落，抓住破绽一击破局，拒绝漫长无逻辑互殴。

## 🧷 事实锁定清单

- 主角身世关系是否已定稿
- 导师身份是否已定稿
- 关键反派立场是否已定稿
- 关键功法来源是否已定稿
- 境界层级与战力差距是否已定稿
- 主线目标是否已定稿
- 卷内阶段目标是否已定稿

## 🧠 续写前的状态

续写时按项目现有文件结构，读取最近相关正文、当前卷纲、相关角色与世界设定、已有追踪表。整理简短的工作摘要（无需另建文件）：

- 已发生的关键事件及来源章节；人物的位置、状态、关系和各自已知的信息。
- 当前目标、未解决问题及与本章有关的伏笔；区分角色已知、读者已知和尚未揭示的内容。
- 当前章节的计划与用户明确的篇幅、必发生、禁止发生和停笔位置。卷纲中的计划仅作为计划，不当作正文已经发生的事实。

读取范围按任务需要扩展，发现状态不一致时回查来源；资料不足标为未知，关键事实无法合理推断时询问用户。不要为了补齐摘要虚构设定，也不强制创建新的追踪文件。

## 📝 写章后的同步

1. 写入并检查章节后，对照正文整理实际发生的变化：事件及来源章节、角色状态和所知信息、世界规则、目标、伏笔的埋设/呼应/回收；无变化可省略。
2. 按项目已有机制，只更新受影响的总览、角色档案或追踪条目。计划中的内容标为计划；回收章节或方向未定可标“待定”。多章续写逐章写作与同步，再处理下一章。
3. 核对更新与正文、原有记录是否一致；保留未发生的计划，不把草稿或设想写成事实。发现冲突先回查来源，无法判断时说明；若写入部分失败，报告未同步的位置及可直接粘贴的内容。
4. 仅在对话交稿或无法写入时，提供标明位置的简短更新建议。只检查或只润色表达时，不擅自改变剧情事实或追踪状态。

## 🏷️ 称谓与术语治理

- 支持三层称谓治理：叙事层、对话层、元数据层可以不同，但必须全书一致
- 角色改名或术语替换前，先扫描全书影响范围，再输出影响报告，再执行替换
- 批量替换后必须做残留检查、误伤检查和变体检查
- 若旧名是其他词的子串，必须先警告再替换
- 世界观术语优先维护专有名词表，避免章节里出现同义混写

## 大纲与伏笔规划

- 按请求层级规划：全书明确核心矛盾和阶段目标；分卷明确冲突、转折与衔接；章节按需安排目标、阻碍、行动、后果和结尾。
- 参考 `references/chapter-outline-template.md`，按题材取舍字段。角色动机与转折应有可追溯的铺垫，不强制固定章数或感情线。
- 记录重要伏笔的来源、状态和可能的回收方式；回收时间可以待定。定期检查长期搁置的线索，结合故事需要决定呼应、回收或保留。

## 🌍 世界观设定规范

世界观应优先写成“可验证规则系统”，不是散文式百科。完整版本建议覆盖以下 7 大类 29 项：

### A. 核心体系与规则

1. 核心命题
2. 世界规则 / 法则（每条规则必须包含限制 + 代价 + 破坏后果）
3. 能力与资源体系（稀缺资源、获取方式、使用代价）
4. 等级 / 境界体系（上限、瓶颈、升级路径与代价）
5. 规则约束与禁忌
6. 规则的元层（规则是谁定的、能否修改、修改的代价）

### B. 地理与环境

7. 地形地貌
8. 环境特征
9. 空间结构
10. 空间关系

### C. 社会体系

11. 权力结构（至少 3 层，并标注制衡关系）
12. 经济体系
13. 法律与秩序
14. 阶层流动

### D. 文化与认知

15. 信仰与宗教
16. 习俗与仪式
17. 称谓与语言
18. 知识传承

### E. 历史与时间

19. 纪年与大事件
20. 历史断层
21. 遗迹与传承
22. 时间体系

### F. 生命与死亡

23. 种族与生命形态
24. 死亡与存续
25. 生活细节

### G. 悬念与伏笔

26. 隐藏秘密
27. 线索体系
28. 潜在冲突
29. 可验证场景（至少 3 个）

### 世界观执行规则

- 新增规则不得与已有规则冲突；若冲突，先明确指出并请求确认
- 核心术语必须与项目规则、角色档案和总览一致
- 修改权力结构时，应检查相关角色档案是否需要同步更新
- 当单文件世界观过大时，可拆成子文件，但主索引必须保留

## 🧭 阶段目标、配角与感情线

- 阶段目标可记录目标、阻碍、代价与下一阶段问题，数量按作品规模决定。
- 按故事需要安排配角的独立目标和主线关系；若有感情线，检查关系变化是否有触发和后果。
- 伏笔记录首次出现、当前状态和回收方向；回收章节未定时标“待定”。

```
生成第 X 卷大纲，卷名：XXX，主线目标：XXX，卷内阶段目标：3 个，列出每 10 章推进点/关系变化点/认知变化点/冲突升级方式/钩子类型
```


### 命令 3：润色章节

```

```

### 命令 3.1：检查规则文件

```

```

### 命令 3.2：检查角色档案

```
检查所有角色档案的信息完整性、关系双向一致、能力边界和潜在冲突
```

### 命令 3.3：检查世界观

```
检查世界观规则、术语统一、代价落地、历史断层与可验证场景是否完整
```

### 命令 3.4：检查卷纲

```
检查第 X 卷或全部卷纲的章节编号、阶段目标、高潮节拍、伏笔布局与跨卷衔接
```

### 命令 3.5：检查风格漂移

```

```

### 命令 4：一致性检查

```
检查第 1-10 章的一致性，查找矛盾和伏笔
```

### 命令 4.1：跨域一致性检查

```
对世界观、角色档案、卷纲、章节和伏笔追踪做交叉一致性检查，按严重度输出问题、证据和修正建议
```

```

```

## 结尾方式与叙事视角

### 需要结合语境检查的结尾句式

```
❌ "他不知道的是，从这一刻起……"
❌ "而此时的他还不知道……"
❌ "他更不知道的是……"
❌ "从此，他的人生改变了……"
❌ "命运的齿轮开始转动……"
```

### 可参考的结尾方式

| 类型         | 示例                           | 适用章节 |
| ------------ | ------------------------------ | -------- |
| **动作钩子** | "他推开门，愣住了。"           | 动作章   |
| **对话钩子** | "'你根本不知道真相。'她说。"   | 对话章   |
| **问题钩子** | "门后是谁？"                   | 悬念章   |
| **场景钩子** | "远处，火光冲天。"             | 过渡章   |
| **发现钩子** | "信的折角处，压着半枚带血的私印。" | 揭秘章   |

### 检查规则

- 根据本章作用选择收束方式；重复套式可调整，情绪余韵或阶段性收束也可以作为结尾
- 结合叙事视角检查无意剧透
