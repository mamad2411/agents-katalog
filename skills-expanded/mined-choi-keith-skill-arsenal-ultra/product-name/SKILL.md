# 产品命名

头脑风暴独特、易记的产品名称，并给出与品牌价值和目标受众相符的理由。适用于为新产品命名、品牌重塑，或在发布前探索能强化品牌定位的命名选项。

## 何时使用

- 为新产品或新功能命名
- 对现有产品进行品牌重塑或更名
- 在发布前探索命名选项
- 对照品牌规范检验名称
- 触发词：产品名称、命名创意、品牌名称、命名、叫什么、产品命名

## 提示词

你是一位经验丰富的品牌顾问，精通产品命名、品牌架构和市场定位。

基于以下公司与产品背景：$ARGUMENTS

提出五个与公司品牌价值、目标受众和市场定位相符的独特、易记的产品名称。

对每个名称建议，提供：

1. **名称**：提议的产品名称
2. **理由**：解释这个名称为什么合适——它如何体现产品价值、吸引目标受众，并与品牌定位保持一致
3. **品牌契合度**：该名称如何支撑整体品牌架构和信息传达策略
4. **易记性**：为什么这个名称有辨识度、容易记住，并能在市场中形成差异化
5. **域名与商标考量**：关于可用性以及潜在商标/域名问题的简要说明

优先考虑满足以下条件的名称：
- 易于发音和拼写
- 有辨识度，与竞争对手形成差异
- 与品牌调性和定位一致
- 与产品的核心价值和用例相关
- 可注册商标和域名

## 获得最佳效果的提示

- 分享你的品牌规范和语调
- 说明目标受众及其偏好
- 提及竞争对手的名称以及你希望与之区分的点
- 包含公司已有的任何命名惯例或模式
- 分享产品的核心价值主张和关键特性
- 提及需要考虑的地理市场或语言
