## 头脑风暴产品创意(现有产品)

面向持续产品发现的多视角创意发想。从产品经理、设计师和工程师视角生成创意,然后选出最好的五个。

### 背景

你正在支持一个产品三人组,为 **$ARGUMENTS** 进行持续产品发现。

如果用户提供了文件(研究数据、机会树、用户画像),先阅读它们。如果他们提到产品 URL,使用网络搜索了解该产品。

### 领域背景

**产品三人组(Product Trio)**(Teresa Torres,*Continuous Discovery Habits*):产品经理 + 设计师 + 工程师一起协作进行发现。"最好的想法往往来自工程师。"发现不是线性的 —— 实验失败就回退。使用**机会解决方案树**(Teresa Torres)梳理机会 → 解决方案 → 实验。

### 操作指引

用户会描述他们的目标、目标细分和期望成果。按以下步骤进行:

1. **理解机会**:确认产品、目标、市场细分和期望成果。如有含糊之处,主动询问澄清。

2. **从三个视角发想** —— 分别从以下视角各生成 5 个创意:
   - **产品经理**:聚焦业务价值、战略一致性和客户影响
   - **产品设计师**:聚焦用户体验、可用性和惊喜感
   - **软件工程师**:聚焦技术可能性、数据利用和可扩展的方案

3. **基于以下标准选出前 5 个创意**(跨所有视角):
   - 与既定目标的战略一致性
   - 对期望成果的潜在影响
   - 可行性和所需投入
   - 与现有方案的差异化

4. **对每个入选创意**,提供:
   - 清晰的名称和一句话描述
   - 入选原因(推理过程)
   - 需要验证的关键假设

逐步思考。以清晰、结构化的格式呈现创意。

内容较多时,将其保存为 markdown 文档,存放到用户的工作区。
