# 收益型投资：可持续与机会型分红分析

分析 `$ARGUMENTS` 以回答：

> 这家公司能否产生足够可持续、足够有吸引力的可分配收益，从而配得上在投资组合中占有一席之地——无论是作为长期收益型底仓，还是作为机会型的高股息仓位？

永远不要把表面上的高股息率当作好机会的证据。本工作流仅用于学习与研究，不构成个性化投资建议。

## 输入

使用如下命令形式：

```text
/income-investment "<company or ticker>" [mode=new|existing] [role=core-income|opportunistic-income|unspecified] [quantity=...] [cost_basis=...] [portfolio_weight=...] [target_yield=...] [tax_residence=...] [portfolio_file=...] [horizon=...]
```

公司或代码为必填项，其余字段均为可选。接受等价的自然语言输入。不要编造缺失的取值：将其标记为 `Unknown` 或 `Not calculable`，并说明其后果。尤其注意：在缺少税收居民身份、账户类型、适用税收协定以及已确认的预扣税处理方式时，不要估算税后净收益。

## 相关工作流

优先使用或引用已有工作流，而不是重复造轮子：

| 需求 | 工作流 |
|---|---|
| 经验证的财务数据与跨来源对账 | `financial-data` |
| 完整的通用基本面研究 | `investment-research` |
| 买入前的最终决策 | `investment-checklist` |
| 组合匹配度、集中度与仓位规模 | `portfolio-review` |
| 决策后的持续跟踪 | `thesis-tracker` |
| 财报发布后的更新 | `earnings-review` |
| 对单一事件的快速分析 | `news-pulse` |

`income-investment` 负责收益型投资这一特定决策。它不得在未明示的情况下推翻当前 `portfolio-review` 的结论。

## 研究纪律

1. 研究前先运行 `date`。将数据截止日期写入报告头部。
2. 按以下顺序优先采用：年报与中期报告、业绩公告、投资者关系文件、监管申报文件、官方公告、交易所官方数据。二手来源仅用于填补空白，并须标注为二手来源。
3. 应用 `../finance-financial-data/SKILL.md`：对决策关键的财务数据，在可行时至少用两个独立来源验证，差异超过 1% 时做出标记。
4. 每一个时效性数字都要标注日期或所属期间。每一条重要陈述都要明确区分为 **已验证事实**、**估计**、**假设** 或 **分析判断**。
5. 涉及派息率、股息率、估值、市值、组合收益与情景测算的精确计算，使用 `python3 scripts/financial_rigor.py`。对影响决策的结果，绝不依赖心算。
6. 保存报告后，运行 `scripts/report_audit.py extract` 与 `verdict` 工作流。未通过审计的报告只是草稿，不算可发布的研究成果。

## 执行工作流

### 1. 解析请求并确立数据质量

- 明确证券、上市地、币种、分红币种、模式、期望角色以及可选的组合输入。
- 说明哪些毛收益、净收益、成本股息率、组合贡献以及交易后测算是可以计算的。
- 将证据质量评级为 `A`（一手材料完整）、`B`（一手材料部分完整）或 `C`（以二手/不完整材料为主）。基本面材料严重不足的，触发 `INSUFFICIENT DATA` 闸门。

### 2. 理解分红本身

在数据可得时至少覆盖五年：

- 分红频率；普通股息、特别股息或浮动分红的属性；支付币种；
- 每股年度股息与分红总额；
- 增派、持平、削减、暂停的次数；
- 股息复合增速（CAGR），注明确切的计算区间以及对特别股息的处理方式；
- 公告日、除息日、股权登记日、派息日等参考日期。

要解释清楚：等待除息日并不是白捡的收益——股价理论上会按分红金额相应下调。分红日历可以为执行时点提供参考，但绝不能成为买入一家劣质公司或拖延一次必要卖出的理由。

### 3. 追溯可用于分红的现金

分析净利润派息率、自由现金流派息率、必要投资之后的现金流、现金流稳定性与质量、利息保障倍数、净负债、债务到期结构、再融资需求、维持性与扩张性资本开支、相关表外承诺，以及与分红形成竞争的回购。

不要跨行业机械套用 EPS 派息率：

| 行业 | 必须使用的行业指标 |
|---|---|
| REIT / SIIC | FFO、AFFO、入住率、LTV |
| 银行 | CET1、可分配利润、监管约束 |
| 保险 | 偿付能力与资本生成能力 |
| BDC | NII、NAV、非应计贷款 |
| 资源类 | 周期中枢现金流与浮动分红政策 |
| 电信 / 公用事业 | 资本开支、负债与 FCF 覆盖 |

### 4. 检验质量与可持续性

评估商业模式、护城河、定价权、周期性、利率/汇率/大宗商品敏感度、收益可预测性、资本配置、管理层质量，以及在下行情景中维持分红的能力。区分会计利润与可重复的可分配现金。

### 5. 为收益流估值

分析当前股息率、历史平均股息率、合适的行业估值倍数、FCF 收益率、合理的内在价值区间、安全边际，以及股价下跌叠加股息削减的组合情景。成本股息率只是回顾性信息，永远不构成继续持有仓位的理由。

### 6. 计算可用收益

仅当输入条件支持时，计算年度毛股息、按支付频率拆分的毛股息、已知的来源地预扣税、估算的税后净收益、对组合收益的贡献，以及拟议交易后的年度收益。如果税务或账户信息不完整，只展示毛收益，并确切说明净收益为何无法计算。涉及协定税率与税务处理时，标注所属司法辖区、账户假设与生效日期。

### 7. 检查组合匹配度

如果提供了组合信息：

- 确定当前权重与拟议权重；
- 检查行业与地域集中度、重复暴露的风险，以及组合收益对单一行业的依赖；
- 区分本金层面的分散与股息层面的分散；
- 在可得时阅读最新的相关 `portfolio-review` 报告。

如果结论出现分歧，同时展示两个结论并解释原因，把公司质地与配置匹配度分开讨论。一只质地优良的收益型证券，仍可能因为组合集中度问题而得到 `HOLD – DO NOT ADD`、`REDUCE` 或 `WATCHLIST` 的结论。

数据允许时，展示按月份分布的预期毛收益。永远不要为了填补某个空白月份而推荐一家更差的公司；把按季度派息的标的组合起来，同样可以形成按月现金流，并不需要逐月派息的标的。

### 8. 构建三个情景

给出基准、不利、严重三种情景。每个情景都必须说明经营假设、可分配现金流、派息覆盖倍数、资产负债表/再融资影响、股息结果以及估值含义。不利与严重情景必须显式检验股息削减，而不是假设股息固定不变。

## 分类、闸门与结论

先对收益属性进行分类：

- **底仓 + 可持续收益**：优质生意，股息可持续且可能增长，持有周期可以很长。
- **机会型收益**：暂时性的高股息率或折价，须附带明确的买入、监控、持有期限与退出规则。
- **股息陷阱**：派息反复缺乏覆盖、杠杆/投资需求与分红不兼容、业务结构性下滑，或高股息率主要由股价下跌造成。
- **不适合收益型投资**：没有有意义的分红、股息率微不足道、证据不足，或股东回报主要以其他方式实现。

使用如下定性记分卡，不要计算数值平均分：

| 维度 | 评级（`Strong`、`Adequate`、`Weak`、`Critical`、`Unknown`） | 证据 |
|---|---|---|
| 生意质地 | | |
| 现金流可见度 | | |
| 股息覆盖 | | |
| 资产负债表强度 | | |
| 分红历史 | | |
| 股息增长潜力 | | |
| 估值 | | |
| 周期性 | | |
| 削减风险 | | |
| 组合匹配度 | | |

在给出结论前检查以下一票否决闸门：

- 派息反复缺乏覆盖；
- 严重的债务或再融资风险；
- 业务结构性恶化；
- 基本面数据不足；
- 重大的治理或诚信问题。

安全、债务、恶化或诚信闸门一旦触发，即压倒记分卡，通常要求给出 `REJECT / YIELD TRAP`（对已有持仓，当现有组合事实不足以支持立即清仓的结论时，则为 `REDUCE`）。数据不足闸门要求给出 `INSUFFICIENT DATA`。不要用记分卡得分去抵消一个被触发的闸门。

只返回一个结论：

- `CORE INCOME`
- `OPPORTUNISTIC INCOME`
- `WATCHLIST`
- `HOLD – DO NOT ADD`
- `REDUCE`
- `REJECT / YIELD TRAP`
- `INSUFFICIENT DATA`

针对结论给出：可能的组合角色、首要理由、首要风险、买入条件、可供研究的仓位区间（绝不存在普适的仓位）、加仓条件、减仓/退出标准、监控指标以及置信度。当组合、税务或风险承受能力信息不足时，不要给出确定的个性化推荐。

## 必需的报告格式

以下标题各使用且仅使用一次，避免重复同样的分析：

1. 执行摘要
2. 结论与分类
3. 可能的组合角色
4. 业务与分红现金来源
5. 分红历史与日历
6. 分红覆盖与安全性
7. 资产负债表与再融资
8. 收益增长
9. 估值与安全边际
10. 税务与币种
11. 组合匹配度
12. 情景：基准、不利、严重
13. 股息削减风险
14. 买入或加仓条件
15. 减仓或卖出条件
16. 监控表
17. 一句话结论
18. 来源与数据质量

将结果保存到 `reports/{company}-income-investment-{YYYYMMDD}.md`，公司标识需使用文件系统安全的写法。第 2 节中须包含记分卡与一票否决闸门的检查结果；第 11 节中在可计算时给出月度收益日历；第 18 节中须包含来源标题、发布方/出版方、发布日期、访问日期、报告期、URL，以及一手/二手来源标注。

## 发布审计

```bash
python3 scripts/report_audit.py extract --report reports/{company}-income-investment-{YYYYMMDD}.md
# 将每个提取出的条目与可靠来源逐一核对，然后：
python3 scripts/report_audit.py verdict --results '<verified JSON>' --report {company}-income-investment-{YYYYMMDD}.md
```

修复未通过的条目并重复审计。对无法弥合的缺口要清楚保留并相应下调置信度，而不是用假设去填平。
