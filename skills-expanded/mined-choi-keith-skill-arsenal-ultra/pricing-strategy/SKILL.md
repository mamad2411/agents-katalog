## 定价策略

设计一套立足于价值交付、竞争定位与支付意愿的定价策略。

### 背景

你正在为 **$ARGUMENTS** 制定定价策略。

如果用户提供了文件(竞争对手定价、调研数据、财务模型或使用数据),先阅读这些文件。如有需要,使用网络搜索调研竞争对手定价。

### 指令

1. **理解所交付的价值**:
   - 核心价值主张是什么?
   - 客户的替代方案是什么(其成本是多少)?
   - 产品交付了哪些可量化的成果?(节省的时间、增加的收入、降低的成本)
   - 基于这些价值,客户的支付意愿是多少?

2. **评估定价模式** —— 推荐最合适的一种:

   | 模式 | 最适合 | 示例 |
   |---|---|---|
   | **统一价(Flat-rate)** | 简单产品、成本可预测 | Basecamp(每月 99 美元统一价) |
   | **按席位(Per-seat)** | 协作工具、团队产品 | Slack、Figma |
   | **按用量计费** | 基础设施、API 产品 | AWS、Twilio |
   | **分层定价** | 用户细分明显的产品 | 多数 SaaS(免费版/专业版/企业版) |
   | **免费增值** | 有病毒传播/网络效应的产品 | Spotify、Notion |
   | **免费增值 + 按用量** | 平台型产品 | Vercel、OpenAI API |
   | **价值定价** | 高影响力的企业级工具 | Salesforce、Palantir |

3. **分析竞争性定价**:
   - 梳理竞争对手的定价层级及各档包含的内容
   - 确定你的产品所处位置(高端、中端、低端)
   - 寻找定价空白或机会
   - 记录行业内的定价惯例

4. **设计定价结构**:
   - **层级**:定义 2-4 个层级,差异化清晰
   - **功能门槛**:哪些功能放在哪一档?(基于价值指标,而非拍脑袋的限制)
   - **价值指标**:按什么单位收费?(用户数、事件数、存储量、API 调用量)
   - **锚定定价**:让最受欢迎的档位看起来是显而易见的选择
   - **年付折扣**:通常在月付价格基础上优惠 15-20%

5. **估算价格敏感度**:
   - Van Westendorp 价格敏感度测试(如有调研数据):
     - 太便宜 → 引发质量疑虑
     - 便宜 → 物有所值
     - 贵 → 开始犹豫
     - 太贵 → 不会购买
   - 或者,基于竞争对手定价与所交付价值进行估算

6. **规划定价实验**:
   - 对定价页做 A/B 测试(不同价格点、档位名称、功能组合)
   - 通过创始人主导的销售对话测试支付意愿
   - 用不同价格锚点做落地页测试
   - 按价格点对转化率做同期群分析

7. **输出定价建议**:
   ```
   推荐模式: [模式类型]
   价值指标: [按什么收费]

   | 层级 | 价格 | 目标细分 | 关键功能 | 定位 |
   |---|---|---|---|---|

   关键假设:
   - [假设] → [如何验证]

   风险:
   - [风险] → [缓解措施]
   ```

逐步思考。保存为 markdown。标记任何在发布前需要验证的假设。
