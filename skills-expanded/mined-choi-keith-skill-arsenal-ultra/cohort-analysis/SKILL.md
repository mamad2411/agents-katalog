# 同期群分析与留存探索

## 目的
按同期群分析用户参与度和留存模式,识别用户行为、功能采用和长期参与度方面的趋势。将定量洞察与定性研究建议相结合。

## 工作原理

### 第 1 步:读取并校验数据
- 接受包含用户同期群信息的 CSV、Excel 或 JSON 数据文件
- 校验数据结构:同期群标识、时间段、参与度指标
- 检查缺失值和数据质量问题
- 汇总关键统计信息(同期群规模、日期范围、可用指标)

### 第 2 步:生成定量分析
- 计算同期群留存率和参与度趋势
- 识别留存曲线、流失模式和异常情况
- 计算各同期群的功能采用率
- 计算环比或同期对比变化
- 如有需要,使用 pandas 和 numpy 生成 Python 分析脚本

### 第 3 步:创建可视化
- 生成留存热力图(同期群 × 时间段)
- 创建展示同期群演进的折线图
- 构建功能采用的对比图表
- 可视化流失节点和参与度趋势
- 输出为交互式图表或静态图片

### 第 4 步:识别洞察与模式
- 找出一个或多个显著模式:
  - 特定同期群的早期流失
  - 后期参与度变化
  - 功能采用聚类
  - 季节性或时间性趋势
- 突出意外发现和偏离情况
- 对比同期群表现以建立基准

### 第 5 步:建议后续研究
- 推荐定性研究方法:
  - 针对流失用户的定向用户访谈
  - 针对高活跃同期群的功能使用调查
  - 关键交互模式的会话回放
  - 高留存与低留存同期群的胜负分析
- 设计后续定量研究
- 建议 A/B 测试或功能实验

## 使用示例

**示例 1:上传 CSV 数据**
```
上传 cohort_engagement.csv,包含列:cohort_month, weeks_active,
user_id, feature_x_usage, engagement_score

请求:"分析留存模式,并找出 2025 年 Q4 同期群
表现不如 Q3 的原因"
```

**示例 2:描述数据格式**
```
"我有 2025 年 1-12 月的月度用户同期群数据。每行包含:
同期群日期、用户 ID、购买频次和客服工单数。
分析哪些同期群的长期留存最好。"
```

**示例 3:功能采用分析**
```
上传包含同期群采用数据的 feature_usage.xlsx。

请求:"对比我们新功能在各同期群中的采用曲线。
哪些同期群采用最快?有什么规律吗?"
```

## 核心能力

- **数据读取**:导入 CSV、Excel、JSON、SQL 查询结果
- **留存分析**:计算并可视化随时间变化的留存率
- **同期群对比**:对比不同同期群组的各项指标
- **异常检测**:标记异常模式或流失点
- **Python 脚本**:生成可复用的分析代码,便于持续分析
- **可视化**:创建热力图、图表和交互式仪表盘
- **研究设计**:建议有针对性的后续研究和访谈方案
- **统计摘要**:提供定量指标和相关性分析

## 获得最佳结果的建议

1. **包含时间维度**:提供跨多个时间段的数据
2. **明确定义同期群**:让同期群分组方式清晰明确(注册月份、功能上线日期等)
3. **提供背景信息**:说明该时期内的产品变更、发布或事件
4. **多个指标**:包含留存、参与度、功能使用、收入等
5. **足够的数据量**:至少 3-4 个同期群才能进行有意义的模式识别
6. **明确输出要求**:说明需要可视化、Python 脚本还是研究建议

## 输出格式

你将收到:
- **数据摘要**:同期群概览和数据质量评估
- **定量发现**:关键指标、留存率和趋势分析
- **可视化**:展示留存曲线和采用模式的图表
- **模式识别**:从数据中得出的 2-3 个重要洞察
- **研究建议**:具体的定性和定量后续研究建议
- **分析脚本**(如有要求):可复现分析的 Python 代码
- **后续步骤**:基于发现的优先级行动建议
