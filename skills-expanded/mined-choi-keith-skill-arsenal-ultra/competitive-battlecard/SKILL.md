## 竞争对战卡

创建一份简洁、可直接用于销售的、针对特定竞品的对战卡。

### 背景

你正在为 **$ARGUMENTS** 创建一份竞争对战卡。

使用网络搜索调研竞品的当前产品、定价、定位和近期变化。如果用户提供了文件(功能清单、赢单/输单数据、销售通话记录),请先阅读这些文件。

### 操作说明

1. **调研竞品**(使用网络搜索):
   - 当前产品功能与特性
   - 定价层级与模式
   - 目标市场与定位
   - 近期的产品发布或变更
   - 已知的优势与短板
   - 客户评价与口碑(G2、Capterra、Reddit)

2. **创建对战卡**,包含以下部分:

   ### 公司概况
   - 成立时间、总部、融资/营收(如已公开)
   - 目标市场与 ICP
   - 一句话定位

   ### 快速对比

   | 能力 | 我们 | 对方 | 胜出方 |
   |---|---|---|---|
   | [功能领域 1] | [我们的做法] | [对方的做法] | [我们/对方/平手] |
   | [功能领域 2] | ... | ... | ... |
   | 定价 | ... | ... | ... |
   | 支持服务 | ... | ... | ... |

   ### 我们的胜场
   - [优势 1]:[证据点或客户引述]
   - [优势 2]:[对方不具备的具体能力]
   - [优势 3]:[更好的做法及理由]

   ### 对方的胜场
   - [对方优势 1]:[我们的反定位]
   - [对方优势 2]:[我们如何弥补这一差距]

   ### 常见异议与应对

   | 客户说 | 这样回应 |
   |---|---|
   | "竞品 X 有 [某功能]" | "[我们的替代做法,以及为什么对他们更好]" |
   | "他们更便宜" | "[价值框架:总体拥有成本、ROI、隐性成本]" |
   | "他们更成熟" | "[我们的优势:速度、创新、专注、支持]" |

   ### 要埋下的"地雷"
   - 向客户提出能凸显竞品短板的问题:
   - "[我们擅长的领域] 对你们团队有多重要?"
   - "你们评估过 [对方不具备的具体能力] 吗?"

   ### 赢单/输单模式
   - 我们通常在以下情况赢单:[模式]
   - 我们通常在以下情况输单:[模式]
   - 竞争性成交中的关键差异点:[决定天平的因素]

3. **保持可扫读**:销售代表需要在通话中随时查阅。使用表格、加粗文字和简短的要点。

保存为 Markdown 文件。格式要便于打印或在 Notion/Confluence 中分享。
