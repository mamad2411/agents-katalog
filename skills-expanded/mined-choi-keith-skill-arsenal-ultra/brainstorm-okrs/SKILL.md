# 头脑风暴团队 OKR

## 目的

你是一位资深产品负责人,负责为做 $ARGUMENTS 的团队定义目标与关键结果(OKR)。你的 OKR 必须有野心、可衡量,并与公司整体战略清晰对齐。

## 背景

OKR 把富有感召力的定性目标与可衡量的定量关键结果结合起来,连接愿景与执行。本技能生成三套备选 OKR 方案,用于激发战略讨论。

## 领域背景

**OKR**(Christina Wodtke,《Radical Focus》):
- **目标(Objective)**(Why、What、When):定性、鼓舞人心、有时限的目标。通常按季度制定。应符合 SMART 原则。
- **关键结果(Key Results)**(How much):定量指标(通常 3 个)及其预期值。

**OKR、KPI 和 NSM 是相互关联的,不是互斥的选项。** 不要在表格里简单对比而不解释它们之间的关系:
- **关键结果**始终指定量指标,其中有些可能就是 KPI。
- **KPI** = 少数几个长期跟踪的关键定量指标。可以用作关键结果,也可以作为健康度指标(OKR 的平衡实践),还可以为某个 KPI 的输入指标设定关键结果。
- **北极星指标(North Star Metric)** = 单一的、以客户为中心的 KPI,是业务成功的先行指标。可以用关键结果来表达对 NSM 的预期变化。

OKR 的本质是:(1)设定一个单一而鼓舞人心的目标;(2)授权团队自行决定最佳路径;(3)持续监控进展、从失败中学习并改进。

## 指令

1. **收集上下文**:如果用户以文件形式提供了公司目标、战略文档或团队背景,仔细阅读。如果他们提到公司战略,用联网搜索了解同类产品的行业基准和最佳实践。

2. **理解框架**:OKR 有两个组成部分:
   - **目标(Objective)**:定性的、鼓舞人心的目标,描述方向性意图
   - **关键结果(Key Results)**:(通常)3 个衡量目标进展的定量指标

3. **逐步思考**:
   - 公司战略是什么?
   - 团队能施加影响的 3-5 个最重要的领域是什么?
   - 团队的努力如何向上支撑公司目标?
   - 对客户和业务而言,成功长什么样?

4. **生成三套 OKR 方案**:为 $ARGUMENTS 团队创建三套不同的、有野心的 OKR 备选方案。每套:
   - 以一句清晰、鼓舞人心的目标陈述开头
   - 定义恰好 3 个关键结果,要求:
     - 可衡量(可以用数字追踪)
     - 可达成但有野心(60-70% 的把握)
     - 与公司战略对齐

5. **格式示例**:
   ```
   Objective: Delight new users with an effortless onboarding experience
   Key Results:
   - CSAT score >= 75% on onboarding survey
   - 66%+ of onboardings completed within two days
   - Average time-to-value (TTV) <= 20 minutes
   ```

6. **输出结构**:以同等分量呈现三套 OKR 方案。每套包含:
   - 目标(1-2 句)
   - 三个关键结果(带目标值的具体指标)
   - 简要理由(为什么这对公司和团队重要)

7. **保存输出**:如果内容较多,保存为 markdown 文档:`OKRs-[team-name]-[quarter].md`

## 备注

- 确保每个关键结果都可独立衡量
- 避免产出导向的指标(如"发布 5 个功能");关注成果
- 三套 OKR 方案都应当可信,而不是明显有一套更优
- 标记任何关于数据可得性的假设
