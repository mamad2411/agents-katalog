# 增长回路

## 概述
识别并设计能够带来可持续增长的增长回路(飞轮)。本技能评估五种经过验证的增长回路机制,帮助你减少对付费获客的依赖,构建产品驱动的增长。

## 何时使用
- 为产品设计增长机制
- 构建可持续的病毒式或转介绍增长
- 减少对付费获客的依赖
- 分析竞品的增长策略
- 为产品驱动增长优化产品

## 5 种增长回路类型

### 1. 病毒式回路
用户在产品中创建的内容被分享到外部平台,从而把新用户带回产品。
- **机制**:用户在产品内创建内容 → 分享到社交/外部平台 → 新用户发现并注册
- **示例**:Figma 设计稿以链接形式分享、Loom 视频通过邮件分享
- **优势**:如果内容天然具有可分享性,用户获取将呈指数增长
- **挑战**:要求产出物高度可分享,且有强烈的分享动机

### 2. 使用型回路
用户在产品内创建内容或价值,然后分享出去,从而吸引新用户或驱动老用户回流。
- **机制**:用户创建 → 分享创作 → 他人消费 → 成为活跃用户
- **示例**:Twitter 长推文、Medium 文章、公开分享的 Notion 模板
- **优势**:增长与产品使用和网络效应直接挂钩
- **挑战**:要求内容创作的摩擦极低

### 3. 协作型回路
用户邀请同事在产品内共同创作或协作,从而在组织内扩大用户基础。
- **机制**:用户创建 → 邀请同事协作 → 同事发现产品价值
- **示例**:Google Docs 邀请、Figma 团队项目、Slack 频道
- **优势**:深入组织内部渗透,留存率高
- **挑战**:最适合协作型/团队型产品

### 4. 用户生成型回路
用户通过其他用户的创作发现新内容或新玩法,进而创作并分享自己的内容。
- **机制**:用户发现内容 → 创作类似内容 → 分享创作 → 更多人发现
- **示例**:TikTok、Pinterest、YouTube 的热门趋势带动创作者参与
- **优势**:形成内容飞轮与网络效应
- **挑战**:需要足够规模的优质内容来维持运转

### 5. 转介绍回路
用户为了获得奖励、激励或社交认可,邀请其他潜在用户。
- **机制**:用户推荐 → 被推荐用户加入 → 推荐人获得奖励 → 发起更多推荐
- **示例**:Dropbox 推荐奖励、Uber 乘客推荐、PayPal 注册奖励
- **优势**:直接激励获客;ROI 易于衡量
- **挑战**:激励要有价值,同时不能侵蚀单位经济效益

## 工作流程

### 第 1 步:定义产品价值
明确用户体验到的核心价值:
- 用户在产品中执行的主要操作
- 每次用户操作创造的价值
- 存在的网络效应(如有)
- 体验中的摩擦点

### 第 2 步:评估回路匹配度
评估哪些增长回路与你的产品契合:
- 产品类型(协作型、内容型、工具型等)
- 目标用户的行为与分享习惯
- 已存在的网络效应
- 现有用户基础与活跃度

### 第 3 步:设计回路机制
创建具体的回路实现方案:
- 触发分享或邀请的触点
- 参与激励(内在或外在)
- 分享机制的便捷程度
- 从邀请到激活的转化率
- 每个用户的回路重复频率

### 第 4 步:计算回路系数
估算增长速度:
- 每个周期每位用户的邀请/分享次数
- 邀请转化为新用户的比率
- 每个周期的净增新用户数
- 每个周期迭代所需时间

### 第 5 步:搭建回路
优先实施杠杆率最高的回路:
- 从对你产品最自然的回路开始
- 优化文案与摩擦
- 度量回路指标与转化率
- 让效果随时间复利累积

## 输入格式
使用 $ARGUMENTS 传入:
- 产品描述与主要用户操作
- 目标用户的人群特征与行为
- 现有的分享/协作功能
- 当前增长渠道与指标
- 约束条件或机会点

## 输出
一份增长回路分析,包括:
- 全部 5 种回路类型针对你产品的排序评估
- 推荐的主增长回路及实施方案
- 后续可叠加的次级回路
- 关键指标与度量框架
- 30-60-90 天实施路线图
- 潜在的回路系数与增长预测

## 框架
基于 Ognjen Bošković 的增长回路研究。聚焦通过产品内生的分享与协作机制,实现用户获取的复利式增长。

## 提示
- 从一个回路开始,做透之后再增加复杂度
- 病毒式回路复利最快,但建立需要时间
- 协作型回路带来最强的留存和 LTV
- 在优化阶段每周度量回路健康度
- 规模化运转后,组合多种回路以产生乘数效应
