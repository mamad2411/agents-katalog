# Theme Factory Skill

本 skill 提供一套精心策划的专业字体与配色主题合集,每套主题都包含精心挑选的色板和字体搭配。主题一经选定,即可应用到任何产物上。

## 用途

使用本 skill 为演示幻灯片应用一致、专业的样式。每套主题包含:
- 一套协调的配色方案,附十六进制色值
- 标题与正文相得益彰的字体搭配
- 适用于不同场景与受众的鲜明视觉风格

## 使用说明

要为幻灯片或其他产物应用样式:

1. **展示主题预览**:展示 `theme-showcase.pdf` 文件,让用户直观地看到所有可用主题。不要对它做任何修改,仅展示该文件供查看。
2. **询问用户的选择**:询问要将哪套主题应用到幻灯片上
3. **等待选定**:获得对所选主题的明确确认
4. **应用主题**:主题选定后,将所选主题的配色和字体应用到幻灯片/产物上

## 可用主题

以下 10 套主题可供选择,每套都在 `theme-showcase.pdf` 中有展示:

1. **Ocean Depths** - 专业而沉静的海洋主题
2. **Sunset Boulevard** - 温暖而充满活力的日落配色
3. **Forest Canopy** - 自然而沉稳的大地色调
4. **Modern Minimalist** - 简洁而现代的灰度配色
5. **Golden Hour** - 浓郁而温暖的秋季色板
6. **Arctic Frost** - 清爽而明快的冬季主题
7. **Desert Rose** - 柔和而精致的灰粉色调
8. **Tech Innovation** - 大胆而现代的科技美学
9. **Botanical Garden** - 清新而有机的花园配色
10. **Midnight Galaxy** - 富有戏剧性的深邃宇宙色调

## 主题详情

每套主题都在 `themes/` 目录中有完整定义,包括:
- 协调的配色方案,附十六进制色值
- 标题与正文相得益彰的字体搭配
- 适用于不同场景与受众的鲜明视觉风格

## 应用流程

选定偏好的主题后:
1. 从 `themes/` 目录读取对应的主题文件
2. 将指定的配色和字体一致地应用到整套幻灯片中
3. 确保恰当的对比度与可读性
4. 在所有幻灯片中保持该主题的视觉风格

## 创建你自己的主题
为应对现有主题都不适合某个产物的情况,可以创建自定义主题。根据提供的输入,生成一套与上述主题类似的新主题。为主题起一个类似的名字,描述其字体/配色组合所代表的意象。利用提供的任何基本描述来选择合适的配色/字体。生成主题后,先展示给用户审阅确认,然后按上述流程应用该主题。
