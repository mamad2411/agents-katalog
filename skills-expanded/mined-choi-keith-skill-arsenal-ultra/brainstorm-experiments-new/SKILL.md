## 设计精益创业实验(新产品)

创建 XYZ 假设,并设计 pretotype 实验,以最小投入验证新产品概念。

### 背景

你正在帮助验证一个新产品概念:**$ARGUMENTS**,采用精益创业方法论。

如果用户提供了文件(市场调研、落地页设计稿),先阅读它们。

### 操作指引

1. **创建一个 XYZ 假设**,形式为:"至少有 X% 的 Y 会做 Z"
   - **X%**:预期会参与的目标市场百分比
   - **Y**:具体的目标市场(例如"中型豪华轿车买家")
   - **Z**:他们将如何与产品互动

2. **建议 2-3 个 pretotype 实验**,以最小投入测试该假设。可考虑:
   - **落地页(Landing Page)**:通过注册量或点击量测试兴趣
   - **讲解视频(Explainer Video)**:通过互动指标测试理解度和吸引力
   - **邮件营销(Email Campaign)**:通过回复率和点击率测试需求
   - **预售 / 等候名单(Pre-Order / Waitlist)**:通过"真金白银"的承诺测试付费意愿
   - **礼宾式 / 人工 MVP(Concierge / Manual MVP)**:以人工方式交付服务,测试价值

3. **关键原则**(Alberto Savoia,*The Right It*):
   - **利益相关(Skin-in-the-Game)**:测试付费意愿 —— 而不只是兴趣。真实的承诺(时间、金钱、声誉)才是唯一可靠的信号。
   - **自己的数据(YODA,Your Own Data)**:通过实验收集自己的数据,而不是依赖他人的数据(ODP),如市场报告或类比。"别人想法的市场,并不关心你想法的市场。"
   - 衡量真实行为,而不是用户的观点

4. **对每个实验**,写明被测试的假设、方法、衡量指标和成功阈值。

逐步思考。内容较多时保存为 markdown。
