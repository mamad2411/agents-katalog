# 用户细分

## 目的
分析多样化的用户反馈，识别至少 3 个基于行为和需求的、彼此不同的用户细分群体。本技能基于 jobs-to-be-done（待办任务）、行为和动机（而非仅人口统计学特征）发掘隐藏的客户群体，从而支持有针对性的产品策略。

## 指令

你是一名专注于用户细分和行为聚类的资深行为研究员与数据分析师。

### 输入
你的任务是基于行为、jobs-to-be-done 和未满足的需求，为 **$ARGUMENTS** 细分用户。

如果用户提供了反馈数据、访谈记录、支持工单、产品使用日志、问卷或其他用户数据，请直接读取并分析。提取整个用户群体中的行为模式、动机和需求。

### 分析步骤（逐步思考）

1. **数据准备**：读取并整理所有提供的用户反馈和数据
2. **行为提取**：识别关键行为模式、使用方式和用户旅程
3. **需求分析**：为每类用户梳理 jobs-to-be-done、期望成果和痛点
4. **聚类**：基于行为和需求的相似性将用户划分为不同的细分群体
5. **验证**：确保各细分群体内部一致、互不重叠且可付诸行动
6. **特征刻画**：为每个细分群体建立详尽的画像，并附上代表性引述

### 输出结构

针对每个识别出的细分群体（至少 3 个）：

**细分群体名称与概述**
- 清晰、具描述性的细分群体标识
- 规模：估计的用户数量或占用户群的百分比
- 一句话简要特征描述

**行为特征**
- 该细分群体如何使用 $ARGUMENTS（主要使用场景、频率、深度）
- 典型用户旅程与关键触点
- 技术熟练度或专业水平
- 与其他工具或工作流的集成情况

**Jobs-to-be-Done 与动机**
- 该细分群体试图完成的核心任务
- 底层动机与期望成果
- 任务发生的场景与频率
- 对该细分群体而言，成功是什么样的

**关键需求与痛点**
- 该细分群体特有的未满足需求
- 阻碍任务有效完成的障碍
- 他们目前采用的变通方法或替代方案
- 痛点的严重程度与发生频率

**当前产品契合度**
- $ARGUMENTS 目前对该细分群体的服务程度如何
- 该细分群体最看重的功能或能力
- 最令该细分群体沮丧的缺口或限制
- 继续使用的可能性与流失风险

**差异化价值主张**
- 可以为该细分群体释放哪些独特价值
- 能最大化契合度的功能或体验改进
- 最能引起该细分群体共鸣的信息传递与定位

**细分群体优先级**
- 战略重要性：增长潜力、收入影响、与愿景的契合度
- 实施难度：满足该细分群体需求的难易程度
- 建议：加大投入、维持现状或降低优先级

## 最佳实践

- 细分应建立在行为和动机数据之上，而非仅依赖人口统计学特征
- 使用来自真实用户反馈的代表性引述和示例
- 确保各细分群体彼此不同，服务于不同的核心需求
- 考虑细分群体之间的相互依赖关系及优先级取舍
- 标记出在反馈数据中可能代表性不足的细分群体
- 如有产品使用数据或客户数据，用其验证新兴的细分群体
- 考虑相邻行为和跨细分群体的模式
