# 视频逆向拆解与复刻

## 这个 Skill 在做什么，以及为什么这样设计

用户甩来一个视频链接，目的不是"看懂这条视频讲了什么内容"（那是普通的视频总结），而是"看懂这条视频
是怎么被做出来的"，然后能照着做一条类似的。这两件事需要的分析深度完全不同：内容总结关心信息，这个
Skill 关心**制作层面**——镜头怎么分、怎么运镜、光线怎么打、什么调色风格、剪辑节奏多快、每一帧要用
什么样的 AI 生图提示词才能重新画出来。

所以整个流程不是"看一遍视频凭印象写感想"，而是先把视频拆成真实存在的关键帧（用场景检测算法抽出来，
而不是脑补），逐帧做视觉分析，再综合成三份产出物。这样产出的分镜脚本时间码是精确到秒/帧的，制图
提示词是能直接丢进 Midjourney / 即梦 / 可灵 这类工具用的，而不是"一个咖啡店的镜头"这种空泛描述。

## 触发场景

用户发来视频链接并表达出"看懂/学会这条视频制作方法"的意图，哪怕只是甩一个链接加一句"这个怎么拍
的"、或者干脆只有链接没多说什么。不要把这类请求当成"帮我总结一下这个视频在讲什么"来处理——除非用户
明确说自己只是想要内容摘要而不关心制作方法。

## 环境依赖

本 Skill 需要一个**能执行 bash 脚本、能调用 yt-dlp 与 ffmpeg、并且能查看图片文件**的运行环境，
同时网络要能访问目标视频平台。具体依赖：

- **yt-dlp**：下载视频、拉取平台字幕/元数据。
  - Linux / macOS：`pip install yt-dlp --break-system-packages`
  - Windows：`pip install yt-dlp`（不需要 `--break-system-packages`）
- **ffmpeg / ffprobe**：抽帧、抽音频、读元数据。
  - macOS：`brew install ffmpeg`
  - Linux：`apt install ffmpeg`
  - Windows：`winget install Gyan.FFmpeg` 或 `scoop install ffmpeg`
- **网络能访问目标视频平台**（YouTube/B站/抖音/小红书等）。如果当前环境的网络策略屏蔽了这些域名，
  下载会失败——处理方式见下面"素材获取失败时怎么办"。
- **读图能力**：视觉分析靠的是宿主自带的多模态读图能力，打开抽出来的关键帧逐张看，不需要额外的
  视觉模型。如果宿主不支持读图，这个 Skill 无法给出可信的镜头分析——不要凭文件名或时长瞎编画面。

## 整体工作流程

### 第一步：确认目标

默认走完下面六步，产出完整三份交付物。如果用户措辞明显只要其中一部分（比如"只要分镜脚本"），就只
产出那部分，但抽帧和逐帧分析这两步仍然要做——它们是所有产出的地基，不能跳过直接凭空写。

如果视频较长（超过 3 分钟），开工前跟用户确认一下：整支都拆，还是只拆某个片段（比如广告/短视频的
黄金开场几秒，分析价值往往远高于中后段）。视频越长逐帧分析工作量越大，没必要死磕全片。

### 第二步：抓取素材

用 `scripts/extract_shots.sh` 一次性搞定下载、抽帧、抽字幕、抽音频：

```bash
bash scripts/extract_shots.sh -u "<视频链接>" -o ./analysis
```

跑完会得到：
- `analysis/frames/shot_XXXX.jpg` —— 按场景切换抽出的关键帧，已包含开场第一帧
- `analysis/frames/timestamps.txt` —— 每张关键帧对应的精确时间戳（秒），按行号与文件序号一一对应，
  分镜脚本的时间码全部从这里取，不要自己估
- `analysis/audio/audio.mp3` —— 完整音轨，用来判断配乐风格、卡点、音效
- `analysis/subs/` —— 平台字幕（若有），是台词/文案最准的来源，比自己听音频转写靠谱
- `analysis/meta/` —— 分辨率、帧率、时长等元数据

**如果关键帧数量明显偏少**（整条视频只切出一两张图，但时长有大几十秒）：大概率是里面有慢速推拉摇移
镜头没有触发"场景切换"判定，不是真的只有一两个镜头。加上 `-i` 参数按固定间隔补抽（例如 `-i 2` 每
2 秒一帧），交叉参考着用。反过来如果切出的帧多到离谱（几百张），把 `-t` 调高（比如 0.4）降低灵敏度
再跑一次。

**如果素材获取失败**（下载失败、无字幕、平台有反爬或登录墙），按优先级降级处理：
1. 直接问用户能不能把视频文件发过来，或者截几张关键画面发过来；
2. 搜索一下这条视频有没有被写过深度拆解、影评、幕后花絮之类的文章作为辅助信息源（但视觉分析终究要
   靠真实画面，文字描述不能替代，不要拿别人的文字描述当成自己看过画面来写分析）；
3. 至少把标题、简介、评论区相关信息抓到，能多提取一点是一点，然后如实告诉用户素材不全、分析会打
   折扣，绝不能在没看到画面的情况下凭空编造镜头内容。

### 第三步：搭建镜头清单骨架

对着 `frames/` 目录和 `timestamps.txt`，先搭一个空的分镜表骨架（镜号 + 时间码 + 时长），景别/运镜/
描述这些列留空，下一步再填。这样能先对总镜头数、整体节奏有个数——这条视频总共切了几刀、平均每镜几
秒——分析每一帧时才有参照系，不是孤立地看每张图。

### 第四步：逐镜头视觉分析

把 `frames/` 里的关键帧逐张打开查看，每一帧都落实下面这些维度。术语从 `references/shot_glossary.md`
里挑，不要自己造词——这样全片描述用词统一，而且能直接喂给生图工具：

- **景别**：特写/近景/中景/全景/远景/大远景
- **拍摄角度**：平视/仰拍/俯拍/顶拍/斜角
- **运镜**：固定/摇/推拉/变焦/跟拍/手持/稳定器/空中/环绕/甩镜——这一帧是静态图，运镜要结合前后帧
  的位置变化、以及时长/音频节奏来推断，不是瞎猜
- **构图**：三分法/对称/引导线/框架式/前景遮挡/负空间/浅景深
- **光线**：自然光/硬光软光/顺光逆光侧光/色温冷暖/剪影
- **色彩与调色风格**：主色调、饱和度、对比度，偏电影感青橙调、复古胶片、高饱和电商风、日系清新、
  赛博朋克霓虹中的哪一种
- **画面主体与动作**：谁/什么在画面里，在做什么
- **文字/图形**：有没有字幕条、标题、贴纸、UI元素，字体风格、位置、动画方式
- **转场**：和下一镜怎么衔接——硬切/淡入淡出/叠化/匹配剪辑/遮挡转场/跳切

把这些内容填回第三步搭好的骨架。

### 第五步：节奏、结构与音频分析

看完所有关键帧后退一步看整体：

- **剪辑节奏**：平均镜头时长、每分钟切了多少刀——快节奏（1~2秒/镜）常见于电商/信息密度高的内容，
  慢节奏（3~5秒以上/镜）常见于氛围感/情绪类内容
- **叙事结构**：有没有"钩子(前3秒)→展开→高潮/转折→收尾(CTA或余韵)"这种结构，短视频/广告类内容
  里几乎是标配
- **音乐/音效**：听一遍 `audio/audio.mp3` 判断音乐风格、大致 BPM 快慢，有没有明显的"卡点"（剪辑
  点是否踩在音乐鼓点或旋律转折上）
- **台词/文案**：从 `subs/` 字幕或画面文字获取，整理出完整文案

### 第六步：生成三份交付物

产出前先看一眼 `references/output_templates.md` 里那个完整跑通的范例，照同等详细程度写，不要比它
更粗略。三份东西分别是：

**A. 分镜脚本**（表格，逐镜头）：

| 镜号 | 时间码 | 时长 | 景别 | 运镜 | 画面描述 | 台词/字幕/文案 | 音乐音效 | 转场 |
|---|---|---|---|---|---|---|---|---|

**B. 制图提示词**（每个关键镜头一组，中文说明 + 英文Prompt——主流生图/生视频工具对英文理解最准）：

```
镜头0X｜[一句话中文描述]
生图 Prompt（文生图）：[主体], [景别+角度], [构图], [光线], [色彩氛围], [风格参考], [画质关键词], --ar [比例]
运镜 Prompt（图生视频，以上图为首帧）：[主体动作], [镜头运动], [节奏], [建议时长]
```

**C. 复刻指南**（两条路径都给，不要只给一种）：
- 路径 A：AI 生成流程（B 里的提示词怎么串联——生图→生视频→剪辑的具体步骤）
- 路径 B：实拍流程（设备、场地、拍摄顺序、每个镜头的执行要点）
- 后期制作（剪辑软件、调色方向、字幕样式、音乐音效来源、导出参数）
- 平台适配（目标平台的画幅/时长/黄金开场秒数等要求）

格式拿不准的地方直接照 `references/output_templates.md` 里的结构来，不要另起一套。

## 特殊情况

- **原视频出现真人清晰面部、可识别品牌/商标、或有版权的原创音乐**：如实拆解不受影响，但在复刻指南
  里提醒用户——直接照搬这些元素做二次传播会有肖像权/商标/音乐版权风险。AI 路径建议生成虚构人物代替、
  实拍路径建议找自己的演员/场地拍摄、音乐建议换成曲风相似但可商用的曲库音乐。提一句就够，不用大段
  说教。
- **横屏还是竖屏**：照抓取到的原始比例分析和输出，制图提示词里的画幅比例参数要和原视频一致，不要
  默认套 9:16 或 16:9。
- **视频里有多段明显不同风格**（比如前半段产品实拍、后半段切成动画/图形）：分段说明，不要用一套
  风格描述硬套全片。
