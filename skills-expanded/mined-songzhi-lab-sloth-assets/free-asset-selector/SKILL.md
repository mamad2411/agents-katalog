# 懒鬼素材库（Free Asset Selector）

> 🦥 懒鬼系列 Sloth Series · 懒得找，懒得挑，懒得踩坑。

为设计任务找**合规、好看、下载得动**的平面素材。三条铁律：

1. **授权先行**：商用场景只用 T0（免费商用无需署名）或 T1（免费但需署名，标注清楚）。
2. **只指路，不搬运**：绝不下载、打包、转存素材文件再发给用户；输出的是搜索关键词 + 直达链接 + 授权备注。
3. **中国可访问性必须标注**：很多免费图库在国内访问不稳定，推荐时必须区分。

## 工作流程

1. **定位素材类型**：摄影图 / 插画 / 图标 / 样机 Mockup / 纹理背景 / 视频片段。
2. **定位使用场景**：印刷（产品册）需要高分辨率 ≥3000px 或矢量；屏幕用（小红书/网页）≥1500px 即可。
3. **查库选站**：在 `references/asset-database.md` 按类型 × 授权等级选 2-3 个站点。
4. **给搜索策略**：按 `references/search-playbook.md` 给出英文搜索关键词（免费图库搜英文词命中率远高于中文）+ 直达搜索链接。
5. **输出交付格式**：每个推荐 = 站点 + 直达搜索链接 + 授权说明 + 是否需要署名 + 国内访问情况。

## 懒鬼模式：素材筛选图（默认输出方式）

用户是来省事的，不是来点开 10 个链接做调研的。**默认必须输出"素材筛选图"**：
一张带缩略图的选品单（HTML 页面），每格包含：缩略图预览 + 编号 + 来源站点 + 授权标注 + 下载链接。

执行规则：
1. 用 AI 的搜图能力先搜 6-10 张候选图作为**方向预览**（搜图结果可能来自付费站，仅作预览参考，必须标注）
2. 每个预览图配 1-2 个 T0 站点的同款直达搜索链接（"去这里下免费可商用的同款"）
3. 用户回复编号即可，然后只针对选中的编号给精确下载指引
4. 绝不让用户"一个个点开链接自己找"——那是没装这个 skill 的 AI 才干的事

**平台适配（双模输出）**：
- 若平台支持对话内网页预览（如 Kimi）→ 直接生成可预览的 HTML 筛选图
- 若是终端/编辑器类 Agent（Claude Code、Codex、Cursor 等）→ 生成 HTML 文件保存到本地并告知路径（用户在浏览器打开），同时在对话里输出 markdown 表格版清单作为兜底
