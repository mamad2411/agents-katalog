# Full-Stack Development

Comprehensive skill for building complete web applications.

## Frontend
- **React/Next.js**: Component architecture, hooks, SSR/SSG, App Router
- **Vue/Nuxt**: Composition API, reactive state, file-based routing
- **Svelte/SvelteKit**: Runes, stores, server-side loading
- **Styling**: Tailwind CSS, CSS Modules, styled-components, design systems
- **State**: Zustand, Redux Toolkit, Pinia, Svelte stores
- **Testing**: Vitest, Jest, Playwright, Cypress

## Backend
- **Node.js**: Express, Fastify, tRPC, Hono
- **Python**: FastAPI, Django, Flask, Litestar
- **Go**: Gin, Echo, Fiber, Chi
- **Rust**: Axum, Actix, poem
- **Auth**: JWT, OAuth2, session-based, RBAC/ABAC
- **API Design**: REST, GraphQL, gRPC, WebSocket

## Database
- **SQL**: PostgreSQL, MySQL, SQLite, with migrations
- **NoSQL**: MongoDB, DynamoDB, Redis, Cassandra
- **ORM**: Prisma, Drizzle, SQLAlchemy, Diesel, GORM
- **Optimization**: Indexing strategies, query plans, connection pooling

## DevOps & Deployment
- **Containers**: Docker, Docker Compose, Podman
- **CI/CD**: GitHub Actions, GitLab CI, CircleCI
- **Cloud**: AWS, GCP, Azure, Vercel, Cloudflare Workers
- **IaC**: Terraform, Pulumi, CloudFormation
- **Monitoring**: Grafana, Prometheus, OpenTelemetry, Sentry

## Best Practices
1. Type-safe end-to-end (shared types, Zod schemas)
2. Error handling at every layer (client, API, database)
3. Caching strategy (CDN, edge, app-level, database)
4. Security: input validation, output encoding, CSRF/XSS prevention
5. Performance: code splitting, lazy loading, N+1 query elimination
