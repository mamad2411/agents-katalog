# 迷思预判（anticipated-misconceptions）

## 目的

帮语文教师在**学生犯错之前**就看到错误会在哪里发生：针对一篇课文或一个知识点，预判 3-5 个常见迷思，给诊断性问题让迷思在课堂讨论中浮出水面，再给补救教学策略。核心理念——预判优于纠错，把"讲完才发现学生理解错了"前移为"备课时就设好检测点"。

## 何时使用

> **路由指引**：如果你是想"预判学生会错在哪"（迷思驱动）→ 用本技能；如果是想"测一下学生学没学会"（考点驱动）→ 用 `formative-assessment`。本技能模式三虽也产出诊断题，但设计起点是"从迷思反推题目"，而非"从考点正向出题"。

- 备课时想"这篇课文学生会有什么问题""这个知识点学生容易怎么理解错"。
- 设计课堂讨论题，让学生在讨论中暴露思维模型而非靠判断题蒙混。
- 设计诊断性小测，用题目揭示"学生究竟理解了什么"。
- 针对已暴露的错误，规划补救教学策略。

## 与兄弟技能的分工（单一数据源）

| 迷思类别 | 权威数据源 | 本技能职责 |
|----------|-----------|-----------|
| 文言字词迷思（之/其/而误用、通假字误判、词类活用漏判、古今异义、特殊句式） | 回查 `gushiwen` | 只记迷思模式与诊断题，字词义项/判定回查不复制 |
| 古诗文鉴赏迷思（意象套用、主旨窄化、手法堆砌、赏析套路） | 回查 `gushi-appreciation` | 只记迷思模式与诊断题，意象/手法判定回查不复制 |

**单一数据源原则**：字词与鉴赏的权威释义/判定回查兄弟技能，本技能只持有"学生怎么错"的迷思模式与诊断题；已有的语料回查取用，保持单一副本。

## 迷思成因类型（诊断元模型）

迷思表面千差万别，成因可归为四类。归类成因能直接指向补救方向，是诊断与设计的元模型：

| 成因类型 | 含义 | 语文典型 | 补救指向 |
|----------|------|----------|----------|
| **过度概括** | 把高频义项/用法当唯一 | "之"一律当"的" | 训练"先判句法再选义" |
| **迁移干扰** | 用现代汉语习惯套古汉语 | 古今异义用现代义 | 建立"古今异义"专门记忆 |
| **套路化** | 把方法当公式，不求判定依据 | 手法堆砌、赏析套术语 | 训练"每结论必附判定依据" |
| **二元简化** | 把复杂对象压成二选一 | 情感=悲伤/喜悦二分 | 训练"分层表述主次情感" |

设计迷思预判与诊断题时，先归因类型，再据此设计补救策略；同一成因可串联多个迷思，贯穿线索常由此生成。

## 核心能力（三种模式，按需切换）

### 模式一：单篇 / 单知识点迷思预判（主场景）

**流程**：
1. 接收一篇课文或一个知识点（如"《岳阳楼记》""词类活用""议论文举例论证"）。
2. 调取 `references/迷思库.md` 对齐该类常见迷思方向；字词/鉴赏类回查兄弟技能确认权威释义。
3. 选取 3-5 个**与本篇/本知识点强相关**的迷思（选取原则：高频＞偶发、本篇特有＞通用、可诊断＞难检测）。
4. 每个迷思产出四要素：
   - **① 迷思是什么**：学生怎么错误理解的，举本篇/本知识点的具体例子（如"'何陋之有'学生译成'有什么简陋的'"）。
   - **② 为什么会产生**：点明成因类型——过度概括（高频义项当唯一）、迁移干扰（现代义套古义）、套路化（套术语不求判定）、二元简化（复杂对象压成二选一）。
   - **③ 3 个诊断性问题**：设计为**课堂讨论题**，让学生在讨论中说明理由、暴露思维模型；判断题会让学生靠猜测蒙混，讨论题才让思维可见。
   - **④ 补救教学策略**：给可执行的教学动作（如"先判句法成分再翻译""每个手法必附判定依据"），指向让学生重建正确思维模型。
5. 给一条**贯穿线索**（a thread across all）：一个能同时检测多个迷思的单一学习习惯（如"翻译前先判句法成分"能同时检测活用漏判与句式忽略）。

**输出骨架**（每迷思按此呈现，便于教师备课直接取用）：
```
迷思N：<名称>
- 是什么：<学生怎么错 + 本篇例子>
- 成因：<过度概括/迁移干扰/套路化/二元简化…>
- 诊断性问题：① … ② … ③ …（讨论题，学生需说明理由）
- 补救策略：<可执行教学动作>
贯穿线索：<一个能检测多个迷思的学习习惯>
```

**完成标准**：迷思数 ≥3 且 ≤5；每个迷思四要素齐全；诊断性问题为讨论题（学生需说明理由）；贯穿线索已给出且能覆盖至少两个迷思。

### 模式二：迷思分类速查

**流程**：
1. 教师指定类别（文言字词类 / 古诗文鉴赏类 / 作文类 / 阅读理解类）。
2. 查 `references/迷思库.md` 对应分类，列出该类全部迷思的名称与"学生怎么错"摘要。
3. 字词类与鉴赏类的权威释义/判定，回查 `gushiwen` / `gushi-appreciation` 后再给教师。

**完成标准**：已回查 `references/迷思库.md` 对应类别；列出的迷思与库记录一致；涉及字词/鉴赏判定处已回查兄弟技能、给出的说法与权威源一致。

### 模式三：诊断性测试设计

**流程**：
1. 接收一篇课文或一个知识点。
2. 设计 5-8 道诊断题，覆盖该篇/该知识点的核心迷思（每迷思至少 1 题）。
3. 每题标注**"它揭示的学生理解什么"**（揭示标签），如"本题揭示学生是否识别宾语前置""本题揭示学生能否区分举例与论证"。
4. 题目设计**让思维过程可见**：用"请说明理由""请写出判定依据""请指出你的思路"等开放设问；纯判断/纯选择需配追问，让学生无法靠猜测蒙混。
5. 给出**快速形成性判读**：标注"答错某题→指向哪个迷思→建议补救动作"，让教师即测即判，错题直接映射到补救策略。

**完成标准**：题目数 ≥5 且 ≤8；每题有揭示标签；题目设问让学生思维可见（开放追问或要求说明依据）；已给出"错题→迷思→补救"的判读映射。

## 迷思库内容方向

`references/迷思库.md` 是本技能的迷思数据层，覆盖四大类共 20 个常见迷思：

- **文言字词类（6个）**：之=的过度概括、其=他的过度概括、通假字=错别字、词类活用漏判、古今异义用现代义、特殊句式忽略。
- **古诗文鉴赏类（5个）**：意象=比喻套用、主旨=作者直接抒情、手法堆砌不求判定、赏析=翻译+赞美、情感=悲伤/喜悦二分。
- **作文类（5个）**：辞藻=文采、举例=论证、排比开头=好、升华结尾=深刻、字数=质量。
- **阅读理解类（4个）**：答案原文找、主旨找中心句、赏析套术语、开放题=随便写。

每条迷思含"学生怎么错 / 为什么错 / 诊断线索"，教师可直接取用。字词与鉴赏的权威释义/判定回查兄弟技能，本库只存迷思模式。

## 诚信与合规护栏

- **以教材教参为基线**：迷思判定与补救策略以统编教材与教参为准；遇争议标注"以教材为准"，给出可讨论方向。
- **诊断题不预设唯一答案**：诊断性问题旨在暴露思维，鼓励学生说明理由；教师判定时接受措辞多变、只要体现关键推理即可。
- **品牌声音**：对外呈现的讲解语气参考 [品牌声音与品牌规范](../../docs/品牌声音与品牌规范.md)——准确、干净、不浮夸，拒绝"秒杀""万能"等浮夸词。
- **迷思是倾向非定论**：标注迷思为"高频倾向"，避免教师将某迷思套到全体学生；结合学情调取。
