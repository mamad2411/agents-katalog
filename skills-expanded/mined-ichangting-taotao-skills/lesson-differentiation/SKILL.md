# 初中语文分层教学（lesson-differentiation）

## 目的

把一篇已有课文或教学设计按学生水平分三层，生成可上手的分层材料。三层共享同一核心任务与课标锚点，只在支架强度与拓展深度上区分——支架是隐形的设计，学生读到的材料看不出自己在"低层"。本技能从已有教学设计出发做分层，适配已有教案，把同一节课改出三档可用材料。

## 何时使用

- 教师说"我的学生水平差距大，一篇课文怎么分层教"。
- 教师要把已有教案改成分层任务（分层布置作业、分组教学）。
- 教师需要差异化材料应对课堂能力分层。
- 教师要做分层复习材料（同一考点，三档难度）。

## 先告诉教师你在做什么

路径确定后，用一两句话说明接下来的动作，例如：*"我先读你的教案定位核心任务与课标锚点，再按三种维度设计三档材料。"* 面向教师只说大白话——"分层依据""支架密度""JSON""渲染"等词留在后台，呈送时只交付可用的分层材料。

## 分层规则（R1-R8，语文适配）

| 规则 | 语文适配 |
|------|----------|
| R1 输出结构 | 1教师计划+3学生文档（Below/At/Above），从同一JSON渲染，shared块保持三页一致 |
| R2 课标范围保持 | 三层都对标同一课标条目（识字与写字/阅读与鉴赏/表达与交流/梳理与探究），保持年级要求 |
| R3 层级入口点 | Below: 降阅读障碍（加注音/释义/段意提示）；At: 标准文本；Above: 原文+拓展文本 |
| R4 支架密度上限 | Below层支架控制在任务数的60%以内，留出学生独立思考空间 |
| R5 必备教学基础设施 | 三层都配齐：核心问题、出口任务、小组讨论环节 |
| R6 隐形修改 | 学生文档使用 Group A/B/C 自然称谓，支架表现为自然任务设计 |
| R7 层内渐进褪色 | Task 1有支架→Task 2减弱→后续自主完成（fade pattern） |
| R8 范围与默认值 | 默认三层(Below/At/Above)；教师可指定两层；默认45分钟 |

规则详细说明与语文示例见 `references/分层设计指南.md`。

## 语文分层的三种维度

同一节课可按以下一种或多种维度分层。维度选择取决于课文类型与核心任务：散文/小说偏阅读难度，写作课偏写作支架，文言文偏翻译分层。

**阅读难度分层**（适用：现代文阅读、散文/小说教学）
- Below：加注音/关键词释义/段意提示，降低文本进入门槛。
- At：标准文本，常规阅读任务。
- Above：原文+拓展文本/对比阅读，加深理解与迁移。

**写作支架分层**（适用：写作课、读写结合课）
- Below：给句式框架/段首提示，帮学生起笔。
- At：给方向提示（写作角度建议），留构思空间。
- Above：开放命题，要求多角度或深度表达。

**文言翻译分层**（适用：文言文教学，回查 gushiwen 词库）
- Below：逐字标注+关键词提示，搭翻译阶梯。
- At：关键词标注，学生据此贯通全句。
- Above：自主翻译+互评，培养独立语感。

## 核心能力（两种模式）

### 模式一：完整分层（主场景）

**输入**：已有课文/教案 + 年级 + 分层需求。

**产出**：1教师分层计划 + 3学生分层材料。

教师计划含：
- 分层依据：据什么分（学情判断依据，如字词掌握度/阅读理解水平/写作能力）。
- 三层差异说明：每层在文本、支架、任务上的具体差异。
- 灵活分组建议：如何按需流动分组，可跨层调整。
- 每层rationale：为什么这样分、这样设计。

学生材料：Group A(Below)/Group B(At)/Group C(Above)，共享核心任务，支架与拓展不同。复用 k12-lesson-planning-zh 的 lesson.json 渲染管线：在 shared 块注册共享内容（核心任务、课标条目），在 documents[] 写三份学生页，用 from_shared 拉取保证三页一致。

**完成标准**：
- 三层都对标同一课标条目（回查 kechengbiao.md 逐字引用）。
- Below层支架密度≤60%（支架数÷任务数）。
- 学生文档通读使用自然称谓（Group A/B/C），保持自然语言。
- R7褪色模式已应用（Task 1有支架→Task 2减弱→后续自主完成）。
- 教师计划含分层依据与每层rationale。

### 模式二：快速分层建议

**输入**：已有课文/教案 + 分层需求。

**产出**：分层建议（这课怎么分三层、每层改什么、为什么），在对话内交付。

**流程**：
1. 分析已有教案的核心任务与课标锚点。
2. 按三种维度（阅读/写作/文言翻译）判断适用哪种分层。
3. 给出三层差异建议：每层改了什么、为什么这样改。
4. 标注依据的规则编号（R1-R8）。

**完成标准**：
- 三层差异清晰，每层改动具体到文本/句式/任务层面。
- 每层有具体改动建议，落到可执行的操作。
- 依据R1-R8规则说明分层理由。

## 隐形修改原则（红线）

- 学生文档使用 Group A/B/C，保持自然称谓。
- 支架融入任务指令本身，表现为自然任务设计（如"你可以用这些句式：……"）。
- 句式框架作为可选工具呈现，让学生主动选用。
- 学生文档通读保持自然语言。

**完成标准**：学生文档通读使用 Group A/B/C 等自然称谓，支架融入任务指令，保持自然语言风格。

## 完成与收尾

当教师确认对分层材料满意，本技能完成。收尾消息给出三层分组的使用建议（如何灵活流动、何时合并讨论），以及按学科定制的后续选项（如"要给某层加更多支架""要补一份出口小测"）。

教师提出修订时，在 lesson.json 的 shared 块做针对性改动后重渲染——改一处，三份学生页同步更新。只针对某一层的改动进该层的 sections，shared 块始终保持单一版本。
