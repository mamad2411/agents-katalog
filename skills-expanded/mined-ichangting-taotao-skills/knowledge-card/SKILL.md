# 教学知识卡片生成器（knowledge-card）

把任意教学内容，变成"拿起来就能用、打印出来就能发"的知识卡片。
四类卡片、四种格式、一种素雅教学风。一次输入，成批产出。

---

## 何时使用

- "帮我把《岳阳楼记》这几句做成默写卡"
- "出一套七年级上册字词卡，要能打印"
- "把《水浒传》主要人物做成人物卡"
- "这套说明文考点，给我做成考点卡"
- 教师贴来一段笔记 / 词条 / 篇目，说"做成卡片"

**不适用**：纯批改作文、出整卷、单一课标原文查询（这些直接答，不必调我）。

---

## 工作流（五步）

1. **判定卡片类型与风格**（见下表 + 视觉规范）。类型：用户已指定则直接用；未指定则自动推断；**推断不确定时，用一道选择题追问一次**，确认后再生成。风格与密度：默认 `elegant` + `balanced`；若用户明确要"水墨风/活泼/板书/密集"，写入 `meta.style` / `meta.density`。
   **完成标准**：卡片类型已确定且为四类之一（字词卡/名著人物卡/古诗文默写卡/通用考点卡）；用户已指定类型时直接采用未追问，未指定但可推断时已记录推断依据，推断不确定时已用一道选择题（给 2–3 个候选）追问确认并收到答复；`meta.style` 已设定（默认 `elegant` 或用户指定值）；`meta.density` 已设定（默认 `balanced` 或用户指定值）。
2. **萃取内容**：按对应模板（见 `references/`）填字段。深内容优先复用兄弟技能：
   - 字词考义 → 调 `gushiwen`（已有「字词卡片模板」）
   - 名著人物 → 查 `whole-book-reading` 的 12 部必读名著素材
   - 古诗文默写/易错字 → 查 `gushi-appreciation` 的默写易错字
   - 考点/题型/答题模板 → 查 `zhongkao-analysis` / `jiangxi-zhongkao-beikao`
   **完成标准**：已按对应模板（`references/` 下字词卡/名著人物卡/古诗文默写卡/通用考点卡模板）的字段清单逐项填充，无字段留空；字词考义已回查 `gushiwen`、名著人物已回查 `whole-book-reading`、古诗文默写及易错字已回查 `gushi-appreciation`、考点题型答题模板已回查 `zhongkao-analysis` / `jiangxi-zhongkao-beikao`；双面卡（默写卡）的正面与背面字段均已填充完整。
3. **生成 `cards.json`**：严格按下方 Schema 输出（这是唯一数据源，四种格式都从它渲染）。
   **完成标准**：`cards.json` 符合上方 Schema 规范；`meta` 含 `title`/`style`/`density`/`source_note` 四项且 `source_note` 不含真实校名/人名/专业名；`cards` 数组非空；每张卡的 `type` 为四类之一且 `title`/`fields` 字段齐全；双面卡的 `back` 字段结构正确（含 `title`/`subtitle`/`fields`）。
4. **渲染格式**：运行 `scripts/` 下脚本。用户未指定格式时，默认四种全出。
   - A4 打印版 + HTML 预览版：`python render_cards_html.py cards.json`
   - Word 卡片包：`python render_cards_docx.py cards.json`
   - 单卡长图 PNG：`python render_cards_png.py cards.json`
   **完成标准**：渲染依赖 `python-docx` 与 `Pillow` 已安装（缺失时已 `pip install python-docx Pillow`）；用户指定格式时仅渲染该格式，未指定时四种格式（A4 打印版 + HTML 预览版、Word 卡片包 `.docx`、单卡长图 PNG）全部生成；每张卡（含双面卡的正背面）在每种格式中均可正常打开/显示，无脚本报错。
5. **交付**：把产出的 `cards.html` / `cards.docx` / `cards.png` 交给教师，并说明每张卡片的类型与适用场景。
   **完成标准**：已将 `cards.html` / `cards.docx` / `cards.png`（按实际渲染的格式）交付给教师；已说明每张卡片的类型与适用场景；已提示渲染依赖（`python-docx` 与 `Pillow`）及安装方式；若 `meta.style`/`meta.density` 非默认值，已说明所采用的风格与密度设定。

> 渲染依赖：本技能脚本需要 `python-docx` 与 `Pillow`。若环境缺失，先
> `pip install python-docx Pillow` 再运行。

## 卡片类型判定

| 优先级 | 类型 | 判定信号 | 上游知识 |
|---|---|---|---|
| 1 | 字词卡 | 单字/词、文言文字词、要求释义/辨析/一词多义 | `gushiwen` |
| 2 | 名著人物卡 | 含"人物"+"作品/名著"，或要求做人物档案 | `whole-book-reading` |
| 3 | 古诗文默写卡 | 含"默写/背诵/诗句/文言文名句"，或要挖空练背 | `gushi-appreciation` |
| 4 | 通用考点卡 | 知识点/题型/考点/答题思路梳理 | `zhongkao-analysis` |

**判定不确定**（例如输入既像字词又像考点）时：**先追问一次**，给 2–3 个候选类型让教师点选，不要猜。

## `cards.json` Schema（唯一数据源）

```json
{
  "meta": {
    "title": "卡片集标题（如：七年级上册 · 字词卡）",
    "style": "elegant",
    "density": "balanced",
    "source_note": "内容来源说明（教材篇目/虚构示例，不得出现真实校名人名）"
  },
  "cards": [
    {
      "type": "字词卡",
      "title": "要",
      "subtitle": "《桃花源记》",
      "fields": [
        {"label": "读音 / 字形", "value": "yāo（通“邀”，邀请）"},
        {"label": "词性", "value": "动词"},
        {"label": "核心义项", "value": "1. 通“邀”，邀请\n2. 要求、相约"},
        {"label": "中考频度", "value": "★★★★☆"},
        {"label": "易错提醒", "value": "教材注 yāo，不写作“邀”"}
      ],
      "back": null
    },
    {
      "type": "古诗文默写卡",
      "title": "《岳阳楼记》",
      "subtitle": "范仲淹",
      "fields": [
        {"label": "情境提示", "value": "写洞庭湖浩渺无边、水势壮阔。"},
        {"label": "默写（挖空）", "value": "衔远山，吞长江，□□□□，横无际涯"}
      ],
      "back": {
        "title": "《岳阳楼记》· 答案",
        "subtitle": "范仲淹",
        "fields": [
          {"label": "完整句", "value": "衔远山，吞长江，浩浩汤汤，横无际涯"},
          {"label": "易错字", "value": "汤汤（shāng shāng，不写“荡荡”）"}
        ]
      }
    }
  ]
}
```

字段说明：
- `type`：四类之一，决定角标颜色与模板提示。
- `title` / `subtitle`：卡片主标题与副标题（如篇目、作者、出处）。
- `fields`：正面上的一系列"标签—内容"对；`value` 支持 `\n` 换行。
- `back`：可选。存在时表示双面卡（默写卡必用），渲染为翻面 / 背面页。

## 四类卡片字段规范（详见 `references/`）

- **字词卡**（`references/字词卡模板.md`）：字词｜读音/字形(通假)｜词性｜核心义项(按考频排序)｜本句语境判定｜中考频度★｜易错提醒｜例句
- **名著人物卡**（`references/名著人物卡模板.md`）：姓名｜出处(作品)｜身份/称号｜性格特征｜关键情节(2–3)｜人物关系｜中考常考角度｜经典评价
- **古诗文默写卡**（`references/古诗文默写卡模板.md`）：正面=篇目/作者+情境提示或上句挖空；背面=完整句+易错字标红+考频
- **通用考点卡**（`references/通用考点卡模板.md`）：考点主题｜知识梳理｜典型真题/例题｜答题模板｜易错警示｜变式训练

## 视觉规范（风格预设 + 密度）

借鉴 baoyu-skills 的 Style×Preset 思路，本技能用 `meta.style` 切换整体视觉、`meta.density` 控制信息密度。**默认 `elegant` 素雅墨青**（即原素雅教学风），其余为可选风格。

### 风格预设（meta.style）

| 预设 | 观感 | 底色 / 文字 | 适用 |
|---|---|---|---|
| `elegant`（默认） | 素雅墨青，留白多 | 宣纸米 `#F7F4EC` / 墨青 `#2F4858` | 打印、课堂通用 |
| `ink` 水墨国风 | 宣纸 + 墨色，衬线 | 米黄 `#F4EFE6` / 墨 `#2B2B2B` | 古诗文、国风课件 |
| `vibrant` 活泼彩绘 | 明快配色 | 暖白 `#FFFDF7` / 靛蓝 `#1F3A5F` | 屏幕分享、吸引学生 |
| `chalk` 板书风 | 黑板 + 粉笔 | 深板 `#2E3440` / 近白 `#F5F5F5` | 投屏板书感（打印自动转白底） |

> 类型角标仍按四类（字词/人物/默写/考点）取色，但整体取色随风格统一偏移。详见 `references/打印版式指南.md` 的"预设配色表"。

### 密度（meta.density）

| 档位 | 网格 | 字号 | 适用 |
|---|---|---|---|
| `minimal` | 3 列 | 偏大 | 字词卡 / 要点少 |
| `balanced`（默认） | 3 列 | 标准 | 多数场景 |
| `dense` | 2 列 | 略小 | 人物卡 / 考点卡（字段多） |

### 通用规则
- 卡片圆角 8px，阴影极淡；打印时去阴影、转灰阶、虚线裁切位。
- 字体：默认"微软雅黑 / 思源黑体"；`ink` 用衬线（思源宋体/宋体）。
- **绝不用按章节的花哨渐变**，保证黑白复印清晰。
- 打印版：A4 网格，卡间留 6mm 虚线裁切位；正背双面卡分"正面页 / 背面页"两批，便于双面打印。
