# 形成性测评（formative-assessment）

## 目的

为单篇课文或单个知识点生成**即测即判**的轻量理解检查题。核心理念：聚焦诊断而非打分——快速判断"学生哪里没懂、需要重教什么"。课尾 5 分钟、一个知识点讲完几分钟就能用上，区别于命题组卷的整卷模拟，专注单课单篇的即时形成性检查，设计借鉴 Claude for Teachers 的 formative assessment。

## 何时使用

> **路由指引**：如果你是想"测一下学生学没学会"（考点驱动）→ 用本技能；如果是想"预判学生会错在哪"（迷思驱动）→ 用 `anticipated-misconceptions`。本技能从课标考点正向出题，而非从迷思反推。

- 课尾出口小测："这课学完了，测一下""出口小测""exit ticket"
- 新课前摸底："明天讲《岳阳楼记》，先看看前置知识够不够"
- 单元中检查："讲到一半，看看这个知识点掌握没"
- 复习前诊断："复习之前，先摸清哪里不会"
- "理解检查""课堂小测""即测即判""形成性评价""check-in""快速检查掌握情况""几分钟小测"

## 核心能力（三种模式）

### 模式一：标准形成性检查（主场景）

输入一篇课文或一个知识点 + 年级，产出结构化检查题。格式锁死见 `references/检查题模板.md`。

1. **确认参数**：课文/知识点（如《岳阳楼记》全文、"词类活用"概念）+ 年级册次 + 课时进度（刚学完 / 次日复习 / 单元中段）。
2. **生成 Part A 核心概念（5-6 题，基础层）**：客观题为主，检查字词、释义、默写、基本理解；文言字词考点回查 `gushiwen`；每题标注 reveal tag。
3. **生成 Part B 拓展思维（3-4 题，推理层）**：主观题为主，检查推理、迁移、评价、鉴赏；对标 `jiangxi-zhongkao-beikao` 考法；开放题写"接受任何体现关键推理的答案"。
4. **生成答案 key + 教师判定指引**：每题给出答案 + reveal tag + "它揭示的学生理解什么"；开放题写可接受的替代表述方向。
5. **生成快速形成性判读**：Part A 大致正确 → 学生已就绪、进入 Part B；Part A 错过某题 → 重教该题对应概念；Part B 弱 → 重教核心推理路径。

**典型题型对照**：

| 层 | 题型偏好 | 检查的能力 | 课例（《岳阳楼记》） |
|---|---|---|---|
| Part A 基础层 | 选择 / 填空 / 默写 / 释义连线 | 字词、释义、背诵、基本理解 | "政通人和"中"政"的义项；默写"先天下之忧而忧" |
| Part B 推理层 | 简答 / 批注 / 比较 / 评价 | 推理、迁移、评价、鉴赏 | 比较迁客骚人与古仁人览物之情异同并说理 |

**完成标准**：
- Part A 5-6 题且 Part B 3-4 题。
- 每题有 reveal tag，答案 key 含教师判定指引。
- 快速判读 ≥ 3 条，每条映射到具体题目与教学行动。
- 文言字词题已回查 `gushiwen`；课标对标已回查 `jiangxi-zhongkao-beikao`。

### 模式二：出口小测（Exit Ticket）

3-5 题极简版，课尾 5 分钟用。

1. **选题**：从本课最核心的 3-5 个理解点各出 1 题。
2. **归类桶**：为每桶写判定标准——got it（能独立答对、表述准确）；almost（方向对但关键点缺失或表述含混）；not yet（答错、空白或答非所问）。
3. **映射行动**：got it → 进入下节课；almost → 课后点拨；not yet → 重教。

**完成标准**：
- 3-5 题，可在 5 分钟内完成。
- 归类桶 ≥ 3 个（got it / almost / not yet），每桶有可操作的判定标准。
- 每桶对应明确的教学行动。

### 模式三：诊断性前测

新课前用，检查前置知识是否就绪。

1. **拆解前置知识**：列出本课所依赖的前置知识（如讲《岳阳楼记》前需"骈散结合""贬谪文学背景"），来自课标与教材。
2. **出题**：每个前置知识出 1 题，共 3-6 题。
3. **标注补救路径**：每题标注"未掌握则需补什么"，补救路径具体可操作。

**完成标准**：
- 覆盖该课的全部关键前置知识。
- 每题标注"未掌握则需补什么"，补救路径指向具体内容与动作。
- 前置知识来自课标与教材，有据可查。

## 输出要素（锁死）

三种模式的产出均按 `references/检查题模板.md` 渲染，必备要素：

- **抬头**：课文/知识点 + 年级册次 + 课时进度 + 对标课标条目。
- **Part A / Part B（模式一）**：题号 + 题干 + 题型 + reveal tag（括注）。
- **答案 key + 教师判定指引**：每题答案 + "它揭示的学生理解什么" + 开放题可接受表述方向。
- **快速形成性判读**：题目结果 → 教学行动的映射，≥ 3 条。
- **归类桶（模式二）**：got it / almost / not yet + 每桶判定标准 + 每桶教学行动。
- **补救路径（模式三）**：每题"未掌握则需补什么"。

## 出题原则

1. **对标课标条目**：回查 `jiangxi-zhongkao-beikao` 的考法数据，题目对标具体考点。
2. **文言字词回查**：涉及文言字词的题回查 `gushiwen`，释义、通假、活用准确。
3. **两档难度区分**：Part A 检查"记住了吗"（字词 / 释义 / 背诵 / 基本理解），Part B 检查"理解了吗"（推理 / 迁移 / 评价）。
4. **reveal tag 是核心**：每题标注它揭示什么，教师扫一眼题目即知这题在测什么。
5. **快速判读可操作**：把题目结果直接映射到教学行动（重教什么、进入什么），给具体动作。
6. **题目原创**：基于课标与教材原创生成。
7. **年级梯度适配**：七年级重字词与基本理解，八年级加鉴赏与比较，九年级重迁移与评价；Part A/B 的认知深度随年级上调。
8. **课堂可落地**：单题作答 30 秒-2 分钟，全套 5-10 分钟内可完成、可判读，匹配课尾或课中插测的真实时长。
