# UGCLane Cursor Rules
# Safe UGC workflow generation

## Always
- Generate original hooks, scripts, and captions
- Add risk ratings to generated content
- Include originality warnings in competitor analysis
- Use deterministic templates (no external API required)

## Never
- Copy competitor content word-for-word
- Automate posting to social platforms
- Generate spam, fake engagement, or bot content
- Bypass rate limits, CAPTCHAs, or paywalls
- Scrape private content or impersonate users
- Suggest platform login automation

## Pattern extraction rules
- Extract hook type, structure, angle, CTA, emotion, format
- Mark content as "inspired pattern" with metadata
- Flag content as high-risk if it sounds spammy or misleading
- Do not extract exact phrasing from competitor examples
