# Team Landing Lab

6-phase team that turns a product brief into a complete landing presence: researched value prop, high-converting landing page copy, pain-oriented articles, onboarding copy, and a conversion review. Requires a product brief, URL, or docs to begin. Never assumes audience, pain, or product capabilities — everything sourced.

## When to Use

- User wants to build or rewrite a landing page for a website, SaaS, marketplace listing, or service
- User needs a value proposition built from scratch or stress-tested
- User wants pain-oriented articles or onboarding copy
- User has research or transcripts to hand the team (works from provided data too)
- Use AFTER `team-business` or `team-marketing` if deeper market research is needed first

## What You Need Before Starting

- Product brief, website URL, docs, or any available product materials
- Optionally: user research, customer reviews, competitor analysis (feeds pain-mapper)
- Optionally: existing copy to audit (conversion-reviewer can work in reverse)

## What This Team Produces

1. **Product Discovery Brief** — product core, philosophy, features, market, credibility (user-confirmed)
2. **Pain Mapping Report** — Four U's table, Before/After, Gain/Pain ratio, verbatim buyer phrases
3. **Value Proposition Document** — VP statement, 3D breakthrough test, MVS, dependencies, brand pitch
4. **Landing Page Copy** — hero, doubt-clearing sections, pricing (3-plan anchor), assessment hook, final CTA
5. **Content Package** — 3 pain-oriented articles + onboarding copy + optional founder note
6. **Conversion Review Report** — pass/fail checklist, top 3 improvement flags, readiness score

## Agent Sequence

1. `product-researcher` — Phase 0: product discovery from all available materials
   - **USER CONFIRMATION GATE** — lead presents brief, waits for explicit approval
2. `pain-mapper` — Phase 1: Four U's analysis, segments, Before/After, Gain/Pain ratio
3. `value-prop-architect` — Phase 2: Define-Evaluate-Build, 3D breakthrough, MVS, brand pitch
4. `landing-copywriter` — Phase 3: full landing page copy (hero + doubt-clearing + CTA + assessment hook)
5. `content-builder` — Phase 4: 3 articles + onboarding copy (runs after Phase 3)
6. `conversion-reviewer` — Phase 5: stress-test all output, readiness score

Max 3 agents active at once. Phases 3 and 4 may run in parallel if context allows.

## Key Rules

- Phase 0 output requires explicit user confirmation before Phase 1 begins — no exceptions
- All pain points must be sourced from real buyer language — never invented
- All product claims must be verified against user-provided materials — never assumed
- Value Proposition Document is the source of truth for all copy — landing-copywriter and content-builder do not make positioning decisions
- conversion-reviewer does not rewrite — only flags; rewrite goes back to landing-copywriter
- If Gain/Pain ratio is below 10:1, flag to user before writing copy — copy cannot substitute for weak value
- If no 3D breakthrough passes, flag to user — copy cannot substitute for undifferentiated positioning

## How to Invoke

Tell lead-landing-lab what you are building and provide any available product materials. If you have research transcripts or data, pass it directly — the team will extract pain phrases, frameworks, and positioning signals from it.

Pass `REVERSE` if you have existing copy to audit — conversion-reviewer runs first and flags what needs to be rebuilt.
