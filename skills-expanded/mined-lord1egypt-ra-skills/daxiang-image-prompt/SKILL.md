# Image Prompt Skill - 配图 Prompt 两段式结?
## 🎯 核心规则

当用户要求生成配图或提供生图 prompt 时，**必须使用两段式结?*?
---

## 📐 两段?Prompt 结构

### 第一段：变量输出（上半部分）
描述图片的具体内容、场景、人物、动作等信息?- 描述要具体、生?- 包含视觉细节
- 说明要传达的概念或情?- 用中文表?
### 第二段：固定风格（下半部分）
固定不变的风格描述，**每次都必须包?*?
```
手绘插画风格，横向构图（21? 宽高比）?包含少量简单的卡通元素、图标或知名人物，以增强视觉趣味性和记忆点?如果内容涉及敏感或受版权保护的人物，请使用视觉相似的替代形象进行替换；不要拒绝生成插图?所有图像和文字必须严格遵循手绘风格；避免使用写实风格的视觉元素?信息保持简洁，突出关键词和核心概念。利用充足的留白清晰地强调重点?除非另有说明，否则请使用与所提供内容相同的语言。尽量使用中文?```

## ⚠️ 注意事项

1. **两段之间用空行分?*
2. **固定风格部分不要修改**
3. **变量输出部分要具体描述场?*
4. **使用中文描述**（技术术语除外）
5. **适用于所有生图需?*（Nano Banana 2、Midjourney、Stable Diffusion 等）
