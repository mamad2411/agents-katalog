# SeaLeap 新品商品推广广告架构

将投放方式选择转为流量结构设计。先明确每个入口承担的任务，再决定先后顺序和需要独立控制的预算。

## 输入

站点、广告 profile、ASIN/子体、产品事实与 Listing、可售库存、贡献利润、生命周期证据、消费者搜索集中度、关键词/竞品研究，以及按定向和广告位拆分的报告。

## 工作流

1. 判断商品阶段、消费者比较方式和已有知识。标准化程度、词的集中程度、决策周期分别记录，不用类目名称一次性替代全部判断。
2. 证据少时，用受控自动探索及账户当前可用的相关关键词组学习；已验证关键词和竞品充足时，可并行测试相应手动入口；页面含义不清时先修复事实表达及定向假设。
3. 为自动、关键词、关键词组和商品投放分别写出目标、商品范围、匹配方式、否定候选、竞价依据和验证指标。关键词组是产品功能概念，不能与广告组或词组匹配混淆。
4. 将需要独立预算的流量放到支持独立预算的 campaign 层级。普通 ad group 不具有独立日预算，不能用“一词一组”承诺隔离预算。
5. 从搜索词与实际广告位报告诊断曝光、点击、转化和费用问题。迁移到精准后重新检查流量规模、出价、预算与归因成熟度；发现 ASIN 字符串不能单独证明只在详情页展示。
6. 每次只调整一个主要控制项，保留可售性、页面、价格、竞争和季节干扰。明确继续学习、保留、扩量或停止的证据。

## 交付

ASIN 与流量诊断、campaign/ad group/target 结构表、预算及竞价依据、否定草案、迁移实验卡和常见异常排查路径。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
