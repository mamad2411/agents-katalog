# 资料整理

资料：{资料}

## 步骤
1. 先记出处，再读内容；拿不到原文时注明「只看到摘要 / 转述」。
2. 每份资料写一张卡片（模板见下）。
3. 摘录原文要短（一两句），加引号并写页码或段落位置；其余用自己的话概括。
4. 评估可信度：来源类型、作者 / 机构、日期、有没有数据和方法、利益相关。
5. 多份资料整理完后，写一段「综合」：共识、分歧、空白。
6. 卡片可以存成工作文件夹里的 notes 文件（写入遵守本次实际权限和审批结果）。

## 卡片模板

```
### [编号] 标题
- 出处：作者 / 机构，发布日期，链接或出版信息，查看日期
- 类型：论文 / 官方文档 / 新闻 / 博客 / 数据集 / 报告
- 一句话要点：…
- 关键内容：
  - …
- 原文摘录：「…」（第 N 页 / 第 N 段）
- 数据与方法：样本、时间、方法（如有）
- 可信度：高 / 中 / 低 —— 理由
- 和我的问题的关系：支持 / 反对 / 补充 …
```

## 综合模板
```
- 共识：… [1][3]
- 分歧：… [2] vs [4]，可能原因：…
- 还没有答案的问题：…
```

## 批量 PDF 的上限与进度
先通过授权的文件列表确定本批 PDF 清单和总数；每个计划步骤最多读取 20 篇，超过 20 篇由统筹用 group_plan 拆成多个批次，最后单独综合，不能在一个步骤里继续下一批。每读一篇记录卡片和引用，报告“已读 / 本步总数”，程序账本只计实际读取成功的文件，重复读取不加数。失败和扫描件列为未读，不把调用次数当完成篇数。
单篇继续使用现有长文档上限；响应有 truncated / 页数上限时，卡片显式写“仅阅读部分内容”、实际页数 / 字符覆盖与遗漏范围。不要声称已读全文，也不要换工具绕过上限；综合时保留这些局限。
