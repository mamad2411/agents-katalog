# 图表规范

要表达：{要表达的内容}

## 1. 按关系选图形
| 想表达 | 用 | 避免 |
|---|---|---|
| 随时间的变化 | 折线图 | 用很多根柱子表示连续时间 |
| 类别之间比大小 | 条形图（类别名长时用横向），按大小排序 | 3D 柱状图 |
| 占比（≤ 5 类） | 堆叠条形图或饼图 | 超过 5 类的饼图 |
| 分布 | 直方图、箱线图 | 只给平均值 |
| 两个变量的关系 | 散点图 | 双纵轴折线图（容易误读） |
| 一个关键数字 | 大号数字 + 对比（环比 / 同比） | 只有一个值的图 |

## 2. 必须有
- 标题写结论（「三月转化率回升到 4.2%」），不只写「转化率趋势」。
- 坐标轴名称和单位；时间轴写清粒度（日 / 周 / 月）。
- 数据来源和时间范围（图下方小字）。
- 柱状图的纵轴从 0 开始。

## 3. 颜色
- 只用颜色突出重点：重点系列用强调色，其余用灰色。
- 同一份报告里，同一个类别始终用同一种颜色。
- 不只靠颜色区分（色弱读者），配合标签或线型；深浅背景下都要看得清。

## 4. 少即是多
- 去掉不必要的网格线、边框、阴影、图例（能直接标在线条旁就不用图例）。
- 一张图只讲一件事；系列超过 5–6 个就拆图或只保留重点。

## 5. 自查后交付
说明每张图要表达的结论、数据来源和生成方式（工具产物或脚本位置）。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。

## Excel 格式、模板与原样修改
1. 先用 office_inspect / office_read 读取表、区域、定义名、公式和现有图表。数值与显示格式分开：百分比、千分位、货币和日期用数字格式，不先转成字符串；同一列小数位一致，百分比默认保留一位小数。
2. 冻结表头，表头写单位，按单位设置列宽、对齐与条件格式；用数据验证限制输入，原始数据与计算区分表，每张表一个工作表、不合并单元格。图表引用实际区域，优先原生可编辑图表，标题、坐标轴、单位、图例与来源完整；图表底数另存 CSV 或工作表，表下注明数据来源、更新时间和筛选条件。
3. 模板：有 office_template_fields / office_template_fill 时先用它们填字段；没有时用 office_inspect 找占位符、公式位置与表区域，再用 office_edit 替换。插行后核对相对公式、表区域、定义名和样式；求值不了的公式标明打开后由 Excel 计算，不删除公式安全限制。
4. 修改现有 XLSX 前建立检查点并绑定最新 revision，只改指定区域和图表，保留无关表、公式、透视表与验证；工具不支持时说明，不用全量重建冒充原样修改。
5. 用 office_validate 校验，核对公式缓存和重算差异；复杂图表与透视表交 Excel 实际打开验收，未验证不得说通过。群里需要 PPT 时把已核对底数和口径交给演示设计师。
