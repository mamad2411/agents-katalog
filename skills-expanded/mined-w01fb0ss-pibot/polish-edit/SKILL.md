# 改写与润色

原文：{原文}
目标：{目标}

## 步骤
1. 通读原文，先用一句话写出它的核心意思；改完后核对这句话没有变。
2. 按目标选改法：
   - **更简洁**：删重复、删空话（「进行了一个……的操作」→ 直接用动词）、长句拆短。
   - **更正式**：去掉口头语和网络用语，用完整句子。
   - **更口语**：短句、用「你」、像当面说话。
   - **缩写到 N 字**：先保留结论和关键事实，再删例子和修饰。
   - **换受众**：换掉对方不懂的术语，补上对方需要的背景。
3. 不改：数字、日期、名字、引用、专业术语的含义、用户明确要保留的句子。
4. 原文有事实错误或前后矛盾时，不擅自改，在说明里指出。

## 交付格式
```
## 修改后
……

## 改了什么
- 结构：…
- 删减：…
- 用词：「原」→「新」（原因）
## 需要你确认
- …
```
篇幅短时可以附一份逐句对照。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
