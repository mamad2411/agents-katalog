# shared

Shared JS package: API client, tile math, color function, URL-state codec.
Consumed by `web/` and `mobile/`. Plain JavaScript (per ADR 0004).

## Commands

| Task | Command |
|---|---|
| Install deps | `pnpm install` (from repo root) |
| Run tests | `pnpm test` |

## TDD

New code starts with a failing test. Use `/tdd` for any new feature area.
