# Reconnaissance & OSINT Automation Skill

This comprehensive security assessment tool enables Claude to conduct authorized reconnaissance and intelligence gathering across multiple domains.

## Key Capabilities

The skill encompasses six primary functions:

1. **Passive Intelligence** — WHOIS queries, certificate transparency searches, DNS record analysis, search engine dorking, and code repository scanning without direct target contact

2. **Subdomain Discovery** — Certificate logs, DNS brute-forcing, wildcard detection, resolution validation, and HTTP probing to map organizational infrastructure

3. **Port Scanning** — Active service detection using Nmap with version identification, OS fingerprinting, and banner grabbing across defined scopes

4. **DNS Analysis** — Full record enumeration (A, AAAA, MX, NS, TXT, SOA, SRV), zone transfer attempts, email security posture assessment (SPF/DKIM/DMARC), and historical record tracking

5. **Technology Fingerprinting** — Server identification through HTTP headers, framework detection, CMS path testing, WAF/CDN recognition, and JavaScript library analysis

6. **OSINT Correlation** — Cross-referencing findings across IP ranges, employee data, credential exposure tracking, and third-party service identification

## Critical Authorization Requirement

The documentation emphasizes: "Always confirm written authorization for the target scope before proceeding. Unauthorized reconnaissance is illegal in most jurisdictions."

## Deliverables

Engagements produce structured reports documenting discovered assets, key findings, attack surface mapping, and recommended next-step integrations with other security assessment skills.
