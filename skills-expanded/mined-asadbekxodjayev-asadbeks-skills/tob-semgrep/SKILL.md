# Semgrep Rule Creator

The Semgrep Rule Creator is a skill designed to facilitate the development of custom Semgrep rules for detecting code patterns and security issues.

## Core Capabilities

This tool helps developers through test-driven rule development, where tests are written before patterns are finalized. It provides AST analysis assistance and supports both taint mode (for data flow tracking) and pattern matching methodologies.

## Key Features

The skill includes:
- Guidance for crafting precise pattern detection rules
- Support for both data flow analysis and general pattern matching
- Reference materials from Semgrep's official documentation
- Pre-built vulnerability patterns organized by programming language

## Getting Started

To use this skill, you'll need Semgrep installed on your system. Installation can be done via pip (`pip install semgrep`) or Homebrew (`brew install semgrep`).

## Related Tools

Two complementary skills are available: one for adapting existing rules to different programming languages, and another general static analysis toolkit that incorporates Semgrep alongside CodeQL and SARIF parsing capabilities.
