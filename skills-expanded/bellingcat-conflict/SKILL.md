# Bellingcat Conflict Investigation Tools

Tools for tracking conflict events, weapons identification, and political violence research.

## Choosing Tools

- Use event databases for incident patterns, mapping services for current context, and specialist references for weapon or munition identification.
- Treat conflict reporting as time-sensitive and corroborate claims with independent sources.

## Investigation Tips

- Use ACLED for comprehensive data on political violence and protest events worldwide
- LiveUAMap provides real-time conflict mapping for Ukraine, Syria, and other active zones
- OSMP (Open Source Munitions Portal) helps identify munitions from verified images
- Cross-reference munitions with CAT UXO for EOD technical specifications
- Bulletpicker provides ammunition guidebooks for identifying small arms ammunition
