# /tf — Task Finish

## Overview

Claude との会話中に「このタスク終わった」という状態を、コンテキストから読み取って task.md に反映するスキル。

**なぜ精度より速度か**
手動修正コスト（チェックを外す）が極めて低いため、確認ダイアログを挟む方がコストが高い。
間違えても 1秒で直せる。止まらずに会話を続けられることの方が価値が高い。

**このスキルが解決したいこと**
WSL 上で Claude Code を使いながら作業するとき、「今の会話で何が片付いたか」を
都度手で task.md に記録するのは面倒。スキル一発でその手間をゼロにする。

## 処理

1. `/mnt/c/Users/kmatuyama/Desktop/task.md` を Read ツールで読む
2. 現在の会話コンテキストを振り返り「何が完了・進捗したか」を判断する
3. 該当するチェックボックスを `[ ]` → `[x]` に更新する
4. 更新内容を 1〜3行で報告する

## 注意
- 確認なしで即更新する
- 間違ってもよい（後で手動修正可能）
- 完了していないタスクのチェックは入れない
