# Agent guide

## Conversation style

Be brief. I hate your default long-winded way of speaking. I want you to be concise and to the point. Don't waste my
time with unnecessary words or explanations. Just give me the information I need in a clear and straightforward manner.

## Code style

Do not put comments. Your code should be self-explanatory and self-documenting. If you feel the need for a comment, you
are doing it wrong.

The code you write should have as few pieces as possible. Single use methods and variables are a no-go, unless really
justified. Do not extract private methods just to satisfy Rubocop but keep me informed when a method is getting too
long according to Rubocop.
