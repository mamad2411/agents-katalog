# 🌐 Diretrizes Globais do Projeto

## 📝 Idioma e Padrão de Código
* **Código:** Siga o padrão Clean Code. Escreva nomes de variáveis, funções, classes e arquivos estritamente em inglês.
* **Commits:** Utilize o padrão de Conventional Commits (ex: `feat(ui): add primary button with brand colors`).

## 💬 Estilo de Comunicação do Agent
* Seja direto, conciso e evite introduções longas.
* Foque em responder com blocos de código limpos e funcionais.
