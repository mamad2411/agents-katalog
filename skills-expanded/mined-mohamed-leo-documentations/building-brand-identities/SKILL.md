# Building Brand Identities

## Purpose

Build a coherent brand system, not isolated creative assets. Strategy must explain the verbal and visual identity; every major choice must trace back to the audience, positioning, personality, or business goal.

## Operating Modes

Classify the task first:
- **New brand:** build foundations from zero.
- **Rebrand/refresh:** audit existing equity before changing anything.
- **Product/sub-brand:** define relationship to the parent brand before identity work.

If the user already fixed a decision (for example the name), preserve it unless they explicitly reopen it or evidence reveals a serious conflict.

## Required Workflow

1. **Frame the brief.** Read `references/discovery-and-research.md`. Capture facts, constraints, assumptions, open questions, target markets/languages, and success criteria. Ask only questions that materially change the outcome. If the user requests a fast first pass, proceed with clearly labeled assumptions.
2. **Research the category.** When current market information matters, research audiences, competitors, category conventions, naming collisions, and visual clichés. Separate evidence from inference.
3. **Lock strategy before aesthetics.** Use `references/strategy-and-positioning.md` to define purpose, audience, competitive frame, positioning, value proposition, promise, reasons to believe, personality, and architecture.
4. **Create the name only when in scope.** Use `references/naming-and-clearance.md`. Develop naming territories before candidates; score finalists; perform preliminary web/domain/social/trademark checks. Never claim legal clearance.
5. **Build verbal identity.** Use `references/verbal-identity-and-messaging.md`. Create a usable messaging system, not just a tagline.
6. **Build visual identity.** Use `references/visual-identity-and-logo.md`. Explore distinct creative territories first, then develop logo, color, type, imagery, iconography, graphic devices, layout, and motion rules.
7. **Handle bilingual brands deliberately.** If Arabic/English or another multilingual system is involved, apply `references/bilingual-arabic-english.md` in addition to the normal workflow.
8. **Turn choices into rules.** Use `references/guidelines-and-activation.md` and the templates to create a source of truth that another designer, marketer, developer, or AI can actually apply.
9. **Run quality gates.** Use `references/quality-gates.md` before calling the identity complete.

## Creative Production Rules

- Generate **3 meaningfully different creative territories** before converging, unless the user has already selected a direction.
- A logo is an identifier, not the whole brand. Do not use it to compensate for weak strategy.
- Prefer distinctive concepts derived from the brand idea over generic industry symbols and software clichés.
- Never imitate a recognizable third-party logo or trade dress. Abstract the strategic principle, then create an original solution.
- When image/design generation tools are available, create reviewable concepts only after the strategic direction exists. When unavailable, deliver precise art direction, construction logic, prompts/specifications, and required variants; do not pretend a final asset was produced.
- Show rationale: for every major name, message, color, type, or symbol choice, state the strategic reason and intended perception.

## Output Contract

For a complete engagement, use `templates/final-brand-identity.md`. The final system should normally cover:
**brief → research → strategy → naming → verbal identity → visual identity → logo system → brand guidelines → applications → rollout/next steps**.

For a lighter request, deliver only the relevant sections while preserving upstream logic.

## Completion Standard

The identity is not complete because it looks attractive. It is complete when it is **distinctive, strategically coherent, usable, adaptable, accessible in real applications, defensible as a direction, and documented well enough for consistent reuse**.
