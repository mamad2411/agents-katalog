# OpenAI 图像提示词

把用户的视觉目标整理成可执行的图像需求；如果用户要求实际生成或编辑图片，就继续执行，不只交付提示词。

## 工作流程

1. 明确交付物和用途：生成还是编辑、主体、画布或比例、受众、成功标准。
2. 涉及模型名、参数、限制、可用性或迁移建议时，先核对当前的 [OpenAI 官方图像提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)。调用参数和提示词正文分开处理。
3. 用最容易维护的形式写提示词。复杂任务可使用 `目标`、`场景`、`主体`、`构图`、`风格`、`文字`、`必须保留`、`限制` 等分节。
4. 描述画面中能看见的证据：位置、大小、材质、光线、纹理、颜色、氛围和媒介。镜头与相机术语只是外观提示，不保证精确物理模拟。
5. 编辑任务先写唯一要改变的内容，再明确列出不能改变的内容。存在多张参考图时，给每张图指定角色。
6. 用户要的是图片而不是提示词文本时，使用可用的图像生成能力完成图片。
7. 按需求检查结果。每轮只改一个变量，便于判断哪项调整有效。

## 必须检查

- 精准文字：原文加引号，规定出现次数，禁止多余文字，并检查拼写和可读性。
- 人物或产品一致性：保留关键外貌、几何形状、标签、姿态、取景、光线和其他被锁定的细节。
- 局部编辑：精确指出目标，并声明无关区域保持不变。如果必须像素级不变，不能只依赖提示词，应使用图像合成。
- 透明背景：提示词中要求主体独立，同时在调用参数中设置透明背景；使用 PNG 或 WebP，并验证真实 Alpha 通道。画出来的棋盘格不是透明。
- 图解、图表、幻灯片和历史场景：独立核对事实、标签、关系、日期和数据。看起来合理不等于事实正确。
- 连续编辑：每轮重申保留条件并检查输出，防止细节逐步漂移。

## 详细模式

任务涉及精准文字、Logo、界面、教学视觉、多参考图编辑、角色一致性、透明素材或生产验收时，读取 [references/prompt-patterns.md](references/prompt-patterns.md)。
