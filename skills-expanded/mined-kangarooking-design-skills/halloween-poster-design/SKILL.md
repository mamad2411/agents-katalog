# 万圣节高级感配色海报设计 Skill

## 1. 使命与边界

将用户的海报需求转化为可执行的设计方案，并按需交付生图 Prompt
或调用当前环境可用的图像生成工具。

本 Skill 不只是配色表。它负责完整的设计决策链：

1.  理解设计 Brief 与硬约束。
2.  选择或组合配色策略。
3.  建立色彩角色、HEX 色值与面积分配。
4.  规划构图、主体、字体、图形和信息层级。
5.  将方案编译成目标图像模型可执行的 Prompt。
6.  检查方案与生成结果是否符合要求。
7.  根据问题进行针对性迭代。

默认使用中文沟通和输出。用户明确要求其他语言时遵循用户要求。

## 2. 何时调用

适用于以下任务：

-   设计万圣节主题海报、活动主视觉、品牌营销图、餐饮促销图、派对邀请函、卡通海报或潮流视觉。
-   为海报制定配色方案、色彩比例、字体和构图规则。
-   将设计 Brief 转换为中文或英文生图 Prompt。
-   基于参考图提炼配色规则、保持构图并调整风格。
-   审查已有海报的色彩层级、可读性和风格一致性。
-   根据生成结果提出有明确目标的修改指令。

如果用户只要求分析或规划，不要擅自生成图像。如果用户明确要求创建、生成或编辑图像，并且当前环境提供可用的图像工具，才调用该工具。

## 3. 设计原则

### 3.1 先确定设计目标，再决定配色

不可把"万圣节"直接等同于"橙色背景加黑色蝙蝠"。首先识别：

-   海报用途与传播场景；
-   主体类型（产品、角色、插画、建筑、文字或组合）；
-   目标气质（极简、复古、浓郁、趣味、神秘、潮流、商业化等）；
-   文案密度与阅读优先级；
-   品牌色、禁用色、参考图和其他硬约束；
-   画幅比例与交付要求。

缺少非关键细节时使用合理默认值，不要为了填表而连续追问。只有当缺失信息会实质性改变设计结果时才提出一个直接问题。

### 3.2 用户硬约束优先

优先级从高到低：

1. 用户明确提出的内容、品牌、色彩、参考图、画幅和输出约束；
2.  设计目标与传播用途；
3.  选定的配色策略；
4.  通用审美建议与默认值。

不可为了套用某一策略而覆盖用户指定的品牌色或必须保留的参考图特征。参考图是构图蓝图时，明确哪些元素需要保留、哪些元素需要改变。

### 3.3 配色必须具有角色分工

每个方案至少明确：

-   主色：建立主要视觉气氛；
-   背景色：承载画面并控制明暗结构；
-   辅助色：构建层次或连接色相；
-   强调色：引导视线、标记重点；
-   中性色：承载文字、留白和轮廓。

一个颜色可以兼任多个角色，但必须说明其用途。色彩面积百分比是设计起始值，不是机械配方；各区间不可同时取最大值，最终比例必须归一化并结合版式验证。

### 3.4 "高级感"需要可执行的定义

不要只写"高级、精致、电影感"。应将其转译为可检查的设计行为：

-   限制竞争性高饱和色的数量；
-   建立明确的明度层级与视觉焦点；
-   控制装饰元素密度；
-   保持字体、图形、材质与色彩策略一致；
-   通过留白、比例和对比建立秩序；
-   避免所有元素同时争夺注意力。

### 3.5 将配色、视觉风格与版式分开决策

这三个维度相关，但不能互相替代：

- **配色策略**：颜色之间如何组织，例如强调色、主题色、相邻色或互补色。
- **视觉风格**：画面以何种视觉语言呈现，例如编辑式极简、复古印刷、趣味卡通、电影感夜景或现代产品广告。
- **版式模式**：主体、标题、信息区和留白如何组织。

不要因为用户说“卡通”就自动选择策略 C，也不要因为用户说“高级感”就自动选择黑金或深紫。应分别判断三个维度，再检查它们是否协调。

## 4. 执行工作流

### Step 1：解析 Brief 与交付意图

提取用途、主体、目标气质、受众、准确文案、品牌资产、品牌色/禁用色、画幅、参考图要求和交付模式。

识别用户当前要的是：
- 设计方案；
- 生图 Prompt；
- 直接生成或编辑图像；
- 既有方案/图像审查。

明确要求“生成、画一张、直接出图、编辑这张图”等最终视觉交付，且当前环境有图像工具时，应直接执行，不要只给 Prompt。明确要求“规划、分析、设计方案、写 Prompt”时，不要擅自生成图像。若用户说“做一张海报”且语境明显指最终视觉成品，默认按直接生成处理；若工具不可用，交付可直接使用的 Prompt 并说明限制。

### Step 2：给每张参考图分配角色

读取 `references/reference-image-handling.md`。参考图可能分别用于配色、构图、主体、风格材质或品牌资产。明确每张图负责的维度，不要默认把一张图的所有特征全部复制到其他维度。

### Step 3：选择配色策略

读取 `references/palette-strategies.md` 和 `references/strategy-routing.md`。

四种基础策略：
- A：强调色驱动——小面积高饱和橙色搭配大面积无彩色；
- B：主题色驱动——大面积暖橙与红棕构建浓郁氛围；
- C：相邻色驱动——橙、金橙、明黄构成连续暖色层次；
- D：互补色对比驱动——橙色、深蓝与暖米白形成冷暖对比。

四套策略是设计原型，不是强制套用的封闭色卡。如果品牌色、用户指定色或参考图色彩与标准色盘冲突，进入**自定义约束配色模式**：先保留用户硬约束，再借用合适的色彩关系或版式逻辑。只有色彩关系确实符合某策略时，才把该策略称为主策略；不得为了归类而替换用户的主色。

默认只选一个主策略。需要组合时，说明主策略与辅策略各自负责什么，不要无差别混合四套方案。

### Step 4：建立色彩参数与检查对比度

明确 HEX、色彩角色、推荐面积比例、明度/饱和度关系、冷暖关系、主体分离方式和文字承载区域。

- 面积比例采用 `references/palette-strategies.md` 中的首稿目标值；各色比例必须合计为 100%，再根据构图调整。
- 区分“案例明确色值”“推荐替代色”和“从图片估算的辅助色”。
- 文字颜色必须单独审查，不能因为两个颜色作为色块搭配好看，就默认适合叠加小字。
- 数字海报可将 WCAG AA 对比度作为可读性参考：普通文字目标至少 4.5:1，大字号展示文字目标至少 3:1。它是保守检查线，不是对所有印刷和艺术设计的绝对美学规定。
- 对比度不足时，优先更换文字颜色、给文字增加独立底板或调整文字承载区域，不要立即推翻整套配色。

### Step 5：规划版式与信息层级

明确第一视觉焦点、第二视觉焦点、主标题、辅助文案、主体/背景关系、装饰密度、信息区和留白。先建立主体与信息层级，再添加装饰。

### Step 6：编译 Prompt

读取 `references/prompt-compiler.md`。按用户需要输出完整设计方案、可复制 Prompt、负面约束或中英双语版本。Prompt 应准确表达已确定的主体、构图、色彩角色与比例、文字层级、风格、材质、画幅和硬约束。

### Step 7：生成或交付

- **设计方案模式：** 输出配色与版式决策，不生成图像。
- **Prompt 模式：** 输出可复制的 Prompt，不自动生成图像。
- **直接生成模式：** 用户明确要求最终图像且当前环境提供图像工具时，调用该工具。
- **审查模式：** 检查现有图像/方案并提出有优先级的修正意见。

平台适配层负责定义具体图像工具的调用方式。若没有可用图像工具，不要声称已经生成图像。

### Step 8：审查实际输出并迭代

读取 `references/quality-checklist.md`。如果生成结果可供检查，必须根据实际图像检查硬约束、配色面积、文字可读性、构图和风格一致性；不要只根据 Prompt 自己判断图像已成功。

如果无法访问或查看生成结果，应明确说明未完成视觉审查，不要虚构检查结果。每轮优先修复最影响目标的 1–3 个问题，并用可观察的修改指令描述变化。

## 5. 标准输出结构

当用户要求完整设计方案时，按以下结构输出：

1.  **设计定位**：一句话描述设计目标和视觉策略。
2.  **策略选择**：说明选用 A/B/C/D 或自定义约束配色模式的原因；如有混合，说明主次。
3.  **色彩资产表**：颜色名称、HEX、角色、面积建议和使用位置。
4.  **色彩关系**：明度、饱和度、冷暖和背景/主体分离规则。
5.  **构图与字体**：主体位置、标题、信息区、装饰、留白。
6.  **完整生图 Prompt**：可直接复制；用户只要方案时可省略。
7.  **负面约束**：仅列与任务相关的失败风险。
8.  **审查重点**：给出最重要的 3--5 项验收条件。

当用户只要求 Prompt 时，不必重复完整理论，直接提供可执行 Prompt
和必要约束。

## 6. 图像生成约束

-   不把色彩 HEX
    当作模型必然精确执行的保证；将其作为颜色锚点，并用相对面积、明暗和冷暖关系辅助描述。
-   不保证图像模型能够准确生成长中文文案、二维码、电话号码或复杂 Logo。
-   若需要准确商业文案，优先建议先生成背景与主体，再用排版工具叠加文字和品牌资产。
-   如果用户提供参考图，遵循用户要求的参考图优先级；不要把参考图未明确的细节当成事实。
-   不要在未被要求时自行添加品牌、Logo、二维码、网址或活动信息。
-   画面中不需要的文字、伪文字、水印和无意义标识应在约束中明确排除。

## 7. 默认行为

当用户只说“做一张高级感万圣节海报”而未给出更多信息：

- 将“做一张海报 / 出一张图 / 直接出图”视为最终视觉交付意图；若有图像工具，直接生成，不要只回复 Prompt。
- 如果用户明确要求“先给方案 / 先写 Prompt / 帮我分析”，则按指定模式交付，不擅自生成图像。
- 如果当前环境没有图像工具，输出可直接复制使用的 Prompt，并明确说明当前不能直接生成图像。
- 默认选择一个主配色策略；用途不明时优先 A（结构清晰），如果上下文明显偏活泼趣味，可选 C。
- 默认采用 4:5 竖版；用户指定画幅时严格遵循。
- 默认使用有限的节日图形元素，明确第一视觉焦点，避免素材堆积。
- 缺少非关键细节时使用合理默认值；只有关键信息缺失会实质性改变结果时才询问。
