# AI 初创团队 CEO 评估器

基于一位全栈工程师在未达 PMF 的 AI 创业团队的一手经验，评估一个早期 AI 初创团队是否值得加入。

## 何时激活

当用户：
- 询问是否应该加入某个创业团队
- 描述了一个创业 offer 或团队，希望评估
- 想知道 AI 创业的警告信号或积极信号
- 询问创业做法是否"正常"
- 用中文提问"这个团队值得加入吗""帮我评估这个 startup""AI 创业有什么坑"

## 核心框架：五资源模型

AI 创业的本质是**"利用极其有限的资源，将知识快速变现的游戏"**。资源分为五类，逐一评估：

| 资源 | 健康信号 | 危险信号 |
|------|---------|---------|
| **人才** | 核心团队技能互补；不是全实习生；有人具备管理经验 | CEO 认为"每个实习生 + Cursor = 高级工程师"；20 个实习生配 3 个正式员工；没人会拆任务 |
| **启动资金** | 明确 runway（12 个月以上）；合理的烧钱速度；与团队规模匹配 | "3 个人就能干掉 DeepSeek"心态；产品未出先烧钱营销；资金来源不明 |
| **技术** | 技术栈匹配领域；AI 使用有章法；存在学习循环 | 用 AI 替代高级判断；技术债务无节制积累；追风口换工具 |
| **人脉** | 创始人有行业关系；分销渠道已确定；能接触早期客户 | 零客户 pipeline；创始人与市场隔绝；"分销以后再说" |
| **设备** | 工作设备充足（Mac 适合创意/ML 工作）；有云服务预算 | 开发人员被迫用低配机器；无云支持 |

## 关键评估维度

### 1. 团队构成

- 高级 vs 初级比例？如果大部分是实习生配合 AI 工具，是巨大危险信号
- 有人具备管理/项目管理能力吗？还是所有人"只写代码"？
- 角色定义清晰吗？还是 CEO 什么都要做？
- 沟通：团队有重叠的工作时间吗？还是大家随机上线、没有人知道别人什么时候在线？

### 2. 职责过载检测

最危险的模式：**一人身兼数职**。

检查清单：
- CEO 是否同时担任 CFO、CTO、PM、HR？
- 一线员工是否也承担 PM、DevOps、QA 职责——且未被认可？
- 是否有人的工作量注定导致睡眠剥夺？
- "异步沟通"是否实际上掩盖了"没人知道别人什么时候在线"？

职责过载的连锁反应：睡眠紊乱 → 健康下降 → 决策疲劳 → 倦怠 → 离职。

### 3. 进度管理能力

问：**谁拆任务、谁估算、谁验收？**

强信号：
- 拆任务的人同时了解开发者和需求
- 估算考虑开发者能力差异（人与人不相等）
- 存在反馈循环：估算准不准？开发者有没有成长？

弱信号：
- CEO 拍脑袋分配任务，不了解复杂度
- 没人跟踪开发者成长或能力退化
- 需求以一句 AI prompt 的形式下发

### 4. 技术与 AI 使用成熟度

好的：
- AI 用来加速已知模式，而非替代工程判断
- Code review 能发现 AI 生成代码的 bug（尤其是缺乏全局上下文的修复）
- 团队有学习文化：知识被记录、沉淀，而非散落在个人脑中

差的：
- AI 写的代码不经 review 直接上线
- bug 修复是一次性补丁，不做根因分析
- CEO 认为 AI 消除了对高级工程师的需求

### 5. 你能从这个团队学到东西吗？

终极决策标准：**"当我认为自己不能从团队中学到更多时，就可以抽身了。"**

加入之前问：
- 这个团队里谁能教我东西？
- 我会获得可以带走的能力吗？
- 团队的知识被记录和共享了吗？还是只在人的脑子里？

## 决策输出格式

评估后输出结构化结果：

```
## 资源评分卡（每项 /10）
- 人才：X/10 — [理由]
- 资金：X/10 — [理由]
- 技术：X/10 — [理由]
- 人脉：X/10 — [理由]
- 设备：X/10 — [理由]

## 危险信号（列出所有）
## 积极信号（列出所有）
## 结论：[加入 / 有条件加入 / 不加入]
## 最大风险：[最需要警惕的一点]
```

## 附加启发规则

- **"3 人干掉 DeepSeek"测试**：如果 CEO 认为小团队能在没有非凡资源的情况下击败大厂，快跑
- **实习生比例测试**：如果 >50% 的技术人员是实习生，公司在用成本替代质量
- **睡眠测试**：如果有人描述经常牺牲睡眠来维持工作，这是结构性问题，不是个人问题
- **学校测试**：更好的学校 → 更好的校友网络。如果创始人来自无名院校且零人脉，分销会很痛苦
- **"我能学什么"测试**：如果你不能至少列出一个具体能获得的技能，重新考虑
- **沉淀测试**：团队的知识能否转化为你的能力？如果文档和辅导不存在，你会停滞不前
