# Google Ads 關鍵字分類 Skill

## 適用範圍

本 Skill 負責將 Google Keyword Planner 匯出的關鍵字清單進行分類，輸出結構化分類結果，供下一階段廣告群組規劃使用。

**不負責：** Match type 決策、廣告群組設定、出價策略。

---

## 輸入要求

開始前必須向用戶逐一確認以下資訊，**全部收集齊全才能開始分類**。

### 必填項目

1. **關鍵字清單**：來自 Google Keyword Planner 的匯出檔案（CSV / Excel / 貼上文字皆可）

2. **目標國家／地區**
   - 例如：台灣全島、香港、僅台北市、馬來西亞等
   - 用途：決定 SERP 驗證時使用哪個版本的 Google（google.com.tw / google.com.hk 等），以及判斷在地化關鍵字是否相關

3. **客戶品牌名稱**
   - 中文名、英文名、常見縮寫全部列出
   - 例如：萬智匯、GeniusHub、geniushub.cc
   - 用途：識別品牌詞

4. **主要商品／服務**
   - 具體描述客戶提供什麼，而不是籠統的行業名稱
   - 例如：「Google 廣告代操服務」而非「數位行銷」
   - 用途：判斷關鍵字相關性，決定是否納入分類

### 選填項目

5. **競品名稱**：已知競爭對手的品牌名稱、產品名稱
   - 若未提供，分類時仍會從 SERP 驗證中嘗試識別競品

6. **廣告投放目標地點**（若與目標國家不同）
   - 例如：公司在台北，但只服務台中以南的客戶
   - 用途：判斷含地名的關鍵字是否相關

如任何必填項目缺漏，先向用戶索取，確認齊全後才繼續。

---

## 分類流程

### Step 1：資料確認

確認清單欄位包含：關鍵字、每月搜尋量（平均）、競爭程度、出價區間（低標 / 高標）。

### Step 1b：前置篩選

分類前先做兩項過濾，移除不值得處理的關鍵字：

**絕對下限：搜尋量 < 10 → 直接剔除，不進入分類流程**
（搜尋量10以下在台灣市場屬統計誤差，任何行業皆適用）

**語言相關性過濾：**
- 與目標地區語言完全無關的字（如全歐語系字詞出現在台灣清單）→ 剔除
- 與客戶商品／服務明顯無關的字 → 剔除，備註原因

過濾完成後，計算剩餘清單的搜尋量四分位數，作為後續相對分層的基準：
- **高層**：前 25%（搜尋量最高的四分之一）
- **中層**：25–75%
- **低層**：後 25%（搜尋量最低的四分之一，但 ≥ 10）

### Step 2：分類執行

依照以下順序處理，**順序不可顛倒**（前面類別優先，已分類的字不重複歸入後面類別）：

#### 類別一：排除關鍵字（Negative Keywords）
包含明顯負面意圖的字，直接標記為排除，不投放。

常見特徵：
- 負評詞：黑店、詐騙、騙、投訴、爛、差評、踩雷
- 免費意圖：免費、破解、crack、free download
- 求職意圖：招聘、徵才、應徵、jobs
- 其他不相關意圖（依產業判斷）

#### 類別二：競品詞（Competitor Keywords）
包含競爭對手品牌名稱、產品名稱的關鍵字。

標記為競品詞，**不自動移入排除清單**，保留供日後品牌進攻型廣告使用。

#### 類別三：品牌詞（Branded Keywords）
包含客戶自身品牌名稱、產品名稱的關鍵字。

#### 類別四：比較/決策詞（Comparison / Bottom-Funnel）
用戶正在做最終決策，意圖明確。

常見特徵：
- 包含「比較」「vs」「哪個好」「推薦」「評價」「值不值得」「CP值」
- 包含「哪裡買」「哪裡有」「費用」「價格」「優惠」

#### 類別五：通用/品類詞（Generic / Category）
描述產品或服務品類，不含明確品牌或決策意圖。

常見特徵：
- 直接描述品類：「台北健身房」「SEO服務」「會計師事務所」

#### 類別六：功能/痛點詞（Feature / Problem-Aware）
用戶在描述問題或尋找解決方案，尚未指定品牌或品類。

常見特徵：
- 「怎麼」「如何」「方法」「解決」「改善」
- 描述痛點：「體重減不下來」「網站沒有流量」

#### 類別七：資訊詞（Informational）
純粹獲取知識，尚無購買意圖。

常見特徵：
- 「什麼是」「介紹」「原理」「歷史」

> 資訊詞預設保留，不排除。是否投放由下一階段決策。

---

### Step 2b：字詞結構輔助判斷規則

分類時，以下字詞結構特徵可輔助判斷意圖，**優先於字面分類**：

**強制升為比較/決策詞（主力）：**
- 含「費用」「價格」「收費」「多少錢」「報價」→ 決策意圖明確
- 含「推薦」「哪家」「比較」「評價」「怎麼選」→ 決策意圖明確
- 含「代操」「代理」「外包」「找公司」→ 直接服務需求

**強制歸入資訊詞（備用）：**
- 含「教學」「課程」「證照」「認證」「自學」「怎麼學」→ 學習意圖
- 含「什麼是」「介紹」「原理」「是什麼」→ 純知識意圖

**強制降為備用（論壇／討論意圖）：**
- 含「ptt」「dcard」「mobile01」「論壇」「討論」「心得」「開箱」→ 資訊／討論意圖，一律備用，不可升為主力

**含地名的關鍵字：**
- 地名與目標投放地點相符 → 保留，正常分類
- 地名與目標投放地點不符 → 降為備用或剔除

---

### Step 3：同義字與變體處理規則

分類完成後，針對每個類別內部處理變體：

- **意圖相同的變體** → 合併為同一組，搜尋量最高者為代表字，其餘列為變體
- **意圖不同的變體** → 分開保留，各自歸入對應類別
- **繁簡/中英混用變體**（如「健身」和「fitness」）→ 意圖相同則合併為同組，但兩個變體都保留在清單中

---

### Step 4：重疊關鍵字處理規則

同一關鍵字符合多個類別時，依照以下優先順序歸類：

1. 排除關鍵字（最優先）
2. 競品詞
3. 品牌詞
4. 比較/決策詞
5. 通用/品類詞
6. 功能/痛點詞
7. 資訊詞

---

### Step 5：各類別主力／備用判定規則

依照以下規則決定每個關鍵字的狀態，**規則有衝突時，以排序較前的規則優先**：

#### 排除關鍵字
- 全數標記「排除」，不可更改

#### 競品詞
- 全數預設「備用」
- 客戶明確表示要做品牌進攻型廣告 → 升為「主力」

#### 品牌詞
- 全數預設「主力」

#### 比較/決策詞
- 搜尋量 ≥ 10 → 全數「主力」（轉換意圖強，不看搜尋量層級）
- 例外：高競爭 + 低層搜尋量（後25%）→ 降為「備用」

#### 通用/品類詞
- 高層搜尋量（前25%）→「備用」（意圖模糊，需充足預算才啟用）
- 中層搜尋量（25–75%）→「備用」
- 低層搜尋量（後25%，但≥10）→「主力」（競爭相對低，值得嘗試）
- 單一品類詞（1–2字，如「google ads」）→ 一律「備用」，不論搜尋量

#### 功能/痛點詞
- 高層 + 中層搜尋量 → 「主力」
- 低層搜尋量（後25%）→「備用」
- 含「教學/課程/證照/自學」等學習意圖字 → 強制「備用」（已在Step 2b處理）

#### 資訊詞
- 全數預設「備用」
- 客戶有明確品牌認知廣告目的 → 可升為「主力」

---

**目標數量控制：每個類別主力字以 10–20 個為上限**

若某類別主力字超過 20 個，依以下優先順序降為備用直到 ≤ 20：
1. 先降競爭程度「高」的字
2. 再降搜尋量較低的字
3. 再降字詞較短（意圖較模糊）的字

不足 10 個則全數保留為主力，無需強行補充。

### Step 6：SERP 抽樣驗證（主動觸發 Claude in Chrome）

分類完成後，**必須主動呼叫 Claude in Chrome 工具執行 SERP 驗證，不等用戶要求**。

執行前先呼叫 `list_connected_browsers` → `select_browser` → `tabs_context_mcp` 取得 tab ID，再開始搜尋。

**抽樣規則：每個類別抽取 10–15%，最少抽 3 個字，優先抽搜尋量最高的字**

執行方式：
1. 使用 `navigate` 工具前往對應地區的 Google（台灣 → `https://www.google.com.tw`，香港 → `https://www.google.com.hk`）
2. 對每個抽樣關鍵字構建搜尋 URL：`https://www.google.com.tw/search?q={keyword}&gl=tw&hl=zh-TW`
3. 使用 `get_page_text` 工具讀取 SERP 前三名結果的標題與描述
4. 判斷頁面類型：
   - 電商/服務頁、報價頁 → 商業/購買意圖
   - 部落格/教學文/問答 → 資訊意圖
   - 品牌官網首頁 → 導航意圖
   - 比較/評測頁 → 決策意圖
5. 若 SERP 結果與預設分類不符 → 記錄並重新歸類

常見需修正情況：
- 字面看似資訊詞，但 SERP 全為服務頁/報價頁 → 移至比較/決策詞或通用/品類詞
- 字面看似通用詞，但 SERP 全為教學文 → 移至資訊詞

驗證完成後列出所有驗證字的判斷結果。若某類別有 30% 以上需修正，對該類別全面重新審查後再進行 Step 5 篩選。

**若 Claude in Chrome 工具不可用（list_connected_browsers 回傳空），跳過此步驟並在輸出備註欄標記「待人工SERP驗證」。**

## 輸出格式

### Step 7：輸出 Excel 檔案

SERP 驗證與分類調整完成後，使用 Python openpyxl 自動輸出 Excel 檔案，包含以下四個工作表：

**工作表一：關鍵字分類清單**

欄位：關鍵字 / 月均搜尋量 / 競爭程度 / 出價低標 / 出價高標 / 分類 / 狀態 / SERP驗證 / 備註

排序規則（依此優先順序）：
1. 狀態「主力」→「備用」→「排除」
2. 同狀態內依搜尋量由高到低排序

其他格式設定：
- 以顏色區分各分類（每個分類一個底色）
- 狀態欄：主力（綠底）、備用（黃底）、排除（紅底）
- SERP驗證欄：填入驗證結果（✓ 正確 / → 調整至[新分類] / — 未抽樣）
- 第一列凍結

**工作表二：數量摘要**

欄位：分類 / 主力 / 備用 / 排除 / 小計（含合計列，使用 SUM 公式）

**工作表三：競品詞（待補充）**

欄位：競品關鍵字 / 月均搜尋量 / 競爭程度 / 出價低標 / 出價高標 / 備註

記錄已知競品資訊及 SERP 驗證中發現的新競品，供日後品牌進攻型廣告使用。

**工作表四：排除關鍵字**

欄位：關鍵字 / 月均搜尋量 / 出價低標 / 出價高標 / 排除原因

獨立存放所有排除關鍵字，方便直接匯出為 Google Ads Negative Keywords 清單使用。

**狀態欄位說明：**
- `主力`：進入下一階段廣告群組規劃
- `備用`：已分類但暫不使用，保留供日後擴展
- `排除`：加入 Negative Keywords 清單

---

## 注意事項

- 分類判斷依據是**搜尋意圖**，不是字面意思
- 有疑慮的關鍵字寧可標記備註，讓用戶最後確認，不要強行歸類
- SERP 抽樣必須在目標地區對應的 Google 版本執行，不同地區結果可能不同
