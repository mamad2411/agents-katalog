# Memory (acaf-memory)

## 基本信息

- **技能名称**: acaf-memory
- **技能类型**: 组合技能
- **融合元技能**: ac-blueprinting + af-memory

## 技能描述

融合设计尚未存在但一旦构想就显得不可避免的技能生态系统与通用记忆抽象接口的能力，当需要前瞻性规划、系统设计或演化路径规划时调用 当定义记忆结构、记忆检索、记忆关联时调用此技能

## 核心能力

### 融合能力1: ac-blueprinting
设计尚未存在但一旦构想就显得不可避免的技能生态系统。当需要前瞻性规划、系统设计或演化路径规划时调用。

### 融合能力2: af-memory
通用记忆抽象接口。当定义记忆结构、记忆检索、记忆关联时调用此技能。

## 应用场景

- 跨领域问题解决
- 复杂系统分析
- 创新思维应用
- 多维度思考

## 调用触发

当需要同时使用ac-blueprinting和af-memory的能力时，可以调用此技能。
