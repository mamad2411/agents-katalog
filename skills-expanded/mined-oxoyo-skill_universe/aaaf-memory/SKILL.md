# Memory (aaaf-memory)

## 基本信息

- **技能名称**: aaaf-memory
- **技能类型**: 组合技能
- **融合元技能**: aa-clazz + af-memory

## 技能描述

融合通用分类法抽象接口与通用记忆抽象接口的能力，当定义分类系统、分类结构或分层分类框架时调用此技能 当定义记忆结构、记忆检索、记忆关联时调用此技能

## 核心能力

### 融合能力1: aa-clazz
通用分类法抽象接口。当定义分类系统、分类结构或分层分类框架时调用此技能。

### 融合能力2: af-memory
通用记忆抽象接口。当定义记忆结构、记忆检索、记忆关联时调用此技能。

## 应用场景

- 跨领域问题解决
- 复杂系统分析
- 创新思维应用
- 多维度思考

## 调用触发

当需要同时使用aa-clazz和af-memory的能力时，可以调用此技能。

## 技能关系

### 协同技能
- aa-clazz
- af-memory

### 相关组合技能
- 其他基于aa的组合技能
- 其他基于af的组合技能
