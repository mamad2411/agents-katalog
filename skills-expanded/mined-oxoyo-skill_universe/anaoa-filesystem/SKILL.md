# 文件系统领域技能（anaoa-filesystem）

## 基本信息

- **技能名称**: anaoa-filesystem
- **技能类型**: 领域技能
- **融合组合技能**: anao-filesystem
- **领域标识**: anao (规划系统+逻辑系统组合) + a (领域级) + filesystem (文件系统)

## 技能描述

提供专业的文件系统操作领域技能，基于规划系统和逻辑系统的组合能力，为文件系统管理提供全面的解决方案。

## 核心能力

### 基础文件操作
- **文件管理**: 创建、读取、更新、删除文件
- **目录管理**: 创建、列出、删除目录
- **路径管理**: 绝对路径、相对路径、路径解析

### 高级文件系统功能
- **元数据管理**: 文件权限、大小、修改时间、所有者
- **文件搜索**: 按名称、类型、内容搜索文件
- **文件监控**: 实时监控文件系统变化
- **跨平台兼容**: 支持不同操作系统的文件系统

### 安全与性能
- **权限控制**: 文件访问权限管理
- **错误处理**: 异常捕获与处理
- **性能优化**: 批量操作、缓存机制

## 应用场景

- **文件管理系统**: 构建文件管理应用
- **数据备份工具**: 自动备份重要文件
- **文件同步工具**: 跨设备文件同步
- **文件搜索系统**: 快速查找文件
- **文件监控系统**: 监控文件变化
- **部署工具**: 自动化部署文件

## 调用触发

当需要进行以下操作时，可以调用此技能：
- 管理文件和目录结构
- 读取或写入文件内容
- 搜索和过滤文件
- 监控文件系统变化
- 处理跨平台文件操作

## 技能关系

### 协同技能
- anao-filesystem (组合技能)
- an-planning (规划系统)
- ao-logic (逻辑系统)
- aq-information (信息系统)
- az-action (行动系统)

### 相关领域技能
- 其他基于组合技能的领域技能

## 调用示例

```
// 创建文件
anaoa-filesystem.createFile('path/to/file.txt', 'Hello, world!');

// 读取文件
const content = anaoa-filesystem.readFile('path/to/file.txt');

// 列出目录
const files = anaoa-filesystem.listDirectory('path/to/directory');

// 搜索文件
const results = anaoa-filesystem.searchFiles('*.txt', 'path/to/search');
```
