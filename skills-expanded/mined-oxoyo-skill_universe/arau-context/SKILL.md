# Context (arau-context)

## 基本信息

- **技能名称**: arau-context
- **技能类型**: 组合技能
- **融合元技能**: ar-inference + au-context

## 技能描述

融合通用推理抽象接口与通用上下文抽象接口的能力，当进行逻辑推理、因果推断、不确定性推理或知识推理时调用此技能 当定义上下文环境、情境感知、语义空间或上下文管理系统时调用此技能

## 核心能力

### 融合能力1: ar-inference
通用推理抽象接口。当进行逻辑推理、因果推断、不确定性推理或知识推理时调用此技能。

### 融合能力2: au-context
通用上下文抽象接口。当定义上下文环境、情境感知、语义空间或上下文管理系统时调用此技能。

## 应用场景

- 跨领域问题解决
- 复杂系统分析
- 创新思维应用
- 多维度思考

## 调用触发

当需要同时使用ar-inference和au-context的能力时，可以调用此技能。

## 技能关系

### 协同技能
- ar-inference
- au-context

### 相关组合技能
- 其他基于ar的组合技能
- 其他基于au的组合技能
