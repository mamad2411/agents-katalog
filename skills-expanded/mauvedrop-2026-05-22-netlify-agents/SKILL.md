# AGENTS.md

## Project overview

Single static HTML page for mauvedrop.com. No framework, no build step, no dependencies.

## Structure

- `index.html` — the entire site; styles are inlined in a `<style>` block

## Conventions

- Keep everything in `index.html` unless the site grows significantly
- Colour palette centres on mauve tones (`#5c3a5c` text, `#e8d5e8` background)
