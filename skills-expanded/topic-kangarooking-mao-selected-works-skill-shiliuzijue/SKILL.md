## R — 原文 (Reading)

> "从一九二八年五月开始，适应当时情况的带着朴素性质的游击战争基本原则，已经产生出来了，那就是所谓'敌进我退，敌驻我扰，敌疲我打，敌退我追'的十六字诀。……基本的原则，仍然是那个十六字诀。十六字诀包举了反'围剿'的基本原则，包举了战略防御和战略进攻的两个阶段，在防御时又包举了战略退却和战略反攻的两个阶段。"
> — 《中国革命战争的战略问题》(1936年12月)

## I — 方法论骨架 (Interpretation)

1. 十六字诀是一套针对对手四种状态（进/驻/疲/退）的精确行动指南，不是泛泛的"灵活应变"，而是有明确的节奏编码。
2. **敌进我退**：对手全力进攻时不要硬碰——收缩核心、保护基本盘、避免正面消耗战。退不是逃跑，而是有秩序地保存实力。
3. **敌驻我扰**：对手站稳后注意力会转移——持续用差异化产品和本地化服务骚扰其薄弱环节，让对手无法安宁。
4. **敌疲我打**：对手的管理链条拉长、反应变慢时——抓住窗口期集中资源主动出击，打有把握的仗。
5. **敌退我追**：对手收缩或调整策略时——趁势扩大市场份额，快速占领对手放弃的空间。
6. 四步形成完整的攻防循环，核心原则是"跟着对手的节奏走，在对手每个状态中找到最有利于自己的行动"——不自我中心，而是以对手的状态为行动的信号。

## A1 — 书中应用 (Past Application)

### 应用1：集中兵力的实战应用 — 第一次反"围剿" (c07)
- **问题**：国民党以优势兵力"围剿"红军，正面硬打必输。
- **方法使用**：毛泽东先想打谭道源，但敌不脱离有利阵地，两度开进两度忍耐撤回（敌进我退）；等了25天才找到战机（敌驻我扰/敌疲我打）；找到好打的张辉瓒后集中兵力一战歼灭。
- **结论**："宁可退让，持重待机"的定力与"一旦出手就集中绝对优势"的果断形成鲜明对比。十六字诀不是机械执行，而是根据实际敌情灵活运用。
- **结果**：前四次反"围剿"均用此方法取得胜利。第五次反"围剿"放弃此原则而惨败。

### 应用2："围魏救赵"的反围攻战术 (c17)
- **问题**：敌人多路围攻根据地，如果每路都防则兵力分散。
- **方法使用**：以次要兵力钳制敌之数路（敌进我退的变体），用主力去攻击敌人的后方基地，迫使敌人回援（敌疲我打）。
- **结论**：十六字诀不是死板公式，而是根据实际情况灵活变通的行动逻辑。
- **结果**：在五台山等抗日根据地反复运用成功，成为以弱克强的经典战术。

## A2 — 触发场景 (Future Trigger)

1. **对手大举进入你的市场**：行业巨头或竞品强势进入你的核心领域，用户开始动摇。用户会说："他们来势汹汹，我们该不该正面迎战""要不要打价格战"。
2. **对手站稳后注意力分散**：竞品在市场上站稳脚跟但开始拓展其他业务线、本地团队管理出现松懈。用户会说："对手最近没那么猛了""他们的服务开始下滑"。
3. **对手出现疲态或管理瓶颈**：竞争对手规模扩大后决策变慢、服务质量下降、团队扩张但效率降低。用户会说："他们的人越来越不好用了""客户开始抱怨他们"。
4. **对手主动收缩或战略调整**：竞品砍掉某些产品线、退出某些区域、或调整战略方向。用户会说："对手退出了XX市场""他们不再做这个方向了"。

**语言信号**：用户提到"对手在___""竞争节奏""该攻还是守""要不要跟进""时机对不对""他们动作很大/动作放缓"等词汇时，应优先激活此skill。

**与相邻skill区分**：
- vs 不对称战略：本skill = "此刻做什么"（节奏执行），后者 = "用什么范式竞争"（战略定义）
- vs 战略-战术辩证法：本skill = "根据对手状态选择攻守节奏"，后者 = "宏观防御中制造微观进攻"
- vs 集中优势兵力：本skill = "判断时机"，后者 = "时机到了怎么集中资源打"

## E — 可执行步骤 (Execution)

### 步骤1：诊断对手当前状态
- 判断对手处于"进/驻/疲/退"四个状态中的哪一个。
  - 进：对手正在加大投入、拓展新市场、推出新品、高调营销。
  - 驻：对手在市场上站稳但增长放缓，注意力开始分散。
  - 疲：对手管理链条拉长、团队膨胀效率下降、客户投诉增多。
  - 退：对手收缩战线、砍产品线、退出区域、或战略转向。
- **完成标准**：能一句话说明对手当前状态及判断依据（如"对手处于'驻'状态，因为他们在本市开了3家店后6个月没新增，且开始拓展外地市场"）。

### 步骤2：匹配对应行动
- 根据对手状态选择行动：
  - 对手"进" → 收缩防守核心客户群，不硬拼价格战，保护现金流和核心团队。
  - 对手"驻" → 用差异化产品/服务持续骚扰其薄弱环节，抢夺其对边缘客户群的注意力。
  - 对手"疲" → 集中资源在最有把握的细分市场主动出击，打一场"速决战"扩大份额。
  - 对手"退" → 趁势快速扩张，填补对手留下的市场空白。
- **判停点**：如果无法明确判断对手状态（信息不足），不要贸然行动——先补充情报，再匹配行动。

### 步骤3：设置状态转换预警
- 对手状态不会一成不变，设定预警信号以便及时切换行动：
  - "进→驻"信号：对手营销投放减少、新增速度放缓。
  - "驻→疲"信号：对手客户投诉增多、员工离职率上升、响应速度变慢。
  - "疲→退"信号：对手关闭门店/砍产品线、退出区域市场。
  - "退→进"信号：对手重新加大投入、换将、战略回调。
- **完成标准**：每个状态转换至少有2条可观测的预警指标，并指定监测频率。

## B — 边界 (Boundary)

### 不要使用的场景
1. **没有明确对手时**：蓝海市场或垄断市场不存在"对手状态"，十六字诀无用武之地。
2. **需要主动定义市场规则时**：如果你是行业开拓者，不应该跟着对手走，而应该让对手跟着你走。
3. **处于绝对优势地位时**：如果你已经明显领先，不需要"跟着对手节奏"，而应该用自己的节奏主导市场。

### 失败模式（来自反例）
- **逃跑主义(ce16)**：把"敌进我退"的"退"理解为全面放弃——退是有秩序的收缩保护核心，不是慌不择路的溃散。第五次反"围剿"后期的"退"变成了逃跑主义。
- **冒进/速胜论(ce05)**：对手刚"驻"就急于"打"，把"敌驻我扰"的"扰"升级为全面进攻，结果准备不足反被反制。正确做法是耐心等待对手"疲"的信号再出手。
- **教条主义(ce01)**：机械套用十六字诀，不看实际条件。毛泽东说"基本的原则仍然是那个十六字诀"，但每次应用的形式都因条件不同而改变。

### 作者盲点
- 十六字诀预设了对手的状态可以被清晰判断，但实际商业竞争中对手可能故意示弱或释放假信号。商业启示：需要多维度交叉验证对手的真实状态，不能仅凭单一信号判断。

## 相关 skills

- **不对称战略** (composes-with): 不对称战略定义竞争范式（"打什么样的战争"），十六字诀执行竞争节奏（"对手进了我退"）。先确定竞争范式，再用十六字诀执行具体节奏。
- **战略-战术辩证法** (composes-with): 十六字诀的"退→扰→打→追"循环，是战略-战术辩证法中"防御中的进攻"的具体执行节奏。
- **主动性灵活性计划性** (composes-with): 十六字诀的四个节奏步骤体现了执行力三要素——"判断对手状态"需要计划性，"选择对应行动"需要灵活性，"设置预警"需要主动性。
