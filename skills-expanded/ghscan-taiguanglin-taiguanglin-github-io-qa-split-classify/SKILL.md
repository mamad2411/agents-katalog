# 問答錄2 拆分與分類（qa-split-classify）

把未分類答疑整理成與第 1–12 章同構的分類資料。
**準則 SoT**：[`wenda2_split_classify_criteria.md`](wenda2_split_classify_criteria.md)
（鐵律、拆分準則、分類總綱、輸入面、schema）；
**逐章準則**：[`chapters/ch01.md`](chapters/ch01.md) … [`chapters/ch12.md`](chapters/ch12.md)。

## 0. 什麼時候用

要把 13–21 章（或任何新進未分類月度答疑）按既有 12 章主題分類、
或是要把多問長訊息拆成原子問答時。

## 1. 鐵律（完整十條見主準則 §0）

1. 只用既有 12 章節點；不自創章，新主題只能「建議新節」（≥5 則同質才建議）。
2. 原子單位＝一個子問題＋對應答案段；編號子問題（「N、」「问题N：」「第N问」
   「①」「一、」）一律拆開，同訊息子問題各自獨立分類、可跨章。
3. 原文逐字保留：編號、問候語（跟第一則）、時間戳格式、簡體用語。
4. 分類看「問句主軸＋師父答案主軸」，不看開頭情境、不看字面關鍵詞。
5. 節內按日期升冪；重複條目各自分類＋標 `duplicate_of`。
6. 拆分/改寫會改 `question_id`、斷播放鈕鍵連——分類產出回建前音檔須重對位。

## 2. 作業程序

1. 讀主準則 §2（拆分）＋§3（分類總綱：3.1 章錨點、3.2 多義詞表、3.3 命名、3.4 程序）。
2. 對輸入串逐則跑拆分判定（主準則 §2.2 觸發表；13–21 章多已預拆，仍逐則驗證）。
3. 定章：先負規則（各章檔 N 條）再正規則（主準則 §3.1＋章檔 R 條）；
   12 章是 fallback，專章訊號優先。
4. 開對應 `chapters/chNN.md` 下探 L2→L3→L4（先專節、後兜底節），
   執行該章逐節準則與易錯歸屬表。
5. 以師父答案主軸印證；衝突時以「實際被回答的內容」為準。
6. 輸出主準則 §6.3 JSONL；信心階梯 high/medium/low；`needs_review` 列清單。

## 3. 驗收（每批次）

主準則 §6.4：條目守恆、抽 10 則複核、chapter=12 比例合理、
low 佔比＜15%、拆分對位無重疊遺漏、節內時間排序。

## 4. 已知邊界（勿踩）

- 「念佛/消業/身體反應/夢/超度/回向/淫欲/疾病/自殺/劇本/地藏菩薩」都是
  同名異章詞——先查主準則 §3.2 判準表，勿按字面定章。
- 既有分類有真實噪音（近同題異章）；以判準為準，不模仿噪音。
- 源檔殘缺（「问题缺失」、有問無答）→ 標 skip，不硬分。
