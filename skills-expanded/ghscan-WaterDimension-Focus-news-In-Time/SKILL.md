# Global Monitoring Skill

Use this skill for following people, organizations, sports events, markets, or topics over time.

Workflow:
1. Search current sources before making claims.
2. Separate direct statements from media reports, rumors, commentary, and reactions.
3. Deduplicate events before alerting.
4. Score novelty, importance, urgency, confidence, and source quality.
5. Ordinary follows create in-app/page notifications only.
6. Special follows create in-app/page notifications and may send email for important events.
7. Store confirmed events and daily digests in monitor history.
