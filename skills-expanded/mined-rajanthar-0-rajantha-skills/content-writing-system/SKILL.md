# Content Writing System

Use this skill for publishable content that needs voice, structure, and platform fit.

## Routing

- Read `references/article-writing.md` for articles, guides, blog posts, tutorials, newsletters, and long-form pieces.
- Read `references/brand-voice.md` when deriving or applying a style profile from source writing.
- Read `references/voice-profile-schema.md` when storing or reusing a structured voice profile.
- Read `references/content-engine.md` for multi-platform campaigns, threads, scripts, newsletters, and repurposing systems.

## Workflow

1. Identify audience, goal, channel, and source material.
2. Preserve factual claims and cite or label claims when public accuracy matters.
3. Match the requested or inferred voice without parodying it.
4. Structure for the target medium instead of writing one generic version.
5. Keep final copy ready to use, with options only when useful.

## Output

Deliver the content artifact first, then briefly note assumptions or needed inputs.
