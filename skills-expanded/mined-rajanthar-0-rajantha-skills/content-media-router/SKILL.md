# Content Media Router

Choose the smallest relevant skill set:

- `content-writing-system`: articles, guides, newsletters, brand voice, content systems, scripts, repurposing.
- `social-publishing`: platform-native posts, scheduling, cross-posting, SocialClaw/social-publisher workflows.
- `knowledge-ops`: knowledge base organization, ingestion, sync, retrieval, and memory/repo knowledge workflows.
- `fal-ai-media`: fal.ai image, video, and audio generation.
- `video-editing`: editing real footage, FFmpeg/Remotion augmentation, video structure.
- `remotion-video-creation`: React/Remotion video composition.
- `documentation-lookup`, `ce-doc-review`, or `ce-release-notes`: docs lookup, doc review, release notes.

Read only the selected child skill(s), then execute the user request.
