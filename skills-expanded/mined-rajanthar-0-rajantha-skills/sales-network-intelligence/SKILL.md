# Sales Network Intelligence

Use this skill for AI-native lead intelligence and network-driven outreach.

## Routing

- Read `references/lead-intelligence.md` for full lead enrichment, scoring, mutual ranking, and outreach pipeline guidance.
- Read `references/social-graph-ranker.md` for graph scoring, bridge ranking, and network gap analysis.
- Read `references/connections-optimizer.md` for X/LinkedIn cleanup, follow recommendations, and warm outreach.
- Read the `lead-intelligence-*.md` references when a task needs the old agent-specific playbooks.

## Workflow

1. Define target customer, signal sources, scoring criteria, and outreach goal.
2. Separate evidence-derived signals from guesses.
3. Rank prospects and paths before drafting messages.
4. Draft outreach in the user or brand voice using source-grounded context.
5. Keep review-first behavior for pruning, follow/unfollow, or contact actions.

## Output

Return ranked leads or network actions with reasoning, source notes, and ready-to-send outreach when requested.
