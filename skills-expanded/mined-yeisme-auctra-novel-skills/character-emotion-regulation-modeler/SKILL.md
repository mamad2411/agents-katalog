# 人物情绪调节建模师

把情绪词转换为“事件—评估—身体—冲动—表达—调节—关系后果—恢复”回路。输出情绪调节图，不做临床诊断。

## 输入

- 一个承重事件、触发、冲突或跨场景情绪问题。
- 人物目标、关系对象、公开规范、身体和资源状态。
- 文本中的动作、语言、节奏、回避与余波证据。
- 当前弧线阶段和下一场景要求。

## 输出

- 情绪基线、事件评估、情绪标签、身体激活和行动冲动。
- 公开表达、私下体验、调节策略、共调节对象和恢复条件。
- 策略成本、二级情绪、场景余波和证伪场景。
- 返回人物设计、压力测试、连续性或 writer 的 handoff。

格式读取 `../character-intelligence-router/references/internal-facet-output-templates.md` 的“情绪调节回路”。需要知识卡时读取 `../character-intelligence-router/references/emotion-appraisal-and-regulation.md`。

## 工作流

1. 记录事件和人物当时的目标，不直接从事件指定情绪。
2. 写人物如何评估责任、可控性、身份、关系和未来后果。
3. 分开身体变化、行动冲动、公开表达和私下体验。
4. 确定人物使用的是情境选择、情境修改、注意部署、重评、抑制、求助或其他策略。
5. 检查策略在当前场景的收益、关系成本和长期副作用。
6. 写情绪峰值后的疲劳、羞耻、空虚、警觉、内疚或行动计划。
7. 比较对上、对下、亲密、陌生和无人观看时的表达规则。
8. 用策略失效、共调节缺席和再次触发场景验证一致性。

## 选择原则

- 表面反应可随关系变化，稳定的是评估与调节机制。
- 少表达不等于少体验，爆发不等于没有调节。
- 成长可以是策略更灵活，而不是人物不再感受。
- 场景结束不等于情绪复位，必须保留余波连续性。

## 边界

- 不诊断情绪障碍、创伤、神经类型或临床风险。
- 不把单一调节策略写成永远健康或永远病态。
- 不用“微表情”确定性识谎。
- 涉及现实自伤或危机时，不以文学分析替代专业支持。

## 验证

- 情绪由具体评估而非剧情标签产生。
- 行动冲动与最终行动被分开。
- 调节策略有即时作用、关系影响和恢复余波。
- 至少有一个关系差异和一个策略失效验证场景。
