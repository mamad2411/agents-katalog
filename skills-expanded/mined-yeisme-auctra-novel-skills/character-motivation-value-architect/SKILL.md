# 人物动机价值架构师

把“他想要什么”展开为目标、需要、奖励、价值、恐惧、承诺和冲突。输出动机价值层级与冲突图，不把人物简化为唯一深层原因。

## 输入

- 当前故事目标、角色功能、关系和主要阻力。
- 人物已做出的投入、牺牲、承诺和拒绝。
- 已知社会资源、制度约束和奖励控制者。
- 需要测试的诱惑、成功、失败或道德选择。

## 输出

- surface goal、underlying needs、protected values、feared outcomes。
- 内在/外在奖励、趋近/回避动机、承诺与沉没成本。
- 动机竞争表、主冲突、诱惑报价和阈值选择。
- 证据状态、替代解释、证伪场景和 handoff。

格式读取 `../character-intelligence-router/references/internal-facet-output-templates.md` 的“动机价值层级与冲突图”。需要机制卡时读取 `../character-intelligence-router/references/motivation-needs-and-values.md`。

## 工作流

1. 从可见投入和选择提取表层目标，不用作者主题代替人物目标。
2. 区分人物希望获得什么与希望避免什么。
3. 检查自主、胜任、关系等需要是否相关，但不强迫套用单一理论。
4. 标出内在奖励、外在奖励、奖励控制者和领取奖励必须表演的身份。
5. 通过不能兼得的选择确定价值排序，而不是罗列价值词。
6. 写出公开承诺、沉没成本、身份性目标和退出时必须面对的观众。
7. 设计诱惑：短期奖励必须真实有效，同时逐步破坏价值或长期目标。
8. 用无人观看、奖励取消、成功后空虚和价值冲突场景验证。

## 选择原则

- 一个行动可以有多个真实动机；输出组合与冲突，不追逐“唯一真相”。
- 外在动机不等于肤浅，内在动机不等于高尚。
- 深层需要只有在成功、失败或关系中产生可观察差异时才有创作价值。
- 社会限制由社会 specialist 建模，不能全部心理化。

## 边界

- 不把所有动机归因为童年创伤、自卑、性欲、权力欲或依恋。
- 不把价值观直接当善恶排名。
- 不强迫所有人物完成治愈或正向弧线。
- 不为现实人物提供操控、诱导或胁迫优化。

## 验证

- 至少存在两项真实且冲突的动机或价值。
- 每个承重动机都有行为、投入、放弃或关系证据。
- 诱惑提供明确短期收益与逐步代价。
- 成功、失败和无人观看场景会产生可区分预测。
