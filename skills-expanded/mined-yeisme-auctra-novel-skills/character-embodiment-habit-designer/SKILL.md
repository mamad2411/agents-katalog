# 人物身体习惯设计师

把人物心理、专业、关系和状态转译为感官、动作、空间、物件、程序与疲劳连续性。输出身体习惯表演图，不用怪癖代替人物深度。

## 输入

- POV 或表演目标、场景环境和媒介。
- 人物职业训练、身体状态、日常、物件和空间证据。
- 关系中的距离、触摸、公开/私下规则。
- 需要外化的情绪、决策、身份或压力机制。

## 输出

- 感官优先级、内感受、默认姿势、节奏和空间偏好。
- 日常程序、物件关系、身体化技能、触摸与距离。
- 疲劳/疼痛影响、压力动作、自我安抚习惯和中断反应。
- 小说或剧本可用的观察线索、证伪场景和 handoff。

格式读取 `../character-intelligence-router/references/internal-facet-output-templates.md` 的“身体习惯表演图”。机制读取 `../character-intelligence-router/references/embodiment-sensation-and-habit.md`。

## 工作流

1. 区分作者镜头与人物感官，确定 POV 最先注意和长期忽略的感觉。
2. 写人物普通状态下的姿势、节奏、距离和空间选择。
3. 把职业、技能和长期经验转换为动作顺序、视线和工具使用。
4. 选择有功能的日常程序、关键物件和自我安抚习惯；说明即时奖励。
5. 写不同关系中的触摸、靠近、撤退和身体权限。
6. 记录睡眠、饥饿、伤势、疼痛、药物、天气和环境对可用能力的影响。
7. 设计习惯被打断、物件丢失、陌生空间和疲劳状态的验证场景。
8. 将可拍动作或 POV 线索 handoff 给 writer，并保持跨场景身体连续性。

## 选择原则

- 每个习惯必须有触发、功能、中断反应、关系意义或长期成本。
- 身体信号可以先于人物理解，但不能被分析者确定性解码。
- 同一人物在家庭、工作、危险和亲密中拥有不同身体权限。
- 环境不仅提供氛围，还提供或剥夺行动可能性。

## 边界

- 不从单个姿势、眼神或小动作判断情绪、撒谎或人格。
- 不把残障、疾病、体型、年龄或神经差异当缺陷模板。
- 不添加无功能的怪癖、重复手势或装饰性仪式。
- 不忽略具体时代、文化、职业、安全与可访问性。

## 验证

- 感官和动作规则会改变 POV、表演、空间或场景节奏。
- 习惯具有触发、即时功能和被打断后的可见反应。
- 疲劳、疼痛和伤势不会在下一场景无故复位。
- 至少有一个普通程序和一个压力破裂场景。
