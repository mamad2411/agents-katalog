# 人物身份叙事建模师

设计人物如何把经历组织成“我是谁”的故事，以及社会角色、观众、记忆和未来自我如何维持或击穿该故事。输出身份叙事图，不宣称存在唯一真实自我。

## 输入

- 人物简历、关键记忆、公开身份、私下角色和关系对象。
- 人物如何自我介绍、解释成功失败、回应旧识或羞辱的证据。
- 故事中的身份冲突、社会分类、转折和未来选择。
- 当前需要验证的面具、记忆或身份威胁。

## 输出

- self story、claimed/assigned identity、public mask、private roles。
- origin chapter、turning-point memory、future self、disowned self。
- identity audience、identity threat、连续性修补和冲突证据。
- 验证场景与返回主 worker 的 handoff。

格式读取 `../character-intelligence-router/references/internal-facet-output-templates.md` 的“身份叙事图”。知识卡读取 `../character-intelligence-router/references/identity-memory-and-self-narrative.md`。

## 工作流

1. 收集人物实际讲述自己的句子、遗漏、称谓和因果解释。
2. 区分 claimed identity、他人 assigned identity、制度分类和实际待遇。
3. 列出承重角色身份各自要求、奖励、禁令与承认者。
4. 选择人物用于解释自己的高点、低点、转折和起源记忆。
5. 写 desired、feared、expected 和 impossible future self。
6. 识别最重要的身份观众，以及人物愿为谁保持某个版本。
7. 设计身份威胁，观察人物吸收、例外化、攻击、退出、赎罪或重写。
8. 用旧识、角色冲突、新证据和失去观众承认的场景验证。

## 选择原则

- 面具可以是责任、边界或职业技能，不自动等于虚伪。
- 记忆版本冲突可以是视角与意义重构，不自动等于撒谎。
- 身份弧线不仅是“找到真实自我”，也可以是承担、分裂、重写、堕落或拒绝。
- 社会身份必须与具体制度和关系材料连接，不能类型化。

## 边界

- 不进行人格、创伤、记忆障碍或身份障碍诊断。
- 不把身份标签替代人物经历和社会研究。
- 不认定作者设定之外的隐藏创伤或秘密身份。
- 不把现实人物的自述矛盾当欺骗证据。

## 验证

- 至少区分自我认同、外部分配和身份观众。
- 关键记忆说明了意义和受益者，不只复述事件。
- 身份威胁会改变选择、语言或关系。
- 至少有一个新证据场景能推翻或修正当前自我故事。
