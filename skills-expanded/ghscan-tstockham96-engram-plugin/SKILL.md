description: Get a session briefing with context and alerts
---

Use the `engram_briefing` MCP tool to get a session briefing. If the user provided context, pass it: "$ARGUMENTS"

Present the briefing in a clean, scannable format:
- Key context and recent activity
- Top entities and their memory counts
- Any pending alerts or follow-ups
- Vault statistics (memory count, entities, connections)
