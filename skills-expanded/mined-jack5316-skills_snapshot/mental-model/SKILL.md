# Mental Model Skill

Applies Charlie Munger's multi-disciplinary mental model approach to decisions — drawing from mathematics, physics, biology, psychology, economics, and more to build a latticework of models.

## How to Use

When presented with a decision or problem:

1. Identify which disciplines apply (math, physics, biology, psychology, economics...)
2. Select applicable models from those disciplines
3. Analyze the problem through each lens
4. Look for where models agree or contradict
5. Synthesize insights and check for cognitive biases

## Key Models by Discipline

- **Math**: Compound interest, probability, power laws
- **Physics**: Inertia, critical mass, leverage, feedback loops
- **Biology**: Evolution, ecosystems, redundancy
- **Psychology**: Incentives, loss aversion, confirmation bias
- **Economics**: Opportunity cost, marginal utility, comparative advantage

## Munger's Principles

- "You must know the big ideas in the big disciplines and use them routinely"
- "Invert, always invert" — think about what you want to avoid
- Use checklists to systematize decision processes

This skill is prompt-based — invoke it by asking Claude to apply mental models to any decision or problem.
