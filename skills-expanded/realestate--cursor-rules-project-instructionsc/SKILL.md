# Project standards (CLAUDE.md) are required

Before making any code or configuration changes in this project:

1. **Read** `CLAUDE.md` (at the repo root).
2. **Use** it as the source of truth for behavioral standards, architecture, security, and conventions (including what was previously in `project_instructions.md`).
3. **Comply** with everything it specifies (don’ts, security, 300-line rule, stack, data flow, etc.).

Do not skip this step. If `CLAUDE.md` conflicts with a user request, follow `CLAUDE.md` and explain the conflict to the user.

If there is any ambiguity about project conventions, prefer the conventions documented in `CLAUDE.md` over introducing new patterns.
