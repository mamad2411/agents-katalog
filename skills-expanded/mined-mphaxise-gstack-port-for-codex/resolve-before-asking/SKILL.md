# Resolve a name or relationship

Start with the relevant local index, then read the matching source page.
Check dated records and links for disambiguating evidence. If several people
share a name, compare role, organization, time, and a second identifier.
An email domain can suggest a lead. Record the evidence that establishes
the relationship.

Use additional mounted sources only inside the task's access boundary. For
public identities, an official public source can settle a remaining question.
Keep private names and relationship details out of external searches unless
the user has authorized disclosure.

When sources conflict, park the unresolved identity and continue independent
work. If the distinction changes the result, ask one question with the
plausible match, its evidence, and what remains ambiguous. Write a durable
relationship only when the evidence and the user's write scope support it.
