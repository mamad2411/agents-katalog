# Fact-check a draft

Extract each checkable statement, including dates, quotations, counts, and
claims about who did the work. Keep the exact wording beside the evidence.

For a public claim, open the primary record and inspect its date and scope.
Trace a quote to the original speaker. For a claim derived from private data,
reproduce it independently from an authorized source. For example, count
distinct event IDs from the underlying records to check a report total.
Check the relationship that proves authorship when a source establishes only
an affiliation. Keep private terms and records inside the approved environment.

Record a source for each claim. Assign a verdict of verified, likely accurate,
unverified, disputed, likely inaccurate, or false. Explain disagreements and
which evidence would resolve them. Apply corrections when editing is in scope.
Remove or qualify unsupported copy before presenting it as verified. Report
remaining uncertainty alongside the affected claim.
