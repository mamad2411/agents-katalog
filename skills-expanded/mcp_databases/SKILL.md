## Capabilities
- Schema inspection and discovery
- Read-only query execution (safe by default)
- Write operations (configurable)
- Natural language to SQL translation
- Vector search and memory (Qdrant, Redis)
- Business intelligence on SQLite
- Multi-database unified access (DBUtils)
- Spreadsheet manipulation (Excel, Airtable)
