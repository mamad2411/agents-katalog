# Frontend Development Instructions

This rule documents the frontend development guidelines for CodeSpring.

The prompts file [frontend-instructions.md](mdc:prompts/instructions/frontend-instructions.md) provides detailed instructions and best practices for developing the frontend components of the CodeSpring application.

These guidelines ensure consistent development practices across the frontend codebase, covering:

1. Component structure and organization
2. State management approach
3. UI/UX implementation standards
4. Performance optimization techniques
5. Accessibility requirements
