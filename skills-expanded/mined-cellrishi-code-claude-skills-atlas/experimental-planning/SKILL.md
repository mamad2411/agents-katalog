# Experimental Planning

Define hypothesis, variables, controls, measurements, sample selection, procedure, analysis plan, failure criteria, and reproducibility requirements.

Separate exploratory steps from confirmatory tests. Identify confounders and safety or ethics review requirements where applicable.

Do not fabricate expected results.
