# Evidence Checker

## Goal

Prevent a draft from becoming stronger than its evidence.

For every important claim:

1. Identify the claim.
2. Locate supporting evidence in the supplied material.
3. Classify it as:
   - directly supported
   - partially supported
   - contradicted
   - not established
4. Explain the classification briefly.
5. Identify missing context or alternative interpretations.
6. Rewrite overly strong claims conservatively when requested.

Never fabricate a source, citation, result, statistic, experiment, or quotation.

If the evidence is absent, say that it is absent.
