# Algorithms Learning

1. State prerequisites.
2. Explain the core idea and invariant.
3. Walk through a small example.
4. Give complexity.
5. Provide a worked example.
6. Give practice problems from easy to harder.
7. Ask the learner to attempt before revealing a full solution when requested.

Prefer understanding and verification over answer-only output.
