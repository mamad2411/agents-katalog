# Evidence Comparison

Extract the claim, population or system, method, evidence, uncertainty, and limitations from each source. Check whether sources answer the same question. Distinguish primary evidence, secondary analysis, and speculation.

Conclude with what is supported, what remains uncertain, and what evidence would resolve the uncertainty.
