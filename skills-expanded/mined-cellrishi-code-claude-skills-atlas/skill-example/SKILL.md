# Example Skill

## Purpose

Provide a small, concrete model for contributors.

## When to use

Use when creating a new reusable instruction package.

## Process

1. Identify the task.
2. Define inputs and constraints.
3. Apply a repeatable procedure.
4. Verify the result.
5. State limitations.

## Expected output

A concise result containing the requested work and any relevant verification notes.

## Limitations

This is a structural example, not a universal workflow.
