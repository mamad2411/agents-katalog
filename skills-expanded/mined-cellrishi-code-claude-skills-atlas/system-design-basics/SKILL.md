# System Design Basics

Clarify requirements first. Estimate scale only from stated assumptions. Separate functional requirements, non-functional requirements, APIs, data model, architecture, bottlenecks, failure modes, and trade-offs.

Do not present speculative capacity numbers as facts. Explain why each component exists and how it can fail.
