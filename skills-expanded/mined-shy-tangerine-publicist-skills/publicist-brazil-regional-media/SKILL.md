# Brazil regional media matrix

**Scope.** Media across 27 states + Distrito Federal for targeted earned media. Pair with `publicist-brazil`.

---

## Regional media structure

Brazil's media is highly regionalized. National outlets (Folha, Globo, Estadão, Valor) have local bureaus, but each state has dominant local players with distinct editorial calendars and pauta processes.

### National outlets with strong regional presence
| Outlet | Bureaus | Regional Contact |
|---|---|---|
| **Folha de S.Paulo** | SP, RJ, BR, MG, RS, PE, CE, BA | Local editorias via pauta@folha.com.br |
| **O Globo** | RJ, SP, BR, MG, RS | Globo local redações |
| **Estadão** | SP, BR, RJ | sucursais@estadao.com.br |
| **Valor Econômico** | SP, RJ, BR | valor@valor.com.br |
| **G1 (Globo)** | All 27 states | g1.globo.com/estado/ |

## Editorial calendar patterns by region

| Region | Key Annual Events | Pitch Timing |
|---|---|---|
| **SP/RJ** | Year-round | 2-4 weeks ahead |
| **Brasília** | Legislative year (Feb-Jul), Budget (Aug-Dec) | 4-6 weeks for policy |
| **Nordeste** | São João (Jun), Carnaval (Feb/Mar) | Avoid festival weeks |
| **Sul** | Expoagro, Fenadoce, Oktoberfest | 6-8 weeks for events |
| **Minas** | FENAMILHO, Expominas | 4-6 weeks |
| **Agro states (MT/MS/GO/PR/RS)** | Harvest (Jan-Mar), Planting (Sep-Nov) | Seasonal hooks |

## Pauta email templates by region

### National/top tier
```
Para: pauta@folha.com.br (or specific editoria)
Assunto: [Sugestão de Pauta] [Tema]: [Gancho local/regional]

Prezado(a) [Nome do editor/repórter se conhecido],

[1 parágrafo: gancho local + relevância para leitores da região]
[1 parágrafo: fonte/dado/exclusivo disponível]
[1 parágrafo: formato sugerido + porta-voz + disponibilidade]

Disponível para alinhamento por WhatsApp: [número]
Atenciosamente,
[Nome], [Organização], [Telefone/WhatsApp]
```

### Regional (WhatsApp follow-up expected)
```
Enviar e-mail → aguardar 2-4h → WhatsApp: "Oi [Nome], mandei sugestão de pauta sobre [tema]. Viu? Posso mandar mais detalhes por aqui se preferir."
```

## WhatsApp contacts

Many regional editors/reporters list WhatsApp on:
- Twitter/X bios
- LinkedIn profiles
- Matéria assinada (final da reportagem)
- Site do veículo → "Equipe" / "Contato"

Email first. Send a WhatsApp follow-up 2-4 hours later only when the journalist has published that number for professional contact.
