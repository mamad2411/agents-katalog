# German business culture & pitch protocols, Germany market

**Scope**. Cultural/communication protocols for German media engagement. Pair with `publicist-germany` + platform skills.

## Core cultural principles

| Principle | Application |
|---|---|
| **Sie vor Du** | Default: "Sie" + Nachname. "Du" nur auf Angebot des Journalisten (meist nach 2-3 Mails/Call). |
| **Titel beachten** | Dr., Prof., Mag., immer in Anrede/Signatur verwenden. |
| **Direktheit** | Deutsche schätzen Klarheit. Kein "Small Talk" im Betreff/Erster Satz. |
| **Trennschärfe** | PR ≠ Journalismus. Keine Vermischung. Transparenz Pflicht. |
| **Pünktlichkeit/Verlässlichkeit** | Deadlines sind heilig. Zusage = Einhaltung. |

## Anrede & Titel (Der erste Eindruck)

### E-Mail / brief
```
Sehr geehrte Frau Dr. Müller,    (akademischer Grad + Nachname)
Sehr geehrter Herr Professor Schmidt,
Sehr geehrte Frau Chefredakteurin Meier,    (Funktionstitel ok)
```

### Nach Du-Angebot
```
Liebe Frau Müller,    (nur nach eindeutigem Angebot!)
Hallo Herr Schmidt,    (lockerer, nach Beziehungsaufbau)
```

**NG**. "Hallo" als Erstkontakt, "Hi", Vornamen ohne Angebot, "Sehr geehrte Damen und Herren" (anonyme Masse = Spam-Signal).

## Betreffzeile (Entscheidung: Öffnen oder Löschen)

### Formel: `[Kategorie] Konkretes Thema: Nutzen/Neuigkeit`
```
[Presseinfo] Neues KI-Tool für Fertigung: 30% weniger Ausschuss
[Expertenangebot] Dr. Weber zu Lieferkettengesetz: Interview nächste Woche
[Hintergrund] Studie zu deutschen KMU und NIS2: Daten exklusiv verfügbar
[Einladung] Pressegespräch 12.10. in Berlin: Wasserstoff-Strategie
```

### Parameter
- **Länge**. ≤ 50 Zeichen (mobile Vollanzeige)
- **Keine**. "Pressemitteilung", "Presseinfo", "Angebot", "Wichtig", "!!"
- **Absender**. Klarer Name + Organisation im From-Feld (nicht "info@", "press@")

## E-Mail-Knigge (Struktur & Ton)

### Aufbau (DIN 5008 / gängige Praxis)
```
Sehr geehrte Frau Dr. Müller,

[1 Satz: Bezug/Anlass, warum gerade Sie und warum jetzt]
[2-3 Sätze: Kernbotschaft mit Was, Warum und Beleg]
[1 Satz: Konkrete Bitte um Interview, Daten oder Termin]
[1 Satz: Angebot, Kontakt herzustellen oder Unterlagen zu senden]

Freundliche Grüße
[Vorname Nachname]
[Funktion]
[Organisation]
[Telefon mobil, wichtig für Rückfragen]
[E-Mail]
[Website]
```

### Dos & Don'ts
| Do | Don't |
|---|---|
| Kurze Sätze, aktive Verben | Schachtelsätze, Passivkonstruktionen |
| Konkrete Zahlen/Daten | "führend", "innovativ", "einzigartig" ohne Beleg |
| Anhang nur auf Anfrage / Link zu Pressekit | PDF unaufgefordert (Virenangst, Größe) |
| 24h Reaktionszeit bei Rückfragen | Wochenende/Feiertag senden (außer Breaking) |
| "Für Rückfragen stehe ich Ihnen gerne zur Verfügung" | "Bei Fragen melden Sie sich" |

## Timing & Versand

### Optimaler Versandzeitpunkt
| Wochentag | Zeit | Grund |
|---|---|---|
| **Dienstag** | 09:30-11:00 | Redaktionskonferenz vorbei, Posteingang gecheckt |
| **Mittwoch** | 09:30-11:00 | Gleich |
| **Donnerstag** | 09:30-11:00 | Gleich, Themenplanung für Woche/Freitag |
| **Montag** | 10:00-11:00 | Nur wenn dringend (Redaktionskonferenz läuft) |
| **Freitag** | Nicht empfohlen | Wochenende naht, geringe Reaktion |

### Embargo & Vorab-Info
- **Embargo**. "Embargo bis DD.MM.YYYY, HH:MM MESZ", **exakt einhalten**
- **Vorab-Info**. 1-2 Tage vor Wire-Versand an Top-Journalisten (Exklusivität)
- **Kein Embargo-Bruch**, Vertrauensverlust irreparabel

## Follow-up (Nachfass), der deutsche Weg

### Regel: **1x nachfassen, dann Ruhe**
| Zeitpunkt | Inhalt | Ton |
|---|---|---|
| **2-3 Werktage** nach Erstmail | "Erlaube ich mir, kurz nachzufassen..." + **neuer Aspekt** (neues Datum, neue Daten, neuer Experte) | Höflich, nicht fordernd |
| **Keine 2. Nachfass** | entfällt | "Sollte kein Interesse bestehen, kurze Rückmeldung 'nicht relevant' genügt" |

### Muster Follow-up
```
Sehr geehrte Frau Dr. Müller,

erlaube ich mir, kurz nachzufassen: Haben Sie meine Mail vom Dienstag gesehen?

Neu: Wir konnten jetzt auch [neuer Datenpunkt / Kundenstatement / Termin] ergänzen.
Falls das Thema nicht in Ihre Planung passt, reicht ein kurzes "nicht relevant".

Freundliche Grüße
...
```

## Absage / "Nicht relevant", Professionell reagieren

### Auf Absage antworten (immer!)
```
Sehr geehrte Frau Dr. Müller,

danke für die kurze Rückmeldung. Verstehe vollkommen.
Falls sich die Lage ändert oder ein anderes Thema passt: Gerne wieder.
Schönen Tag noch.

Freundliche Grüße
...
```

**Nie**. Nachhaken, argumentieren, "aber...", beleidigt reagieren. Branche ist klein.

## XING / LinkedIn, Deutsche Business-Netzwerke

### XING (deutscher Standard)
- **Profil**. Foto, aktuelle Funktion, Skills "PR", "Medienarbeit", "Pressearbeit"
- **Kontaktanfrage**. **Immer mit Nachricht**, "Sehr geehrte Frau Müller, ich lese Ihre Artikel zu [Thema] regelmäßig. Darf ich Sie für gelegentliche Themen-Updates vernetzen?"
- **Nachricht nach Accept**. "Danke für die Vernetzung. Bei Themen zu [X] melde ich mich gerne. Beste Grüße"

### LinkedIn (internationaler, wachsend)
- Englische Profil-Sprache ok, aber **Nachrichten auf Deutsch** (wenn Gegenüber deutsch)
- Gleicher Ansatz: Persönliche Notiz bei Einladung

### NG auf beiden
- Massen-Einladungen ohne Nachricht
- Pitch in der Einladungs-Nachricht
- "Folgen" statt "Vernetzen" für Journalisten (weniger aufdringlich)

## Pressekits / Unterlagen, Was Journalisten erwarten

### Digitales Presskit (Link, kein Anhang)
| Element | Format | Muss |
|---|---|---|
| Pressemitteilung | PDF + HTML-Text | ✓ |
| Fotos/Logos | ZIP (Print: 300dpi / Web: 72dpi) | ✓ |
| Factsheet | PDF (1 Seite) | ✓ |
| Biografien/Expertenprofile | PDF | ✓ |
| Video/B-Roll | Link (WeTransfer/Drive/Server) | optional |
| Ansprechpartner | Name, Telefon **mobil**, E-Mail | ✓ |

### Anhang-Regel
- **Erstmail**. **Kein Anhang**, nur Link zum Presskit
- **Auf Anfrage**. Gezielt einzelne Dateien (nicht 20 MB ZIP)

## Messen & Events (IFA, IAA, Hannover Messe, etc.)

### Akkreditierung
- **Früh beantragen** (4-6 Wochen vorab)
- **Presseausweis** + Unternehmensbestätigung
- **Pressezentrum** nutzen: Arbeitsplätze, WLAN, Pressemitteilungen abholen

### Vor-Ort-Pitch
- **Termin vorab** (2-3 Wochen vorher via Pressebetreuer)
- **Kurze Slots** (15-20 Min), Journalisten haben straffen Plan
- **Demo/Produkt** bereit, "Anfassen" > "Erklären"
