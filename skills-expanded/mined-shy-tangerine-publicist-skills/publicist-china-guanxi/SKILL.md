# Guanxi (关系) operational protocols, China market

**Scope**. Cultural/relationship layer for journalist engagement. Pair with `publicist-china` + platform skills.

## Theoretical basis (费孝通 差序格局 / 翟学伟 三维度)
- **差序格局**. 亲疏远近圈层, 关系投资按圈层递减
- **三维度**. 情感 + 利益 + 面子, 缺一不可
- **人情投资**. 非物质化趋势 (帮子女升学/接送孩子 > 现金)

## WeChat contact etiquette (首道关卡)

### 加好友备注模板 (必填)
```
姓名 / 公司 / 事由 / 目标媒体/账号
例: 张三 / 某科技公司 / 产品发布合作 / 36氪编辑部
```

### 预热期 (加好友后 3-5 天)
- 读对方朋友圈：了解生活节奏、价值观、敏感点
- 读公众号近期文：掌握选题偏好、文风、商单比例
- 点赞/评论 1-2 条高质量内容 (真诚，非刷存在感)
- **不发任何推销信息**

### 首条沟通话术 (单条、简短、人称)
```
[编辑/运营称呼] 你好，我是[公司]的[姓名]。
关注贵号[具体栏目/文章标题/日期]有一阵了，[具体赞赏点]。
我们有[本地化落地故事/独家数据/专家]，与贵号[近期选题方向]高度契合。
材料已备齐[脱敏数据表/专家中文简历/官方投稿链接]，属于[editorial/企业供稿/付费合作]。
请问是否适合进一步沟通？如需核对，北京时间[时间段]通过贵方官方渠道回复即可。
[姓名] [微信名同公司简称]
```

### 跟进节奏
- **第1次**. 首条发出后 3-5 个中国工作日
- **话术**. "打扰了，上条信息不确定您是否看到。若不合适直接回'不合适'即可，不耽误您时间。"
- **最多 2 次**, 无回应即止，不群发、不批量加好友

## 会面/饭局文化脚本

### 座次学 (主陪/副陪)
- **主陪**. 主人右手边, 最重要客人/最高级别
- **副陪**. 主人左手边, 次重要/负责买单/协调
- **记者/编辑**. 通常安排主陪或主陪对面 (便于交流)
- **公关人员**. 副陪或侧位, 服务、记录、协调

### 敬酒/劝酒话术
- **首轮**. 主人敬全桌 → 主陪回敬主人 → 依次敬主陪/副陪
- **公关敬记者**. "感谢[编辑称呼]长期关注[公司/行业]，这杯替公司敬您，您随意。"
- **不强劝**. "您酒量好/不好我都懂，心意到就行", 给台阶

### 结束信号识别
- **领导"催主食" / "上汤/面"**. 谢幕前奏 → 提前安排结账/叫车/离场借口
- **最后 30 分钟定成效**. 关键承诺/共识落在此时

## 送礼梯度 (安全区间)

| 级别 | 参考金额 | 适用对象 | 形式 |
|---|---|---|---|
| 处/局级 | 1500-3000 | 媒体领导/总编 | 土特产/茶/书籍 + 适度现金 |
| 科/股级 | 800-1500 | 资深记者/编辑 | 土特产/办公用品/餐券 |
| 记者/编辑 | 300-800 | 一线记者/运营 | 伴手礼/咖啡券/定制周边 |

**铁律**. 下级礼值 ≤ 上级 80% (费孝通梯度法则), 超额成负担触发隐性惩罚

### 三阶渗透法 (非现金优先)
1. **帮私事**. 接送孩子、预约挂号、推荐装修/留学/医疗资源
2. **送土特产**. 家乡特产/公司定制周边/有纪念意义的书籍
3. **适度现金**. 红包/购物卡, 最后、最小比例

## 面子守恒定律

### 给面子 > 给利益
- 公开场合不揭短、不纠错、不反驳
- 私下沟通用"请教"而非"指正"
- 让对方在同事/领导面前"有面子"

### 补救算法 (踩雷后)
```
方式 = 随机选择(["假装求助", "超额回礼", "家庭介入"])
执行力度 = min(原金额×2, 月收入×0.3)
生成仪式感事件(时机, 方式, 执行力度)
```

## 长线关系维护 (Nurturing)

### Meltwater 葛然 4步法 (验证有效)
1. **找到合适 Influencer** (记者/专家/策展人/博主)
2. **发布深度行业报告**, 为他们提供优质内容素材
3. **Nurturing**, 做朋友，非工具人；记住生日/晋升/调动/孩子考试
4. **持续新闻点**, 非单次发稿，建立长期内容日历

### 实操清单 (季度)
- [ ] 春节/中秋/生日: 微信红包(200-500) + 语音/视频通话
- [ ] 重大选题前: 主动提供独家线索/数据/专家 (不求回报)
- [ ] 对方晋升/调动/获奖: 当日祝贺 + 小礼
- [ ] 自己有重大发布: 独家先给核心关系记者
- [ ] 记者跳槽: 关系随人走，维护新单位联系

## 禁忌清单 (红线)
- ❌ 批量加好友 / 群发消息
- ❌ 首条就发稿件/要版面/要联系方式
- ❌ 送礼超梯度 / 现金比例过高
- ❌ 公开场合让记者/编辑难堪
- ❌ 承诺"保发" / "保首页" / "保阅读量"
- ❌ 把 ProfNet/采访需求 转成 通用推销名单
- ❌ 微信群叫卖 / 朋友圈发商单广告
