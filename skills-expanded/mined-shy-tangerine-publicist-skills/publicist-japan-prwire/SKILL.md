# Kyodo News PR Wire (共同通信PRワイヤー), Japan market

**Scope**. Japan's premier wire distribution service (共同通信グループ). Pair with `publicist-japan` + `publicist-japan-kishaclub`.

## Service overview
- **Operator**. 株式会社共同通信ピー・アール・ワイヤー (共同通信グループ全面バックアップ)
- **Positioning**. "数よりも価値を届ける", 信頼性・中立性・正確性・速報性重視
- **Article pickup rate**. ~70-77% (業界No.1)
- **Domestic reach**. ~2,500媒体・~4,000カ所配信先 / 提携メディア~70サイト(うち55全リリース転載)
- **Overseas reach**. 世界150万ヶ所・35,000媒体 / AsiaNet(アジア太平洋) + PR Newswire(欧米他)
- **Translation**. 英文チェック(JBN) → 各国通信社 → 現地語翻訳 → 現地メディア配信

## Acceptability standards (配信前審査)
- **入会審査**. 全会員企業実施, 信頼ある企業のみ登録、お断りケースあり
- **配信前チェック**. 共同通信PRワイヤー内規 + プレスリリース取扱基準
- **抵触判断時**. 適用見送り or 掲載後削除の可能性
- **基準公開**. `kyodonewsprwire.jp/corp/acceptability_standard/`

## Distribution channels (国内)
1. **メディア配信**, メール/FAX/専用Web/提携メディア約70サイト
2. **提携メディア転載**, 51サイト全リリース転載、16サイト一部転載
3. **SNS配信**, X/Facebook/一部Instagram
4. **ニュースサイト・クリッピング** (無料), 国内約2,000サイト掲載・転載レポート

## Usage protocol

### Pre-distribution checklist
- [ ] **会員登録** (入会審査通過済み)
- [ ] **原稿準備**. 日本語/英文、誤字脱字チェック、メディア視点で校正済み
- [ ] **分類判定**. `editorial` / `企業供稿` / `分発`, リリース内で明示
- [ ] **カテゴリ選択**. 国内159種・海外14種から適切選択
- [ ] **入稿締切**. 配信同時刻1営業日前 (余裕持った計画必須)

### Distribution flow
1. **入稿** → 専用Web/メール/専任スタッフ
2. **審査** (内規+基準) → 通過/修正指示/見送り
3. **配信** → 選択チャネル(メディア/提携/SNS/海外)
4. **レポート**, クリッピング/アクセス解析/記事掲載結果/広告換算値

### Wire vs. club vs. direct
| Channel | Role | When to Use |
|---|---|---|
| **PR Wire** | Broad guaranteed delivery + SEO (提携サイト転載) | Formal announcements, earnings, major launches, crisis |
| **記者クラブ投げ込み** | Targeted to beat reporters + briefing opportunity | Industry-specific, needs journalist Q&A |
| **個別ピッチ** | High-touch, exclusive, relationship-building | Feature stories, expert positioning, sensitive topics |

**Complementary**, not substitutes. Wire for record/SEO/reach; Club for access; Direct for depth.

## Compliance checklist
- [ ] 会員資格維持 (年会費/審査)
- [ ] リリース分類明示 (`editorial`/`企業供稿`/`分発`)
- [ ] 審査基準適合 (誇大/虚偽/誤解招く表現不可)
- [ ] 海外配信時: 英文JBNチェック → 現地語翻訳プロセス理解
- [ ] APPI/個人情報: 記者連絡先等を海外CRM/モデルに入れない
- [ ] 特定電子メール法: 商業性メール判定・オプトアウト表示確認
