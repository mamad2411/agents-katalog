# German press clubs (Presseclubs), Germany market

**Scope**. Germany's press club ecosystem for accreditation, networking, and press conference access. Pair with `publicist-germany`.

## Press club system

| Club | Location | Focus | Membership |
|---|---|---|---|
| **Bundespressekonferenz (BPK)** | Berlin | Federal politics, government briefings | ~500 print + 100+ online correspondents; hauptberuflich tätig |
| **Forum Deutscher Presseclubs** | Nationwide | Umbrella org for 40+ clubs | Member clubs only |
| **Deutscher Presseclub** | Berlin | General, 60+ years | Journalists, media professionals |
| **Frankfurter PresseClub** | Frankfurt | Business/finance | Journalists in Rhine-Main |
| **Kölner Presseclub** | Köln | Regional/Rhenish | Active journalists in Köln/Rheinland |
| **Hamburger Presseclub** | Hamburg | Media hub, agencies | NDR, Spiegel, Zeit, agencies |
| **Münchner Presseclub** | Munich | Bavaria, industry | BR, SZ, agencies |
| **Landespressekonferenzen** | State capitals | State politics | Landtag-accredited |

## Membership requirements (typical)
- **Hauptberufliche journalistische Tätigkeit** (full-time journalism)
- **Redaktionelle Unabhängigkeit** (editorial independence)
- **Mindestens 1 Jahr Berufserfahrung** (1+ years experience)
- **Empfehlung durch 2 Mitglieder** (sponsored by 2 members)
- **Aufnahmegebühr + Jahresbeitrag** (fees vary €50-300/year)

**Foreign correspondents**. Separate category (ausländische Korrespondenten), require Akkreditierung via Auswärtiges Amt.

## Club services for members
- **Arbeitsplatz/Infrastruktur**. Schreibtische, WLAN, Telefon, Drucker
- **Veranstaltungen**. Hintergrundgespräche, Podiumsdiskussionen, Pressekonferenzen
- **Presseausweis**. BLE-Presseausweis (via Deutsche Journalisten Agentur)
- **Netzwerk**. Jobbörse, Versicherungen, Fortbildungen, Rechtsberatung
- **Akkreditierungshilfe**. Bei Behörden, Messen, Events

## Access for PR professionals (non-members)

### Pressekonferenzen at clubs
- **BPK**. Regierungspressekonferenzen (Regierungssprecher, Minister), **offen für akkreditierte Journalisten**
- **Landespressekonferenzen**. Ministerpräsidenten, Landesminister
- **Frankfurter/Münchner Clubs**. Wirtschaftspressekonferenzen (Unternehmen, Verbände)
- **Club-eigene Events**. Nur für Mitglieder + geladene Gäste

### Press club as venue (venue hire)
- Clubs vermieten Räume für **externe Pressekonferenzen**
- **Voraussetzung**. Themenrelevanz, journalistisches Interesse
- **Kosten**. Raummiete + Technik + Catering (€500-3000)
- **Vorteil**. "Neutraler Ort", Journalisten kommen eher

## Protocols for PR at press clubs

### Organizing a press conference at a club
1. **Club kontaktieren** (Geschäftsstelle), Thema, Datum, erwartete Teilnehmerzahl
2. **Relevanz prüfen**, Club entscheidet ob "journalistisch relevant"
3. **Einladung via Club-Verteiler**, Club versendet an Mitglieder (Glaubwürdigkeit++)
4. **Technik/Logistik**, Club stellt Raum, Ton, Video, Streaming
5. **Presseausweis-Kontrolle**, Einlass nur mit gültigem Ausweis

### Pitching to club members (indirect)
- **Nicht direkt an Mitglieder mailen**, Club-Verteiler nur für Mitglieder
- **Weg**. Eigene Pressekonferenz im Club → Mitglieder berichten
- **Alternative**. Hintergrundgespräch mit Club-Vorstand → Weitergabe an relevante Ressorts

## Accreditation (Akkreditierung) for events
| Event Type | Via | Requirements |
|---|---|---|
| **Bundesregierung** | BPK | Presseausweis + Online-Akkreditierung |
| **Bundestag** | Bundestagsverwaltung | Akkreditierungsantrag + Ausweis |
| **Messen (IFA, IAA, etc.)** | Messe-Veranstalter | Online-Portal + Nachweis journalistischer Tätigkeit |
| **Sport (Bundesliga, etc.)** | DFL/Verband | Saison-/Einzelakkreditierung |
| **Konzerne (SAP, Siemens, etc.)** | Unternehmenskommunikation | Einladung + Ausweis |

## Key differences vs. Japan Kisha clubs
| Dimension | Germany (Presseclubs) | Japan (Kisha Clubs) |
|---|---|---|
| **Structure** | Voluntary associations (Vereine) | Institutionalized, in-ministry |
| **Membership** | Individual journalists | Media organizations |
| **Access** | Club events + venue hire | Daily briefings, exclusive access |
| **Government link** | BPK independent, government-funded | Clubs inside ministries |
| **Exclusivity** | Low (many clubs, open events) | High (closed, cartel-like) |
| **Foreign access** | Foreign correspondent category | FCCJ separate, limited |
