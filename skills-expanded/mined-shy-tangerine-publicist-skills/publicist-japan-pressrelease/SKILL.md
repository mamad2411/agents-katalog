# Japan press release distribution services, selection guide

**Scope**. Domestic wire/comparison for Japan earned media. Pair with `publicist-japan` + `publicist-japan-prwire` + `publicist-japan-kishaclub`.

## Service comparison matrix (2024-25 verified)

| Service | Operator | 提携媒体 | 単発料金 | 定額/月額 | 強み | 弱み | Best For |
|---|---|---|---|---|---|---|---|
| **PR TIMES** | 株式会社PR TIMES (東証プライム) | ~230 | ¥30,000~ | ¥70,000~/月 | 国内シェアNo.1、上場企業43%利用、SNS拡散強、PV 8,900万 | 個別記者コンタクトは上位プランのみ | 幅広いリーチ、スタートアップ(2年無料枠)、一般消費者向け |
| **@Press** | ソーシャルワイヤー株式会社 | ~80 | ¥30,000~ (ライト) | ¥59,800 (スタンダード) | 記事化率No.1うたう、専任担当者一貫サポート、メディアリスト作成代行 | 提携数PR TIMESより少ない | 記事化重視、初心者、BtoB/専門領域 |
| **ValuePress** | 株式会社バリュープレス | ~40 | ¥30,000~ (エコノミー) | ¥35,000~/月 (スタンダード) | 利用社数最多、プロ原稿作成・添削、記者個別コンタクトプランあり | 提携媒体数少ない | 中小企業、原稿作成支援必要、コスパ重視 |

## Selection decision tree

```
目的 → 推奨サービス
├─ 最大リーチ + SNS拡散 + スタートアップ無料枠 → PR TIMES
├─ 記事化率重視 + 手厚いサポート + 原稿チェック → @Press
├─ 原稿作成支援 + 記者個別コンタクト + コスパ → ValuePress
├─ 信頼性/中立性 + 海外配信 + 翻訳 + 大企業/公共 → 共同通信PRワイヤー
├─ 予算最優先 + 頻繁配信 + SEO長尾 → Dream News
├─ PR業務自動化 + FAX + クリッピング + 予算大 → Digital PR Platform
└─ 複数併用 (2割/8割の配分) → 2割をPR TIMES/@Pressに、8割をValuePress/Dream Newsに配分
```

## Usage protocols (common)

### Pre-distribution
- [ ] **原稿準備**. 日本語タイトル/リード/本文/連絡先/会社概要/画像/動画
- [ ] **分類**. `editorial` / `企業供稿` / `分発`, リリース内明示
- [ ] **カテゴリ**. 各サービスの分類コードから適切選択
- [ ] **入稿締切**. 配信希望日 1営業日前 (共同通信PRワイヤー等) 〜 当日AM (PR TIMES等)
- [ ] **審査**. 各社基準 (誇大/虚偽/誤解招く表現不可), 通過前は配信されない

### Post-distribution
- [ ] **クリッピング/レポート**. 掲載サイト/記事化結果/アクセス解析/広告換算値
- [ ] **個別ピッチ併用**. リリース配信 + 重点記者へ個別メール (記事化率大幅UP)
- [ ] **効果測定**. PV/掲載数/問い合わせ/売上貢献, 次回計画に反映

## Wire + Club + Direct = 三位一体

| Layer | Tool | Role | Timing |
|---|---|---|---|
| **1. Wire** | PR TIMES / @Press / 共同通信PRワイヤー | 公式記録 + SEO + 広域配信 + 提携サイト転載 | 発表日 0:00 / 朝一 |
| **2. Club** | 記者クラブ投げ込み | 担当記者へ直接届く + ブリーフィング機会 | 発表日 AM (先行/同日) |
| **3. Direct** | 個別ピッチメール/電話 | 独占/深堀り/関係構築 | 発表前/直後 (媒体別) |

**Never rely on wire alone.** 記事化は「配信」≠「取材」。個別アプローチが不可欠。

## Compliance checklist
- [ ] リリース分類明示 (`editorial`/`企業供稿`/`分発`)
- [ ] 特定電子メール法: 商業性判定・送信者明示・オプトアウト
- [ ] 景品表示法: 誇大/虚偽/根拠なし優良誤認不可
- [ ] APPI: 記者個人情報の海外持ち出し禁止
- [ ] 業法: 金融/医療/薬事/建設等, 事前確認必須
- [ ] 共同通信PRワイヤー: 入会審査/配信前審査/取扱基準遵守
