# Japanese business culture & pitch protocols, Japan market

**Scope**. Cultural/communication protocols for Japanese media engagement. Pair with `publicist-japan` + platform skills.

## Core cultural principles

| Principle | Application |
|---|---|
| **建前と本音** (Tatemae/Honne) | Public politeness ≠ private intent; read silence as potential reluctance |
| **面子** (Face) | Never embarrass journalist publicly; give graceful exit paths |
| **おもてなし** (Omotenashi) | Anticipate needs: provide materials early, respect deadlines, offer interpreter |
| **縁** (En - connections) | Warm intro > cold pitch; FPCJ/PR agency/partner referral > direct |
| **謙遜** (Kenkyo) | Modesty in claims; "微力ながら" / "恐縮ですが" over "自信あります" |

## 名刺交換 (Meishi), first physical contact

### Procedure
1. **立って両手で渡す**, 自分の名刺を相手より低い位置で
2. **相手の名刺を受け取ったら**. 目を通し、「田中様ですね、よろしくお願いいたします」と確認
3. **机上に整列**, 会議中は席順通りに並べて置く（ポケット即入れNG）
4. **自分の名刺**. 日本語面と英語面を用意し、役職・部署・携帯電話・メールアドレスを記載

### Media-specific
- **記者の名刺**. 「記者」「編集委員」「デスク」「キャップ」等の肩書き確認
- **フリーランス**. 「フリーランス記者」「ライター」, 媒体名確認必須

## アポイント取得 (Appointment), email/phone

### メール件名 (20-30字、スマホ全文表示)
```
【取材依頼】〇〇プロジェクトについて / 株式会社〇〇 広報 田中
【インタビューのお願い】貴紙〇月〇日号特集に関連し / 田中
【情報提供】貴番組〇月〇日放送予定の件 / 株式会社〇〇 田中
```
**NG**. 「プレスリリース」「ご案内」「お知らせ」のみ, 秒殺される

### メール本文構成 (400字以内)
```
田中太郎 様
いつもお世話になっております。株式会社〇〇 広報の田中太郎でございます。

貴紙〇月〇日付「〇〇特集」を拝読し、弊社の〇〇が貴紙の読者層にとって有益と存じ、ご連絡差し上げました。

弊社では[具体的な成果/データ/事例]を実現しており、〇〇様のご専門分野と高い親和性がございます。
つきましては、[取材形式: 対面/オンライン/電話]にて〇〇様のお時間を30分ほどいただけますと幸いです。

お忙しいところ恐縮ですが、ご検討のほどよろしくお願い申し上げます。

株式会社〇〇 広報部 田中太郎
TEL: 03-xxxx-xxxx / Mobile: 090-xxxx-xxxx
Email: tanaka@xxxx.co.jp
```

### 送信タイミング
- **最適**. 火・水・木 午前 10:00-11:00 (編集会議直後)
- **避ける**. 月曜AM (会議多)、金曜PM (締切)、祝前日、年末年始/盆/ゴールデンウィーク

### 電話フォロー (メール送信後)
- **当日〜翌日**. 「メールお送りしました、ご確認いただけますか」
- **記者は電話好き**, 締切間際はメールより電話

## 取材当日・フォローアップ

### 対面取材
- **時間厳守**. 5分前到着
- **資料**. 印刷版 + データ版 (USB/クラウド) 両方用意
- **録音/録画**. 事前確認・了承取得
- **携帯番号必須**, 記者「夜間でも連絡取れる安心感」

### オンライン取材
- **ツール明記**. Zoom/Meet/Teams + 事前接続テスト
- **録画了承**. 明示的同意
- **代替手段**. 通信トラブル時の電話切り替え手順

### フォローアップ (返信なし時)
- **初回**. 3-5営業日後、追加情報付きで1回のみ
  ```
  お忙しいところ恐れ入りますが、先日お送りした取材の件についてご確認いただけますと幸いです。
  追加で[新データ/専門家コメント/現場取材可能日程]をお伝えできます。
  ご多忙であれば「不必要」とご一報いただけますと助かります。
  ```
- **2回目以上**. しない (迷惑メール扱いリスク)

### 断られた時
```
ご丁寧にご返信いただきありがとうございます。
現在ご多忙のためご対応が難しいとのこと、承知いたしました。
また機会がございましたら、その際はぜひよろしくお願い申し上げます。
今後のご活躍をお祈り申し上げます。
```
**感謝 → 理解 → 将来への布石**, 関係を切らない

## 取材後・お礼

### 24時間以内お礼メール (必須)
```
本日は貴重なお時間をいただき、誠にありがとうございました。
特に[具体的な話題/発言]についてのお話は、多くの読者にとって参考になると感じました。

いただいたお話をもとに、〇月末の掲載に向けて記事を作成いたします。
掲載前には原稿をお送りし、内容のご確認をお願いする予定です。
（ファクトチェックのみ、表現の修正はご遠慮ください）

引き続きよろしくお願い申し上げます。
```
**ポイント**. 具体的言及 + 掲載スケジュール + ファクトチェック提案

### 掲載後
- **記事URL/紙面PDF** 共有 + 感謝
- **SNS拡散** (許可確認済みなら)
- **次回ネタ** の種まき: 「次は〇〇テーマでお声がけできれば」

## 季節・ライフイベント (関係維持)

| Timing | Action |
|---|---|
| **年始** (1/1-1/7) | 年賀メール/カード: 「本年もよろしく」+ 自社トピック予告 |
| **春** (3-4月) | 異動/昇進確認 → 新担当者へ引き継ぎ挨拶 |
| **夏** (7-8月) | 暑中見舞い: 手書きハガキ/メール |
| **秋** (9-10月) | 年賀状準備/敬老/秋の特集ネタ提案 |
| **年末** (12月) | 年末挨拶: 「本年は大変お世話に」+ 来年予告 |
| **記者誕生日/昇進/受賞** | 当日メール/カード，「おめでとうございます」のみ |

## 禁忌 (タブー)

| NG | 理由 | 代替 |
|---|---|---|
| 一斉CC/BCCピッチ | 信頼喪失、個人情報漏洩 | 1名ずつ個別送信 |
| 「プレスリリース」件名 | 営業メール即判定 | 具体的件名 |
| 添付のみ本文なし | 開く手間=負担 | 本文リード+リンク |
| 初回から長文/資料山盛り | 読まない | 核心のみ、興味あれば追加 |
| フォロー2回以上 | 迷惑=関係断絶 | 1回のみ、柔らかく |
| 断りに反論/食い下がる | 面子潰し=永久拒絶 | 感謝+理解+将来 |
| 掲載前原稿の表現修正要求 | 編集権侵害 | ファクトチェックのみ |
| 記者の私用携帯へ深夜連絡 | プライバシー侵害 | 緊急時のみ、事前了承済みなら |
