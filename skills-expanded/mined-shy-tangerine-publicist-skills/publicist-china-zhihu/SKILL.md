# Zhihu (知乎), China market

**Scope**. Only 知乎 editorial/expert engagement. Pair with `publicist-china`.

## Platform rules (verified)

### Community norms (核心红线)
- **鼓励**. 真诚表达、专业讨论、友善互动
- **反对**. 不友善、低质、低俗、抄袭、侵权、虚假认证、**恶意营销导流**
- **机构号规范 (试行)** 禁止:
  - 邀请用户代发软文/硬广
  - 准备稿件邀请用户发布
  - 邀请用户点赞/评论/关注指定内容
  - 邀请用户提出指定问题
  - 恶意引流优质用户

### 恶意营销行为 (自动重拳)
- 多次发布含联系方式/推广链接的低质内容
- 同一回答多问题重复发布
- 短时间内大量私信邀请活动/推广产品
- 利用提问做产品推广/介绍
- 短时间内大量发布重复/相似品牌曝光提问

### 处罚机制
- 盐值/权重大幅缩水 (不可逆)
- 回答折叠、限流、禁言
- 严重者永久封禁
- 关联公司被罚 (北京智者天下科技 2021/2017 两次被罚)

### 商业化路径 (官方)
- **知+** / 商业插件, 广告纳入生态闭环
- 伪装成"硬核测评"的软文打击力度极大
- 一旦被用户举报或系统判定为违规广告 → 盐值权重缩水甚至永久禁言

## Pitch protocol

### Pre-pitch verification
1. **Account type**. 个人号 vs 机构号 (不同规范)
2. **Expertise verification**. 专业资质认证 (医生/律师/教授/工程师等), 高权重
3. **Content history**. Read last 20+ answers for beat, depth, tone, commercial ratio
4. **Salt value (盐值)**. High 盐值 = 高权重 = 更难商业化但更可信

### Editorial engagement (non-commercial)
- **Source requests**. Match expert to live question (知乎提问/圆桌/想法)
- **Proactive expert positioning**. Provide unique data/insight for high-follow questions
- **Format**. Deep answer (1000+字), structured, cited, limitation-acknowledged
- **No links** in answer body (引流=违规); bio/profile only

### Commercial engagement (if absolutely needed)
- **Only via 知+/官方商业插件**, zero private deals
- **明确标识**. "包含商业推广" / #广告
- **Creator must disclose**. 品牌合作关系
- **Risk**. Community hostile to covert marketing; backfire probability high

## Compliance checklist (per pitch)
- [ ] No contact info/links in answer body
- [ ] No duplicate answers across questions
- [ ] No private message solicitation
- [ ] Expert credentials verified (专业资质认证优先)
- [ ] Commercial → 知+平台内闭环 + 明确标识
- [ ] 敏感领域 (医疗/金融/法律) → `NEEDS_REVIEW` + 法务确认
- [ ] No "guaranteed ranking/upvote" promises
