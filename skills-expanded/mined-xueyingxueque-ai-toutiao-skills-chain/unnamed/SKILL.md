# 选题炼金 v1.0.0

**职责**：把素材清单变"能爆的选题"——基因匹配 + 打分排序 + 定角度和标题。**选题层是整条流水线的价值核心，素材本身不决定爆不爆，角度决定。**

> **来源**：AI今日头条副业引擎 references/01-选题爆款手册.md 独立而成（完整方法论见该文件）。

## 工作流

**Step 1：初筛淘汰**——纯融资没亮点 / 太小众 / 过 72h 峰值 / 与受众无关 → 淘汰
**Step 2：四基因匹配**——情绪钩子 / 信息差 / 身份标签 / 行动触发；命中 < 2 条 → 淘汰
**Step 3：8 维打分**——情绪/传播/独家/身份/时效/密度/实用/安全，每项 1-5 分总分 40；≥35=核弹级全形态 / 30-34=合格 / 24-29=边缘 / <24=淘汰
**Step 4：定角度 + 3 个候选标题**——12 大公式各用一套，选 1 个主推（**主推标题即结论前置，能抛冲突的优先**）
**Step 5：排序入选**——Top N（默认 8-12 条）；全形态范围以 06 账号规格为准（ai_daily=8 条精选）

## 验收标准（上级核对）

- 每条入选选题：8 维打分 ≥30 + 命中基因 ≥2
- 主推标题 = 结论前置，能抛冲突
- 分数/基因记录完整（发布前可删）
