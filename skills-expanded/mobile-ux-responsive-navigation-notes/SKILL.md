# Mobile UX + responsive navigation notes

## Sources reviewed / adapted

- `cline/skills` — reviewed README and `frontend-design` skill for production-grade frontend polish and anti-generic design guidance.
- `VoltAgent/awesome-agent-skills` — reviewed curated skill quality standards and security notice; used the principle of selecting/adapting only relevant guidance, not importing whole repositories.
- `travisvn/awesome-claude-skills` — reviewed references to frontend/design skills and the idea of lightweight contextual skills.

## Applied principles

- Prefer a focused project-local skill over copying unrelated repositories.
- Keep the skill scoped to the actual task: mobile-only responsive navigation for HTML/CSS/Vanilla JS.
- Prioritize accessibility state, touch targets, reduced motion, no overflow, and theme preservation.
- Avoid generic/mobile-slop design: use restrained, cohesive, premium surfaces and purposeful spacing.
- Keep desktop layout untouched by placing visual changes in mobile media queries.
