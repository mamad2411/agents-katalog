# Sound & Pacing Craft (声音与节奏工艺)

## 职责与定位

把普通解说视频的“平淡念白与杂乱背景”重塑为具有电影感与沉浸感的高级视听体验。
解决知识/技术视频中最普遍的五大顽疾：
1. **语速轰炸**：旁白无停顿连珠炮吐字，观众认知过载；
2. **音效被淹没**：音效与旁白抢夺中频，瞬态模糊不清；
3. **录屏恶性循环**：短录屏无脑 `loop` 4~6 次，视觉抽搐廉价；
4. **文字不可见**：Callout 卡片遮挡背景重要操作，文本对比度达不到无障碍标准（如 < 2:1）；
5. **长视频渲染爆炸**：未压缩帧写盘耗尽磁盘几十 GB 临时空间导致崩溃。

## 核心法则与工程基准

### 1. 音效设计三大铁律 (The Three Rules of SFX)
* **时间要预判 (Lead-in -15ms)**：位移类音效（Whoosh / Sweep）必须比画面视觉切点提前 **10 ~ 20ms（推荐 15ms）** 触发。人耳对瞬态的感知优先于视网膜，提前进入能让大脑产生“被声音拉扯过去”的丝滑运动感。
* **落点要精准 (Frame Anchor)**：到达类音效（Impact / Tap / Hit）的峰值撞击瞬态必须严格钉在**物理动效真正缓动归零（停住）的那一帧**。早半帧则显得抢拍轻浮，晚半帧则显得动作拖沓。
* **层级要让位 (Ducking & Isolation)**：
  * **旁白说话时**：背景环境声（Texture）与音效中频（500Hz ~ 3kHz）必须主动下潜 **-6dB**（Ducking）；
  * **演示音效时**：旁白必须绝对“闭嘴”，留出 **0.8s ~ 1.2s 的纯音效真空期**，让观众听清声音的质感与力量。

### 2. 语速黄金区间与声学测算 (Pacing Metrics)
* **量化测算公式**：
  $$\text{CPM (Char Per Minute)} = \frac{\text{字数}}{\text{总时长 (秒)}} \times 60$$
  $$\text{CPS (Char Per Second)} = \frac{\text{字数}}{\text{总时长 (秒)}}$$
* **行业基准**：
  * **危险过快（机关枪式）**：$\ge 380$ CPM（$> 6.3$ CPS），信息无法沉淀，听众极度疲倦；
  * **普通播报**：$330 \sim 360$ CPM（$5.5 \sim 6.0$ CPS）；
  * **科技解说黄金区间**：$\mathbf{260 \sim 300\text{ \textbf{CPM} (4.3 \sim 5.0 CPS)}}$。声音沉稳、清晰、有留白与高级感。

### 3. 意群切片与原生 PCM 静音注入 (The Chunking Method)
**切忌直接用算法拉伸全局音频（Pitch/Tempo Stretch 会导致电音与失真）**。正确做法是**“意群切片 + 精确插入二进制静音”**：
* 将整段文案拆解为 10~25 字的独立意群短句进行 TTS 合成（避免神经网络在长文本中自回归暴冲与吞音）；
* 在分句之间根据视听需要，拼接对应毫秒数的零采样二进制数据（如 22050Hz 16-bit 格式下，1 秒静音 = 44,100 字节 `b'\x00\x00'`）：
  * **0.5s ~ 0.6s**：段落小分句换气；
  * **0.8s**：核心概念提出后的记忆吸收停顿（配合画面卡片弹出）；
  * **1.0s ~ 1.2s**：演示 Whoosh / Tap / Impact / Glitch 时的纯听音真空期；
  * **1.5s**：章节转换或升华金句转折点。

### 4. 真实录屏定格法则 (Freeze-Frame on Final State)
* 4~7 秒的真实操作录屏（如命令行、PR 审查、工具配置、看板）绝不循环播放；
* 使用 ffmpeg `tpad=stop_mode=clone:stop_duration=...` 扩展素材时长，操作动作执行完毕后**平稳定格在最终完成态**；
* 背景录屏添加径向暗角遮罩（`footage-scrim`），使其沉淀为高质感背板，衬托前景 Callout。

### 5. 高对比度视觉包装标准 (WCAG AA)
* 浮层卡片必须采用半透明毛玻璃系统：`rgba(10, 16, 24, 0.92)` 配合 `backdrop-filter: blur(16px)` 与细边框（`rgba(255, 255, 255, 0.16)`）；
* 文字颜色严禁使用低饱和暗灰，正文使用 `#d1dbe0`，高亮使用品牌色（`#38e8d8`、`#ffb75c`、`#ff6f61`）；
* 必须通过 `hyperframes check` 的 WCAG AA 校验（对比度 $\ge 4.5:1$，推荐 $\ge 8:1$）。

### 6. 长视频流式压制 (Streaming Encode Pipeline)
* 超过 3 分钟（或超过 6,000 帧）的 1080p 视频渲染，避免全量未压缩 PNG 写盘（易耗尽 80+ GB 临时空间）；
* 必须配置流式编码管道（如设置 `PRODUCER_STREAMING_ENCODE_MAX_DURATION_SECONDS=600` 或 `--low-memory-mode`），将浏览器画面直通 pipe 给 ffmpeg 实时压制。

## 标准制作执行清单 (Checklist)

1. [ ] **语速审计**：统计分镜字数与秒数，确认 CPM 是否处于 260~300 区间，标记峰值场景；
2. [ ] **意群拆分**：将长段旁白按 10~25 字拆分为短意群，并在关键名词前后保留标点；
3. [ ] **音频合成**：单句合成并注入 0.5s ~ 1.2s 精确声学静音，导出分镜音轨；
4. [ ] **录屏定格**：使用 ffmpeg `tpad` 将短录屏补长至目标分镜时长，杜绝 `loop`；
5. [ ] **音效打点**：在静音留白期内绑定 SFX，Whoosh 提前 15ms，Impact 卡点目标帧；
6. [ ] **视觉校验**：深色毛玻璃卡片排版，确保文本对比度 100% 达标 WCAG AA；
7. [ ] **流式导出**：配置环境变量启用流式编码管道，直接完成最终视频压制。
