# 非真人机制推演

仅参考 claudework 的非真人图解部分，不复制其品牌、数字或技术结论。无需原片或 motion-skills 即可使用本文。先确定解释对象，再选下列场景。不使用真人出镜或真人旁叠加图形。

## 输入与视觉系统

输入：旁白、机制的真实节点和条件、可追溯数据、配置示例。输出：分镜、元素清单、状态序列、语音锚点、可随机定位的动画。

图解用浅色底、深色细线与少量语义强调色。图形主体占画面约 65%-85%；标题保持短。节点必须包含对象名称或动作，线必须说明方向。颜色不能是唯一的信息载体。示例尺寸比例是创作建议，不是原片测量结果。

## 四种模板

| 模板 | 场景步骤 | 替换槽位 | 交接方式 |
| --- | --- | --- | --- |
| P2 机制逐层展开 | 起点 → 当前条件节点 → 画出分支 → 激活实际路径 → 扩展新规则 → 返回总览 | nodes、edges、conditions、selectedPath | 保留已有节点坐标，扩展时整体缩放；回路回到真实起点 |
| P3 上下文筛选 | 左列原始信息逐条出现 → 相关行高亮 → 对应连线 → 右列接收筛选结果 → 正反例判定 | sourceRows、includedIds、verdicts | 复用行对象 ID，保持来源和去向可追踪 |
| P4 数字证据 | 坐标和单位 → 第一组条形 → 第二组条形 → 差异标注 → 来源说明 | values、units、baseline、source | 柱高由数据计算，不能把零值画成非零柱 |
| P5 配置定位 | 文件全貌 → 聚焦相关行 → 逐项展开值 → 标出冲突 → 给出更改后的结果 | filename、code、focusLines、beforeAfter | 移动代码视窗，行高与光标坐标统一 |

## 可执行的动效设计

P2 建立稳定图坐标，节点出现后才画相关边，边的进度 p 同时驱动前缘标记。出现新分支时先为其腾出空间，再显示节点，避免整图重排导致对象跳位。使用 SVG path 或既有图布局库；每个节点和边都有稳定 ID。反馈路径使用弧线绕开正文。

P3 每行记录 sourceY、targetY 和 inclusion；非相关行淡出，相关行沿连接方向迁移。不要把所有行一起淡入成一张静态表。完整列表和筛选列表必须由同一数据生成。

P4 条形增长和数值变化共用 p；相同比例尺，最终数值停稳供读。P5 高亮矩形从代码行框计算，不用手猜像素；摄像机与高亮共用坐标变换。代码太长先删去无关部分，不靠缩到不可读来塞满画面。

每段写出 enter、develop、resolve 三个状态及旁白锚点。建议一次节点或行的变化用 0.25-0.6 秒，读图时间由内容决定；这些是起始调参值，不是原片节奏复刻。以完整判断、分支或反馈作为分段依据，不以固定秒数切割。纯图解长段必须随着机制发展更新节点、路径或聚焦点。

## 同步与验收

本项目旁白用 CosyVoice，先生成最终音频，再用 Seqvio 的实际对齐结果定位关键语句；只有 cue 时长不代表逐词对齐。节点出现对齐所指对象的首次提及，路径激活对齐因果动作，音效对齐视觉事件帧。记录采样率、帧率及实测误差。

检查图路径是否符合机制、对照是否同一尺度、被移除信息是否仍可解释、配置是否有效。随机定位和顺序播放必须得到同样状态。调试节点 ID、场景编号和进度文本只写入验收报告，不进入成片。
