# 几何关系解说

## 风格与素材

参考 eleven：0–13s 抽象开场，13–31s 流程，35–47s 指标与迭代，47–65s 控制与系统，65–71.141s 收束。

主要信息区是接近白色的留白画布、细连线、小标签、少量黑色交互节点。深色开场与浅色解释形成章节反差。曲面材质只附着于代表系统实体的主体，不能随意撒装饰球。没有实体语义时采用线/图形关系即可。

槽位：`entities[]`、`edges[]`、`selectedRoute`、`request`、`toolStates[]`、`measuredData`、`variantResults`、`result`。所有数据/认证使用本项目证据；原片数字只作为来源画面观察。

## G1：同一形体的连续变换

参考 0–9s、57–65s。单一主体 → 相交轮廓 → 两个有连接的实体 → 系统整体。保留轮廓中心或一个连接端点作为匹配锚。每次变化对应“分解/连接/合成”之一，不能只轮流换漂亮图形。

2D 优先 SVG path、clip 或离散匹配遮罩；真实体积/遮挡确有意义才用 Three.js。复杂拓扑变化不强行做错误 path morph，可用共享端点的遮罩交接。建议主体占画宽 0.25–0.5，留白供关系展开。

## G2：请求路由与工具调用

参考 13–22s。输入胶囊位于下方或中心；上方一个起点节点分出三路。请求沿选中分支到达目标，其他路径保持低强调；被选目标转成工具步骤，再输出结果文本。线先建立方向，对象再沿线走，目标到达后响应。

`pathProgress` 同时驱动路径描边和请求位置：总长 L，dashOffset=L*(1-p)，请求取路径弧长 L*p。父层镜头变换统一作用于路径、对象和标签。建议每个 travel 0.5–1.2s，真实节拍由旁白与步骤决定。

## G3：测试推进到分发

参考 25–31s。竖向检查轴逐项完成，当前项与数值同步更新；最后的完成节点转成分发起点，多条线到不同渠道图标。百分比从真实 passed/total 推导，不能为了动画编造中间值。每个勾选引起一次可见变化；完成后再分发。

## G4：指标异常到分支实验

参考 35–47s。类别簇 → 曲线局部峰谷 → 异常摘要 → A/B 两条路 → 结果交接。共用一个实体颜色和 id；相机从整体定位到异常点，点的描边保留到摘要中；实验路径从该异常生成。仅有最终数据时画机制示意，不伪造历史曲线。

## G5：控制与边界

参考 47–57s。开关组体现状态变化；凭证图标只在有实际来源时展示；中心锁或边界围住已解释的实体，再拉远到网络分布。图标描边统一，背景保持低信息密度。安全/合规结论必须来自内容证据，不继承来源标志。

## 验收

整个镜头不是同时全图亮起；跟随对象可追踪，目标回应可见。线宽在 1080p 可从 2–3px 起测，字体需在交付尺寸读清。重复微动不能替代状态变化。建议曲线/间距不是原片源码参数。

任意输出帧由纯时间状态重建。绑定稳定 target id 与 Seqvio resolved Beat，SFX 瞬态对齐到达/勾选事件。CosyVoice 输出需通过真实对齐生成词句锚点，不能仅按字数计算。先做路径和中间帧预演，再完善材质。
