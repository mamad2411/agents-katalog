# 参考视频场景模板集

## 使用入口

当前只保留非真人场景，按完整动画过程分段，不设固定秒数限制。先读 [完整动作场景 skill](atomic-scene-motion/SKILL.md) 的 55 个动作配方，再用下表确定风格。配方是动作阶段，可以组合成一个完整场景，不等同每个配方都必须单独切片。

先决定当前镜头要让观众看见的变化，再选择下列一个主风格。不要把四种风格的颜色、材质和镜头全部混在一起。用户明确混合时，先统一字型、线宽、背景、焦点尺度和对象身份。

| 任务 | 子技能 | 参考 |
| --- | --- | --- |
| 终端工作变成可见成果；桌面与手机接力 | [illustrated-product-demo](illustrated-product-demo/SKILL.md) | claudeauto、opus4 |
| 解释判断、信息筛选、反馈回路、数据依据 | [mechanism-explainer](mechanism-explainer/SKILL.md) | claudework 的非真人部分 |
| 把能力、流程、测评、分支变成连续几何关系 | [geometric-agent-explainer](geometric-agent-explainer/SKILL.md) | eleven |
| 输入、选素材、编辑、预览、协作的产品流程 | [media-workflow-demo](media-workflow-demo/SKILL.md) | Introducing_Google_Vids |

子技能目录可分别安装；各自包含核心实现规则，不依赖 motion-skills。当前根目录用于成套选择。模板是制作约束与配方，不是已经实现的渲染组件库。

## 参数化制作

为每个镜头填写 [场景实例契约](references/scene-contract.md)。固定的是对象关系和动作语法；主题、资产、文字、色彩和最终时长是输入。没有可用资产时先补资产，不能用带标题的空框冒充已完成画面。

1. 读子技能中的参考时间段，观看对应片段及中间帧。证据目录由 [参考映射](references/source-map.md) 定位。
2. 写下主体、证据或示意、动作、结果、下一镜头继承对象，按语义填充配方。
3. 先生成低成本的动作预演，观察主体发展与转场；再完善字体、素材质量和材质。
4. 旁白主时钟：CosyVoice 音频经过实际对齐后进入 Seqvio resolved manifest。精确同步按 [同步与验收](references/sync-and-qa.md) 执行。
5. 用新话题替换模板内容，检查仍能解释该话题。这比只重绘原参考片更能验证复用性。

## 防止再次退化

- 真实 UI、代码、表格自然需要矩形。检查框内是否发生内容变化、框之间是否传递对象，不能靠换圆角或微漂移代替进展。
- 不机械要求所有镜头至少两个非文字对象。单个主体、一个关键词或结尾定格都有合法用途；连续多个镜头仅文字入场而无演示才是问题。
- 不按固定秒数拆场景。长机制图在一次判断、一个分支展开或反馈回路完成后才分段，继承节点和相机状态。静止阅读需有具体阅读任务。
- 不模仿来源中的虚构产品名称、数字或资质；它们只用于分析该参考的画面设计。
- 场景编号、参考时间码、模板 id、调试框只存在作者资料中，成片不显示。
- 参数、曲线和颜色均为观察后的复现起点，不能声称还原了原片工程或其准确 easing。
