# 插画陪伴的成果演示

## 观察与风格

参考 claudeauto 0–34s、38–54s；opus4 0–38s、42–74s。主要手法是窗口尺度变化、前后层切换、指针操作、同一成果跨设备延续。像素角色只提供陪伴和过场，产品结果占主要注意力。

复现起点：背景可用低饱和浅灰绿或浅灰紫，深色终端与浅色网页形成对照；不复制背景涂鸦。结论短句可用衬线字体，终端等宽、产品 UI 无衬线。实际字体本地加载。窗口边界遵循产品本身，不额外套框。

## 必备槽位

`terminalSteps[]`（实录/明确示意）、`resultBefore`、`resultAfter`、`focusRegions[]`、`cursorEvents[]`、`mobileResult`（需要跨设备时）、`characterFrames`（可选自有角色）、`claim`、`brandAsset`。证据标识和裁切区域在作者资料中记录。

## 配方 I1：工作窗口到成果

参考 claudeauto 0–8s、11–24s；opus4 14–22s、56–68s。

| 阶段 | 构图与动作 | 结果 |
| --- | --- | --- |
| 输入 | 终端位于 (0.5W,0.48H)，宽约 0.48W；推近命令区域 | 观众知道任务 |
| 执行 | 保持输入锚点；代码/状态按步骤替换，重要一行高亮 | 工作有可见进展 |
| 产出 | 终端移至左后方；结果从右前方进入，宽约 0.58W | 同屏保持因果 |
| 证明 | 推近结果局部；图表、页面或运行状态实际改变 | 结论有证据 |

建议镜头变换 0.45–0.9s，不是原片实测参数。结果移动与遮挡区域同步计算。禁止整段只晃动终端外框，禁止用打字速度模拟实际任务速度却不标注示意。

## 配方 I2：角色携带观点

参考 opus4 2–14s、claudeauto 8–12s。自有角色从窗口边缘离开，带出一个与任务有关的物件；窗口退到侧边，短句进入原主体附近。角色移动路径有准备、主体位移、附属物跟随，收尾停止。建议角色占 8–16% 画宽、短句一至两行，勿遮挡结果。没有角色素材时用任务文件/成果缩略图承担交接，不能临时复制来源角色。

## 配方 I3：操作到跨设备接收

参考 claudeauto 24–46s；opus4 42–56s。

先把镜头拉近真实 Share/Copy 操作区域，指针到位后按钮变状态；保留同一内容标识，切到消息接收或手机打开。桌面约 0.55W，手机约 0.18W，尺寸按阅读需求调整。先展示通知，再展示手机内容，不让结果早于发送。移动端内容必须是同一成果的适配布局，不能单纯横版截图缩小。

## 配方 I4：状态徽记到收束

参考 opus4 66–81.386s；claudeauto 46–60.047s。从实际页面抽出一个状态标记，原页面退出，标记在中心完成状态变化，再交给一句结论和本项目标志。状态变化需有真实依据；不得复制来源中已通过/已合并结果。结尾允许静止阅读，不额外添加场景编号。

## 实现与验收

每个窗口统一使用世界坐标，镜头变换作用于父层；指针目标由同一坐标映射，防止放大后点偏。状态由当前帧求值，禁止回调累积 DOM 状态。输入、执行、结果分别绑定真实语义事件；声音对齐点击或落定，不对齐整个镜头入场。

验收：遮住标题仍能看到任务过程；前后窗口里的成果一致；指针命中；角色退场后结果可读；终端字不可读时必须放大局部。不同项目重新填资产和字幕，不沿用参考品牌。使用 Seqvio 时消费已解析的 Beat/timeMap；CosyVoice cue 时长不等于词级同步。
