# 媒体工作流演示

参考 Introducing_Google_Vids 的操作连续性和素材表现，不照搬品牌、界面或原片图片。本文可独立使用，无需 motion-skills。先准备真实素材缩略图、操作界面和可展示的完成结果，不能用空白矩形替代素材库。

## 输入与构图

输入：目标任务、操作步骤、可用 UI、素材清单、旁白、最终产物。输出每镜的输入状态、焦点动作、输出状态和下一镜保留对象。

以明亮中性底配有限的蓝、紫或其他产品强调色；图库必须有真实照片或视频帧的内容差异。正文紧凑，动词字卡可短时放大。窗口、素材图与工具图标交替承担主体，不连续用全屏大字复述旁白。引用产品时按实际 UI 制作；示意 UI 在文档中标注为示意。

## 五种模板

| 模板 | 场景步骤 | 替换槽位 | 关键运动 |
| --- | --- | --- | --- |
| M1 动词成为控件 | 短动词 → 字形/位置保留 → 控件边界出现 → 光标点击 → 操作结果 | verb、control、result | 同一对象由文字变为可操作按钮，不硬切成无关界面 |
| M2 输入成为产物 | 提示词输入 → 资料文件进入 → 提交 → 大纲或脚本按结构展开 | prompt、inputs、outputSections | 文件汇入同一入口，输出逐项占据稳定位置 |
| M3 素材库到画面 | 搜索 → 缩略图铺开 → 光标定位 → 选中图抬升 → 背景退让 → 同图落入编辑器 | assets、selectedId、destinationRect | 保持同一张图片及裁切焦点连续 |
| M4 声音试听 | 选择声音 → 试听 → 波形反馈 → 成品轨道 | voiceOptions、audio、track | 反馈来自实际媒体，不引入真人录制画面 |
| M5 协作交接 | 编辑界面 → 多人光标执行不同动作 → 头像确认 → 评论锚定对象 | collaborators、actions、comments | 光标有明确目标，评论跟随所指对象 |

## 实现配方

M3 为每张素材保存 ID、原始尺寸、裁切焦点。建立图库的规则行列坐标，选中图单独提升层级，其他图降低对比。把选中图从 sourceRect 插值到 destinationRect，同时插值裁切；编辑器底层先到位，图随后落入。不要复制两张略有不同的图片冒充连续运动。相邻镜只允许一个主运动方向，焦点落稳后才揭示新操作。

M1 文本和按钮标题使用同一文字对象；按钮边框扩展时文字基线不跳。光标点击坐标从目标控件的变换后矩形求取。M2 打字是输入动作，生成输出按段落或列表项展示，不能逐字拖慢所有正文。

M4 波形由实际音频采样或 RMS 包络生成。需要配音时使用本项目指定的 CosyVoice。试听、旁白和演示音效分别排程；展示音效本身的片段留出听辨空间。示意波形不可假装与声音实测一致。M5 不同光标分时操作，避免所有对象同时追逐焦点。

建议位移或焦点转移从 0.4-0.8 秒起调，点击反馈从 0.1-0.2 秒起调；属于创作默认值，不是源视频测量。镜头时长随完成操作和读懂结果的时间决定，不设固定 39 秒或统一切镜频率。

## 同步与验收

先用最终 CosyVoice 音轨和 Seqvio 实际对齐输出确定语言锚点，再放置控件出现、选择完成、媒体入轨等事件。音效以点击、落位或播放开始的实际帧定位，不以场景起点替代。音频内部起音偏移也要计入。

检查素材授权、图库内容差异、文字可读性、鼠标命中、图片裁切连续、最终输出确实包含所选素材。逐帧检查落位前后，随机 seek 检查确定性，正常速度检查操作是否可理解。禁止自动加入左上角场景名、模板名、ID 或调试字幕。
