# 🎨 09 - Tailwind CSS v4 Architecture Engine

## Purpose & Responsibility
Compose clean, responsive utility CSS layouts using Tailwind CSS v4 `@theme` tokens, container queries, and `tailwind-merge`.

## Directives
1. **Theme Tokens**: Reference system CSS variables defined in `@theme` instead of hardcoded hex values.
2. **Container Queries**: Use `@sm:`, `@md:`, `@lg:` for component-level container responsiveness.
