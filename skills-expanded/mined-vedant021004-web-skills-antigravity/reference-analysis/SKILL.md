# 🔍 01 - Reference Analysis & Benchmarking Engine

## Purpose & Responsibility
Deconstruct world-class reference websites to extract reusable spatial patterns, typographic scales, interaction cadences, and shader techniques without copying layout templates.

## Benchmark Standards
1. **Apple**: Spatial hierarchy, hardware product showcases, camera scroll-storytelling, translucent glass overlays.
2. **Stripe**: Multi-layered WebGL shader canvas gradients, precision financial UI tables, documentation typography.
3. **Linear**: High-density luxury dark mode (`#000000`/`#09090b`), sub-50ms shortcut-first interactions, subtle 1px border glows.
4. **Vercel**: Strict monochromatic black/white contrast, Geist font family usage, edge compute layout alignment.
5. **Framer**: Declarative spring dynamics, layout morphing, fluid canvas pan/zoom gesture physics.
6. **Spline**: Interactive WebGL 3D model embedding with real-time camera transitions and hover reactions.
7. **Neon**: Vector glow physics, high-contrast border beams on dark translucent backdrops.
