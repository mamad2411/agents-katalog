# ⚛️ 07 - React 19 Expert Engine

## Purpose & Responsibility
Enforce strict state boundaries, component composition patterns, custom hook abstractions, and zero-re-render optimizations.

## Directives
1. **Local State Preference**: Keep transient state local to leaf components.
2. **Compound Components**: Build modular UI components with compound patterns (`Modal.Content`, `Modal.Actions`).
3. **Custom Hooks**: Isolate complex UI logic into reusable typed hooks.
