# 🎭 00 - Creative Direction & Art Direction Engine

## Purpose & Responsibility
Establish emotional resonance, bespoke brand identity, editorial typography pairings, and non-derivative visual concepts for digital web experiences prior to line-one code generation.

## Architectural Directives
1. **Bespoke Visual Identity**: Never generate generic corporate templates. Every experience must feature a distinct visual voice, intentional palette hierarchy, and high-contrast editorial typography.
2. **Typography Harmonization**: Pair expressional display fonts (Geist, Space Grotesk, Syne, General Sans, Instrument Serif) with ultra-legible body type (Inter, JetBrains Mono, Switzer).
3. **Color & Lighting Architecture**: Anchor dark modes in deep blacks (`#000000`/`#09090b`), high-contrast off-whites (`#ffffff`/`#f4f4f5`), translucent glass backdrop filters (`backdrop-filter: blur(16px)`), and subtle perimeter glow beams.
4. **Negative Space Discipline**: Utilize asymmetrical visual weight, dynamic visual entry points, and generous whitespace to guide reader focus.
