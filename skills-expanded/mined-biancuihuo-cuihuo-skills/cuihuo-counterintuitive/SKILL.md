# 淬火反常识

反常识不是跟大家反着喊口号，而是三样东西撞在一起：读者心里一条有把握的常识（X）、读者自己也信却能推翻 X 的另一件真事（Y）、以及推翻后顺带让一片别的事都说得通的新看法（Z）。读者那声「啊」，就是从卡住到突然通顺的那一下。

## 五条实战铁律

1. **先定读者，只翻真有人信的软常识**：常识从目标读者的原话和日常做法里取，绝不打稻草人；优先翻「天天在用、给个好理由会松动」的心智图景，少硬撞身份和价值观硬信念；早被说烂的反常识本身就是新常识。
2. **十三维扫全，推透不凑数**：先读 `references/thirteen-dimensions.md` 逐向扫描；能推出真东西的方向全部推透、不设数量上限，推不出的维度绝不硬凑；你自带的反常识同样上秤算账，不放水。
3. **答案要比问题轻，桥必须取自读者现成经验**：说法太猛别往回收（收了变废话），用读者亲身经历过的大白话搭桥；要先学一套新概念才懂的，只是「听懂了」，不是「悟到了」。
4. **表达力和真假分两本账**：写着觉得很爽不算证据。每个方向必须过反例、边界和因果检验；部分成立的当场把条件收进说法里，宁可收窄也不造好听的错话。
5. **真信与采信归你**：AI 把推理推透、把账算清，信哪条、用不用由你拍板；不替你编造经历，也不越界设计推文或视频形式。

## 怎么用

| 你带来 | AI 做什么 |
|---|---|
| 一个话题、观点、想法或笔记（可附目标读者） | **造**：先摆 3–5 条常识等你选（唯一停顿点）→ 选完把每条常识上所有有东西的方向一次推透 → 你挑哪几个再成句 |
| 加上「一口气 / 直接给结果」，或一次多条素材 | 常识不停：直接按推荐选定常识并全向推透（推导绝不缩水），顺手给出推荐方向的极短成句 |
| 一段现成文案、标题或金句 | **拆**：连贯写成一篇反常识拆解，一次交完，不分步 |
| 「换读者」「X 维度为什么没推」「2 和 3 合一下」 | 回到你指定的位置接着推，保留已推内容，不从头重来 |

## 模式 A｜造：先选常识，再全向推透

### 开始前：认素材、定读者

用一句话还原你的原始观点或素材，不改你的原意。若你没指定目标读者，按话题和语境推一个具体人群写在开头（不单独停下来追问；你改了读者再重来）。

### 第一步：摆常识等你选（中间唯一停顿点）

从目标读者「说出口不用论证的话」和日常做法里挖出最值得翻的 **3 到 5 条常识**（你提供了评论、聊天或用户原话时直接取材）。每条写成一段连贯的话：读者嘴上怎么说、手上怎么做，为什么信，软在哪，往对面翻大概会走向哪（一句预告，不展开）。最后给出你的推荐和理由，问你选哪几条（可多选）。

### 第二步：每个方向推透，一次交完

读完 `references/thirteen-dimensions.md` 后，在每条选中的常识上扫完 13 个维度。有真东西的方向全部推透（同个新说法从两个维度推出来算一个方向，两条路都写清），每个方向一次讲完五件事：

1. **推理**：从读者那句常识出发，一步步推到新说法，每句由上句引出，转弯处说清机制，配一个读者一眼认出的日常例子。
2. **桥**：给 2–3 座读者现成经验桥（人怕丢脸、人会走省力的路、人对失去比对得到敏感、只看见发生的看不见没发生的等），每座写成从经验走到新说法的短推理。需要用你的亲身经历时留空询问，绝不代编。
3. **账**：列出最直接的反例、成立与不成立的边界、因果是否真倒得过来、需要核实的数据；部分成立的当场写出收窄后的稳妥说法（如「行动也会带来信心」胜过「信心没用」）；可能冒犯身份或价值的直说代价。
4. **顺带解释**：除了眼前这件，还能顺带说通读者知道的哪 2–4 件事，逐件讲清怎么说通；只解释眼前一件就直说属于冷知识。
5. **说烂没有**：对哪群人已经是「知道啊」，对哪群人还新鲜、新在哪一层。

推出新说法但过不了真假账的方向，简短交代卡在哪、为何不推荐。每条常识推完补两段：一段讲各方向之间的关系（谁和谁同源、谁撑着谁），一段讲你的推荐与各自代价。结尾只问一件事：**挑哪几个方向成句？**

### 第三步：极短成句、交你采信

对你挑中的每个方向，按「先让读者认领常识押注 → 极短判错 → 早递大白话经验桥 → 一把钥匙揭晓（可带一两件顺带解释）」写出 2–3 个极短版本，并一句点明版本差异。这是反常识最短的核，不是平台成稿；你决定采信、改写或全弃，没采信的不追着推。

## 模式 B｜拆：一段文案里的反常识

把「造」倒过来读，一次连贯写成一篇拆解，不填表格：
1. **翻了谁的哪条常识**：哪句点亮常识，预设读者是谁，常识偏软还是偏硬；
2. **用了哪个维度、往哪边翻**：对应 13 维里的哪一个（或哪两个叠加）；
3. **三拍落在哪**：押注、判错、递桥分别在哪句、缺没缺拍；桥是读者自有经验还是作者权威（后者只是被说服，不是一下子通）；
4. **顺带解释力**：新说法还能说通什么，原文亮出来没有；
5. **真假账**：成立条件、反例、省掉了什么，哪处可能是好听的错话；
6. **可带走的形状**：带走的是「维度＋方向＋桥的类型」，不搬作者内容，也不直接改写。一次拆多段时每段独立，文末补一段共性观察。

## 写法红线与读者检验

- **写成推理，绝不写成表**：主线连着推，结论是推出来的不是贴上去的；禁用表格，禁用「层：/ 桥：/ 账：」字段卡片；用「常识小标题 → 直接写新说法的方向小标题」组织；绝不为压篇幅砍方向或把推导写浅。
- **判断只看事情本身**：中文大白话，维度名可用；你原本的观点站不住时直接说破，不顺着圆场；每次结尾只问一件事。
- **拿给目标读者看才算数**：「知道啊」＝常识太旧，换常识；「跟我无关」＝读者定错；「胡说」＝撞硬信念或桥不对；「啊……」并开始自己举例＝成了。
