# 淬火问题逆向

把一篇深度长内容或商业对标，从表面表达还原成它背后真正在解决的问题结构与市场交易：看清它帮哪类人解决什么现实卡点、问题怎么环环相扣、作者怎么承接需求和变现，以及留下了哪些值得你另起炉灶继续回答的真问题。只带回真问题与市场洞察，不抄对方经历和成品。

## 四条硬规矩

1. **有原文证据才写，没料绝不脑补算命**：严禁从一篇公开文章硬猜读者的童年阴影或隐秘潜意识；原文没提价格、交付、转化或产品形态时，如实标明「原文未涉及」，绝不为填满栏目编造。
2. **把「当事人的原话」和「你的抽象解释」分开写**：比如材料里当事人说「想出去十天业务别停」，你可以解释为「降低创始人个人依赖」，但绝不能把后者冒充成当事人亲口追求的目标。
3. **默认一次性主动做完，不中断逼你填表**：只对核心主干问题做深，旁支和过渡段一笔带过，不给每条问题平均分配字数。
4. **守住材料边界**：只拿到节选片段时，只拆片段承载的问题，绝不冒充全文结构；只听说「数据很好/很差」却没有具体指标时，不倒推需求真假或编造爆款归因。

## 三步打穿工作流

深度追问需求与变现承接时，按需查阅 `references/demand-market-lenses.md`（按原文材料取用，绝不机械填表）。

### 第一步｜还原问题推进结构

1. **来源与实际任务**：用 2–3 句话交代现有来源信息（作者/标题/平台/链接或路径，缺的留白不猜）、表面主题、核心目标受众，以及作者真正想让读者相信什么、发生什么改变或采取什么行动。
2. **切分问答并找出主问题**：按「作者开始回答一个新问题」切分正文，找出拿掉就会让整篇论证和最终行动失去必要性的**主问题（Q0）**（主问题往往不等于标题）。把隐含没写成问句的问题还原出来，只负责转场和情绪铺垫的段落剔除掉。
3. **画出问题推进结构图**：用稳定编号（`Q0 / Q1 / Q1.1` 配 `A1 / A1.1`）和清晰树状缩进呈现出三种推进关系：
   - **问答接力**：上一个答案自然逼出下一个问题；
   - **主问题拆解**：多个子问题共同托住一个上位问题；
   - **观点对撞**：同一现象下，作者用新解释打掉旧解释。
   同时单独标出**原文打开了、却没真正答完的问题**。如果一篇内容里实际存在两套并行的主问题，分别画出，不强行揉成一条。

### 第二步｜挖出受阻处境、进展、替代品与变现承接

只挑 1–3 条最核心的主干问题往深里挖，**只写原文或你补充的材料里有依据的部分**：

- **真实受阻处境**：谁在什么具体场景里卡住了？原本想做什么，哪里没有按预期发生？同时保留材料里的当事人原话视角与你的抽象概括。
- **想取得的进展与既有渴望**：当事人想从眼下状态走进什么新状态？作者接住了市场上哪一种已经存在的渴望（区分渴望本身、作者给它的解释、作者递出的方案）？
- **现有替代品与失灵缺口**：当事人原本用什么办法凑合——不仅看同行竞品，还要看跨品类土办法、自己动手硬扛、或者干脆拖着维持现状。旧办法原本承诺什么、卡死在哪一步？
- **变现与行动承接**：作者用什么机制、案例、产品形态、价格锚、交付方式或行动引导接住这份需求？（如果是纯观点/知识长文没有商业承接，如实说明，重点看作者用什么承诺换取读者信任或关注。）
- **单篇盲区与下一步验证线索**：一篇文章只是市场的一扇窗，顺手指出如果真要确认这个需求成不成立，下一步最缺哪 1–2 类现实证据（例如评论区真实异议、实际成交阻力、用完后的结果反馈）。

### 第三步｜提炼值得另起炉灶的未解真问题

从上面两步里挑出 **2 到 4 个原文没答透、答偏了、跳过前提、或换个切口更有穿透力的真问题**。每个问题说清四件事：
1. 原文原本是怎么答（或怎么绕过去）的；
2. 为什么这个回答还不彻底、在什么边界下站不住；
3. 如果另起炉灶重新回答，最锋利的切口在哪里；
4. 哪些可核验的事实或观察值得继续追查（只给问题和切口，绝不直接生成仿写稿）。

**可选：迁移到你的视角**（仅当你主动提供了自己的定位、目标受众或产品信息时才写；未提供时绝不硬套任何预设定位）：对照上述未解问题，标明哪些直接贴合你的受众、哪些需要改换切口、哪些属于对方专属情境不建议硬搬。

## 交付与保存

- 默认直接在当前对话中完整交付，语言简洁、讲证据，清楚区分「原文事实」「作者主张」「分析推论」和「未提及留白」。
- 仅当你明确要求落盘，或当前工作区 `.cuihuo/local.yaml` 配置了 `storage.benchmark` 时，再保存为 `YYYY-MM-DD_<来源简称>_<短题>.md`（只保留必要短锚点，不整篇复制第三方原文）。
- 结尾只问一句：
  > 这张问题图里，哪一个未解问题最让你有反应，想接着往下挖？

## 下一步交接

如果看完问题图后，你想挑中某一段细拆修辞与观众价值、围绕选中的未解问题找反常识切口、把自己的观点磨成硬论证，或针对关键假设做多视角碰撞与决策下注，交回 `/cuihuo` 调度对应能力。
