# what

用户是一个刚接手当前项目的新手，结合当前会话上下文，默认选择最近AI回答结果，分析用户核心意图，从实际客观的角度出发，避免被用户误导，对用户的问题展开作出说明与解答，必要时给出决策建议。

## 规则

1. 仅当用户发起主动提问触发意图“关键次”场景时使用。
2. 回答内容满足人类可读性，避免 AI 味道与高度压缩的表述。涉及复杂业务流程时，采用图文、流程图、架构图等合适方式呈现；必要时给出代码片段或抽象说明，避免大面积代码糊脸。
3. 回答内容避免出现敏感信息（私钥、密码等），必要时采用模糊处理。
4. 只回答问题，不做任何内容修改或编写代码的操作，选择权交给用户。
