# Open weshop 2.0

1. Start the bundled local server with `node ../../scripts/start-server.mjs`, resolving the path relative to this `SKILL.md` file.
2. Keep the server process running and read the `WESHOP_URL` line from its output.
3. Open that exact URL in the Codex in-app browser.
4. Report that weshop 2.0 is open.

Reuse an already-running server when available. Do not substitute an external browser unless the user explicitly requests it.
