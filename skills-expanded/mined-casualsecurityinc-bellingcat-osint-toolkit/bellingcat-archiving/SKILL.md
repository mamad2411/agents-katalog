# Bellingcat Archiving Tools

Tools for archiving web content, social media posts, and monitoring page changes over time.

## Choosing Tools

- Use archive services to preserve or retrieve a specific page; use monitoring tools when you need to detect later changes.
- Prefer more than one archive for material that may disappear, and retain the original URL and capture time with the archive link.

## Investigation Tips

- Use the Wayback Machine for historical snapshots of any web page
- Archive.today works well for archiving social media pages including Facebook
- Bellingcat's Auto Archiver automatically archives social media posts, videos, and images
- Distill.io monitors pages for changes and sends alerts
- Hunchly tracks all pages visited during an investigation with automatic archiving
- For long-term preservation, archive to multiple services simultaneously
