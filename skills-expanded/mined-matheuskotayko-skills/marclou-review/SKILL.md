# Marc Lou Review

## Quick start

Review the landing page / product / copy against the 31 rules in [REFERENCE.md](REFERENCE.md). For each rule, say pass, fail, or n/a, and give one concrete fix if it fails. End with the top 3 highest-impact fixes.

Example output for one rule:

```
1. No free plan — FAIL
   Pricing page offers a "Free" tier with unlimited use.
   Fix: cap free tier hard (e.g. 3 uses) or remove it, force a paywall.
```
