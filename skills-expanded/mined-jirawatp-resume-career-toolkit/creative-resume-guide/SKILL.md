# Creative Resume Guide

For creative professionals, the resume itself is a portfolio piece. But it still needs to pass ATS.

## The Two-Version Strategy

**Version 1: ATS-safe** (for online applications and job portals)
- Single column, standard fonts, no graphics
- All the same content as the designed version
- Clean and professional, but not visually adventurous
- .docx and text-based .pdf formats

**Version 2: Designed** (for networking, direct emails, portfolio website, in-person)
- Full creative treatment showing your design skills
- Can use columns, custom typography, color, icons
- .pdf only (high-quality, print-ready)
- Must still be readable and information-complete

## When to Use Which

Use ATS version for: online application portals, job boards, any system where you upload a file
Use designed version for: portfolio website, email to a hiring manager, networking events, interview handouts, creative agencies that explicitly say ATS is not used

## Creative Touches That Are ATS-Safe

Even the ATS version can show design sensibility through:
- Thoughtful use of white space
- Clean typographic hierarchy (2 fonts max)
- Strategic bold and italic for emphasis
- Simple horizontal rules between sections
- One accent color used sparingly
- Hyperlinked portfolio URL

## Design Principles for the Visual Version

- The resume must be readable in a 6-second scan
- Information hierarchy matters more than decoration
- Consistent alignment and spacing demonstrate attention to detail
- 2-3 color palette maximum
- Ensure it prints well in black and white
- Match the visual identity of your portfolio website

## Portfolio Integration

- Link to your portfolio prominently in the header
- For specific achievements, link directly to the relevant case study
- Consider offering a PDF download of the designed resume on your portfolio site
- Make sure the web version is responsive
