# Career Pivot Guide

Translate experience from one field into the language and priorities of another.

## Why Career Changes Are Hard

Recruiters pattern-match. They see "teacher" and think "not qualified for corporate training" even though the skills overlap heavily. The fix is translation: reframing true experience using the vocabulary, metrics, and priorities of the target industry.

## Translation Process

### 1. Identify Transferable Skills

Every role builds skills that cross industries. Map your experience to these universal categories:

- **People leadership:** Managing, mentoring, hiring, performance reviews
- **Project execution:** Planning, coordinating, delivering on deadline and budget
- **Communication:** Presenting, writing, negotiating, stakeholder updates
- **Analysis:** Data interpretation, research, problem diagnosis, decision-making
- **Operations:** Process design, quality control, vendor management, compliance
- **Revenue:** Sales, client acquisition, upselling, retention

### 2. Learn the Target Vocabulary

Every industry has its own terms for the same activities. Research job postings in your target field and build a translation table:

| What you call it | What they call it |
|-----------------|-------------------|
| Students | Learners / end users |
| Lesson plans | Training curriculum / program design |
| Parent conferences | Stakeholder communication |
| Patient care | Client service delivery |
| Platoon | Cross-functional team |
| Mission | Initiative / program |
| Guests | Customers / clients |

### 3. Rewrite Experience Using Target Language

Take each bullet from your current resume, strip out industry-specific jargon, and reconstruct it using the target industry's vocabulary while preserving the truth.

**Teacher applying for corporate L&D:**
Before: "Taught 5th grade math to 28 students"
After: "Designed and delivered curriculum for 28 learners, achieving 94% proficiency on standardized assessments through differentiated instruction and data-driven intervention"

### 4. Build Bridge Experience

If you have zero experience in the target field, create some:
- Freelance or volunteer projects
- Relevant certifications or courses
- Side projects demonstrating target skills
- Industry community participation

### 5. Craft the Transition Narrative

You will be asked "why the change?" Prepare a 3-sentence answer:
1. Discovery: "Through [experience], I found that I am energized by [target field activity]"
2. Connection: "My background in [old field] gives me [unique advantage] for [new field]"
3. Action: "I have been building toward this through [certification/project/volunteering]"

## Resume Format for Career Changers

Use a hybrid format:
1. Summary (explaining the transition positively)
2. Core Skills (transferable, using target language)
3. Relevant Experience (grouped by skill, not chronology, if helpful)
4. Professional History (chronological, abbreviated)
5. Education and Certifications (especially new ones)

## Output Format

```
CAREER PIVOT TRANSLATION

Current field: [X]
Target field: [Y]

TRANSFERABLE SKILLS
1. [Skill] -- relevant because: [why it matters in target field]
...

| Your term | Target industry term |
...

REWRITTEN BULLETS
Original: "[current bullet]"
Translated: "[reframed bullet]"
...

TRANSITION NARRATIVE
[3-sentence script for "why the change?"]

GAP ANALYSIS
Skills to develop: [list with action items]
Bridge experiences to build: [suggestions]
```
