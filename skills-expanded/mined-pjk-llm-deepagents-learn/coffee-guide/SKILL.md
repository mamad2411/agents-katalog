# 咖啡冲煮指南

## 器具清单
- 手冲壶(细口温控壶)、滤杯(V60 或 Kalita 均可)、滤纸
- 磨豆机(建议手磨或电磨,现磨现冲)、电子秤、温度计

## 推荐起步参数(手冲)
- **粉水比**: 1:15 —— 15g 豆子配 225g 水
- **水温**: 88–92°C(浅烘偏 90–92,深烘偏 88–90)
- **研磨度**: 中细,接近白砂糖颗粒大小
- **总萃取时间**: 2:30–3:00 分钟

## 手冲五步
1. **润纸**: 放好滤纸,用热水冲一遍,滤掉纸味并温杯
2. **倒粉**: 倒入研磨好的咖啡粉,轻轻拍平粉床
3. **闷蒸**: 注入 2 倍粉量的水(如 15g 粉 → 30g 水),等待 30–45 秒让 CO2 排出
4. **分段注水**: 第一段画圈注水到总水量 60%,暂停;第二段中心注水补到 225g
5. **收尾**: 移走滤杯,轻轻摇匀咖啡液后倒出

## 常见问题排查
- **太酸**: 研磨更细 / 水温更高 / 延长萃取时间
- **太苦**: 研磨更粗 / 水温更低 / 缩短萃取时间
- **流速太快**: 研磨太粗,或粉床不平、有通道
- **流速太慢**: 研磨太细,或闷蒸时间过长

## 意式浓缩(Espresso)简述
- 粉量 18g,萃取 25–30 秒,出液 36g(粉液比 1:2)
- 水温 90–94°C,压力 9 bar,研磨细如食盐
