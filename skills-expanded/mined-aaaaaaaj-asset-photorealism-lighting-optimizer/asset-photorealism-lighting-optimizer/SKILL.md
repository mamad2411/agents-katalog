# 资产真实感与光线优化

> 版本：260812 | 适配重点：Image_2 图片编辑与参考图重绘

把参考图的设计资产转换成可信的电影实拍、棚拍实物或真人摄影质感。真实化不是重新设计：先保护身份、构图、结构和文字，再修复材质、光线、尺度、空间与摄影机响应。

## 交付硬规则

1. 最终可复制提示词不得超过3000个可见字符，默认写在2200至2700字符内，为平台计数差异留余量。
2. 每次新增要求或修改要求后，都重新输出一遍完整提示词。不得只给局部补丁、追加段落或“其余不变”。
3. 最终提示词放在一个带 `text` 标记的代码块中，利用界面代码块自带的复制按钮。代码块外只允许一句必要说明，不附英文重复版本。
4. 所有图片生成、真实化、重新布光和返修提示词，必须在摄影画质部分原样加入：
   “增加光线采样数，收敛噪点，减少随机颗粒，亮点，暗部噪声。最大程度保留原图的细节和质感，同时去除噪点拟合。”
5. 降噪不能被解释为磨皮、涂抹材质、减少细节、整体模糊或塑料化。
6. 用户只要求提示词时，不调用生图工具。用户明确要求直接生成或修改图片时，再使用图像生成工具。
7. 用户说明的时代、日夜、材质、位置、人物和剧情事实高于从画面亮度或文件名做出的推测。

## 每次任务的固定流程

### 1. 先读图，不急着写

内部建立资产清单：

- 画幅、机位、焦段感、消失点、地平线、透视畸变。
- 主体身份、数量、相对位置、前后遮挡、大小关系。
- 建筑层数、门窗、平台、楼梯、植物、家具、武器、文字、纹样等高风险内容。
- 当前材质、综合色调、已有光源、阴影方向、反射和空气状态。
- 用户允许改变与禁止改变的边界。

除非用户要求分析，不把这份清单单独输出；将它转化为提示词中的结构锁定。

### 2. 选择唯一主模式

| 模式 | 适用情况 | 执行重点 |
|:---|:---|:---|
| 严格转真实 | 构图和设计成立，只是假 | 锁全部内容，只改材质、光线、空气和摄影机响应 |
| 有限结构修正 | 用户要求删人、补道具、校透视、改比例 | 先列准许变化，再锁其余内容 |
| 多参考合成 | 目标图加角色、武器、光色或材质参考 | 为每张图规定职责，禁止越权 |
| 定点返修 | 已出图只有一两个问题 | 保留已成立部分，但仍输出完整新版提示词 |

### 3. 按真实感优先级写

固定优先级：

1. 身份、文字、数量、构图和结构。
2. 日夜、天气和主要光源。
3. 材质粗糙度、厚度、接缝、磨损与反射。
4. 接触阴影、尺度、前中后景和空气透视。
5. 焦段、景深、高光、黑位、动态范围与降噪。
6. 当次最可能发生的禁止项。

字数不足时按倒序删减，不能平均压缩导致核心约束变弱。

### 4. 使用稳定结构

按任务需要选用这些段落，不机械堆满：

```text
基准与修改边界
结构与内容锁定
主体或人物
真实材质
光源与曝光
空间、透视与摄影
摄影与画质
严格避免
```

高风险对象应单列，例如文字、屏幕内容、武器、古树、结界、巨物、四视图或多人身份。

### 5. 交付前校验

运行：

```powershell
py -3 scripts/validate_image_prompt.py <提示词.txt>
```

人工再检查：用户要求是否全部出现；日夜是否正确；是否把材质名称误当成改色许可；主光是否有明确来源；是否加入固定降噪条款；是否是一份完整提示词；是否在3000字符以内。

## 多参考图职责合同

逐张写清：对象、用途、锁定内容、不得继承内容。

- 目标图：唯一负责构图、机位、人物、建筑、道具、文字与物体位置。
- 角色图：只负责脸、年龄、发型、体型、服装和身份。
- 武器图：只负责武器形状、长度、材质、持有手和握法。
- 光色图：只负责天气、世界光向、软硬度、色温、曝光与空气状态。
- 材质图：只负责表面物理响应，不改变目标图的结构和综合色调。

用户说某张图“只是给你看、不给模型引用”时，最终提示词中不得出现该图号，也不得要求模型参考它；只把从中验证出的物理规律改写成目标图自身的描述。

## 光线总原则

- 先确定一个主要环境光，再加入画面中真实存在的灯笼、火盆、窗光、屏幕或法术等局部实际光源。
- 每个光源都要有方向、色温、遮挡、衰减、影响范围和投影结果。禁止无来源正面补光、统一环境光、全场染色和处处轮廓光。
- 日间不使用月光逻辑；阴天也有宽阔天空散射光。日间灯笼与火焰只影响附近区域。
- 夜景不等于全蓝和死黑。冷色月光或夜空散射光负责空间，暖灯只形成有限暖光区，二者之间保留真实阴影。
- 真实光线要同时改变材质：金属高光集中，玉石有内部透光，漆面反射深沉，粗石漫反射，织物吸光，湿地只在合适角度产生破碎反射。

## 返修协议

接到“把某项改成……”“再暗20%”“不要裂纹”“文字保持不变”等反馈时：

1. 找出新要求推翻的旧描述并彻底删除，不能让新旧条件同时存在。
2. 保留用户仍认可的构图、结构、色调、光线和材质。
3. 重建完整提示词，在一个代码块中重新交付。
4. 禁止只回答一段替换文字，禁止写“在上一版基础上加入”。

## 最终判断

输出前问自己：这张图若由真实剧组、道具师、置景师、服化师和摄影师共同完成，它的材料为什么这样反光，阴影从哪里来，物体靠什么承重，远近为什么有层次，瑕疵是否符合尺度？提示词必须能回答这些问题，而不是只堆叠“电影级、超写实、8K”。
