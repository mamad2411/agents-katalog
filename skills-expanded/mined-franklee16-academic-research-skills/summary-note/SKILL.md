# summary_note — 文献总结主技能

根据用户意图，使用 Skill 工具调度下列子技能之一，并把用户提到的文件夹、文件名、问题等参数原样传递给它。

## 路由规则

| 用户意图（关键词） | 调度的子技能 |
| --- | --- |
| 总结 / 归档 / 整理文献 / 文献总结表 | `summary_archiving` |
| 标签 / 分组 / 关键词 / 整理文献标签 | `summary_grouping` |
| 回答 / 问题 / 「回答我的问题：…」 | `summary_answering` |

## 流程

1. 读取用户指令，按上表判断意图。
2. 意图明确 → 用 Skill 工具调用对应子技能，转达用户的完整需求与参数。
3. 意图不明确（既不像总结、也不像打标签或提问）→ 向用户列出三项功能，请其选择：
   - ① 总结文献（生成/更新文献总结表 `paper_archiving.xlsx`）
   - ② 整理文献标签（生成/更新文献分组表 `keyword_summary.xlsx`）
   - ③ 回答问题（基于已整理的文献给出文献名单）
4. 若用户一次提出多项（如「先总结再打标签」），依次调度对应子技能。

## 约定

- 默认文献文件夹为项目根目录下的 `note\`（递归含子文件夹）；所有输出生成在项目根目录。
- 术语保持一致：文献总结表＝`paper_archiving.xlsx`；文献分组表＝`keyword_summary.xlsx`。
