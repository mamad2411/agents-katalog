# 质性访谈提纲设计 / Research-Grade Interview Guide Design

这个 skill 把"研究思路"变成"经得起方法论审稿的质性访谈提纲"。它的立场不是"快速生成一串看起来像访谈题的问题"，而是**每一道访谈问题都能回答"它服务哪个研究问题、能不能挖到深度、会不会诱导受访者、依据是什么"**。

它是 `questionnaire-design`（量化问卷）的质性姊妹 skill。两者方法论不同、不可互换：

| | `questionnaire-design`（量化） | 本 skill（质性） |
|---|---|---|
| 出发点 | 构念 → 量表题项 | 研究问题 → 访谈问题 |
| 挂靠什么 | 成熟**量表** | 成熟**访谈框架**（IPR / Yin 协议）+ 同主题已发表提纲 |
| 质量标准 | 信度、效度（α、AVE…） | **可信度四准则**（credibility/transferability/dependability/confirmability） |
| 出题红线 | 11 条量表红线 | 质性提问红线（诱导/双重负载/封闭化/术语/"为什么"质问/抽象/社会赞许） |
| 效度/偏差控制 | 注意力检测、CMB 程序控制 | 三角验证、成员核验、反身性与立场性、搜寻负向案例 |
| 预试 | 认知访谈 + 小试点 | IPR 专家 close reading + pilot + 饱和评估 |

适用：中英双语、质性访谈提纲（半结构化 / 结构化 / 关键知情人 / 精英 / 案例研究访谈）。**不做**量化问卷、量表（走 `questionnaire-design`）。

## 启动时先做的两件事

**第一，亮明边界声明（每份产出开头都要有）。** 访谈提纲设计只管**数据收集工具这一侧**——它能让提纲问对问题、挖到深度、降低诱导与偏差、为后续编码与三角验证铺好路；但它**不替你抽样、不替你做编码/主题分析、不保证结论可推广到其他案例或总体**。在质性里"可推广"叫 transferability，靠的是厚描述、目的性抽样与跨案例分析，不是靠一份提纲（详见 `references/trustworthiness-and-sampling.md`）。还要讲清：**这份提纲是案例的数据收集工具，不是案例研究本身**——案例的可信度还要靠多源证据三角验证（Yin）。**本 skill 设计的是工具，不替代伦理审查程序与个人信息合规**（见 `references/trustworthiness-and-sampling.md` §4）。不写这条，用户会误以为"好提纲=好研究"。

**第二，确认五个关键参数**（用户没说就用默认值并在产出里点明）：
- **语言**：中文 / 英文 / 中英双语（默认问什么语言答什么）
- **研究问题（RQ）与理论视角**：要回答哪几个研究问题？有没有理论命题（proposition）？——这是出题的起点，等价于量化里的构念，没有它无法开工。
- **案例 / 研究取向**：是案例研究吗？走 Yin（实证、命题驱动、结构）还是 Stake/Merriam（解释、涌现、灵活）？案例的边界（一个县/一家机构/一个项目）是什么？（见 `references/case-study-traditions.md`）
- **访谈对象 + 进入路径**：关键知情人 / 精英（领导、管理者、专家）还是普通参与者？是否涉及脆弱/权力不对等人群？怎么进得去（引荐人 / 组织授权）？这决定敬语、提问姿态、能问什么、伦理强度（精英访谈与 access 规范见 `references/trustworthiness-and-sampling.md` §3.0、§3、§4）
- **结构化程度 + 后续分析**：结构化 / 半结构化（默认半结构化，质性最常用）；后续要做主题分析、案例分析还是扎根理论？——分析目的会反过来影响出题（带着分析目的设计工具）
- **访谈方式**：线下 / 视频 / 电话（默认线下）——影响录音同意话术与非言语探测，见 `references/modality-considerations.md`

如果用户只给了一句模糊的"帮我做个关于 XX 的访谈提纲"，**先把研究问题和访谈对象问清楚再动手**——研究问题不清，后面全是返工。

## 核心工作流：从研究问题到访谈提纲

整个流程整合 Castillo-Montoya（2016）的访谈提纲精炼框架（IPR 四阶段）与 Yin 的案例研究协议。本 skill **做第 1–7 步**（对齐→检索锚定→出题→组装→自检→可信度与三角验证设计→产出），交付含研究者版 + 后续验证清单；其后真正落地的专家近读、pilot、饱和、抽样与编码（IPR Phase 3/4）由用户执行，本 skill 只写成后续清单——**不要假装替用户跑了访谈或编码**。

### ⛔ 出题前的阻断式闸门（START GATE — 不可跳过，违反即返工）

**进入"出题"（第 3 步）之前，必须先把下面这张清单逐条建成 TodoWrite 待办，并全部勾掉。** 这不是写完后的自检，而是**动笔前的放行条件**。

> 最常见、最严重的失败模式：因为"我熟这个领域"，凭训练记忆直接出题，跳过检索同主题提纲与出处核查。这正是本 skill 用整节"宁缺毋编"要防的事；而且**"凭印象碰巧对" ≠ "已核查"**——碰巧没错也骗得过快速浏览、骗不过方法论审稿人，并且会把未核验内容包装成定稿。所以这道闸门强制前置，不靠自觉。

把以下每一项建成一条 TodoWrite todo（让用户看见你在走闸门）：

1. ☐ **已确认五个关键参数**（语言 / RQ 与理论视角 / 案例取向 / 访谈对象与进入路径 / 结构化程度与后续分析）——见上节。
2. ☐ **已做映射矩阵草稿**（第 1 步）：每个 RQ 至少一题、无孤儿题。
3. ☐ **已 web 检索同主题/同领域已发表的访谈 protocol、机构化提纲、学位论文附录提纲**（第 2 步），并在产出里写明"借了什么结构/维度、改了什么"。**检索为空也要明确写"已检索，未见可借鉴的同主题提纲"**——不许默认跳过、不许用"我知道这个领域"替代检索。
4. ☐ **已 web 核查每一个要落笔的框架 / 理论锚点 / 阈值的真实出处**（提出者、年份、期刊/出版社、核心主张）：IPR=Castillo-Montoya 2016、可信度四准则=Lincoln & Guba 1985、饱和=Guest 2006 / Hennink 2017、Yin 六类证据等；**理论锚点（如边界理论、社区感、liminality、实践共同体）同样必须核**。核到的回贴进产出或一份 `_REFERENCES.md` 并附 URL；核不实就标"待核"或删。

⚠ **第 3、4 项是硬闸**：只要还有一个要引用的出处没 web 核过、或还没检索同主题提纲，就**不允许开始写访谈问题**。正确顺序是——先建 TodoWrite → 再去搜 → 搜完回填 → 最后才出题。

### 第 1 步 · 研究问题化与命题（对应 IPR Phase 1）
把研究问题写清楚，并（若走 Yin）列出理论命题。**关键动作：做一张"研究问题—访谈问题映射矩阵"**——每一道访谈问题都要挂到某个研究问题上，孤儿题（挂不上任何 RQ 的题）要删或改。这是访谈提纲构念效度的第一道关，等价于量化里"每题服务一个构念"。
- 雷区：直接把研究问题原样抛给受访者（研究问题是写给同行的，访谈问题是说给受访者听的，两者语域不同——Castillo-Montoya 的核心提醒）。
- 产出映射矩阵：研究问题 → 对应访谈问题编号 → 该题想挖什么。

### 第 2 步 · 检索并锚定成熟框架与同主题提纲（对应量化的"挂靠成熟量表"）
**这是质性提纲最容易被忽略、却最能提质量的一步。** 完整流程见 `references/protocol-structure-and-refinement.md`，要点：
- **先锚定方法论框架**：IPR 四阶段（提问结构）+ Yin 协议（案例研究的多源证据与证据链）+ Rubin & Rubin 的"主问题—追问—探测"提问层级。
- **再检索同主题/同领域已发表的成熟访谈提纲或机构化提纲**（如政府/基金课题的结构性访谈提纲、同主题学位论文附录的提纲、领域经典研究的 protocol）。看别人怎么分板块、怎么提问、问到哪些维度——**借结构、借维度，不照抄题面**。
- **核验出处（质量闸）**：凡引用某框架（IPR、Yin、Lincoln & Guba、饱和样本量），**必须 web 核查**真实出处、提出者、年份、核心主张——方法论引用同样是高频幻觉区（详见末尾"宁缺毋编"与 `references/sources.md`）。
- ⚠ 与量化不同：质性**没有"标准化的成熟提纲"可以原样套用**——访谈提纲天生要为具体研究情境定制。所以这里锚定的是**设计理念和结构**，不是拿一份现成题目来填。

### 第 3 步 · 生成访谈问题（对应 IPR Phase 2：构建探询式对话）
按 `references/question-writing-and-probes.md` 出题。每道题分三层（Rubin & Rubin）：
- **主问题（main questions）**：覆盖研究问题的主干，事先备好。
- **追问（follow-ups）**：针对受访者具体回答的澄清（"能再具体讲讲吗""你说的 X 是指…？"）。
- **探测（probes）**：维持深度与方向（"还有呢""能举个例子吗"），可静默、可具体。
硬约束：
- **开放式、非诱导**——让受访者用自己的话讲（这是质性访谈的命脉）。
- 过**7 条提问红线**：①诱导 ②双重负载/一题两问 ③封闭化（能用是/否答完）④术语黑话 ⑤生硬质问"为什么" ⑥抽象到无法作答 ⑦社会赞许诱导——每条都有坏例→好例（见 `references/question-writing-and-probes.md`）。
- **大游览开场（grand tour）**：先用一个宽松、易答、明显切题的问题让受访者打开话匣（Spradley），再逐步收窄到关键问题。**别用最敏感或最抽象的问题开场。**
- 用 Spradley 的描述型 / 结构型 / 对比型问题搭配，避免单调。

### 第 4 步 · 组装整份提纲（IPR Phase 2 的对话流）
按 `references/protocol-structure-and-refinement.md` 的四段式：
**开场（知情同意 + 暖场/基本信息）→ 过渡题 → 核心题（按研究问题/主题成块）→ 收尾题**。
- 开场：自我介绍、研究目的、保密与录音知情同意、易答的背景题暖场。
- 核心题按研究问题或主题分块，敏感题靠后。
- 收尾必给"兜底题"：**"还有什么是我没问到、但您觉得重要的吗？"**——精英/关键知情人常在这里抖出最有价值的信息（Solarino & Aguinis）。
- 现场主用**现场简版**（只列主问题），把**现场详版**（含所有追问探测）留作访前准备与备查——逼自己真正去听受访者讲，而不是念稿（三版提纲：研究者版 / 现场详版 / 现场简版，命名全程统一，见 `references/word-output.md`）。

### 第 5 步 · 自检（写完必做，见下方清单）
含 IPR Phase 3 的"近读核查表"精神（朗读每一题，查结构、措辞、长度、可理解性）。

### 第 6 步 · 可信度与三角验证设计
在提纲里显式安排可信度策略（Lincoln & Guba）：哪些题与哪些**其他证据源**（文件、档案、统计、观察）交叉印证（三角验证，Yin）；是否做**成员核验**（把整理后的理解回给受访者确认）；研究者**立场性声明与反身性**如何记录（见 `references/trustworthiness-and-sampling.md` §1b）。这是质性版的"效度/偏差控制"——主要服务 credibility/confirmability、对位量化整套效度论证（不是与 CMB 单项严格等价；若要类比 CMB 的同源偏差，对应的是"别只访单一信息源"那条）。详见 `references/trustworthiness-and-sampling.md`。

### 第 7 步 · 产出
按下方模板输出**研究者版**（Markdown），并附**后续验证清单**（专家 close reading、pilot、饱和评估、抽样与编码准备）。需要时导出**现场详版/现场简版** Word（见 `references/word-output.md`）。

## 产出模板

```
# [研究主题] 访谈提纲

## 〇、边界声明
本提纲面向数据收集工具的设计质量（与研究问题对齐、挖掘深度、降低诱导、为三角验证铺路），
不替代抽样、编码与主题分析，也不单凭提纲保证结论可推广——
可推广（transferability）靠厚描述、目的性抽样与跨案例分析。本提纲是案例的数据收集工具，
不是案例研究本身；案例可信度还需多源证据三角验证。

## 一、研究问题—访谈问题映射矩阵（设计逻辑）
| 研究问题(RQ) | 对应访谈问题编号 | 该题想挖什么 | 交叉验证的其他证据源 |
|---|---|---|---|
| ... | ... | ... | ... |

## 二、访谈对象与抽样说明
[关键知情人/精英/普通参与者；目的性/理论抽样逻辑；预估样本量与饱和判断]

## 三、提纲正文
[开场：自我介绍 + 研究目的 + 保密与录音知情同意]
[暖场/基本信息题]
[过渡题]
[核心题——按研究问题/主题分块，每题标注：服务哪个RQ、主问题/追问/探测、是否敏感]
[收尾兜底题]

## 四、可信度、伦理与反身性设计
[credibility/transferability/dependability/confirmability 各用什么策略；三角验证的证据源；是否成员核验]
[研究者立场性声明：身份/与受访者权力关系/圈内外/利害/预设命题，及其可能如何影响提问与解读；反思日记安排]
[研究伦理与合规：伦理审查前置判断（是否送审/批件号）、知情同意与录音单独同意、匿名化与保密口径、PIPL 去标识化、数据留存与销毁、退出与撤回权]

## 五、后续验证清单（本 skill 未替你完成的步骤）
- 专家评审：用 IPR 的"近读核查表"逐题朗读评审
- pilot：1–2 个试访，refine 题目与追问技巧
- 饱和：预估样本量——编码饱和约 9–17 人（Hennink et al. 2017；同质人群+窄主题时常约 12 人即可识别绝大多数码，Guest et al. 2006），意义饱和约 16–24 人，依异质性与主题复杂度上调（走反身性主题分析则用"信息力"而非饱和，Malterud et al. 2016）
- 抽样：目的性/理论抽样的具体标准；进入现场 access/引荐路径
- 分析准备：主题分析(Braun & Clarke)或案例分析(Yin 模式匹配/跨案例)的编码思路

## 六、设计依据（「方法论精解」档才展开）
[每个关键决定标注方法论依据 + 权威出处，见 references/]
```

**用途档位只分两档**（确认参数时若用户没说，默认「真实研究工具」）：

- **真实研究工具**（默认）：只给可直接上手的提纲，方法论依据在题旁做精简标注即可，不展开第六部分。你/团队拿去就能用。
- **方法论精解**（科研进阶）：在真实研究工具基础上，**额外展开第六部分**——为什么这样分块、为什么这道题这样问而不直接抛研究问题、为什么大游览开场、为什么敏感题放最后、三角验证怎么排，每个决定标注方法论依据与权威出处，便于深入理解、复用与写进论文方法章。

⚠ 措辞纪律：向用户确认档位时，用「真实研究工具 / 方法论精解」这类**科研导向**的称呼，不要叫「教学演示」「教案」——使用者是来做研究的，不是来上课的。

## 写完必做的自检清单

把这些当成 TodoWrite 逐条过：

1. **边界声明**在不在？没承诺抽样代表性 / 可推广 / 替用户编码吧？讲清"提纲≠案例研究本身"了吗？
2. **每道访谈问题都挂到某个研究问题**了吗（映射矩阵无孤儿题）？没有把研究问题原样抛给受访者吧？
3. 过了**7 条提问红线**吗（①诱导 ②双重负载/一题两问 ③封闭化 ④术语 ⑤生硬"为什么" ⑥抽象 ⑦社会赞许）？每题都是开放式吗？
4. 有**大游览开场**吗？敏感题靠后了吗？没用最抽象/最敏感的题开场吧？
5. 主问题—追问—探测**三层齐**了吗？收尾有**兜底题**吗？
6. **可信度四准则**各安排了策略吗？**三角验证**的其他证据源点明了吗（案例研究尤其必须）？写了**研究者立场性声明**、逐题查过是否夹带立场、精英访谈点明了权力不对等吗？
7. 为关键发现安排**搜寻反证/负向（偏差）案例**了吗（尤其快饱和、做可迁移性论证、或仅有滚雪球/便利样本时）？
8. **研究伦理与合规**到位吗：提示了**伦理审查前置判断**？知情同意含录音单独同意/可撤回？没承诺"完全匿名"（用保密+去标识化）？中文场景对接了 **PIPL**（去标识化/敏感信息单独同意）？
9. 访谈对象是精英/关键知情人时，用了精英访谈规范（敬语、做足功课、给开放空间、搜寻反证）与 **access/引荐**接口吗？涉及脆弱/权力不对等人群时加了专门保护吗？
10. **现场版没泄漏方法论标签**吧（没把"服务 RQ1""构念=X"印给受访者）？三版命名统一（研究者版/现场详版/现场简版）吗？
11. **所有引用的框架、方法、阈值、提出者，都 web 核查过真实出处了吗？**（IPR=Castillo-Montoya 2016；可信度四准则=Lincoln & Guba 1985；饱和=Guest et al. 2006 / Hennink et al. 2017；六类证据/三角验证/证据链=Yin；反身性=Berger 2015 / Finlay 2002）核不实就标"待核"或删——范例细节也不许凭印象补（记住 de Rond 教训）。
12. 后续验证清单给了吗（没假装替用户做访谈、pilot、编码）？中英双语时方法论术语并列了吗（可信度/trustworthiness、三角验证/triangulation、饱和/saturation、立场性/positionality、关键知情人/key informant）？

## 一条贯穿始终的纪律：宁缺毋编

质性研究的可信度建立在"研究过程透明可追溯"。**提纲与方法说明里出现的每一个框架名、提出者、文献、阈值（饱和人数、四准则归属），都必须能追溯到真实权威来源。** 找不到就标"待核/据……"或删除，绝不凭印象编一个像模像样的方法论引用——那比不引更糟，骗得过快速浏览的读者，骗不过方法论审稿人。这条对「方法论精解」档尤其重要：你在向研究者讲清方法依据、内容可能写进论文方法章，更不能示范一个假引用。常见幻觉：把 IPR 框架的四阶段记错、把"12 人饱和"的条件略去当成铁律、把可信度四准则张冠李戴、把 Yin 的六类证据数错、**把范例细节凭印象补全**（如 de Rond 战地案例的"诗歌/三阶段/医疗记录"——细节漂移式幻觉，出现在标杆位危害更大）、把 emic/etic 发明权记到 Spradley、把"完全匿名"当成访谈能兑现的承诺。
