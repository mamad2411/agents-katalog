# 读懂论文 · 参数提取

## 目标

给你一篇天线/电磁论文，我帮你把里面的设计逻辑和所有参数精确提取出来，让后续建模复现可以直接用。

## 为什么需要这一步

论文作者经常省略关键细节——材料参数没给全、网格设置一笔带过、端口去嵌处理提都不提。这一步就是要把这些"坑"找出来，避免你建模时反复试错。

## 多模态能力

若底层模型不具备原生识图能力，本技能通过 **vision 技能的多模态模型** (vision.js) 来处理论文中的所有图片。

### 什么时候必须用 vision.js

论文中以下内容在**正文文字中找不到或信息不完整**时，必须用 vision.js 读取图片：

| 图片类型 | 提取内容 | vision.js 提示词要点 |
|---------|---------|---------------------|
| 天线结构图 | 天线类型、层叠结构、形状 | "描述天线结构、各层材料、馈电位置" |
| 尺寸标注图 | 所有标注的尺寸变量和数值 | "读取所有尺寸标注，区分变量名和数值" |
| 加工实物照片 | 确认是否有文字未描述的细节 | "描述天线实物，注意接头、焊点、支撑结构" |
| 等效电路图 | 电路拓扑、元件值 | "识别电路结构和元件参数" |
| S 参数/方向图 | 趋势、关键数值范围 | "提取曲线趋势和关键点大致数值" |
| 表格截图 | 逐行读取 | "逐行读取表格数据" |

### 论文图片读取流程

```
论文 PDF
  │
  ├── 正文 → 直接读取（你的文本能力）
  │
  └── 图片 → 用户导出为 PNG/JPG 后
       │
       ├── vision.js 天线结构图 → 了解几何关系
       ├── vision.js 尺寸标注图 → 提取所有数字
       ├── vision.js 加工实物图 → 发现隐式细节
       └── vision.js 结果曲线图 → 确认 benchmark 范围
```

### 图片读取结果的使用规则

1. **尺寸数值**：图片中的标注数值与正文交叉验证。不一致时优先正文 > 表格 > 图片标注
2. **几何关系**：图片用于理解空间关系（如馈线在贴片哪一侧、层叠顺序），具体尺寸以正文和公式为准
3. **隐式细节**：图片中看到的但正文没提的结构（如 SMA 接头、支撑柱、调谐短截线），记录到 `assumptions` 中
4. **曲线对比**：图片中 S 参数的趋势和范围用于 Phase 5 验证时的视觉交叉检查

## 输出文件

- `model_spec.yaml` — 结构化参数，可直接喂给建模脚本
- `paper_notes.md` — 关键公式解读、逻辑梳理、存疑点记录
- `figures/` — 论文关键图片的提取记录（vision.js 返回的描述文本）

## 提取内容

### 1. 几何参数
```
每层介质：材料名、εr、tanδ、厚度
每个金属结构：形状、尺寸（用变量命名）、位置
地的处理：有限还是无限、尺寸
```
> 几何结构图 ← vision.js 辅助提取

### 2. 激励与边界
```
端口类型（波端口/离散端口/平面波）
端口阻抗
边界条件（open / periodic / 电壁磁壁）
对称面（如有）
```
> 馈电结构图 ← vision.js 辅助确认端口位置

### 3. 求解器设置
```
求解器类型（时域/频域/本征模）
频率范围
网格类型与密度
收敛标准（精度、最大pass数）
```

### 4. 设计公式
```
论文引用的设计公式
各变量物理含义与数值
公式适用范围和假设条件
```

### 5. Benchmark 指标
```
论文给出的 S参数值（谐振频率、带宽、S11最小值）
方向图指标（增益、波束宽度、副瓣电平）
效率数据
```
> 结果曲线图 ← vision.js 辅助确认趋势和范围

### 6. 隐式假设与缺失信息
```
论文没说但对复现有影响的因素
可能影响结果但没讨论的参量
```
> 实物照片 ← vision.js 辅助发现加工/测试细节

```yaml
  type: "waveguide_port"

  s11_min_db: -25

vision_extractions:
  - figure: "Figure 1 - 天线结构图"
    method: "vision.js"
    findings: "矩形微带贴片，嵌入馈电，单层基板，地平面覆盖整个基板底面"
  - figure: "Figure 2 - 尺寸标注图"

```

## 信息完整度评级

- **绿色**：参数齐全（正文+图片交叉验证通过），可直接建模
- **黄色**：有个别缺失（如图片模糊致某一尺寸不确定），需合理假设补充
- **红色**：关键信息缺失严重（结构图都没有或完全看不清），建议联系作者或换论文

## 论文图片导出方法

用户需要先将论文 PDF 中的图片导出为 PNG/JPG：

1. **Adobe Acrobat**：工具 → 导出 PDF → 图像 → PNG
2. **浏览器打开 PDF**：右键图片 → 另存为
3. **arXiv HTML**：直接右键网页中的图片 → 另存为
4. **截图工具**：Win+Shift+S 截取论文中的图

导出后告诉 Claude 图片路径，Claude 将调用 vision.js 进行识别。
