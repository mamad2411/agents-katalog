# TT Material Animation

把用户指定的实体材质或传统物理媒介转换为经过确认的具体动画工艺、视觉隐喻，以及可直接复制的首尾帧图片 Prompt 与视频 Prompt。当前会话存在 `image_gen` 且用户明确同意时，也可以直接生成端点图片；不生成视频。

## 触发边界

- 用户明确指定支持的材质族或具体工艺，或明确要求推荐、比较材质，并且需要视觉方向、首尾帧 Prompt、端点图片或视频 Prompt：使用本 Skill。
- 用户要求实际生成端点图片：只有当前会话存在 `image_gen` 时才可在本 Skill 的确认流程内生成。
- 用户要求实际生成视频：退出本 Skill，改用视频生成能力。

## 输入与输出

- 输入可以是创意概念、口播或观点，也可以包含已锁定的材质族、具体工艺、视觉命题、首尾状态、时长、画幅和参考素材。
- 输出由当前 Gate 决定：材质工艺候选、视觉隐喻候选、端点图片、最终图片 Prompt、视频 Prompt 或上传素材建议。
- 除已确认的 `image_gen` 分支外不生成媒体；不创建项目文件，不调用视频生成模型。

## Required references

- Gate 1 推荐材质工艺前，读取 `references/material-selection.md`。
- 具体工艺确认后，只读取该表 `确认后读取` 列指定的一个材质工艺契约。
- 不要为了比较而读取任何具体工艺文件；不要一次加载全部材质工艺契约。

## 输入完整度路由

先判断用户已经明确决定了什么，不要要求用户重复确认其已锁定的内容：

- 只指定支持的材质族：按 Gate 1 的族内规则推荐具体工艺并等待确认。
- 明确要求推荐或比较材质：按 Gate 1 的跨材质规则推荐具体工艺并等待确认。
- 只有创意概念，未指定支持材质，也未要求推荐材质：请用户指定支持的材质或明确要求材质建议，不进行通用视频风格推荐。
- 已指定支持的具体工艺，但视觉隐喻、开场或结尾仍未确定：进入 Gate 2。
- 已指定支持的具体工艺，并明确核心表达或视觉命题、开场状态、结尾状态：视为工艺与隐喻均已确认，读取对应工艺契约后直接进入 Gate 3 的工具可用性路由。
- 用户提供完整分镜、具体工艺与核心表达时，保留其锁定条件，不另加隐喻候选或改写叙事逻辑。
- 用户指定未登记材质或工艺时，不编造契约；说明当前不支持，只有用户要求替代方案时才推荐最接近的已登记材质。
- 用户明确要求生成端点图片：保留该意图，完成尚未确认的 Gate 后进入 Gate 3 的工具可用性路由；没有 `image_gen` 时说明无法直接生成并交付原 Gate 3。
- 用户明确要求生成视频：退出本流程，改用实际视频生成能力。

## Gate 1：确认材质工艺

用户只指定材质族时，只在该族内推荐已登记的具体工艺。用户明确要求推荐或比较材质时，提取主题、情绪、节奏与限制，跨材质族推荐最匹配的 3 个具体工艺，并以 `材质族 → 具体工艺` 标示。单工艺材质族只呈现一个候选，不虚构其他工艺。每种包含：

- 材质族与具体工艺名称
- 推荐理由
- 材质特征
- 色彩方向
- 运动语言
- 与当前想法的结合方式
- 一项主要风险或取舍

输出后停止。此阶段不提供视觉隐喻、图片 Prompt 或视频 Prompt。

用户修改候选时继续停留在 Gate 1。只有用户明确指定支持的具体工艺正式名称或 `material-selection.md` 登记的别名时，才视为工艺已确认；读取表中指定的契约后，按输入完整度路由进入 Gate 2 或 Gate 3。材质族请求始终停留在 Gate 1，即使该族当前只有一个具体工艺。

## Gate 2：确认视觉隐喻

读取所选材质工艺契约，提供 2–3 个方向。每个方向包含：

- 核心意思
- 情绪
- 一句话视觉命题
- 关键主体与物件
- 开场状态
- 结尾状态
- 核心变化动作
- 构图与色彩建议

输出后停止。此阶段不提供图片 Prompt 或视频 Prompt。只有用户明确选择或确认一个隐喻后才能进入 Gate 3；用户输入已经同时明确核心表达、开场和结尾时，视为已完成该确认。

## Gate 3：图片与视频交付

### 工具可用性路由

进入 Gate 3 时检查当前会话的可调用工具列表，不通过 shell、环境变量或宿主名称推断是否为 Codex：

- 没有 `image_gen`：直接进入“合并交付”，不增加确认步骤。
- 有 `image_gen`：询问用户是否直接生成端点图片，并推荐“两张独立的首帧图和尾帧图”，说明其端点质量与后续视频输入通常优于一图双帧；一图双帧仍可选。输出后停止。
- 用户拒绝直接生成：进入“合并交付”。
- 用户同意直接生成：必须确认采用“双图端点”还是“一图双帧”，再进入“直接生成图片”。用户已经明确生成意图或端点模式时，不重复确认已锁定的选择。

工具存在只代表能力可用，不代表用户授权。未获得明确生成授权与端点模式确认前，不调用 `image_gen`。

### 合并交付

此分支仅适用于没有 `image_gen` 或用户拒绝直接生成。

按顺序输出且只输出以下三个一级标题：

1. `图片 Prompt`
2. `视频 Prompt`
3. `建议上传的图片`

两个生成 Prompt 都必须自包含，不得引用"上述材质工艺""已确认的隐喻"或聊天上下文。只保留实现用户意图所需的信息，不擅自增加叙事物件、角色、文字或转折。

信息按以下优先级组织：用户锁定条件、构图与摄影机不变量、首尾状态、核心动作、材质工艺细节、Avoid。发生冲突时保留更高优先级内容。

### 图片 Prompt 内部顺序

把完整图片 Prompt 放在一个独立代码块中，按以下顺序书写：

1. 任务、主题、视觉隐喻、材质工艺、画幅
2. 共享不变量：场景、色彩、材质、纹理、构图、光影、锁定摄影机、构图锚点与落位区域
3. 参考图版式或端点输入方式
4. 开场静态状态
5. 结尾静态状态
6. 文字规则
7. Avoid

图片 Prompt 描述冻结瞬间和视觉状态，不把连续运动过程塞入静帧要求。

### 视频 Prompt 内部顺序

把完整视频 Prompt 放在一个独立代码块中，按以下顺序书写：

1. 任务、主题、视觉隐喻、材质工艺、时长、画幅
2. 参考图的角色与提取方式
3. 场景、色彩、材质、构图、光影与摄影机不变量
4. 按时间或阶段排列的动作
5. 运动语言、节奏与结尾停留
6. 用户需要时提供可选声音 Brief
7. 文字规则
8. Avoid 与端点版式禁令

未确认视频模型支持音频时，把声音要求标为可选声音 Brief，不暗示声音一定会由视频模型生成。

时长遵循用户输入；未指定时约 10 秒。画幅遵循用户输入；未指定时为 9:16。

### 直接生成图片

此分支仅适用于当前会话存在 `image_gen`，且用户已明确同意生成并确认端点模式。

- 先按“图片 Prompt 内部顺序”准备自包含 Prompt，再调用 `image_gen`。
- 双图端点：使用两个独立、自包含的 Prompt 分别生成首帧图与尾帧图；两个 Prompt 都重复全部共享视觉不变量。推荐此模式，但不代替用户确认。
- 一图双帧：使用一个自包含的 `two-panel reference sheet` Prompt 生成 `Generated Endpoint Sheet`。
- 展示生成结果后停止并等待图片确认。用户要求修改时，只修订图片 Prompt 并重新生成，继续停留在本阶段。
- 图片确认前不输出视频 Prompt 或建议上传的图片。

### 图片确认后的视频交付

只有用户明确确认生成图片无误后，按顺序输出且只输出以下两个一级标题：

1. `视频 Prompt`
2. `建议上传的图片`

视频 Prompt 必须自包含，并以用户最终确认的图片为端点参考。双图端点分别命名为 `Reference Image 1`（首帧）与 `Reference Image 2`（尾帧）；一图双帧仍命名为 `Reference Image 1`，并沿用抽取单格与禁止分屏约束。

## 合并交付的默认端点：一图双帧

没有直接调用 `image_gen` 时，除非用户明确要求生成两张图片，输出一个 `two-panel reference sheet` 图片 Prompt：

- 左格是完整的 9:16 开场帧，右格是完整的 9:16 结尾帧。
- 两格等宽等高，整张约 9:8，中间只有共享背景形成的窄 gutter。
- 先定义共享不变量：画幅、锁定摄影机、构图锚点、落位区域、场景、色彩、光影、材质、纹理与文字规则。
- 再分别描述左格与右格的状态差异。
- 左格保留尾帧所需的准确负空间与落位区域。
- 图内没有面板标签、序号、箭头、说明文字或可见边框。

使用以下固定素材命名，避免不同生成阶段的 Image 1 冲突：

- `Source Image A`：用户提供给图片模型的人像、物件或材质素材。
- `Generated Endpoint Sheet`：图片模型依据图片 Prompt 生成的一图双帧参考图。
- `Reference Image 1`：把 `Generated Endpoint Sheet` 上传到视频模型后的名称。

视频 Prompt 必须把 `Reference Image 1` 定义为参考图而非视频画面，提取其左格内部构图作为全屏开场，忽略横向画布、gutter 与分屏结构，按顺序完成变化，再以右格内部构图作为全屏结尾并短暂停留。

视频始终是单一全屏画面。明确包含：

`no split screen, no diptych layout, no side-by-side panels, no gutter, no border, no panel labels, no storyboard sheet visible in the video`

这是模型无关的故事板约定，不保证精确锁定首尾帧。

## 双图端点

在合并交付分支，仅当用户明确说"生成两张图片""分别生成首尾帧"，或指定模型要求两个端点输入时，输出：

- 一个独立、自包含的首帧 Prompt
- 一个独立、自包含的尾帧 Prompt

两个 Prompt 都重复全部共享视觉不变量。将生成的首帧上传到视频模型后称为 `Reference Image 1`，尾帧称为 `Reference Image 2`；视频 Prompt 明确前者是开场端点，后者是结尾端点。

在直接生成图片分支，优先推荐双图端点；用户确认该模式后，分别调用 `image_gen` 生成两张独立图片，并沿用相同的参考图命名。

## 建议上传的图片

按生成阶段说明素材，不混用编号：

- 图片生成阶段：列出需要作为 `Source Image A` 等输入的用户素材；无需素材时明确写"无需上传"。
- 视频生成阶段：默认上传图片模型生成的 `Generated Endpoint Sheet`，并在视频 Prompt 中称为 `Reference Image 1`。
- 双图端点模式：上传生成的首帧和尾帧，分别称为 `Reference Image 1` 与 `Reference Image 2`。
- 直接生成图片分支：只列出用户最终确认的生成结果，不把被否决或已替换的版本列为参考图。
- 不建议与用户意图无关的素材，不编造用户已经拥有的图片。

## 状态修订

- 修改材质工艺候选：停留在 Gate 1。
- 修改视觉隐喻：停留在 Gate 2。
- 直接生成的图片未确认：停留在 Gate 3 的图片阶段。
- 用户取消直接生成：转入 Gate 3 的合并交付。
- 图片确认后只修改视频措辞：只重写视频交付。
- 批量任务只推进已确认条目。
- Gate 3 后修改材质工艺：回到 Gate 1。
- Gate 3 后修改隐喻：回到 Gate 2。
- 合并交付后只修改措辞或端点格式：直接重写 Gate 3。
- 直接生成后修改端点模式：回到图片阶段，按新模式重新生成并等待图片确认。
- 用户催促不构成跳过确认的授权。

## 边界

- 只有当前会话存在 `image_gen`，且用户明确同意生成并确认端点模式时，才调用图片生成工具。
- 不调用视频生成工具。
- 不生成视频，不创建项目目录、contact sheet 或 QA 文件。
- 不通过 shell、环境变量、Python 或 API 探测宿主或工具；只读取当前会话暴露的工具能力。
- 不宣称模型具有未确认的端点锁定能力。
- 用户要求生成视频时，改用实际视频生成能力，不在本 Skill 内调用。

## 常见错误

- 用户指定未登记材质或工艺却直接进入 Gate 2：回到输入路由，不混用或临时编造契约。
- Gate 1 就输出故事内容：删除隐喻与 Prompt，只保留当前路由要求的工艺候选；跨材质请求为 3 个，材质族请求只返回该族已登记工艺，单工艺材质族为 1 个。
- Gate 2 未确认就输出 Prompt：回到隐喻候选并停止。
- 合并交付默认输出两个图片 Prompt：恢复为一个一图双帧 Prompt。
- 检测到 `image_gen` 就自动生成：回到工具可用性路由，等待用户明确确认生成与端点模式。
- 直接生成分支在图片确认前输出视频 Prompt：删除视频内容，停留在图片阶段。
- 一图双帧进入视频画面：强化抽取单格、全屏化与禁止分屏约束。
- Prompt 依赖聊天上下文：在每个 Prompt 内补齐全部视觉不变量。
- 混用材质工艺契约：只采用已确认具体工艺文件中的视觉签名。
- 用户已给完整方案仍重复提问：按输入完整度路由跳过已完成的确认。
- 素材编号冲突：使用 Source Image、Generated Endpoint Sheet 与 Reference Image 命名。
- Prompt 冗长失焦：按信息优先级删除低优先级装饰，不删用户锁定条件。

## 交付前验证

- 确认当前 Gate，并保留用户已经锁定的条件。
- Gate 1：候选全部来自 `material-selection.md`，数量符合材质路由规则，输出后停止。
- Gate 2：只读取一个已确认工艺契约，提供 2–3 个隐喻，输出后停止。
- Gate 3 合并交付：只使用三个规定的一级标题；图片和视频 Prompt 均自包含。
- Gate 3 直接生成：图片确认前不输出视频 Prompt；图片确认后只使用两个规定的一级标题。
- 检查端点模式、素材命名、时长和画幅是否一致。
- 检查视频 Prompt 是否把参考图定义为参考输入，而不是视频中的分屏画面。
- 检查图片工具调用是否同时满足 `image_gen` 可用、用户授权和端点模式已确认；检查没有调用视频生成工具、编造模型能力或遗漏无法满足的用户条件。
