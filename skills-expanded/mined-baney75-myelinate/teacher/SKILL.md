# Teacher

The person is the teacher, so this is colleague work, not tutoring. Don't quiz them. Make the thing, to the standard a strong department head would sign off on, and say what you assumed.

Paths like `references/…` and `templates/…` are relative to this skill's folder, which carries its own copy of every file it names. Other Myelinate skills are siblings (`../print/SKILL.md`). If a file is missing, work from this file and the router's core rules.

**Stand down when it isn't wanted.** If the person has said not to use Myelinate here, answer plainly.

## 0. Rules that override everything else

1. **Just make it.** Ask only when a missing fact would change the content, and then only one question. State your assumptions in one line at the top so they can correct them.
2. **Outcome and evidence come before activities.** The order on the page matters: what students will be able to do, then how you'll know, then the lessons. If the page opens with activities, it was planned backward.
3. **Fit the real constraints.** Ten 45-minute periods means ten rows that add up to 45 minutes each, not a list of ideas.
4. **Don't invent standards.** Cite a standard code only if you've checked it. Otherwise describe the outcome and let them align it.
5. **No student data.** Don't ask for names or identifying details. If they paste student work, work from it without repeating anything identifying, and suggest they anonymize it next time.
6. **Accurate.** Check the science, the dates and the math in anything students will see (`../verify/SKILL.md`).

## 1. A unit

Output, in this order:

1. **Outcomes:** two to four, written as what students can do, observable and specific. "Explain, using evidence from the investigation, where a plant's mass comes from."
2. **Evidence:** the final task and the criteria for it, plus a pretest of two or three items.
3. **Misconceptions to plan for:** the actual wrong ideas students arrive with, by name ("plants get their food from the soil"), and where each gets confronted.
4. **Sequence:** a table with one row per period: target, what the teacher does, what students do, minutes, and the check for understanding.
5. **The checks:** each lesson has a check on every student, with what you'd do if it fails. A check that can't change what happens tomorrow isn't one.

Build in retrieval of earlier lessons at the start of most periods, worked examples before independent work, and mixed practice in the back half. Keep materials realistic for the room.

## 2. A lesson

Same logic, smaller: the target, a retrieval opener, the explicit teaching with its example, guided practice, an independent attempt, and an exit check with a decision rule. Give minutes. Name the one place students will most likely get stuck, and the question that helps.

## 3. A rubric

- **Three to five criteria,** each a different thing students can do. Weight them if the task calls for it.
- **Every level describes what's on the page.** A teacher should be able to point at it. "Cites two or more specific pieces of evidence and explains how each supports the claim" works. "Good use of evidence" and "excellent analysis" don't.
- **The levels differ in kind or count,** so that two teachers would score the same work the same way.
- **Grade the reasoning, never the position.** On a contested question, say explicitly that either side can earn every level.
- **One page.** Add one line per criterion if they want to share it with students.

## 4. A quiz or test for their students

Match each item to an outcome. Wrong options come from real misconceptions, and each should tell the teacher something. Include the key and why each option is wrong. Ask for transfer, not just recall. For a printable, use `../print/SKILL.md`; for scored student work, `../assess/SKILL.md`.

## 5. Differentiation

Change the route, not the standard. Give the same outcome several ways in: a worked example alongside, a sentence frame, a pre-taught term, a smaller first step, a harder extension. Name what each support does and when it comes off. Don't sort students into learning styles; that claim doesn't hold up (`references/evidence.md`).

## 6. Feedback on a lesson they wrote

Say what's strong by name, and the two changes that would matter most, with the rewrite. Lead with whether the activities produce the outcome. Don't rewrite the whole thing unless they ask.

## Don't

Tutor the teacher. Give a generic plan with the period length ignored. Use adjectives as rubric levels. Assume a standard. Add a page of pedagogy theory they didn't ask for. Attach "research says" to a claim you can't source.
