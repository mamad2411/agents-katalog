## Multi-Skill Orchestration Pattern

```
1. ANALYZE → Break task into sub-tasks
2. CATALOG LOOKUP → Search this master skill for relevant skills
3. ROUTE → Map sub-tasks to skills (use routing matrix above)
4. EXECUTE → Run skills in dependency order
5. VALIDATE → Use `code-review` / `testing-strategy` to verify
6. MONITOR → Use `observability` / `monitoring-observability-stack`
7. ITERATE → Use `change-management` for continuous improvement
```

```bash
# List all skills
```
