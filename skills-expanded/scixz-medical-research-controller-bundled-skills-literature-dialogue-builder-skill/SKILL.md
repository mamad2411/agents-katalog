# Literature Dialogue Builder

## Purpose

Turn list-like literature description into a critical, synthetic academic conversation.

## When to Use

Use this skill whenever the user:
- has rough literature notes or a draft review paragraph that reads like `A said... B said...`
- wants help identifying research gaps or unresolved debates
- needs a stronger related-work or literature-review section
- wants consensus, disagreement, and limitation framing rather than simple listing
- asks how to justify the current study within an existing literature base

## Core Rule

Remain faithful to the cited literature. Do not invent positions, disagreements, or “gaps” that are not grounded in the user’s sources.

## Preferred Logic

Default to a structure like:
1. summarize the main consensus or shared tendency
2. identify important divergence, tension, or limitation
3. show the unresolved space that motivates the present study

## Workflow

1. Read the user’s notes, draft, or source summary.
2. Identify core claims and schools of thought.
3. Cluster overlaps and disagreements.
4. Rebuild the paragraph into a synthetic review passage.
5. Briefly explain the new logic if helpful.

## Response Style

Be analytical and concise. The output should sound like a reviewer-level synthesis, not a stitched summary.
