# Growth Skill Protocol

Use this skill when optimizing content, landing pages, release notes, or product documentation for search engines and generative AI answer engines.

## Execution Workflow

1. **Intent Analysis**: `search-intent-analyst` maps targeted search queries and AI prompt patterns.
2. **Dual-Optimization**:
   - Traditional SEO: `seo-specialist` optimizes technical metadata, schema markup, and site structure.
   - AEO (Answer Engines): `aeo-specialist` structures direct entity definitions, Q&A blocks, and citations for LLMs.
3. **Indexation Audit**: `content-indexer` tracks Google indexation status and LLM citation share-of-voice.
