# Bellingcat People Investigation Tools

Tools for finding information about individuals — searching by name, email, phone, username, and across data breaches and public records.

## Choosing Tools

- Start with the identifier you have—name, username, email, or phone number—and prefer sources that match that identifier directly.
- Treat search results as leads, verify identity with independent public evidence, and avoid collecting more personal data than needed.

## Investigation Tips

- Start with username search (Sherlock, Maigret, WhatsMyName) across hundreds of platforms
- Check email addresses against data breaches (Have I Been Pwned, Intelx.io, Leak-Lookup, DeHashed)
- Use Epieos/holehe to check what platforms an email is registered on
- For phone numbers: TrueCaller, GetContact, and country-specific directories (192.com for UK, Ratsit for Sweden)
- Search for name variants using Bellingcat's Name Variant Search tool
- Use Ghunt to find Google account information from an email address
- Cross-reference findings across multiple tools to verify accuracy
