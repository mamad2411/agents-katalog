# E資格（JDLA Deep Learning for ENGINEER）

**先に `question-authoring` スキル（共通ルール・適用手順）を読むこと。** viz（図解SVG）と calc（3段ロケット）の書き方・配色・PNG目視検証の手順は `question-authoring-stats` の該当節にすべて従う。ここは試験固有の情報だけ。

準拠シラバス: **「E資格 試験出題範囲（シラバス 2026）」第1.0版（2025年10月14日）／2026年8月試験（E2026#2）より適用**。2026年8月時点でこれが最新（直前まではシラバス2024が有効だったが、この問題集は次の適用版に合わせる）。
原本: https://www.jdla.org/download-category/syllabus/ （リポジトリにPDFは置いていない。細項目・キーワード全量が要るときは原本を引く）

⚠ **E資格のシラバスを非公式の対策ブログから拾わない。** G検定同様、細項目・キーワードは版によって出入りがある（シラバス2026ではCAM・正則化項の係数・IoTデバイスが削除され、パープレキシティ・Shifted window・Next token prediction・RAG・自己回帰・Integrated Gradientsが追加された）。カテゴリ名は完全一致 JOIN なので、ずれると行が黙って落ちる。

## G検定との違い（この問題集の設計方針）

G検定は「広く浅く・概念の弁別」、E資格は**JDLA認定の講座修了が受験前提の実装者向け資格で、数式・計算・仕組みの深さが要求される**。この問題集は g-kentei の構成（カテゴリ=シラバス大分類、terms/vs で用語弁別）を土台にしつつ、中身は stats-basics の厚み（calc 3段ロケット、viz 図解）を主役に寄せる。

- G検定で「Adam = モメンタム + RMSProp」と暗記させた話を、ここでは実際に更新式の意味を `calc` で追わせる、というレベル差
- **試験そのものに実装・コーディング問題は出ない**（実装力は受験資格である認定プログラム修了時点で担保される。本試験は択一式）。ただし「畳み込み後の出力サイズを計算する」「クロスエントロピー損失を数値で出す」のような**手計算で解く問題**は本試験にも見られる形式なので、この問題集でも重視する
- `code` 列・`snippet` は基本使わない（数式を見せたいときは `calc` に書く。コード片を見せる価値がある場面のみ例外的に使う）

## カテゴリ名（完全一致で JOIN。番号込みで書く）

公式シラバスの**大分類5個**をそのままカテゴリにしている（G検定が大分類10個をカテゴリにしたのと同じ粒度の考え方）。中分類・小項目はカテゴリにしない。

**シラバスのグレー網掛け（オプション扱い＝出題対象外）は出題しない。** 2026版では線形代数の一部（行列演算・固有値分解）と確率・統計の大半、機械学習の多くの中項目（k近傍法〜性能指標の一部）がオプション表記になっている（原本PDFのグレー部分を参照）。**ただし G検定と違い「除外＝出題しない」という明確な公式方針ではなく、あくまでシラバス上の重み付けの目安。** この問題集では、オプション表記の項目も**基礎理解として出題してよい**（実装者としての土台知識であり、他区分（stats-basics・g-kentei）との重複可）。オプション/必須の区別が要る作問判断に迷ったら原本PDFで網掛けを確認する。

## 出題形式（公式・非公式ソースの一致で確認）

- CBT方式、**120分・100問前後、全問4択の多肢選択式**（複数選択もある）。**1問あたり約1分12秒**（G検定の41秒よりは余裕があるが依然として短い）
- **受験資格として JDLA 認定プログラムの修了が必要。** 試験そのものにコーディング問題は出ない（コーディング力は認定プログラム側で担保）。ただし計算問題（出力サイズ、損失値、寄与率など）は出る
- 合格ラインは非公表（推定 6割前後）。合格率は概ね 63〜78%で推移（直近 2025年第1回 68.26%）

## 解説の流儀

`asked` / `why_asked` / `kid` / `terms` / `think` / `calc` / `eg` / `vs` / `opt` を付ける。**`viz` は仕組み系に手厚く付ける**（g-kentei よりさらに比重を上げる。E資格は「なぜそのアーキテクチャが効くか」を問う試験のため）。

- **`terms` は用語弁別に使う**（G検定と同じ）が、ここでは**数式の記号の読み方**も terms に入れてよい（例: `["Σ", "総和記号。全部足すという意味"]`）
- **`calc` は「計算問題には必ず付ける」を徹底する。** 出力サイズ計算、損失関数の数値計算、寄与率、Gini係数、ユークリッド距離など、公式に数値を当てはめて手を動かせる問題には全部付ける。書き方は `question-authoring-stats` の3段ロケット（日本語→小さい数字で全ステップ→記号版）に完全準拠。**読者の数学は「G検定レベルの直感は済んでいるが、シグマ・行列・微分の記法にはまだ慣れていない」前提**（[[user_career_background]] 参照。ユウは中1以降の学校数学を経ていない）
- **`viz` は「なぜ効くか」に絵があるものに絞る**（question-authoring-g-kentei と同じ判断基準）。定番: 計算グラフ（誤差逆伝播・連鎖律）、CNNの畳み込み窓とストライド、RNNの展開図とBPTT、LSTMのゲート、Attentionの重み、Skip connection（ResNet/U-Net）、Encoder-Decoder、GANの生成器/識別器、混同行列、k近傍・k-meansの点群、SVMのマージン、活性化関数の曲線比較、Bias-Varianceのトレードオフ曲線
- 統計・G検定と重なる概念（正則化・混同行列・活性化関数・Adam等）は viz を流用してよいが、**E資格の文脈（実装者視点）に合わせて構図か文言を調整する**（同じ絵をコピペで文脈だけ差し替えるのは避ける。stats-basics/g-kentei は「なぜ」重視、E資格は「どう計算に効くか」重視）

## 内容の注意

### 頻出（シラバス改訂履歴と過去問傾向の一致から）

- 誤差逆伝播法（連鎖律）、CNNの出力サイズ計算、Adam系最適化アルゴリズムの更新式、RNN/LSTM/GRUのゲート、Transformer の Self-Attention と Scaled Dot-Product Attention
- 生成モデル（VAEのReparameterization Trick、GANのモード崩壊、拡散モデル）— 2026シラバスで自己回帰・RAG・Next token predictionが追加され、LLM関連の比重が増した
- 深層学習の説明性（XAI）: Grad-CAM、Integrated Gradients、SHAP/LIME（2026シラバスでCAMが削除されGrad-CAM/Integrated Gradientsに整理された点に注意）

### 引っかけの定番（G検定と共通する土台＋E資格固有）

- **k近傍法（教師あり・分類）と k-means（教師なし・クラスタリング）は別物**（G検定と同じ罠がここでも通用する）
- **バギング（Random Forest、並列・分散低減）とブースティング（勾配ブースティング、逐次・バイアス低減）は逆方向の効果**
- **Self-Attention（同一系列内）と Source Target Attention（Encoder-Decoder間）は参照先が違う**
- L1正則化（スパース化・特徴量選択）と L2正則化（重みを均等に縮小）の効果の違い
- **バッチ正規化（ミニバッチ単位）とレイヤー正規化（サンプル単位、系列長に依存しない）** — Transformer系はLayer Normが標準という文脈で問うと効く
- 事前学習（BERTのMLM/NSP）とファインチューニングの役割分担

### この問題集固有の除外・注意

- シラバスのグレー網掛け（オプション）領域も出題してよい（上記の通り）が、**細項目の暗記（正式名称の綴りなど）だけを問う問題は作らない**。仕組み・使い分け・計算で理解を問う
- 音声処理（サンプリング定理・MFCC等）・強化学習（DQN/A3C）は他区分に重複が無い領域なので厚めに書いてよい
