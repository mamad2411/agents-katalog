# Pythonクイズ（通勤ドリル）

**先に `question-authoring` スキル（共通ルール・適用手順）を読むこと。** ここは試験固有の情報だけ。

資格試験ではなく、Pythonの文法・標準ライブラリの「知っていないと詰まる」挙動を通勤・移動時間に一問一答で確認する自主コンテンツ。出題形式は**「このコードを実行すると何が出力される？」**で統一されている。

## 出題形式（固定フォーマット）

- **`code`列（questions.code）に実行するPythonコードスニペットを必ず入れる。** これが主役で、`question_text`は「このコードを実行すると何が出力される？」のような定型文でよい（同じ定型文の繰り返しでよく、G検定のように問題文の多様性は求めない）
- **選択肢は「実際の出力」の候補。** 正解の出力＋「ありがちな勘違いをするとこうなる」誤答3つ。`エラーになる`を選択肢の1つに入れてよい（本当にエラーになる問題も、エラーにならないのに「エラーになる」を誤答として置く問題も両方作ってよい）
- **コードは必ず自分の頭の中で実際に実行して出力を確認してから問題にする。** Pythonの実行結果を誤って書くと即座に問題として破綻する（他区分より正確性のシビアさが一段高い）。特に注意: 辞書のキー順序（3.7+は挿入順保持）、セットの表示順（不定なので出題を避けるか順序に依存しない出力にする）、浮動小数点の丸め誤差、`is`と`==`の違い、可変デフォルト引数の使い回し、リストのコピーの深さ

## 選択肢の作り方

`question-authoring`の一般ルール（正解だけ長い・詳しいを避ける、位置参照を書かない等）に加えて:

- 出力候補は**見た目の桁数・記法を揃える**（例: `[1, 2, 3]` と `[1,2,3]` のようなスペース有無だけの違いを正誤の分かれ目にしない。実際のPythonの`print`出力の書式に忠実に）
- 誤答は「ありがちな勘違い」を再現する: 破壊的メソッドが値を返すと思い込む（`.append()`は`None`を返す等）、浅いコピーと深いコピーの混同、スライスの端点の解釈違い、演算子の優先順位の勘違い、可変長引数のアンパックの向きの取り違え等

## 解説の流儀（explanation-clarity 6テコをフル装備。2026-08-04〜）

既存の初期47問は`asked`/`think`/`opt`のみだったが、2026-08-04の拡充で全問に以下を揃える方針に統一した（既存分は非破壊マージで追記済み）:

| キー | 必須 | 内容 |
|---|---|---|
| `asked` | ○ | 何を問うているか（定型文でよい） |
| `point` | ○ | 決め手。「〜なら○○」形の一撃の判断ルール。多くは「使ったメソッド／構文が何をするか」を1文で |
| `why_asked` | ○ | なぜこの挙動を知っておくべきか（実務でハマりやすい理由） |
| `kid` | ○ | ざっくり言うと。コードの動きを日本語の文章で追う |
| `eg` | ○ | たとえると。プログラミング外の身近な比喩（kidとは別角度） |
| `terms` | ○ | 使われているメソッド・構文の名前と意味 `[["用語","説明"], ...]` 2〜4個 |
| `think` | ○ | 考え方。コードを1行ずつ実行結果を追う因果の流れ |
| `vs` | ○ | 紛らわしい挙動・似た構文との違い（例:`.append()`と`+=`、`copy()`と`deepcopy()`） |
| `opt` | ○ | 選択肢の解説。選択肢と同数、正解は「正解。」で始める |
| `viz` | 任意 | 参照・コピー・スコープなど「メモリ上で何が起きているか」が絵になるものだけ。値の変化を箱と矢印で描くと効く（ミュータブル/イミュータブルの区別、浅いコピー vs 深いコピー、クロージャの変数捕捉等） |
| `calc` | 通常不要 | 数値計算主体の問題集ではないので基本使わない |
| `snippet` | 使わない | `code`列が既に模範コードの役割を兼ねる |

`kid`と`think`はどちらも「コードの動きを追う」内容になりがちなので書き分けに注意: **`kid`は結論寄りの要約**（「appendで足してpopで抜くから元と同じ形に戻る」）、**`think`は1行ずつ追う詳しい過程**（「1行目で...、2行目で...、だから最終的に...」）。

## 内容の注意

- **「文法」問題集なので、標準ライブラリの細かい引数名の暗記のような瑣末な出題は避ける。** 挙動の理解を問う（可変/不変の違い、参照とコピーの違い、スコープの捕捉タイミング、例外の伝播順序等）
- 他のPython関連スキルは無い（このリポジトリで唯一のPython問題集）。stats-basics/g-kentei等のcalc/viz流儀とは独立した設計
