## Project Overview

Deep learning research repo for predicting fractal turbulence parameters (`k_min`, `k_max`, `sigma`) from synthetic fractal cloud images. The full pipeline: synthetic data generation (pyFC) → HDF5 datasets → CNN training and evaluation.

## Environment Setup

```bash
# Conda (Python 3.9)
conda env create -f environment.yml
conda activate py39

# Or pip (Python 3.11)
pip install -r requirements_py311.txt
```

The `src/pyFC_lib/` directory must be on `sys.path` for pyFC to import. The generation scripts handle this automatically via `sys.path.insert`.

## Architecture

### Data Generation Pipeline

`src/dataset_generator.py` — `DatasetGen` class is the core generator:
- INI-driven config (`configs/dataset_config.ini`) with safe expression parsing (supports `np.sqrt(5.)` etc.)
- Generates `pyFC.LogNormalFractalCube` slices, log10-transformed, stored as float32
- Serial or parallel (`num_workers`) generation, batched writes to HDF5
- pyFC API compatibility wrapper (`_gen_cube_compat`) handles version differences in seed kwargs

`src/param_sampler.py` — `ParameterSampler` for the flexible workflow:
- Per-image continuous sampling of `k_min`, `k_max`, `sigma`, `mean`
- Enforces Nyquist limit: `k_max <= floor(max(ni, nj, nk) / 2)`
- Supports `uniform` and `exponential` (skewed toward larger values) distributions

**Generation scripts** (`scripts/`) all configure via environment variables. The flexible script (`run_generation_flexible.py`) is the current primary workflow; legacy scripts (`run_generation_random_*.py`, `run_generation.py`) remain for reference.

### HDF5 Layout

Two layouts exist — code must handle both:

- **Flat** (generated by `DatasetGen` or flexible script): `/images` (N, H, W) + `/parameters/{k_min, k_max, sigma, mean, beta, ni, nj, nk, seed}`
- **Grouped** (after merge/append): `/{HxW}/images` + `/{HxW}/parameters/...` — supports multi-resolution datasets

`DatasetGen._detect_layout()`, `load_dataset()`, `merge_datasets()`, and `append_dataset()` all auto-detect and handle both layouts.

### Model Packages

**`src/fractal_classifier_01/`** — Classification-first framework (TensorFlow/Keras):
- YAML-driven config (`config/default_config.yaml`)
- Modules: `data/`, `models/`, `training/`, `evaluation/`, `visualization/`, `analysis/`
- CLI: `scripts/train.py`, `scripts/evaluate.py`, `scripts/analyze.py`
- Kernel analysis and convergence tracking (see `KERNEL_ANALYSIS_GUIDE.md`)

**`src/fractal_classifier_02/`** — Lightweight regression framework (PyTorch, depthwise-separable CNN ~180K params):
- Depthwise-separable CNN (~180K params), Huber loss for continuous `k_min` prediction
- CLI: `scripts/train.py`, `scripts/evaluate.py`

### Key Parameter Constraints

- `k_min >= 1` (pyFC physical minimum)
- `k_max <= floor(max(ni, nj, nk) / 2)` (Nyquist limit)
- `k_min < k_max`
- `sigma > 0`
- pyFC uses `kmin`/`kmax` (no underscore) as kwargs; stored parameters use `k_min`/`k_max`

### Data Files

Generated datasets live in `data/raw/*.h5`. Performance JSON summaries are written to `data/raw/perf/`. Outputs (model checkpoints, figures) are organized under `outputs/{kmin,kmax,sigma,comparison}/`.

## Testing

Tests cover `DatasetGen` only (not the model packages). They use `configs/test_config.ini` with small dimensions for speed. The test runner at `tests/run_tests.py` accepts class names as positional args.
