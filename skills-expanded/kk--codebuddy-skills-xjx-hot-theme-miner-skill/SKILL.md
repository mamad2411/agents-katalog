# 热门题材挖掘 Skill

## 触发时机

当用户提出以下需求时，使用此 Skill：
- 今日/当前最热门题材是什么？
- 挖掘热点题材/热门板块
- 哪些股票最有上涨潜力？
- 题材龙头股分析
- 最热题材Top3 / 最具潜力个股Top5
- 市场热点挖掘 / 主题投资机会

## 核心能力

### 1. 热门题材挖掘（Top3）
- 实时获取东方财富概念板块涨幅、涨停家数、资金流入
- 基于「驱动力 × 资金强度 × 可持续性」三维评分模型排序
- 输出每个题材的：驱动逻辑、想象空间、生命周期阶段
- 标注题材级别：短期事件催化 / 中期产业趋势 / 长期战略方向

### 2. 个股筛选（Top5）
- 在Top3题材成分股中，叠加五维过滤：
  - 题材核心度：龙头地位、涨幅排名、市值排名
  - 技术形态：涨幅、换手率、量比
  - 资金面：主力资金流向趋势
  - 基本面：营收/净利增速、PE、ROE
  - 催化剂匹配度：业务与题材驱动因素的契合程度
- 综合评分排序输出Top5标的

### 3. 中长期价格空间预测
- 基于估值修复空间 + 业绩增长空间
- 给出6个月/12个月目标价区间（乐观/中性/悲观三情景）
- 计算上涨空间（%）并标注置信度

### 4. 操作策略输出
- 对每只个股输出：建议仓位 + 入场时机 + 止损设置 + 出场信号
- 风险提示：估值风险、题材证伪风险、追高风险、流动性风险、监管风险

## 执行流程概览

```
Step 1: 市场情绪采集 → 涨跌停统计、情绪评级
Step 2: 题材数据采集 → 概念板块行情 + 涨停股匹配
Step 3: 题材评分与Top3筛选 → 三维评分 + 生命周期判定
Step 4: 成分股数据采集 → 候选股资金流向 + 基本面
Step 5: 个股评分与Top5筛选 → 五维评分 + 龙头标注
Step 6: 价格预测与策略生成 → 三情景目标价 + 操作建议
Step 7: 报告组装 → 完整 Markdown 报告输出
```

详细流程参见 [`references/execution_pipeline.md`](references/execution_pipeline.md)。

## 注意事项

1. **数据实时性**：建议在交易日盘中（9:30-15:00）或收盘后运行，获取当日最新数据
2. **题材周期**：生命周期判断具有一定滞后性，高潮期信号出现时可能已接近尾声
3. **价格预测**：中长期目标价基于当前基本面，业绩变化可能导致预测偏差
4. **仓位管理**：建议单一题材仓位不超过总仓位30%，严格执行止损
5. **免责声明**：本分析仅供参考，不构成投资建议
