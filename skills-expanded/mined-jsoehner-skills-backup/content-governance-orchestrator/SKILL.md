## When to Use

Use for generating technical documentation, office file creation (PDF, DOCX, PPTX, XLSX), or SEO-optimized content creation and auditing.



## Procedure

1. Identify the content type: Technical Docs (Tutorials/Reference), Office Docs (PDF/DOCX/PPTX/XLSX), or SEO Content.

2. For Technical Docs: Use `tutorial-engineer` for step-by-step guides and `reference-builder` for API/Configuration guides. Apply `writing-clearly-and-concisely` rules.

3. For Office Docs: Use the respective format-specific skills (`docx`, `pdf`, `pptx`, `xlsx`) to generate, edit, or analyze documents.

4. For SEO Content: Use the SEO suite (`planner`, `writer`, `refresher`, `authority-builder`, `cannibalization-detector`, `meta-optimizer`, `snippet-hunter`, `structure-architect`) to optimize for E-E-A-T and ranking.

5. Synthesize the final output to ensure it meets the target audience's needs and follows the project's brand voice.



## Pitfalls

- Avoid 'AI-sounding' prose; use the 'writing-clearly-and-concisely' rules.

- Ensure SEO content is balanced between keyword density and human readability.

- Verify all technical documentation (tutorials/reference guides) matches the current implementation.



## Verification

1. Technical documentation is clear, accurate, and follows the correct format.

2. Office documents are correctly formatted and contain all required data.

3. SEO content is optimized for both search engines and human users.
