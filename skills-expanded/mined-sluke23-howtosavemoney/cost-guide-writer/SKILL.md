# 成本结构说明书写作器

**把本书体例抽象成“给任意主题写同款说明书”的纪律。**

目标是写出帮助读者做决定的说明书：先看懂成本为什么产生，再知道什么情况下选什么、怎样验证、第一步做什么。迁移问题组织、计算与证据方法，不机械复制原书章节数量、城市结构或口号。

本 Skill 作者：毛毛&luke。可独立安装，路径以本目录为基准；[体例样本](references/guide/目录.md) 仅用于观察写法与修订方法，其历史价格、政策和经验不能直接当成新主题的事实依据。

## 确定这次要交付什么

先利用用户已有材料明确：主题、读者、他们要做的决定、地域/版本/时间范围、预计使用周期，以及要整篇、单章、目录还是改稿。只追问会改变结论或篇幅的关键缺口；其他可说明假设后继续。

- **写新稿**：按用户范围完成正文；要求成稿时，不停在目录或写作建议。没有现成数据可以写已知方法、条件化结论和明确标注的假设算例，不能补造事实。
- **搭框架**：交付按决策组织的目录、各章要回答的问题、需要的资料和拟做的算例；未核实内容写成调查任务，不装成正文结论。
- **改旧稿**：保留用户已确认的目的与事实，定位比较口径、数字、依据和行动的缺口，交付改稿及影响结论的修改/待核实项。不要为了像原书而改掉原主题。

未指定格式时默认 Markdown。只需短文就做一篇可独立阅读的说明书；需要长稿再采用分章、总目录、工具表和核查记录。不要因调用本 Skill 自动创建 GitHub 项目、网站、PDF 或发布流程。

## 把主题变成一组读者决定

读取 [写作体例与迁移方法](references/writing-method.md)。先定义需求与最低可接受条件，再找主要成本由谁、在什么时候、按什么规则承担。比较时保留现实可行的现状方案；借用、租赁、维修、短期试用或暂不购买等，只有适用时才加入。

目录围绕“选不选、怎么选、如何开始、用起来如何维护、何时退出/复核”等实际问题展开，随主题调整；不拿产品类别或知识百科替代读者决策。不能量化的质量、隐私、照护或健康等因素可以单列约束与取舍，不强行折成钱。

## 先把账和依据立住，再写结论

涉及比较、金额、研究、政策、资费或操作步骤时，读取 [成本与依据纪律](references/cost-and-evidence.md)。统一功能、质量底线、用量、期间、币种与费用边界，区分一次性支出、持续支出、可退资金占用、时间投入与不确定损失。

重要数字列输入、公式、单位、期间和假设，用可用计算工具复核；至少呈现能让结论改变的关键条件。需要算例而没有实价时，明确使用假设数字；不以“示例”掩盖假引文、假政策或捏造的用户经历。未知成本写未知及查法，不当零。

具体事实只引用实际读到且能支持该项结论的资料。政策查适用的官方原文与办事指南，报价查对应规格与条件，技术限制查相应版本文档，效果主张查适合该问题的研究；用户账单与自述说明来源。访问不到就保留缺口，不能把主页、搜索摘要或本文样本当完成核实。纯假设演示不需要为虚构报价寻找“官方背书”。

## 写成能执行的正文

每个核心决策至少让读者知道：**何时适合、成本怎么算、结论会在哪些条件下变化、下一步如何核对或行动。** 有重要事实或数字就给依据，证据不足则收窄结论。字段可以融入连贯文字，不必每节都摆同一套表头；无须机械套入政策、月份和补贴。

结论尽量写成“在这些条件下，方案 A 在这个指标上更合适”；紧接比较表或算例解释原因与局限。第一步要有对象、动作和完成凭据；检查、提交、审批、生效与实际结果分别写清。不要把“去了解一下”“按需选择”当作整节的行动结论。

去 AI 味靠补条件、数字和具体动作：删“终极、铁律、人人必省、半小时搞定”等无依据断言；少用反问、整齐口号与空洞小结。原书也有待核实公式和简化表述，不能照搬。跨主题完整示例与编辑注释见 [家庭打印示例](references/worked-example.md)，需要观察成稿如何串起条件、计算和行动时再读。

## 交付前查能否复算、能否照做

按用户要求的规模交付，并做以下针对性复核：

- 选择与比较是否服务同一需求？是否漏掉关联收费、首期资金或退出成本？标题是否超出了正文能支持的范围？
- 表格、公式、正文结论是否一致？期间、用量、分母、整数门槛与情景边界是否正确？同一收益或成本有没有重复算？
- 引用是否真能支持相邻结论？适用对象、地区、版本、时间及未确认项是否写清？假设、用户事实和当前资料是否分开？
- 读者能否从第一步开始，并知道何时算完成、何时应换方案或重新核对？未核实部分是否影响了直接操作的可靠性？

发现错误要改正文、表格和计算，不只在末尾加免责声明。交付主要成稿，必要时附简短核查记录与待核实项；短稿不强制另造许多文件。保留用户署名、许可与既有章节链接要求，既有项目改稿时只同步实际受影响的产物。
