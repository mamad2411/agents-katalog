# 隐性收入申领对照器

**你的情况里，有哪些城市发给你的钱忘了领？**

把用户的情况和待遇条件逐项对照，找出值得补查、补填、补办的项目，说明归谁办理、还缺什么、下一步去哪查。范围包括城市项目、全国性税收与社会保险制度，分别标明主管部门和适用地区。作者：毛毛&luke。

内置资料来自《一线城市省钱指南》，版本和来源哈希见 [source.json](references/guide/source.json)。整个文件夹可独立安装、离线读资料；路径均相对本 Skill 目录，不依赖其他 Skill。离线快照用于发现线索，当前金额、窗口和资格仍需查现行官方原文。

## 先收集会影响判断的情况

优先使用已经提供的信息。没有城市时先问城市；有城市可先列少量相关项目，再补关键缺口，不让用户填完长问卷才能得到帮助。

- 初筛：所在城市及必要的区、目前在职/待业/求职/灵活就业/退休、租房或自有住房、最近的变化，如毕业、入职、离职、取证或生育。
- 按命中项目再问：工作、参保、公积金缴存、户籍和居住是否同地，相关缴费时长；税务年度及有无预缴、已有扣除；毕业或证书时间与类型；配偶和子女等项目要求的家庭条件。
- 每个候选都确认“是否已申报、已按月享受、自动结算、由单位办理、已到账或正在审核”。不知道享受状态不能直接说“忘领了”。

只需回答条件或遮盖信息后的摘要，不索要身份证号、银行卡号、验证码、登录口令、完整住址或未经处理的病历。精确日期仅在核对窗口、追溯或待遇期间时补问。用户不愿提供的条件标为待确认，不替其假定。

## 按生活事件挑项目

先读 [待核实清单](references/guide/docs/待核实清单.md)，再用 [项目对照与追问](references/benefit-map.md) 挑选相关项目，读取所引用小节全文。章节索引见 [资料目录](references/guide/目录.md)。通常从以下范围开始，不把所有项目都推给每个用户：

| 情况 | 优先对照 |
| --- | --- |
| 在职租房、有公积金或缴过个税 | 租房提取、住房租金扣除、年度汇算；已按月享受的另记 |
| 刚毕业、新入职、持有职业技能证书 | 当地就业/人才/技能补贴、住房支持；先核项目是否实际存在并受理 |
| 离职、裁员、合同结束或暂时无收入 | 失业保险金及医保衔接；自费参保补贴等仅在查到当地依据后补充 |
| 生育、照护孩子或赡养老人 | 生育待遇、育儿相关项目、相应税收扣除及可用公共服务 |
| 发生就医支出或异地就医 | 已结算报销、可补办事项、大病医疗扣除，避免重复计算 |
| 本来就计划换家电、数码产品 | 当前消费补贴及资格限制；不为拿补贴新增不必要支出 |

四城之外可按相同方法筛查，再查当地规定；区级、园区或单位申报项目不能扩展成全市人人适用。原书无覆盖的新项目标为补充检索，来源写实际读到的官方材料，不虚构章节出处。

## 核对后再写结论

涉及现在能否办、多少钱、截止日、材料或操作路径时，按 [官方核对与金额口径](references/verification.md) 查主管部门现行文件和办事指南。具备联网能力就核对；不能联网或访问受阻时，给待查条件、机构入口和咨询问题，保持“规则待核实”。

每项同时记录公开规则的核对状态、个人条件的匹配状态和办理状态，不能由“政策存在”推导“本人可领”，也不能由“本人初步匹配”推导“一定到账”。已读原文也仅能作按用户信息的初步对照，审批结果以经办机构为准。

优先排查窗口临近且有依据的项目，再考虑已知匹配、办理成本和实际用途。未查明的截止日写待查，不编造日期制造紧迫感；对不匹配、已享受或已过窗口的项目说明理由，必要时询问合法更正、补报或复核程序，不默认过去几年都能追领。

## 给出申领对照结果

先给最值得处理的少量项目和关键原因，再用简洁表格列“项目与权益类型、为什么与我有关、还缺什么/是否已享受、规则与匹配状态、下一步及期限”。表格放不下的材料、官方链接和金额依据接在对应项目后，不堆成十几列。

对优先项目，给足完成下一步所需的信息：适用地区及年度、本人还是单位申请、需由谁提供的材料、直接办事指南和查询日期；未核实字段明示待查。菜单名称只引用实际读过的指南，不凭印象编造点击路径。用户已有申请记录时，转为查进度、补材料或确认是否重复申报，不再列为新漏领。

金额分别呈现：现金补贴/保险待遇、税款减少或退还、账户资金提取、实物/服务及消费减免。只在期间、条件和互斥关系都明确时，汇总同口径且可同时享受的金额；未知不当零，月度和一次性不直接相加。专项扣除额不是退款，公积金提取不是新增收入，生育津贴不与同一期间已发工资盲目相加。具体复算示例见 [金额口径](references/verification.md#金额怎么写)。

来自指南的建议标注实际读过的本地章节链接；政策结论附实际读取的官方原文及日期；按用户数字的计算注明公式、单位、期间和假设。区分用户自述、历史快照、当前原文和个人测算，不把源文件哈希或文档修改日期当成现行性证明。

## 办理边界与许可

帮助整理清单、材料摘要、咨询问题和申报内容草稿。实际登录、提交、签署、联系经办机构或设置外部提醒需要用户明确授权，不因调用 Skill 自动执行。官方系统需要实名材料时让用户自行在官方入口提交；不建议虚构离职原因、租赁、亲属或劳动关系来满足条件，也不为补贴鼓励购买证书课程、挂靠参保或重复申报。
