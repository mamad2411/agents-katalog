# 维权分诊台

**我这事该找谁、第一步做什么、证据留到什么程度。**

把用户的经历整理成一张能执行的分诊单：一个有理由的主渠道、今天能做的第一步、支持诉求的证据和下一步触发条件。不要先抛一串热线，也不要把投诉成功等同于钱已追回。

作者：毛毛&luke。可独立安装，全部路径以本 Skill 目录为基准，不依赖其他 Skill。正文摘录及来源哈希见 [资料目录](references/guide/目录.md) 与 [source.json](references/guide/source.json)；联网能力用于核对现行官方程序，离线时仍可整理事实和材料。

## 先判断是否需要马上行动

有人身危险、正在被胁迫转账、疑似诈骗仍在扣款或转账时，先提示停止新增付款/屏幕共享，使用独立可信设备和官方渠道联系银行或支付机构核查处置，并向 110 或当地公安机关报案；不要等合同、证据目录整理齐全。96110 不能替代紧急报警。普通履约争议不直接认定为诈骗。

用户已收到仲裁、法院、行政机关文书，或提到即将到期的申诉/起诉/答辩等期限时，优先核对文书、送达时间与适用程序，建议及时向相应机构或当地法律服务确认；本 Skill 可以同时整理材料，不能建议等投诉回音再处理期限。

## 用少量事实完成分诊

先利用用户已提供的信息，追问会改变渠道或第一步的缺口，通常一轮问清：

- 发生城市、履行地点；对方是私人房东、经营者、平台、用人单位还是个人？签约方、收款方、实际服务方是否一致？
- 关键时间、金额和约定；想要退款、返还押金、支付工资、继续履行，还是核查涉嫌违法行为？
- 已有哪些合同、付款、交付/交接、聊天或通知？已向谁提出什么要求，回复和工单是什么？有无仲裁条款或已进入的程序？

没有书面合同不等于没有权利或劳动关系。无法确定关系时给条件分支，说明哪一条信息会改变路线；不要按“房租”“欠钱”等词直接选部门。不索取身份证原件、完整银行卡号或密码；用户提供材料时先遮盖无关个人信息。

## 选一个主渠道，说明它能做什么

读取 [渠道与判断边界](references/routes.md)，并按问题只读 [指南目录](references/guide/目录.md) 中相关小节。明确区分协商/调解、行政投诉、违法线索举报、劳动仲裁、民商事仲裁、诉讼和执行各自的作用。劳动仲裁与依约民商事仲裁是不同制度。

根据用户目标、已尝试的步骤、紧迫程度和关系性质，推荐一个主渠道，必要时给一个有触发条件的后续渠道；财产与人身风险等确需并行时说明各自目的。不要规定“协商→平台→12315→12345→法院”必须逐级走完。对方明确拒绝、失联或期限紧迫时，不重复安排无效等待。

涉及当前受理范围、管辖、前置条件、提交入口、费用或法定期限时，按 [官方核对方法](references/official-verification.md) 查适用原文；先核对具体机构、地域和事项。无法联网或官方资料不足时，标注未核实项，给出要向受理机构确认的具体问题，不编造办理菜单、处理天数和适用法院。

## 把证据与要证明的事实对应起来

读 [证据与行动模板](references/evidence-and-actions.md)，按当前阶段列出已有材料、关键缺口和合法取得办法。分别回答“现在够做什么”“正式主张还缺什么”“原件留到什么时候”，不以文件数量、录音时长或证据评分判断够不够。

截图可用于沟通，原始聊天、文件、载体及必要上下文应保留；展示副本可以脱敏，不能篡改原件。没有合同或对方真实姓名时，先用已有订单、付款、账号、工作管理记录等建立事实线索，再说明如何经平台或法定程序核实，不要求用户私下购买身份数据。

普通案件不要求一律公证、全程偷拍或重新接触对方取证；证据易灭失、数额较大或已进入正式程序时，再建议咨询证据保全等适用措施。不要为取证进入他人私密空间、绕过账号权限，或公开他人身份信息施压。录音、截图的证明力与合法性需具体判断，不设“微信文字高于电话”的固定排序。

## 给用户一张简短分诊单

优先写结论和理由，按信息量调整篇幅，通常包括：

1. **初步判断与主渠道**：目前是哪类关系、谁处理什么，哪些事实未确定。
2. **今天第一步**：联系哪个主体/机构、提出什么具体要求；适合时附可复制的事实说明草稿。区分建议回复日期与法定期限。
3. **证据留到什么程度**：对应争点的已有材料、最关键缺口、原件与副本如何保存及保留终点。
4. **下一步触发条件**：例如明确拒绝、超过约定答复日期、出现停业转移迹象或收到正式文书后分别怎么办；不要保证受理、赔偿或追回。
5. **核对依据**：指南具体小节、实际读到的官方文件/入口及核对日期；把用户陈述、材料能证明的事实和待核实推测分开。

不随意估算胜率，不凭“跑路”“霸王条款”就断言犯罪、合同无效或当然获得惩罚性赔偿。材料不足时，先完成已有事实支持的行动，不用笼统“咨询律师”替代全部分诊；案件复杂或涉及紧急法定期限时，指出需要当地法律服务确认的具体问题。
