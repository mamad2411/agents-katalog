# 借贷成本透视器

**把一切利率话术翻译成同一个口径：年化 IRR。**

先还原钱何时到手、何时付出，再算成本。主比较列为“有效年化 IRR”；月度方案同时给“月 IRR”和“月 IRR×12（名义年化）”，实际日期方案给“XIRR（实际天数/365）”。说明所用约定，不把不同年化口径混成一个数字，也不把数学结果冒称所有产品统一法定披露口径。

作者：毛毛&luke。源资料与修订信息见 [source.json](references/guide/source.json)。内置 Python 3.9+ 标准库计算器，可独立安装、离线运行；所有路径以本 Skill 目录为基准，不依赖用户工作目录或其他 Skill。

## 收集够算的数据

先用已有资料；缺少改变结果的条件时再问。单算成本不需要用户城市、收入、证件或银行账户；合同/账单截图先遮盖姓名、账号、证件号、电话等个人信息。

最少需要实际到账或获得的融资金额、每笔还款及费用金额、实际日期或等间隔期数。重点核对：

- 费用按原本金、剩余本金还是其他基数收？本金何时归还，首期何时扣款，有无宽限、尾款或气球贷？
- 手续费、服务费、担保费、强制保险/会员等何时收？已从放款扣除、并入月供或直接付第三方的，不能漏算或重复加入。
- “免息”是否有手续费、强制搭售、失去的现金购价优惠、返现条件或延迟到账？现金价、首付和融资额要分开。
- 提前还款是全额还是部分，结清金额包括什么、未到期费用是否退、正常还款是否还会扣？以实际结清报价核对。

读 [13.3 借贷成本](references/guide/book/13-防守.md#s13-3) 与相关 [待核实清单](references/guide/docs/待核实清单.md)；按话术用 [现金流还原](references/cashflow-modeling.md) 定位需要的条款。没有完整现金流时先给缺口，必要时按明确假设列情景；不能从“日息万五”或“月费率 0.6%”直接断言全产品唯一 IRR。

## 用同一算法复算

读取 [IRR 算法与输入格式](references/irr-method.md)，把借款人收到的钱记为正、归还及强制费用记为负。等间隔用 periodic；有实际日期优先用 dated，比较方案使用同一时间约定、金额与费用边界。折扣或返现未确定时单列情景，不默认一定拿到。

运行 [loan_irr.py](scripts/loan_irr.py)，展示关键输入和可复核的现金流摘要。计算器能处理月度/其他等间隔或实际日期、同日多笔收付，以及先流入后偿还的常规借贷现金流。多次变号可能无解或多解，脚本会拒绝输出单一 IRR；遇到数值范围或数据问题按错误说明补数据或改用经核验的方法，不随意挑一个根。不能执行脚本时按公式用可用计算工具复算，未经计算不要凭印象给精确百分数。

最终通常给：实际净流入、净流出合计、净融资成本、有效年化 IRR、名义年化（月度等适用时）、还款峰值与关键未知项。现金流、公式和时间约定要能解释结果；输出百分数须带 `%`，不能把小数利率误当百分数。计算示例只在最后显示时四舍五入，不提前舍入利率或重新修改合同月供。

## 比较与提前还款

比较报价时列出放款金额、还款期限、现金流及强制费用差异。金额或期限不同，即使 IRR 较低，总费用或阶段性还款压力也可能更高；不靠单一百分数替用户决定负债规模。

提前结清按 [情景比较](references/cashflow-modeling.md#提前还款和置换) 算“原计划”和“结清后”两套全周期现金流，同时另外比较从今天起可避免的未来付款与结清支出。已经付出的费用是历史成本，不能作为继续借款或提前还款一定划算的理由。部分提前还款需新的剩余计划；不能凭总利息估算。原书 14.2 的固定还款阶段结论和未经证实贴息不作为依据。

## 解释来源与下一步

优先指出广告费率为何与实际融资成本不同，再给结果、假设和要向贷款方核对的具体问题。用户已经有困难时可以整理还款清单、结清报价或官方协商问题，不鼓励借新还旧来掩盖现金缺口。

指南建议引用实际读过的本地小节；用户数据测算注明公式与日期假设。当前产品资费以合同、官方账单和还款表为依据；关于监管披露口径、费用合法性、司法保护上限或征信后果，另查适用对象与现行官方原文，未核实就说明缺口。不能仅因测得某年化值就认定违法或建议拒还。
