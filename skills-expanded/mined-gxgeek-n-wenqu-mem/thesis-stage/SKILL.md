# 论文阶段诊断

基于文件扫描和进度度量标准，判断当前论文所处阶段、完成度百分比、风险等级，并推荐下一步行动和技能组合。

## 触发场景

- 用户说"当前阶段""进度怎么样""下一步做什么""论文状态"
- 需要了解论文整体推进情况
- 阶段转换时确认是否满足转入条件
- Orchestrator 需要生成报告前自动调用

## 流程

### Step 1: 加载判定标准
读取 `references/stage-routing.md` 获取 8 阶段判定依据表（文件特征、完成度计算、转移条件、推荐技能组合）。
读取 `references/progress-metrics.md` 获取进度度量标准（评估维度、风险等级判定、里程碑节点）。

### Step 2: 扫描项目状态
读取以下信息源：
- `CLAUDE.md` — 获取论文基本信息和当前状态
- `.project/01_项目管理/进度计划.md` — 获取进度数据
- `.project/01_项目管理/任务看板.md` — 获取待办任务
- `zjuthesis/body/graduate/master/` — 检查各章节文件的存在性和修改时间

### Step 3: 判定当前阶段
对照 `references/stage-routing.md` 中的 8 阶段判定依据表：

| 阶段 | 判定依据 |
|------|---------|
| **选题** | 主题待定，方法论未选。CLAUDE.md 仅有研究方向要点 |
| **开题** | 有主题和方法论，开题报告材料存在（`.project/02_开题报告/`） |
| **中期报告** | 第1-2章完成，数据采集进行中。中期报告文档存在 |
| **论文撰写** | 全章节初稿，数据已分析。第1-5章均有草稿 |
| **预答辩** | 完整初稿，准备答辩。PPT 文件存在 |
| **盲审** | 已提交盲审版本。匿名版 PDF 已生成 |
| **答辩** | 盲审通过，准备最终答辩 |
| **完成/定稿** | 答辩通过，最终修改。所有签字页完成 |

### Step 4: 计算完成度
依照 `references/progress-metrics.md` 的加权公式：
```
总进度 = Σ(阶段权重 × 阶段内完成度)

阶段权重：选题(5%) + 开题(10%) + 中期(20%) + 撰写(35%) + 预答辩(15%) + 盲审(5%) + 答辩(5%) + 定稿(5%)
```

### Step 5: 判定风险等级

| 等级 | 标准 | 后果 |
|------|------|------|
| **高风险** | 核心维度≤2分或完成度<30% | 极有可能延期毕业；答辩未通过需二次答辩 |
| **中风险** | 完成度30%-60%，节点临近 | 可能仓促提交质量不达标 |
| **低风险** | 完成度>60%，按计划推进 | 常规风险 |

### Step 6: 输出诊断报告
```
## 当前阶段: [阶段名]
## 完成度: [XX]%
## 风险等级: [高/中/低]
## 阶段转移条件: [是否满足] [还需完成]
## 下一步行动
1. ...
2. ...
3. ...
## 推荐技能
- /thesis-xxx: 说明
- /thesis-yyy: 说明
## 里程碑提醒
- 下一里程碑: [名称] [预计日期]
```

## 阶段转移条件速查

| 转移 | 必要条件 |
|------|---------|
| 选题 → 开题 | 主题明确 + 方法论选定 + ≥30篇文献阅读 |
| 开题 → 中期 | 开题报告通过 + 文献综述完成 |
| 中期 → 撰写 | 中期答辩通过 + 数据采集完成 |
| 撰写 → 预答辩 | 全章初稿 + 数据分析完成 + 格式自查 |
| 预答辩 → 盲审 | 预答辩通过 + 论文修改完成 |
| 盲审 → 答辩 | 盲审结果通过 + 修改意见全部回应 |
| 答辩 → 定稿 | 答辩通过 + 最终修改完成 |

## 里程碑节点

| 里程碑 | 核心交付物 | 通过标准 |
|--------|-----------|---------|
| 选题确定 | 选题方向陈述 + 初步文献综述 | 导师认可选题方向 |
| 开题答辩 | 开题报告完整版 | 评审组通过 |
| 中期报告 | 中期报告 + 第1-2章 | 中期答辩通过 |
| 预答辩 | 论文完整初稿 + PPT | 预答辩通过 |
| 盲审提交 | 匿名版论文PDF | 格式检查通过 |
| 最终答辩 | 终版论文 + 答辩PPT | 答辩委员会通过 |
| 定稿提交 | 最终PDF + 签字页 | 图书馆审核通过 |
