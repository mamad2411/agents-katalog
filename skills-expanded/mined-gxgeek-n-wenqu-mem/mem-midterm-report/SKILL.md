# ZJU MEM 中期报告生成

## 1. 定位与边界

本 skill 负责 ZJU MEM 中期报告的全流程生成。输入用户的开题报告内容、论文进展材料、课程信息和封面身份，输出可直接提交的中期报告 Word 文档和配套资料。

**模式**：

- **登记表模式**：只生成《论文中期报告登记表》（含论文信息 + 500字摘要）
- **完整报告模式**：生成完整中期报告 Word（封面 + 目录 + 五段正文 + 第1-2章全文 + 三级目录）
- **配套模式**：生成 PPT 大纲 + 系统填报指引
- **全量模式**（默认）：以上全部

与 `mem-reading-report` 的衔接：中期报告的第1节"课程学习/实践实训/读书报告"可直接引用 `mem-reading-report` 的输出（读书报告篇数、核心文献矩阵）。

## 2. 输入收集

### 2.1 必填信息

一次性收集，不要反复打断。

| 字段 | 来源 | 说明 |
|------|------|------|
| 封面身份 | 用户确认 | 学号/姓名/导师/学院/专业 |
| 研究方向 | 用户确认 | 用于摘要和登记表 |
| 论文题目 | 用户确认 | 可以与研究方向略有差异 |
| 题目来源 | 默认"企业内部需求" | MEM 常见来源 |
| 论文形式 | 默认"工程管理专题类" | MEM 常见形式 |

### 2.2 进展材料（完整报告模式必须）

| 材料 | 要求 |
|------|------|
| 开题报告内容 | 研究目标、内容、方法、技术路线 |
| 已完成章节 | 至少第1章和第2章完整正文 |
| 论文三级目录 | 全部章节的 1/2/3 级标题 |
| 阶段性成果 | 数据、指标、图表、SOP等证据 |
| 课程学习情况 | 课程名/学分/成绩/修读学期 |
| 实践实训情况 | 内容/时间/收获 |
| 读书报告情况 | 篇数/题目/完成日期/是否口头报告 |
| 下一步计划 | 月份/任务/交付物/验收标准 |
| 开题报告不符说明 | 如有偏离需说明，无偏离也要核对 |

缺少进展材料时，不能编造成果。只能给框架草稿并标注`[待用户补充]`。

## 3. 章节模板（MEM 五段结构）

### 封面
- 学校：浙江大学
- 标题：工程管理硕士学位论文中期报告
- 论文题目 / 学号 / 姓名 / 指导老师 / 学科(专业) / 所在学院 / 日期
- 格式：黑体标题，宋体正文，居中对齐

### 目录
- 自动 TOC 域（`TOC \o "1-3" \h \z`）
- Word 打开后右键更新

### 第1节：课程学习及读书报告完成情况

```
1.1 课程学习完成情况
  - 表格：课程编号/名称/类别/学分/成绩/状态/修读学期
  - 只列与论文直接相关者
  - 统计总学分、是否满足培养方案

1.2 实践实训及读书报告完成情况
  - 实践实训：单位/岗位/内容/时间/与论文关系
  - 读书报告：篇数/题目/完成日期/是否口头报告
  - 引用 mem-reading-report 输出的核心文献矩阵（可选）
```

### 第2节：已完成的论文工作及阶段性成果

```
2.1 总体工作进展
  - 论文整体完成度和进度概述
  - 明确"已完成初稿X章"还是"初稿框架已形成"
  - 不要夸大（"七章全部完成"需有材料支撑）

2.2 各章节完成情况及取得的阶段性成果
  - 每章：状态/字数/核心内容/关键数据或材料/完成度(%)
  - 用 成果展示三步法：做了什么 → 怎么做的 → 得到什么结果
  - 缺数据时写"初稿框架已完成，具体数据待补充"
```

### 第3节：与开题报告的不符情况说明

- 没有偏离也要写明"经核对，研究工作严格按开题报告计划执行"
- 有偏离时写：原计划 → 实际执行 → 原因与调整方案 → 对研究目标的影响
- 论文题目的微调（如加副标题）不属于不符，可以写"题目表述优化"

### 第4节：下一步论文工作安排

```
4.1 重难点分析及拟解决的措施
  - 5个难点，每个基于论文实际内容（禁止通用套话）
  - 每个：具体问题（点名章节/方法/数据） → 为什么难 → 拟怎么解决
  - 禁止写：重复率/AIGC 风险处理、编译问题、格式检查等通用项
  - 推荐方向（根据实际论文选取）：
    · 论证逻辑/术语一致性（跨章写作的时间跨度导致的前后不对齐）
    · 多源数据时间对齐（不同数据源采集窗口不重合）
    · 方法论论证充分性（参数选取理由、假设检验交代）
    · 改进效果归因（混淆因素排除）
    · 单案例外部适用性（结论推广边界）
    · 指标口径统一（不同章对同一指标的定义不一致）

4.2 具体工作安排
  - 表格：序号/时间/工作内容/预期成果/备注
  - 覆盖至定稿提交
  - 拒绝"继续看文献""完善论文"等空话
```

### 第5节：已经撰写的论文章节内容

- **第1章完整正文**（绪论：背景/问题/研究现状/内容/方法/技术路线）
- **第2章完整正文**（文献综述与理论基础）
- **论文三级目录**（全部章节的1/2/3级标题，含参考文献和附录）
- 格式必须符合《浙江大学工程管理硕士学位论文规范要求》

## 4. 配套资料生成（全量模式）

完成 Word 后，同步生成：

| 资料 | 格式 | 要求 |
|------|------|------|
| 登记表 | DOCX（独立文件） | 论文信息表格 + 500字摘要 + 导师签署区 |
| 系统填报指引 | MD | 研究方向/指导小组成员/报告题目/摘要等字段的填写值 |
| PPT 大纲 | MD | 核心要点 + 时间分配 |
| 自评清单 | MD | 对照评审表6项逐条自检 |

## 5. 质量门

### 自动评分（MEM 100 分制）

| 维度 | 分值 | 低分特征 |
|------|------|---------|
| 完成度 | 30 | 缺章节、字数不足、五段结构缺段、进展材料不足 |
| 规范性 | 20 | 封面缺项、图表无编号、引用混乱、缺三级目录 |
| 逻辑性 | 20 | 章节间无衔接、五段逻辑断裂、与开题脱节 |
| 可行性 | 20 | 下一步计划空洞、无时间节点、无验收标准 |
| 创新性 | 10 | 成果缺少证据支撑、与开题完全重复 |

- <70：不能交付，标注草稿
- 70-79：有条件通过
- ≥80：正式初稿

### 评审表6项自检

逐项核对（详见 `references/midterm_requirements.md`）：
1. 课程学分/实践环节是否达标
2. 论文章节是否完整、有实质内容
3. 三级目录是否完整、逻辑清晰
4. 整体工作量是否充分
5. 格式是否符合规范
6. 内容是否符合MEM选题和开题要求

任何一项有风险，必须在交付时标注。

## 6. 对抗审查循环

复用 `mem-reading-report` 的对抗审查循环机制（§15），额外增加中期报告特有检查项：

| # | 检查项 | 判定 |
|---|--------|------|
| 1 | 五段结构完整性 | 缺段→FAIL |
| 2 | 第1节课程/读书报告是否占位符 | 全空→FAIL |
| 3 | 第2节成果是否有证据 | 只有描述无数据→WARN |
| 4 | 第3节不符说明是否诚实 | "毫无偏离"且无核对依据→WARN |
| 5 | 第4节计划是否有时间节点 | 无月份/无交付物→FAIL |
| 6 | 第5节是否含第1-2章全文 | 只有摘要或目录→FAIL |
| 7 | 三级目录是否完整 | 缺章/缺级→FAIL |
| 8 | 登记表摘要字数 ≥ 300 | 不达标→FAIL |
| 9 | 封面日期是否完整 | 年月日任缺→FAIL |
| 10 | 与开题报告题目一致性 | 完全不一致且无说明→FAIL |

## 7. 与 mem-reading-report 的衔接

- 中期报告的第1节可引用读书报告输出：篇数、题目、核心文献矩阵
- 若用户已完成读书报告生成，自动填入统计数据
- 若未完成，标注 `[待完成第4篇读书报告]`

## 8. 失败模式

- 第1节全空或占位符 → 教务直接退回
- 课程列表写成泛泛概述缺具体表 → 评审认为敷衍
- 读书报告写"4篇"但未列题目/主题 → 缺乏证据
- "已完成七章初稿"但第5节只附1-2章 → 评审质疑完成度
- §4.1重难点写"重复率/AIGC 风险处理""格式检查""补充文献"等套话 → 评审判定为模板化、缺乏真实思考
- §4.1写"数据脱敏""法务审核"但论文实际无此需求 → 编造困难，评审反问"你问过公司法务了吗？"
- 商业价值、数据指标无来源说明 → 盲审质疑可信度
- 封面缺日期或导师信息 → 格式退回
- 下一步计划只有"继续完善论文" → 评审扣分
- 生成痕迹（Codex/AI/自动评分等词）残留在正文 → 直接否决
- 多次编辑导致文档中出现孤立残留段落 → 格式混乱
