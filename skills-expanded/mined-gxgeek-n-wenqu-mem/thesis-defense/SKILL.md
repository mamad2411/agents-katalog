# 答辩准备

为 ZJU MEM 实践导向论文提供完整的答辩准备方案。核心原则：重点防范预答辩/盲审常见风险（数据真实性、实用性不足、AI 工具使用伦理、格式不规范），输出帮助用户自信应对 15-20 分钟陈述 + 专家提问。

> **⭐ 先读实战 Playbook**：`references/midterm-playbook-实战.md`——含**评委真实阅读模型**(30秒扫骨架→追因果线→三连接测试)、**主线重建 + 导航图可扫描性审计**、**答辩手卡高密度打印做法**、**从答辩录像提取老师问答**(桥接 video-transcribe-analyze)、**MEM 三致命定调问题通用答法**。通用打底看 `defense-strategy.md`，实战方法看本 playbook；**中期答辩模式**的 ZJU 五段 PPT 逐页结构/讲稿/中期特有问答/评审打分见 `references/midterm-defense-ppt.md`。

## 触发场景

- 用户说"预答辩准备""盲审模拟""答辩 PPT""常见问题""模拟问答""答辩策略"
- 中期报告通过后或盲审前需要准备
- 论文主体完成后需要答辩材料

## 流程

### Step 1: 确认阶段与材料
确认当前论文阶段（中期后/预答辩/盲审/最终答辩），扫描已有材料：
- 论文章节完成情况
- 图表、数据分析结果
- 已有 PPT 或答辩材料

### Step 2: 加载答辩策略
读取 `references/defense-strategy.md`，获取完整答辩指导：
- 答辩陈述框架（15-20分钟时间分配）
- 核心创新点提炼方法（四维创新框架）
- 实践价值论述模板（三段式）
- 局限性应对话术（承认-转化-弥补）
- 8-12个常见问题分类（方法论/数据/创新/实践/局限性）
- PPT大纲模板（25-30页结构）
- 模拟问答技巧

### Step 3: 生成答辩策略文档
基于论文实际内容，生成个性化答辩策略，写入 `.project/08_答辩准备/答辩策略.md`：
- **陈述框架定制**：按论文实际章节填充时间分配
- **创新点提炼**：用四维框架分析论文创新点
- **实践价值论述**：基于论文实际数据和效果撰写三段式论述
- **局限性预案**：识别论文3-5个实际局限，逐条准备应对话术

### Step 4: 生成预测问答
生成 15-20 个答辩常见问题，覆盖 5 大类别，写入 `.project/08_答辩准备/预测问答.md`：

**方法论类（3-4题）：**
- 为什么选择 PDCA 而非其他方法论？
- 数据采集的科学性如何保证？
- 研究方法的局限性及弥补方案？

**数据类（3-4题）：**
- 数据来源可靠性及真实性验证？
- 样本量和时间跨度是否足够？
- 数据分析方法选择依据？

**创新类（3-4题）：**
- 与已有研究的本质区别是什么？
- AI 工具的角色和边界？
- 成果的可推广性？

**实践类（3-4题）：**
- 方案落地的最大困难及克服方式？
- 实践效果的量化指标？
- 对行业实践的指导意义？

**局限性类（2-3题）：**
- 研究的主要局限性？
- 如何改进和后续研究计划？

每题提供：问题原句 + 回答框架（结论先行→论据支撑→实例佐证）+ 建议时长（2-3分钟）

### Step 5: 主线审计（评委视角，投入产出最高）
按 playbook 第二、三节：把论文压成"主线一页纸"(问题→根因→方案→验证)，跑**三连接自测**(诊断↔改进/原因↔指标/方案↔案例)，再做**题目/目录/摘要可扫描性审计**(让主线30秒可见)。产出复习稿，标出最易被追问的断点(常见=综合评分/合成指标的可复算性)。

### Step 6: 生成/优化答辩 PPT
**套官方模板做 PPT → 用 `report-ppt-builder`**（python-pptx 套学校母版、复用论文真图、每页嵌演示者备注、量化自检门 qa_check），不要只用 paper-slide-deck 出图。要点：官方结构、每页论点+图+数据、成果用大字卡(改进前→改进后)、断言式标题、跨页一致。`paper-slide-deck` 仅在需要"图片版幻灯"时用。

### Step 7: 做高密度答辩手卡（站台真正用的）
按 playbook 第四节：把讲稿+预测问答+关键数字**去重合并成 2 页高密度手卡**（问答速查表 + 数字表 + 每页PPT一句话 + 临场铁律），用 `md → 紧CSS HTML → soffice PDF → lp 打印` 导出。别打十几页站台翻不动。

### Step 8: 输出答辩准备检查清单
```
□ 主线一页纸能否 30 秒讲清（问题→根因→方案→验证）？三连接测试有无断点？
□ 题目/目录/摘要 三层导航图，主线与"管理定调"是否一眼可见？
□ 三致命定调题（质量vs质量管理 / 换个公司也一样 / 合成指标怎么算）答法背熟？
□ 是否突出实践导向和AI赋能价值？数据/文献是否已验证？
□ PPT 是否简洁自明、成果用大字卡、每页论点+图+数据？qa_check 几何门是否 0 告警？
□ 图表是否自明（图题下置、表题上置）、跨页一致？
□ 高密度答辩手卡（≤2页）是否做好并打印？站台不翻十几页。
□ 是否进行过模拟答辩练习？陈述控制在 15-20 分钟？
```

## ZJU MEM 答辩重点提醒

- **预答辩**需提交符合浙大规范的论文终稿 + PPT（15分钟陈述 + 提问）
- **盲审**为双盲：匿名提交，重点考察内容质量
- 强调：工程背景、问题导向、真实数据、成果可行可鉴
- 常见风险：数据不真实、实用性弱、AI 使用伦理未说明、格式问题

## 输出位置
- 策略文档：`.project/08_答辩准备/答辩策略.md`
- PPT大纲：`.project/08_答辩准备/PPT大纲.md`
- 预测问答：`.project/08_答辩准备/预测问答.md`

## 中期答辩模式（ZJU 中期报告会专用）

中期答辩会与预答辩/盲审/最终答辩**共用上面的通用打法**（主线审计 → 预测问答 → 高密度手卡），但材料按 ZJU 中期报告会的**官方五段结构**组织，且更看"进度达标、成果真实、问题诚实"而非讲完全部细节。切到本模式时：

- **五段 PPT 逐页结构 + 讲稿 + 时间分配**（约 19 页：课程与读书报告 → 已完成工作与阶段成果 → 与开题不符说明 → 下一步安排 → 已撰写章节）、**中期特有预测问答**（"和开题有变化吗""完成度怎么算""你的 PDCA 和工厂 PDCA 有何不同""单案例结论能推广吗"）、**中期评审模拟与 100 分制打分**——全部见 `references/midterm-defense-ppt.md`。
- **PPT 出图**同 Step 6：套学校母版走 report-ppt-builder；成果证据页（§2）占全场至少一半时间，数据页停顿 3 秒。
- **与中期报告衔接**：从 `mem-midterm-report` 的 §1–§5 提取 PPT 数据（课程表/成果表/工作安排），PPT 是报告精华版（保留约 30%、突出 3 个核心数据点）。
- 开场 30 秒定调、现场应对（卡壳/追问/超时）、致谢页禁"谢谢聆听"等话术见该 ref。

## 常见错误避免
- PPT 内容过多或过少（控制在15分钟陈述量）
- 回答问题时回避弱点或缺乏数据支撑
- 忽略 AI 伦理、数据来源可信度等 ZJU 关注点
- 直接生成完整答辩稿而不先输出提纲和问题模拟
- 不提醒盲审双盲要求（匿名、格式严格）
