# 论文记忆管理

长期记忆与学习笔记管理，采用费曼学习法 + 反思日志 + 知识连接理论。严格按照 6 条写入规范管理记忆，确保跨会话记忆统一、可长期积累、可持续使用。

## 触发场景

- 用户说"记录""记住这个""写到记忆""备忘"
- 导师反馈后需要记录修改意见
- 写作过程中产生重要洞察
- 阶段里程碑需要存档
- 时间节点/截止日期需要备忘

## 流程

### Step 1: 加载记忆协议
读取 `references/memory-protocol.md` 获取完整记忆管理规则：
- **6条写入规则**：客观中立语气 / 3-8行/条 / 日期戳YYYY-MM-DD / 滑动窗口最近5条 / 知识交叉连接 / 100%保留原始表述
- **5种分类**：主题决策 / 导师反馈 / 写作洞察 / 数据发现 / 时间节点
- **归档规则**：何时归档、归档格式、索引维护
- **记忆文件格式模板**

### Step 2: 读取当前记忆状态
- 读取 `memory/user-personal-memory.md` — 获取当前最近 5 条记录
- 读取 `memory/archive_index.md` — 获取归档索引

### Step 3: 分类并记录
将用户输入（$ARGUMENTS）按以下5种分类归类：

| 分类 | 标识 | 典型内容 |
|------|------|---------|
| **主题决策** | [主题] | 方法论选择、研究范围调整、标题修改决定 |
| **导师反馈** | [导师] | 修改意见、格式要求、研究方向建议 |
| **写作洞察** | [写作] | 发现好的表达方式、结构优化思路 |
| **数据发现** | [数据] | 数据分析中的新发现、意外结果 |
| **时间节点** | [节点] | 提交截止日期、答辩日期、导师约谈 |

**记录格式（严格遵守）：**
```markdown
### YYYY-MM-DD — [分类]
[用户原始表述，100%保留]

**上下文:** [简要背景说明]
**相关链接:** [[YYYY-MM-DD 相关记录标题]]
```

### Step 4: 滑动窗口维护
- 主索引 `memory/user-personal-memory.md` 永远只保留最近 5 条
- 当第 6 条写入时，最早的一条移入 `memory/archive_index.md`
- 归档时添加归档原因和归档日期

### Step 5: 确认输出
```
✅ 已记录到: memory/user-personal-memory.md
📂 分类: [主题决策|导师反馈|写作洞察|数据发现|时间节点]
🔗 关联: [[相关记录名]]
📝 当前主索引: [N]/5 条
```

## 6条写入规则速查

1. **客观中立语气**：记录事实和反馈本身，不添加情感色彩
2. **3-8行/条**：保持信息密度，超8行拆分，少于3行合并
3. **日期戳 YYYY-MM-DD**：以 `### YYYY-MM-DD — [分类]` 开头
4. **滑动窗口最近5条**：主文件仅保留5条，溢出自动归档
5. **知识交叉连接**：每条末尾添加 `[[相关链接]]`，至少关联1条已有记录（首条记录标注 `[[初始记录]]`，无需关联已有记录）
6. **100%保留原始表述**：【个人思考】板块严格保持用户原话，不擅自改写立场和结论

## 归档规则

- **主索引达上限**：新记录写入触发最旧记录归档
- **阶段结束时**：批量归档相关决策记录
- **时间节点过期后**：自动移入归档
- **归档文件超100条**：按年份拆分为 `archive_2024.md` 等

## 禁止操作

- 不得擅自删除用户已有记录（归档 ≠ 删除）
- 不得修改用户原始表述的立场
- 不得在未确认时自行填写用户思考内容
- 不得创建超出 5 种分类的新类别
- 不得将不同主题的记录强行合并
