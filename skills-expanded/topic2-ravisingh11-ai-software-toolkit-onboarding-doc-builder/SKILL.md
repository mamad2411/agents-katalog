# Onboarding Doc Builder

Create or refresh high-signal onboarding documentation from the current repo state.

## Focus Areas

- setup instructions that match the real repo
- architecture or module overview
- workflow, release, and debugging shortcuts
- glossary or local terminology that blocks new contributors

## Rules

- Derive docs from actual repo evidence.
- Do not invent team process that is not visible in the codebase.
