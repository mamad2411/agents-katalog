# moodboard

Decide the look before you make anything, so production stays coherent.

## Process
1. **Gather references** via Unsplash (real imagery) and/or quick generations (Nano Banana/Higgsfield) for
   mood exploration. Pull brand cues with Brand.dev if branding an existing entity.
2. **Define the direction:** a named style (editorial, brutalist, luxe, retro-futurist, organic, etc. - not
   "modern clean"), a palette, a type pairing, texture/finish, and motion feel if relevant.
3. **Assemble** a tight board: 6-12 references grouped by theme (colour, type, imagery, composition, texture).
4. **Write the rationale:** why this direction fits the brand/audience/goal.

## Output
- A moodboard (reference set + palette + type + direction brief) that the rest of the project is judged against.

## Guardrails
- One coherent direction, not a grab-bag. Avoid generic defaults.
- Credit reference sources; mark which images are AI vs. real (licensing).
