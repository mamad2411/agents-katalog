Run the onboarding interview defined in [`docs/playbooks/start.md`](../../../docs/playbooks/start.md).

Follow that playbook exactly: welcome the user, run a short conversational
interview (idea, background, goals, mode, stack, pace), then write `PROJECT.md`,
the design skeleton, and the roadmap in `docs/progress.md`, and offer to write
the first milestone. This is the user's first impression — keep it warm and
brief.
