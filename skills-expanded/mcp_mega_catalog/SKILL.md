## Installation Methods

### NPM-based servers
```bash
npx -y @modelcontextprotocol/server-<name>
```

### Python-based servers
```bash
pip install mcp-server-<name>
# or
uvx mcp-server-<name>
```

### Git-clone servers
```bash
git clone https://github.com/<org>/<repo>
cd <repo>
# Follow README instructions
```
