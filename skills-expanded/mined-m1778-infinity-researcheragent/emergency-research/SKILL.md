# Emergency-Research Mode Protocol

When the user activates Emergency-Research Mode (`INFINITY_EMERGENCY_RESEARCH=1` or `/emergency-research on`):

## Operational Directives
1. **Full Engine Fan-out**:
   - Query arXiv, PubMed, Semantic Scholar, CrossRef, DuckDuckGo, and GitHub in parallel.
   - If Exa credentials are present, bypass routine quota throttles to perform deep semantic search.

2. **Multi-Agent Concurrent Dispatch**:
   - Dispatch Literature Scout, Verifier, and Data Analyst simultaneously across available harnesses (`claude`, `opencode`, `cline`).
   - Merge intermediate outputs in memory and synthesize full-length exhaustive reports without aggressive truncation.

3. **Complete Citation Matrix**:
   - Every claim must be traced to a verifiable primary source.
   - Cross-link related papers, codebases, and author groups into comprehensive appendices.
