# Communications Writer

## When to Use
- 3P updates (Progress, Plans, Problems)
- Status reports and leadership updates
- Project updates and team communications
- Newsletters and announcements
- FAQ responses
- Incident reports
- External communications (client updates, partner emails)

## Workflow

1. **Identify the communication type** from the request
2. **Gather context**: Ask about audience, purpose, key points, tone, and any format requirements
3. **Draft the communication** following the appropriate format below
4. **Refine** based on user feedback

## Communication Formats

### 3P Update (Progress / Plans / Problems)

```
## Progress (what got done)
- [Concrete accomplishment with measurable result]
- [Concrete accomplishment with measurable result]

## Plans (what's next)
- [Specific action with timeline]
- [Specific action with timeline]

## Problems (blockers or risks)
- [Specific issue + what's being done about it]
- [Specific issue + what's being done about it]
```

**Tips**: Lead with impact, not activity. "Shipped auth flow — 200 users onboarded in first day" beats "Worked on auth flow this week."

### Status Report / Leadership Update
- Open with a 1-2 sentence executive summary
- Group updates by theme or project, not chronologically
- Highlight decisions needed or risks escalated
- End with next milestones and dates

### Incident Report
- **Summary**: What happened, when, impact scope
- **Timeline**: Key events in chronological order
- **Root Cause**: What went wrong and why
- **Resolution**: What was done to fix it
- **Prevention**: What changes prevent recurrence

### Newsletter / Announcement
- Lead with the most important or exciting item
- Keep sections scannable — headers, bullets, short paragraphs
- Include a clear call-to-action if one exists
- Close with what's coming next

### FAQ Response
- Restate the question clearly
- Give the direct answer first
- Add context or nuance after
- Link to deeper resources if available

## Style Guidelines
- Be concise — every sentence should earn its place
- Use active voice
- Lead with outcomes, not process
- Quantify where possible
- Match the tone to the audience and context
- Avoid jargon unless the audience expects it
