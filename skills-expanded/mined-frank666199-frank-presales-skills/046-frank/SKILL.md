# Skill: Frank-投标决策评估工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度4 - 招投标全流程实操
- **Description**: 从匹配度、竞争格局、商务条件、资源投入四维度输出投/弃标建议

---

## When to Use
收到招标文件后，做投标决策前使用

---

## Input Requirements
- 招标文件解析报告
- 竞争情报
- 公司资源情况

---

## Workflow
1. 评估项目匹配度：资质/技术/案例/经验与招标要求的匹配程度
2. 分析竞争格局：竞争对手数量/优势/与我方对比
3. 评估商务条件：预算/付款方式/合同条款/风险
4. 评估资源投入：人力/时间/资金/机会成本
5. 量化评估：四维度评分（1-10分）
6. 输出投/弃标建议和理由
7. 制定投标策略（如决定投标）

---

## Output Format
投标决策评估报告（含四维度评分+投/弃标建议+投标策略）

---

## Output Template
```
评估维度 | 评估项 | 评分(1-10) | 依据 | 风险/机会 | 权重 | 加权分
```
