# Skill: Frank-企业项目风险预判工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度6 - B端企业项目专精
- **Description**: 预判B端项目落地、预算、协作风险并规避

---

## When to Use
B端项目评估阶段和执行阶段

---

## Input Requirements
- 项目方案
- 客户组织情况
- 竞争态势

---

## Workflow
1. 预判落地风险：技术可行性/资源匹配/时间约束
2. 预判预算风险：预算冻结/预算削减/付款延迟
3. 预判协作风险：内部阻力/部门博弈/人员变动
4. 预判竞争风险：竞品介入/价格战/关系变化
5. 预判需求风险：需求蔓延/需求变更/期望偏差
6. 针对每类风险制定规避方案
7. 输出风险预判报告

---

## Output Format
B端项目风险预判报告（含五维风险+规避方案+监控机制）

---

## Output Template
```
风险编号 | 风险类别 | 风险描述 | 发生概率 | 影响程度 | 规避方案 | 监控指标
```

---

## Example
| 字段 | 内容 |
|------|------|
| R003 | 协作风险 | IT部门对新系统抵触 | 中 | 高 | 安排IT部门参与方案设计 | IT部门参与度 |

- 规避方案可操作
