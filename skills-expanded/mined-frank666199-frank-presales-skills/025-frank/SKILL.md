# Skill: Frank-价值主张提炼工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度2 - 售前全流程标准化
- **Description**: 基于客户痛点，用场景-痛点-价值三段论生成价值主张

---

## When to Use
方案开篇、汇报开场、竞品对比时使用

---

## Input Requirements
- 客户痛点清单
- 我方方案核心能力
- 竞品对比信息

---

## Workflow
1. 梳理客户Top3痛点，按影响程度排序
2. 对应我方方案的核心能力，形成'痛点-能力'映射
3. 用'场景-痛点-价值'三段论构建价值主张
4. 量化价值产出（降本X%/增效X倍/合规率X%）
5. 生成电梯演讲版（30秒）和详细版（3分钟）
6. 输出竞品对比中的差异化价值主张

---

## Output Format
价值主张文档（含30秒版+3分钟版+竞品差异化版）

---

## Output Template
```
价值主张版本 | 场景描述 | 客户痛点 | 我方方案价值 | 量化指标 | 竞品差异
```
