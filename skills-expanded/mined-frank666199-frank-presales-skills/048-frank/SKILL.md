# Skill: Frank-商务标书编制工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度4 - 招投标全流程实操
- **Description**: 生成符合招标要求的商务应答、报价策略、优惠条件、服务承诺

---

## When to Use
决定投标后，进入商务标书编制阶段

---

## Input Requirements
- 招标文件商务要求
- 报价方案
- 公司商务资质

---

## Workflow
1. 编制商务应答：逐条响应商务要求
2. 确定报价策略：报价方式/分项报价/总价
3. 准备优惠条件：免费服务/延长质保/赠送模块
4. 编写服务承诺：响应时间/服务质量/人员保障
5. 整理商务资质：营业执照/财务报告/税务证明/社保
6. 编制商务偏离表
7. 全稿合规检查

---

## Output Format
商务标书（含商务应答+报价表+优惠条件+服务承诺+资质文件）

---

## Output Template
```
条款编号 | 招标商务要求 | 商务应答 | 偏离状态 | 支撑文件 | 备注
```

---

## Example
| 字段 | 内容 |
|------|------|
| B2.3 | 质保期≥2年 | 承诺质保期3年 | 正偏离 | 服务承诺书 | 优于招标要求 |

- 优惠条件可兑现
- 资质文件在有效期内
