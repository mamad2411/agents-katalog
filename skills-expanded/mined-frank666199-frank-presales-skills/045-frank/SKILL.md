# Skill: Frank-招标文件解析工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度4 - 招投标全流程实操
- **Description**: 自动拆解招标文件，标注关键条款、偏离项、废标风险点

---

## When to Use
收到招标文件后第一时间使用

---

## Input Requirements
- 招标文件全文
- 公司资质清单
- 产品技术参数表

---

## Workflow
1. 解析招标文件结构：公告/投标人须知/技术要求/商务要求/评分标准/合同草案
2. 提取关键信息：项目预算/投标截止时间/资质要求/保证金
3. 识别废标条款（星号条款/实质性要求）
4. 标注技术偏离项：逐条对比我方能力
5. 分析评分标准：技术分/商务分/价格分权重和细则
6. 识别控标点和排他性条款
7. 输出招标文件解析报告

---

## Output Format
招标文件解析报告（含结构拆解+关键信息+废标条款+偏离分析+评分分析）

---

## Output Template
```
条款编号 | 招标要求 | 类型(资格/技术/商务/废标) | 我方情况 | 偏离状态 | 风险等级 | 应对建议
```

---

## Example
| 字段 | 内容 |
|------|------|
