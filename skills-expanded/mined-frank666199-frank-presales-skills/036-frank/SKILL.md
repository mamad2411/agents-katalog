# Skill: Frank-项目效益分析工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度3 - 方案编制与文档优化
- **Description**: 用ROI模型量化项目经济/管理/社会效益，生成决策可用报告

---

## When to Use
方案中需要效益分析章节，或领导决策需要效益论证

---

## Input Requirements
- 项目投资额
- 运营成本数据
- 效益预期数据

---

## Workflow
1. 量化经济效益：降本金额/增效价值/创收预期
2. 量化管理效益：流程优化/决策效率/风险降低
3. 量化社会效益：服务提升/公众满意度/数据价值
4. 构建ROI模型：投资回收期/净现值/内部收益率
5. 进行敏感度分析（乐观/基准/保守三场景）
6. 生成效益分析图表
7. 输出效益分析报告

---

## Output Format
效益分析报告（含三维度效益+ROI模型+敏感度分析+图表）

---

## Output Template
```
效益类型 | 效益项 | 量化指标 | 年度金额 | 计算依据 | 置信度
```
