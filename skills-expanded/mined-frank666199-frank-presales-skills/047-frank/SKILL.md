# Skill: Frank-技术标书编制工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度4 - 招投标全流程实操
- **Description**: 按招标文件技术评分标准，逐条响应并生成技术偏离表

---

## When to Use
决定投标后，进入技术标书编制阶段

---

## Input Requirements
- 招标文件技术要求
- 公司技术方案
- 技术证明材料

---

## Workflow
1. 建立技术响应矩阵：招标条款→响应内容→证明材料→偏离状态
2. 逐条编写技术响应，确保响应到招标文件的每个子项
3. 编制技术偏离表：正偏离/无偏离/负偏离
4. 准备技术证明材料清单
5. 编写技术方案亮点（对应评分项）
6. 编制实施方案和质量保障方案
7. 全稿一致性检查

---

## Output Format
技术标书（含响应矩阵+偏离表+方案正文+证明材料清单）

---

## Output Template
```
条款编号 | 招标要求 | 响应内容 | 偏离状态 | 证明材料 | 得分预估
```
