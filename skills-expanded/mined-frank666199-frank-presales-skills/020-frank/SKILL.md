# Skill: Frank-项目内部评审汇报工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度2 - 售前全流程标准化
- **Description**: 适配公司内审，标准化售前汇报逻辑与内容

---

## When to Use
方案需提交公司内部评审时使用

---

## Input Requirements
- 方案文档
- 项目背景资料
- 评审关注点

---

## Workflow
1. 确定评审对象和关注点（技术/商务/风控/法务）
2. 按'项目概况-方案要点-技术亮点-商务条件-风险评估-资源需求'组织汇报
3. 准备评审材料包（方案摘要+关键图表+Q&A预案）
4. 预判评审委员会可能提出的问题
5. 生成汇报PPT和演讲脚本
6. 输出评审待办事项清单

---

## Output Format
内部评审汇报材料（PPT+演讲脚本+Q&A预案）

---

## Output Template
```
汇报章节 | 核心内容 | 关键数据 | 时长(分钟) | Q&A预案
```

---

## Example
| 字段 | 内容 |
|------|------|

- 风险不隐瞒
