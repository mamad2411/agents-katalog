# Skill: Frank-偏离表处理工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度4 - 招投标全流程实操
- **Description**: 对无法满足的条款，生成最小风险偏离说明和替代方案

---

## When to Use
投标文件中存在偏离招标要求的条款时使用

---

## Input Requirements
- 偏离条款清单
- 招标文件原文
- 我方能力说明

---

## Workflow
1. 将偏离分为：正偏离（优于要求）/无偏离（满足要求）/负偏离（不满足要求）
2. 对正偏离：突出优势，争取加分
3. 对负偏离：评估废标风险→制定替代方案→编写偏离说明
4. 偏离说明结构：偏离原因→影响分析→替代方案→风险控制
5. 评估偏离对评分的影响
6. 准备偏离谈判话术
7. 输出偏离处理表

---

## Output Format
偏离处理表（含偏离说明+替代方案+风险评估+谈判话术）

---

## Output Template
```
条款编号 | 招标要求 | 偏离类型 | 偏离说明 | 替代方案 | 评分影响 | 废标风险
```
