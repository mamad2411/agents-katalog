# Skill: Frank-企业多层级需求对齐工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度6 - B端企业项目专精
- **Description**: 对齐企业老板、部门、执行层多方需求

---

## When to Use
B端项目涉及企业多层级人员时使用

---

## Input Requirements
- 企业组织架构
- 各层级需求描述
- 项目范围

---

## Workflow
1. 梳理企业层级：老板（战略层）/部门负责人（管理层）/执行人员（操作层）
2. 分析各层级关注点：老板关注ROI和战略/部门关注管理效率/执行关注操作便利
3. 收集各层级需求并标注来源
4. 识别需求冲突和优先级
5. 组织需求对齐会议，协商解决冲突
6. 形成统一需求文档，各方确认
7. 输出需求对齐报告

---

## Output Format
企业多层级需求对齐报告（含各层级需求+冲突分析+统一需求+确认表）

---

## Output Template
```
需求编号 | 需求描述 | 来源层级 | 关注点 | 冲突情况 | 解决方案 | 确认状态
```

---

## Example
| 字段 | 内容 |
|------|------|
