## When to Use

## Input Requirements
- 投标文件
- 招标文件合规要求

---

## Workflow
1. 校验资质合规：资质等级/有效期/范围匹配
2. 校验公章合规：公章类型/位置/清晰度
3. 校验格式合规：文件格式/大小/命名/份数
4. 校验响应合规：实质性条款/非实质性条款响应
5. 校验报价合规：报价方式/币种/税费/有效期
6. 校验时间合规：递交时间/有效期/服务期
7. 输出合规校验报告

---

## Output Format
合规校验报告（含合规/不合规项分类清单）

## Output Template

