## When to Use

## Input Requirements
- 项目需求
- 适用法规政策
- 政务信息化标准

---

## Workflow
1. 梳理适用法规：政府采购法/招投标法/数据安全法/网络安全法/个人信息保护法
2. 对标行业标准：政务信息系统整合共享/等保2.0/密码评估/信创要求
3. 在方案中嵌入合规设计：安全合规/数据合规/信创合规
4. 使用政务规范用语，避免商业口语
5. 突出政策响应：方案如何落实上级政策要求
6. 加入政务信息化绩效目标
7. 输出合规方案文档

---

## Output Format
G端合规方案（含法规对标表+合规设计+政策响应+绩效目标）

---

## Output Template
```
合规维度 | 适用法规/标准 | 方案对应措施 | 对标条款 | 合规状态
```
