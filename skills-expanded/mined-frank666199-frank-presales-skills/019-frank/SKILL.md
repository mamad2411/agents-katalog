# Skill: Frank-售前方案内部预审工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度2 - 售前全流程标准化
- **Description**: 自查方案漏洞、逻辑问题、落地性短板

---

## When to Use
方案初稿完成后，提交客户前进行内部预审

---

## Input Requirements
- 方案文档
- 需求清单
- 招标文件（如有）

---

## Workflow
1. 检查方案完整性：是否覆盖所有需求项
2. 检查逻辑一致性：前后表述是否矛盾
3. 检查技术可行性：方案是否有落地依据
4. 检查商务合理性：报价与方案是否匹配
5. 检查合规性：是否符合行业法规和标准
6. 检查竞争性：与竞品方案对比是否有亮点
7. 输出预审问题清单和修改建议

---

## Output Format
方案预审报告（含问题清单+修改建议+通过/不通过结论）

---

## Output Template
```
审查维度 | 问题描述 | 所在章节 | 严重程度 | 修改建议 | 负责人
```

---
