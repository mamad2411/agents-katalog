# Skill: Frank-售前项目台账管理工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度2 - 售前全流程标准化
- **Description**: 标准化管理所有跟进项目，杜绝线索流失

---

## When to Use
日常项目管理，每周/月更新

---

## Input Requirements
- 项目基本信息
- 当前进展状态
- 下一步计划

---

## Workflow
1. 建立项目台账模板：项目编号/客户/阶段/金额/预计成交时间/负责人/状态
2. 按阶段分类管理：线索/需求/方案/投标/谈判/成交/流失
3. 设置关键节点提醒（如投标截止日/方案提交日）
4. 每周更新进展，标注风险和需要支持的事项
5. 月度统计汇总：转化率/平均周期/金额分布
6. 生成项目看板和统计报表

---

## Output Format
项目台账表 + 项目看板 + 月度统计报表

---

## Output Template
```
项目编号 | 客户名称 | 项目阶段 | 预估金额 | 成交概率 | 预计成交 | 负责人 | 下一步 | 风险
```
