# Skill: Frank-技术方案分册设计工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度3 - 方案编制与文档优化
- **Description**: 针对云/大数据/AI/安全/IoT场景，生成含架构图和技术选型的详细设计

---

## When to Use
方案中需要专业技术分册，或客户要求详细技术方案

---

## Input Requirements
- 项目需求
- 技术约束
- 现有技术资产

---

## Workflow
1. 确定技术方案范围：基础设施/平台/应用/集成/安全
2. 设计技术架构（含架构图）
3. 制定技术选型方案（对比分析+选型理由）
4. 详细设计各技术组件
5. 设计部署方案（物理/逻辑/网络拓扑）
6. 制定技术标准和规范
7. 输出技术方案分册

---

## Output Format
技术方案分册（含架构图+选型表+部署方案+技术标准）

---

## Output Template
```
技术组件 | 选型方案 | 备选方案 | 选型理由 | 部署方式 | 性能指标
```
