# Skill: Frank-政务项目红头话术适配工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度5 - G端政府项目专精
- **Description**: 适配政府公文风格，优化汇报与方案话术

---

## When to Use
面向政府客户的方案、汇报、纪要需要公文风格适配

---

## Input Requirements
- 原始文档
- 文档类型（方案/汇报/纪要）
- 目标读者层级

---

## Workflow
1. 将商业用语转为政务用语（如'产品'→'系统'，'客户'→'服务对象'）
2. 增加政策引用和上级精神呼应
3. 调整语气：客观严谨、不夸大、用数据说话
4. 规范格式：标题层级/编号方式/用语习惯符合公文规范
5. 加入政治站位表述（如'以人民为中心'）
6. 确保表述与上级政策文件一致
7. 输出政务风格文档

---

## Output Format
政务风格适配文档 + 修改对照表

---

## Output Template
```
原文表述 | 政务适配后 | 修改类型 | 修改理由
```

---

## Example
| 字段 | 内容 |
|------|------|
| '我们的产品很好' | '本系统可有效提升政务服务效能' | 用语适配 | 政务公文避免商业推广语气 |

## Constraints
- 用语符合政府公文规范
- 政策引用准确
- 不使用商业推广语气
