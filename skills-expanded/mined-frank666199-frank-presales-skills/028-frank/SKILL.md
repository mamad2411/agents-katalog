# Skill: Frank-项目可行性研究报告优化工具

## Profile
- **Author**: Frank
- **Version**: 1.0.0
- **Language**: 中文
- **Category**: 维度3 - 方案编制与文档优化
- **Description**: 规范可研结构，强化可行性与落地性论述

---

## When to Use
政府项目立项阶段，需要编写可行性研究报告

---

## Input Requirements
- 项目基本信息
- 可研初稿（如有）
- 政策依据文件

---

## Workflow
1. 规范可研结构：总论→现状分析→需求分析→建设必要性→建设方案→投资估算→资金筹措→效益分析→风险分析→结论建议
2. 强化建设必要性论述：政策依据+现实需求+发展需要
3. 细化技术可行性分析：技术成熟度+方案可行性+实施可行性
4. 完善经济可行性分析：投资估算+运营成本+效益测算
5. 补充风险分析和应对措施
6. 优化结论和建议部分

---

## Output Format
优化后的可行性研究报告（含评审通过级质量）

---

## Output Template
```
章节 | 规范要求 | 当前内容 | 优化建议 | 优化后内容
```
