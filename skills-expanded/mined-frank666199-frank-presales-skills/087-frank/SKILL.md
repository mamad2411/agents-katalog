## When to Use

## Input Requirements
- 完整方案
- 汇报时间

---

## Workflow
1. 分析高层关注点：战略价值/投资回报/风险控制/竞争优势
2. 精简内容为一页纸：背景(20%)+方案(30%)+价值(30%)+投资(10%)+风险(10%)
3. 提炼3个核心价值点
4. 准备30秒/3分钟/15分钟三版本
5. 突出量化价值：降本X万/增效X倍/风险降低X%
6. 预判领导提问并准备应答
7. 输出高层汇报材料

---

## Output Format
高层汇报材料（含一页纸+30秒版+3分钟版+15分钟版+Q&A预案）

---

## Output Template
```
汇报版本 | 时长 | 核心信息 | 关键数据 | 呈现方式
```
