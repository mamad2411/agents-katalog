# Reglas para Antigravity/Cursor (sin Copilot)

Siempre leer y respetar docs/statement.md y .github/copilot-instructions.md.

- Backend: Node.js con Express.
- Frontend: React SPA.
- BD: PostgreSQL o MySQL; en produccion debe ser RDS.
- AWS SDK: v3 para Node.js.
- Variables de entorno obligatorias; nunca hardcodear credenciales.
- Contrasenas en BD: almacenar con MD5.

Contexto vivo:
- Cada cambio en arquitectura, infraestructura, rutas, modelos o servicios AWS debe reflejarse en .github/copilot-instructions.md.
