# 90 Days of Cybersecurity

Structured 90-day cybersecurity learning plan — from Network+ foundations to active penetration testing.

Repo: `farhanashrafdev/90DaysOfCybersecurity` (18.7k stars)
URL: https://github.com/farhanashrafdev/90DaysOfCybersecurity

## Roadmap

| Days | Focus |
|------|-------|
| 1–15 | Networking fundamentals (OSI, TCP/IP, subnetting, DNS, HTTP) |
| 16–30 | Linux for security (bash, permissions, processes, logs) |
| 31–45 | Security concepts (CIA triad, threat models, OWASP Top 10) |
| 46–60 | Tools (Nmap, Wireshark, Burp Suite, Metasploit basics) |
| 61–75 | Web app security (XSS, SQLi, IDOR, auth bypass) |
| 76–90 | Penetration testing methodology, CTF practice, report writing |

## Certification path

Network+ → Security+ → CEH or eJPT → OSCP

## Daily study prompt

```
I am on Day [N] of 90 Days of Cybersecurity.
Topic: [topic].

1. Explain the concept — what it is, why it matters, real-world example.
2. Show a hands-on lab I can do locally or on TryHackMe / HackTheBox.
3. Key tool to practice: [tool name + one command example].
4. Quiz me with 3 questions when I say "quiz me".
```

## CTF helper prompt

```
I am solving a CTF challenge. Category: [web / pwn / crypto / forensics / reversing].
What I know so far: [describe the challenge].
Hint level: [nudge only / explain the technique / walk me through].
Do NOT give me the flag directly — guide me to find it.
```

## Threat model prompt

```
Act as a security analyst. Perform a basic threat model for [system/app].
Use STRIDE: Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege.
For each threat: likelihood (1-5), impact (1-5), one mitigation.
Output as a markdown table.
```
