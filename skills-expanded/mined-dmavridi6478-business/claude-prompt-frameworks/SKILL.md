# Claude Prompt Frameworks

Eight acronym frameworks for building structured, high-quality prompts. Each letter is a component to fill in.

## 01 — C-L-A-R-I-T-Y

| Letter | Stands for |
|---|---|
| C | Context |
| L | Look & Feel |
| A | Ask |
| R | Rules |
| I | Input |
| T | Target |
| Y | You (role) |

## When to use which

| Use case | Best framework |
|---|---|
| Quick one-off prompt | CATCH or TRUST |
| Creative / content work | MAGIC or RIPPLE |
| Complex research task | SOCRATES or ANTICIPATE |
| Project or campaign | PARTNER or CLARITY |
