# Voice and Audio Tools (hosted)

Source: iCloud note "Links and sites". The repo already has `ai-voice-tools` for open-source models (OpenVoice, F5-TTS, Fish Speech, Kokoro, CosyVoice); this skill covers the hosted tools. Capability notes unverified live.

| Need | Tools |
|---|---|
| Natural TTS and voice cloning | elevenlabs.io (also elevenlabs.io/genfm podcast generation), speechma.com, freetts.com |
| Podcast production | podcastle.ai, podial.ai |
| Music generation | musicgpt.com, minimax.io/audio |
| Stem separation / vocal remover | x-minus.pro/ai |
| Speech cleanup | Adobe Enhance Speech |
| Transcribe and summarise meetings | tl;dv, notta.ai, proactor.ai, quillmeetings.com, fireflies-style tools |
| Lecture summaries | balise.io |
| Video dubbing | vozo.ai |

## Rules
1. Voice cloning requires the speaker's explicit consent; refuse to clone a third party's voice for impersonation.
2. Record meeting-transcription tools' data-retention and consent rules before inviting a bot to a call.
3. Check licence terms before using generated music commercially.
