# Public APIs — Curated Free API Directory

A community-maintained list of 1,400+ free public APIs, organized by category with auth type, HTTPS support, and CORS status.

## What it replaces

Spending hours searching for usable public APIs across Stack Overflow, Reddit, and random blog posts.

## Categories covered (sample)

| Category | Examples |
|---|---|
| AI/ML | Hugging Face Inference, OpenAI, Cohere, Stability |
| Finance | Alphavantage, CoinGecko, Yahoo Finance |
| Weather | OpenWeatherMap, WeatherAPI, Open-Meteo |
| Government | US Census, EPA, NASA, EU Open Data |
| Sports | TheSportsDB, API-Football, NBA Stats |
| Books/News | Open Library, NewsAPI, NY Times |
| Social | Reddit API, Dev.to, Mastodon |
| Geocoding | OpenStreetMap Nominatim, ip-api.com |

## API entry format

Each entry lists:
- **API name** and brief description
- **Auth** method (No, apiKey, OAuth)
- **HTTPS** (Yes/No)
- **CORS** support (Yes/No/Unknown)
- **Link** to documentation

## When to reach for it

- Building a demo and need sample data fast (weather, stock prices, quotes)
- Enriching user profiles or company records without a paid data vendor
- Teaching API integration — large selection of no-auth APIs
- Pre-flight check before committing to a paid API vendor
