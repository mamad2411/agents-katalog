# Claude Prompts for Recurring Work

Paste any of these directly into Claude, filling in the bracketed placeholders.

## Daily work

```
Give me a 3-bullet summary of this email thread and what action I need to take.
[PASTE THREAD]
```

```
Write a professional email to [name] about [topic]. Tone: [formal/warm]. Keep it under 150 words.
```

```
Here are my rough meeting notes. Turn them into a clean action item list with owners: [PASTE]
```

```
Create a structured weekly status update I can send to my team based on these bullet points: [PASTE]
```

```
/DEVIL — Push back hard on this plan and tell me exactly what could go wrong: [PASTE PLAN]
```

## Communication

```
Create a 30-minute meeting agenda for [topic] with time blocks and discussion questions.
```

```
Explain [concept] to me like I have no background. Then give me 3 questions to test whether I actually understood it.
```

```
Write a job description for [role] at a [company type]. Focus on outcomes, not just tasks.
```

```
Here is this data. Write a 3-paragraph narrative that explains the key trend and why it matters: [PASTE DATA]
```

```
Help me prepare for a difficult conversation with [person] about [topic]. Give me talking points and likely objections.
```

## Strategy and growth

```
Rewrite this for [audience]. Make it clear and relevant to their priorities. Remove anything they won't care about: [PASTE]
```

```
Create a week-by-week project plan for [goal] starting [date]. Include dependencies and milestones.
```

```
I am presenting [topic] to [audience]. Give me an opening hook, 3 main points, and a strong close.
```

```
Turn these steps into a clear standard operating procedure that anyone could follow without me in the room: [PASTE STEPS]
```

```
Help me write a self-performance review. My wins were [X]. My growth areas were [Y].
```
