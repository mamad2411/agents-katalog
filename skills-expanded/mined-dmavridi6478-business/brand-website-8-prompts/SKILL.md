# Brand + Website in One Afternoon

Eight sequential prompts from @martiendejong_dev. Run them in order inside a single session. Each prompt assumes you've completed the previous one — paste the output of each step into the next.

---

## Prompt 1 — Lean Brand Consultant

```
I'm launching a brand for [business/product] and want to focus only on what's essential to launch credibly today. My target audience is [target audience], and I solve [specific problem]. Define the minimum brand elements I need to go live, prioritizing functionality and clarity over unnecessary polish. Also identify what I should deliberately postpone or avoid investing time in at this stage.
```

---

## Prompt 2 — Messaging Strategist

```
Based on my business [business] and target audience [audience], create one clear, powerful core message I can use across all brand touchpoints. In a single sentence, explain what I offer, who it's for, and why it matters—so clearly that a stranger can understand it within 5 seconds, without needing any additional context
```

---

## Prompt 3 — Lean Brand Designer

```
Based on the core message of [your business], create the most minimal visual identity needed to launch. Define just one primary color and one accent color with HEX codes, one Google Fonts font pairing, and a simple text-based or minimalist logo concept that I can create myself in under 15 minutes. Keep it practical, cohesive, and easy to execute—no complex branding system or unnecessary design elements.
```

---

## Prompt 4 — Lean Website Strategist

```
Using the core message and visual identity of [your business], create a simple, conversion-focused one-page website structure. Include only the essentials: a strong headline communicating the core message, a short supporting paragraph explaining the offering, relevant proof or credibility where available, and one clear call-to-action. Keep the structure minimal, easy to build, and focused on getting the brand live today—no multi-page navigation, unnecessary sections, or complex features.
```

---

## Prompt 5 — Credibility Consultant

```
For the single-page website of my [business], identify the strongest and most authentic proof I can present today, even if I don't have traditional credentials or extensive results yet. Consider available evidence such as early outcomes, a clear and credible process, relevant experience, a personal story, or transparency about being new. Then write one concise proof section using only what I genuinely have right now—no exaggerated claims or invented credibility.
```

---

## Prompt 6 — Lean Copywriter

```
Using the core message, proof points, and website structure for [your business], write the complete copy for a single-page website, including the main headline, supporting context paragraph, proof section, and one clear CTA. Keep every sentence concise, specific, persuasive, and ready to publish as-is. Avoid jargon, filler, generic marketing language, and placeholders that would require rewriting later.
```

---

## Prompt 7 — Launch Coordinator

```
Create a concise go-live checklist for my [business] to confirm that the minimum viable brand is ready to launch today. Verify that the core message is clear, the visual identity is applied consistently, the website works properly, and the contact method is functional. Focus only on critical issues that could damage credibility or make a poor impression on a first-time visitor. Flag the top 2–3 problems that must be fixed before launch, and ignore minor cosmetic imperfections.
```

---

## Prompt 8 — Growth Consultant

```
Now that my [business] minimum viable brand is live, create a simple 2-week iteration plan focused on real-world feedback rather than assumptions. Identify the key signals I should monitor—such as visitor behavior, common questions, drop-off points, objections, and areas of confusion—to determine what needs improvement next. Prioritize actionable insights over cosmetic changes, and explain how I should use the feedback to make informed updates to the brand.
```
