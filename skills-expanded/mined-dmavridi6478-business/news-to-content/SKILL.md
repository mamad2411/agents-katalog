# News to Content

Search for this week's top 3 developments in a niche and turn each into a TikTok content angle.

## Usage

```
/news-to-content [niche]
```

## Prompt

Search for the 3 most recent significant developments in [niche] this week. Summarise each and suggest a TikTok angle for each one.

## Steps

1. Web-search for the latest news in the niche (past 7 days).
2. Pick the 3 most significant or shareable stories.
3. For each story:
   - **Summary** — 2–3 sentences, plain English
   - **TikTok angle** — a hook line + the content format (e.g. "here's why this matters to you" / storytime / reaction)
   - **Time-sensitivity** — post today / this week / evergreen
