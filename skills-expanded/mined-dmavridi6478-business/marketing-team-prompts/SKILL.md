# Marketing Team Prompts

10 prompts that replace specific marketing roles. Swap in your product/service details.

## 1. Content Strategist

```
Act as a senior content strategist. Create a 30-day content plan for [business/product].
Include: content pillars, post types, posting frequency, and one hero piece per week.
Target audience: [describe]. Goal: [awareness / leads / retention].
```

## 2. Copywriter

```
Act as a direct-response copywriter. Write 3 versions of a sales email for [product/offer].
Each version should use a different hook: curiosity, pain point, and social proof.
Keep each under 150 words. CTA: [your CTA].
```

## 3. Email Marketer

```
Act as an email marketing specialist. Write a 5-email welcome sequence for new subscribers to [brand].
Each email should have one job. Include subject line, preview text, and body copy.
Brand voice: [describe]. End goal: [purchase / book a call / activate feature].
```

## 4. SEO Specialist

```
Act as an SEO specialist. Give me 10 long-tail keywords for [topic/niche] with low competition.
For each: explain search intent, suggest a content angle, and rate difficulty 1-10.
My site focuses on: [describe].
```

## 5. Ad Creative

```
Act as a paid social creative director. Write 3 Facebook/Instagram ad scripts for [product].
Format: Hook (3 sec) → Problem → Solution → Proof → CTA.
Target: [audience]. Budget level: [awareness / conversion].
```

## 6. Landing Page Writer

```
Act as a conversion copywriter. Write a full landing page for [offer].
Sections: headline, subheadline, problem, solution, features/benefits, social proof, FAQ, CTA.
Tone: [describe]. Reader's main objection: [what holds them back].
```

## 7. Brand Strategist

```
Act as a brand strategist. Define the brand identity for [business].
Deliver: brand mission (1 sentence), core values (3), brand voice (3 adjectives + what it avoids),
ideal customer profile, and 1 positioning statement.
```

## 8. Market Researcher

```
Act as a market research analyst. Analyse the competitive landscape for [product/niche].
Identify: 3 direct competitors, their positioning, pricing model, key weaknesses, and gaps I can exploit.
Format as a comparison table plus a 3-bullet opportunity summary.
```

## 9. Social Media Manager

```
Act as a social media manager. Write 7 days of posts for [platform] promoting [product/topic].
Mix formats: educational, story, engagement question, behind-the-scenes, testimonial, tip, CTA post.
Brand voice: [describe]. Keep each post under [character limit].
```

## 10. Analytics Translator

```
Act as a data analyst. I'll give you raw marketing metrics — translate them into plain-English insights
and 3 actionable recommendations.
Metrics: [paste your numbers].
Context: [what we were trying to achieve].
```
