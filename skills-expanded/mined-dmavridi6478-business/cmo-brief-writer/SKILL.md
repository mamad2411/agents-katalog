# CMO brief writer

Prompt (from "The CMO's ChatGPT Playbook", routine 10): "Turn these notes into a brief: goal, audience, message, deliverables, budget, and deadline."

## Procedure
1. Read the notes. Extract the six fields; mark each EXPLICIT (stated), INFERRED (derived, say from what) or MISSING.
2. Write the brief with the six headings in that order, one tight paragraph or list each.
3. List MISSING fields as questions at the end; never invent budget, deadline or audience.
4. Keep it to one page. Add a one-line "what success looks like" only if the notes state it.
