# Useful Websites for Entrepreneurs

Five free-tier-first tools, each solving one narrow job well. Verify current
free-tier limits before relying on them — they change pricing periodically.

| Tool | What it's for | Link |
|---|---|---|
| Hunter | Finds professional email addresses and discovers potential customers/contacts by domain or name — the standard first stop for cold-outreach list-building | https://hunter.io |
| SERPtag | Keyword research, rank tracking, and search-visibility monitoring across major search platforms | https://serptag.com |
| BuiltWith | Looks up what technology stack (CMS, analytics, hosting, ecommerce platform, ad pixels) any live website is running — useful for competitor research and lead qualification | https://builtwith.com |
| Microsoft Clarity | Free session recordings, heatmaps, and AI-summarized UX insights showing where visitors click, scroll, and drop off — a no-cost alternative to paid heatmap tools | https://clarity.microsoft.com |
| Carrd | Builds simple, professional one-page sites fast (landing page, personal profile, waitlist page) — free tier covers most single-page needs | https://carrd.co |

## When to reach for which

- Building a cold-outreach list and need verified emails → Hunter.
- Need to know what keywords a page should target or how rankings are trending → SERPtag.
- Sizing up a competitor's or prospect's stack before a sales call or before deciding what to build → BuiltWith.
- A landing page's conversion rate is off and you need to see *why* (not just that) → Microsoft Clarity's session recordings and click heatmaps.
- Need a page live today for a waitlist, personal bio, or single-offer page, no full site build → Carrd.
