## When to use this skill

Reach for one of these instead of improvising when a task needs:

- **Illustrations** for a deck, landing page, or doc → unDraw
- **Brand/product logos as real SVG** rather than hand-drawn paths → SVGL
- **Pre-built landing-page component patterns** (hero sections, bento grids, glare/glowing effects) → Aceternity
- **A CSS glassmorphism effect** without manually tuning blur/opacity/refraction → Glassmorphism generator
- **Visualizing/debugging a JSON payload** as an interactive graph → JSON Crack
- **Studying real iOS/web product flows screen-by-screen** for reference before designing one, instead of guessing at patterns → Mobbin
- **Studying ecommerce/product-page UX patterns specifically** (filterable by platform/category) → Ecomm.Design
- **Browsing creator-shared UI component snippets** by component type for a sharper starting point → UI.live
- **Previewing a color palette and font pairing on a real layout** before committing to a hex value → Realtime Colors
- **Editing shadcn design tokens against a live dashboard preview** instead of guessing at CSS variables → tweakcn
- **Building a realistic layered shadow** (not a flat single box-shadow) and copying it as CSS or a Figma layer → Smooth Shadows
- **Inspecting what a font file actually supports** (variable axes, layout features, glyph count) before relying on it → Wakamai Fondue
- **Browsing curated reference sites before starting a build** (so it doesn't default to a template look), matched to the actual job — SaaS landing page, restrained editorial, or award-tier interaction → Design inspiration galleries below
- **Finding a real example AI image/video generation prompt** to adapt, rather than writing one from a blank page → AI prompt discovery libraries below

## AI prompt discovery libraries

Not design-reference galleries — these browse *other creators' actual AI
image/video generation prompts*, filterable by model, with a one-click
"use this prompt" flow. Reviewed from an uploaded screen-recording (a
TikTok, @simplydigital, "3 Websites for unlimited FREE PROMPTS"); this
session's network egress is blocked to all three domains, so they weren't
independently browsed — the descriptions below come from what the
recording actually showed on screen, not a live visit.

| Site | What it's for | Link |
|---|---|---|
| Meigen.ai | Gallery of AI-generated images/video, filterable by model (GPT Image, Seedance 2.0, Nanobanana, Midjourney); each post shows the full prompt its creator used, with "Use as Prompt" and "Use as Ref" buttons | https://www.meigen.ai |
| Yesand.ai | Similar prompt-attached image/video gallery, browsable by category (Featured, World Cup, Pride Month, Grads, Fashion, Collage, Video, Portrait) rather than by model | https://yesand.ai |
| YouMind (Prompts) | Billed as "the world's largest free AI prompt library" — 20,000+ image/video/workflow prompts, updated daily, organized into curated packs and a "hottest this week" feed; each entry has a "View full prompt" / "Try now" pair | https://youmind.com/prompts |

These are attribution-driven community galleries — the prompts belong to
the individual creators who posted them (e.g. a Meigen.ai post credited
to "Pierrick Chevallier | IA" for a Seedance 2.0 anime-action prompt),
not the platforms. Browse and adapt from them directly rather than
treating any single one as a generic template to copy verbatim without
crediting its source. See `ai-video-image-prompt-structure` in this
repo's skills for the reusable *structural pattern* these libraries all
converge on, written fresh rather than lifted from any one example.

## External AI tools worth knowing about

Not Claude Code skills — external SaaS products. Mention these to the user as *options* when they're evaluating tooling; don't assume access or an account exists.

| Tool | What it's for |
|---|---|
| Genspark | Multi-agent AI workspace — one prompt fans out to research/writer/analyst/designer agents inside a shared project (research, docs, slides, analysis) |
| Google Stitch | Text/voice-to-UI — describes a screen or flow in plain language, generates a working interface draft (landing pages, app flows, MVP concepts) |
| Google Flow | AI video/scene-builder — storyboards and generates cinematic clips/scenes from text descriptions (campaigns, concept videos) |
| Gumloop | Visual AI workflow automation — chains triggers/AI steps/actions (e.g. inbound email → extract → summarize → notify) without code |
| Figma Make | AI prototyping inside Figma — turns a design or idea into a clickable, interactive prototype fast |
| Kombai | AI design engineer — turns a prompt into a crafted, production frontend that reads as hand-made, not AI-default; positioned for engineers who want design taste without a separate designer handoff |
| Visily | AI prototyping — turns a prompt, a screenshot, or a hand-drawn sketch into an editable UI concept, for exploring direction before spending time polishing |
