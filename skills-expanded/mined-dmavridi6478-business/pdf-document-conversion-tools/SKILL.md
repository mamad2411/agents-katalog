# PDF, Document and Conversion Tools

Source: iCloud note "Links and sites". Capability notes unverified live.

## Hosted tools
- **PDF editing/conversion**: d-pdf.com, simplepdf.eu, lightpdf, hipdf.com, PDF.wondershare.com, sejda.com (edit PDFs), tinywow.com (many free file and AI tools), cloudconvert.com (any format to any format), iloveimg.com (images).
- **Translation**: deepl.com. **Video/audio conversion**: videoconverter.wondershare.com, cloudconvert.com.
- **Formula/spreadsheet helpers**: formulabot.com / formula.bot, gptexcel.uk, rows.com, "graphs" (Excel to graphs).

## Self-hosted option
**Stirling-PDF** (stirlingpdf.io) runs locally in Docker and keeps documents off third-party servers. See `repo-stirling-pdf`.

## Rules
1. For contracts, medical, HR or financial documents prefer Stirling-PDF or a local tool; do not upload confidential files to free hosted converters.
2. In this environment convert attached PDFs to Markdown with the `pdf-to-markdown` skill first (standing preference).
3. State what the conversion may lose (layout, tables, OCR accuracy) and spot-check the output.
