# AI Business Consultant — 10 McKinsey-Replacement Prompts

> These prompts replace common high-cost consulting outputs. Fill in the `[BRACKETED]` fields with your specific context before running.

---

## Prompt 1 — SWOT Analysis

```
Act as a business strategist. Build a SWOT for [INSERT BUSINESS] in [INSERT INDUSTRY].

Include:
- Strengths (internal)
- Weaknesses (internal)
- Opportunities (market)
- Threats (competitive)

Add:
- Top 3 strategic implications from the SWOT
- 3 'next actions' tied directly to the SWOT findings
- Use assumptions explicitly if data is missing; list 'data to request' at the end
```

---

## Prompt 2 — Growth Levers

```
Identify 5 scalable growth levers for a [TYPE OF BUSINESS].

Cover: revenue expansion, operational efficiency, distribution, partnerships, brand reach.

For each lever:
- Expected impact
- Effort required
- Risks
- Leading indicator KPI

Rank levers by Impact × Confidence × Speed (simple score).
```

## Prompt 3 — 30-60-90 Day Plan

```
Create a 30-60-90 plan for a new [INSERT ROLE] at [COMPANY].

For each phase (30 / 60 / 90 days):
- Objectives
- Key stakeholders to engage
- Deliverables
- Success metrics
- Quick wins

Include:
- Do / Don't list for the first 30 days
- Recommended meeting cadence
- 5 questions to ask leadership in week 1
```

---

## Prompt 4 — Revenue Model Projection

```
Develop a lean revenue model for [PRODUCT/SERVICE].

Define:
- Pricing strategy
- CAC drivers
- Payback period
- LTV assumptions
- Churn assumption

Output:
- Month-by-month MRR for 12 months
- Best / base / worst scenarios

List 5 model sensitivities and which metric to validate first.
```

---

## Prompt 5 — Churn Reduction

```
Suggest 3 data-driven churn reduction strategies for a SaaS targeting [TARGET CUSTOMER].

Use: behavior signals, cohort analysis, feedback loops, onboarding friction points.

For each strategy:
- Hypothesis
- Experiment design
- Measurement window
- KPI
- Tool / data needed

Include an 'early warning signals' checklist (5 items).
```

---

## Prompt 6 — KPI Dashboard Framework

```
Outline the 7 critical KPIs for a [BUSINESS TYPE].

Group into: acquisition, activation/engagement, retention, revenue, efficiency.

For each KPI:
- Definition
- Formula
- Reporting cadence
- Owner
- Threshold bands (green / yellow / red)

Provide a one-page dashboard layout recommendation (section headings and placement).
```

---

## Prompt 7 — Pricing Strategy

```
Act as a pricing advisor. Propose 3 pricing approaches for [OFFER] aimed at [SEGMENT].

Include:
- Value-based anchor
- Tier structure
- Packaging options
- Positioning narrative

Provide:
- Pros / cons for each approach
- Risks
- Test plan (A/B or cohort rollout)

Recommend the default option and explain why, based on segment willingness to pay.
```

---

## Prompt 8 — Go-to-Market Plan

```
Design a GTM plan for launching [PRODUCT] to [TARGET MARKET].

Define:
- ICP (Ideal Customer Profile)
- Messaging
- Channels
- Distribution model
- Sales motion
- Onboarding path

Include:
- 90-day launch plan
- Budget buckets
- Success metrics by funnel stage
- Top 5 objections + rebuttal lines
```

---

## Prompt 9 — Value Proposition

```
Draft a persuasive value proposition for [BRAND OR PRODUCT].

Structure:
Customer job / pain → Insight → Solution → Proof → Differentiation → Outcome

Provide:
- 1 core statement
- 3 supporting bullets
- 3 tagline options

Include a 'who it's NOT for' section to sharpen positioning.
```

---

## Prompt 10 — Pivot Directions

```
Recommend 3 strategic pivot options for a startup facing [SPECIFIC PROBLEM].

For each pivot:
- New segment or use case
- Product change required
- Moat logic
- Revenue model shift

Provide:
- Risks
- Required capabilities
- 30-day validation experiments
- Kill criteria

Rank pivots by survivability and upside (simple score).
```
