# Pascal Editor — Browser-Based 3D Architectural Editor

A web-native 3D spatial design tool for architectural layouts, floor plans, and building visualisation.

## What it replaces

Desktop-bound CAD tools (AutoCAD, SketchUp, Revit) when you need an embeddable, browser-first 3D editor for a web product.

## Key capabilities

- **3D spatial design**: Draw walls, rooms, and spaces in 3D directly in the browser
- **Floor plan mode**: Top-down 2D layout that auto-converts to 3D
- **Material and finish library**: Apply materials to surfaces
- **Export**: STL, OBJ, or JSON for further processing
- **Embeddable**: React component-ready for integration into larger web apps

## When to reach for it

- Building a real-estate or architecture SaaS that needs a spatial editor
- Creating a space-planning tool (office layouts, interior design, event venues)
- Replacing a paid Matterport-style embed with an owned 3D experience
- Adding a floor-plan builder to a property listing or hospitality platform

## Stack

TypeScript · Three.js · React · WebGL
