# CMO monthly review

Prompt (from "The CMO's ChatGPT Playbook", routine 07): "From this data, write wins, misses, lessons, and next month's changes. Plain English, one page."

## Procedure
1. Take the data supplied (table, export, Drive file). State the period and the source. Missing period or source = ask once.
2. Compute only what the data supports: change vs prior period, vs plan if a plan is supplied.
3. Write one page with four headed sections: **Wins**, **Misses**, **Lessons**, **Next month's changes** (each change has an owner and a date placeholder).
4. Every number carries its source cell or file. Never fill missing data; write "not provided".
5. Plain English: no acronyms without expansion, sentences under 25 words.
