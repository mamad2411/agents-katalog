# 8 Claude Marketing Prompt Frameworks

8 acronym frameworks for structured marketing copy and strategy prompts.
Select the framework that fits your goal, fill in the bracketed fields, and paste.

---

## ANGLE — Positioning & Differentiation

> A: Audience · N: Need · T: Gap · L: Language · E: Edge

```
Audience: [who you're speaking to]
Need: [the core problem or desire they have]
Gap: [what the market currently misses]
Language: [the words and tone they use — casual, technical, emotional, etc.]
Edge: [your unique differentiator or unfair advantage]

Using this ANGLE framework, write a positioning statement and tagline for [product/brand].
```

---

## CLAIM — Offer & Conversion Copy

> C: Context · L: Lure · A: Ache · I: Impact · M: Motion

```
Context: [situation the reader is in right now]
Lure: [the hook or promise that grabs attention]
Ache: [the painful problem or frustration they feel]
Impact: [the transformation or result after using your offer]
Motion: [the call to action — what to do next]

Using this CLAIM framework, write [landing page headline + subhead / email subject + opener / ad copy] for [product/service].
```

---

## FLOW — Content & Narrative Structure

> F: Focus · L: Line · O: Offer · W: Warmth

```
Focus: [single idea or topic this piece is about]
Line: [opening line or hook that earns the read]
Offer: [what value, insight, or next step you're giving]
Warmth: [the human/emotional tone that makes it feel real, not corporate]

Using this FLOW framework, write a [LinkedIn post / email / short-form video script] about [topic].
```

---

## RAMP — Campaign & Growth Planning

> R: Reach · A: Angle · M: Milestones · P: Push

```
Reach: [channels and audiences this campaign will target]
Angle: [the creative angle or campaign concept]
Milestones: [the 3–4 measurable checkpoints — week 1, month 1, month 3]
Push: [the amplification tactics — paid, organic, partnerships]

Using this RAMP framework, build a [30-day / 90-day] campaign plan for [product/launch/event].
```

---

## KNOW — Audience Research & Messaging

> K: Known · N: Needs · O: Obstacles · W: Wants

```
Known: [what this audience already believes or assumes]
Needs: [what they functionally require — features, outcomes]
Obstacles: [what stops them from buying or changing — doubt, price, habit]
Wants: [what they emotionally desire — status, ease, belonging]

Using this KNOW framework, map the full buyer psychology for [target customer] and rewrite [headline / email / sales page] to speak directly to it.
```

---

## VALUE — Content Strategy & Proof

> V: Vehicle · A: Audience · L: Length · U: Upside · E: Evidence

```
Vehicle: [content format — carousel, thread, email, video, article]
Audience: [who will see this]
Length: [approximate word count or duration]
Upside: [the main benefit or takeaway for the reader]
Evidence: [stats, case studies, stories, or proof points to include]

Using this VALUE framework, outline and draft a [content piece] about [topic] for [platform].
```

---

## VOICE — Brand Voice & Style Guide

> V: Values · O: Overtone · I: Inclusions · C: Cuts · E: Examples

```
Values: [the 2–3 core brand values that should come through]
Overtone: [the emotional register — witty, warm, authoritative, rebellious, etc.]
Inclusions: [words, phrases, or references to use — industry terms, cultural references]
Cuts: [words, phrases, or tones to avoid — jargon, corporate-speak, etc.]
Examples: [1–2 existing pieces of copy that already sound right]

Using this VOICE framework, define the brand voice for [brand/product] and rewrite [sample text] in that voice.
```

---

## PATH — Sales & Nurture Sequences

> P: Problem · A: Action · T: Trust · H: Hand-off

```
Problem: [the specific problem the prospect is stuck on]
Action: [the first small action you're asking them to take]
Trust: [how you'll demonstrate credibility — testimonials, data, story, guarantee]
Hand-off: [the natural next step — demo, purchase, consultation, download]

Using this PATH framework, write a [3-email / 5-email] nurture sequence for [product/service] starting from [entry point — free download / webinar / ad click].
```

---

## Quick Framework Selection Guide

| Goal | Best framework |
|---|---|
| Launch a new product | ANGLE → CLAIM |
| Write content or a post | FLOW → VALUE |
| Plan a campaign | RAMP |
| Understand your buyer | KNOW |
| Define brand voice | VOICE |
| Write sales emails | PATH |
| Conversion copy | CLAIM |

---

## Chain for a full marketing brief

```
1. Run KNOW to map buyer psychology.
2. Run ANGLE to lock positioning.
3. Run CLAIM to write core offer copy.
4. Run PATH for the email nurture sequence.
5. Run FLOW for organic content around the launch.
6. Run RAMP to build the campaign plan around all of the above.
```
