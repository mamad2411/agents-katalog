| WordPress | 10web.io |
| Support chatbot | chatbase.co, voiceflow |

## Rules when using this skill
1. Ask who owns the code and where it will be hosted; builders differ on export and lock-in. Verify export on the live site.
2. Never paste secrets or customer data into a hosted builder.
3. For anything shipped, run `security-review` and `accessibility` skills on the output.
