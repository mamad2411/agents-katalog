# Canva Template Etsy Shop

Source: reviewed from an uploaded infographic carousel — "Build one Canva
template with AI. List on Etsy. Sell it while you sleep." (@earchoe,
carousel 18 of a 21-part series — a specific worked example, not a
generic passive-income framework). A Canva template is a digital
product with zero marginal cost to duplicate: build once, list it,
every sale after the first is pure margin.

## What sells best (2026)

Ranked by the source, evergreen-repeat-buyer potential first:

1. **Instagram carousel packs** — "30 templates for [niche coaches / real
   estate / therapists]." Evergreen, repeat buyers.
2. **Pitch deck templates** — freelancers and consultants buy repeatedly.
   £15-45, high perceived value.
3. **Media kit templates** — creators need them, can't design them, pay
   without hesitation. £12-30.
4. **AI prompt cards** — digital or printable. New format, low
   competition, fast-growing niche.
5. **Lead magnet templates** — eBook covers, checklists, challenge
   graphics. Every coach needs these.

**What makes a template worth buying**: solves a *specific, narrow*
problem ("30 Instagram carousel templates for coaches" beats "social
media templates" every time — specific sells, generic doesn't), looks
professional and edits easily (font/color/text swaps only, no complex
layers a non-designer would fumble), has clear preview/mockup images (the
listing image *is* the sale). Avoid over-complicated templates — if
editing one requires knowing Canva deeply, it produces refund requests and
bad reviews; test with 3 people before listing.

## The 30-minute build process

1. **Research top sellers.** On Etsy: search "[your niche] Canva
   template," sort by bestselling. Note what's selling and at what price.
   Don't copy — understand the demand.
2. **Brief Canva Magic Design** with the prompt below, then pick the best
   generated layout.
3. **Build the full template pack** — 9 slides (or the count that fits
   the format), matching colors, placeholder copy that instructs buyers
   ("Replace with your headline"). Save as a Canva template share link.
4. **Create the product mockup** with the second prompt below — this
   becomes the listing image.

### Prompts (copy-paste, for Canva Magic Design)

```text
Design a set of 9 Instagram carousel slides for [niche]. Clean, minimal, easy to edit. Placeholder text and images.
```

```text
Professional product mockup for a digital template pack.
```

## Platform comparison

| Platform | Fees | Best for |
|---|---|---|
| **Etsy** | 6.5% transaction fee + listing fees | Largest search traffic — templates buyers find by *searching*. Carousel packs, media kits, social templates. Start here. |
| **Gumroad** | No listing fees; 10% per sale on the free plan (lower with subscription) | Selling directly to your own existing audience. Premium bundles, courses + templates, higher price points. |
| **Beacons** | 0% fees on the paid plan (~$10/mo) | Built for content creators — integrates with TikTok/Instagram bio link. Ideal with 1,000+ followers in the niche; selling directly from a social audience. |

## Pricing guide

| Tier | Price (GBP) |
|---|---|
| Single template (1 carousel / 1 post design) | £5-9 |
| Small pack (5-10 templates, one niche) | £9-17 |
| Full pack (20-30 templates, cohesive brand) | £17-35 |
| Premium bundle (templates + guide + bonus) | £35-65 |

Volume comes from multiple listings, not one hero product — the source's
own math (100 sales/month at £17 average = £1,700, called "a realistic
6-month target") assumes a focused shop with 10-15 listings in a specific
niche, not a single bestseller. Treat that figure as the source's own
illustrative target, not a verified outcome — this account's own results
aren't disclosed.

## The Etsy listing structure

Use this structure for every listing, not just the first:

```text
TITLE: "[Number] [Format] Canva Templates for [Niche] | Editable | Instant Download"
  e.g. "30 Instagram Carousel Templates for Health Coaches | Stories Included"

IMAGE: Professional mockup (not a raw screenshot)

DESCRIPTION — first 3 lines matter most:
  1. What it is and who it's for
  2. What's included
  3. How they get it and edit it

TAGS (use all 13): Canva template · [niche] template · Instagram carousel ·
  social media template · editable · digital download · [niche] content ·
  content creator · [niche keyword]
```

## Launch checklist

- [ ] **Product built and tested** — 3 non-designers have tested editing
  it; all placeholder text is clearly labeled; all fonts are free in
  Canva.
- [ ] **Product mockup created** — a professional listing image showing
  the template in use, not a raw screenshot.
- [ ] **Delivery file prepared** — a PDF with the Canva template share
  link (set to "anyone with the link can use template"), usage
  instructions, and a quick-start guide.
- [ ] **Etsy/Beacons listing live** — title with keywords, professional
  description, all 13 Etsy tags used, price set, instant digital-download
  delivery configured.
- [ ] **First 3 listings published** — never launch one product; launch
  3-5 variations of the same niche simultaneously to find which converts
  fastest.
