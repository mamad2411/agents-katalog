# Tool Comparison (Web Search)

Search and compare two tools side-by-side using live data — pricing, features, and user reviews as of 2026.

## Usage

```
/tool-comparison-web [Tool A] [Tool B]
```

## Prompt

Search for and compare [Tool A] vs [Tool B] as of 2026. What are the latest pricing, features, and user reviews?

## Steps

1. Web-search each tool's current pricing page.
2. Search for recent comparison articles and reviews (2025–2026).
3. Search for user reviews on G2, Reddit, Product Hunt, or Trustpilot.
4. Return a structured comparison:
   - **Pricing** — side-by-side current tiers
   - **Key features** — what each does better
   - **User sentiment** — who prefers which and why
   - **Best for** — recommended use case for each
   - **Verdict** — which to choose for common scenarios
