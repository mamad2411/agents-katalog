# How to Use Claude to Start a Business

Source: @51ultron
9 steps · full business launch sequence

Paste any prompt directly into Claude, filling in the bracketed placeholders.

---

## Step 1 — Validate the Idea

```
I want to start a business around [idea]. Help me validate it before I build anything.

1. Who would pay for this and why?
2. What is the simplest version I could sell this week?
3. What are the top 3 reasons this fails?
4. What would I need to be true for this to work?

Return a one-page validation report: opportunity size, target buyer, minimum viable offer, and the single biggest risk.
```

---

## Step 2 — Create Core Business Files

```
Act as a brand strategist. I am starting [business name/type] for [target customer].

Write two files for me:

**about-me.md** — A personal founder brief: who I am, what I've done, why I'm starting this, what I believe about [industry], and what makes me the right person to build it. 300 words, first person, honest.

**brand-voice.md** — My brand's communication style: tone (3 adjectives), what we always say, what we never say, a before/after example of a rewritten sentence, and the one feeling we want every customer to leave with.

Return both as separate markdown documents I can save to my project folder.
```

---

## Step 3 — Build Claude Projects by Function

```
I am setting up Claude Projects to run my business. Help me define three projects:

**Strategy Project** — What system prompt should I give Claude so it always acts as my strategic advisor? It should know my business model, my constraints, and push back on bad ideas.

**Brand Project** — What system prompt should I give Claude so it always writes in my brand voice and never breaks it? Include the voice rules from my brand-voice.md.

**Operations Project** — What system prompt should I give Claude so it manages recurring tasks — follow-ups, scheduling, reporting — without me having to re-explain context each time?

Return each as a ready-to-paste system prompt.

[Paste your about-me.md and brand-voice.md below:]
```

---

## Step 4 — Create Business Assets with Artifacts

```
Act as a [designer / copywriter / consultant]. Using my brand voice and business details below, create the following artifact for me:

[Choose one:]
- One-page pitch deck (5 slides: problem, solution, market, offer, CTA)
- Website homepage copy (hero, features, social proof, FAQ, CTA)
- Pricing page with 3 tiers and feature comparison table
- Lead magnet (PDF title, 5-section outline, key takeaway per section)
- Email welcome sequence (5 emails, subject lines + body, Day 1/3/5/7/14)

Brand details: [paste key brand info]

Return as a complete, polished artifact I can use immediately.
```

---

## Step 5 — Sales Scripts and Outreach

```
Act as a sales coach. I sell [product/service] to [target buyer] at [price point].

Write me:
1. A 60-second verbal pitch for a cold introduction
2. A cold DM (under 150 words) that opens a conversation without pitching
3. A 5-email outreach sequence for a warm lead who showed interest but went quiet
4. Three objection responses for: "Too expensive," "Not the right time," "I need to think about it"

Tone: [confident / consultative / casual — pick one]. Return as a ready-to-use sales script kit.
```

---

## Step 6 — Connect Your Tools

```
I want to connect Claude to my existing tools so it can take actions, not just give advice.

My current tool stack: [list tools — e.g. Gmail, Google Calendar, Notion, HubSpot, Slack]

For each tool:
1. What connector or integration exists (native, Zapier, MCP)?
2. What tasks could Claude handle automatically once connected?
3. What is the one workflow I should set up first?

Return a prioritized setup plan with the highest-leverage connection first.
```

---

## Step 7 — Cowork on Real Documents

```
I need to work on a real business document with Claude as a collaborator, not just an advisor.

Document type: [contract / proposal / SOP / investor update / job description / client report]
Context: [describe the situation, the audience, and what the document must accomplish]

Open a Cowork session and help me:
1. Draft the full document from scratch
2. Flag anything legally, commercially, or logically risky
3. Suggest the strongest version of any weak section
4. Format it for the intended reader

Work through it section by section. Don't finish until it's ready to send.
```

---

## Step 8 — Build the Product with Claude Code

```
I want to build [product/tool/app] using Claude Code.

My technical level: [non-technical / some coding / comfortable with code]
What it should do: [describe the core function in one sentence]
Who will use it: [target user]
Stack preference: [web app / mobile / CLI / no preference]

Help me:
1. Decide the simplest technical approach
2. Write a CLAUDE.md file for this project so Claude always knows the context
3. Create the first working version I can test in under an hour
4. List the three next features to add after the first version works

Start with the CLAUDE.md file.
```

---

## Step 9 — Daily Business Brief

```
Act as my chief of staff. Generate my daily business brief.

My business: [one-line description]
My current focus this week: [top 3 priorities]
Yesterday's summary: [paste or describe what happened]
Open items: [paste list or describe pending decisions]

My brief should include:
- Top 3 actions for today (ranked by impact)
- One risk I should be watching
- One thing I am probably avoiding that I should not be
- A one-sentence reminder of the long-term goal

Keep it under 200 words. Direct tone. No filler.
```

---

## Usage guide

Run steps 1–3 to launch a new business from scratch.
Run step 9 every morning to stay on track.
Run steps 4–5 before any sales or marketing push.
Run step 6 once your core workflow is defined.
Run steps 7–8 when you need to build or ship something real.
