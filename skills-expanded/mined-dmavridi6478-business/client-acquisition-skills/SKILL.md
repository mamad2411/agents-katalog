## Folder 01 — Client & Market Intelligence (9 skills)

Understand your market, ideal clients, and what makes them buy.

### ICP Architect
```
Act as an ICP (Ideal Customer Profile) architect. Using [company description, current clients, product/service], define our perfect ICP: industry, company size, revenue range, decision-maker title, key pain points, buying triggers, and disqualifiers. Return a structured ICP document with a one-paragraph summary I can use in outreach.
```

### Pain Point Intelligence Builder
```
Act as a buyer pain point analyst. Research [target market/persona] and uncover their top 5 real pains around [problem area]. For each pain: name it, describe the root cause, quantify the business impact where possible, and suggest the emotional language buyers use when talking about it. Return as a markdown list.
```

### Buyer Language Extractor
```
Act as a voice-of-customer analyst. Using [reviews, testimonials, forum posts, or interview transcripts — paste below], extract the exact words and phrases buyers use to describe their problems, goals, and outcomes. Group by theme and return a swipe file of 20 real phrases I can use directly in copy and outreach.
```

### Competitive Positioning Analyst
```
Act as a competitive positioning analyst. Compare [our company] to [competitor 1], [competitor 2], [competitor 3] across: pricing, core value prop, target segment, key weaknesses (from reviews), and positioning gaps we can own. Return a positioning matrix and 3 differentiation angles I can lead with.
```

## Folder 02 — Prospecting & Lead Intelligence (10 skills)

Find the right prospects and prioritise the best opportunities.

### Ideal Prospect Finder
```
Act as a B2B prospecting strategist. Based on our ICP [paste ICP], suggest 10 specific ways to find prospects: which platforms, search filters, communities, events, and trigger signals to monitor. For each, describe the action and expected lead quality. Return as a prioritised list.
```

### Buying Signal Detector
```
Act as a sales intelligence analyst. Given these signals about [company/prospect name]: [paste signals — job postings, funding news, tech stack changes, social posts, website updates], identify which indicate active buying intent for [our solution]. Rate each signal high/medium/low and suggest a timely outreach angle for each.
```

### Lead Scoring Expert
```
Act as a lead scoring expert. Using these criteria for our ICP [paste ICP] and this list of prospects [paste list], score each lead 1–10 across: fit, timing, budget signals, and engagement. Return a ranked table with a one-line outreach priority note for the top 5.
```

### Account Prioritiser
```
Act as an account prioritisation strategist. Given this list of [X] target accounts [paste list], rank them by revenue potential and likelihood to close this quarter. Use these factors: company size, growth signals, tech stack fit, and any known pain points. Return a tiered list: Tier 1 (pursue now), Tier 2 (nurture), Tier 3 (deprioritise), with reasoning.
```

## Folder 03 — Outreach & Conversation Starters (10 skills)

Start better conversations with personalised, relevant outreach.

### Personalised Opener Writer
```
Act as a cold outreach specialist. Write 5 personalised opening lines for [prospect name] at [company], referencing [specific trigger: recent funding / LinkedIn post / company news / role change]. Each opener should feel like it was written for them specifically, not templated. Under 2 sentences each. High-reply tone, no fluff.
```

### Icebreaker Strategist
```
Act as an outreach icebreaker strategist. Using [prospect's LinkedIn profile / company news / recent content — paste below], craft 3 custom icebreakers that open a genuine conversation without pitching. Each should reference something specific, show real curiosity, and end with a low-friction question.
```

### LinkedIn Message Writer
```
Act as a LinkedIn outreach expert. Write a connection request message and a follow-up message sequence (3 messages, 3–5 days apart) for [prospect name] at [company]. Goal: start a conversation about [pain point / topic]. Keep connection request under 300 characters. Follow-ups: conversational, no hard sell. Include a clear but soft CTA in message 3.
```

### Multi-Channel Outreach Planner
```
Act as a multi-channel outreach strategist. Design a 14-day outreach sequence for [prospect segment] using email, LinkedIn, and [optional: phone/social]. Map each touchpoint: channel, day, message angle, and CTA. Vary the value offered in each touch (insight / resource / case study / direct ask). Return as a table.
```

## Folder 04 — Sales Conversion (10 skills)

Convert more prospects into clients with stronger conversations.

### Objection Handler
```
Act as a sales objection coach. For each of these common objections to [our product/service]: [paste objection list], write a 2–3 sentence response that acknowledges the concern, reframes it, and moves the conversation forward. Tone: confident but not pushy. Return as a ready-to-use objection bank.
```

### Value Proposition Builder
```
Act as a value proposition strategist. Using [product/service description] and [target persona], craft 3 distinct value propositions: one focused on time saved, one on revenue impact, one on risk reduction. For each: headline (under 10 words), supporting statement (2 sentences), and one proof point or metric. Return in a format I can use in decks and emails.
```

### Proposal Writer
```
Act as a proposal writer. Using [client name], [their stated pain points], [our proposed solution], and [pricing/scope], write a professional proposal covering: executive summary, problem statement, proposed solution, scope of work, timeline, investment, and next steps. Tone: consultative, confident. Return as structured markdown.
```

### Negotiation Assistant
```
Act as a negotiation coach. I'm entering a negotiation with [client name] over [deal details]. Their likely objections are [paste]. Help me: prepare my opening position, identify my walk-away point, anticipate their counter-moves, and script 3 responses to the most likely pushbacks. Return a negotiation brief I can reference in the meeting.
```

## Folder 05 — Pipeline & Acquisition Optimisation (10 skills)

Follow up intelligently and optimise your entire pipeline for more clients.

### Pipeline Health Checker
```
Act as a pipeline analyst. Using these pipeline metrics [paste: stage counts, deal sizes, conversion rates, average age in stage], diagnose the health of my sales pipeline. Identify: the biggest bottleneck stage, deals at risk of going cold, and the top 3 actions I should take this week. Return as a prioritised action plan.
```

### Follow-Up Strategist
```
Act as a follow-up strategist. I last spoke to [prospect name] about [topic/demo/proposal] on [date]. They said [their response]. Write a follow-up sequence: day 3, day 7, day 14 — each with a different angle (value add / new insight / direct ask). Tone: persistent but not annoying. Include a breakup email for day 21 if no reply.
```

### Win-Loss Analyst
```
Act as a win-loss analyst. Using these deal outcomes from the last quarter [paste: won/lost deals with reason if known], identify: top 3 reasons we win, top 3 reasons we lose, the profile of deals most likely to close, and one process change that would improve our win rate. Return as an executive summary with actionable recommendations.
```

### Acquisition Optimiser
```
Act as a client acquisition system auditor. Review my current process: [paste workflow, tools, and key metrics]. Identify the 3 highest-leverage improvements I can make in the next 30 days to increase the number of qualified clients acquired per month. For each: what to change, why, and how to measure impact.
```

## Usage guide

Run folders in order for a new market or campaign:
1. **Folder 01** — Build your ICP and map the market before any outreach
2. **Folder 02** — Find and score the right prospects
3. **Folder 03** — Start conversations that get replies
4. **Folder 04** — Convert conversations into signed clients
5. **Folder 05** — Review, follow up, and compound results each quarter

Run individual skills on demand for specific bottlenecks (e.g., Objection Handler before a tough renewal call; Win-Loss Analyst at end of quarter).
