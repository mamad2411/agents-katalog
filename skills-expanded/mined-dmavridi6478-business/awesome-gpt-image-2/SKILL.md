## GPT Image 2.5 model differences (from the spotlight section)

- **Sunburst**: precise editing — swap objects, change materials, modify specific elements while keeping the rest stable.
- **Flare**: fast, high-quality everyday generation — better default for bulk or time-sensitive production.

## Prompt discipline this repo teaches

Good GPT Image 2 prompts consistently include:
1. **Subject** — what is the main object/character/scene
2. **Style** — photorealistic, illustration, 3D render, etc.
3. **Lighting** — studio, natural, dramatic, etc.
4. **Composition** — angle, framing, crop
5. **Background** — specific, not just "white"
6. **Technical spec** — resolution hint, format for use (social, print, ad)

The 500+ cases in this repo are the fastest way to see that discipline applied to real commercial scenarios.
