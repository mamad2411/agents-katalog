# Everything you must know in Claude - six levels

| Level | Question | Options on the slide |
|---|---|---|
| 01 Where you open it | Which surface? | Browser (claude.ai: nothing to install, works on a locked-down work laptop); in Chrome (reads the tab, clicks, fills forms); on mobile (iOS and Android, same account and chats); on Desktop (works alongside real files, folders and apps; "the only door that reaches your files") |
| 02 Which brain you pick | Which model? | Haiku: fast and light, high volume, simple jobs. Sonnet: the daily driver, balanced speed and intelligence. Opus 5.5: the hard thinking. Fable 5.1: the frontier tier, when the task is genuinely difficult. Mythos: restricted to select organisations, not public yet |
| 03 How hard it thinks | Which effort? | Low: formatting, extraction, cleanup. Medium: everyday work, drafting, summarising, editing. High: the default, analysis and real decisions. Max: when the task actually deserves the wait. The trap: more thinking is not more correct; long reasoning gives it more room to be confidently wrong |
| 04 How you work | Which mode? | Chat (one question, one answer); Cowork ("about to be invisible in Chat"); Claude Design (a canvas for slides, prototypes and visuals, changed by talking); Projects (load files and instructions once, every chat starts smart); Claude Code (built for developers, also the fastest way to make Claude run things). Works inside Chrome, Excel, PowerPoint, Slack |
| 05 What you get back | Which output? | Artifacts (a document, dashboard or deck you can edit); real files (Word, Excel, PowerPoint, PDF); live artifacts (dashboards that refresh with your real data each time you open them) |
| 06 What it is plugged into | Which context? | Connectors (Gmail, Drive, Calendar, Notion, Slack, HubSpot and dozens more); memory (carries what matters between chats); skills (instructions you write once, followed forever) |

## Quick picks (added here)
- Locked-down laptop, one-off question: browser + Sonnet + Medium + Chat.
- Recurring report from your files: Desktop/Cowork or Claude Code + Opus + High + real files; connect the data source; save the steps as a skill.
- A hard analysis you will act on: Opus or Fable at High; check the reasoning against the source, because Max does not guarantee correctness.
- This session already has: connectors (HubSpot, Calendly, Gmail, Slack, Notion and others), skills (this repo), artifacts (published via the Artifact tool), Claude Code.
