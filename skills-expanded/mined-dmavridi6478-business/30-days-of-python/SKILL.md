# 30 Days of Python

Structured 30-day Python learning plan by Asabeneh Yetayeh. 3 difficulty levels per day, ending with web scraping, APIs, and databases.

Repo: `Asabeneh/30-Days-Of-Python`
Course: https://github.com/Asabeneh/30-Days-Of-Python

## Structure

| Days | Topics |
|------|--------|
| 1–5  | Syntax, variables, data types, operators, strings |
| 6–10 | Lists, tuples, sets, dictionaries, conditionals |
| 11–15 | Functions, modules, comprehensions, higher-order functions |
| 16–20 | Classes, file I/O, exceptions, regex |
| 21–25 | Virtual env, packages, APIs, JSON |
| 26–30 | Web scraping, pandas, databases, statistics |

## Daily practice prompt

```
I am on Day [N] of 30 Days of Python.
Topic: [topic from the repo].

1. Explain the concept in plain English (no jargon).
2. Show one minimal working example.
3. Give me 3 exercises at difficulty levels: beginner / intermediate / advanced.
4. Show the solution only after I ask.
```

## Accelerated review prompt

```
I already know [language / concepts]. I want to complete 30 Days of Python faster.
Skip basics I know: [list them].
For each remaining day, give me: key concept + one gotcha + one real-world use case.
Focus on: Python-specific idioms that differ from [my language].
```

## Project prompt (after Day 20)

```
I have completed 20 days of Python. Help me build a mini-project that uses:
- Functions + OOP
- File I/O or a database
- A public API
- Basic error handling

Project idea: [your idea or ask for one].
Keep it completable in a weekend.
```
