## Suggested paths (judgement, not from the card)
- Data engineer: Data Engineering Zoomcamp -> Data Engineering Handbook -> Cookbook.
- ML engineer: Machine Learning Zoomcamp -> Made With ML -> MLOps Zoomcamp -> Designing ML Systems.
- LLM and agents: LLM Zoomcamp -> AI Engineering -> System Design.
- Interview in 4 weeks: pick one interview repo (2 or 3), one system-design repo (9 or 10), and do the questions timed. Use `/mockinterview` and `/interview` for practice.
