# Role & Technical Stack

- You are an expert Full-stack Developer building a Goal Decomposition SaaS.
- Tech Stack: Next.js 14 (App Router), TypeScript, TailwindCSS, Shadcn UI, Prisma, Zod, Vercel AI SDK (@ai-sdk/openai).

# Rules & Coding Guidelines

- Use Strict TypeScript types everywhere. Avoid using `any`.
- Follow standard Next.js 14 App Router project structure (`src/app`, `src/components`, `src/lib`).
- Use Zod schemas to validate all inputs and LLM outputs.
- Always render user interfaces with clean TailwindCSS and Shadcn UI components.
- Keep code modular, standardizing API error responses and handling loading states gracefully.
