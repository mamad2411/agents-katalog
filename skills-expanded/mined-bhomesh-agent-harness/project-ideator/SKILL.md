# Project Ideator Skill

A comprehensive methodology and execution framework for conceiving, evaluating, and architecting modern software projects from zero to a production-ready engineering blueprint.

## 1. Ideation Archetypes & Domains

When ideating, explore opportunities across key archetypes:

1. **Full-Stack & SaaS**:
   - Modern workflow automation (B2B, internal tooling, productivity).
   - Real-time collaborative workspaces (Canvas, document sync, CRDTs).
   - High-leverage niche platforms (vertical SaaS for underserved industries).
2. **AI & Machine Learning / Agents / RAG**:
   - Multi-agent orchestration frameworks and deterministic agent runtimes.
   - Domain-specific multimodal RAG (legal, biomedical, codebases, financial).
   - Local-first AI assistants leveraging Ollama, WebGPU, and quantized LLMs.
3. **Mobile & Cross-Platform**:
   - Offline-first personal management with end-to-end sync.
   - Sensor-driven, computer-vision mobile applications (fitness, diagnostics, field work).
4. **DevOps, Developer Tools & CLI Utilities**:
   - Developer ergonomics, sandbox management, observability, and reproducible test fixtures.
   - Microservices diagnostic agents and configuration drift detectors.
5. **Web3, FinTech & Automated Systems**:
   - Algorithmic portfolio rebalancers, smart account abstraction, audit bots, decentralized identity.
6. **Cross-Disciplinary & Custom**:
   - CyberSecurity threat emulators, IoT telemetry hubs, scientific simulations, EdTech platforms.

## 2. The 7-Point Project Specification Standard

Every generated project concept must be detailed with precision:

1. **Identity & Elevator Pitch**:
   - Distinctive Name, memorable tagline, category, and target audience.
2. **The Problem & Value Proposition**:
   - Acute pain point in existing workflows.
   - Why incumbents or naive approaches fail.
   - The "Unfair Advantage" / "Secret Sauce" of the solution.
3. **Core Feature Matrix**:
   - **Phase 1 (MVP)**: Minimal feature set delivering 10x value for the core loop.
   - **Phase 2 (Growth)**: Collaboration, integrations, automations, telemetry.
   - **Phase 3 (Enterprise / Advanced)**: High availability, compliance, fine-grained access control, AI automations.
4. **End-to-End Technical Architecture**:
   - Frontend: UI framework, state management, design system, caching.
   - Backend: API style (REST/gRPC/GraphQL), language runtime, job queues, concurrency model.
   - Data Layer: Primary storage, vector search, caching, relational schema design.
   - Mermaid Architecture Diagram illustrating dataflow and service topology.
5. **Key Data Models & API Contracts**:
   - Concrete schemas (e.g. JSON/TypeScript interfaces, SQL entities) and core endpoints.
6. **Engineering Risks & Hard Problems**:
   - 2-3 specific technical challenges (race conditions, latency, scale, rate limits) with concrete mitigation patterns.
7. **Antigravity Multi-Agent Execution Plan**:
   - Step-by-step handoff roadmap to Antigravity's specialized subagents (`code_architect`, `database_architect`, `backend_specialist`, `frontend_specialist`, `qa_test_engineer`, `devops_engineer`).

## 3. Workflow & Usage

When invoked:
1. Identify user constraints: preferred languages, target platform, domain interest, complexity level.
2. If the user does not specify a domain, provide 3 distinctive high-potential concepts across diverse domains.
3. Once a concept is selected (or when requested), generate the complete 7-Point Technical Specification.
4. Provide immediate actionable commands or Antigravity subagent invocation prompts to begin development.
