# Canva Production Pipeline

## When to use
CANVA:ON tam üretim döngüsü.

## Pipeline
1. `brief-writer` → BRIEFS/
2. `creative-scenarios` → SCENARIOS/
3. `canva-edit-design` → design
4. `canva-brand-check` + `canva-design-feedback`
5. `canva-implement-feedback` (revizyon)
6. `canva-resize-for-social`
7. `canva-export-pipeline`
8. `archive-loop`

## Default
BRIEF-ONLY modda 1–2 adımda dur; Canva adımları atla.
