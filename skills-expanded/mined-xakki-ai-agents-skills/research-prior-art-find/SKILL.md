# Prior-art research

Identify the desired behavior and acceptance boundaries before searching. Discover relevant public or authorized existing implementations through available source interfaces; repository names or search results alone do not prove a capability exists or ships in the selected release.

Inspect authoritative implementation, version, documentation and compatibility evidence. Compare input/output and integration boundaries, deployment requirements, maintenance state, license and real limitations. Distinguish a feature already shipped from a proposal, historical branch, unsupported claim or missing integration seam. Record relevant source links and uncertainty, and recommend reuse, adaptation or new work only to the extent the evidence supports it.

Finding a candidate does not authorize installing, cloning private code, changing dependencies, forking, executing untrusted code or publishing. Follow the user's actual scope and runtime interfaces; never infer product or network access from an example command.
