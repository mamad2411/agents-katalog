# Evidence to actions

Identify the actual documents or meeting notes, versions, requested scope, language and permitted output. Preserve source location such as page, section, timestamp or speaker when available. Distinguish direct commitments, decisions and obligations from suggestions, inferred actions, contradictions and low-confidence transcription or OCR.

Normalize each proposed action with the supported owner, date, status, dependency and source. Mark missing or ambiguous fields rather than inventing owners or deadlines. Reconcile against the authorized existing task source when requested and available; avoid creating duplicates from repeated notes. State incomplete or inaccessible source coverage.

Prepare an actionable reviewable result. Create or change tasks, send follow-up messages or modify external systems only when the user's instruction and applicable interface authorize those specific effects. An extracted action is not itself authorization to execute it.
