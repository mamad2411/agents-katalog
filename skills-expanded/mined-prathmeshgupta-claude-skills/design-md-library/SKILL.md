# DESIGN.md library

~73 curated `DESIGN.md` files under `design-md/<brand>/`. When the user wants a
UI that looks or feels like a specific brand, or wants one consistent design
language, **open the matching `design-md/<brand>/DESIGN.md` and follow it** as
the design spec. Browse `design-md/` for the full brand list (airbnb, apple,
linear.app, notion, stripe, vercel, figma, framer, intercom, mongodb, nike …).

Source: VoltAgent/awesome-design-md.
