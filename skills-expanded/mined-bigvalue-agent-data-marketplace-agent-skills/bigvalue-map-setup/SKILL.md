# 지도 키 설정 안내

현재 산출물에 필요한 지도 설정을 확인하고, 고객이 따라 할 수 있는 발급·적용 방법을 안내한다. 지도 선택이나 서비스 구현 방식을 새로 정하는 스킬은 아니다.

## 안내할 내용 선택

프로젝트와 대화에서 사용하는 지도 기능, 실제 호출 위치, 키 설정 여부, 실행 주소, 키를 읽는 파일·변수를 확인한다. 이미 알 수 있는 내용은 다시 묻지 않고, 안내에 필요한 정보가 없을 때만 확인한다.

| 사용 방식 | 카카오 | 네이버 |
|---|---|---|
| 브라우저에서 지도 표시 | JavaScript 키·도메인 등록 | Client ID·Web 서비스 URL 등록 |
| 서버에서 주소 변환·경로 등 REST API 호출 | REST API 키 | Client ID·Client Secret |

서버가 있다는 이유만으로 서버용 지도 키를 요구하지 않는다. 서버가 빅밸류 데이터만 조회한다면 지도 키는 브라우저용만 필요할 수 있다. 두 방식 모두 사용한다면 각각 필요한 설정을 안내한다.

| 현재 상태 | 안내 방향 |
|---|---|
| 지도 키가 없거나 예시값만 있음 | 호출 방식에 맞는 키·필요한 사용처 설정·입력 위치 안내 |
| 기존 웹 지도 키가 있고 실행 주소가 바뀜 | 기존 앱 설정에서 새 주소 등록 여부 확인, 재발급부터 권하지 않음 |
| 키가 있지만 지도 표시나 API 호출이 실패 | 키 종류·서비스 활성화·사용처 설정과 실제 오류를 확인해 필요한 조치 안내 |
| 사용하는 지도 기능의 정상 동작 확인 | 발급 안내 생략 |
| 외부 지도 링크·이미지 등 키를 요구하지 않는 구성 | 고객에게 불필요한 키 발급 요청 생략 |

키가 없어도 가능한 제작은 이어 가고, 설정이 남으면 완료 답변에 함께 안내한다. 키 누락을 이유로 선택한 지도를 바꾸지 않는다. 사용자가 발급 방법을 먼저 물었다면 그 시점에 안내한다.

## 제공사별 참고문서

필요한 제공사 문서에서 웹 지도 또는 서버 API 부분을 참고한다. 네이티브 앱 SDK는 해당 SDK의 공식 인증 안내를 확인한다.

- 카카오: [키 발급·연결 설정](references/kakao.md)
- 네이버: [키 발급·연결 설정](references/naver.md)

메뉴가 달라졌거나 안내가 맞지 않으면 참고문서의 공식 링크에서 현재 절차를 확인한다. 빅밸류 데이터 API 키와 지도 제공사의 키는 별개다.

## 고객에게 전달할 내용

남은 설정이 있을 때 **로그인 링크 → 필요한 메뉴·키 → 필요한 사용처 설정 → 키를 넣을 파일·변수** 순서로 짧게 안내한다. 해당 프로젝트의 값을 사용하고, 이미 끝난 단계는 줄인다. 형식과 문장 수는 상황에 맞춘다.

- 웹 지도에는 지도를 여는 페이지의 실제 주소를 안내한다. 서버 REST 호출에 웹 도메인 등록을 일괄 요구하지 않고 해당 API의 인증·사용처 설정을 따른다.
- 입력 위치는 실제 SDK·API 호출 코드를 기준으로 정한다. 서버용 비밀값은 서버 환경변수·Secret에 설정하도록 안내한다. 브라우저용 키를 서버 Secret에 저장하는 것만으로 지도에 전달되지는 않는다. 빌드 때 읽는 값이면 변경 후 재빌드가 필요한지도 함께 알린다.
- 카카오 JavaScript 키와 네이버 Client ID는 웹 지도에 사용하며 네이버 Client Secret·카카오 어드민 키를 브라우저 설정에 넣지 않는다. 안내에 실제 키 값을 반복할 필요는 없다.
- 로그인·약관 동의·키 발급은 고객이 제공사에서 진행할 수 있도록 안내한다. 발급 안내 요청을 유료 서비스 신청이나 결제 승인으로 해석하지 않는다.

결과는 제작한 부분과 남은 지도 설정을 구분한다. 키가 입력됐다는 이유만으로 정상 동작을 확정하지 않고, 지도 표시·서버 API 중 실제로 확인한 결과를 적는다.
