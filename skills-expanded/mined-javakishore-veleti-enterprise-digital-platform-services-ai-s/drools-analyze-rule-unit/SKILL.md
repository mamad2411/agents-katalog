# Analyze Rule Unit

1. Identify the rule unit, unit data, data sources, and entry points.
2. Inspect which rules and facts belong to the unit.
3. Evaluate cohesion, domain boundaries, lifecycle, and coupling.
4. Identify shared-state or cross-unit dependencies that weaken isolation.
5. Compare unit boundaries with application/business capabilities.
6. Keep rule units focused on coherent decision domains.

## Output
- Unit Boundary
- Data Sources
- Rule/Fact Cohesion
- Coupling Risks
- Recommended Structure
