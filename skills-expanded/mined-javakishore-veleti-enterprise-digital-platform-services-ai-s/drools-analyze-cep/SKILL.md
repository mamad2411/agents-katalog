# Analyze CEP

1. Identify event types, timestamps, clock mode, entry points, and event ordering assumptions.
2. Inspect temporal operators, windows, expiration, and accumulation logic.
3. Evaluate late, duplicate, or out-of-order event behavior.
4. Trace event-to-activation behavior for representative scenarios.
5. Check memory retention and window size for high-volume streams.
6. Separate event-source problems from rule-engine temporal semantics.

## Output
- Event Model
- Temporal Logic
- Window/Ordering Findings
- Match/Performance Risks
- Recommended Action
