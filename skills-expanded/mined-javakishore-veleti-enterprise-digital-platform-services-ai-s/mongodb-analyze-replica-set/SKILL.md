# Analyze Replica Set

1. Map members, roles, priorities, votes, tags, hidden status, and arbiter usage.
2. Inspect primary availability, member state, replication lag, oplog window, and recent elections.
3. Correlate election events with network, host, resource, or maintenance changes.
4. Evaluate topology against required availability and read/write behavior.
5. Treat election tuning as high impact; do not change production settings without authorization.

## Output
- Replica Set Topology
- Election/Replication Evidence
- Oplog/Lag Findings
- Availability Impact
- Recommended Action
