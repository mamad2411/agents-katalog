# Analyze Spring Boot Integration

1. Trace Spring Data/driver configuration and affected repository/query code.
2. Identify connection string, topology discovery, pool settings, timeouts, read preference, read concern, and write concern.
3. Inspect query shapes and index support.
4. Correlate application exceptions with MongoDB server, replica, sharding, connection, and host evidence.
5. Distinguish application pool/configuration problems from database-server problems.
6. Route generic framework issues to `spring-boot-*` skills.
7. Never expose credentials.

## Output
- Integration Flow
- Driver/Pool Configuration
- Query/Concern Findings
- Runtime Correlation
- Recommended Action
