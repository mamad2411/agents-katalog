# Analyze CloudWatch

1. Resolve cluster, environment, time window, broker/topic/group dimensions, and incident symptoms.
2. Inspect relevant MSK metrics and logs at the configured monitoring level.
3. Correlate broker/capacity, storage, network, partition, and consumer-lag signals.
4. Compare affected brokers/groups with healthy peers.
5. Correlate metric changes with deployments, scaling, configuration, and maintenance events.
6. Distinguish correlation from root-cause evidence.

## Output
- Monitoring Scope
- Key Signals
- Correlated Changes
- Failure Assessment
- Recommended Next Skill
