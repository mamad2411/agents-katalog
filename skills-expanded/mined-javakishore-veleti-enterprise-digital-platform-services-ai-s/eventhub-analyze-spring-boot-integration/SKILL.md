# Analyze Spring Boot Integration

1. Trace the application path from REST/job/domain event to Event Hubs producer or from Event Hubs consumer to business processing.
2. Inspect client lifecycle, configuration, credentials references, batching, retries, consumer groups, checkpointing, and serialization.
3. Check thread/concurrency and graceful-shutdown behavior.
4. Correlate application logs/traces with Event Hubs metrics.
5. Route framework issues to relevant `spring-boot-*` skills.
6. Never expose connection strings or tokens.

## Output
- Integration Flow
- Client Configuration
- Producer/Consumer Findings
- Runtime Correlation
- Recommended Action
