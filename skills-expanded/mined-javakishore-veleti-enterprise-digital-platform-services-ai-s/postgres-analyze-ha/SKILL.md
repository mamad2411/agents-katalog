# Analyze High Availability

1. Identify region, HA mode, primary/standby zones, server state, and application connection behavior.
2. Inspect recent failovers, maintenance, health events, and recovery timing.
3. Correlate failover with application retries, pools, DNS, and transaction behavior.
4. Evaluate whether the configured HA mode meets availability requirements.
5. Distinguish server failover time from application recovery time.
6. Do not initiate production failover without explicit authorization.

## Output
- HA Topology
- Failover Timeline
- Application Recovery
- Availability Findings
- Recommended Action
