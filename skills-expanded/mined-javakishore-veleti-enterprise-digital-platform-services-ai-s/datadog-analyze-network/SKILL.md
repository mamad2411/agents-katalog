# Analyze Network

1. Resolve source, destination, environment, cluster/host, port, and incident window.
2. Inspect available network flow and performance signals.
3. Correlate network behavior with APM dependency spans and infrastructure changes.
4. Distinguish network transport issues from application timeout, service discovery, mesh, or dependency failures.
5. For AKS/Istio workloads, route direct runtime inspection to `aks-analyze-service-networking` or `aks-analyze-istio`.

## Output
- Communication Path
- Network Signals
- APM Correlation
- Failure Layer
- Recommended Action
