# Analyze Security Signals

1. Confirm the relevant Datadog security capability is enabled and the investigation is authorized.
2. Resolve service/resource, environment, time window, and signal type.
3. Inspect the signal and correlated infrastructure, application, identity, or network evidence.
4. Separate confirmed observations from detection-rule interpretation.
5. Avoid exposing secrets, credentials, PII, or exploit details unnecessary for remediation.
6. Route platform remediation to the owning technology skill when appropriate.

## Output
- Security Signal
- Correlated Evidence
- Affected Resources
- Confidence/Unknowns
- Recommended Defensive Action
