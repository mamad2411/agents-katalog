# Analyze Glue Schema Registry

1. Identify registry, schema, format, producer, consumers, and deployed versions.
2. Inspect serialization/deserialization integration and schema references.
3. Evaluate compatibility and rollout sequencing.
4. Correlate schema failures with producer/consumer deployments.
5. Distinguish schema-contract errors from Kafka transport failures.
6. Do not infer missing business semantics.

## Output
- Schema Topology
- Producer/Consumer Versions
- Compatibility Findings
- Failure Evidence
- Recommended Action
