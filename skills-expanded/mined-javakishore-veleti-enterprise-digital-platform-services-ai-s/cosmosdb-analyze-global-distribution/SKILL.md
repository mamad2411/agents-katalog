# Analyze Global Distribution

1. Resolve configured regions, write regions, failover priorities, and consistency model.
2. Inspect regional health, latency, replication, and application preferred-region behavior.
3. For multi-region writes, inspect conflict-resolution configuration and relevant conflict evidence.
4. Evaluate failover readiness and whether application SDK configuration follows region strategy.
5. Distinguish regional platform issues from application routing/configuration problems.
6. Do not initiate failover unless explicitly authorized.

## Output
- Region Topology
- Replication/Failover Findings
- Conflict/Latency Evidence
- DR Readiness
- Recommended Action
