# Analyze LLM Observability

1. Resolve AI application, environment, model/provider, workflow, and time window.
2. Inspect available model/agent/chain spans, latency, errors, token usage, retrieval, and tool-call telemetry.
3. Correlate AI workflow failures with application APM and infrastructure signals.
4. Distinguish model/provider latency, retrieval problems, tool failures, orchestration issues, and application errors.
5. Do not expose prompt content or user data when it contains sensitive information.

## Output
- AI Workflow Path
- Latency/Error Findings
- Token/Usage Signals
- Failure Layer
- Recommended Action
