# Analyze Graph Extension

1. Verify the graph extension is supported for the exact Azure PostgreSQL version/region.
2. Identify graph model, traversal patterns, SQL integration, and data volume.
3. Inspect extension configuration and query plans where available.
4. Evaluate whether PostgreSQL graph extension semantics fit the workload versus a dedicated graph platform.
5. Measure traversal latency using representative graph queries.
6. Treat preview/community extension lifecycle as an architecture dependency.

## Output
- Extension Support
- Graph Model
- Traversal/Performance Findings
- Architecture Fit
- Recommended Action
