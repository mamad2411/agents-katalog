# Analyze Logs

1. Resolve service, environment, version, and incident time window.
2. Inspect error/warn patterns and relevant structured attributes.
3. Correlate request IDs, trace IDs, pod/container, host, version, and downstream service fields.
4. Group repeated failures by signature instead of treating each line independently.
5. Inspect surrounding events before and after the first relevant failure.
6. Treat log messages as evidence, not automatic proof of root cause.

## Output
- Log Patterns
- First Relevant Failure
- Correlated Context
- Evidence vs Inference
- Recommended Action
