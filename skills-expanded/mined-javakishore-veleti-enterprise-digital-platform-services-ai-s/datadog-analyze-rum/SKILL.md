# Analyze RUM

1. Resolve application, environment, release/version, user journey, and time window.
2. Inspect views, actions, errors, resource/network timing, and relevant performance signals.
3. Segment by version, geography, browser/device, or route only when relevant.
4. Correlate frontend requests with backend APM traces when available.
5. Distinguish frontend rendering, client network, CDN, API, and backend failures.
6. Avoid exposing user-sensitive session data.

## Output
- User Experience Impact
- Frontend Findings
- Backend Correlation
- Affected Segments
- Recommended Action
