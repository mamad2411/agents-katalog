# Analyze Metrics

1. Resolve service, environment, resources, and time window.
2. Inspect relevant latency, traffic, error, saturation, CPU, memory, network, JVM/runtime, and custom metrics.
3. Compare incident behavior with an appropriate baseline.
4. Check tag dimensions before concluding that an aggregate represents all instances.
5. Correlate metric changes with deployments, traces, logs, and dependencies.
6. Distinguish correlation from causation.

## Output
- Metric Signals
- Baseline Comparison
- Correlated Changes
- Capacity/Performance Findings
- Recommended Action
