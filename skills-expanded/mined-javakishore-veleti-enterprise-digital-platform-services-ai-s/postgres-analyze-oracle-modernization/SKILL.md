# Analyze Oracle Modernization

1. Inventory Oracle schemas, datatypes, packages, procedures/functions, triggers, sequences, SQL patterns, and dependencies.
2. Classify objects as directly portable, transformable, or requiring redesign.
3. Translate PL/SQL semantics deliberately rather than mechanically.
4. Identify Oracle-specific behaviors with no PostgreSQL equivalent.
5. Define regression/performance tests for converted database logic.
6. Keep schema/code conversion separate from data-movement and cutover planning.

## Output
- Oracle Inventory
- Compatibility Categories
- Conversion Hotspots
- Validation Requirements
- Recommended Migration Plan
