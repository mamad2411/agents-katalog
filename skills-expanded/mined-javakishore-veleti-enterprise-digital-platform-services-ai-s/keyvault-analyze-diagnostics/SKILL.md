# Analyze Diagnostics

1. Inspect diagnostic settings and destinations.
2. Confirm relevant audit/resource logs are enabled for the investigation requirement.
3. Correlate Key Vault access failures with caller identity, operation, network path, and timestamps.
4. Look for repeated denied requests, deletion/recovery actions, or unusual access patterns.
5. Integrate findings with Datadog/SIEM evidence when enterprise telemetry is available.
6. Never reproduce sensitive payloads.

## Output
- Diagnostic Coverage
- Audit Findings
- Correlated Access Events
- Observability Gaps
- Recommended Action
