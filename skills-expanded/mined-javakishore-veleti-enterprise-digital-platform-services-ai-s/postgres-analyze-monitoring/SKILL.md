# Analyze Monitoring

1. Identify available Azure/PostgreSQL metrics, logs, query telemetry, and application traces.
2. Verify coverage for CPU, memory, storage, connections, replication, query latency, locks, and errors.
3. Correlate database signals with application requests and deployments.
4. Inspect alert thresholds and telemetry gaps before declaring health.
5. Route Datadog-specific analysis to `datadog-*` skills.
6. Avoid logging sensitive SQL parameters or credentials.

## Output
- Monitoring Coverage
- Key Signals
- Application Correlation
- Alert/Telemetry Gaps
- Recommended Action
