# Diagnose Rule Failure

1. Read service context, rules, tests, runtime logs, and the calling application path.
2. Classify the failure as compilation, matching, agenda, fact-state, session, integration, or business-logic related.
3. Compare expected facts and outcomes with actual runtime evidence.
4. Trace rule execution when firing behavior is unclear.
5. Check recent rule artifact/version changes.
6. Identify the first confirmed divergence from expected behavior.

## Output
- Failure Scope
- Expected vs Actual
- First Confirmed Divergence
- Supporting Evidence
- Recommended Action
