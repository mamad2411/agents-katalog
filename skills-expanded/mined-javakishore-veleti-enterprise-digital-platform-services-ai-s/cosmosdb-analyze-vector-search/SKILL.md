# Analyze Vector Search

1. Identify embedding model, dimensions, vector field, vector policy, index type, and retrieval pattern.
2. Inspect vector-index configuration and query filters.
3. Evaluate:
   - embedding dimensionality alignment
   - index suitability
   - top-k behavior
   - metadata filtering
   - RU/latency
   - recall/quality tradeoffs
4. Correlate retrieval behavior with RAG requirements.
5. Keep model-quality issues separate from database/index issues.

## Output
- Vector Configuration
- Index/Query Findings
- RU/Latency Evidence
- Retrieval Quality Risks
- Recommended Action
