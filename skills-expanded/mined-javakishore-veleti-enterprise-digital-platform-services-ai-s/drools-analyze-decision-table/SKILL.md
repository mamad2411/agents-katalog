# Analyze Decision Table

1. Identify the decision table source and generated rule semantics.
2. Inspect condition columns, action columns, ranges, wildcards, and row interactions.
3. Detect gaps, overlaps, duplicates, unreachable rows, and implicit precedence.
4. Compare generated behavior with business examples and tests.
5. Preserve stakeholder-readable structure where possible.
6. Do not infer missing business policy.

## Output
- Table Structure
- Coverage/Gaps
- Conflicts/Overlaps
- Generated Rule Risks
- Recommended Changes
