# セグメント経済性の深掘り

複数事業を持つ企業の、セグメント別の稼ぐ力の違いを読み解く。全体の規律は `../../docs/research-discipline.md` を参照。

## 手順

### 1. Identifier解決
`search_companies(query="対象企業名")` で `edinetCode` を確定する。

### 2. セグメントデータ取得
`get_segments(edinet_code=...)` で複数年度のセグメント別売上・利益・利益率・YoYを取得する。「No segment data」が返る場合、その企業は単一セグメント開示であり、これはデータ欠損ではなく仕様（`docs/research-discipline.md` 規律4の「開示なし」の扱い）。単一セグメント企業に対して本スキルを適用する意味は薄いため、`investment-research` スキルの財務トレンド分析に切り替える判断も伝える。

### 3. セグメント構成比の検算
各年度でセグメント別売上構成比の合計を確認する。100%に届かない場合、残差はセグメント間消去・調整額であり、多くの場合ツールから個別開示されない。この点を必ず注記する（`get_segments` のトヨタでの実例: reportable 2セグメントの構成比合計が98.69%だった）。

### 4. セグメント別収益性の比較
売上規模だけでなく営業利益率を必ず併記する。売上構成比が高いセグメントが必ずしも利益率が高いとは限らない（金融セグメントが自動車セグメントの数倍の利益率を持つ、といった構造は珍しくない）。

### 5. 資産配分（取得できる場合）
`get_financials` や `get_facilities` からセグメント対応する設備投資・資産規模の手がかりを探す。ツールがセグメント別の資産配分を直接返さない場合は「取得不可」と明記する。

### 6. 定性情報での補強
`get_text_blocks_structured` や `get_text_blocks` の事業概況セクションが取得できれば、各セグメントの事業内容・主要子会社を補足する。`get_subsidiaries` で各セグメントに対応する主要子会社（連結比率含む）を確認する。

## レポート構成

1. 免責
2. Identifier
3. セグメント構成（直近年度の売上・利益・構成比）
4. セグメント別収益性の時系列（複数年度、営業利益率の推移）
5. 観察（どのセグメントが構造的に高収益か、その仮説はデータから導けるか）
6. データ品質メモ（構成比合計・調整額の扱い、単一セグメント企業の場合はその旨）
7. 使用ツールと呼び出し回数
8. データの鮮度
