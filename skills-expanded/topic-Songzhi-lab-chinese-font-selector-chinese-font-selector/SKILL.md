# 中文字体选配（Chinese Font Selector）

为中文场景做出**合规、好看、能落地**的字体决策。三条铁律：

1. **授权先行**：先确认使用场景的授权安全等级，再谈审美。商用场景默认只用 T0/T1 级字体。
2. **场景决定字体**：小红书卡片和图书内页的选字逻辑完全不同，先定位场景×气质矩阵。
3. **中文为主，英文为辅**：中文占版面 80% 以上时，英文字体必须配合中文的气质和字面率，不能反过来。

## 工作流程

1. **定位场景**：确认是 小红书/社交媒体图、产品册/印刷物料、网页/UI、出版物内页、还是海报标题。
2. **确认授权等级**：商用项目 → 只用 T0（开源）或 T1（厂商承诺免费商用）；涉及转售/嵌入 App/字库产品 → 只用 T0。
3. **查矩阵选字**：在 `references/fonts-database.md` 的场景×气质矩阵中取候选，每个推荐必须标注字体名、授权类型、获取渠道。
4. **配对与排版**：按 `references/pairing-rules.md` 执行中英混排配对和中文排版规则（字号阶梯、行距、标点挤压）。
5. **输出交付格式**：每个方案给出 标题字/正文字/辅助字 三层 + 英文/数字搭配 + 具体字重 + 下载来源 + 授权备注。

## ## 默认立场（所有使用者通用）

- 合规优先：不确定授权的字体一律标注风险，绝不含糊带过
- 中性场景优先推荐字重齐全、授权铁稳的字体（如思源黑体/思源宋体）
- 用户明确表达过个人字体偏好时，以用户偏好为准

## 输出模板

```
【场景】xxx
【方案名】如：人文书卷气 / 现代专业感
- 标题字：字体名 字重 — 授权：OFL/免费商用 — 来源：xxx
- 正文字：字体名 字重 — 授权 — 来源
- 数字/英文搭配：xxx
- 排版要点：字号阶梯、行距、字距建议
- 授权备注：需要注意的限制（如无则写"无特殊限制"）
```

详细字体库与配对规则见 references/ 目录。
