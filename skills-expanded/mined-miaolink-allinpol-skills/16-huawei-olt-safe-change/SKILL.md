# 华为 OLT 安全变更

## 适用范围

适用范围（CLI 命令在下列机型上一致，行动前仍须确认目标型号、release 与补丁）：MA5600 系列（MA5600T、MA5608T、MA5683T、MA5680T）；MA5800 系列（MA5800-X2、MA5800-X7、MA5800-X15）；EA5800 系列（EA5800-X2、EA5800-X7、EA5800-X15）。已观测参考上下文为 MA5800-X7 / MA5800V100R018 / SPH507，不可未经校验直接套用到其他 release。

## 目标

降低任何配置命令的运维风险。

## 何时使用

当任务与本 Skill 描述匹配时使用。先校验 release、patch、CLI 模式与范围。

## 前置条件

显式授权；release 已校验；基线；依赖；测试 ONT；回滚。

## 已确认命令

- [已确认] 变更前后优先使用所有适用的 `display`；[破坏性] 将每条配置命令视为有风险的变更。

## 发现类命令

- [DISCOVERY] 若本 release 未标为 `[已确认]`，用 `?` 校验语法。

## 语法

最低方案：目标、变更前状态、命令、影响、成功准则、中止与回滚。对于 GEM mapping：确认 `binding times`/profile 范围、空闲 mapping-index、VLAN/GEM/service-port 一致、已脱敏的 OLT+BNG 快照、专用回滚，以及事后端到端验证。

## 示例

DBA 之前：列出 ID 与 bind-times；service-port 之前：列出索引与路径。

## 预期结果

每层一次变更，结果可对比，且无范围外改动。

## 已知错误

出现任何意外错误时停止，原样记录，不要尝试变体。

## 诊断

判断失败属于语法、依赖、能力还是状态。

## 依赖

回滚与可靠的管理访问。

## 风险

丢失管理面、多租户业务，或改动 online ONT。`commit` 将变更应用到对象/上下文；全局 `save` 是**可选**持久化，绝非每次变更的固定尾步，也绝不能在无用户明确选择与授权时执行。

默认：`WRITE`（含必要 `commit`）→ 验收 → **结束（不 save）**。仅当用户明确要求落盘时，再走 `30-huawei-olt-config-save`。

## 回滚

必须在执行前写好，并使用已确认语法/发现结果。

## 安全规则

优先 `display`；为每条命令分级；查阅参考与 Binding times；对 `[破坏性]` 要求显式确认；不记录凭据；以本 OLT 的 CLI 为权威。

## 禁止事项

未经确认不要执行破坏性操作；不要改动管理/路由；不要把生产当作试验场。


## 配置保存（PERSIST）

- 对象视图内 commit（如 line/srv profile）只提交该对象，**不是**整机落盘。
- **禁止**在本 Skill 的每次改配/开通/删户后自动执行全局 save。
- 落盘为**用户可选**步骤：变更结束后可询问是否 save；未明确选择则保持运行态不落盘。细节见 30-huawei-olt-config-save。
