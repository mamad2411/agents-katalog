# jintao_node_eye · AI Agent 行为规则

> 本文件控制 AI Agent 的行为模式，目标：**最小化 Token 消耗，最大化精准度**。

---

## 一、首次进入项目

1. **先读 `AI_INDEX.md`** — 一次性理解全项目结构、依赖关系、入口函数。
2. **不遍历目录** — 读完 `AI_INDEX.md` 直接定位到目标文件。
3. **不执行 `ls`, `grep`, `find` 等探索性命令**，除非 `AI_INDEX.md` 中找不到所需信息。

---

## 二、修改代码规则

1. **精准定位** — 用 `AI_INDEX.md` 第六节「文件修改指南」找到目标文件。
2. **最小改动** — 只改目标函数/类，不改无关代码。
3. **Diff 优先** — 输出 diff 而非全量文件，减少 Token 开销。
4. **一次只改一件事** — 不要在一次交互中混合多个不相关的修改。

---

## 三、禁止行为

| 禁止动作 | 原因 | 替代方案 |
|---------|------|---------|
| 执行 `ls -R` 或递归遍历 | 消耗海量 Token 且无意义 | 读 `AI_INDEX.md` |
| 读取不需要的文件 | 浪费上下文窗口 | 只读目标文件 |
| 在对话中输出全量文件 | Token 开销大 | 用 diff 或指明行号 |
| 运行无关测试 | Token 和计算双重浪费 | 只跑相关单测 |
| 修改无关模块 | 引入 bug 风险 | 聚焦目标模块 |

---

## 四、任务流程

```
用户指令
  │
  ▼
① 查 AI_INDEX.md → 找到目标模块/函数/文件
  │
  ▼
② 读目标文件（仅目标函数附近的代码块）
  │
  ▼
③ 修改代码（最小改动原则）
  │
  ▼
④ 验证改动的正确性
  │
  ▼
⑤ 输出结果（diff 格式）
```

---

## 五、Prompt 使用约束

- **系统 Prompt** 在 [`prompts/node1_system_prompt.txt`](prompts/node1_system_prompt.txt)
- **知识库** 在 [`prompts/node1_knowledge_base.txt`](prompts/node1_knowledge_base.txt)
- 修改 Prompt 后不需要重启 ComfyUI，节点会自动重新加载
- 不要给 LLM 传入不相关的上下文

---

## 六、性能目标

- 单次交互 Token 消耗 < 5000 (不含代码执行结果)
- 首次项目理解 Token 消耗 < 2000 (通过 `AI_INDEX.md`)
- 修改一个函数 < 3 轮交互
