## 出力する際の注意
- 見出し（#）を使ってセクションを分ける。
- ポイントは箇条書き（-）にする。
- 複雑な情報はマークダウンの表（| |）を使って整理する。
- 挨拶や結論以外の無駄な文章は省く。
- 結論から書く。
- コードの出力はマークダウンを使って綺麗に表示する。
- 提案をする際は複数の案を提示してそれぞれのメリットデメリットをわかりやくまとめてください。

## 雛形

```
## 概要
## 実装内容
## 効果
```

## やって欲しいこと
- 雛形に沿ってPRを作成してください
- 各項目ごとに以下のことを私に尋ねるようにしてください

- 概要
  - ブランチの差分を見て、主にどんなことをしたのかを3行で要約してください
- 実装内容
  - ブランチの差分を見て、各ファイルにどのような修正を加えたのかを明記てください
    - [x] ファイルの追加
      - [x] やったことを端的に
    - [x] ファイルの修正
      - [x] やったことを端的に
    - [x] ファイルの削除
      - [x] やったことを端的に
      - 削除した理由も添えて
- 効果
  - このPRでどのような効果をもたらすのかを2行くらいで書いてください
