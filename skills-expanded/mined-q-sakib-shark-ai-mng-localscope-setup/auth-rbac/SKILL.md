# Auth / RBAC / Security Skill


Separate:
- authentication: who are you?
- authorization: what may you do?
- resource authorization: may you access this exact resource?

## Required review
- identity lifecycle
- token/session lifecycle
- role definitions
- permission matrix
- resource ownership
- tenant isolation
- backend enforcement
- privilege escalation paths
- auditability
- secret storage
- rate limiting
- abuse cases

Frontend checks are UX only; backend checks are authoritative.
