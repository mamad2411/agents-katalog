# Project Documentation Pack

## Goal

Assemble working documentation that matches the approved direction and agreed service scope.

## Process

1. Check `05_client_approval/APPROVAL_DECISION.md`.
2. Identify the agreed service scope and what is explicitly outside scope.
3. Use `06_design_documentation/DOCUMENTATION_CHECKLIST.md` as scope control.
4. For each sheet, verify connection to measured/CAD plan, not just AI visual.
5. Record disputed or temporary decisions in `00_project_admin/DECISIONS.md`.
6. Before delivery, check consistency of plans: zones, dimensions, materials, planting, lighting.

## Rules

- AI visual is not a source of dimensions.
- Every drawing must have a clear purpose.
- Do not invent default project variants or package contents.
- If a section is not included in the agreed scope, mark this explicitly instead of leaving it empty without explanation.

## Output

- Updated documentation checklist.
- List of completed sheets.
- List of mismatches or missing data.
