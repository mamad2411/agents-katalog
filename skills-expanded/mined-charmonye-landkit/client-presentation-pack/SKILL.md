# Client Presentation Pack

## Goal

Prepare a clear client choice, not a pile of AI images.

## Process

1. Use only options from `04_ai_concepts/SHORTLIST.md`.
2. Group options by concept, not by generation service.
3. For each option, provide a short explanation: idea, strength, compromise.
4. Separately state which elements can be combined across options.
5. Do not promise exact dimensions, cost, or feasibility before they are calculated.
6. Save client materials in `05_client_approval/01_presentation_pack`.

## Format

Recommended structure:

- project title;
- source plan/site;
- 5-7 selected options;
- option comparison;
- questions for the client to choose direction;
- next step after approval.

## Output

- Presentation structure.
- Short captions for options.
- Client questions.
