# 复现验证 · 结果对比

## 目的

论文复现完后，回答核心问题：**这篇论文的结果我能复现出来吗？**

## 三方对比

```
论文声称值 ──┐
              ├──→ 逐项对比 ──→ 偏差矩阵 ──→ 溯源 ──→ 复现结论
理论解析值 ──┘
CST仿真值  ──┘
```

## 验证流程

### 1. 数据对齐

把三个来源的数据按同一指标对齐：
- **S参数**：谐振频率、S11最小值、10dB带宽
- **方向图**：主瓣方向、3dB波束宽度、副瓣电平、前后比
- **增益**：峰值增益、增益-频率曲线
- **效率**：辐射效率
- **阻抗**：输入阻抗实部/虚部

### 2. 计算偏差

```
偏差 = |参考值 - 仿真值| / |参考值| × 100%
```

### 3. 偏差分级

| 等级 | 阈值 | 含义 |
|------|------|------|
| 绿色 | < 5% | 复现成功，与论文一致 |
| 黄色 | 5%~15% | 有差异，需排查具体原因 |
| 红色 | > 15% | 严重不符，建模或论文本身有问题 |

### 4. 偏差溯源

黄色和红色指标逐一排查：
1. 几何尺寸是否与论文一致？
2. 材料参数（εr, tanδ）是否准确？
3. 网格是否收敛？→ 建议细化后再跑一遍
4. 边界条件是否匹配真实物理场景？
5. 端口设置和去嵌是否正确？
6. 论文本身是否美化了数据、漏了关键参数？

### 5. 输出复现结论报告

- `verification_report.json` — 结构化数据
- `verification_report.md` — 人类可读的结论报告
- 明确给出：**哪些能复现、哪些有偏差、偏差原因是什么**

## 对比示例

| 指标 | 论文值 | 理论值 | CST仿真 | 偏差 | 评级 |
|------|--------|--------|---------|------|------|
| 谐振频率 | 28.0 GHz | 28.3 GHz | 28.1 GHz | 0.4% | 绿色 |
| S11最小值 | -25.0 dB | -23.5 dB | -24.2 dB | 3.2% | 绿色 |
| 10dB带宽 | 3.3 GHz | 3.1 GHz | 3.6 GHz | 9.1% | 黄色 |
| 峰值增益 | 7.2 dBi | 6.8 dBi | 7.0 dBi | 2.9% | 绿色 |
| 3dB波束宽度 | 78° | — | 82° | 5.1% | 黄色 |

## 常见偏差原因及对策

| 现象 | 可能原因 | 建议操作 |
|------|---------|---------|
| 谐振频率偏移 | εr 实际值不对/边缘场效应 | 核对材料数据、细化网格 |
| 带宽偏宽 | 损耗算少了 | 检查导体/介质损耗设置 |
| 增益偏低 | 导体损耗/端口失配 | 检查PEC设置、端口匹配 |
| S11形貌差异大 | 几何参数偏差 | 逐尺寸核对、网格细化 |
