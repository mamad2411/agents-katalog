# 电影感提示词

把用户的画面种子放大成清晰、可执行、可验收的电影感成图提示词。所有引用都在本 Skill 内；只按任务需要读取，不依赖作者电脑、私有仓库或外部连接器。

## 输出原则

- 忠于用户的主体、情绪和用途，不用审美炫技改写原意。
- 使用 `references/aesthetic-library/INDEX.md` 选择一组适合的视觉参考，再读取所选卡片。
- 卡片中的创作者姓名只用于内部分析。最终英文提示词必须转译为构图、光线、色彩、镜头、材质等可观察特征；不得写 `in the style of`，不得要求精确模仿仍在世创作者。
- 不虚构器材事实。无法确认时使用通用、物理上自洽的摄影语言。
- 不使用空洞堆词，例如 `8K masterpiece best quality`。

## 1. 理解任务

抓住三件事：

1. 主体与场景；
2. 情绪与视觉重心；
3. 用途：产品 hero 图、人像、电影场景、视频首帧或场景资产。

缺少非关键细节时做一个明确、保守的默认并继续，不连环追问。只有缺失内容会实质改变构图或安全边界时才询问。

## 2. 选择审美方向

先读审美库索引。通常选择：

- 一种世界构建方向，决定场景里有什么、元素密度和叙事情绪；
- 一到两种摄影语言，决定机位、镜头、光型、色彩和介质。

产品静物可以只选摄影方向；宏大场景和视频首帧应同时考虑世界构建与摄影。向用户说明借用了哪些可观察特征，但不要暗示创作者本人参与、授权或背书。

## 3. 生成四层英文提示词

按以下顺序写成一段自然英文，通常 150–250 词：

1. **器材层**：画幅、镜头、焦段、光圈、相机高度和焦点位置。
2. **画面层**：构图、机位、光源动机、方向、色温、影调与颜色关系。
3. **场景元素层**：被允许出现的元素、数量、位置、深度带、物理支撑和留白。
4. **质感层**：皮肤、材质、空气介质、胶片颗粒或数字洁净度，以及必要的缺陷抑制。

### 景深与焦点

- 产品/人像特写：默认浅景深，同时写明焦点，例如瓶盖、标签边缘或眼睛。
- 中景叙事：默认 f/2.8–f/4，主体清楚，背景柔和但可辨。
- 大观图/场景资产：默认 f/8 深焦，前后景都能作为一致性参考。
- 不把“电影感”误写成所有东西都虚化。

### 空间与物理

- 定量描述主体距镜头的距离和画面占比。
- 大型物体必须说明落地、悬挂或承托方式，避免悬浮。
- 多元素场景为每类元素分配专属深度带或画面区域。
- 逆光主体要么接受剪影并写明轮廓光，要么提供有动机的补光。
- 仰拍前景必须有足够高度才能真实入镜。

### 干净度

闭合元素清单，并在适合时加入：

`clean uncluttered frame, no stray objects, no background junk, nothing else in the frame, no text, no watermark, no unintended logos`

若用户确实需要文字或品牌标识，只豁免必要部分，并提醒模型生成文字可能不可靠。

## 4. 固定交付格式

```markdown
## 🎬 提示词（直接复制）
<完整英文提示词>

## 审美方向
- 世界构建：<可观察的场景与叙事特征>
- 画面语言：<可观察的构图、光线、色彩与介质特征>

## 关键决策
- <3–5 条中文说明>

## 变体方向
1. <更克制/更明亮/不同时刻等>
2. <另一种构图或情绪>

## 🔧 后期建议
<只给与当前用途直接相关的去瑕疵、局部修复或超分建议>
```

## 5. 场景资产模式

当用户需要给视频模型使用的多角度场景时：

1. 先生成一张深焦、无人物的锚点大观图；
2. 用户确认锚点后，再生成 3–5 个派生机位；
3. 每张派生提示词声明保持参考图的元素、材质、光线和颜色不变，只修改相机角度；
4. 不声称仅靠文字可以保证一致性，明确要求把锚点图作为参考图上传。

## 6. 图片验收与迭代

用户提供生成图时，读取 `references/quality-checklist.md`，按以下顺序检查：

1. 主体与意图是否正确；
2. 镜头、焦点、景深和空间关系是否自洽；
3. 光源是否有动机，材质是否真实；
4. 是否多出或缺少元素；
5. 是否存在横纹、塑料感、过锐、伪文字、融合边缘或重复纹理。

输出差距清单和一份完整修订提示词。一次只修改导致失败的层，保留已经成功的部分。

## 7. 边界

- 不处理与视觉提示词、成图规划或图片验收无关的任务；此时不应触发本 Skill。
- 不协助伪造身份、冒充创作者授权或声称某位创作者参与了结果。
- 对“完全复制某位仍在世创作者风格”的要求，改为提供不含姓名的高层视觉特征组合。
- 对要求精确复制现有受保护画面、商标或品牌包装的请求，保留用户合法拥有的必要元素，其他部分提供原创替代方案。
- 遵守当前模型和平台的安全、版权与隐私规则；本 Skill 不绕过模型限制。
