# figure-legend｜论文图注的写法与审法

图注是**独立于正文的第二份说明**：读者可能只看图，不看正文。本 skill 只管图注这一层的结构、口径与诚信，不管图怎么画。

## 0. 先判一件事：这张图该不该有这个图注

若一个面板在图注里写不出「它呈现了什么事实」，问题不在图注，在图：回 `paper-figure-audit` 处理该面板的去留，不要用图注替它解释。

## 1. 构件与顺序

固定四段，顺序不可换：

```text
Fig. N | <名词短语式总题>
a  <面板 a 呈现了什么>
b  <面板 b 呈现了什么>
统计口径：n / 离散度定义 / 所用检验 / 多重比较处理
数据来源：<源数据文件名或 Source Data 声明>
```

| 构件 | 规则 |
|---|---|
| 总题 | **只放名词短语**。结论式动词、具体数值、"首次""显著"这类判断都不进总题。 |
| 面板句 | 一个面板一句，写**图中呈现的事实**；面板未提供就不得凭空写（见 §6）。 |
| 统计口径 | n、离散度定义、检验名称、多重比较处理，四件事收在图注里；正文不再另起一处重复交代。 |
| 数据来源 | 一句数据可得性声明；有 Source Data 就点名文件。 |

## 2. 时态分工（英文图注）

- 描述**图中呈现的事实** → 现在时（`shows`, `indicates`, `is`）。
- 描述**样本制备、实验操作、已完成的处理** → 过去时（`were collected`, `was measured`）。
- 两类句子不得混用同一种时态；混用会让读者分不清哪些是图里看到的、哪些是做过的。

## 3. 自足性

图注必须**脱离正文可读**。检验方法：把正文遮住，只看图与图注，能否回答「画了什么、怎么编码、多少样本、关键数值是多少」。

必须进图注的：颜色/形状/线型的映射、样本量、关键数值与单位、组别定义。
不得依赖正文的：任何解释图中编码的句子（`as described in the main text` 这类不算自足）。

## 4. 显示标签（图内文字）

- 普通描述性标签：首字母大写（`Tuned XGBoost`、`+ Causal guidance`）。
- **保留规范拼写**：`XGBoost`、`DeepSeek`、`GPT-5.2`、`RF`、基因/蛋白/数据集/软件名，一律照原样，**不要做自动 title case 或聚类大小写转换**。
- 正文里的句子仍按正常句法大小写；图内标签的大小写规则不得搬进正文。
- 面板字母：小写粗体，置于面板左上；正文引用写作 `Fig. Na`，大小写与图内一致。

## 5. 中文图注

- 构件顺序与英文完全一致：名词短语总题 → 逐面板一句 → 统计四要素 → 数据可得性。
- 时态分工保持一致：图中事实用现在时，制备与操作过程用过去时。
- 专名不翻译：`XGBoost`、`DeepSeek`、`GPT-5.2`、`RF`，以及基因、蛋白、数据集与软件名称保留原拼写。
- 数值与单位精度必须与正文逐一相符；**不得借图注重述之机改口径、换单位或重舍入**。

## 6. 复用与授权（红线）

- 复用已发表图版、或改写他人图版时，逐子图给一句话定性（常用过去时），并附授权/署名串，例如「经 Springer Nature 许可改编自文献 …」。
- **没有授权信息就标 `[待确认: 该图版的授权状态与署名串]`，不得编造 DOI、卷期页、作者或授权声明。**
- 不得为未提供的面板写面板字母、轴题、图例或读数——那是编造。

## 7. 审图注清单

交付前逐条过一遍，任何一条不过就写明「未过：原因」，不要含糊带过：

- [ ] 总题是名词短语，不含数值与结论。
- [ ] 每个面板都有对应描述，且与图中实际编码一致。
- [ ] n、误差/离散度定义、检验、多重比较校正齐备。
- [ ] 颜色/形状映射自足，遮住正文仍可读懂。
- [ ] 关键数值与单位与正文逐一相符，未改口径。
- [ ] 显示标签保留专名拼写。
- [ ] 数据可得性声明存在。
- [ ] 复用材料附授权串；没有则已标 `[待确认]`。
- [ ] 面板字母与正文引用的大小写、编号一致。

## 8. 输出契约

- **写**：给出可直接粘贴的图注正文，再列 2–4 条要点说明为什么这么写（总题为何用这个名词短语、数字为何保留或删除、统计口径从哪来）。
- **审**：按 §7 逐条给判定，问题定位到具体面板或具体句子，并给出改法。**不得只给结论「写得还行」。**
- 缺信息一律写 `[待确认: 具体问题]`，不要用看起来合理的值填空。

## 9. 边界与转介

| 遇到 | 转去 |
|---|---|
| 图里还有句子、结论、指标卡、装饰 | `paper-figure-audit` |
| 图里的字号、尺寸、面板对齐、导出格式 | 目标期刊说明，或本机图表审计工具 |
| 统计方法选得对不对、图型选得对不对 | 不属于本 skill；交统计核查或同行评审 |
| 图注之外的正文润色、章节起草 | `academic-writing-suite` |

本 skill 只管图注**能说什么、该怎么组织**，不管图怎么画，也不替作者判断统计是否成立。
