# Recall from Mnemo's memory

1. Call the `recall` MCP tool with a clear natural-language query
   (e.g. "who owns the Falcon payment module").
2. Answer ONLY from the returned facts. Cite the source/time each fact carries.
3. If `recall` returns nothing, say memory has nothing on that yet — do not guess.
