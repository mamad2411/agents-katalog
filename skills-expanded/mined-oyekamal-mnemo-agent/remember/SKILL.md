# Remember into Mnemo's memory

1. Call the `remember` MCP tool with a clear declarative statement
   (e.g. "Zara owns the Falcon payment module; it depends on the Ledger service").
2. If the fact is time-specific, pass `when` as an ISO date so "as-of" queries work.
3. Confirm briefly what you stored.
