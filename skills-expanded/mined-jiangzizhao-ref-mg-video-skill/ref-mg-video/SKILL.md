# 参考图驱动的 MG 动画视频（先定风格 → 出图 → 再动画）

用户的固定诉求：**每条视频内容不同，风格靠她给的参考图现定**。所以这条流程的灵魂是——
**看懂参考图 → 把风格钉死成一份「风格锁」→ 所有镜头都套同一把锁出图 → 再让图动起来。**

> 跟 `video-design` 的区别：那个是纯代码画几何扁平图（干净但简陋）；**这个是 AI 出插画 + 代码合成动画**，质感接近抖音「自然奇境科普季」那类精致 MG。跟 `xhs-imagegen` 的区别：那个只出一张封面；这个出**一整套风格统一的镜头图**并做成视频。

## 铁律（每条开工前过一遍）
- **文字不进 AI 图。** ChatGPT 画中文必糊/错字。**插画只画画面，一个字都别让 AI 写**；所有标题/数据/字幕一律最后在 Remotion 里叠（矢量清晰、可改、可动）。这是比"整张交给 AI"高级得多的做法。
- **风格锁一次定死，全片不改。** 配色/线条/质感/光影/构图/镜头/情绪，写成一段固定「风格头」，每个镜头提示词都以它开头，只换主体。飘一张就整片不像一个人画的。
- **动效服务阅读、克制、有节奏**（同 video-design 头号原则）：每屏一个焦点、文字少、一套配色、逐个入场、留安全区、首尾有记忆点。
- **🔴 MG 动画＝元素单独生成透明图再动（最高铁律，严格执行）。** 凡是画面里**会独立运动的东西**（主体、每个配角、每一层、每个飞入的小件），都必须是**独立的透明 PNG 元素**，且**优先在 ChatGPT 里单独重新生成**（`ONLY this single object on a FULLY TRANSPARENT background, PNG alpha, no background, no scene, torn white paper collage edge, CMYK halftone`）——干净、边好、带撕纸边。**⚠️ 生成这些元素必须走图生图（`--ref` 全景/锚图），不能只靠文字新造。** 全景图出好后，每个要动的元素都 `--ref` 那张全景图（或已确定的锚图）来出透明单体版——这样抠出来的元素才跟全景图里画的**长得一模一样**（同一个主体，不是"风格像但细节对不上"的另一个新造物），拼回场景才不会跳戏。纯文字新写只用来出**全景图里根本没有、要新增的元素**。**三条禁令**：① **禁止用 CSS/代码画个假元素来充当要动的东西**（血泪：镜6 的 HBM 层片当初 CSS 画方块——不是 MG，返工）；② **禁止让"烧死在背景图里"的元素假装动**（没抠出来根本动不了，顶多整张 Ken Burns）；③ **别再用 PIL 从全景图里裁元素当素材**（血泪：镜12 用 PIL 裁芯片/报纸——边糙、带残底、糊，用户明确否掉「你扣不是让你扣，应该在 chatgpt 重新生成」）。PIL 只用于给已是干净素材的图补个撕纸边/羽化，**不用于从合成大图里抠主体**。判据：开工做某镜前先列「这镜哪些元素要动」→ 每一个都先在 ChatGPT 单独生成透明 PNG，缺一个就先去生，别硬做。

## 工作流

### 第 1 步 · 开场先问，收两样东西
**skill 一触发，先问用户：「这条视频风格定好了吗？定好的话把参考图发我。」** 按她的回答分两种：
1. **风格已定** → 她会直接甩一张（或几张）参考图。收下即可，不用再追问。
2. **风格没定** → 引导她：可以截一段她喜欢的视频画面，或形容个大概方向，再帮她一起定。
同时收第二样：**文案 / 选题**——这条讲什么、几个点、什么用途（科普？功能？观点？）。
> 缺哪样就只问哪样，别堆问题。文案长就替她提炼成「每屏一句」，长句留口播。

### 第 2 步 · 分析参考图 → 写「风格锁」（这步最关键）
把参考图**读进来**(Read 工具看图)，逐项拆解、用中文写成一份可复用的风格头。至少覆盖：
- **配色**：主色/辅色/强调色 + 底色，给出 hex（自己从图里估），并说清哪个是点缀。
- **线条/描边**：有没有黑描边？粗细？圆角还是硬边？
- **质感**：扁平纯色 / 纸质噪点 / 渐变体积感 / 手绘笔触 / 3D 微立体？
- **光影**：平涂无光 / 柔和投影 / 高光体积？
- **构图与主体**：主体大小占比、居中还是偏置、留白多少、视角（正面/等距 45°/俯视）。
- **情绪气质**：可爱 / 硬核 / 高级 / 童趣 / 复古…
把这份写下来给用户看一眼「我理解的风格对不对」，再往下走。**这份就是后面每张图提示词的开头。**

### 第 3 步 · 分镜 + 每镜头出图提示词
- 按文案拆 4~7 个镜头（开场 hook → 分点 → 收尾），每镜头一句话主旨。
- 每个镜头写一条**中文出图提示词**，结构固定：
  ```
  <风格锁那一整段>。
  画面主体: <这一镜要画的东西/场景/概念, 具体到构图>。
  竖版 9:16 构图, 主体<居中/偏上>, 四周留白便于叠字。
  纯画面, 不要任何文字/logo/水印。
  ```
- **关键一致性技巧**：
  1. 先出**第 1 张当风格锚**（anchor），最能代表这套风格的那镜。
  2. 后面每张都 `--ref 锚图`，把风格钉在锚上；提示词里风格头一字不改，只换主体。
  3. 需要「同一角色/同一物件」反复出现，就把它的外观写进风格锁，并始终 --ref。

### 第 4 步 · 出图（Claude 直接执行，确认「开跑」后）
**这是一等步骤 —— Claude 自己调 `gen-shot.sh` 出图、Read 回来看、不行就重跑，闭环在 Claude 侧。** 顺序永远是「先把锚出满意 → 再用锚铺其余」：

```bash
D=~/Desktop/mg-<主题>-$(date +%Y%m%d)   # 这条视频的镜头图放一起

# ① 出风格锚：直接 --ref 用户给的参考图，把那套质感迁到我们的主体上
~/.claude/skills/ref-mg-video/gen-shot.sh "<风格头 + 镜1主体>" 01锚 --ref <用户参考图> --dir "$D"

# ② 锚满意后，其余每镜 --ref 我们自己的锚锁一致；每镜只换主体/配角，风格头一字不改
~/.claude/skills/ref-mg-video/gen-shot.sh "<风格头 + 镜2主体>" 02 --ref "$D"/01锚-*.png --dir "$D"
~/.claude/skills/ref-mg-video/gen-shot.sh "<风格头 + 镜3主体>" 03 --ref "$D"/01锚-*.png --dir "$D"
```

执行循环（每张都走一遍）：
1. **跑 gen-shot.sh** → 自动存 PNG 到 `$D`。
2. **Read 那张 PNG** 贴给用户看。
3. **不满意就重跑**（ChatGPT 每次不同）或微调「主体/配角」描述——**风格头别动**。锚要反复出到满意为止，它定了后面才稳。
4. 若参考图把不该有的元素（如钱/手）串进这镜 → 这张**撤掉 `--ref`**、靠文字风格头保一致；或换 `--ref` 一张更干净的锚。

> ⚠️ 每镜画面**按场景变**（主体/构图/环绕元素各不同），锁死的只有「质感 DNA」（配色/网点/版画质感/气质）。别把锚的具体内容（钱、手、某道具）无脑复制到每一镜。

> **🔁 出图这一整段（全景 + 每镜要动的透明元素）都可以批量/loop 跑**（分镜多、每镜的透明元素也多时，一张张手动等太慢）：锚定好之后，把队列列全——① 剩下每镜的全景图 ② 每张全景图确定后，该镜所有要动的元素（各自 `--ref` 那张全景图出透明单体版，见上面铁律）——一起用 `/loop` 或后台批量任务依次调 `gen-shot.sh` 跑完，再一次性 Read 全部结果（全景 + 各元素）给用户审。**但动画怎么动（第 5 步）不能 loop、必须人工**——图全部出完给用户看，问清楚「这镜哪些元素动、怎么动」，再动手写 Remotion 动画。别让 loop 一路跑到出成片，动效脑补出来的十有八九要返工（血泪见下面的实战坑）。

### 第 5 步 · 导进 Remotion 做合成动画（A 方案·默认）
在 `~/skill-explainer/` 新建一个 Composition（1080×1920 / 30fps）。把 PNG 放进 `public/`，用 `staticFile()` 引。**让静图"动"的手法**（全部 `useCurrentFrame`，禁 CSS 动画）：
- **镜头运动 Ken Burns**：整张缓慢推进/平移（`scale 1→1.08`、`translate`），静图立刻有呼吸感。
- **视差分层**：一张图里若主体和背景想分开动，出图时**把主体单独出一张干净背景的图**，Remotion 里前后景不同速度位移。
- **入场/转场**：镜头间用叠化/线扫/缩放模糊；元素逐个 spring 淡入上移。
- **叠信息层**：大标题（遮罩升起）、关键词高亮、数字滚动、清单勾选、底部进度条——**这些都在代码里加**，矢量清晰。
- 配色取自「风格锁」的 hex，字体用系统字体（苹方/宋体，见 render-setup 第 3 节，禁 google-fonts）。

### 第 5 步替代 · 真实运动（B 方案·可选，要 key）
想要冒烟/流水/镜头真动那种"活过来"的感觉：把镜头图当关键帧，走 `ai-manju` 的 **Seedance 图生视频**（需开火山方舟 key，用户目前**没开**）。文字仍最后在 Remotion/剪辑里叠。默认先做 A，她要 B 再说。

### 第 6 步 · 自检 → 渲染 → 交付 → 下一步
- **抽帧自检**（render-setup 第 4 节）：查中文没方块、没溢出、配色统一、安全区够、图片没拉伸变形。
- 渲染（用系统 Playwright chrome，`--browser-executable`，见 render-setup 第 2 节），`cp` 到桌面中文名并 `open`。
- 交付说清：比例/时长/风格；**永远给下一步**：①换风格(给新参考图) ②改某镜/重出某张图 ③加配音(ElevenLabs key)/背景音乐 ④升级成 B 真运动 ⑤这条定 → 沉淀成她的固定模板。

## 生图实战坑（血泪，务必读）

- **反推提示词定风格最准**：让用户把参考图丢给 ChatGPT「反推出一段生图提示词」，把这段（尤其 texture / 配色 / style keywords / negative 那几段）当**风格锁**，比你肉眼描述稳得多。英文提示词对「编辑拼贴 / 半调网点」这类风格更稳。
- **⚠️ ChatGPT 会自作主张出中文 clickbait 海报**：提示词里只要有 `magazine cover / news / poster / cover / 封面 / storytelling / high-impact` 这类词，再加上一个中文题材（内存涨价、地沟油…），ChatGPT 大概率**无视你的 no-text，生成一张塞满中文大字、真人脸、+1200元 的抖音海报**。解法：① 删掉一切 cover/news/poster/storytelling 措辞 ② 开头就写 `A wordless editorial paper-collage illustration. This is NOT a poster and NOT a magazine cover.` ③ 结尾 negative 里逐条列 `no text, no letters, no chinese characters, no captions, no numbers, no large realistic human face`。清爽单主体（一个瓶子/一根内存条）比抽象题材更容易出干净图。
- **一张图出全景 + 每个要动元素的透明图**：本流程的标准出法——先出一张**全景合成图**（当风格定盘 + 可当静态海报），再按需出**各「要动元素」的透明底 PNG**（背景板 + 主体 + 各配角），供 Remotion 分层绑动画。透明底直接在提示词里要 `transparent background, PNG alpha, 只有这一个主体`（实测 ChatGPT web 后端能出真 alpha，占比 40-80% 透明，不用抠图工具）。

## 动画落地经验（2.5D 分层，实战确认）

- **流程铁律**：**先出分镜图（全景 + 各要动元素的透明层）给用户审 → 用户说「每个元素怎么动」→ 再做视频**。别自己脑补动法就渲，返工大。
- **定格逐帧手感 = 灵魂**：参考视频那种是「捏黏土/剪纸摆拍」的逐帧感，不是丝滑插值。做法：① `const sf = Math.floor(frame/STEP)*STEP`（STEP=3 约 on-threes / STEP=4 更顿），**所有插值都用 sf 驱动** → 动作一顿一顿；② 每层加 **boiling**（定格伪随机微位移/旋转，每步都变）→ 边缘沸腾、像手抖摆拍。丝滑=不像，定格+沸腾=像。
- **编排要有节拍，别一进场就晃**：典型 = 主体先飞入 → 配角一点点靠近（慢移入，不是立刻到位）→ 到位才互动（拉扯/角力）→ 收尾（吞没等）。用不同时间窗 + 延后启动的振幅错开。
- **「越来越多 / 淹没」= 一张张 sprite 飞入累积**，不是缩放一个大图、也不是整片遮罩漫。几十个 sprite 错开入场（远处/角落先落、中心后埋，按离中心距离排序），从画面外朝落点飞入 + 定格。sprite 必须**和整体同风格**（同一套出图提示词出的透明单元素）。用户明确否掉了「一整片漫」和「变大」两种做法。
- **透明单元素直接出**：ChatGPT web 后端能出真 alpha（占比 40-80%），提示词里写 `transparent background, PNG alpha, ONLY this single subject, torn white paper cutout edge`；背景板则出「中间留空、四周有配角」的不透明图。
- **⚠️ 生图卡了别硬等，能抠就抠**：ChatGPT 网页通道不稳，提交那步经常卡死（日志出现 `composer did not clear — the prompt may not have sent`），然后干等 300 秒超时，纯浪费时间。凡是「已有全景图里有的元素」（比如淹没用的芯片/钞票 sprite、某个配角），**别再赌生图——直接用 PIL 从全景图里裁一块**（纹理/配色/半调跟背景 100% 一致，风格反而更统一），再用代码补「撕纸白毛边」。撕边做法：取矩形→算到边缘距离 `d`→两层高斯模糊噪声 `noise`→`keep = d/band > noise` 得参差撕口→`inner.MaxFilter(23)` 向外膨胀出 ~11px 白纸边→合成 `透明底 + 白纸 + 纹理裁到inner`，alpha 取白纸 mask。见 `ShotFoundation.tsx` 的 `mem_chip.png` 生成脚本。

## 一致性排错（出图老飘怎么办）
1. 风格头是不是每张**一字不差**？改了就飘。
2. 有没有 `--ref` 锚图？没锚必飘。
3. 锚图本身够不够「风格标准」？不行先把锚重出好。
4. 主体描述别夹带风格词打架（比如锚是扁平，某张又写了"写实光影"）。
5. 中文还是被 AI 画进去了？→ 提示词补「纯画面，不要任何文字」，文字全交给 Remotion。
