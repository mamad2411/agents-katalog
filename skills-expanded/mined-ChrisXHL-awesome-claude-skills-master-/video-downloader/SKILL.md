# 视频下载器

此技能直接将 YouTube 和其他平台的视频下载到您的计算机。

## 何时使用此技能

- 下载 YouTube 视频以供离线观看
- 保存教育内容以供参考
- 归档重要视频
- 获取视频文件以进行编辑或再利用
- 从平台下载您自己的内容
- 保存会议演讲或网络研讨会

## 此技能做什么

1. **下载视频**: 从 YouTube 和其他平台获取视频
2. **质量选择**: 允许您选择分辨率 (480p, 720p, 1080p, 4K)
3. **格式选项**: 下载各种格式 (MP4, WebM, 仅音频)
4. **批量下载**: 可以下载多个视频或播放列表
5. **元数据保留**: 保存标题、描述和缩略图

## 如何使用

### 基本下载

```
Download this YouTube video: https://youtube.com/watch?v=...
```

```
Download this video in 1080p quality
```

### 仅音频

```
Download the audio from this YouTube video as MP3
```

### 播放列表下载

```

```

### 批量下载

```
Download these 5 YouTube videos:
1. [URL]
2. [URL]
...
```

## 重要说明

⚠️ **版权与合理使用**
- 仅下载您有权下载的视频
- 尊重版权法和平台服务条款
- 仅用于个人、教育或合理使用目的
- 不要重新分发受版权保护的内容

## 提示

- 如果需要较小的文件大小，请指定质量 (720p vs 1080p)
- 对播客或音乐使用仅音频以节省空间
- 下载到专用文件夹以保持井井有条
- 在慢速连接上下载之前检查文件大小

## 常见用例

- **教育**: 保存教程和课程以供离线学习
- **研究**: 归档视频以供参考
- **内容创作**: 从平台下载您自己的内容
- **备份**: 在重要视频被删除之前保存它们
- **离线观看**: 无法上网时观看视频
