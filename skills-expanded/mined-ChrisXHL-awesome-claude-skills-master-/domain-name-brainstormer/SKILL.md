# 域名头脑风暴器

此技能通过生成创意选项并检查实际可注册的内容，帮助您为项目找到完美的域名。

## 何时使用此技能

- 启动新项目或公司
- 发布产品或服务
- 创建个人品牌或投资组合网站
- 重塑现有项目品牌
- 为副业项目注册域名
- 当您的首选被占用时寻找可用的替代方案

## 此技能做什么

1. **了解您的项目**: 分析您正在构建的内容以及目标对象
2. **生成创意名称**: 创建相关的、令人难忘的域名选项
3. **检查可用性**: 验证哪些域名在多个顶级域名 (TLD) 中实际可用
4. **多个扩展名**: 建议 .com, .io, .dev, .ai, .app 等
5. **提供替代方案**: 如果首选被占用，提供变体
6. **品牌见解**: 解释为什么某些名称效果很好

## 域名命名技巧

### 什么构成好域名

✓ **简短**: 15 个字符以下最理想
✓ **令人难忘**: 易于回忆和拼写
✓ **可发音**: 可以在对话中说出来
✓ **描述性**: 暗示您做什么
✓ **品牌化**: 足够独特以脱颖而出
✓ **无连字符**: 更易于口头分享

### TLD 指南

- **.com**: 通用，受信任，非常适合企业
- **.io**: 科技初创公司，开发人员工具
- **.dev**: 聚焦开发人员的产品
- **.ai**: AI/ML 产品
- **.app**: 移动或 Web 应用程序
- **.co**: .com 的替代方案
- **.xyz**: 现代，创意项目
- **.design**: 创意/设计机构
- **.tech**: 技术公司

## 示例工作流

### 初创公司发布
1. 描述您的初创公司想法
2. 获取跨 TLD 的 10-15 个域名建议
3. 审查可用性和定价
4. 挑选前 3 个最爱
5. 立即注册

### 个人品牌
1. 分享您的姓名和职业
2. 获取变体 (firstname.com, firstnamelastname.dev 等)
3. 同时检查社交媒体句柄可用性
4. 跨平台注册一致的品牌

### 产品命名
1. 描述产品和目标市场
2. 获取创意、品牌化的名称
3. 检查商标冲突
4. 验证域名和社交媒体可用性
5. 与目标受众测试名称

## 成功秘诀

1. **行动迅速**: 好域名很快被抢走
2. **注册变体**: 获取 .com 和 .io 以保护品牌
3. **避免数字**: 难以口头交流
4. **检查社交媒体**: 确保 @username 也可用
5. **大声说出来**: 测试是否易于发音
6. **检查商标**: 确保没有法律冲突
7. **着眼长远**: 5 年后还有意义吗？

## 定价背景

当建议域名时，我会注明：
- 标准域名: ~$10-15/年
- 溢价 TLD (.io, .ai): ~$30-50/年
- 已占用域名: 如果列出则为市场价格
- 溢价域名: 数百到数千美元
