# Mochi — Project Instructions

## What is Mochi?
End-to-end design system generator. User gives prompt + options → gets complete coded design system + Figma import + documentation page.

## Long-term Vision
Phase 1: Design System Generator (current)
Phase 2: Frontend UI Generator (from design system)
Phase 3: Backend Generator (full-stack)

## Tech Stack
- Next.js (App Router)
- Claude Code server for AI generation
- Vercel for hosting
- Figma REST API for Figma integration

## Repo
- GitHub: github.com/haider0072/mochi (private)
- Default branch: main

- Mascot: Cute mochi character
- Branding: Soft pastels, rounded shapes, playful typography
