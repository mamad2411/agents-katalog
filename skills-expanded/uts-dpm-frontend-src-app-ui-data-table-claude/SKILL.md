# Data Table Component

Reusable paginated table component with sorting and row selection.

## Index

| File                        | Contents (WHAT)                                       | Read When (WHEN)                                |
| --------------------------- | ----------------------------------------------------- | ----------------------------------------------- |
| `data-table.component.ts`   | Table logic, pagination signals, row hover state      | Modifying table behavior, adding table features |
| `data-table.component.html` | Table template, pagination controls with icon buttons | Changing table layout, fixing UI issues         |
| `data-table.types.ts`       | Column configuration interface                        | Adding columns, configuring table display       |
