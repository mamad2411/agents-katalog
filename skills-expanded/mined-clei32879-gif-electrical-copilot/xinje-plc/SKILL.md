# 信捷（XINJE）PLC 编程 Skill

面向 XD / XC 系列 + XDPPro 编程环境（用户桌面「信捷PLC编程工具软件」）。信捷指令体系与三菱 FX 系列相近（XC 类三菱 FX 风格，XD 为扩展指令集），是国产化替换常见的机型。

## 一、机型与软元件速记

### XC 系列（经济型，类似三菱 FX 风格）
- 输入 X0 起（按 8 进制编址：X0~X7、X10~X17…）、输出 Y0 起（8 进制）。
- 软元件：M（中间继电器）、S（状态）、T（定时器）、C（计数器）、D（数据寄存器）、特殊软元件 M8000 起 / D8000 起（系统状态）。

### XD 系列（主推，扩展指令多）
- 编址与软元件大体同 XC，XD 增加更丰富的应用指令、高速输入输出、通信指令、PID、定位指令。
- 高速计数 HSC、高速脉冲输出（PLSY/PLSR、定位指令 DRVA/DRVI）、PWM。
- 机型后缀含义：如 XD3-24T-E：24 点、T=晶体管输出（可发脉冲）、R=继电器输出；E=以太网机型。

## 二、XDPPro 环境要点

- 新建工程选机型 → 主程序（梯形图/指令表/ST）、子程序、中断程序、初始化。
- 变量表：可命名符号（如 `M启动`、`D设定温度`），程序里用符号更可维护。
- 在线监控：运行监控、强制、时序图/软元件监控表；下载前先编译。
- 通信设置：编程口（USB/串口）、以太网机型用 IP 连接。

## 三、常用指令速查

### 基本指令
| 指令 | 含义 |
|---|---|
| LD / LDI | 常开 / 常闭取母线 |
| OUT / OUTI | 输出线圈（OUTI 立即刷新） |
| AND / ANI / OR / ORI | 串联常开/常闭、并联常开/常闭 |
| ANB / ORB | 块串联 / 块并联 |
| SET / RST | 置位 / 复位 |
| PLS / PLF | 上升沿 / 下降沿脉冲 |
| MPS / MRD / MPP | 进栈 / 读栈 / 出栈 |
| NOP / END | 空操作 / 程序结束 |

### 定时/计数
- T0（100ms）、T200 段（10ms）等按机型区分；K 为设定值（十进制常数）。
- C0 普通计数器、C235 起高速计数器（按机型）。

### 应用指令（功能指令，用 FNC 编号）
- MOV（传送）、CMP（比较）、ZCP（区间比较）、ADD/SUB/MUL/DIV（四则）、INC/DEC。
- BCD/BIN 转换、SEG/7 段译码、编码 ENCO/DECO。
- PID 指令：定时采样做 PID 控制（温度/压力）。
- 数据寄存器成批：BMOV、FMOV。

### 高速与定位
- PLSY：定速脉冲输出（频率+个数）；PLSR：加减速脉冲。
- DRVA/DRVI：绝对/增量定位（配伺服/步进，需确定脉冲方向+脉冲端）。
- 高速计数：HSCS/HSCR/HSCZ（比较置位/复位/中断）。
- 高速输出指令按 XD 机型支持（Y0/Y1 高速端）。

### 通信指令
- Modbus：XD 支持 Modbus RTU（485）与 TCP（E 机型）；用特殊寄存器配置站号/波特率，或用指令收发。
- 自由口：串口用 SEND/RCV 或 MOV 收发自定义协议（需查具体机型指令表）。
- 与威纶通 HMI：EBPro 选 XINJE XD/XC 或 Modbus；与伺服（信捷/禾川）常用脉冲 + 方向，或 Modbus/总线。

## 四、典型程序结构建议

1. 开机初始化（清状态、装载参数、上电默认）。
2. 输入采集/滤波（按钮去抖：用定时器或边沿+延时）。
3. 工艺主逻辑（状态机/顺序控制，见 plc-skill 模板）。
4. 输出/动作执行（带互锁：正反转互锁、急停优先）。
5. 报警与故障（保持+复位、灯/蜂鸣器输出、上报 HMI）。
6. 通信与数据交换（HMI 地址、伺服/变频 Modbus 读写）。

## 五、调试与排障

- 程序不运行：查 RUN/STOP 状态、编程口是否占用、PLC 是否报警（ERR 灯）。
- 输出不动：查输出条件、输出点是否被强制/占用、公共端电源、COM 接线。
- 脉冲/伺服不动：查脉冲端接线（Y0/Y1）、方向信号、伺服使能、电子齿轮/脉冲模式设置。
- 通信不通：站号、波特率、校验位、线序（485 A/B 反接常见）、HMI/上位机协议选择。
- 用 XDPPro 软元件监控表/时序图逐点跟踪。

## 安全边界

- 涉及设备动作的程序改动，先离线仿真/空载试机；确保急停/门锁硬回路独立于程序。
- 高速、定位、伺服相关参数（电子齿轮、加减速）改动会直接影响运动，改动前备份参数。
