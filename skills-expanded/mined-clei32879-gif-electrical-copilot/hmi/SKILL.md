# 触摸屏 / HMI 设计 Skill

主攻威纶通 EBPro（EasyBuilder Pro），并覆盖通用 HMI 设计方法。与 PLC 程序、伺服、机器视觉项目配套。

## 一、通用 HMI 设计流程

1. **需求梳理**：画面清单（主画面、手动、自动、参数、报警、配方、诊断）、操作权限（操作员/工程师/管理员）、报警清单。
2. **地址规划**：与 PLC 程序一一对应的地址表（位元件：启动/停止/运行/报警；字元件：设定值/反馈值/计数/配方参数）。地址表是 HMI 与 PLC 的"合同"，先定表再开发。
3. **画面开发**：按工艺分区，配色统一，字号最小可读（一般 ≥ 12px 宋体/雅黑），按钮 ≥ 40x40 便于触控。
4. **安全与防误操作**：关键操作二次确认（窗口确认/长按）、权限分级、互锁在 PLC 侧兜底（HMI 只是界面，最终安全由 PLC 程序保证）。
5. **模拟与下载**：EBPro 离线模拟 → 在线模拟（连 PLC）→ 下载到触摸屏（USB/以太网）。

## 二、威纶通 EBPro 要点

### 新建工程
- 新建 → 选择机型（如 MT8071iE / TK6071iP / eMT 系列）→ 设置分辨率、颜色。
- 系统参数 → 新增设备（PLC 型号选择：信捷 XD/XC、三菱 FX、Modbus RTU/TCP 等）→ 设置通信（COM 口、波特率、站号）。

### 常用对象
| 对象 | 用途 |
|---|---|
| 位状态指示灯 | 显示开关/运行/报警状态（按地址位） |
| 位状态切换开关 | 置位/复位/切换（直接写位） |
| 多状态指示灯/切换开关 | 按数值显示多状态（如 0=停止/1=运行/2=故障） |
| 数值显示/数值输入 | 字地址显示与输入（含上下限、缩放、单位） |
| 文字/图形 | 静态标注、动画 |
| 配方 | 多组参数管理、批量下载到 PLC |
| 报警显示/事件登录 | 报警记录、历史查询 |
| 趋势图/历史数据 | 曲线、数据记录（SD 卡/内部） |
| 窗口/弹出窗口 | 二次确认、参数页弹出 |
| 宏指令 | 复杂逻辑、数据打包、自定义通信 |

### 地址映射示例（信捷 XD 系列）
- PLC 位地址在 EBPro 中通常用 `M0`、`X0`（输入）、`Y0`（输出）、`S0`（状态）等；字地址 `D0`、`TD0`（定时器）等。
- 与 PLC 程序保持同一张地址表，修改 PLC 时同步更新 HMI 地址。

### 通信设置常见
- 信捷 PLC：EBPro 选 XINJE XD/XC（或通过 Modbus RTU/TCP）；COM 口、波特率 9600/19200、数据位/停止位/校验要与 PLC 一致。
- 三菱 FX：FX 编程口或 FX3U 串口协议；FX5U 可用以太网（SLMP/MC 协议）。
- Modbus：RTU 485 或 TCP，站号唯一，功能码映射（0x=线圈、1x=输入、3x/4x=寄存器）。

### 宏指令（EBPro）
- 宏在工程树"宏"中编辑，支持 If/Then/Else、For、GetData/SetData 读写 PLC、窗口切换 MacroCommand 等。
- 用于：数据转换、自定义协议打包、条件逻辑、开机初始化。

## 三、其他 HMI 平台差异（要点）

- **昆仑通态 MCGS**：组态软件 MCGS 嵌入版/通用版，画面+策略（运行策略：启动/循环/退出策略）。
- **信捷 TH 系列**：TH 屏 + XDPPro 配套，通常与信捷 PLC 直接组态，变量与 XD 地址直连。
- **汇川 IT 系列**：用 ITStudio（现 InoProShop 生态），与 H5U 等 EtherCAT/Modbus 联动。
- 设计原则相通：**地址表先行、安全兜底在 PLC、画面分区清晰**。

## 安全边界

- HMI 只做人机界面；**安全联锁（急停、门锁、光幕）必须在 PLC/硬回路实现**，不得依赖 HMI 软件逻辑。
- 权限密码、配方、报警记录涉及数据安全，备份工程文件。
