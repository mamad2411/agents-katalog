# Context7 Integration Rules

When answering user queries or writing code regarding:
- Library APIs or documentation (e.g., Kotlin, Android Jetpack Compose, Retrofit, Node.js, Express, Vitest, Gemini API)
- Framework setup, configuration, or upgrades
- Code examples for external dependencies
- Using features of third-party packages or SDKs

Automatically use Context7 MCP to fetch up-to-date, version-specific documentation and code examples straight from the source.
Do not rely on outdated training data or guess API signatures.
