# Finance Daily Insight — 一文通透

## 设计哲学与第一性原理 (Design Philosophy & First Principles)

> **一篇文章，服务两种读者，承前启后，逐步升级。一切分析必须根植于金融市场第一性原理。**

市场永远不是由表象新闻驱动的，而是由**资金的行为偏好**与**预期的折现机制**驱动的。

### 核心底层第一性原理 (必须贯穿每一期分析)：
1. **资本物理学（钱的本质）**：
   - 钱天然**厌恶风险**、本能**追逐超额回报**。在无风险利率高悬（如美债10Y走高）时，资本引力剧增，必然对未来虚无缥缈的画饼进行折现率杀估值；只有当确定性高或风险补偿极具吸引力时，资本才会冒进。
2. **时间维度（买在预期，卖在事实）**：
   - 市场价格不是对“当下事实的反应”，而是**对“未来现金流预期的提前贴现”**。
   - **“利好出尽变利空”的本质是边际买盘断层**：若市场在靴子落地前已打满预期（Priced-in），利好公布之时，正是最先潜伏买入的聪明钱“获得对手盘流动性、兑现利润离场”的时刻；
   - 真正决定资产未来涨跌的，永远是 $\Delta = \text{实际事实} - \text{已有预期}$ 的**预期差**，而不是新闻本身的好坏。
3. **博弈结构（边际定价与对手盘约束）**：
   - 价格由市场上最后 1% 的边际资金决定，而不是存量持股者的良好愿望。没有新增增量资金持续加价，热度就会被高位获利盘砸塌；大资金建仓需要恐慌廉价筹码，出货必须借助亢奋的“利好消息”创造承接流动性。
4. **约束力边界（意愿 vs 能力）**：
   - 投资意愿永远受制于资产负债表与借贷成本。钱想不想买是态度，借不借得到钱、加不加得起杠杆、监管允不允许是物理能力。

核心不变量：
1. **事实不造假** — 每个数字可溯源
2. **机制不空话** — 绝不用“情绪推动/利好利空”搪塞，每个结论追到预期差与资金约束变化
3. **教育不居高** — 不把读者当傻瓜，用底层逻辑帮小白摆脱“见利好就冲”的韭菜思维
4. **连续不刻意** — 只在真正碰撞时关联往期
5. **验证不回避** — 公开承认每期判断的对错
- 详见完整公理参考：`references/first-principles.md`

## 日期与范围

### 日期解析
- 用户说"今天" → 使用用户本地日期；如主要市场仍在交易，标注盘中
- 用户指定日期 → 使用该日期
- 无指定 → 使用当前本地日期

### 市场范围
- 默认覆盖：全球宏观 + 美股 + A股 + 港股 + 汇率 + 利率 + 大宗商品
- 用户指定市场 → 聚焦该市场，但保留关键跨市场传导
- 薄日（信息少）→ 缩量而非凑数

### 模式判断
- 周一至周四 → **日度洞察模式**
- 周五 → **周度总结 + 下周展望模式**（自动切换，无需用户指定）
- 用户明确说"周度" / "下周展望" → 强制周度模式，无论星期几

在文件头部记录：报告日期、模式（日度/周度）、市场范围、数据新鲜度。

### 一级源（优先）
- Reuters / Bloomberg / Financial Times / Wall Street Journal / The Economist
- 财新 / 第一财经 / 财经杂志 / 21世纪经济报道 / 经济观察报
- 央行、统计局、交易所、监管机构、公司公告等官方发布
- 详见权威官方清单：`references/authority-sources.md`（整理自主人关注清单与全球官方源）

### 二级源（需回溯验证）
- FT中文网 / WSJ中文网 / 新浪财经 / 凤凰财经
- Wind / 东方财富 / 同花顺（仅在一级源不可得时）

### 禁用源
- 自媒体 / 公众号（含自己的历史文章——不能自引自证）
- 未经核实的社交媒体
- 标题党或情绪化内容

### 数据标签
- `【实】` 已确认的实际数据
- `【预】` 市场预期/共识
- `【估】` 估算/模型推断
- `【待】` 已报道但未独立验证 — 不可作为核心判断依据

## 工作流程

### Phase 0: 历史碰撞检测（连续性引擎）

> 这是本 skill 的核心创新。不刻意回顾，只在真正碰撞时关联。

**碰撞检测流程：**

1. 执行 `python3 scripts/collision_detector.py` 或直接读取 `markdown/finance-insight-index.json`
   - 这个 JSON 记录了每期的：日期、核心判断、验证条件、待验证日期、已教概念列表
2. 扫描最近 5 期的"待验证判断"
3. 对比今日事实与市场数据，检测 4 种碰撞：

| 碰撞类型 | 触发条件 | 处理方式 |
|---|---|---|
| **证实** | 今日数据/事件确认了往期判断 | 在"上期验证"段简述：判断→验证数据→结论 |
| **证伪** | 今日数据/事件否定了往期判断 | 同上 + 分析为什么判断错了（约束变化 or 框架缺陷） |
| **延伸** | 今日事件是往期分析的逻辑延续 | 在正文分析中自然引用（"X月X日我们分析了Y，今天Z正是该传导链的下一环"） |
| **反转** | 今日事件与往期分析方向完全相反 | 在核心分析中专门讨论：为什么反转？哪个约束变了？ |

4. 如果无碰撞 → 跳过，不刻意制造关联
5. 如果有碰撞 → 自然融入文章结构（见下方"文章结构"中的位置）

**已教概念池管理：**
- 从 `finance-insight-index.json` 读取 `taught_concepts` 数组
- 今日文章中出现的概念，如果已在池中：一句话唤醒（"我们在X月X日详细讲过Y"），不重复展开
- 如果不在池中：完整展开（见 Phase 3 的概念教育规则）
- 写完后更新池

> 如果 index 文件不存在（首次运行），跳过碰撞检测，正常运行，并在输出时创建 index。

### Phase 1: 事实采集与验证（全景四维源头扫描）

> 严禁只抓大盘指数涨跌或表面新闻！必须深挖**对市场产生巨大作用的底层源头**。

1. **四维源头全景扫描**（必须覆盖影响全球定价的四大源头）：
   - **源头 ①：主权债务与期限溢价 (Term Premium)**
     - 美财政部（TGA 账户资金流向、国债回购上限与实际操作规模、发债计划与赤字压力）；
     - 10Y/30Y 美债收益率、美债收益率曲线倒挂/陡峭化、期限溢价水平；
     - 全球长债联动共振（如英国国债、日本国债收益率异动）。
   - **源头 ②：地缘冲突与大宗商品时滞传导 (Commodity & Inflation Lag)**
     - 中东地缘局势、关键咽喉通道（如霍尔木兹海峡通行量）、产油国设施安全；
     - 原油（Brent/WTI）、工业金属等大宗商品价格异动；
     - **时滞传导分析**：明确区分“当下发布的 CPI 能源基数效应”与“当前油价跳涨对未来 1-2 个月通胀的滞后冲击”。
   - **源头 ③：全球货币与套息交易去杠杆 (Carry Trade & De-leverage)**
     - 主要央行（BOJ 日本央行、ECB、Fed）的突变预期与官方立场；
     - 关键融资货币汇率（USD/JPY、DXY）大幅异动；
     - 套息交易（Carry Trade）平仓对高 Beta 资产（美股科技股、加密资产、新兴市场）的流动性抽血效应。
   - **源头 ④：大国经贸博弈与外汇逆周期对冲 (Trade & FX Intervention)**
     - 进出口总额、贸易顺差、供应链关键分项；
     - 外部贸易关税与制裁施压政策；
     - 人民币汇率（在岸 CNY、离岸 CNH）与央行逆周期调节（中间价偏弱/偏强指引的点位差及其政策意图）。

2. **事实过滤与信息沉淀**
   - 整理 4-6 条关键事实链条，每条必须包含完整的：**事件主体（谁做了什么） + 核心数字（实际值 vs 预期值/前值） + 市场即时反应 + 为什么对全局定价重要 + 来源 + 数据标签**。
   - 严禁空洞的“某板块活跃”或“大盘受情绪影响”。

3. **交叉验证与数据标签**
   - 重要数字至少两个独立来源确认；不确定的标 `【待】`。
   - 标签规范：`【实】`（已确认实际数据）、`【预】`（市场共识/掉期预期）、`【估】`（模型/机构测算）、`【待】`（需进一步确认）。

### Phase 2: 机制分析与矛盾分层（主要矛盾 vs 次要矛盾）

> 任何市场剧烈波动都不是单一数据引发的，而是结构性约束收紧与博弈主体冲突的结果。

1. **理清博弈源头与施力主体**：
   - 谁是真正的施力者（美财政部、美联储、日本央行、中国央行、地缘力量）？
   - 他们各自面临的物理约束（债务赤字、通胀声誉、汇率底线、出口竞争力、武器与航道控制）是什么？
   - 他们的行为如何改变了市场的无风险利率“锚”或资金流动性？

2. **核心矛盾分层（必须明确区分主要矛盾与次要矛盾）**：
   - **主要矛盾（底层全局结构性张力）**：
     - 决定未来数周至数月大势走向的根本矛盾。
     - 例如：全球央行传统货币工具失效（利率压不住地缘油价、对 supercore 工资螺旋滞后、长端利率被财政部发债/回购博弈对冲）vs 市场既有宽松定价的冲撞；或者全球四大施力主体同时收紧约束对全球风险资产流动性的抽水。
   - **次要矛盾（局部性、日内性、表象扰动）**：
     - 短期数据发布（如某日单项 PPI/CPI 微幅超预期、个别票委常规表态、行业短期题材炒作）。
     - 次要矛盾本身不能创造长期趋势，但会成为主要矛盾的放大器或催化剂。
   - **主次矛盾转化与确认机制**：
     - 阐明次要矛盾在什么条件下会激化并强化主要矛盾，在什么条件下主要矛盾会被打破或反转。

3. **第一性原理因果链条推演**：
   `施力主体行为/地缘突变 → 核心约束变化 (流动性/期限溢价/融资成本) → 谁的资产负债表受压迫 (被动平仓/去杠杆) → 哪类资产被重定价 (折现率杀估值 vs 现金流重估) → 观察与证伪信号`

### Phase 3: 分层写作（核心创新 — 一文服务所有读者）

#### 写作原则

**正文语言**：专业但清晰 — 用行业标准术语，但每个术语首次出现时即时展开。

**分层阅读机制**：

1. **概念即时展开**（面向小白）
   - 关键术语**首次出现**时，紧跟一个展开块：
   ```
   > 💡 **风险偏好**是什么？简单说，就是市场愿不愿意为了更高收益去承担更大的不确定性。
   > 想象你面前有两个选择：银行存款（确定的 2%）和一只股票（可能赚 20% 也可能亏 10%）。
   > 当大家都愿意选股票时，风险偏好高；当大家都跑去存银行时，风险偏好低。
   > 今天文章里说的"风险偏好回升"，就是资金从确定性资产流向不确定性资产。
   > ⚠️ 新手误区：风险偏好高 ≠ 市场一定涨，它只说明资金在移动，不说明移动是对的。
   ```
   - **概念已在往期教过**时（在已教概念池中），仅一句话唤醒 + 新维度：
   ```
   > 💡 **风险偏好**（我们在 9月3日 详细讲过）—— 今天的新维度是：它和汇率的关系。
   ```

2. **机制深度**（面向专业人士）
   - 正文用标准的机制分析语言
   - 不因教育展开而稀释分析深度
   - 展开块是"插入"而非"替代"

3. **方法传授**（面向成长中的读者）
   - 每篇文章末尾有一个"本期分析方法"段，教读者如何用本文的分析框架分析下一个类似事件
   - 格式：`新闻事实 → 约束变化 → 谁的行为改变 → 哪类资产重定价 → 什么信号证伪`
   - 配一个举一反三的假设场景

#### 叙事风格（融合原 finance-explosive-article 的德哥风格）

- **认知反转**：每篇必须包含至少一个"不是A，而是B"结构
  - 质量门槛：A = 普通读者/标题的假设，B = 真正的定价约束
  - 如果 B 无法链接到数据/政策/流动性/利率/资金流/资产负债表 → 不用
- **可复用模型**：每篇留下一个命名的系统模型
  - 例如："流动性-风险偏好传导模型"、"政策预期-资产负债表修复模型"
  - 四层格式：触发变量 → 传导机制 → 资产定价 → 验证信号
- **禁止空话**：
  - ❌ "因为利好所以涨" / "市场情绪推动" / "资金炒作" / "政策刺激"
  - ✅ 解释谁在重定价什么 / 哪个约束变了 / 资金怎么在系统中流动 / 什么会证伪

### Phase 4: 验证闭环

每篇文章末尾留下结构化的待验证判断：

```markdown
## 本期待验证

| 判断 | 验证条件 | 验证日期 | 碰撞时回顾 |
|---|---|---|---|
| 美联储 12 月降息概率大于 50% | CME FedWatch 12月合约 > 50% | 2026-09-17 | 下周同数据出来时 |
| A股量能萎缩将持续 | 连续 3 日两市成交 < 8000亿 | 2026-09-13 | 下周一 |
```

这个表格同步写入 `finance-insight-index.json`，供下期 Phase 0 碰撞检测使用。

### Phase 5: 周度模式（周五 / 用户指定时自动触发）

当处于周度模式时，在日度内容之后追加：

#### 5a. 本周验证总结
- 回顾本周所有待验证判断的实际结果
- 计算准确率（诚实面对）
- 分析：对了为什么对，错了为什么错

#### 5b. 下周展望
- 宏观定位：`偏进攻 / 中性偏进攻 / 中性偏防守 / 偏防守`
  - 必须指明定位依据的具体变量
  - 包含：仓位上限范围、加仓条件、减仓条件、关联风险
- 行业多空矩阵（中美双市场各 2-4 个方向）
  - 每个行业方向需要：行业级证据（不能仅凭单只股票）、市场行为验证、预期差判断、假设与证伪
  - 置信度标签：`高` / `中` / `低`（低 = 仅观察）
- 关键日历与观察清单
- 情景推演（基准 / 备选 / 尾部风险）

#### 5c. 个股参考（谨慎且有条件）
- 中美各 2-4 只，包含多空方向
- 每只必须有：方向、论据（2-4 条证据）、预期差象限、入场条件、止损/证伪、仓位建议范围
- 没有明确入场/止损/证伪 → 降级为 `观察` 而非 `买入`
- 反对追涨追跌

> 周度模式的内容仍然是**同一篇文章的延伸**，不是独立的第二篇。

## 文章结构（必须遵循）

### 日度模式


## 写作风格

- 犀利、直接、不废话
- 短段落、清晰节奏
- 用对比（"不是A，而是B"）但不堆砌
- 用因果链，不用情绪词
- 数字尽量量化（+15bps, -2%, 8000亿）
- 概念展开块温暖但不居高临下 — 像一个有耐心的朋友在解释
- 专业分析部分锐利但克制 — 结论强，但不overstep证据
- `说白了` / `真正的问题是` / `底层逻辑是` 少用但精准
- 不说"笔者认为" / "我们预计" → 说"数据显示" / "机制指向"

## Fallback 规则

| 情况 | 处理 |
|---|---|
| 数据无法验证 | 不呈现为事实 |
| 市场未收盘 | 标注盘中/待定 |
| 来源不清 | 丢弃该条新闻 |
| 外部数据获取失败 | 仅用已有的来源支持的事实，在头部注明局限 |
| 可靠信息不足 3 条 | 发布 1-2 条 + 明确说明"今日可验证信息有限" |
| 无法写文件 | 在 chat 中输出 markdown |
| index.json 不存在 | 创建新的，跳过碰撞检测 |
| 无碰撞 | 跳过"上期碰撞"段，不刻意制造 |
| 所有碰撞都是"待定" | 不勉强判对错，保留待定 |

## 目标

产出一篇文章，让读者：

1. **小白**：看完能复述今天市场发生了什么、为什么、以及下次遇到类似情况怎么分析
2. **进阶读者**：发现"我上次学的概念在这期又出现了，而且有了新的维度"
3. **专业人士**：获得一个可验证的机制判断、一个可复用的系统模型、一个诚实的证伪信号
4. **连续读者**：感受到"这个作者敢公开验证自己的判断，对了会说为什么对，错了会说为什么错"
5. **所有人**：记住一个可复用模型，在下一次类似事件中独立分析
