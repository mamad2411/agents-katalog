# Codex 작업 지침

이 저장소에서 작업하는 Codex 에이전트는 [공통 에이전트 가이드](agent.md)의 Git, 보안, 테스트와
CI 규칙을 따른다.

`docs/`를 생성하거나 크게 수정할 때는 다음 순서로 작업한다.

1. 대상 도메인의 `README.md` 또는 `index.md`에서 문서 책임과 우선 정본을 확인한다.
2. [문서 관리 정책](docs/governance/documentation-policy.md)을 적용한다.
3. 대규모 재작성·이동·폐기라면 [문서 재작성 가이드](docs/governance/documentation-rewrite-guide.md)의
   완료 게이트를 적용한다.
4. 현재 구현에 관한 주장은 코드·테스트·설정과 대조한다.
5. 변경 뒤 상대 링크, 메타데이터, 필요한 도메인 진입점·색인·로그를 검증한다.

정책 전문을 이 파일에 복제하지 않는다. 단순 오탈자처럼 책임·정본·탐색 구조를 바꾸지 않는
수정에는 재작성 절차 전체를 요구하지 않는다. 커밋과 원격 작업은 사용자 요청 또는 명시적인 작업
권한이 있을 때만 수행한다.
