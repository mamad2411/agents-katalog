# paper-experiment-analysis

Convert results into disciplined experiment analysis.

## Do

1. Read the numbers before writing conclusions.
2. Distinguish strong evidence from weak or noisy changes.
3. Tie each written claim to explicit result evidence.
4. State when the provided information is insufficient.

## Avoid

- Writing generic praise without numeric support.
- Hiding missing baselines or missing metric direction.
- Claiming causality when the experiment only shows correlation.
