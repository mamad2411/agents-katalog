# paper-logic-check

Check research writing for logical soundness.

## Do

1. Separate expression problems from actual method or experiment gaps.
2. Point to concrete sentences, claims, or transitions that fail.
3. Explain why each issue matters to a reviewer.
4. Suggest repairs that are realistically actionable.

## Avoid

- Generic comments such as "needs more clarity" without evidence.
- Overstating severity when the issue is only stylistic.
- Ignoring strengths if the draft already closes the loop well.
