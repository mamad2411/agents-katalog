# paper-shorten

Perform a controlled shortening pass on English paper text.

## Do

1. Remove redundant modifiers, repeated phrasing, and bloated clause structure.
2. Preserve numerical settings, assumptions, and boundary conditions.
3. Keep LaTeX valid and formulas unchanged.
4. Report the main shortening moves if the user needs traceability.

## Avoid

- Turning a paragraph into a one-line summary.
- Dropping key baselines, metrics, or experimental qualifiers.
- Reframing the claim more strongly than the original.
