# rsun-lean-canvas — 一頁商業邏輯圖

Lean Canvas 是 9 個方格組成的一頁紙，強迫你在 20 分鐘內說清楚一個專案的商業邏輯。它不是商業計畫書，而是「假設清單」——你在建立什麼、為誰建立、如何知道成功了。

**適用時機：**
- 新客戶第一次洽談，需要快速了解他們的商業模式
- 估價前確認產品邏輯（避免估錯方向）
- 客戶說不清楚「為什麼要做這個系統」時

---

## 9 個方格說明

### 方格填寫順序（有邏輯的）

```
Step 1 → Problem（最重要，先想清楚）
Step 2 → Customer Segments（為誰解決）
Step 3 → Unique Value Proposition（你的核心承諾）
Step 4 → Solution（怎麼解決）
Step 5 → Channels（如何觸達客戶）
Step 6 → Revenue Streams（如何賺錢）
Step 7 → Cost Structure（要花多少）
Step 8 → Key Metrics（怎麼衡量成功）
Step 9 → Unfair Advantage（為什麼是你）
```

---

### 1. Problem（痛點）

列出 **Top 3 問題**，必須是客戶真實感受到的痛點：
- 問題越具體越好（不要說「效率低」，要說「每次核准需要 3 天，郵件來回 15 封」）
- **現有替代方案**：客戶現在怎麼解決這個問題？（Excel？人工？競品？）

```
問題 1：[具體痛點]
問題 2：[具體痛點]
問題 3：[具體痛點]

現有替代方案：[Excel / 人工 / 競品名稱]
```

### 2. Customer Segments（客戶群）

誰是這個系統的**最終使用者**？（不是付錢的客戶，而是實際使用的人）

- 主要用戶：[角色描述，例：房產仲介、倉庫管理員、會計人員]
- 早期採用者：[最願意嘗試新系統的那群人，他們的特徵是？]

> 注意：在 B2B 專案中，「付錢的客戶」和「使用系統的人」往往不同，都要列出。

### 3. Unique Value Proposition（獨特價值主張）

一句話說清楚這個系統帶來的最大好處：

```
[動詞] + [結果] + [目標客群] + [不需要 ...]
```

範例：
- 「讓房產仲介在 5 分鐘內完成物件刊登，不需要聯繫 IT 人員」
- 「自動彙整所有供應商報價，讓採購主管省去 80% 手動整理時間」

### 4. Solution（解方）

對應 Problem 的 3 個核心功能：
- 每個問題對應一個解方
- 聚焦**功能**，不是技術實作
- 這裡的答案會成為 PRD 的 P0 功能需求

```
問題 1 的解方：[核心功能]
問題 2 的解方：[核心功能]
問題 3 的解方：[核心功能]
```

### 5. Channels（觸達管道）

用戶如何找到這個系統，或系統如何觸達用戶？

- **Inbound**：用戶主動進來（官網搜尋、App 下載、員工培訓）
- **Outbound**：系統主動推送（Email 通知、SMS、推播）
- **整合觸點**：透過哪個平台進入（LINE / 企業 ERP / 客戶自有系統）

### 6. Revenue Streams（收入來源）

客戶的**商業模式**（他們怎麼靠這個系統賺錢或省錢）：

- 收費模式：訂閱制 / 交易抽成 / 一次性授權 / SaaS
- 節省成本模式：減少人工、縮短流程、降低錯誤率
- 預計規模：月交易量、用戶數、訂閱金額（估算即可）

> 這個方格幫助你判斷：客戶的 ROI 合不合理？他們能從這系統賺回多少？

### 7. Cost Structure（成本結構）

建立這個系統的主要成本：

- **開發成本**（這就是我們的估價）
- **維運成本**：主機、資料庫、CDN、第三方 API 費用（月費）
- **人力成本**：上線後需要幾個人維護？
- **客戶獲取成本**（如果系統本身有行銷功能）

### 8. Key Metrics（關鍵指標）

怎麼知道這個系統成功了？選 3-5 個最重要的數字：

```
指標 1：[名稱] → 目標：[數字]
指標 2：[名稱] → 目標：[數字]
指標 3：[名稱] → 目標：[數字]
```

> 這些指標後來會成為 PRD 的 Step 2 成功指標。

### 9. Unfair Advantage（不可複製的優勢）

**這個是最難填的，也是最重要的。**

什麼讓這個方案難以被競爭者複製？

- 專有資料（客戶已有的歷史資料）
- 獨特整合（深度整合客戶現有系統）
- 產業 Know-how（只有這個客戶懂的業務邏輯）
- 先發優勢（搶先佔領特定市場 / 客群）
- 品牌信任（長期合作關係）

> 如果填不出來，這個專案可能存在很高的競爭風險，需要和客戶討論。

## 注意事項

- **填不出 Unfair Advantage** → 主動和客戶討論差異化策略，這是風險信號
- **Problem 和 Solution 不對應** → 停下來重新確認需求，否則估價會偏差
- **Customer Segments 只有一個角色** → 想清楚是否有其他用戶（如管理員 vs 一般用戶）
- 整個 Canvas 應該在 **30 分鐘內完成**，不要過度分析，它是假設，不是事實
