# Skill: UI Flow-Driven Delivery (BTHWANI)

Goal: ship complete end-to-end flows with zero UI drift.

Steps:

1. Flow Definition: entry/exit + branches + critical edge cases.
2. Surface Map: mobile + web + MCPW in one bundle.
3. IA: what is visible first vs hidden (progressive disclosure).
4. Components: UI kit only + full state matrix.
5. Microcopy: use glossary; errors must be fix-oriented.
6. QA: device matrix + RTL/EN + accessibility basics.
7. Acceptance: block merge if any rule fails.

References: @30-uiux-governance-core, @33-uiux-glossary-min, @34-user-surface-shells-no-duplication.
