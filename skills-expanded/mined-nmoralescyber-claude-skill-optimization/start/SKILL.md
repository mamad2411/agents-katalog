# DEPRECATED: start

This skill has been deprecated for a solo cybersecurity-focused founder/operator workflow.

## Reason for deprecation

`start` is a one-time bootstrap skill that initializes the productivity system, sets up working memory, and decodes shorthand on first use. You are already past initial setup — re-running first-run onboarding has no value, and keeping it active risks Claude triggering it when you actually want ongoing maintenance instead. Library tuning and improvement are continuous work, not a setup step.

## Use these alternatives instead

| Need | Skill |
|---|---|
| Audit, tune, or improve your installed skill library | `skill-optimizer` |
| Re-sync tasks or refresh memory from current activity | `personal-assistant` |

## Restoration

If your role changes (e.g., you wipe your environment and need to re-onboard from scratch, or you set up a new machine), restore the original from the originally-installed plugin location, or remove this stub from `~/.claude/skills/start/SKILL.md` so the original takes precedence.
