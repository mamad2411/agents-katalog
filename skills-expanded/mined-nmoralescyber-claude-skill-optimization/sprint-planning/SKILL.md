# DEPRECATED: sprint-planning

This skill has been deprecated for a solo cybersecurity-focused founder/operator workflow.

## Reason for deprecation

Sprint planning assumes a team to allocate work across, ceremonies (planning, review, retro), and a velocity/capacity model that only makes sense with multiple contributors. As a solo founder/operator, there is no team to plan a sprint for — the overhead of running sprint ceremonies against yourself produces process theater, not throughput. Backlog management and feature scoping are the underlying needs, and both are better served by lighter-weight skills.

## Use these alternatives instead

| Need | Skill |
|---|---|
| Track and prioritize the backlog you're working through | `productivity:task-management` |
| Scope and write up an individual feature or initiative | `product-management:write-spec` |

## Restoration

If your role changes (e.g., you start managing a team, you start running sprints, etc.), restore the original from the originally-installed plugin location, or remove this stub from `~/.claude/skills/sprint-planning/SKILL.md` so the original takes precedence.
