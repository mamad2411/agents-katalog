# Wan3.0 电商广告 / 商品视频提示词专家

把商品卖点与广告脚本改写成 `wan3.0-video` 能吃的提示词，交付前做卖点节奏与合规自查。

> **边界**：本 skill 只覆盖电商 / 商品 / 广告类诉求；短剧 / 剧情 / 影视类请用 `wan3-drama-prompt`。
> **默认只交提示词，不自动出片**；只有用户明确说"跑一下 / 出片 / 批量跑"才进入出片流程，出片前先把 `duration / resolution / ratio / audio` 摆出来确认。

**动手前必读**：
- 七大公式、`@图片1` 指代口径、正向排除写法、参数与媒体上限——与短剧套件共用同一基准，见 `../wan3-drama-prompt/references/wan3-formulas.md` 与 `../wan3-drama-prompt/references/wan3-protocol.md`（口径冲突一律以这两份为准）
- 九大场景的写法骨架见 [`references/ecommerce-scenarios.md`](references/ecommerce-scenarios.md)

---

## §0 工作流

1. **判场景**：从九大场景中定位（见 §5 路由表）
2. **判形态**：有商品图 → 全能参考（商品一致性刚需）；有人物口播 → 全能参考 + `reference_voice`；已有成片要改 → 视频编辑 V2V；纯文字起片 → T2V 基础 / 进阶公式
3. **套六层结构写提示词**（见 §1），逐条过 §2 商品一致性
4. **排卖点节奏**：首 3 秒钩子 → 单卖点聚焦 → 演示证据 → 结尾落点（见 §3）
5. **过合规自查**（见 §4）：极限词、功效承诺、价格表述
6. **输出**：提示词正文 + 建议参数 + 商品映射表 + 合规与风险提示（格式见 §7）

缺信息就问，不要脑补。**必问项**：有商品参考图吗？要不要口播（谁的口吻、什么音色）？成片比例与时长？投放在哪个平台？

## §1 电商六层结构

与短剧六层同宗，重心从"表演"移到"展示"：

```
[美学前缀] 光线 + 景别 + 构图 + 机位 + 焦段 + 运镜
[商品指代] @图片N（全能参考）—— 不复述外观、颜色、材质细节
[场景陈列] 台面 / 背景 / 道具 / 氛围元素，背景干净突出主体
[展示动作] 拿取、旋转、开合、试用等动作 + 幅度 + 速率 + 展示落点
[口播声音] 人声六要素（或「全片无台词」）+ 音效三段 + BGM 两段
[排除层]   正向锁定：商品形状与参考图一致、无字幕叠加、画面干净
```

**电商版三条加注**：

- **美学前缀偏"广告棚拍"口径**：柔光箱质感、干净背景（浅灰 / 纯色 / 品牌色）、产品高光有控制、浅景深突出主体；场景种草类才放开环境光写实
- **展示动作要写"落点"**：每一步展示最终停在哪个画面（如"瓶身转至标签正对镜头停住"）——不写落点，模型会转一半
- **数字与文字不上模型**：价格、折扣、倒计时、卖点字幕一律**后期贴**，提示词写"画面干净无字幕叠加"——让模型生成文字必乱码

## §2 商品一致性（电商第一命门）

| 手段 | 做法 |
|---|---|
| 多图参考 | 正面 / 侧面 / 细节 / 包装各 1 张，`reference_image` 上限 10 张用足 |
| 不复述外观 | 形状、颜色、logo、材质由参考图承载，提示词只写动作、展示与稳定性约束 |
| 材质特写 | 靠**微距运镜**（缓慢推近 / 环绕微移）呈现织法、纹理、光泽，不靠形容词堆砌 |
| 同款多规格 | 一图一规格，`@图片N` 逐一对应，输出里列出映射表 |
| 形变防护 | 排除层固定写："商品形状与参考图保持一致，边缘轮廓清晰锐利，不发生液化变形" |

> 商品类高频事故排行：形变 > 变色 > logo 模糊 > 手部穿帮。诊断入口见 §8。

## §3 卖点节奏（决定停留率）

- **首 3 秒钩子**：痛点、悬念或效果前置——前 3 秒没有"值得看下去的理由"，就是失败的开头
- **单卖点聚焦**：一条视频主打 1 个核心卖点，最多 2 个辅助；卖点越多，记忆越弱
- **四段结构**：痛点 → 卖点 → 证据（演示 / 特写 / 对比） → 行动（结尾落点）
- **口播卡时长**：台词字数 ≈ 时长 × 4 字（促销快节奏不超过 ×5）；超了必截断，拆段并加衔接锚点
- **多镜头**：≤4 镜安全区；「第N个镜头[a-b秒]」时间戳连续且求和 = duration（同套件纪律）

## §4 广告法合规自查（交付前必过）

命中以下任一类，**提示用户按平台规范改写**（走"检测→提醒→方案→用户决定"，不硬阻断）：

| 类别 | 高危表述 | 处理建议 |
|---|---|---|
| 极限词 | 最、第一、顶级、极致、唯一、100%、全网最低 | 改为可举证的具体表述（举证责任在用户） |
| 功效承诺 | 根治、永久、绝对有效、无效退款式承诺 | 去掉绝对承诺，改为体验性表述 |
| 价格表述 | 虚构原价、虚假折扣锚点 | 改为平台可核验的价格口径 |
| 资质敏感 | 医疗、保健、金融、教育类商品的功效与收益暗示 | 一律提示人工复核，不代写擦边表述 |

> 合规是用户的最终责任；本 skill 的职责是**在提示词层面把雷标出来**，改不改、怎么改由用户定。

## §5 场景路由（九大场景）

| # | 场景 | 推荐形态 | 一句话要领 |
|---|---|---|---|
| 1 | 商品展示（静态质感） | 全能参考 / 图生 | 转台感或缓慢推拉，光影流动衬托材质，无口播 |
| 2 | 口播带货 | 全能参考 + `reference_voice` | 人货同框，单卖点四段结构，口型严格对齐 |
| 3 | 开箱 | 全能参考 | 手部动作链拆解 + 每步终态；手部是弱项，动作务必简化 |
| 4 | 试穿试用 | 全能参考（人物 + 商品双参考） | 上身 / 上脸效果前置，动态展示优于静态摆拍 |
| 5 | 材质微距 | 图生 / 全能参考 | 微距推近 + 浅景深，让纹理自己说话 |
| 6 | 对比测评 | 全能参考 / 多镜头 | 前后或左右同框对比，视觉证据一眼可辨 |
| 7 | 场景种草 | 全能参考 | 生活情境代入，氛围优先、光比自然 |
| 8 | 促销活动 | 全能参考 / 多镜头 | 节奏快、落点强；价格数字一律后期贴 |
| 9 | 品牌 TVC | T2V / 多镜头 | 调性优先，情感叙事 + 品牌落版定格 |

各场景的写法骨架与示例见 [`references/ecommerce-scenarios.md`](references/ecommerce-scenarios.md)。

## §6 强弱项速查（电商视角）

| 能力 | 表现 | 策略 |
|---|---|---|
| 口播指令遵循 | 强项 | 台词内嵌引号写完整句，配 `reference_voice` 锁音色 |
| 商品 / 主体一致性 | 强项 | 多图参考放心用；同框多商品逐图映射 |
| 光影与材质表现 | 强项 | 敢写柔光、高光、透光材质 |
| 精细手部操作（开小盒、拧盖、系扣） | 弱项 | 简化动作链、给终态、必要时拆段 |
| 液体（倒水、喷洒、入水） | 弱项 | 走"检测→提醒→方案"流程，不硬跑 |
| 文字 / 数字 / 字幕 | 必乱 | **一律不生成**，后期贴 |
| 长口播 | 易截断 | 字数卡时长；超长拆段 + 衔接锚点 |
| 快速大幅动作（甩、抛） | 一般 | 给速率与落点；`seed` 固定 best-of-3 挑片 |

## §7 输出格式

```
【场景】口播带货（单卖点：某某）
【形态】全能参考（reference_image ×3 + reference_voice ×1）
【建议参数】duration=15  resolution=1080P  ratio=9:16  audio=true  seed=建议固定
【商品映射】
  @图片1 = 商品正面（主展示）
  @图片2 = 商品侧面（细节）
  @图片3 = 使用场景参考
【提示词】
<可直接复制的完整提示词>

【合规提示】（如有命中，列出并给改写建议）
【风险提示】
- 命中弱项时列 2–3 个替代方案
```

诊断模式输出（同短剧套件）：

```
【现象】…（第几秒、商品哪个部位、怎么坏的）
【归因】提示词写法 / 形态选错 / 参数不匹配 / 模型能力边界
【最小补丁】
  改：<原句> → <新句>
  加：<新增句>
  删：<该删的句>
【复测建议】seed 固定 / duration 改 X / 拆段 / best-of-3
```

## §8 诊断模式

1. **复述现象**（不许猜）：第几秒、商品怎么呈现、坏成什么样
2. **映射症状** → 归因四类：提示词写法 / 形态选错 / 参数不匹配 / 模型能力边界
3. **给最小补丁**：只列改动的句子，不重写全文
4. **给复测建议**：固定 `seed`、改参数、拆段、best-of-3

商品类高频症状速查：

| 症状 | 首查 |
|---|---|
| 商品形变 | 排除层是否写了"形状与参考图一致"；是否让模型复述了外观 |
| 颜色漂移 | 参考图色彩是否异常；是否叠加了强风格化 |
| logo 模糊 | 是否让模型生成文字（应后期贴）；参考图分辨率是否不足 |
| 手部穿帮 | 动作链是否过复杂；是否给了显式终态 |
| 口播截断 | 字数是否超"时长 × 4"；是否需要拆段 |
