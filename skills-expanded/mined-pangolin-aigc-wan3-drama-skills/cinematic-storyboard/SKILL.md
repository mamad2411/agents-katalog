# 电影化分镜与单元切分技能

将一集（或多集）剧本转换为「电影化分镜脚本」，并将分镜切分成一个个「单元」（段落），每个单元对应一个 ≤15 秒的视频片段。

## 触发条件

当用户提供剧本文本（含场次头、人物、△动作描述、台词、VO/OS 等），并希望：
- 生成「电影化分镜」「运镜脚本」「镜头脚本」，或
- 将分镜「切分成段 / 单元 / 15 秒片段」，或
- 明确要求输出格式「像 分镜.txt 那样」

时，使用本技能。

## 输入格式

输入为一集或多集剧本，典型结构如下：

```
第X集
X-X 场景名 时间(日/夜) 内/外
人物：角色1 角色2 ...
字幕：（可选，如 民国·申城·外滩）
△动作描述（分镜提示，通常以 △ 或【特写】等标记开头）
角色名（情绪/动作标注）：台词内容
角色名（VO）：内心独白台词
角色名（OS）：画外/回忆音台词
（闪回画面）/（接镜头）/（转场）等标记
```

## 输出格式（三层结构）

输出为纯文本，采用「集 → 单元 → 镜头」三层结构：

### 第一层：集标题
```
第X集 分镜脚本
```

### 第二层：单元（分镜切分成段）
每个单元对应一个 ≤15 秒视频片段，格式：
```
单元 N：X-X 场景名 时间 内外场次站位描述： <该片段内人物的空间站位、距离关系、走位描述>
```
- `单元 N`：从 1 开始，每集内连续编号
- 紧跟场次头（原样保留 `X-X 场景名 时间 内外`），可附 `(闪回)`、`(转场)`、`(结尾留钩子)` 等状态标注
- `场次站位描述：` 后描述本单元内角色的物理站位、彼此距离、面向、掩体位置等，为镜头调度提供空间基准

### 第三层：镜头行
每个单元内的镜头从 1 开始编号，一行一个镜头，格式：
```
N. 景别代号 (运镜方式) 前景：<前景描述或"无">。【画面动作描述】【声音设计描述】<台词部分>
```
- `<台词部分>`：有台词写 `角色名：台词内容`（VO/OS 写 `角色名（VO）：...`）；无台词写 `:(无台词)`

镜头行完整示例：
```
4. CU (固定镜头) 前景：无。【特写秦书瑶脸部，从脖子到头顶。她眼波流转，神态傲慢中带着惬意】【声音低缓，带着一丝感叹，语速慢】秦书瑶：今夜的外滩，太静了。
1. WS (低机位推轨镜头) 前景：虚化的沾满雨滴的古董车窗。【秦书瑶身穿紧身旗袍站在大门光晕中，摄影机贴近湿润石板路缓慢向前推】【环境音：幽微的爵士乐混杂着远处的车轮声】:(无台词)
```

## 镜头行字段详解

### 1. 景别代号（必填，放在最前）
| 代号 | 含义 | 用途 |
| --- | --- | --- |
| WS | 远景/全景 Wide Shot | 建立场景、环境关系、群体调度、气势场面 |
| MS | 中景 Medium Shot | 人物半身、动作、双人关系、走位 |
| MCU | 中近景 Medium Close-Up | 胸部以上、情绪推进、对话主力景别 |
| CU | 特写 Close-Up | 「脸部，从脖子到头顶」、情绪爆发、关键道具 |
| ECU | 极特写 Extreme Close-Up | 眼睛、手指、血印、极致细节强调 |

- 面部特写统一描述为「特写XXX脸部，从脖子到头顶」，保证生成一致性。

### 2. 运镜方式（必填，紧跟景别，用英文括号包裹在中文里）
写在 `( )` 内，描述机位与运动。常用词库（可组合中英文）：
- 固定类：`固定镜头`、`固定广角`、`正俯拍固定`
- 推拉类：`推轨镜头`、`缓慢推镜`、`急推镜头`、`极近推镜`、`轨道后拉`
- 摇移类：`平移镜头`、`平移跟拍`、`急速横摇 Whip Pan`、`向下摇摄`、`视线引导下摇 Tilt Down`、`缓慢上摇`
- 角度类：`低角度仰拍`、`高机位俯拍`、`越肩反打`、`过肩镜头`、`倾斜镜头 Dutch Angle`
- 手持/跟随：`手持微晃`、`手持晃动`、`斯坦尼康跟拍`、`贴地手持跟拍`、`环绕变焦`
- 特殊/特效：`慢动作 Slow-mo`、`匹配剪辑 Match Cut`、`大摇臂下降 Crane Down`、`焦点虚实转换`、`快速焦点转换`、`主观视线 POV`
- 转场类：`叠化 Dissolve`、`前景遮挡转场 Wipe`、`硬切 Hard Cut`、`推进拉出转场`

### 3. 前景（必填）
`前景：` 后写具体前景遮挡物或 `无`。前景用于营造纵深与偷窥感，例如：
- `前景：虚化的沾满雨滴的古董车窗。`
- `前景：秦书瑶虚化的肩膀。`（越肩/过肩必写虚化肩膀）
- `前景：刺客的枪管。` / `前景：焦外的、燃烧的红色龙凤喜烛。`
- 无前景时写 `前景：无。`

### 4.【画面动作描述】（第一个方括号，必填）
描述该镜头内的具体画面：角色动作、走位、表情、镜头运动落点、环境变化。要具体可执行，带空间与朝向信息。

### 5.【声音设计描述】（第二个方括号，必填）
每个镜头都要有独立的声音/表演层标注，从以下维度择一或组合：
- **环境音**：`【环境音：清脆的高跟鞋脚步声】`、`【撕裂夜空的马嘶声】`、`【密集的枪火声】`
- **气口/呼吸**：`【气口：倒抽一口凉气0.8s】`、`【气口：沉稳的呼吸留白1.0s】`（可带秒数）
- **无声留白**：`【无声留白2.0s】`
- **微表情/表演提示**：`【微表情：咬肌紧绷】`、`【动作轻缓无声】`
- **台词语气（有台词时）**：`【声音低缓，带着一丝感叹，语速慢】`、`【爆喝声，音量极大】`、`【内心VO，声音极度绝望沙哑】`

### 6. 台词部分（必填，行尾）
- 有台词：`角色名：台词内容`
- 内心独白：`角色名（VO）：台词内容`
- 画外/回忆音：`角色名（OS）：台词内容`
- 无台词：`:(无台词)`（前面加英文冒号，与样例一致）

## 单元切分规则（分镜切分成段·核心）

1. **时长优先**：每个单元对应一个 ≤15 秒的视频片段。按镜头数量与节奏估算，通常每单元 **3-6 个镜头**。
2. **切分依据**：在以下位置切出新单元 ——
   - 空间/站位发生明显变化（人物走位、新角色入画、包围圈形成）
   - 场景/时空切换（进入闪回、转场、切回现实）
   - 戏剧节拍转换（如从温情→冲突、从对峙→爆发）
3. **场次站位描述**：每个单元开头必须交代本片段内角色的物理站位、彼此距离、面向与掩体，作为该段所有镜头的空间基准。
4. **单元连贯**：同一单元内的镜头共享同一空间与时间，镜头间是连续动作的分解。
5. **结尾留钩子**：每集最后一个单元在场次描述后标注 `（本集结尾留钩子）` 或 `（结尾留钩子）`，末镜画面「切黑，留出悬念钩子」。

## 镜头拆分规则（分镜·核心）

1. **切镜密度第一**：每个语义停顿（逗号、分号、语气词）、每次情绪转折、每个被提及的人/物，都应切镜。宁可多切不要少切。
2. **一句台词至少 2-3 个镜头**：说话人 → 听话人反应；有逗号的台词按逗号切，中间插入听话人/被提及物镜头。
3. **禁止连续同角色同角度**：相邻两镜若人物相同且角度相同，应合并或换角度/换景别/插入反应镜头。单人长台词必须在分句间插入旁观者反应。
4. **VO/OS 独立成镜**：内心独白、画外音、回忆音单独成镜，常配特写或主观视线镜头。
5. **重要△动作独立成镜**：无台词的关键动作（拔枪、坠马、推门、按血印）单独成镜，`:(无台词)`。
6. **越肩/过肩必带虚化前景**：双人对话/对峙优先越肩反打，`前景：XXX虚化的肩膀。`
7. **前景纵深**：关键镜头善用前景（雨滴、烟雾、枪管、门框、烛火）营造纵深与情绪。
8. **台词不重复**：一句台词拆成多镜时，按语义把片段依次分配到各镜，相邻镜头台词绝不重复。

## 景别 / 运镜 / 声音的选择建议

- **建立镜头**用 WS + 推轨/俯拍 + 环境音；**情绪爆发**用 CU/ECU + 急推 + 气口；**动作场面**用 MS + 手持/斯坦尼康 + 密集音效；**转场**用 Match Cut / Dissolve / Wipe / Whip Pan。
- **声音设计**要与画面情绪匹配：安静场面用「无声留白 / 气口」，冲突用「爆喝 / 密集枪火」，濒死/绝望用「游丝气声 / 空灵回忆」。

## 转场与特殊标记

- 剧本中的 `（闪回画面）`、`（接镜头）`、`（转场）` 在单元场次标注中体现为 `(闪回)`、`(转场)` 等。
- 跨场景/时空切换用一个专门的转场镜头承接（Match Cut / Dissolve / Wipe / 硬切），并在【画面】中说明转场逻辑（如「相似动作轴线反转」「形状与动势匹配」）。

## 输出要求

1. 开头输出集标题 `第X集 分镜脚本`。
2. 按「单元 → 镜头」顺序输出；单元内镜头从 1 连续编号，跨单元不连续（每单元重新从 1 开始）。
3. 每个镜头独占一行，字段顺序严格为：`序号. 景别 (运镜) 前景：X。【画面】【声音】台词`。
4. 每个镜头都必须包含：景别代号、运镜、前景、【画面】、【声音】、台词部分（无台词写 `:(无台词)`），缺一不可。
5. 多集连续处理时，逐集输出，集与集之间另起 `第X集 分镜脚本` 标题。
6. 最终输出为纯文本，可直接保存为 `.txt` 文件，文件名建议 `分镜.txt` 或 `{集数}_分镜.txt`。
7. 覆盖率：确保剧本每一句台词、每一条关键△动作都有对应镜头，不遗漏钩子与转场。
