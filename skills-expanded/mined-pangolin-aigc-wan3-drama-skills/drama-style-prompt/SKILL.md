# 剧集视觉风格系统提示词生成

根据用户给出的剧集类型，生成一段**可直接使用**的视觉风格系统提示词。该提示词用于约束视频生成模型（如 万相）的全局画面基调，保证同一剧集所有片段风格统一。

## 工作流程

1. **解析剧集类型**，提取五个定位要素（缺失时按题材惯例合理推断，不追问）：
   - **媒介形式**：真人实拍写实 / 3D CG 动画 / 2D 动画
   - **年代**：如 80年代、民国、古代、现代、架空
   - **地域场景**：如 农村、旧上海、都市、仙侠世界
   - **情绪基调**：克制沉稳 / 紧张唯美 / 华丽浪漫 / 悬疑压抑 等
   - **硬性约束**：用户明确的禁令或要求（如 严禁背景音乐、人物与参考图一致）
2. **逐维度填充框架**（见下方九维框架），每个维度做出与题材匹配的**具体、可执行**的决策。
3. **输出成品提示词**，按输出规范组织为单份可直接粘贴的文本。

## 九维框架

每份系统提示词按以下维度组织（可按题材合并或裁剪，但前 4 项与最后 1 项必须有）：

| 维度 | 必须回答的问题 |
|------|----------------|
| [整体定位] | 媒介质感（胶片/数字/离线渲染）、参考影像风格（如 ARRI Alexa + 35mm、国漫番剧）、总体气质一句话 |
| [色彩与对比] | 饱和度高低、色温具体 K 值、主色板（列出 5-8 种具体颜色）、对比度/反差策略、高光与暗部处理 |
| [光照] | 主光类型（自然散射光/伦勃朗光/逆光轮廓/体积光丁达尔）、光比软硬、人物面部受光与肤质呈现 |
| [镜头与构图] | 景深与背景虚化程度（给百分比）、常用景别与机位清单（过肩/反打/俯仰/特写/建立镜头）、偏好角度 |
| [空间与机位规则] | 180° 轴线、反打背景真实性、相邻镜头景别机位变化、切换节奏（写实剧必写；动画可简化） |
| [表演与角色] | 表演颗粒度（眉眼/呼吸/停顿/微动作）、不同年龄角色的状态差异、发丝衣物等物理细节、对口型要求 |
| [特效与氛围] | 题材专属氛围元素（雨雾霓虹/灰雾空气感/灵气粒子符纹），无需特效的写实题材写"画面纯净统一" |
| [画面信息呈现] | 剧情内道具、纸张、告示、界面的材质与磨损感呈现方式（可并入其他段） |
| [最终成片目标] | 用一句话收拢全部关键词的成片描述 + 所有硬性约束（禁令必须原样保留，如"严禁背景音乐"） |

## 题材 → 风格决策规则

以下为三个已验证的锚点风格，新题材通过就近类比 + 差异化调整生成：

- **写实年代剧（农村/年代/家庭）**：胶片低饱和灰调、阴天柔光、低对比 LOG 观感、纪录片式克制表演、完整轴线规则。色温偏暖灰 3500K 左右。
- **民国/旧上海/年代传奇**：伦勃朗光 + 逆光轮廓 + 丁达尔，双色温对撞（暖黄 4300K + 青蓝 6800K 霓虹），湿地反光、雨雾辉光，紧张但唯美的旧上海电影感。给出亮度/对比度/柔焦的具体数值。
- **3D 漫剧/仙侠/国漫**：离线渲染壁纸级画质、次表面散射瓷白肌肤、通透水润瞳孔、多层轻纱 + 金线刺绣服饰、暖金冷青双色光、灵气流光粒子特效、高级灰低饱和底色 + 金/朱红/月白点缀。

新题材类比示例：
- 现代都市情感 → 靠近写实锚点，改为数字电影机质感、城市玻璃幕墙冷暖光、色温 5000K 中性偏冷
- 古装宫斗 → 融合民国锚点的戏剧光与实拍质感，主色板改为宫墙红、鎏金、黛青
- 悬疑刑侦 → 写实锚点 + 压低亮度、加大暗部占比、冷青主调、手持镜头呼吸感
- 2D 动画 → 参照 3D 锚点结构，替换渲染描述为手绘赛璐璐/厚涂质感

完整锚点提示词原文见 [examples.md](examples.md)，生成时参考其用词密度与句式。

## 输出规范

- **写实剧**用 `[标签]` 分段格式（如 `[整体定位]`、`[色彩与对比]`），每段一整句到数句的连贯描述；**动画/风格化题材**可用分号串联的单段长文本（参照 3D 漫剧锚点）。
- 参数必须**具体量化**：色温写 K 值，虚化写百分比，需要时给亮度/对比度/柔焦数值，禁止"适当""合理"等模糊词。
- 色板必须列出**具体颜色名**（如 水泥灰、土褐、暗青绿），不写"低饱和色系"了事。
- 全文中文，一次性输出完整成品，不加解释性前后缀，用户复制即可使用。
- 用户给出的硬性禁令（如 严禁背景音乐、严禁配乐）放在 [最终成片目标] 段末，原样强语气保留。
- 涉及参考图的剧集，在 [光照] 或 [表演] 段加入"人物要与参考图保持一致"类表述。
