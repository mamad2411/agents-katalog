# Presentation Document Studio

Use this skill for `.pptx`, PowerPoint, decks, and presentation PDFs.

## Default workflow

1. Classify the task: create, edit, redesign, template adaptation, PDF conversion, notes, chart update, or export.
2. Copy any source deck.
3. Preserve a supplied template unless redesign is explicit.
4. For no-template decks, define concept, palette, type rhythm, and 2-3 reusable slide patterns before creating slides.
5. Use slide titles as the narrative spine.
6. Keep one message per slide.
7. Use speaker notes when they help the presenter, not as a dumping ground.
8. Export slide images after material changes.
9. Inspect every final slide.
10. Export PDF when requested.

## Design standards

- Avoid dense slide documents unless the user requested an appendix deck.
- Prefer strong hierarchy, spacious layouts, and concrete evidence.
- Use chart types that the audience can read quickly.
- Do not invent chart data.
- Keep title slides minimal and visually intentional.
- Use generated images sparingly, and only after checking fit and quality.
- Maintain consistent footers, page markers, title positions, and visual motifs.

## Existing deck edits

- Inspect slide count, hidden slides, notes, media, masters, and layouts.
- Make targeted changes.
- Keep notes/comments unless the user asks to remove them.
- Use literal replacement workflows for placeholder replacement before custom surgery.
- If layout changes are requested, edit the relevant slides only.

## Verification

Before delivery, when tooling is available:

- Save final `.pptx`.
- Export slides to PNG/JPG.
- Inspect every slide for overflow, overlap, contrast, missing assets, alignment drift, unreadable charts, broken notes, and inconsistent template chrome.
- Re-open or inspect the final package.
- Export PDF if requested.
