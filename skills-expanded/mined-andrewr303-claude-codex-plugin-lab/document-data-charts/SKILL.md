# Document Data Charts

Use this skill for all quantitative document components.

## Required resources

Read the relevant resources:

- `../business-plan-document/SKILL.md` for business-plan and financial-plan data standards.
- `../word-document-studio/SKILL.md` for Word tables and report charts.
- `../presentation-document-studio/SKILL.md` for slide charts.
- `../../business-plan-skill.txt` for investor-grade assumptions and financial reasoning.

## Rules

- Never invent data for charts or tables.
- Every value must come from user input, extracted source data, live research, or a labeled assumption/estimate.
- Show units, currency, date range, and source.
- Reconcile totals.
- Do not smooth contradictory source numbers. Flag the conflict.
- Prefer conservative/base-case numbers in investor materials.
- Use tabular numerals where the format supports it.

## Chart selection

- Line: trend over time.
- Bar/column: category comparison.
- Stacked bar: composition, only when labels stay readable.
- Waterfall: bridge from one financial state to another.
- Scatter: relationship between two measures.
- Table: exact values or multi-field lookup.
- Heatmap: dense matrix, only when color scale is meaningful.

Avoid decorative charts that make numbers harder to read.

## Financial schedules

For financial plans:

- Build revenue bottom-up.
- Tie cost of revenue to operations assumptions.
- Tie operating expenses to hiring, marketing, R&D, and G&A assumptions.
- Include working capital and capex when material.
- Show break-even logic.
- Stress-test revenue down 30% and costs up 20% when requested or when investor-grade planning is implied.

## Table design

- Use explicit column widths.
- Keep short values compact.
- Give narrative columns enough width.
- Repeat headers for multi-page tables.
- Align numbers consistently.
- Avoid mini-essay cells unless the table is truly the right form.

## Verification

Before final delivery:

- Check formulas, totals, margins, growth rates, and labels.
- Confirm chart data matches source table.
- Confirm visual labels are readable in the final render.
