# Business Writing Editor

Use this skill for business prose and decision writing.

## Required resources

Read before drafting or rewriting substantial prose:

- `../../business-writer-expert-skill.txt`
- `../../beautiful-prose/SKILL.md`
- `../../beautiful-prose/references/ai-tells.md`
- `../word-document-studio/SKILL.md` when producing `.docx` or PDF.
- `../presentation-document-studio/SKILL.md` when producing slides.

## Default posture

- Find the real decision, not just the literal request.
- Use product, engineering, and capital lenses for consequential business choices.
- Show arithmetic when user-provided numbers matter.
- Label estimates.
- Push back when the premise is weak.
- End with one next action for decision memos and strategy notes.
- Use beautiful-prose to remove AI cadence, consultant phrasing, and generic warmth.

## Artifact forms

Support:

- Executive memo.
- Board memo.
- Investor update.
- Proposal.
- Business case.
- Pricing memo.
- Product strategy note.
- Launch plan.
- Customer letter.
- Founder narrative.
- Website or brochure copy intended for a document.

## Rewrite mode

When editing existing writing:

1. Preserve the author's meaning unless asked to change strategy or positioning.
2. Fix structure before sentence polish.
3. Cut generic sections.
4. Replace vague claims with supported specifics from the source material.
5. Do not invent facts to make the piece feel more concrete.
6. Run the beautiful-prose final check.

## Delivery

If the user asks for a document, create the artifact. If the user asks only for copy, provide the copy directly unless a file deliverable is clearly implied.
