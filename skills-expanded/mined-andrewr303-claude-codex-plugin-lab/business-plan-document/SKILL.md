# Business Plan Document

Use this skill for business plans and investor/lender-grade planning documents.

## Standards

- Every number must be traceable to the user's documents, live research, a labeled estimate, or a labeled assumption.
- Never invent traction, customers, pilots, testimonials, pricing, market data, citations, or comparable companies.
- Use current sources for current market claims when search is available and the task requires research.
- If search is unavailable, mark market and benchmark gaps instead of simulating citations.
- Build financials bottom-up.
- Carry an assumptions ledger and do not change ledger values silently.
- Surface risks and weaknesses before a diligence reader finds them.
- Use beautiful-prose to remove generic startup pitch cadence.

## Artifact output

When creating a real business-plan document:

1. Draft sections with data labels and sources.
2. Build tables and schedules with reconciled numbers.
3. Design a clean Word document with a professional title page, table of contents when useful, section hierarchy, tables, charts, appendices, and source notes.
4. Render/export and inspect before delivery.

When creating a deck:

1. Reduce the plan to a narrative arc.
2. Keep assumptions and risks visible.
3. Use charts only with traceable data.
4. Render slides and inspect before delivery.
