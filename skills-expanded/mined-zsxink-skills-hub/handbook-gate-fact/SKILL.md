# 事实门禁（handbook-gate-fact）

卡数字可信：关键数字是否带取数口径、证据是否分级标注、未验是否明示、时效快照是否一致。

## 唤醒条件
主技能在 ④ 写作循环、gate-consistency 通过后唤醒；或打回 topic-research。

## 输入
- chapter_laid_out + research_pack（取数口径 / 快照时刻）

## 输出
- review_verdict：pass / 打回 topic-research（附违反 K）。

## 引用原子（见 references/kernel_skills.md）

本技能**检查**以下原子（由上方写作技能拥有）：

| K | 名称 | 维度 |
|---|---|---|
| K19 | 证据可信：精确数字带取数口径，并按实测/读文档/未验分级标注、可复现验 | 讲解 |
| K37 | 时效与口径诚实，禁夸张话术 | 一致性 |

## 完成判定
- [ ] - [ ] 每个关键数字带取数命令 / 口径 / 误差
- [ ] - [ ] 证据按 实测/读文档/未验 分级，未验明示
- [ ] - [ ] 第三方数字列不同口径并写采信理由
- [ ] - [ ] 时效快照时刻与全书一致，无夸大话术

## 做法步骤
1. 1. 抽所有数字，查是否带取数命令 + 口径 + 误差（K19）。
2. 2. 查事实性断言是否打 实测/读文档/未验 标签，未验是否写进正文（K19）。
3. 3. 查第三方数字是否列不同口径并写采信理由，倍数是否写明「这句话不能说成……」（K19/K37）。
4. 4. 查统一快照时刻是否与附录一致。违反项打回 topic-research 补证据。

## 反例
- - ❌ 「效率大幅提升」「约一万多 token」。
- - ✅「13,809 token（逐项做差称出，±2 量级）」。
- - ❌ 未实跑的结论当事实。
- - ✅「分叉、恢复、回放我一次没实跑过，这条别照着我说的信。」
