# 结构门禁（handbook-gate-structure）

卡结构合规：章题、首句论断、小节标题、章首契约、收尾交付物、下章钩子、系列骨架模板是否齐。

## 唤醒条件
主技能在 ④ 写作循环末尾、成书前唤醒；或按 review_verdict 打回 outline。

## 输入
- chapter_laid_out + outline.md

## 输出
- review_verdict：pass / 打回 outline（附违反的 K 编号 + 位置）。

## 引用原子（见 references/kernel_skills.md）

本技能**检查**以下原子（由上方写作技能拥有）：

| K | 名称 | 维度 |
|---|---|---|
| K01 | 章题写成读者原话疑问或收益承诺 | 结构 |
| K02 | 首句即论断，不写背景铺垫 | 结构 |
| K03 | 开场钩子：反直觉断言/硬数字/亲历翻车先上桌，实测时间线当骨架 | 结构 |
| K04 | 章首签契约、结论先交付 | 结构 |
| K05 | 小节标题写成带反转的完整句 | 结构 |
| K06 | 操作内容编号化成流程骨架 | 结构 |
| K07 | 「你以为→其实→为什么更好」三段式 | 结构 |
| K08 | 末句交接棒，下章首句接住 | 结构 |
| K09 | 章末收尾交付物：一句断言/原则清单/自问清单三选一，下章钩子收尾；同名固定栏目为可选强化项 | 结构 |
| K10 | 全书路线图与章型节奏编排 | 结构 |
| K11 | 篇幅预算：每节/每章字数配比与取舍，目标字数公开标注进导航页 | 结构 |
| K31 | 系列级骨架模板：封面元数据+导航页统计+章节骨架（§编号/Part分区/双语标题）+收尾交付物 | 一致性 |

## 完成判定
- [ ] - [ ] 章题是疑问/收益句 + 英文副标，无「X概述」
- [ ] - [ ] 首句即论断，无「本章将介绍」
- [ ] - [ ] 小节标题带反转，无名词短语
- [ ] - [ ] 章首契约 + 先说结论存在
- [ ] - [ ] 有收尾交付物（一句断言/原则清单/自问清单）+ 末句下章钩子；同名固定栏目仅当 outline 声明选用时检查其全书统一
- [ ] - [ ] 每章标注目标字数（供导航页统计）
- [ ] - [ ] 系列骨架模板（K31）逐项齐：封面元数据 / 导航页统计 / §编号+Part 分区 / 双语标题 / 收尾交付物

## 做法步骤
1. 1. 逐章对照 K01-K11 与 K31 清单打勾。
2. 2. 章题单独抽出来读，读不懂或没张力即打回。
3. 3. 收尾检查分两步：先查「收尾交付物 + 下章钩子」是否齐（K09 硬项）；再查「若 outline 声明选用同名固定栏目，全书是否统一命名」（软项，未选用不卡）。
4. 4. 把违反项写成「Kxx @ 章节位置：问题」，交给 outline 重写骨架。
5. 5. 全部通过才放行进入排版/门禁总检。

## 反例
- - ❌ 「章题写「上下文工程简介」，通过」——K01 违反。
- - ✅ 「章题「你打第一个字之前，账单已经 13809」，带英文副标，过。」
- - ❌ 末句写「本章总结」。
- - ✅ 末句抛下章悬念并嵌交接棒数字。
- - ❌ 因「没有『他们本来想这么做』栏目」打回——但 outline 未声明选用同名栏目。
- - ✅ 检查收尾交付物（断言/清单/自问）是否齐即可，同名栏目仅当声明选用时卡统一。
