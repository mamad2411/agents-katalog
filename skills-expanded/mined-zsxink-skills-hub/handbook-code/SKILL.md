# 代码+双栏注释（handbook-code）

产出可复制、带中文注释、可核证的代码 / 命令块，作为正文的教具与证据。

## 唤醒条件
主技能在 ④ 写作关，draft 遇到要贴代码 / 命令时唤醒。

## 输入
- chapter_draft 中需要代码支撑的点 + research_pack 的真实样本

## 输出
- 带注释代码块（并入 chapter_draft 或独立 code_block.md）。

## 引用原子（见 references/kernel_skills.md）
本技能**拥有**并应用以下原子：

| K | 名称 | 维度 |
|---|---|---|
| K28 | 代码与命令块＝可复制教具＋可核证物 | 视觉 |

## 被检查门禁
本技能**自身校验**其拥有的视觉原子（K28 → handbook-code），无独立门禁；以「可复制 + 带注释 + 带真实输出」三项完成判定为准（见原子字典）。

## 完成判定
- [ ] - [ ] 代码读者能直接复制用（真实成品，非干代码）
- [ ] - [ ] 每段配中文注释讲「这段在防什么 / 做什么」
- [ ] - [ ] 关键行做指认式解读（「中间那行 const matches 是判断汉字的」）
- [ ] - [ ] 证据块带真实路径 / PR 号 / 版本号 + 你这一跑的真实输出 + 一句结论

## 做法步骤
1. 1. 贴代码前问「读者能直接复制用吗」，不能就换成最小可用成品（SKILL.md / hooks JSON / 安装命令 / 目录树）。
2. 2. 每段代码配一句中文注释讲它在防什么，挑一行做指认式解读并明说「不写代码也能看出」。
3. 3. 证据类片段带真实路径 / PR 号 / 版本号，声明有没有改动过。
4. 4. 每个命令块后必须紧跟「我这一跑打出来是 X」的真实输出 + 一句结论；给不出输出的命令不贴。

## 反例
- - ❌ 贴一段省略号满满的「示意」代码。
- - ✅ 贴完整 SKILL.md，逐字段讲 name/description，「就这么简单」。
- - ❌ 命令块只写命令不写输出。
- - ✅「方式就两条命令，你现在跑一遍也是同样的东西……我这一跑打出来是 4100 25。」
