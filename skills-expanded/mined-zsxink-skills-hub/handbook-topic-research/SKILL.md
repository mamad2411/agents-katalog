# 选题·受众·证据研究（handbook-topic-research）

为「为什么写、写给谁、凭什么信」三件事产出证据底座，是 research_pack 的「选题与证据」部分。

## 唤醒条件
主技能在 ① 立意 与 ② 研究 阶段唤醒；或用户要补事实证据 / 系列定位时单独调用。

## 输入
- 主题 brief（一句话定位 + 读者假设）
- 已有书 / 竞品清单
- research_pack（本技能只填选题与证据段）

## 输出
- research_pack.topic.md：受众定位、非专家取材边界、关键数字与取数口径表、证据可信度分级、时效快照时刻、系列定位与读者分流。

## 引用原子（见 references/kernel_skills.md）
本技能**拥有**并应用以下原子：

| K | 名称 | 维度 |
|---|---|---|
| K19 | 证据可信：精确数字带取数口径，并按实测/读文档/未验分级标注、可复现验 | 讲解 |
| K33 | 非专家身份当取材标准与安抚装置 | 一致性 |
| K37 | 时效与口径诚实，禁夸张话术 | 一致性 |
| K38 | 系列自指：交代写作方法与读者分流 | 一致性 |

## 完成判定
- [ ] - [ ] 每个关键数字都带取数命令 / 口径说明 / 误差范围
- [ ] - [ ] 证据按 实测 / 读文档 / 未验 三档分级，未验处明示「这条别照着我说的信」
- [ ] - [ ] 写明全书统一快照时刻（截至 YYYY-MM-DD）
- [ ] - [ ] 序言给出读者分流（没用过 X 先读哪本）
- [ ] - [ ] 只写以作者身份也能验证、也会关心的部分

## 做法步骤
1. 1. 先写读者画像：谁会在群里问这件事、他卡在哪、作者相对他的真实位置（含非专家反差）。
2. 2. 列关键数字清单，每个补一行取数命令 + 口径 + 误差；不同来源口径冲突时写清采信哪一个。
3. 3. 给每条事实性断言打 实测/读文档/未验 标签，未验写进正文。
4. 4. 定统一快照时刻，写进附录占位。
5. 5. 写序言两段：本书怎么产出（自用哪些工具/几个 agent/多久）+ 读者分流。

## 反例
- - ❌「这个方案大幅提升了效率」——没有数字、没有口径。
- - ✅「在我这个 3 文件任务上它慢了十几倍（21.9s vs 305.9s，逐项做差称出，±2 量级）」。
- - ❌ 把未亲自跑过的结论当事实陈述。
- - ✅「分叉、恢复、回放这三样我一次没实跑过，这条别照着我说的信。」
