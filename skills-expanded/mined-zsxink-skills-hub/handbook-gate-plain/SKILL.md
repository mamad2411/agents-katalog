# 说人话门禁（handbook-gate-plain）

卡「读得懂」：新概念是否从已知推、类比有无失真声明、天真反问有无回应、引文有无人话译文、好坏示例是否并置、是否给判断线不替决定。

## 唤醒条件
主技能在 ④ 写作循环、gate-structure 通过后唤醒；或打回 draft / metaphor-research。

## 输入
- chapter_laid_out + metaphor_pack

## 输出
- review_verdict：pass / 打回 draft（附违反 K）。

## 引用原子（见 references/kernel_skills.md）

本技能**检查**以下原子（由上方写作技能拥有）：

| K | 名称 | 维度 |
|---|---|---|
| K12 | 单一隐喻母体贯穿，新概念挂回母体 | 讲解 |
| K13 | 类比后立刻声明失真点 | 讲解 |
| K14 | 由已知推未知的递进披露 | 讲解 |
| K15 | 最小可运行样本先行 | 讲解 |
| K16 | 机制链与边界对比替代下定义 | 讲解 |
| K17 | 替读者提天真反问，再用「但」字撤地毯 | 讲解 |
| K18 | 引文三段式：原文→人话→为何关键 | 讲解 |
| K20 | 好坏示例并置与一句话微例 | 讲解 |
| K21 | 给判断线与场景落点，不替读者决定 | 讲解 |
| K22 | 负面示范先行：先给❌负面示范建张力，再给✅正确做法 | 讲解 |

## 完成判定
- [ ] - [ ] 新概念从读者已知推出来，不空降
- [ ] - [ ] 类比后紧跟「失真点」声明
- [ ] - [ ] 易质疑处有「你可能会想」+ 解答
- [ ] - [ ] 引文有三段式（原文→人话→为何关键）
- [ ] - [ ] 原则配 ❌/✅ 并置 + 微例
- [ ] - [ ] 给判断线，不替读者下结论

## 做法步骤
1. 1. 逐条新概念检查是否先锚已知再讲差异（K14/K15/K16）。
2. 2. 每个类比查是否紧跟失真声明（K13）；隐喻是否全书不换喻（K12）。
3. 3. 易质疑观点查有无天真反问 +「但」撤地毯（K17）。
4. 4. 引文查三段式（K18）；原则查 ❌/✅ 并置与微例（K21）；功能介绍查三问 + 判断线（K22）。
5. 5. 违反项写「Kxx @ 位置」打回 draft 或 metaphor-research。

## 反例
- - ❌ 直接下定义「Skill 是……」无已知锚点。
- - ✅「Skills 就是 AI Agent 的 App。」先挂已知再展开。
- - ❌ 类比只写「就像乐高」不写失真。
- - ✅「乐高拼错了你一眼看得见；这东西拆错了安静地不工作。」
