# 一致性门禁（handbook-gate-consistency）

卡声音 / 术语 / 跨章 / 招牌句式 / 两面记账是否与全系列一致。

## 唤醒条件
主技能在 ④ 写作循环、gate-plain 通过后唤醒；或打回 draft。

## 输入
- chapter_laid_out + 全书已写章节（跨章上下文）

## 输出
- review_verdict：pass / 打回 draft（附违反 K）。

## 引用原子（见 references/kernel_skills.md）

本技能**检查**以下原子（由上方写作技能拥有）：

| K | 名称 | 维度 |
|---|---|---|
| K32 | 系列声音：第一人称人设+口语尺度+招牌句式与固定标记词 | 一致性 |
| K33 | 非专家身份当取材标准与安抚装置 | 一致性 |
| K34 | 术语纪律：首见给人话定义，全书一词一义 | 一致性 |
| K35 | 跨章引用织网并指定权威版本 | 一致性 |
| K36 | 两面记账：好处必配代价，不替对象打圆场 | 一致性 |
| K38 | 系列自指：交代写作方法与读者分流 | 一致性 |

## 完成判定
- [ ] - [ ] 第一人称声音一致，无客观教科书腔
- [ ] - [ ] 术语首见人话定义、全书一词一义
- [ ] - [ ] 跨章指针存在（见 §XX / §XX 详述）
- [ ] - [ ] 招牌句式出现（这不是 A 是 B / 一句话讲清楚 / 反直觉的是）
- [ ] - [ ] 优点同章配代价小节

## 做法步骤
1. 1. 扫声音：是否全程「我」+ 至少一次「你」，有无无主语客观段（K32）。
2. 2. 扫术语：首见是否人话定义，后文是否复用同一写法（K34）。
3. 3. 扫跨章：已讲/将讲的点是否有指针，同事实多处是否标权威来源（K35）。
4. 4. 扫招牌句式与判断：是否用「这不是 A 是 B」「一句话讲清楚」「反直觉的是」，机制后有无 ≤20 字断言（K32）。
5. 5. 扫两面记账：每项优点是否同章有「代价：」小节（K36）。

## 反例
- - ❌ 某章突然切第三人称客观腔。
- - ✅ 全程「我试过 / 我踩过 / 我核过三遍」。
- - ❌ 同一概念前后两种写法。
- - ✅ 首见定义后全书固定；名词冲突时声明以实跑运行时为准。
