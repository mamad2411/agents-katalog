# 大纲·结构骨架（handbook-outline）

把主题落成全书路线图与每一章的骨架（章题、首句论断、小节目录、收尾栏目、下章钩子）。

## 唤醒条件
主技能在 ③ 大纲 阶段唤醒；或在 gate-structure 打回后重写骨架。

## 输入
- research_pack + metaphor_pack

## 输出
- outline.md：全书三幕路线图 + 每章 skeleton（章题/首句论断/小节目录/收尾栏目名/下章钩子）。

## 引用原子（见 references/kernel_skills.md）
本技能**拥有**并应用以下原子：

| K | 名称 | 维度 |
|---|---|---|
| K01 | 章题写成读者原话疑问或收益承诺 | 结构 |
| K02 | 首句即论断，不写背景铺垫 | 结构 |
| K03 | 开场钩子：反直觉断言/硬数字/亲历翻车先上桌，实测时间线当骨架 | 结构 |
| K04 | 章首签契约、结论先交付 | 结构 |
| K05 | 小节标题写成带反转的完整句 | 结构 |
| K06 | 操作内容编号化成流程骨架 | 结构 |
| K07 | 「你以为→其实→为什么更好」三段式 | 结构 |
| K08 | 末句交接棒，下章首句接住 | 结构 |
| K09 | 章末收尾交付物：一句断言/原则清单/自问清单三选一，下章钩子收尾；同名固定栏目为可选强化项 | 结构 |
| K10 | 全书路线图与章型节奏编排 | 结构 |
| K11 | 篇幅预算：每节/每章字数配比与取舍，目标字数公开标注进导航页 | 结构 |
| K31 | 系列级骨架模板：封面元数据+导航页统计+章节骨架（§编号/Part分区/双语标题）+收尾交付物 | 一致性 |

## 被检查门禁
本技能由 **handbook-gate-structure** 检查（见原子字典 K01-K11、K31）；门禁打回时本技能负责重写骨架。

## 完成判定
- [ ] - [ ] 每章有章题（读者原话疑问 / 收益句）+ 英文副标
- [ ] - [ ] 每章首句是一句可转述的论断（≤30 字，加粗）
- [ ] - [ ] 小节标题都是带反转的完整句
- [ ] - [ ] 章首有契约（答什么/不答什么/交哪节）+ 先说结论
- [ ] - [ ] 每章有收尾交付物（一句断言/原则清单/自问清单三选一）+ 末句下章钩子；同名固定栏目为可选强化项（按本书定位决定，非强制）
- [ ] - [ ] 每章 skeleton 标注目标字数（供导航页公开统计）
- [ ] - [ ] 排章符合 总览→上手→最小实战→深挖→端到端 三幕递进
- [ ] - [ ] 系列骨架（K31）逐项齐：封面元数据 / 导航页统计 / §编号+Part 分区 / 双语标题 / 收尾交付物

## 做法步骤
1. 1. 排章：前言明示三幕，章序 总览→10 分钟上手→最小可运行例子→分主题深挖→端到端实战；每 1-2 案例章后插概念整合章。
2. 2. 写每章章题：先写读者会在群里怎么问，原话当标题；非疑问型改写成收益句；补英文副标，禁用「X概述」。
3. 3. 写首句论断：动笔前用一句话写清「这章想让读者记住什么」，放第一段第一句。
4. 4. 写小节目录：每节标题含动词 + 反常事实（禁用「概述」「基本原理」）。
5. 5. 写章首契约 + 先说结论小节；写收尾交付物（一句断言/原则清单/自问清单三选一）+ 末句抛下章悬念，并嵌入本章具体数字当交接棒。仅当本书定位需要连载感时，才选同名固定栏目（如「他们本来想这么做，后来没做」）并全书统一使用。
6. 6. 为每章 skeleton 标目标字数（参考 K11 配比：序章/附录短，主线章节长），成书后按实际字数回填导航页统计。
7. 7. 套系列级骨架模板（K31）逐项填空：封面元数据（证据来源声明/涵盖内容/文档版本）、导航页统计（章数/字数/节数）、§编号与 Part 分区、双语标题、收尾交付物，缺一项不算成稿。

## 反例
- - ❌ 章题「权限模型概述」「成本分析简介」。
- - ✅「两个插件都想管文件编辑，谁赢」「一份好的 AGENTS.md 该写什么」。
- - ❌ 首句「本章将介绍……」「随着 AI 的发展……」。
- - ✅「Codex 不是一个工具，是一套系统。」
- - ❌ 每章强制套同一个「固定栏目名」（如每章都写「他们本来想这么做」）。
- - ✅ 每章保证有收尾交付物（断言/清单/自问），栏目名按本书定位可选统一。
