# 图示·可视化（handbook-diagram）

把空间结构与流程讲清楚成可扫读的纯文本图（ASCII 树 / 箭头链路），零图像依赖。

## 唤醒条件
主技能在 ④ 排版关，draft 遇到结构 / 流程时唤醒。

## 输入
- chapter_draft 中需可视化的层级 / 链路

## 输出
- ASCII 树 / 箭头链路（并入 chapter_laid_out）。

## 引用原子（见 references/kernel_skills.md）
本技能**拥有**并应用以下原子：

| K | 名称 | 维度 |
|---|---|---|
| K29 | 纯文本图：ASCII 树与箭头链路 | 视觉 |

## 被检查门禁
本技能**自身校验**其拥有的视觉原子（K29 → handbook-diagram），无独立门禁；以「层级用 ASCII 树、流程用箭头链、零散文描述空间」完成判定为准（见原子字典）。

## 完成判定
- [ ] - [ ] 层级用 ASCII 树，每个节点带中文职责注释
- [ ] - [ ] 流程用一行「A → B → C」箭头链再逐环展开
- [ ] - [ ] 不用散文描述空间关系（「A 在 B 下面」式）

## 做法步骤
1. 1. 讲目录 / 层级时用 ASCII 树替代文字，每个节点补一句中文职责注释。
2. 2. 讲流程先摆一行箭头链（每环 ≤10 字）再逐环展开。
3. 3. 需要概念图时优先纯文本；确需配图再产出最小 SVG/mermaid，且保持可复制、可被 agent 读取。

## 反例
- - ❌「这个文件在 src 下面，组件在 components 里面，工具在 tools 里……」（散文绕晕）。
- - ✅ 直接画 `.claude/skills/ ├── react-component/ │ └── SKILL.md # 创建组件的规范`。
- - ❌ 流程写成三段叙事无骨架。
- - ✅「模型想写圈外 → 内核拒绝 → 带理由重试 → 卡片弹到你面前」。
