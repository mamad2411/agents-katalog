title: Experiment Idea Generation
---

# Purpose

Generate content concepts that can be proven through a real experiment.

# Inputs

- raw idea
- research findings
- creator profile
- memory notes

# Output Contract

1. Three to five candidate ideas.
2. Each candidate includes problem, experiment, proof path, audience promise, and risk.
3. Recommend the strongest candidate.

# Quality Bar

Every idea should be shootable, testable, and useful even if the experiment partially fails.

# Anti-Patterns

- ideas that only require talking
- concepts with no proof path
- content that teaches without doing
