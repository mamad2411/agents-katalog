# 数学建模竞赛论文写作与诊断润色助手（内容版）

## 定位与分工

- **本 skill 只写内容**：结构、摘要、正文表述、统计结果报告、模型对比、严谨性审查、篇幅取舍。
- **排版与格式交给 `math-paper-template`**（LaTeX 骨架/字号字体/编译/复现）。
- **格式真源**：写正文前先读 `../../assets/official-paper-format.md`（官方 docx 提炼，内含"明文规定 vs 通行惯例"的分层）与 `../../assets/huashubei-writing-guide.md`（2026 实战踩坑）。下方「官方内容规范速览」是写作时的速览，与真源冲突时以真源为准；排版细节查 template。
- **数值纪律**【不变量】：正文每个数字来自 reports/（RESULTS/SENSITIVITY/DIAGNOSIS_REPORT）或代码输出，改脚本重跑后做「论文数字↔csv」零漂移核对。核对协议与措辞强度校准见 `../paper-gate/SKILL.md` G1。
- **验收交给 `paper-gate`**：写作时参照其 G1 声明白名单与 G2 撰写要求（16 条：复合问题拆三级标题、篇幅失衡提示、假设来源自查、数量级哨兵、语言去AI化、AI 工具不入文献列表），完稿后由 docgate.py 机械检查——本文件不复述规则全文，以 paper-gate 为唯一真源。约束分级约定（【事实】/【不变量】/【观察】）也在那里。
- **国奖档次对标交给 `guozhan-paper`**：摘要定量化写法、R1-R4 衔接、检验四件套、正反例语料（`../guozhan-paper/references/evidence-corpus.md`）。
- **能力探测**：完整论文从零生成时，若当前环境提供 MathModelAgent MCP（`mma_start`）可用它一键生成；否则按本 skill 手动构建，能力等价。

# 篇幅取舍：上限服从赛事官方，内容完整性优先

**篇幅哲学**：把内容讲清楚比压页数更重要。页数上限是【事实】（各赛事口径速查 `../../assets/paper-gate-rules.yaml` `pages.by_event`；docgate 对超页只给 WARN，不阻断），页面预算是【观察】——它是"每问讲清楚通常要多少地方"的经验值，不是配额。

超页与欠页的两个方向都是误区：
- 常见误区：为压页数砍掉检验闭环、关键数值与机制解释。省下的是半页，丢掉的是评委判断推理链的唯一依据。
- 常见误区：为填满预算注水（重复描述、把一句话拆成三句、罗列无解读的特征）。篇幅失衡提示（docgate [06] WARN）的用意是让你去看最薄的一问是不是真缺内容，不是让你加字。

删减优先级：重复描述 > 过度展开案例 > 冗余特征列表 > 啰嗦学术化表述。

页面预算（华数杯 30 页正文示例，附录不计；【观察】以正文实际需要为准）：
```
摘要+关键词                    0.5页
一、问题背景与重述(含1.3贡献)   1.5页
二、问题分析                    2页
三、符号说明                    1页
四、模型假设(4-8条精炼)         0.5页
五、数据预处理                  1.5页
六~九、四个问题(各4.5页)       18页
十、灵敏度分析                  1.5页
十一、模型评价与推广            1页
十二、结论                      1页
参考文献                        0.5页
══════════════════════════════════
正文总计                        ≤30页
```
**增量置换存量**：新增一个缺失项时，顺手找一处等量可删的冗余。页数上限是硬的，内容只增不减就会超页——这条不是要求逐字等重，而是让每次增补都伴随一次"哪里其实可以更少"的判断。

# 官方内容规范速览（真源：official-paper-format.md）

标【事实】的是官方明文或工程确定行为，其余是通行惯例与样本观察；与真源冲突时以真源为准。

1. **摘要三段论**：起始段（背景+研究问题，2-3 行）→ 主体段（每问一段：问题简化→数学归类→建模思想→算法→模型特点→主要结果[定量]）→ 推广段（推广+灵敏度一句）。【事实】含关键词控制在 A4 一页以内，不放表格/公式/图（一页也放不下）。关键词通常 4-6 个，以当届赛事模板为准；重点是覆盖问题词/模型词/算法词三个方向，不在凑数。
2. **题目命名三式**：直接复制 / 「基于主模型的 原题」/ 谐音梗（不推荐——评委从中读不出方法信息）。
3. **问题重述**（≤1 页）：三部分（背景+需解决问题+现有研究方法）；自组织词句不整段照抄（与题面的重合率由 docgate [13] 机械核对）；不引用原题图表；时间紧可以先拷贝再改，但改的动作不能省。
4. **问题分析**：这一章不写求解结果——结果只出现在摘要与求解节。评委在这里看的是推理链，提前给出结果会让人怀疑建模是倒推的。每问回答三问（要做什么/目标/怎么做）；对附件做数据分析；可含思路导图。
5. **模型假设**：【事实】官方对条数无明文规定；【观察】通行惯例 4-8 条、国奖样本常见 4-6 条——条数由模型真实需要的简化决定。三个来源：题目自带/题目推得/模型需要。警惕"模型正确性"类假设（假设本文方法是合适的）——那是循环论证，一旦这样假设，后文所有检验都失去意义。是否遗漏数据前提型假设，自查见 `../paper-gate/SKILL.md` G2-4。每条假设要在正文建模处被引用，否则它只是装饰。
6. **符号说明**：三线表三栏（符号|符号说明|单位）、约半页、不换页、不参与一般表格编号；只用一次的符号不必列。
7. **每问三段式**：模型建立→求解→检验。检验闭环是国奖样本最一致的特征（滚动验证、小规模精确对照、独立复算等）；docgate [09] 靠关键词给形态提示，换了措辞的检验它认不出，真缺检验它也拦不住，所以要人工看一眼。
8. **模型总结**：优点突出亮点（【观察】样本常见 5-7 条，条数服务于"有没有说清强在哪"）、缺点真实（=改进方向）、推广半页。
9. **参考文献**：【事实】官方下限 5 篇、另起一页、书/刊/网三种格式（详见 official-paper-format.md §十四），正文标注 [编号]；AI 工具不是出版物，不进文献列表。【观察】国奖样本常见 8 篇以上。卷期页码要真实可核，检索不到就标"无法核实"。
10. **AI 声明**：【事实】正文后、参考文献前；两套措辞（未使用／使用了+用途+详见附录）。

# 操作 2：摘要重写（最后写，一页以内）

```
【背景1-2句】→ 针对问题一(方法+结果1句) → 问题二(方法+结果1句)
→ 问题三(方法+结果1句) → 问题四(方法+结果1句)
→ 本文创新点在于：①②③（各1句）
关键词：XX XX XX XX（个数与分隔符以当届模板为准；国奖样本多用空格）
```

- 【事实】含关键词控制在 A4 一页以内。
- 【不变量】每问至少有一个能直接回答题目的量化数值，且每个数值都能在正文表格里找到。摘要最后写、数值从正文复制，就是为了守住这条。
- 推荐："准确率 99.7%，独立验证误差 <1.5%"。不推荐："模型效果良好，精度较高"。
- 常见误区：把第一段写成全文目录（连续罗列数据预处理、模型体系、四问目标与所有算法），背景与问题主线被淹掉。第一段只承担"为什么这个问题值得做"。
- 字数是结果不是目标：【观察】国奖样本每问 2-3 句、全文 550-1000 字；为凑字数增删真实内容属负优化。
- 不回避缺点、不夸大优点（措辞上限取自 `../paper-gate/SKILL.md` G1 声明白名单）。

# 操作 6：灵敏度分析（篇幅按上方页面预算，内容来自 SENSITIVITY_REPORT.md）

| 参数值 | 指标1 | 指标2 | 本文选用 |
|--------|-------|-------|----------|
每个参数：一个表格 + 1-2 句分析。

结论句跟着实测走：
- 扰动后目标变化很小 → "参数波动对总目标影响较小，模型稳健"（这句是评委的定拿分点，实测成立时别漏）；

# 学术写作规范（统计学博士审校）

## 段落与句式
- 常见误区：正文论证段落写成 bullet 列表（"•""●""-"）——评委读不到推理链，只看到结论堆叠；bullet 密集也是 AI 生成文本的高频特征。这一条没有机械检查兜底（docgate [11] 查的是分号密度、组合词与套话，不查 bullet），只能靠写的时候自觉。
- 论证用散文：每段 3-5 句、一段一个完整论点（【观察】样本常见 ≤150 字），段间用过渡词连接。
- 作用域不同不冲突：题干条款梳理、检查清单、符号罗列、排版层的技术路线步骤，这类内容本身就是列表，用 bullet 反而更清楚。

## 过渡连接词表
| 关系 | 论文可用词 |
|------|-----------|
| 递进 | 在此基础上、进一步地、此外、不仅如此 |
| 因果 | 因此、由此、鉴于此、从而、进而 |
| 转折 | 然而、但是、尽管如此、与此相对 |
| 列举 | 其一…其二…、首先…其次…最后 |
| 总结 | 综上、概括而言、上述结果表明、总体来看 |

## 语态与时态
- 全程被动语态：✅"本文构建了非对称XGBoost" ❌"我们构建了"。
- 建模过程过去时（"本文采用 Corrado 秩检验，结果表明…"）；普遍规律/结论现在时；图表引用现在时（"如表X所示"）。

## 图表分析三段式
描述（客观数据特征）→ 解读（机制/原因）→ 结论（建模选择/理论启示）。行数不是指标，三段齐不齐才是。

图在正文里先引后出、出现后有解释。常见误区：连续堆两三张图，再统一补一句"结果如图所示"——每张图各自要回答什么就丢了；而图表数量本身不是得分项（【观察】国奖样本的图表量都在几十的量级，那是内容量的副产品，凑数只会产出没有解读的图）。

## 统计结果报告规范（每个数值结果三要素）
```
1. 效应量：点估计（CAR=-0.57%、Rank IC=0.192）
2. 不确定度：标准误、置信区间、p 值
3. 实质性解读：这个效应在业务上意味着什么
```
推荐："CAR 在[-3,+3]窗口内均值为-0.57%（95%CI: [-0.63%, -0.51%]），Corrado Z=-166.54，p<0.001。扣除 0.50% 双边摩擦成本后净 CAR 为-0.07%，表明全样本事件不具备可交易的经济价值。"

不推荐：
- "p<0.05，显著"——只给判据不给效应量，读者无法判断这个"显著"有没有实际意义（大样本下几乎必然显著）；
- "模型效果很好"——无量化，等于没说；
- "这回答了问题X的要求"——刻意点题，评委自己会对题，这句话占掉的是本该放数值的位置。

## 业务解释自然融入
结论→证据→理论顺序："CAR 显著为负（均值-0.57%，Corrado Z=-166.54，p<0.001），与代理成本理论预期一致——高比例质押触发投资者对公司治理风险的规避行为。"

# 数学建模严谨性审查（每个建模决策回答三问）

1. **为什么选这个模型？** → 模型对比表（AIC/RMSE/p 值对比替代方案）
2. **假设条件是否满足？** → 诊断检验（正态/异方差/自相关/VIF）——交 `statistical-diagnosis` 出 DIAGNOSIS_REPORT.md
3. **结论对模型选择的敏感度？** → 灵敏度分析（改参数/改方法）——交 `sensitivity-analysis` 出 SENSITIVITY_REPORT.md

## 常见统计谬误及规避
| 谬误 | 表现形式 | 规避方法 |
|------|---------|---------|
| 大样本谬误 | N=200,000 时 p 总是 <0.001 | 报告效应量+经济显著性阈值 |
| 多重比较 | 同时检验 8 类事件不校正 | BH-FDR 或 Bonferroni |
| 数据窥探 | 全样本筛选特征再交叉验证 | Purged WF CV 严格时序分割 |
| 幸存者偏差 | 只用沪深300回测 | 明确样本范围，讨论外推局限 |
| p-hacking | 试多个 θ 直到显著 | 预设搜索范围，报告全部结果 |

## 公式书写规范
- 变量首次出现即定义（符号+含义+单位）；全文统一连续编号，不按章重编。
- 复杂公式分层拆解（基础层→中间层→输出层，每层独立编号）；引用写"式(X)"而非"公式(X)"。

## 算法步骤书写规范
```
Step1: [名称] — [具体操作]
Step2: [名称] — [具体操作]
复杂度：O(...)或迭代次数上限
```
推荐：输入 → 目标函数 → 约束 → 输出逐步写出。
不推荐："本文使用 SLSQP 求解"——评委据此无法判断问题是否被正确建模，也无法复现。

# 华数杯/国赛内容范式（2026 实战沉淀，详见 huashubei-writing-guide.md）

- **结果数字一条链**【不变量】：附件数据 → 程序输出 → 论文数字 → 附录复算，全程可复现可核对；改脚本重跑后做「论文数字↔csv」一致性核对，零漂移才确认无害。华数杯 2026 的实测教训就是改了脚本没回改论文。
- **章节要点**：问题重述自组织词句、问题分析不写结果、假设三来源、符号说明三栏表、每问三段式带检验闭环——已在上方「官方内容规范速览」逐条展开，这里不再复述口径（多一套复述就多一套漂移的机会）。
- **特殊值表注**：负值/0 值/负 R²/恒定量加 * 与表注（措辞见 guide 2.2）。docgate 未实现表注抽查，这一条只能人工过。
- **AI 声明**：【事实】正文后、参考文献前。
