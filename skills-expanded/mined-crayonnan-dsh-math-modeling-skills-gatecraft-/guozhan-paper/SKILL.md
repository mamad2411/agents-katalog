# 国奖论文写作范式（基于 2023C/2024C/2025C 获奖论文实测提炼）

## 触发词
- "国奖"、"获奖论文"、"对标"、"论文档次"、"范式"、"怎么写摘要"、"问题重述"、"模型检验"

## 何时读哪个文件

| 要做的事 | 读 |
|---|---|
| 写摘要/分析/检验/灵敏度/附录之前 | 本文件 |
| 想看某条写法的**原文出处**（页码、正例原句、反例详文） | `references/evidence-corpus.md` |
| 格式数值（字号/边距/行距/文献/AI 声明位置） | `../../assets/official-paper-format.md`【事实】 |
| LaTeX 骨架、三线表、matplotlib 中文坑 | `math-paper-template` |
| 通用内容规范与严谨性审查 | `math-modeling-paper` |
| 规则冲突时谁说了算、一条规则该写多硬 | `paper-gate`「规则分级约定」 |
| 交付前机械检查 | `paper-gate` G3 / `../../assets/docgate.py` |

**分工**：本 skill 管"国奖档次的内容范式"（怎么写才像一等奖）；`math-modeling-paper`
管通用内容规范与严谨性审查；`math-paper-template` 管排版工程。

**本文件的性质**：全部来自 5 篇获奖样本的归纳, 属分级约定里的**【观察】层**——
它描述"国奖样本里常见什么", 不描述"官方要求什么"。与官方模板冲突时以官方为准；
与 `docgate.py` 的机械判定冲突时以 docgate 为准。样本出处见 `references/evidence-corpus.md`。

# 1. 章节骨架（国奖样本常见顺序）

```text
摘要 + 关键词（第1页）
一、问题重述
    1.1 问题背景（2-3句，引出价值与痛点）
    1.2 题目信息（题干关键条款 bullet 化：数据形式、已知条件、隐含约束）
    1.3 待求解问题 + 总体技术路线图（每问 1 句复述；图见 3.7）
二、模型的假设（每条 1 句且"可辩护"：短期性/无竞争/数据可信等）
三、问题分析（总览段 + 每问 3 层递进，见 3.1）
四、符号说明（表格：符号 | 含义 | 单位）
五、数据收集与预处理（筛选 → 清洗 → 特征工程 → EDA；诊断证据在此产出，见 3.8）
六~九、问题一~四：每问七段式（C023 实测）
    x.1 问题分析（含每问流程图）    x.2 数据预处理（先诊断后定模型形式）
    x.3 模型建立（含候选对比表）    x.4 模型求解（Step1-N 算法步骤）
    x.5 结果可视化（带阈值线/置信带） x.6 检验 / 敏感性
    x.7 结论（编号分条、每条带数值，独立成节）
十、模型的灵敏度分析（或并入问题末；C023 为每问内嵌式，二者取一但要闭环）
十一、模型的评价与推广（优点/缺点/推广，写具体不写空话）
参考文献
末章、AI 使用记录（合规披露：工具名+用途；未使用则写"未使用 AI 技术"，见 3.6）
附录 A/B/C（见 §6）
```

【观察】五篇语料都用了这个顺序, 且每问的七段结构完全一致——一致性的收益是评委可快速定位,
不是格式本身有什么魔力。若某问确实没有"数据预处理"这一步, 省掉该段比硬凑一段空话好。

【事实】假设条数、正文页数、行距、字号一律以当届官方模板为准
（页数速查 `../../assets/paper-gate-rules.yaml` `pages.by_event`；其余见 `official-paper-format.md`）。
样本里的假设 4-6 条、正文 24-30 页都是**个体选择**, 不是规范——
历史上就发生过把获奖样本的"≤35 页/1.5 倍行距"误升格为规范的漂移。
附录代码可以很长（C023 正文 24 页 + 附录 97 页）。

【不变量】图表全文连续编号、图/表前缀分离、正文引用集合 ⊆ 题注集合——由 docgate [02] 机械核对, 不必手数。

# 2. 摘要写法（国奖实证 4 段式）

```
[背景段 2 句]：一句话点明研究对象与痛点（如"现有方案忽略个体差异；时点过早检测失败率升高，过晚有安全风险"）
 [问题一&二各一段] 方法 → 结果（带具体数值：R²、AUC、误差率、收益金额、p 值等）
 [问题三&四各一段] 同上
 [可选灵敏度段 1 句] 对参数扰动的稳定性结论
关键词：通常 4-6 个，具体数量与分隔符以当届官方模板为准
```

【事实】篇幅的唯一硬约束是含关键词控制在 A4 一页以内（`official-paper-format.md` §四）。

【观察】国奖样本每问 2-3 句、全文 550-1000 字。**字数是结果不是目标**——
决定篇幅的是每问是否都有一个能直接回答题目的量化数值, 而不是凑到某个区间。
为凑字数增删真实内容, 是这条规则最常见的误用。

【不变量】摘要里的每个数字都要能在正文表格找到；正文没做的检验不要在摘要里声称做过
（docgate [04] 机械核对孤例数字, 但它的子串匹配会误报, 见 `paper-gate`「已知局限」）。

推荐/不推荐对照：

- 推荐：「模型准确率 99.7%，独立验证误差 <1.5%」（2025C 问题四原句）
- 不推荐：「模型效果良好，精度较高」
- 推荐：「针对问题一，…首先…进而… 结果显示…」
- 不推荐：把第一段写成全文目录（连续罗列数据预处理、模型体系、四个问题的目标和所有算法）——
  这是常见误区, 后果是背景与问题主线被淹没, 评委读完第一段仍不知道你要解决什么。

缩写首次出现给出全称 + 括号缩写（NIPT 等）。

# 3. 问题的分析+建模+检验 三件套

## 3.1 问题分析（每问 1 段，3 层递进）
```
题干要什么 →（转折出）难点/坑（数据稀疏、重复测量、类别不平衡…）→（因此）用什么工具+为何合适 →（并配）什么检验自证有效
```
范例："鉴于数据存在重复测量与层次结构，选择线性混合效应模型(LMM)+REML，
并以 AIC/BIC 比较模型、检验正态性"——一句话里有难点、选型、理由、检验四件事。

## 3.2 模型建立（正文公式）
- 每个变量的定义先给符号表（符号 | 说明 | 单位），公式给 (编号)、变量下标规范
- 引入约束/推广/扩展时依次罗列公式(3)(4)(5)…
- 多说"为什么这模型"：1-2 句立足问题特性，不罗列教科书
- 方案比选（对比表）：| 方法 | 适用 | 优点 | 缺点 | 本文选择 |

## 3.3 模型检验/诊断（国奖样本最一致的特征）

五篇语料**无一例外**都有独立检验节, 这是国奖与非国奖最稳定的区分点。
"检验四件套"（原始数值与分题型分布见 `references/evidence-corpus.md` §3）：

1. **模型对比**：对数似然值、AIC、BIC 表
2. **检验统计量**：LR(χ²) 或 Wald，给出 χ² 值与 p 值
3. **方差分解**：σ_u²/σ_e²、ICC 并解释其含义
4. **假设诊断图**：Q-Q 图 + 直方图（正态性）+ 残差 vs 拟合（同方差）+ 分类交叉检验

常见误区：写"经检验，模型合理"却不给检验对象与判据——评委无法复核, 等于没检验。
四件套也不必全用：按题型取（回归类要方差分解, 分类类要混淆矩阵与 ROC,
时序类要残差白噪声检验）。判定细则归 `statistical-diagnosis`。

## 3.5 衔接写作的四项要求（R1-R4）

> 论文句子由阶段报告的事实推导（`competition-workflow` 阶段 0.5/1/2 报告先行）；
> 范文原句只作样本, 照搬句式会写出与本文模型不符的话。
> 下面每项给"要求 / 怎么判 / 正反例指针", 正反例详文与页码在 `references/evidence-corpus.md` §4。

### R1 定位陈述（每问开头）
- **要求**：每问开头陈述与前问在模型层面的事实差异：①共享构件（决策变量/公式/参数）；
  ②新增或改变的构件；③改变原因（题目新增条件 / 变量类型 / 数据规模 / 口径）。
  两问同构则显式声明复用。
- **怎么判**：对两问的决策变量集、约束集、目标函数做集合差, 然后问——
  开头段覆盖了哪些差异项？漏掉的那几项, 是评委看不出来还是看不出来会误判？
  常见误区：只写"在问题一基础上进一步考虑"而不说清变的是哪个构件、为什么变,
  评委无法判断这是真递进还是套模板。
- **正反例**：2023C p24（正）/ 2026 华数杯 7.1（反）——详文见 evidence-corpus §4。

### R2 选型依据（每个主要模型）
- **要求**：每个主要模型的选型依据至少满足其一：①数据结构证据（指明哪条数据发现
  推出该设计）；②对比证据（候选模型实测比较并报指标差异）。
- **怎么判**：对每个模型问"为什么是它、为什么不是最简备选"——正文能答且指向数据或实验就够了。
  出现"本文采用 X 模型"而前文没有任何依据, 是评委最容易扣分的地方。
- **写法分工**：问题分析章给选型结论, 正文建模节开头用 1-2 句重述动机；
  候选比选表置于正文建模节。
- **正反例**：2023C LSTM 选型（正, 但未报对比数值）/ 2026 华数杯（依据全前置, 正文未重述）。

### R3 结果解释闭环（每个关键结果）
- **要求**：每个关键结果依次给出：①数值；②机制解释（为什么是这个数）；
  ③外部一致性核验（常识 / 理论预期 / 独立口径基准）。
- **怎么判**：逐条过关键结果表, 问三段各在哪一句。缺的通常是③——
  数值算出来了、机制也编出来了, 但没有任何独立口径能佐证这个量级合理。
- **数量级跳变要特别处理**：跨数量级或反直觉的结果, 机制解释要**紧挨着**结果写。
  分散在后页等于没写——docgate [04] 的数量级哨兵就是为这个场景加的。
- **正反例**：2023C 七日收益 p22（三段齐全）/ 2026 华数杯碳排 204.5 万吨→62.3 吨
  （机制写了但不在跳变旁边）。

### R4 构件复用声明（跨问）
- **要求**：跨问复用的符号、公式、参数显式声明复用；符号定义全篇唯一；
  新增构件与复用构件可区分。
- **怎么判**：符号表 + 公式编号审计——每个符号定义唯一吗？每处跨问引用有显式指认吗？
  一句"本问同样采用问题二中的公式 7"就够, 成本极低。
- **正反例**：2023C p24、2026 华数杯 p24（两篇均达标, 未见明确违规项）。

优化类求解与验证决策表见 `../../assets/optimization-playbook.md`。

## 3.6 严谨性用语规范

- **主张分级**：每处结论标注证据等级 A=数据复算支持 / B=理论推导支持 / C=定性论证。
  C 级论证写成 A 级事实是最常见的越级（如"验证了模型的准确性"却没有对应的核验动作与结果）。
  措辞上限的完整映射见 `paper-gate` G1 声明强度校准表。
- **无依据词**：无数值的"显著提升"、未经证明的"最优"、"完美"、"完全一致"
  （除非有逐项核对记录）。问题不在词本身, 在于读者无法复核。
- **范围声明**：分析/复算类内容写明覆盖范围与未覆盖项（如"未复算数值"）。
  主动划边界比被评委发现边界更划算。
- **摘要↔正文↔表格三方对账**【不变量】：摘要每个数字映射到正文某张表；
  改写摘要时不要产生新数字。docgate [04] 机械核对。
  反例（大湾区杯摘要与正文方案完全无关）详文见 evidence-corpus §5。
- **表内列间数学自洽**：同表各列若存在数学关系就要成立
  （λ↔半衰期=ln2/λ、权重和=1、增长率↔基期、CAGR↔份额）。逐列验算。
  **docgate 未实现此项**, 只能人工过——反例（泰迪杯 λ=0.010 半衰期写成 9.3 天）见 evidence-corpus §5。
- **AI 痕迹规范**：正文不出现工具名/模型名标注（如"[GPT-5, OpenAI 计算得到]"）；
  引用的模型名要真实发布；统一在附录"AI 使用记录"披露
  （C023"未使用 AI 技术"亦是合规披露）。【不变量】由 docgate [03] 机械扫描：
  参考文献区命中 → FAIL（官方明文）, 正文命中 → WARN。
- **方法-样本量匹配**：n<5 时熵权/CRITIC 赋权没有统计意义（Min-Max 归一化在 n=2 退化为 0/1）；
  正类 <20 时 AUC/精确率不可靠；比例/百分比变量的系数解释要核对量纲
  （0.782 vs 0.00782 差 100 倍）。每个表观指标后面跟着样本量。
  判定细则归 `statistical-diagnosis`, 案例见 evidence-corpus §5。

## 3.7 流程图两层规范

- **第 1 层·总体技术路线图**：四问方法链串联, 问题间箭头标注**传递物**
  （如"浓度模型→达标概率 p(t,b)→DP 输入"）；置于 1.3。
- **第 2 层·每问流程图**：四阶段骨架——①数据 ②模型 ③约束与检验 ④求解与敏感性；
  **节点内容用本问关键词**（"保障率约束""单调性约束""k=2 聚合"直接进框）；
  置于 x.1 之后；四框与正文四节一一对应。
- **怎么判**：随便指一个节点, 它的文字能回答"本问做了什么"吗？
  常见误区：节点写"数据预处理→模型建立→求解→检验"这类任何论文都通用的空泛步骤词,
  于是流程图变成了装饰；另一类误区是把关键设计（如防泄露的 Purged WF）埋在正文段落里
  而不画进节点, 评委扫读时看不见。
- **备注**：方案比选用对比表呈现, 不必画成分支菱形；保持顺序四阶段, 避免过度复杂。
  实测出处（C023 图2/3/7/9/10 页码）见 evidence-corpus §6；
  四阶段节点对照表与图型模板见 `../../assets/figure-playbook.md`（含规格→drawio/PNG 生成与 OCR 读回复核）。

## 3.8 先诊断、后建模

- **要求**：每问建模前有一句"诊断结论→模型形式"的因果声明, 诊断证据为图或表
  （热力图/分布图/对比表）。
- **怎么判**：找到"本文采用 X 方法"那句, 往前翻——前文有没有诊断依据？
  常见误区：先宣布方法再补数据（大湾区杯问题一"本文采用 AHP-熵权-CRITIC-PCA 组合赋权"）,
  评委读到的是结论而不是推理。
- **正反例**：C023 热力图→"非单调→排除简单线性→引入二次项"（p5-6）、
  表2 MixedLM vs GLM（AIC 712.63 vs 749.92、LR=41.29）→选定 LMM（p7）；详文见 evidence-corpus §7。

# 4. 灵敏度 / 稳健性分析
```latex
\section{模型的灵敏度分析}   % 或并入问题末
调参方式：±5% / ±10% / 扰动成本区间；
呈现：表格（参数取值 | 关键输出（利润/准确率）| 变化率）+ 1-2 句结论
落点："参数波动对目标影响较小 / 结果保持稳定 → 模型稳健"
```
【观察】2024 国奖动态调参 4 个不确定参数后写"总利润与问题三中差距极小，模型稳健"——
这句是拿分点, 但拿分的原因是它交代了**扰动了什么、比对了什么、结论是什么**三件实事。
只写"模型具有良好的稳健性"没有这三件, 就是空话。

方法选择按题型自适应, 归 `sensitivity-analysis`（分档规则以该 skill 为真源）。
【不变量】正文没有做灵敏度或稳健性检验时, 摘要不要声称做过。

# 5. 图表与表格规范
- 表格：三线表（顶/中/底横线），列宽紧凑，数字对齐；表题在表上、中文；表内列给出单位
- 图形：双幅子图（散点+拟合 / 箱线+残差）；热力图(相关性)；坐标轴中文 + 单位
- 图题在图下、正文先引后出（凡引必见图）
- 【事实】真约束是**图内文字的最终打印字号 ≥9pt**；dpi 只是达成手段, 统一取 300
  （figsize 宽 ≈ 显示宽的换算见 `math-paper-template`；`bbox_inches='tight'` 会破坏该换算, 见 `huashubei-writing-guide` 2.1）
- 【观察】国奖样本的图表量都在几十的量级（2023 篇 24 表；2024 篇 32 图）——
  这是内容量的副产品，不是目标带。每张图/表在正文里是否都被引用并解释了结论, 比总数重要;
  凑数会产出没有解读的图。样本计数与"为什么不给配额"见 evidence-corpus §8。
- 【不变量】编号连续性与引用对账由 docgate [02] 机械核对, 不必人工数。

## 7. 交稿前自查（问句版）

**先跑机械检查, 再读下面的问句。**
`python ../../assets/docgate.py <最终提交文件>` 已覆盖：图表编号对账与引用、AI 工具名扫描
（含参考文献区）、摘要孤例数字与数量级哨兵、错别字与标点残骸、变量解释空残骸、
图片几何、篇幅失衡提示、结构形态提示、页边距。这些不必人工逐条数——
完整协议与判级见 `paper-gate` G3。

下面是 docgate **覆盖不了**的部分, 靠人判断：

**内容与统计**
- 每问是否都有一个能直接回答题目的量化数值？（摘要里那个数在正文哪张表？）
- 每个主要模型的选型依据, 是指向数据发现还是指向对比实验？只有"本文采用 X"的段落还剩几处？
- 关键结果是否都有①数值②机制③外部核验三段？缺的是哪一段？
- 模型对比表 / AIC-BIC 表存在吗？表里的数值能对上代码输出吗？
- 表内列间数学关系逐列验算过了吗？（λ↔半衰期、权重和=1、CAGR↔份额——docgate 不查这项）
- 每个表观指标后面跟着样本量吗？n<5 的赋权、正类<20 的 AUC 还在吗？
- 本地复算过吗？论文里每个数值与代码输出零漂移？

**结构与呈现**
- 每问开头有没有 R1 定位陈述（继承/新增/变因）？漏了哪个差异项？
- 每问有没有流程图, 且节点文字是本问关键词而不是通用步骤词？
- 每问有没有独立结论节, 且每条带数值？
- 灵敏度节有没有"扰动了什么/比对了什么/结论是什么"三件实事？
- 评价与推广写的是具体优缺点, 还是"具有一定的参考价值"这类空话？
- 附录有没有材料清单 + 完整可运行代码（无占位符残留）？

**格式（以官方模板为准）**
- 页数/字号/行距是否对照过当届官方模板？超页时先删的是冗余描述还是检验闭环？（后者是负优化）
- AI 声明位置对不对（正文后、参考文献前）？
- 参考文献是否达到官方下限、格式一致、正文引用处与文末条目一一对应、每条真实可核？
