# Channel Notes

Channel notes are a channel-scoped crystallization layer: one short Markdown note per channel.

Use them for:
- Decisions that have converged in this channel
- Deferred items / non-goals
- Open questions
- Next steps

Do **not** use them for:
- Global user preferences or hard constraints (use `remember`)
- Stable project operating rules (use `AGENTS.md`)
- Long design documents (use `docs/proposals/*` or a task/note)
- Raw task logs or transient stream-of-consciousness

Keep notes short. Prefer whole-document cleanup over append-only growth.
