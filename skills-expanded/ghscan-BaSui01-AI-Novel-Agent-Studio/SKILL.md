# 人设一致性检查（OOC）

在评价或修改涉及角色言行的文本时，按下列清单核对。**不得**因本 skill 调用额外工具；仅使用当前角色已可见的工具。

## 检查项

1. **语音特征**：口癖、语气、用词层级是否与角色卡 / 世界状态中的 speech_style 一致
2. **动机一致性**：行为是否符合已知动机、禁忌与关系网；突然改口需有情节依据
3. **能力边界**：是否越权使用尚未获得的技能/情报/身份
4. **情绪连贯**：情绪跳变是否有触发事件；避免无铺垫的性格翻转
5. **称谓与关系**：对他人称谓、敬语是否匹配当前关系阶段

## 输出建议

- 列出具体 OOC 片段（引用原文短句）
- 说明冲突的设定来源（角色卡字段 / 前文事件）
- 给出最小改写建议，避免重写整段
