# Plain language

- Put the most important fact first.
- Use one idea per sentence and keep sentences under 25 words.
- Prefer common words: "use" instead of "utilize", "start" instead of "initiate".
- Name the actor: "Support replies within one day", not "A reply will be provided".
- Define a technical term the first time it appears, or replace it.
