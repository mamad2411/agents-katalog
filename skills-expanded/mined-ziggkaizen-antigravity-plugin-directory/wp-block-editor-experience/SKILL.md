# WordPress Block Editor Experience

Use this skill when the block exists but its editing experience, discoverability, or parity needs design or review.

## Procedure

1. Identify the user's editing task and the minimum controls required.
2. Use native WordPress components and placement conventions.
3. Separate content editing from advanced configuration.
4. Define insertion, selection, empty, loading, error, and disabled states.
5. Configure InnerBlocks, templates, allowed blocks, locking, variations, and transforms deliberately.
6. Verify keyboard, focus, labels, announcements, zoom, and narrow layouts.
7. Compare editor and front-end structure, dimensions, typography, and interactions.
8. Test with realistic content extremes.
