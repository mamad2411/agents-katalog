# WordPress performance remediation and validation

Use this skill only after measurable evidence and a specific hypothesis exist.

## Responsibilities

- prioritize by user impact, confidence, effort, risk, and reversibility;
- define the controlled change and expected metric movement;
- preserve correctness, security, privacy, accessibility, and data integrity;
- benchmark equivalent before/after states;
- test negative, personalized, stale-cache, failure, and rollback cases;
- produce a transparent report.

Use [performance-finding-template.md](resources/performance-finding-template.md), review [example-audit-report.md](examples/example-audit-report.md), and run [validate-performance-remediation-workflow.md](workflows/validate-performance-remediation-workflow.md).
