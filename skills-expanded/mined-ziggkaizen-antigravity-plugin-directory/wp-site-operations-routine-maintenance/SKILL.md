# wp-site-operations-routine-maintenance

Use this skill for periodic operational reviews.

## Boundary

Routine maintenance should discover and prioritize work. Findings that mutate production should become separate approved changes unless the maintenance window explicitly covers them.

## Workflow

Use [`workflows/run-wordpress-routine-maintenance-workflow.md`](workflows/run-wordpress-routine-maintenance-workflow.md).

## Resource

Use [`resources/routine-maintenance-checklist.md`](resources/routine-maintenance-checklist.md).

## Completion Evidence

Produce a dated maintenance record with evidence, severity, owner, next action, due date, accepted risk, and any separate change or incident records.
