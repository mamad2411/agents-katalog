# ADR Writing

Use this skill to create or review architecture decision records.

## Process

1. Identify the decision, not just the topic.
2. Capture current context and constraints.
3. List considered options.
4. State the selected option.
5. Explain consequences and accepted tradeoffs.
6. Document risks and follow-up triggers.
7. Link related docs, issues, or prior decisions when available.
8. Keep implementation details version-specific only when verified.
