# GitHub Actions Release and Deployment Review

Use this skill when workflows deploy, publish, release, sign, attest, promote artifacts, or alter external environments.

## Review Focus

- protected environments
- approvals
- OIDC and cloud auth
- minimal write permissions
- concurrency
- artifact provenance
- rollback readiness
- release evidence
- manual dispatch input safety
