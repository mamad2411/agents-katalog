# Repo Issue Breakdown

Use this skill when an issue is too broad to implement or review safely.

## Breakdown Goals

- create small actionable units
- preserve context
- avoid mixed bug/feature/task issues
- define acceptance criteria
- identify dependencies and sequencing
- avoid creating tracker noise
