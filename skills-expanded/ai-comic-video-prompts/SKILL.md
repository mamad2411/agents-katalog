# AI 漫剧单镜头视频提示词转换技能

本技能接在 ai-comic-storyboard 之后：分镜表已经写好，现在把每个镜头改写成 AI 视频工具更容易理解的完整单镜头提示词，方便逐条复制到 Vidu 等工具生成视频素材。

核心目标：**镜头能看懂，角色不变脸，场景不跳变，动作能接上，台词和音效写进提示词。**

## 核心原则

1. **所有回复使用中文。**
2. **一镜一提示词**：每个镜号只输出一条完整提示词。台词、画外音、音效必须写进"完整提示词"里，不要拆成独立列。
3. **忠于分镜表**：不改变镜头顺序、不新增剧情、不改原台词。必要时可把分镜里的抽象情绪翻译成可见动作。
4. **保持参考一致性**：提示词开头必须说明人物五官、发型、服装、年龄感、气质、场景结构、画风与参考图保持一致。
5. **动作写完整过程**：写清动作起始、动作变化、动作结果，不要只写"紧张/害怕/震惊"。
6. **场景必须有动态**：补充光线变化、雨水、风声、屏幕光、灯光闪烁、背景空间等环境状态，避免静态硬照感。
7. **限制项必带**：每条提示词末尾都要有稳定性限制，尤其是人物不变脸、不换发型、不换服装、场景不跳变。
8. **所有产出落盘**：单镜头提示词、素材生成记录、筛选补镜记录和质检清单都写入项目文件夹。

## 工作流程

### 阶段零：定位分镜和素材来源

1. **扫描当前目录**，查找 AI 漫剧项目文件夹。优先识别：
   - `00_剧本概览.md`
   - `07_视觉资产/`
   - `08_分镜脚本/`
2. **读取目标集分镜表**：
   - 默认读取 `08_分镜脚本/01_第01集_完整分镜表.md`
   - 用户指定第X集时，读取 `08_分镜脚本/01_第XX集_完整分镜表.md`
   - 如果用户只给片段分镜，读取对应 `01_第XX集_片段名_分镜表.md`
3. **读取素材索引**：
   - `07_视觉资产/00_视觉资产总览.md`
   - `07_视觉资产/01_人物提示词.md`
   - `07_视觉资产/02_场景提示词.md`
   - `07_视觉资产/03_道具提示词.md`
   - 分镜表中的"使用素材"列
4. **没有分镜表时**，不要从剧本直接生成视频提示词；提示用户先用 ai-comic-storyboard 生成分镜表，或让用户粘贴包含镜号、景别、运镜、画面内容、台词音效、时长、使用素材的分镜片段。
5. **检查是否已有提示词产物**：
   - 如果已有 `09_视频提示词/`，先读取总览和目标集提示词文件。
   - 生成第2集及后续集数时，禁止覆盖已有提示词、生成记录或筛选记录；目标文件存在时，除非用户明确要求修改，否则另存为 `_v2` 或先询问。

### 阶段一：检查分镜是否能直接转提示词

逐镜检查分镜表。每个镜头至少要有：

1. 镜号
2. 景别
3. 运镜
4. 画面内容
5. 人物动作 / 表情
6. 台词 / 画外音 / 音效
7. 预估时长
8. 使用素材

如果某个镜头只有抽象表达，如"女主很害怕"，先补成可见动作：后退半步、瞳孔微缩、手指发紧、呼吸变轻、眼神闪烁等。

### 阶段二：生成单镜头 Vidu 提示词

每条提示词必须包含以下信息：

| 模块 | 写法要求 |
|------|----------|
| 参考图一致性 | 保持同一角色/场景/道具参考图：五官、发型、服装、年龄感、气质、画风、场景结构不变 |
| 素材调用 | 写清调用哪些人物主体、场景母版、道具图或关键帧；缺素材则标 `待补素材_名称_用途` |
| 镜头语言 | 景别 + 运镜 + 节奏，如 `近景，缓慢推镜头` |
| 动作过程 | 动作起始、动作变化、动作结果 |
| 情绪可视化 | 把紧张、震惊、压抑等翻译成眼神、手部、呼吸、身体姿态 |
| 场景氛围 | 光线、色调、天气、空间、环境动态、悬疑/甜宠/压迫等氛围 |
| 台词与音效 | 原台词不改；画外音要标注；环境音、动作音、情绪音写进提示词 |
| 画质描述 | 电影级光影、超写实、高细节、4K画质、画面稳定、质感细腻 |
| 限制项 | 无画面畸变、无模糊、无结构错误、无多余肢体、无重复人脸、人物不变脸、不换发型、不换服装、场景不跳变 |

#### 提示词模板

```Markdown
保持参考图中的【角色/场景/道具】一致：【人物五官、发型、服装、年龄感、气质】保持不变，【场景结构、光线、色调、画风】保持一致。镜头语言为【景别 + 运镜 + 节奏】。画面中【人物/主体】位于【空间位置】，动作从【起始动作】开始，随后【动作变化】，最后【动作结果】。人物表情与情绪表现为【可见表情/眼神/手部/身体反应】。场景为【具体环境】，包含【光线/天气/背景动态/关键道具】，整体氛围【情绪关键词】。台词/画外音：【保留原台词】。音效：【环境音】；【动作音】；【情绪音】。电影级光影，超写实，高细节，4K画质，画面稳定，质感细腻。无画面畸变、无模糊、无结构错误、无多余肢体、无重复人脸、人物不变脸、不换发型、不换服装、场景不跳变。
```

### 阶段三：输出文件

有剧本项目时，在项目文件夹内创建 `09_视频提示词/`；没有项目时，在当前目录创建 `【剧名或项目名】_视频提示词/`。

推荐结构：

```text
09_视频提示词/
├── 00_视频提示词总览.md
├── 01_第XX集_单镜头Vidu提示词.md
├── 02_第XX集_素材生成记录.md
├── 03_第XX集_素材筛选与补镜记录.md
└── 04_第XX集_成片质检清单.md
```

#### 防覆盖规则

- **每集独立文件**：第1集用 `01_第01集_单镜头Vidu提示词.md`，第2集用 `01_第02集_单镜头Vidu提示词.md`。
- **目标文件存在时禁止覆盖**：生成前检查目标文件是否存在。存在时不要覆盖；除非用户明确要求修改该集，否则另存为 `_v2` 或先询问。
- **总览只追加/局部更新**：`00_视频提示词总览.md` 是全剧索引，第2集及后续集数只追加 `## 第XX集` 段落。
- **记录按集追加**：素材生成记录、筛选补镜记录、成片质检清单按集单独建文件；同名文件存在时遵守目标文件防覆盖规则。

#### 单镜头提示词表

默认输出四列：

| 镜号 | 使用参考素材 | 完整提示词 | 预估时长 |
|------|--------------|------------|----------|

如果用户要求严格沿用教程格式，输出三列：

| 镜号 | 完整提示词 | 预估时长 |
|------|------------|----------|

注意：不要把台词、画外音、音效单独拆列；它们必须写入"完整提示词"。

### 阶段四：生成版本记录表

为每个镜头预留 2-3 个版本：

| 镜号 | 版本 | 生成策略 | 是否可用 | 问题 | 最终选择 |
|------|------|----------|----------|------|----------|
| 01 | v1 | 按原提示词生成 | 待填 | 待填 | 待填 |
| 01 | v2 | 降低动作幅度 | 待填 | 待填 | 待填 |
| 01 | v3 | 强化画面稳定和表情一致性 | 待填 | 待填 | 待填 |

不要为用户虚构已生成结果；如果用户还没有生成素材，`是否可用/问题/最终选择` 写 `待填`。

### 阶段五：素材筛选、补镜和质检

输出前读取 [references/video-prompt-quality-check.md](references/video-prompt-quality-check.md)，生成筛选和质检清单。

筛选原则：

```Markdown
能看懂剧情 + 人物不明显崩 + 场景不明显跳 = 可先保留
```

常见需要补镜的情况：

1. 两个镜头接不上
2. 人物动作突然跳变
3. 情绪转折太突然
4. 关键道具没有交代清楚
5. 结尾悬念不够强
6. 台词太长但画面撑不住

优先补：人物反应镜头、手部特写、道具特写、环境空镜、转身/低头/抬眼等过渡动作。

## Vidu 基础生成建议

1. 画面比例：9:16 竖屏。
2. 分辨率：1080P 高清。
3. 帧率：25fps 或 30fps。
4. 视频时长：按分镜表预估时长，通常 1-4 秒。
5. 同一镜头至少生成 2-3 版备用。
6. 环境镜头优先调用场景母版；人物镜头优先调用人物主体 + 场景母版；道具/脚步/手机等镜头可用关键帧或道具图。
7. 如果后续镜头需要延续前一镜场景和光线，建议从前一镜抽取稳定关键帧作为参考图。

## 注意事项

1. **不要把抽象情绪直接丢给 AI**：害怕写成后退半步、瞳孔微缩、手指发紧；紧张写成呼吸变轻、肩膀绷紧、眼神闪烁；震惊写成猛地停住、嘴唇微张、眼神定格。
2. **不要让提示词失去镜头感**：每条都要包含景别和运镜。
3. **不要遗漏声音**：没有台词的镜头也要写环境音、动作音或情绪音。
4. **不要虚构素材已经生成**：提示词阶段只产出生成指令和记录表，素材可用性等用户生成后再填写。
5. **不要实际操作剪辑软件**：本技能可以生成剪辑前检查表和导出建议，但不负责剪映/Premiere 操作。
