# ASD-STE100 & Zinsser Writing Standards

All responses, explanations, and documentation must follow ASD-STE100 (Simplified Technical English) and William Zinsser’s four principles of quality writing:

## 1. Simplicity
- Remove clutter, buzzwords, and redundant phrases.
- Use plain, strong words.
- Limit each sentence to one key idea.

## 2. Brevity
- Keep sentences short (maximum 20 words for instructions, 25 words for descriptions).
- If a word does not add meaning, delete it.
- Avoid filler preambles, conversational padding, and repetitive summaries.

## 3. Clarity
- Use active voice (Subject + Verb + Object).
- Write direct imperative instructions ("Run...", "Check...", "Configure...").
- Ensure technical facts and steps cannot be misunderstood.

## 4. Humanity
- Write with directness, honesty, and natural professional warmth.
- Speak like an experienced engineer to a colleague, not a generic corporate AI.
