# 搜查令

搜查令回答“要查什么”，可以交给探子、探子 Pro、其他信息采集 Skill、MCP、Agent 自带搜索或未来能力执行。它不替保洁判断资料含金量，也不把关键词优先级改写成证据等级。

## 选择模式

按任务选择一种主模式，必要时组合，但不要把三套清单机械全跑：

1. **行企研搜查令**：行业、市场、产业链、商业模式、竞争、公司、财务、PEST 外部环境、趋势、驱动力或痛点。先读取[行企研搜索设计](references/行企研搜索设计.md)；任务对应行企研专项 Skill 时，再读取[行企研专项关键词组件](references/行企研专项关键词组件.md)中相应一节。
2. **用研搜查令**：公开用户需求、评论、体验、购买、流失、替代、潜在需求、职业社群与沉默/非消费线索。读取 [用研搜索设计](references/用研搜索设计.md)。
3. **舆情热点搜查令**：事件传播、观点阵营、情绪变化、关键节点、平台差异、互动与反转。读取 [舆情热点搜索设计](references/舆情热点搜索设计.md)。

通用材料类型和关键词构造读取 [搜索维度与材料清单](references/搜索维度与材料清单.md)。涉
及具体产品、公司、品牌或社群时，读取 [对象扩展与社群采集指令](references/对象扩展与社群采集指令.md)。平台表是“包括但不限于”；按当时可用渠道扩展。

## 工作流

关键词优先使用公开材料中常见、直接关联问题的重要词，不将分析表的维度逐项变成必搜词。带回字段是采集提示：原文有就保留，没有则注明；需要推算或加工的内容留给分析环节。

1. 明确研究问题、主对象、包含/排除、地域、时间窗和本轮需要带回的字段。
2. 选择主模式与适用观察角度。行企研任务还要标明“行业研究”或“企业研究”视角，以及对应的专项 Skill；单项研究只选一个专项组件，完整研究只组合已确定要调用的专项组件。
3. 生成多组关键词组合：覆盖主对象的中文名、英文名、简称、旧称、别名和同义词，并向上扩展所属品类、向下扩展细分对象，同时加入相邻对象、替代对象、指标、事件、材料类型、使用场景、地域、时间范围、限定词和排除词；不得只用一个关键词搜索一次便结束。
4. 同时设计支持、反例、负面、失败、退出、替代和“未发生/不采用”方向的查询。
5. 涉及社群时逐平台写搜索词、目标内容、需带回字段和样本范围；不以通用网页搜索替代平台内讨论。
6. 将搜索任务拆成可并行的任务包，交给当时可用的信息能力；搜查令不规定只能使用某个采集工具。

## 输出

```text
搜查令模式：行企研 / 用研 / 舆情热点 / 组合
研究视角：行业研究 / 企业研究 / 用户研究 / 舆情热点
对应专项 Skill：
研究问题：
主对象、相邻对象与排除对象：
地域 / 时间窗 / 语言：

任务包｜待查问题｜关键词簇｜目标材料或平台｜需带回字段｜对象/时间/地域限定｜反例与排除词

平台专项任务：平台｜搜索词｜目标内容｜需带回字段｜样本范围
采集结果统一字段：链接｜标题/原文标识｜主体｜发布时间｜内容/摘要｜对象层｜公开互动字段（如有）｜抓取时间
```

搜索结果返回后再进入资料审核。搜查令不评价来源优先级，不决定能否引用，也不把单帖互动、少量案例或搜索排序当成总体事实。
