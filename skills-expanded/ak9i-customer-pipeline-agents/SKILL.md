# AK9I Customer Pipeline — Repository Agent Instructions

> **Chat is execution context. GitHub is institutional memory.**

Before substantive work, every AI/project agent must:

1. Fetch/read the current merged default branch.
2. Read applicable governance.
3. Read `control-room/CURRENT_PROGRAM_STATE.md`.
4. Read `control-room/MASTER_PIPELINE_TRACKER.md`.
5. Read `control-room/DEPENDENCY_MAP.md`.
6. Read its applicable charter in `governance/CHAT_LANE_CHARTERS.md`.
7. Read relevant shared and stage contracts.
8. Inspect active work packets in its ownership.
9. Inspect acceptance and integration findings affecting its work.
10. Preserve immutable requirement IDs.
11. Record durable decisions in GitHub.
12. Never use remembered chat state as authority when merged repository state differs.
13. Never place customer/student PII in GitHub; use de-identified references and authoritative-system pointers.
14. Never silently redefine shared lifecycle terms or cross-lane contracts.
15. Surface dependencies through the governed dependency/PCR mechanism.
16. Distinguish assumptions, proposals, observations, and established facts.
17. Never invent business metrics, targets, operational states, approvals, or completed offline actions.
18. Never claim independent acceptance for its own functional output.
19. Update tracker/dependency/current-state artifacts when work materially changes.
20. Leave the repository easier for another lane to understand than it found it.

## Authority order

1. Explicit AK9I executive/user direction.
2. `governance/AK9I_PIPELINE_PROGRAM_AUTHORITY.md`.
3. Other current governance/shared contracts.
4. Accepted work-packet/decision records.
5. Current merged implementation/evidence.
6. Chat context only when not in conflict with the above.

If paths are renamed, locate the current canonical replacement rather than assuming the artifact disappeared.

## Communications rule

Cross-lane communication should normally be durable: work packets, tracker updates, PCRs, dependency records, decisions, evidence, acceptance findings, and integration defects. Do not make the human operator act as an inter-lane API.
