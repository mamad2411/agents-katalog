# ETF量化趋势分析技能

基于ETF资金流向数据，运用"双维度三层"分析框架，对A股市场趋势进行系统化量化判断。

## 分析框架概览

```
输入：日期 → 数据获取 → 三维分析 → 输出报告
                        │
              ┌─────────┼─────────┐
              ▼         ▼         ▼
           大盘趋势   结构性行情  市场情绪
           (宽基ETF)  (行业ETF)  (跨境ETF)
```

## 工作流程

### Step 1: 获取ETF数据

运行数据获取脚本获取当日ETF资金流向数据：

```bash
python scripts/fetch_etf_data.py <YYYY-MM-DD> --detail
```

脚本返回JSON数据，包含：
- 宽基ETF净流入/流出规模（亿元）
- 行业ETF资金流向排名（Top5流入/流出）
- 跨境ETF资金流向
- 主要ETF折溢价率、换手率
- 资金集中度指标

若脚本执行失败（网络问题、非交易日等），通过 WebSearch 搜索补充数据：
- 搜索关键词：`"<日期> ETF资金流向 宽基 行业"`
- 搜索关键词：`"<日期> ETF净流入 东方财富"`

### Step 2: 加载分析框架

读取完整分析框架参考文档：

```
references/etf-framework.md
```

该文档包含：指标体系、判断标准、信号清单、历史案例、十三条核心规律。

### Step 3: 执行三维分析

根据获取的数据，按以下三个维度逐一分析：

#### 维度一：大盘趋势判断（宽基ETF）

基于宽基ETF资金流向，判断大盘所处位置：

| 信号 | 判断 | 置信度 |
|------|------|--------|
| 宽基大额流入(>100亿/日) + 汇金增持 + 成交占比>6% | 底部确认，上涨在即 | ★★★★★ |
| 宽基大额流入(>100亿/日) + 成交占比>6% | 底部区域，可以布局 | ★★★★☆ |
| 宽基持续流出 + 成交占比<4% | 顶部或调整，减仓 | ★★★★☆ |
| 宽基流出 + 行业ETF活跃 | 风格切换，结构性行情 | ★★★☆☆ |

#### 维度二：结构性行情判断（行业ETF）

基于行业ETF资金分化度，判断市场结构：

- 资金集中度>50% → 结构性行情，聚焦主线
- 资金分散流入 → 全面行情，配置宽基
- 资金快速撤离 → 热点退潮，警惕调整

识别当日资金流入Top行业，判断主线方向（科技/消费/金融/周期/红利）。

#### 维度三：市场情绪判断（跨境ETF）

- 跨境ETF溢价>10% → A股资金外流意愿强，A股可能走弱
- 跨境ETF溢价收敛 → A股吸引力回升，A股可能走强
- 跨境ETF换手率>500% → 纯投机炒作，回避

### Step 4: 生成综合信号

将三维分析结果汇总，匹配交易信号清单：

**买入信号**：
- ⭐⭐⭐⭐⭐ 底部确认：宽基连续3日净流入>100亿 + 汇金增持
- ⭐⭐⭐⭐ 趋势启动：宽基净流入>50亿 + 成交占比>6%
- ⭐⭐⭐ 结构性机会：行业分化 + 某行业持续净流入>30亿

**卖出信号**：
- ⭐⭐⭐⭐⭐ 顶部警示：宽基连续3日净流出>100亿 + 成交占比<4%
- ⭐⭐⭐⭐ 调整信号：宽基持续净流出 + 行业ETF快速撤离
- ⭐⭐⭐ 热点退潮：行业ETF净流入转负 + 换手率突增

**观望信号**：
- 方向不明：宽基流入流出交替 + 成交占比稳定
- 风格混沌：行业资金分散 + 无明显主线

## 注意事项

1. **数据时效性**：ETF资金流向数据通常在交易日收盘后更新，盘中数据为估算值
2. **滞后性提醒**：行业ETF资金流向平均滞后大盘约1个月，宽基ETF大额流入是同步/确认信号
3. **国家队影响**：中央汇金等国家队的大规模增持会扭曲宽基ETF资金流向信号
4. **综合判断**：ETF指标权重40%，需结合技术指标(30%)和宏观政策(30%)综合判断
5. **非交易日**：若查询日期为非交易日，提示用户并建议查询最近交易日
