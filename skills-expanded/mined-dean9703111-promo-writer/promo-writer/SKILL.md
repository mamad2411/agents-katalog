# Promo Writer

把一份長篇內容（課程大綱、講稿、逐字稿、筆記）萃取成乾貨，再用作者本人的語氣，寫成一篇有共鳴、能引發報名慾望的宣傳文。

```
長篇來源內容 → 萃取乾貨 + 選定切角 → 套用語氣風格撰寫 → 輸出 promo.md
```

## 用途

這個 skill 解決的問題：長篇內容（例如 `content.md` 課程大綱）資訊量大、結構像大綱，無法直接當宣傳文。它需要被轉化成一篇**像作者本人寫的、有故事、有情緒、有乾貨**的貼文。

核心價值在於**穩定重現作者的語氣與風格** —— 風格規則定義於 `references/voice-and-style.md`，範例見 `references/examples.md`。

## 何時使用

- 使用者提供一份長文，要求轉成宣傳文 / FB 貼文 / 直播宣傳。
- 使用者要求「用我的語氣 / 我的風格」撰寫宣傳內容。
- 使用者要為一場直播、說明會、課程、活動寫暖場貼文。

## 核心原則

**宣傳「價值」，不「銷售課程」。** 文章要讓讀者從內容本身就獲得乾貨、產生共鳴，進而想報名；而不是靠折扣碼、QR Code、價格表硬推。除非使用者明確要求，否則不要放這些銷售元素。

## 工作流程

### Step 1 — 讀取來源內容

完整讀取使用者提供的長篇內容，理解：
- 核心主軸與最想傳達的訊息
- 有畫面、反直覺、有共鳴的「乾貨點」（見 `voice-and-style.md` 第 9 節）
- 可引用的金句、可改寫成故事的場景

### Step 2 — 確認關鍵資訊

撰寫前先確認以下資訊，使用者已在指令中提供的就不必再問：
- **宣傳標的**：免費直播 / 線上說明會 / 課程 / 活動？
- **報名連結**：要放在結尾的 URL（沒有就先留 `<連結>` 佔位）。
- **平台**：預設 Facebook；若要 Thread / YouTube / IG 版本另行調整長度。
- **切角**：使用者是否指定切角。若未指定，從來源內容挑出 2–3 個可行切角，簡短列出讓使用者選擇（一份長文足以支撐多篇不同切角的貼文）。

### Step 3 — 萃取乾貨、選定切角

- 一篇文章只鎖定**一個切角**、3–4 個重點。
- 把長文的標題與條列**轉化**成「我的體會」「為什麼這對你重要」，不要原樣搬運。
- 為開場挑一個能寫成真實小故事的場景。

### Step 4 — 依語氣風格撰寫

嚴格遵循 `references/voice-and-style.md`：
- 4 區塊「起承轉合」結構，`────` 分隔。
- 開場用金句／提問 + 真實故事（含對話引述與轉折瞬間）。
- 句子完整、有敘事流動，**不堆疊名詞短語**。
- emoji 克制（只用 `1️⃣2️⃣3️⃣`、`👇`、`👉`）。
- 慣用句式收尾邀請，附報名連結。
- 全文約 500～1000 字。

對標 `references/examples.md` 的黃金範例檢查語氣與節奏。

### Step 5 — 輸出

將成品寫入來源內容**同目錄**的 `promo.md`。若該檔已存在且為不同切角，與使用者確認要覆寫或另存（例如 `promo-2.md`）。

## 風格速查

| 面向 | 重點 |
|------|------|
| 調性 | 第一人稱、誠懇平實、像前輩分享心得 |
| 結構 | 開場故事 → 承（體會）→ 轉（乾貨條列）→ 合（方法論 + 邀請） |
| 開場 | `❝金句❞` 或 `❝提問❞` 或 `【標題】` + 真實場景 + 對話引述 |
| 排版 | 短段落、`────` 分隔、`1️⃣ →`、`👇`、`👉` |
| emoji | 克制，功能性使用，不裝飾 |
| 結尾 | 「不只是 X，而是 Y……就是我想給你的答案」+ `👉 連結` |
| 禁忌 | 喊口號、浮誇詞、銷售腔、折扣碼／QR Code、句子破碎、emoji 過量 |

## 品質檢查清單

產出前逐項確認：

- [ ] 開場有金句／提問 + 一段真實故事，故事裡有對話引述與轉折瞬間
- [ ] 結構是 4 區塊、用 `────` 分隔
- [ ] 乾貨是「轉化」而非「搬運」，只聚焦一個切角、3–4 個重點
- [ ] 句子完整連貫，沒有名詞短語堆疊、沒有破碎感
- [ ] emoji 克制，沒有裝飾性 emoji
- [ ] 結尾用慣用句式自然邀請，沒有銷售腔
- [ ] 沒有折扣碼／QR Code／價格表（除非使用者要求）
- [ ] 全文約 500～1000 字
- [ ] 整體讀起來像作者本人寫的，對標得上 `examples.md` 黃金範例
