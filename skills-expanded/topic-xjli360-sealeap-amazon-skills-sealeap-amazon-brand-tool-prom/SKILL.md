# SeaLeap 品牌工具与旺季促销组合

围绕品牌与商品的成熟度选择工具，让商品引流、品牌承接与促销成本可以一起核查。

## 输入

品牌资格、商品线和成熟/潜力/新品 ASIN、当前页面/旗舰店、价格/库存/利润、广告表现、促销资格与日期、素材权利、工具可用性和预算。

## 工作流

1. 分别判断品牌认知与 ASIN 成熟度，选择“新兴品牌有成熟商品、成长品牌有成熟商品、品牌与商品都未成熟”的路线。
2. 以曝光、转化、复购或新客目标筛选当前可用工具。**Amazon Posts 已于 2025 年 7 月停用，MYCE 于 2024-02-16 停止发送活动**；课件里的对应发布步骤只作历史背景。
3. 用真实同系列/互补商品设计品牌广告、旗舰店专区或符合资格的虚拟捆绑，分别保留新品与成熟品的表现，不假设流量必然转移。
4. 检查广告与落地页在商品、场景、价格、活动和品牌信息上的一致性，再分开测试素材、位置或关键词。
5. 旺季按准备、高峰、收尾安排商品、页面、广告和促销；计算优惠叠加后的净收入及库存覆盖，审核全部阶段总预算。
6. 通过总利润、销售、CVR、ACoS 和品牌指标复盘，记录同期变化。不能把三项同时改变的案例当作单一动作因果。

## 交付

品牌/ASIN 状态、工具可用性及历史退役清单、商品组合和落地页草案、促销叠加计算、阶段预算、实验及回退计划。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
