# 导演统一审核技能（极速版 · 双阶段）

[技能说明]
    极速版分镜师已并入导演，审核从三阶段收为**双阶段**：
    - **阶段一 · production 审核**（§1）：导演自审自己产出的 production（剧情拆解 + 镜头编排 + 提示词卡片一体审）
    - **阶段二 · 服化道审核**（§2）：导演跨阶段审 art-designer 产出（含风格前缀块）

    **审核执行者 = director**（自审同 agent 内生成+审核）。

    **加载策略**：按任务类型精读对应章节 + §0 通用原则（阶段一读 §0+§1，阶段二读 §0+§2）。

    **不产出独立审核文件**。自审作为内部质控流程，得分摘要在 director 返回消息中汇报给主 Agent。

---

## §0 通用审核原则

[审核立场] 你的任务是**找出问题**，而非确认通过。批判性逐行比对 / 脑内预演 / 逐项评分。

[流程] 1. 读上游+被审对象+依赖素材 → 2. 逐行比对（弱化/遗漏/偏离）→ 3. 脑内预演（想象生成效果）→ 4. 逐项评分 → 5. 特殊核对 → 6. 输出。

审核最多修订两轮；仍失败则保持 FAILED，交用户决策，禁止自动进入下一阶段。

[评分] 9-10 精准免改 · 7-8 基本到位有 1-2 处可改 · 5-6 明显问题需改 · 1-4 严重不足。

[输出规范]
    PASS：✅ **审核：PASS** + [评分表] + 整体评价（1-2 句）
    FAIL：❌ **审核：FAIL** + [评分表] + 业务问题（位置/当前问题/修改方向）+ 修改优先级（🔴 必须 / 🟡 建议）

## §1 阶段一 · production 审核（合并剧情脚本 + 提示词标注）

[审核对象]
    `outputs/<集号>/<段号>-production.md`（镜头卡片 + 人物清单 + 场景清单 + 后期参考）

[审核前必读]
    - 对应剧本段（从 `script/EPNN.md` 提取本段内容，逐行比对基准）
    - `assets/cinematography-bible.md`（场景映射 / 负面约束 / 配色基调）
    - `assets/asset-index.md`（@引用核对）

[结构瘦身核对]（违反为"必须修改"）
    □ production **不得**包含全剧恒量（摄影机基准/画幅规则/配色基调/逐镜摄影级提示行）——这些在 cinematography-bible。
    □ 每个剧情点**必须**有"场景类型"标签（对应 director-skill 场景类型枚举；新场景标 `⚠ 新场景类型：XXX`）。
    □ **视频提示词不得写**：风格前缀块（`Shot on ARRI…` 归服化道）、模型字段、线稿、摄影机参数、**avoid 负面约束**。出现即"职责错位"，要求删除。

[A · 剧情拆解与镜头编排]（每个剧情点评分 1-10）
    □ 逐行比对完整性 / 叙事完整性 / 合并拆分检查 / 时长合理性
    □ 镜头密度：对照场景类型检查 ASL（动作 2-3s·对话 4-6s·沉思 6-8s）；平均每镜 >6s 且非沉思戏 → 过稀
    □ 省略检查：是否有应省略的无信息位移
    □ 30 度法则 / 叙事功能（写不出功能=不该拍）/ 节奏合理性 / 剪辑原则（Murch 优先级·信息耗尽即切·情绪不切）
    □ 运动速度字段、情绪弧字段是否标注
    □ 尾画面 + 角色状态表（位置/朝向/姿态四维 + 关键道具/环境 + 最后一镜标"→下一段/段结束"）
    □ 武打段落（仅）：七要素 + 关键打击"蓄力-爆发-落点"三拍 + 动作四维度具体

[B · 提示词卡片质量]（每个剧情点评分 1-10）
    每张卡片核对（违反扣分·系统性缺失=FAIL）：
    □ **镜头覆盖率**：每 P 卡片数 = 镜头表镜头数（常遗漏最后 1-2 镜）
    □ **无风格前缀混入**：视频提示词**不得**以 `Shot on ARRI…` 风格前缀开头（极速版归服化道）= 违规扣分
    □ **无模型/无线稿**：卡片不含模型字段、不含线稿
    □ **景别/运镜元数据**：每张标景别 + 运镜（← 镜头表）+ 情绪映射
    □ **时间戳动作链**：正文是否为 `- [起-止s] 动作描述` 的时间戳动作链？时间戳总和=镜头时长？动作物理化、污染词已替换？卡片头是否为 `镜头 · 时长 · 驱动 · 景别 · 运镜`、并有 `图片：@图N…；无字幕，无bgm` 一行？
    □ **视觉代偿**：括号情绪注记 `（...）` 是否翻译为物理微动作（不允许抽象情绪直接入提示词）
    □ **无 avoid**：卡片是否**不含** avoid 负面约束（极速版不写）= 出现即扣分
    □ **固定句**：图片行是否含 `无字幕，无bgm`
    □ **参考图引用**：`{{@图N}}` 角色/场景是否齐全（服化道未完成时占位是否标注待回填）
    □ **多机位 C 标记**：一镜多固定机位是否用 `[C01·机位说明]/[C02·…]` 分段
    □ **密度控制**：描述密度匹配景别（近景高密度·远景低密度）

[C · 上传清单]
    □ 完整性：每张卡片列出所需参考图（人物/场景分开上传，合成=FAIL）
    □ @引用一致性：上传清单编号与段头素材对应表一致（占位待回填可接受）
    □ 场景角度：首尾帧卡片是否标起始/终止两个场景角度

[D · 台词零丢失]
    □ 逐条比对剧本台词 → 每句**内嵌在对应卡片的时间戳动作链里**（`@角色："原文" [原著]`·不单列台词字段）；遗漏=FAIL；补充台词标 `[补]`

[E · 人物/场景清单 + 后期参考]
    □ 人物清单：筛选合理性 / 外观可设计性 / 素材状态标注（复用/变体/新增）
    □ 场景清单：完整性 / 环境可设计性 / 素材状态标注
    □ 后期参考：环境音/音效/沉默/听觉记号薄留且**未混入视频提示词**

[F · 段间 handoff]（非最后一段必有）
    □ Handoff 级别（L1/L2/L3）+ 理由 / 尾帧状态 / 跨段可复用素材

[评分表]
    | 剧情点 | 镜头编排 | 提示词质量 | 翻译/物理化 | 上传清单 | 台词完整 | 尾画面 | 均分 | 问题摘要 |
    |--------|---------|-----------|------------|---------|---------|--------|------|---------|
    | P01    | 9       | 9         | 9          | 10      | 10      | 9      | 9.3  | 无 |
    人物清单：X/10 · 场景清单：X/10 · **剧情点平均分：X.X/10**

## §2 阶段二 · 服化道审核

[审核对象]
    `assets/character-prompts.md` 和 `assets/scene-prompts.md` 中本集新增内容

[审核前必读]
    - 本集各段 production 的人物清单和场景清单
    - 既有素材（风格一致性参照）
    - `assets/cinematography-bible.md`（配色/光源规则）+ `visual-style-presets.md`（风格前缀块）

[审核流程]
    1. 建立整体理解（人物/场景清单 + 待审产出）
    2. 逐项比对（每个人物/场景对照清单外观关键词，找遗漏/偏离/矛盾）
    3. 脑内预演（想象丢进文生图工具的生成效果）
    4. 逐项评分

[验收清单]
    人物造型提示词（每人评分 1-10）：与清单一致性 / 辨识度 / 描述精确 / 细节完整 / 风格匹配 / 格式可执行
    □ **风格前缀块**：每张人物/场景提示词顶部是否带"风格前缀块"（风格前缀 + 生图 avoid）？缺失 = FAIL
    □ **生图 avoid 正确**：是否含生图专属 avoid（text overlays/HUD/手指/水印）？是否**误把动态约束**（jitter/identity drift）写进生图？
    场景环境提示词（宫格整体 1-10）：逐格与清单一致性/氛围/空间/关键元素；整体覆盖完整/宫格规格/格间风格一致/格式可执行
    跨集一致性（EP02+·不评分）

[阶段二注意事项]
    文生图（Nano Banana 等）高频注意点：避免"神似某真人"的面部描述、避免具名品牌 logo、避免政治/敏感宗教符号。

## §3 合规审核说明

本系统不做平台合规审核，跳过合规扫描步骤——影视微短剧创作，无平台敏感内容审核需求。各阶段审核流程中不嵌入合规扫描。若具体项目有平台投放合规要求，由用户在投放前自行核查。
