# 参考图（设定图）Go/No-Go 审图清单（用户手工流水线）

**定位**：本 skill 是**用户**在手工流水线中使用的审图工具。服化道产出参考图提示词、用户用 Nano Banana Pro 等出**人物设定图 / 场景图**后的"用户审图 Go/No-Go"节点由此 skill 支撑。

**不是 director 审核**：director 审核的是 production 与服化道提示词的**文字**（review-skill §1/§2）；本 skill 审核的是用户**生成出来的图**。两者互补。

**极速版说明**：手工流水线是"出设定图 → 上传参考图 → 直接生视频"，**没有"逐 KF 出分镜图再审"那一层**；本清单审的就是那批**人物/场景设定图**（也可用于审 i2v 成片帧）。

---

```
服化道产出参考图提示词（character-prompts.md / scene-prompts.md）
        │
        ▼
用户用 Nano Banana Pro 等出人物设定图 / 场景图（每个角色/场景一张）
        │
        ▼
★ 本 skill 使用点 ★
    每张设定图出来后 · 对照清单逐项审查 · Go / No-Go
        │
    ┌────┴────┐
    ▼         ▼
   Go        No-Go
    │         │
   锁定为     反馈给导演/服化道

        │
        ▼
全部设定图 Go 后 → 作为参考图上传 i2v 平台跑视频
```

## §1 通用审图清单（每张 KF 都过）

### 1.1 角色一致性（identity）

对照 `assets/character-prompts.md` 的角色主图和出图提示词中的角色描述：

- [ ] **面部特征**：五官比例、眼睛颜色、发色发型、肤色与主图一致？
- [ ] **服装**：主要服装（制服/便服/太空服）款式、颜色、材质一致？
- [ ] **体型**：身高、肩宽、比例符合角色年龄/性别设定？
- [ ] **标志性特征**（如有）：神经接口位置、疤痕、纹身、配饰等特殊标记？
- [ ] **年龄段**：儿童/青年/中年/老年区分准确？

**致命问题**（直接 No-Go）：
- 角色面部与主图偏差明显（别人的脸）
- 年龄段错（把中年画成青年等）

### 1.2 构图 · 景别 · 机位

对照出图提示词（信息版）中的构图描述：

- [ ] **景别**：中景/近景/特写/大全景与提示词一致？
- [ ] **机位角度**：低角度仰拍 / 正面 / 俯视等与提示词一致？
- [ ] **画幅**：2.39:1 宽银幕（全片锁）· 2K 或以上分辨率？
- [ ] **角色占画面比例**：提示词标注 25% / 60% / 8% 等与实际一致？
- [ ] **角色位置**：前景 / 中央 / 画面左下 等与提示词一致？
- [ ] **角色朝向**：后背朝向观众 / 侧脸 3/4 / 正面 等与提示词一致？

### 1.3 光影（Deakins 单光源）

对照情绪版提示词中的光影描述：

- [ ] **主光源位置**：从左/右/顶/底/逆光 方向射入·与提示词一致？
- [ ] **光色色温**：冷蓝 5500K / 暖橙 3200K / 等·与提示词一致？
- [ ] **对比度**：高对比（70% 阴影）/ 中对比 / 低对比·与提示词一致？
- [ ] **阴影方向**：主光源方向的阴影投向是否物理正确？
- [ ] **辅光（如有）**：深景暖色辅光（指示灯 / 屏幕自发光）是否存在·亮度不盖过主光？
- [ ] **Deakins 单光源原则**：画面是否只有一个主光源（没有多灯穿帮）？

**常见翻车**：
- 多光源互相打架（左右脸都是高光·光位不明）
- 光色与提示词不符（提示词冷蓝但出图偏暖）
- 阴影方向违背物理（光从左来但右脸也暗）

### 1.4 道具 · 环境

对照出图提示词中的道具和环境描述：

- [ ] **关键道具位置**：控制面板 / 医疗设备 / 屏幕 等在正确画面位置？
- [ ] **关键道具状态**：屏幕暗屏 / 亮屏 / 指示灯颜色 等与提示词一致？
- [ ] **环境动态元素**：指示灯 1Hz vs 3Hz 无法从静态图判断·检查指示灯颜色/状态位
- [ ] **场景布局**：指挥舱 / 医疗舱 / 走廊 等主要场景结构与 scene-prompts 设定图一致？

### 1.5 前景 / 氛围粒子（如适用）

对照情绪版提示词中的前景氛围描述（非所有 KF 都有）：

- [ ] **前景遮挡物**：管线 / 舱壁 / 肩部剪影 等·是否有·位置正确？
- [ ] **氛围粒子**：细尘埃 / 液泡 / 星尘 / 火星溅射·类型与场景匹配？
- [ ] **粒子密度**：极简美学场景（情绪峰值）不应有过多粒子·平构图场景应该有足够粒子
- [ ] **分层关键词生效**：前景是否明显虚化/散景（不是和主体一样清晰）？

### 1.6 跨镜一致性（多 KF 同段时）

对照已锁定的上一张 KF（通常是 KF1 作为 Style Anchor）：

- [ ] **场景延续**：同一场景内·墙面/地板/道具位置是否一致？
- [ ] **光影延续**：主光源色温/位置是否保持（即使焦点切换）？
- [ ] **角色服装延续**：同一时间线内角色服装/状态是否一致？
- [ ] **色调延续**：整体冷蓝底色 / 暖色能量元素的色彩基调统一？
- [ ] **机位一致性**：如提示词声明"严格保持机位"·角度/焦段/景别应该保持？

### 1.7 AI 常见画崩（Nano Banana Pro 通病）

- [ ] **手部解剖**：5 指正确？没有多指 / 少指 / 手指畸形 / 错位？手/腕关节比例正常？
- [ ] **脚部解剖**：5 趾正确（如裸足出镜）？
- [ ] **面部左右对称**：眼睛大小、眉毛位置、嘴角对称（除非提示词要求非对称表情）？
- [ ] **眼睛**：瞳孔清晰 / 眼白不呆滞 / 反光正常？特别关注特殊要求（如特殊设定的角色的异常瞳孔）是否被误画成恐怖效果
- [ ] **文字 / Logo / HUD 漏出**：画面中是否混入可读文字、品牌 Logo、UI overlay（全片禁止）？
- [ ] **肢体穿模**：手臂穿过身体 / 腿部交叉异常？
- [ ] **头发物理**：发型在静态图中是否自然（不是飘起异常）？

**致命问题**（直接 No-Go）：
- 手指数量不对
- 画面混入可读文字 / 品牌 Logo

## §2 按场景类型的专项审图

### 2.1 飞船内部

- [ ] **冷色调主导**：飞船内部冷蓝/冷白灯光？
- [ ] **Deakins 极简单光源**：控制台冷蓝 / 走廊冷白 / 一盏实用光·画面简洁？
- [ ] **人物站位**：多人戏对照 staging-skill 的站位规范？
- [ ] **神经接口**（如可见）：接口位置、金属质感一致？

### 2.2 太空奇观

- [ ] **恒星/星云位置**：远景·散焦？星云色彩与世界观设定一致？
- [ ] **飞船剪影**：剪影线条清晰·舰体形态符合设定？
- [ ] **空间深度**：前景（自舰船/残骸）+ 中景（目标舰）+ 远景（星云）三层？

### 2.3 异构体内部

- [ ] **异质空间感**：非欧几何暗示、有机结构、令人不安的对称？
- [ ] **光线异常**：光源不合常理（自发光/折射异常/影子方向矛盾）？
- [ ] **色调转变**：与飞船内部色调形成对比？

### 2.4 地球闪回

- [ ] **色调区分**：与太空段明显不同·暖色调 / 过曝 / 低饱和？
- [ ] **时代感**：未来地球的科技元素（VR/天堂/义体）？
- [ ] **氛围粒子**：微尘光斑 / 暖色尘粒·与闪回时态匹配？

### 2.5 外星接触

- [ ] **异质感**：非人类美学·有机/几何混合？
- [ ] **光线**：非自然光源·自发光/折射？
- [ ] **比例暗示**：外星实体的尺度通过参照物暗示？

## §3 注意事项（必检）

**品牌/政治/宗教**：
- [ ] 无真人脸识别风险（"神似某真人"）
- [ ] 无品牌 Logo
- [ ] 无真实政治符号 / 敏感宗教符号

**文字 / UI**：
- [ ] 画面无可读文字（中文 / 英文 / 符号都算）
- [ ] 无 HUD 界面元素 overlay
- [ ] 控制台屏幕的内容是抽象图形·不是可读数据

## §4 Go / No-Go 判定规则

### Go（通过 · 锁定为 KF.png）

同时满足：
- §1 通用清单全部打勾（致命问题零容忍）
- §2 对应场景类型专项清单全部打勾
- §3 注意事项全部打勾

**Go 的实际动作**：
1. 保存图片为 `KF1.png` / `KF2.png` / ... （命名与 production 文件里的引用一致）
2. 如果本 KF 进入 keyframe-library（跨段复用候选）· 同步保存一份到 `assets/keyframes/`
3. 该 KF 可作为后续 KF 的 delta ref / 驱动层的首/尾帧使用

### No-Go（不通过 · 调整重抽）

任何 §1/§2/§3 致命问题命中·或累积 3+ 个非致命问题。

**No-Go 的实际动作**：
1. 记录问题清单（哪些 checkbox 失败 / 具体描述）
2. 反馈给 导演 → 导演 调整本 KF 的 Nano Banana 提示词（delta 改写 / 加负面约束 / 换 ref）
3. 用新提示词重抽
4. 回到本 skill 重审

**Nano Banana Pro 重抽技巧**（无需改 production 文件·用户可自行微调）：
- 手部问题 → 追加 `avoid hand deformation, avoid extra finger count, anatomy correct hands`
- 文字漏出 → 追加 `avoid text, no English, no Chinese, avoid any readable words`
- 多光源 → 追加 `avoid multi-light studio, single light source only`
- identity 漂 → 强化 character ref 的权重 / 重新上传主图
- 单次 seed 换别的 → Nano Banana 多 seed 试（1-2 次如仍失败·回 导演）

## §5 反馈模板（No-Go 时用）

用户把以下模板发给 导演（或在后续对话里提）：

```
## KFx No-Go 反馈

**失败的 check 项**：
- §1.1 角色一致性：角色A被画成年轻女性·需要中年男性比例
- §1.7 手部解剖：角色D右手 6 指
- §3 注意事项：屏幕上漏出可读英文 "WARNING"

**建议调整方向**：
- 加负面约束：`avoid female proportions, male character, avoid extra finger count, avoid readable text, no English`
- 加强 ref：角色A主图权重提高

**重抽基于**：
- Nano Banana Pro · 输入 refs 保持原 production 文件清单
- 只调 delta 提示词
```
