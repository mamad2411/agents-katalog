# 提示词翻译手册（极速版 · 导演执行层）

> **极速版说明**：原"分镜师"已并入导演。本手册是**导演组装视频提示词卡片**时的翻译参考——把镜头表的动作链/运镜/焦点翻译成 i2v 平台能理解的提示词。
> **不含**：模型选择（模型无关）、线稿（已删）、风格前缀（`Shot on ARRI…` 归服化道·视频提示词不写）、**avoid 负面约束（不写）**。
>
> ⚠ **卡片最终格式以模板为准**：见 `director-skill/templates/director-analysis-template.md`——**时间戳动作链**（`- [0-2s]…`·台词内嵌）· 无 avoid。本手册提供运镜翻译表/焦点/复合镜头/情绪核心翻译等**方法论**（仍有效）；下方示例里的 `avoid …` 行与旧卡片骨架**已作废**，组装时按模板的时间戳动作链格式落地。

[技能说明]
    导演在镜头表（已含景别/运镜/焦点/动作链/光影/台词）基础上，为每个镜头组装一张提示词卡片。组装 = ① 上传清单（场景图/人物图/道具图各自独立·分开上传）② 提示词正文（运动描述 + 运镜翻译）③ 执行参数（驱动模式）④ 台词。

    **参考图使用原则**：场景图、人物图、道具图**各自独立上传不合成**（合成进 i2v 会压缩掉画质和 identity）；需要多角度场景时用同一场景的不同角度变体。

[组装流程]（每个镜头 · 完整卡片格式与产出白名单以 `director-skill/templates/director-analysis-template.md` 为单一权威，本节只给组装要点）
    1. **上传清单**：角色设定图 @图X（三视图·分开上传）+ 场景图 @图Y（分开上传）+ 道具图 @图Z（如需）。不合成。服化道未完成时用占位待回填。
    2. **提示词正文**：运动描述（动作链与表情并入·物理化）+ 运镜翻译（见下表）+ 光影补充（仅在镜头表描述不够时）+ 污染词替换。**不写风格前缀、不写模型、不写线稿。**
    3. **执行参数**：驱动模式（首帧 / 首尾帧 / 续写 / 多元参考·按运镜翻译表的模式列判断）+ 时长（取自镜头表）。
    4. **台词**：原文照搬·零丢失·写入提示词 + 独立台词字段标注·补充台词 `[补]`。台词密度检查：驱动 ≥8s 且无台词又无明确静默理由时，检查是否应补台词/旁白。

    **提示词格式**（无风格前缀·无模型）：
    ```
    无BGM无字幕。角色为{{@图X}}。场景为{{@图Y}}。
    [运动描述·动作链并入·污染词已替换]。[光影补充（按需）]。
    ```
    **static 运镜**：不写运镜描述，只写人物动作。**非 static**：按 [运镜翻译表] 翻译。

[情绪核心翻译原则]
    **原则 1 · 括注 = 情绪密码（硬）**：镜头表/动作链中 `（...）` 括注定义这个时刻"关于什么"。必须读括注理解意图、译为物理动作/微表情，意图优先级高于同时刻其他动作。
    **原则 2 · 一句一核心（硬）**：每条提示词只有一个情绪核心。承载情绪重量的动作放句首给最具体物理描写，其余从属或省略，不把情绪核心埋在中间。
    **原则 3 · 不加噪声（硬）**：不添加镜头表里没有的动作/元素（噪声会稀释情绪核心、分散 AI 注意力、提高出错率）。
    **原则 4 · 情绪意图→物理翻译**：抽象情绪词 AI 不懂，按"括注意图 → 物理动作/微表情 → 提示词"翻译。
    ```
    （压抑的计算）   → 眼睛不动·瞳孔微缩·手指轻点桌面一次 → "瞳孔微缩，右手食指轻点桌面一次后静止"
    （恐惧被理性压制）→ 咽喉微动·手指收紧后松开·呼吸幅度极小 → "喉结微微滚动，手指收紧后缓缓松开"
    ```
    **正误对比**（同一动作链"角色盯着通讯窗口两秒后点击接受·无感情评估"）：
    - ✗ `角色看向屏幕，手伸向杯子，眨眼，点击，周围窗口闪烁。`（"看向"是污染词·情绪核心被淹没·噪声堆积）
    - ✓ 运镜 static → 冷静·客观·疏离；正文 `角色面部完全静止，瞳孔微缩，右手食指缓慢抬起点击一次后放下。`

[四项铁律]
    **铁律 1 · 污染词扫描（硬）**：禁用事件名/抽象概念（打游戏、驾驶、战斗、瞄准、望向、注视等）→ 改具体动作/姿态/物体。详见 seedance-prompt-methodology。
    **铁律 2 · 视觉元素代替抽象动作（硬）**：背对/望向/凝视/回眸 → 身体朝向 + 头部方向 + 眼睛焦点。镜头表通常已完成翻译，验证即可。
    **铁律 3 · 密度控制景别（硬）**：用描写细节多少控制 AI 构图焦点——特写加强面部细节、全景加强环境大尺度+人物小剪影、俯拍写头顶/肩背、仰拍写下巴/颈部/背景。
    **铁律 4 · 氛围粒子按场景绑定（选用·通用）**：按场景类型选择性写入前景粒子，例如：
    - 室内（生活/功能）→ 屏幕反射光斑 / 灰尘微粒
    - 太空舱内 → 冷光束尘埃 / 金属微粒
    - 太空外景 → 星尘 / 微粒反射
    - 城市外景 → 光污染 / 屏幕反射
    - 闪回/梦境 → 暖色微尘光斑 / 胶片颗粒
    - 界面（通讯/新闻）→ 屏幕微粒反光 / 数据流光斑
    → 镜头表"前景氛围"字段已给方向，精化为提示词表达。项目专属粒子按题材在 cinematography-bible 补充。

[avoid 负面约束 — 极速版不写]
    **极速版视频提示词不写 avoid**。卡片只保留 卡片头 + 图片行（含"无字幕，无bgm"）+ 时间戳动作链，整段直接复制粘贴。

[BGM 策略]
    对话/独白/动作戏 → 禁止 BGM（写"无背景音乐"）；纯视觉蒙太奇/建立镜头 → 允许 BGM（描述风格节奏）；不确定 → 默认禁止。镜头表"声音.BGM"字段已给决策，直接执行。

[群演 / 一次性配角]
    不分配 @引用，提示词中直接文字描述外观和动作（镜头表角色表中群演已用"群演：[描述]"写好，直接取用）。

[运镜执行]
    导演镜头表已定义每镜运镜和焦点意图。组装时**忠实翻译为提示词**，不改运镜决策。职责：翻译（运镜意图→提示词语言）、验证（在 i2v 能力范围内）、预警（超能力如 360° 环绕→标注替代）、细化（加速度曲线/呼吸感等执行细节，不改方向/类型）。
    **运镜多样性自检**：连续 2 个以上驱动条相同运镜 → 标注提醒。

    ## 运镜翻译表
    | 运镜 | 驱动模式 | 提示词怎么写 | 可靠度 |
    |---------|---------|------------|------|
    | static | 首帧 | 不写运镜·只写角色动作/表情变化 | ★★★★★ |
    | slow dolly in | 首尾帧 | `镜头缓慢向前推近，[角色动作]` | ★★★★★ |
    | dolly out | 首尾帧 | `镜头缓慢后退，[角色/环境揭示]` | ★★★★★ |
    | pan | 首尾帧 | `镜头水平向[左/右]缓慢摇动` | ★★★★★ |
    | tilt up/down | 首尾帧 | `镜头[上/下]摇` | ★★★★★ |
    | track（侧跟）| 首帧/首尾帧 | `镜头与角色保持平行向[方向]移动` | ★★★★ |
    | handheld | 首帧 | `镜头带与[脚步/心跳/呼吸]频率一致的震颤`·**须指定节奏源** | ★★★★ |
    | crane up/down | 首尾帧 | `镜头[上升/下降]` | ★★★★ |
    | orbital | 首尾帧 | `镜头绕角色[顺/逆时针]弧形移动至[终止角度]`（≤180°）| ★★★ |
    | whip pan | 首帧 | `镜头快速横扫向[方向]，约0.3秒完成，中间成运动模糊` | ★★★★ |
    | rack focus A→B | 首尾帧 | `焦点从[A·清晰]缓慢转移到[B·从模糊变清晰]，约Xs` | ★★★ |

    **加速度曲线**：ease-in→"起始缓慢逐渐加速"；ease-out→"起始迅速最后X秒缓缓停下"；punch-stop→"瞬间高速[推/拉]然后突然停住"。

    ## 焦点翻译表
    | 焦点指令 | 提示词怎么写 |
    |-------------|------------|
    | 深景深·全局 | 不写焦点（默认全清晰）|
    | 锁定 [对象] | 加强该对象细节描述（密度控制景别）|
    | 极浅·隔离 | 只写该物件细节，其他不描述 |
    | rack focus A→B·缓慢 | `焦点从前景[A·清晰]缓慢转移到背景[B·从模糊变清晰]，[A]同时变虚焦，约[X]秒` |
    | rack focus A→B·瞬间 | `焦点瞬间从[A]切到[B]，[A]立刻虚焦` |
    **rack focus 三要素**（缺一即被忽略）：① 起点清晰对象 ② 终点变清晰对象 ③ 速度/时长。

    ## 走位变化翻译表
    | 走位 | 提示词怎么写 |
    |---------|------------|
    | 角色不动（表情/微动作）| 只写变化：`嘴唇重新抿紧，眉头微皱一瞬` |
    | 角色位移（A→B）| `角色缓步从画面左侧走到右侧` |
    | 进入画面 | `[角色描述]从画面[方向]走入` |
    | 离开画面 | `角色转身向[方向]走出画面` |
    | 他人闯入 | `[闯入者]从[方向]进入画面，[主角反应]` |
    | OTS 前景角色 | 前景角色不写动作（静态构图元素），只写焦点角色动作 |

    ## 复合镜头模式翻译
    **OTS（过肩）**：`画面左前方一个人的右肩和后脑勺柔和虚焦占据画面25%，形成自然框架。焦点在画面右侧的B，面朝左前方，[表情]。浅景深，前景肩膀完全虚化。` 驱动层只写 B 的动作/表情变化。
    **正反打**：两个相邻 OTS 镜头各出一张卡片（镜1 焦点 B / 镜2 焦点 A），后期交替拼接。**一致性硬规则**：两张场景图光线方向/色温一致；同一角色始终在画面同一侧（180° 轴线）；背景环境一致。
    **建场→景别递进**：建场镜头远景场景图 + 写环境动态（灯光/粒子/舱门），角色不写；进入镜头中景场景图 + 角色图 + 以角色动作为主。
    **插入+反应**：插入 `极特写，[物件]占满画面。极浅景深，仅[物件]清晰，周围完全虚化。[微动态]`；反应 `角色为{{@图N}}。[角色]深吸一口气，瞳孔微缩，嘴唇缓缓抿紧。`（不写"表情变悲伤"）。
    **rack focus + dolly in**：两个变化写进一句 `镜头缓慢向前推近，同时焦点从前景的手（清晰）缓慢转移到角色面部（从模糊变清晰），手逐渐虚焦。` 需起始/终止两张场景图。
    **鸟瞰**：`俯拍鸟瞰视角，摄影机正上方垂直向下。[主体]在画面中央，[场景]四周展开。` 鸟瞰+crane 用首尾帧（高位+低位场景图）。
    **倒影/镜面**：`画面中央一面[反射面]，其中映出[角色]的倒影。[倒影中姿态/表情]。` 只画倒影不画本体。

    ## 编排注记翻译
    镜头表下方有编排注记（走位触发 + 焦点设计 + 情绪流向）时，按触发链翻译：
    示例注记 `角色起身（→tilt up 跟随）→ 走向窗口（→track 侧跟）→ 停步望窗外（→镜头停·rack focus 背影→窗外天空·2s）`
    → 首尾帧·两张场景图（起始：角色在室内；终止：窗外天空）·提示词 `角色起身，镜头上摇跟随。角色走向窗口，镜头侧跟。角色停步面朝窗外，焦点从角色背影缓慢转移到窗外天空（约2秒），背影逐渐虚焦。`
    **时长分配**：注记有 N 个触发动作 → 除以镜头总时长 → 每动作分配时间 → 不超过节拍密度（每拍 ≈ 2.5s）。

[禁忌规则]
    - 不重写动作链——直接取用，仅做污染词替换
    - 不合成参考图——场景图和人物图分开上传
    - 不重复参考图已锁定信息（角色外观/服装/发型）
    - 不添加镜头表未描述的动作或元素
    - 不用否定句（"不要移动"→"保持静止"）
    - 不在一条提示词塞叙事不相关的场景
    - **不写风格前缀（归服化道）·不写模型·不写线稿**
    - 不用自然语言跨图引用（"同上一帧构图"·AI 看不懂）
    - 台词零丢失——原剧本台词一句不能少
