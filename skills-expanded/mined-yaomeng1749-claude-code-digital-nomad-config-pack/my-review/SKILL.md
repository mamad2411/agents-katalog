# My Review — 个人知识审计

> 审计 `~/Desktop/My vault/My vault/知识库/`。

## 知识库路径

```
~/Desktop/My vault/My vault
```

## Usage

```
/my-review               # 完整审计
```

## 审计维度

1. **矛盾检测**：文章间的直接矛盾、时间矛盾
2. **重复检测**：>80% 内容重叠 → 建议合并
3. **时效检查**：>30天未更新 → 标记 stale
4. **完整性**：孤立文章、断裂链接、缺失主题
5. **质量**：Key Takeaways 是否存在、文章长度

## Output

打印审计结果，包含：
- 矛盾列表（需用户裁决）
- 重复列表（建议合并）
- 过期文章
- 质量问题

## Rules

- 矛盾只报告，不自动裁决
- 重复只建议，不自动合并（审计模式下）
