# 保洁

将已经采集到的网页、PDF、表格、公告或笔记，整理成可复核、不可重复计算的证据台账，交给下游分析。

按输入选择工作方式：资料清洗与审核执行下述四步，交付证据台账；已有报告、图表或附件需要核对时，读取并执行[成稿核对](references/成稿核对.md)，给出核对结果、问题单和交付状态。混合任务先沿用已有台账处理资料问题，再核对成果，不重复登记来源。

发现影响判断的缺口或矛盾时，列明问题并定向补搜，再给出处置建议。核对可以更正计算、指出推理缺口并提出修订建议；需要新增研究结论时，明确返回受影响的分析任务。

## 资料清洗与审核：做四件事

### 1. 登记资料

为每份材料记录来源、链接或文件路径、发布日期、取得日期，以及原文定位（页码、表号或段落）。

优先追到原文。媒体转述可保留，但标为“仅见转述”；引用同一原始报告、公告或数据表的多篇材料，只算一个来源。

### 2. 拆开、去重、分级

按“这条材料想证明什么”拆分证据，不把整篇文章当一条证据；区分事实、测算、企业自述、观点和推断。

分级针对具体主张及其证据。同一材料对不同主张可有不同等级；官方身份、企业自述、个案或社群来源分别记录，不能直接决定证明力。复合主张先拆成可单独核对的部分，较窄部分的等级不能代表原整句成立。例如，可核验的付款记录能证明该笔交易，不能据此证明整个行业的收入水平。

| 等级 | 简单判断 | 使用边界 |
|---|---|---|
| S | 直接原始记录可得，所需对象、定义、时点和核验依据清楚，直接支持目标主张 | 可陈述其实际证明的事实 |
| A | 原文可得，方法、样本或独立核对满足该主张的验证需要 | 可作该范围内的核心证据 |
| B | 可定位的证据支持较窄主张，但自述、方法或口径限制会影响其更广用途 | 说明来源性质与支持范围后使用 |
| C | 有可靠转述或部分依据，目标主张仍有关键缺项待核 | 用于明确归属的转述、背景或补证线索 |
| D | 对目标主张仅有间接线索或尚未核实的表达，支持关系较弱 | 用于探索、案例线索或风险信号，继续核实 |
| Z | 内容已被证实编造、伪造或失实 | 排除失实部分，保留更正或反证定位 |

每条证据还标：来源类型、原文是否取得、方法是否清楚、是否独立来源、实际支持范围及核验状态（已核实／待核实／存在矛盾／已确认失实）。等级与核验状态配合使用；原文暂时无法取得时记录待核实，不因缺源判为Z。原文与报告说法相反时，保留原文作反证并更正该主张，不把矛盾自动等同于来源造假。

### 按材料类型审核

除通用分级外，按材料类型检查以下项目；缺项不能靠推测补齐，记入证据台账的限制或缺口。

| 材料 | 必查项 | 常见误用 |
|---|---|---|
| 数据、统计表、财报、融资数据 | 指标定义、统计期、地区、单位/币种、分子分母、样本和方法；增长率还要有基期 | 把媒体转述当原始数据；把公司披露、媒体估算和不同口径数据相加或比较。 |
| 新闻、公告和公司事件 | 原始公告/报道、事件发生日与发布日期、当时版本、被转述数据的原始出处 | 用新闻标题代替正文；把后续更正前的旧报道当最终事实。 |
| 行业/咨询/学术报告 | 发布机构、版本、数据截止日、样本与方法、原表/原图的页码；确认拿到的是全文而非摘要 | 只凭摘要或媒体摘录引用市场规模；把方法不明的估算写成事实。 |
| 政策与监管文件 | 发文机构、文号、日期、适用地区和对象；区分征求意见稿、正式文件和执行结果 | 把政策目标或支持方向写成已经产生的实际效果。 |

国内与国际数据必须分开记录：注明国家/地区、口径与可比条件；没有明确可比依据时，不得合并、直接类比或互相验证。

### 时效与证据不足

- 记录数据对应时期、发布日期、取得日期及版本，按研究时点和信息变化速度判断时效。当前价格、政策状态或产品能力应核对截至研究时点的有效版本；历史比较使用当时数据。只因材料年代较早不判失效，近期发布的材料也要检查其数据期和后续更正。
- 声称“已交叉验证”时，说明独立来源并排除同源转载。直接适用的原始记录可用于核实具体事实，不为凑来源数量重复搜索；原文缺失或方法缺项写明影响哪条主张。
- 证据不足时，保留已支持的较窄表述、明确归属的自述或案例，也可作为说明依据且可替换的情景参数。未经核实的量不能写成已证实事实；条件性测算应保留假设及其对结果的影响，关键缺口仍按任务补证。

### 3. 审核与二次桌研

数字或事实不一致时，不平均、不按“更合理”挑选。先对齐对象、时间、地区、单位、分母、样本、方法，再追查来源谱系。

现有材料不能裁定时，先用**补证任务单**说明要查什么，再执行二次桌研：

```text
待核主张：
现有说法：来源 A / 数值或表述；来源 B / 数值或表述
已核对项：对象、时间、地区、单位、分母、样本、方法、来源谱系
缺失项：原文 / 定义 / 分母 / 样本 / 方法 / 版本或更正（按实际填写）
补证目标：优先取得什么原始材料；需要补几条独立来源
完成标准：取得何种材料后才能判断“已解决”或“多口径并存”
```

- 有总路由时可交它协调；单独使用时，由当前 Agent 选择可用的搜索、浏览器、MCP、数据库或信息采集 Skill，查找原文、定义、方法及更正。任何特定采集 Skill 都不是前提。
- 按任务和用户授权选择渠道；仅允许免费时不用付费能力。没有可用渠道或用户不允许补搜时，保留具体缺口，不声称已完成核实。

新取得的材料仍是候选资料，须重新登记、去重、分级和比对，再给出处置建议。

补证后只给出以下一种处理建议：

- **已解决**：原文或更正能确认错误或解释差异；
- **多口径并存**：原文证明统计对象不同，分别保留范围；
- **未解决**：记录待核项及其对具体判断的影响，未核实部分不作已证实前提，已支持部分继续交接；
- **拒绝引用**：内容已确认失实，或关键缺项使其不能支持拟使用的主张，且无法改成有依据的较窄表述。只排除该部分或用法；可用的转述、案例及补证线索保留。缺少原文或未公开方法本身不等于失实。

禁止用百分比差异阈值、来源名气、转载数量或“看起来合理”裁定冲突。

### 4. 交接证据台账

每条可用证据保留：

`主张｜主张类型｜原文摘录/数值与单位｜来源与链接｜页码/段落｜时间/地区/版本｜定义/分母/样本/方法｜S-Z｜来源类型/原文状态/方法质量/独立性｜是否同源｜矛盾及核验状态｜能否使用及支持范围｜限制或待补材料`

同时交付：去重记录、矛盾台账和缺口清单。不得将台账汇总改写为报告结论。

## 最低检查

- 关键数字能回到原始链接/文件及具体页码、表号或段落；
- 比例有分母，增长率有基期，动态信息有取得日期；
- 同源转载没有被当作多源验证；
- 企业自述、政策目标和实际效果没有混为一谈；
- 未核实的内容没有被写成已证实事实，失实部分未作依据；情景参数、适用范围及影响结论的缺口可以定位。
- 政策原文只能证明政策内容；企业官网只能证明其当期公开说明，不能自动证明实际效果、收入或用户规模。

## 研究链路

可单独审核一批材料，也可在研究路由中审核采集结果、分析中的补充资料或核对最终交付物。成稿核对覆盖事实与证据、计算与推理、正文与图表及附件的一致性，并复查修改结果。输入不限于某个工具的输出；当前 Agent 使用可用的读取、计算、搜索和页面检查能力完成核对，其他 Skill 仅作可选协助。
