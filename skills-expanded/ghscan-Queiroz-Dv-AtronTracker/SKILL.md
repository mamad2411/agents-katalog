# Angular

## Regras

- Usar Angular moderno compatível com a versão do projeto.
- Preferir Reactive Forms para formulários complexos.
- Manter componentes focados em apresentação/orquestração.
- Evitar lógica de domínio espalhada no template.
- Não usar localStorage como fonte de autoridade para autorização.
- Respeitar guards e autorização do backend.
- Evitar APIs depreciadas.

Antes de introduzir uma abstração, procure uma implementação existente que possa ser reutilizada.
