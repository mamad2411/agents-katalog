# 宣传封面与静帧

封面不是“视频第一帧截图”，而是一张**独立可读的平面作品**。用户刷到它时只给 0.5 秒，标题必须自己成立。

## 运行前提

导出脚本随包发布，但运行时依赖不随 npm 包安装：

```sh
# 在仓库里（或自己的项目里）装一次
npm i -D playwright
npx playwright install chromium
```

只在本仓开发环境运行最省事（`npm install` 已带 Playwright）；从 npm 装包单独使用时，先执行上面的命令。脚本缺依赖会**直接失败并打印安装命令**，不会静默跳过：

- `缺少依赖 playwright` / `Cannot find package 'playwright'`：没装 Playwright，按上面装。
- `浏览器未安装` / `Executable doesn't exist`：Playwright 装了但 chromium 没下载，跑 `npx playwright install chromium`。

## 先定三件事

1. **平台与比例**：视频封面 `1080×1920`（9:16）；图文/小红书 `1080×1440`（3:4）；横版 `1920×1080`（16:9）。
2. **一句话主张**：不是产品名，是“我的什么经验，解决了什么问题”。
3. **证据**：真实 UI 卡片、真实数据、真实界面局部；没有就留白，不要伪造。

## 标题公式

优先用第一人称，二选一：

- **我的 + 具体任务/数量 + 终于/不再 + 具体痛点**
  - 例：`我的 20 个并行任务，终于不用一个个追了`
- **分享我的 + 方法名 + 结果**
  - 例：`分享我的 Leader Agent 工作法：20 个任务并行跑`

标题要同时满足：

- **是我的经验**：出现“我的/我”；不要写成产品说明书。
- **问题具体**：`一个个追`、`切来切去`、`人卡在循环里`，不要写“效率低”这种空词。
- **对读者有用**：副标给出方法或收益，例如“把追问交给 Leader Agent，人只负责决定”。

不要用：

- `AI 时代的高效工作法`（空，谁都能说）
- `dsh-leader-agent 产品介绍`（产品名不是主张）
- `提升 300% 效率`（没有证据的数字）

不要在一张封面里塞三个卖点。主标题 + 一个眉标 + 一句副标，够了。

## 版式

以 1080×1920 为基准：

- 四周安全区 ≥ 64px；底部品牌区与平台 UI 按钮留 ≥ 120px。
- 主标题 120–160px，2–4 行；最后一行可降到 60–80px，形成节奏。
- 眉标 22–28px 等宽字体；副标 36–44px；正文最小 28px。
- 一个主强调色 + 最多一个辅助暖色。数字/关键词用一个颜色，其余保持高对比白。
- 真实 UI 卡片放 2–3 张就够；整块看板缩小后文字不可读，只提供纹理，不提供信息。
- 深色底要有层次：径向光、细网格、噪点按需叠加，别盖住文字。
- 标题与素材之间留出呼吸区；宁可少一张卡，不要压住标题。

3:4 版本不是把 9:16 裁短：标题缩到 100–130px，素材卡缩到 2 张，底部品牌上移。16:9 则把标题放左、素材放右。

## 制作流程

1. 用固定 px 的 `#stage` 写一张静态 HTML，不依赖响应式断点；预览时整体缩放，不改字号。
2. 素材图放 `assets/`，最终需要单文件时再 base64 内嵌；不要引用外网图片。
3. 标题、眉标、副标、品牌四层先排版，再放素材；不要先堆截图再找地方塞字。
4. 用 [`scripts/render.mjs`](scripts/render.mjs) 导出，尺寸必须与平台一致。
5. 在 100% 和 25% 缩放下各看一遍：25% 时还能读出的才是标题，读不出的只是装饰。

```sh
# 9:16 视频封面
node .agents/skills/promo-stills/scripts/render.mjs \
  --url /absolute/path/cover-9x16.html \
  --out /absolute/path/cover-9x16.png \
  --width 1080 --height 1920

# 3:4 图文封面
node .agents/skills/promo-stills/scripts/render.mjs \
  --url /absolute/path/cover-3x4.html \
  --out /absolute/path/cover-3x4.png \
  --width 1080 --height 1440
```

脚本只做“打开页面 → 等字体与图片 → 截图”，不修改设计。页面有 `pageerror` 时直接失败，避免导出一张半成品。

## 验收

- [ ] 25% 缩略图下，主标题仍可读；没有字被截断或压到边缘。
- [ ] 主标题是“我的/分享我的”，不是纯产品名。
- [ ] 副标说清了方法或收益，不是重复主标题。
- [ ] 素材没有假数据、假头像、假 token；截图里的路径/用户名已脱敏。
- [ ] 所有图片 `naturalWidth > 0`；没有外网依赖。
- [ ] 9:16 / 3:4 / 16:9 各自独立排版，不是简单裁切。
- [ ] 输出文件尺寸、文件名、平台用途一一对应。
