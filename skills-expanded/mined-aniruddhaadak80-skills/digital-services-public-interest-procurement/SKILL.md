# Run technology procurement that avoids lock-in

> Open standards, exit clauses, data portability, and evaluation weighting beyond lowest bid.

**Track:** 🏛️ Public Sector & GovTech · **Domain:** Digital Services · **Level:** advanced · **~45 min**

**Who this is for:** Civic Technologists, Program Managers, Policy Analysts, Gov IT Teams

## When to Use This Skill

Open standards, exit clauses, data portability, and evaluation weighting beyond lowest bid.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Specify outcomes and open standards, not brand names
2. Require data export in documented formats as contract condition
3. Weight total-cost-of-ownership over N years, incl. exit costs
4. Score maintainability and team transferability in evaluation
5. Include government-held IP/reuse rights for custom builds
6. Pilot before enterprise award whenever legally possible

## Common Pitfalls

- Proprietary formats making exit cost infinite
- Lowest-bid winners unable to actually deliver
