# Build proof-of-work that beats credentials

> Case studies with problem→approach→outcome narratives and verified public artifacts.

**Track:** 🎯 Career & Job Search · **Domain:** Search Assets · **Level:** intermediate · **~35 min**

**Who this is for:** Job Seekers, Career Changers, New Grads, Anyone Levelling Up

## When to Use This Skill

Case studies with problem→approach→outcome narratives and verified public artifacts.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Pick 3 projects showing range: depth, collaboration, and outcome ownership
2. Structure each as situation → constraints → your decisions → measurable result
3. Link verifiable artifacts: repos, live demos, merged PRs, shipped metrics
4. Audit links yearly like a footprint audit — dead links kill credibility
5. Write the 'what I'd do differently' section; seniority shows in reflection
6. Match portfolio depth to target role level, not maximum effort everywhere

## Common Pitfalls

- Ten half-finished demos instead of three polished cases
- Group projects presented without clarifying your exact contribution
