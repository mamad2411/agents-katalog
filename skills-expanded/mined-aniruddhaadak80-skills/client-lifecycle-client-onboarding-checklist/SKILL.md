# Onboard clients like a product company

> Structured kickoff, access collection, comms rhythm, and success definition starting engagements right.

**Track:** 💼 Freelance & Business · **Domain:** Client Lifecycle · **Level:** foundation · **~25 min**

**Who this is for:** Freelancers, Consultants, Agencies, Independent Developers

## When to Use This Skill

Structured kickoff, access collection, comms rhythm, and success definition starting engagements right.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Kickoff agenda: goals, stakeholders, decision process, comms channels
2. Collect ALL accesses before start date via secure checklist
3. Set weekly update template + response-time expectations mutually
4. Define what 'done' means for phase one in writing
5. Introduce them to your process doc; boundaries stated kindly
6. 30-day check comparing delivered vs promised explicitly

## Common Pitfalls

- Week-one chaos from missing credentials and unclear owners
- Success criteria discovered at invoice time
