# Control scope creep professionally

> Change requests, written confirmations, and tradeoff framing protecting margins and relationships.

**Track:** 💼 Freelance & Business · **Domain:** Client Delivery · **Level:** intermediate · **~25 min**

**Who this is for:** Freelancers, Consultants, Agencies, Independent Developers

## When to Use This Skill

Change requests, written confirmations, and tradeoff framing protecting margins and relationships.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. SOW lists explicit exclusions, not just inclusions
2. Log every 'small favor' request in a visible tracker
3. Respond to creep with options: add budget, swap scope, or phase later
4. Confirm any verbal changes in same-day recap email
5. Re-baseline timeline visibly when scope changes materially
6. Debrief post-project: where creep entered, plug that door

## Common Pitfalls

- Absorbing 'quick fixes' until resentment explodes
- Change requests raised at invoice time
