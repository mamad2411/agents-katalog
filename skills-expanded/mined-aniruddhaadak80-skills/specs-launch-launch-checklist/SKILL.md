# Run launches with a go/no-go checklist

> Coordinated release across support, marketing, legal, and engineering with rollback plans.

**Track:** 📋 Product Management · **Domain:** Specs & Launch · **Level:** intermediate · **~30 min**

**Who this is for:** Product Managers, Product Owners, Founders, Product Analysts

## When to Use This Skill

Coordinated release across support, marketing, legal, and engineering with rollback plans.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Freeze scope two weeks out; bug-fix-only policy
2. Verify analytics events fire correctly in staging AND preview
3. Support briefed with FAQ, known issues, escalation path
4. Legal/privacy sign-off for anything touching personal data
5. Rollback plan rehearsed: flags off or previous version restore
6. Schedule T+1 and T+7 metric reviews before celebrating

## Common Pitfalls

- Analytics broken on day one making results unreadable
- Support discovering features from user tickets
