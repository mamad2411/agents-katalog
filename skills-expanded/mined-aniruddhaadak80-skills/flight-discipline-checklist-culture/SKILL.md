# Use checklists as culture, not compliance

> Challenge-response execution, no-interruption rules, and sterile cockpit below 10,000ft.

**Track:** ✈️ Aviation & Aerospace Ops · **Domain:** Flight Discipline · **Level:** foundation · **~25 min**

**Who this is for:** Pilots, Flight Ops, Safety Managers, Maintenance Engineers, Aviation PMs

## When to Use This Skill

Challenge-response execution, no-interruption rules, and sterile cockpit below 10,000ft.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Execute challenge-response verbally: both pilots verify each item
2. Any interruption restarts the checklist from the top — always
3. Sterile cockpit below 10,000ft: operational talk only, no exceptions for VIPs
4. Never memory-substitute flows for published checklist items
5. Report checklist deviations in SMS without fear — data beats shame
6. Update checklists through your change process when procedures change

## Common Pitfalls

- Muscle-memory 'do-verify' skipping actual verification
- Checklist interrupted by ATC and never restarted
