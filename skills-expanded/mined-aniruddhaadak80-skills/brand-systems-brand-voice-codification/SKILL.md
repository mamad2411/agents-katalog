# Codify brand voice so anyone (or any agent) can write on-brand

> Voice attributes with do/don't pairs, vocabulary allowlists, and worked examples across channels.

**Track:** 📣 Marketing & Growth · **Domain:** Brand Systems · **Level:** intermediate · **~35 min**

**Who this is for:** Growth Marketers, Content Strategists, Lifecycle Marketers, Founders

## When to Use This Skill

Voice attributes with do/don't pairs, vocabulary allowlists, and worked examples across channels.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Define 3-4 voice attributes as spectrums ('playful but never silly')
2. For each attribute write three do/don't example pairs from real copy
3. Maintain vocabulary lists: words we own, words we ban, words we're neutral on
4. Channel adaptations documented: support ≠ social ≠ legal tone shifts
5. Include two full worked examples: one good post, one bad post annotated
6. Test codification: new writer produces on-brand draft in one pass using only the guide

## Common Pitfalls

- Adjective soup ('bold yet approachable') without behavioral examples
- Guidelines locked in PDFs no working writer opens
