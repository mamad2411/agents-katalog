> Riskiest assumption isolated, smallest build shipped, honest signal collected.

Riskiest assumption isolated, smallest build shipped, honest signal collected.

## Journey Steps

1. Step 1 — Cut MVP scope without cutting the point: start with "Write the riskiest assumption sentence: 'This works if…'"
2. Step 2 — Read validation signals honestly: start with "Count actions, not compliments: pre-orders, waitlist signups, LOIs"
3. How it fits together: Scope cuts are the product. Concierge versions count as MVPs.
