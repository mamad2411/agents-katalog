# Run design-stage computational checks

> In-silico screening of designed constructs: specificity scoring, off-target checks, and documentation gates — always paired with institutional biosafety approval.

**Track:** 🧬 Biotech & Pharma · **Domain:** Bioinformatics · **Level:** advanced · **~40 min**

**Who this is for:** Bioinformaticians, Lab Scientists, Regulatory Affairs, Genetic Engineers, Clinical Data Managers

## When to Use This Skill

In-silico screening of designed constructs: specificity scoring, off-target checks, and documentation gates — always paired with institutional biosafety approval.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Confirm institutional biosafety committee approval covers this construct class
2. Score target specificity computationally; flag high-homology regions
3. Check designed elements for problematic repeats/restriction sites
4. Record every design parameter and tool version in the lab notebook system
5. Route flagged designs through supervisor review before any ordering
6. Archive sequences and rationales to the registered inventory

## Common Pitfalls

- Skipping specificity screening because 'previous round worked'
- Design records living only in chat threads
