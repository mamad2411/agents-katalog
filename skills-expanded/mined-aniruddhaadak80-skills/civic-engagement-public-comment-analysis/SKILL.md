# Analyze public comments without bias amplification

> Representative sampling, theme coding with reliability checks, and reporting honoring minority voices.

**Track:** 🏛️ Public Sector & GovTech · **Domain:** Civic Engagement · **Level:** intermediate · **~35 min**

**Who this is for:** Civic Technologists, Program Managers, Policy Analysts, Gov IT Teams

## When to Use This Skill

Representative sampling, theme coding with reliability checks, and reporting honoring minority voices.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Inventory comment sources; weight channels by reach, not volume alone
2. Deduplicate campaigns while preserving legitimate distinct senders
3. Code themes with double-coding on a sample; measure agreement
4. Report majority AND minority themes explicitly with counts
5. Publish methodology so conclusions can be scrutinized
6. Feed results into decision documents with responses to themes raised

## Common Pitfalls

- Form-letter campaigns counted as thousands of unique voices
- Analysis confirming the pre-written decision
