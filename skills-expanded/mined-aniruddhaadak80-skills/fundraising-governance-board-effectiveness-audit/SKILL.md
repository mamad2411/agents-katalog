# Audit board effectiveness honestly

> Roles, composition, meeting design, and give/get expectations aligned to actual strategy needs.

**Track:** 🌍 Nonprofit & Impact · **Domain:** Fundraising & Governance · **Level:** foundation · **~30 min**

**Who this is for:** Nonprofit Leaders, Program Managers, Fundraisers, Board Members

## When to Use This Skill

Roles, composition, meeting design, and give/get expectations aligned to actual strategy needs.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Map current skills vs strategy needs (finance? legal? community voice?)
2. Clarify fiduciary vs advisory roles in writing for every member
3. Design meetings for decisions: consent agendas, pre-reads, one big question
4. Set explicit give/get expectations asked at recruitment, revisited annually
5. Run self-assessment yearly with anonymous input
6. Recruit to gaps with real role descriptions, not warm-body fills

## Common Pitfalls

- Boards micromanaging operations while skipping fiduciary duty
- Meeting time consumed by staff reports over decisions
