# Drive quality with inspection test plans

> Hold points, witness points, and documented ITPs preventing rework discovery too late.

**Track:** 🏗️ Construction & Built Environment · **Domain:** Site Execution · **Level:** intermediate · **~35 min**

**Who this is for:** Project Engineers, Site Managers, Cost Estimators, Contractors

## When to Use This Skill

Hold points, witness points, and documented ITPs preventing rework discovery too late.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. ITP per work package: activities, acceptance criteria, hold/witness points mapped
2. Notify inspectors per contract notice periods; never bury holds
3. Record results same-day with photos keyed to location references
4. Non-conformances tracked to closure with disposition (repair/rework/accept)
5. Trend NCR types monthly; repeat classes get process fixes not re-training alone
6. Close-out book compiled continuously, not at handover panic

## Common Pitfalls

- Covered work inspected via memory and promises
- Hold points waived verbally under schedule pressure
