# Package publishes for discovery

> Titles, thumbnails, descriptions, and chapters engineered as a system per platform.

**Track:** 🎬 Media & Video Production · **Domain:** Post & Publishing · **Level:** foundation · **~25 min**

**Who this is for:** Video Creators, Podcasters, Documentary Makers, Content Studios

## When to Use This Skill

Titles, thumbnails, descriptions, and chapters engineered as a system per platform.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Title promises specific payoff; thumbnail shows tension or outcome, minimal text
2. Test title/thumbnail as a pair — they argue or agree as one unit
3. First line of description restates the promise for search
4. Chapters named by content curiosity, not 'Part 1'
5. Adapt aspect ratio, length, and hook timing per platform natively
6. Log packaging hypotheses with results; build your own playbook

## Common Pitfalls

- Same file cross-posted everywhere identically
- Thumbnail text unreadable at feed size
