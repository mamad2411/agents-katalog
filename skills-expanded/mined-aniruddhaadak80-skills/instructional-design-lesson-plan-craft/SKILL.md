# Design lessons around attention rhythms

> Open with curiosity, alternate instruction with active practice, close with retrieval.

**Track:** 🎓 Education & Teaching · **Domain:** Instructional Design · **Level:** intermediate · **~35 min**

**Who this is for:** Teachers, Instructional Designers, Course Creators, Trainers

## When to Use This Skill

Open with curiosity, alternate instruction with active practice, close with retrieval.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Hook in first 4 minutes tied to today's objective, not trivia
2. Direct instruction segments ≤10 minutes before activity switch
3. Every explanation followed by immediate low-stakes practice
4. Build checks-for-understanding every segment (cold call safely, mini-whiteboards)
5. Plan misconception responses in advance, not improv
6. Close with retrieval: students reconstruct key idea unprompted

## Common Pitfalls

- Beautiful slides doing the learning for students
- No planned response to the #1 predictable confusion
