# Keep lab notebooks worth citing

> Daily entries linking intent, method versions, observations, and next actions.

**Track:** 🔬 Scientific Research · **Domain:** Reproducibility · **Level:** foundation · **~25 min**

**Who this is for:** Researchers, PhD Students, Postdocs, Research Software Engineers

## When to Use This Skill

Daily entries linking intent, method versions, observations, and next actions.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Entry per session: goal, exact methods/versions, raw observations
2. Note failures fully — negative results are future time savers
3. Attach instrument outputs immediately with filenames explained
4. Sign/date entries; never backfill silently (GxP adjacent habit)
5. Index by experiment ID referenced everywhere else
6. Weekly review: unresolved questions become next week's plan

## Common Pitfalls

- Notebook as polished rewrite losing real-time value
- Critical parameters living only in memory
