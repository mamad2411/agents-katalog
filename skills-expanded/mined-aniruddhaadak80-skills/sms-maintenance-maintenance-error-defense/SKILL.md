# Defend against maintenance error systematically

> Task interruption protocols, independent inspections, and tool control closing classic error chains.

**Track:** ✈️ Aviation & Aerospace Ops · **Domain:** SMS & Maintenance · **Level:** intermediate · **~30 min**

**Who this is for:** Pilots, Flight Ops, Safety Managers, Maintenance Engineers, Aviation PMs

## When to Use This Skill

Task interruption protocols, independent inspections, and tool control closing classic error chains.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Interruption protocol: mark the task, never resume from memory (dirty-finger rule)
2. Independent inspection required for critical/duplicate-inspection items
3. Tool and hardware control: shadow boards + end-of-task reconciliation
4. Record discrepancies in writing immediately; verbal-only handoffs forbidden
5. Shift turnover via written log plus verbal walkthrough of open items
6. Mine error reports yearly for training themes by task type

## Common Pitfalls

- 'Almost done' tasks resumed incorrectly after distraction
- Duplicate inspections signed by the person who did the work
