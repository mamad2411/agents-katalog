# Escalate deterioration early with objective triggers

> Use early-warning scores and defined thresholds so concern becomes action without hesitation cost.

**Track:** 🏥 Healthcare & Clinical · **Domain:** Clinical Workflow · **Level:** intermediate · **~25 min**

**Who this is for:** Nurses, Physicians, Clinical Managers, Health Informaticists

## When to Use This Skill

Use early-warning scores and defined thresholds so concern becomes action without hesitation cost.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Track early-warning score trend, not single readings
2. Set personal trigger: score X or rise Y means senior review within Z minutes
3. Present escalation in ISBAR with the numbers that triggered you
4. Document time of concern, who notified, response received
5. If response inadequate, use chain-of-command explicitly — policy protects this
6. Debrief after events: what threshold would have fired earlier?

## Common Pitfalls

- Normalizing gradual overnight decline across serial readings
- Waiting for rounds when criteria already met
