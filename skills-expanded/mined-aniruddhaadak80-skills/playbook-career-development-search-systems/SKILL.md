# Playbook: Run your job search like a system

> Truth-effective assets converting interviews into defensible offers.

**Track:** 🗺️ Career & Job Search · **Domain:** Journey Playbooks · **Level:** journey · **~110 min**

**Who this is for:** Job Seekers, Career Changers, New Grads, Anyone Levelling Up

## When to Use This Skill

Truth-effective assets converting interviews into defensible offers.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Build a resume that is true AND effective: start with "Convert duties to outcomes: action verb + what changed + metric where real"
2. Step 2 — Prepare a STAR story bank, not memorized scripts: start with "Inventory career moments: conflict, failure, leadership, ambiguity, impact"
3. Step 3 — Negotiate offers without fear or fantasy: start with "Anchor on market bands from multiple current sources for THIS role/city"
4. How it fits together: Assets ? stories ? negotiation, in that order. Each compounds the last.
