# Engineer the menu on data, not vibes

> Popularity × margin matrix driving placement, pricing, and cull decisions each season.

**Track:** 🍽️ Food & Beverage Ops · **Domain:** Kitchen Consistency · **Level:** intermediate · **~40 min**

**Who this is for:** Chefs, F&B Managers, Restaurant Owners, Catering Leads

## When to Use This Skill

Popularity × margin matrix driving placement, pricing, and cull decisions each season.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Classify items: stars (high-high), plowhorses (popular-low margin), puzzles, dogs
2. Reposition stars to golden zones; rename/rephoto puzzles before cutting
3. Test price moves ±5% on plowhorses before dramatic changes
4. Cull dogs ruthlessly but keep one 'traffic anchor' if it drives visits
5. Watch ingredient crossover — cutting one dish may strand inventory
6. Repeat analysis every season with same metrics for trend honesty

## Common Pitfalls

- Menu redesigns driven by chef boredom instead of matrix
- Margin math ignoring waste and prep labor
