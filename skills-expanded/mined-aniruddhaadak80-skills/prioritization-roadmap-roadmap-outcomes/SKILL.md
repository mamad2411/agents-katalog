# Build outcome-based roadmaps

> Communicate problems and metrics per quarter, leaving solution space for teams.

**Track:** 📋 Product Management · **Domain:** Prioritization & Roadmaps · **Level:** intermediate · **~35 min**

**Who this is for:** Product Managers, Product Owners, Founders, Product Analysts

## When to Use This Skill

Communicate problems and metrics per quarter, leaving solution space for teams.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Structure by quarter → outcome metric → problem statements, not feature lists
2. Attach each bet to a company-level objective explicitly
3. Mark confidence: now/next/later with evidence tags
4. Reserve ~20% capacity for unplanned learning and debt
5. Review monthly against leading indicators; kill zombie bets
6. Share externally-safe version with customers to reset expectations

## Common Pitfalls

- Gantt charts of features pretending certainty
- Roadmap as promise archive nobody revisits
