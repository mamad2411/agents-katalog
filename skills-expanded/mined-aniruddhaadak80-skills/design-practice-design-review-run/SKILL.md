# Run design reviews that improve work

> Structured critique rituals: intent first, questions before solutions, owner decides.

**Track:** 🧠 UX Research & Design · **Domain:** Design Practice · **Level:** intermediate · **~25 min**

**Who this is for:** UX Researchers, Product Designers, Design Leads, Service Designers

## When to Use This Skill

Structured critique rituals: intent first, questions before solutions, owner decides.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Designer opens with context, constraint, and specific feedback asks
2. Reviewers describe observed effects before proposing changes
3. Questions outnumber statements; 'what if' over 'you should'
4. Timebox per artifact; park tangents visibly
5. Owner records decisions and explicitly defers or accepts each thread
6. Follow up next review on prior feedback resolution

## Common Pitfalls

- HiPPO redesigns announced as feedback
- Reviews becoming taste debates without user grounding
