# Pre-produce shoots that don't improvise

> Shot lists, location scouts, gear checks, and contingency plans making shoot days boring.

**Track:** 🎬 Media & Video Production · **Domain:** Pre-Production · **Level:** foundation · **~30 min**

**Who this is for:** Video Creators, Podcasters, Documentary Makers, Content Studios

## When to Use This Skill

Shot lists, location scouts, gear checks, and contingency plans making shoot days boring.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Write the one-sentence deliverable definition before anything else
2. Shot list from the edit backwards: every shot has a destination
3. Scout locations at shoot TIME of day for light and noise reality
4. Gear checklist per shot type; batteries and media double what seems enough
5. Contingency plan per risk: weather, noise, subject cancellation
6. Confirm everyone 24h before with call sheet including parking/access notes

## Common Pitfalls

- "We'll figure it out there" burning golden-hour hours
- Missing B-roll discovered in the edit
