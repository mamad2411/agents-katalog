# Commission systems with sign-off rigor

> Test sequences, punch lists, and turnover documentation preventing day-one surprises.

**Track:** 🔋 Energy & Renewables · **Domain:** Project Development · **Level:** intermediate · **~30 min**

**Who this is for:** Solar Engineers, Energy Analysts, Project Developers, O&M Teams

## When to Use This Skill

Test sequences, punch lists, and turnover documentation preventing day-one surprises.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Verify installation against stamped design before energization tests
2. Run test sequence per spec: continuity, insulation, polarity, then live tests
3. Record string-level baselines — they're your degradation reference forever
4. Punch-list every deficiency with owner + deadline before turnover
5. Training handoff to O&M includes docs, credentials, and monitoring walkthrough
6. Archive commissioning package searchable by future troubleshooting

## Common Pitfalls

- Energizing on partial inspections under schedule pressure
- String baselines never recorded, degradation unknowable
