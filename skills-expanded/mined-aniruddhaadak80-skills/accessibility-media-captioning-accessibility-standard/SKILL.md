# Caption and describe to accessibility standard

> Accuracy thresholds, speaker ID, sound description, and audio-description planning from production.

**Track:** 🎬 Media & Video Production · **Domain:** Accessible Media · **Level:** foundation · **~30 min**

**Who this is for:** Video Creators, Podcasters, Documentary Makers, Content Studios

## When to Use This Skill

Accuracy thresholds, speaker ID, sound description, and audio-description planning from production.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Target 99% accuracy minimum; auto-captions are drafts, never deliverables
2. Identify speakers and meaningful non-speech sounds ([laughter], [door slams])
3. Frame-rate captions to speech rhythm; reading speed limits respected
4. Plan shots for audio-description feasibility during production
5. Test with deaf/HoH and blind reviewers before publishing
6. Version caption files alongside video; re-cut means re-caption

## Common Pitfalls

- Auto-captions shipping with names mangled beyond recognition
- Description crammed into nonexistent gaps post-production
