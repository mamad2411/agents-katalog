# Playbook: Reset a stale roadmap

> Quarterly outcome-based roadmap replacing the feature promise list.

**Track:** 🗺️ Product Management · **Domain:** Journey Playbooks · **Level:** journey · **~60 min**

**Who this is for:** Product Managers, Product Owners, Founders, Product Analysts

## When to Use This Skill

Quarterly outcome-based roadmap replacing the feature promise list.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Build outcome-based roadmaps: start with "Structure by quarter → outcome metric → problem statements, not feature lists"
2. Step 2 — Choose a prioritization framework that fits your stage: start with "Inventory current backlog candidates with owners attached"
3. How it fits together: Kill zombie bets publicly. Roadmaps earn trust by subtraction as much as addition.
