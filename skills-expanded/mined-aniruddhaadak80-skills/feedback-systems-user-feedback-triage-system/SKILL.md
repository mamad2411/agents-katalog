# Triage user feedback into signal, not noise

> Structured capture, revenue-weighted pattern analysis, and closed-loop responses feeding roadmaps.

**Track:** 📋 Product Management · **Domain:** Feedback Systems · **Level:** intermediate · **~30 min**

**Who this is for:** Product Managers, Product Owners, Founders, Product Analysts

## When to Use This Skill

Structured capture, revenue-weighted pattern analysis, and closed-loop responses feeding roadmaps.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Centralize all channels into one tagged repository weekly minimum
2. Tag by theme + severity + account value; verbatims preserved always
3. Weight patterns by reach × severity, not loudest voice frequency
4. Close the loop with reporters when their item ships — retention gold
5. Review top themes monthly against roadmap; justify divergences in writing
6. Purge 'build everything' conclusions by forcing rank-ordering exercises

## Common Pitfalls

- Feedback collected into voids, training users to stop talking
- Enterprise squeaky wheels overriding quiet majority signals
