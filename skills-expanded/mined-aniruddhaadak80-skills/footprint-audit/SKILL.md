# Audit an online professional footprint

> Verify claims, detect namesake contamination, and flag privacy leaks across public profiles. Use during background reviews, bio writing, personal-brand cleanups, or pre-publication fact checks.

**Track:** 👥 People & HR · **Domain:** Policy & Engagement · **Level:** intermediate · **~40 min**

**Who this is for:** HR Managers, Recruiters, People Ops, Team Leads

## When to Use This Skill

Verify claims, detect namesake contamination, and flag privacy leaks across public profiles. Use during background reviews, bio writing, personal-brand cleanups, or pre-publication fact checks.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Enumerate surfaces: code hosts, socials, blogs, portfolios, badge pages
2. Verify each claim at its primary source; record URL and date checked
3. Label every claim VERIFIED / UNVERIFIED / CONTAMINATED (namesake)
4. Search name + achievement pairs to catch other-person attribution
5. Flag leaked PII (phone, DOB) onto a takedown list — never republish it
6. Draft bios drawing ONLY from verified items with conservative rounding

## Common Pitfalls

- Trusting AI answers blending namesakes
- Republishing contact data because 'it is already public'
