# Audit product pages for conversion leaks

> Above-fold promise, objection handling, trust signals, and friction mapping per template.

**Track:** 🛍️ E-commerce & Retail · **Domain:** Conversion & Merchandising · **Level:** intermediate · **~35 min**

**Who this is for:** E-commerce Managers, Merchandisers, Retail Operators, DTC Founders

## When to Use This Skill

Above-fold promise, objection handling, trust signals, and friction mapping per template.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Above fold answers: what is it, who's it for, why this one — in 3 seconds
2. Gallery shows scale/use cases, not just studio angles
3. Objections answered inline near decision points (sizing near size selector)
4. Shipping/returns cost visible BEFORE checkout surprise
5. Mobile-first scroll test: would YOU buy on a phone one-handed?
6. Fix leaks by expected impact before running new traffic

## Common Pitfalls

- Beautiful hero videos pushing buy-button below fold on mobile
- Return policy discovered at payment step
