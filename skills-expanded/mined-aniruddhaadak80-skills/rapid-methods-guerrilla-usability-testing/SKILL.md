# Run guerrilla usability tests that still count

> Fast hallway/café testing with tight tasks and honest limits about what the data supports.

**Track:** 🧠 UX Research & Design · **Domain:** Rapid Methods · **Level:** foundation · **~20 min**

**Who this is for:** UX Researchers, Product Designers, Design Leads, Service Designers

## When to Use This Skill

Fast hallway/café testing with tight tasks and honest limits about what the data supports.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Test ONE flow with 5 participants; depth beats breadth here
2. Script tasks identical for everyone; improvise probes only
3. Time-box sessions to 10 minutes respecting volunteers
4. Note severity immediately after each session while fresh
5. Stop when three consecutive users succeed — you learned it
6. Report as directional evidence, never statistical proof

## Common Pitfalls

- Leading participants past obstacles to finish the sample
- Generalizing café demographics to your entire audience
