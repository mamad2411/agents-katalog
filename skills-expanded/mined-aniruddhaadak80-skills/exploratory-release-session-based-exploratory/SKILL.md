# Run session-based exploratory testing

> Charter-driven timeboxed sessions producing documented findings, not random clicking.

**Track:** 🧪 QA & Testing · **Domain:** Exploratory & Release · **Level:** intermediate · **~35 min**

**Who this is for:** QA Engineers, SDETs, Test Automation Engineers, Developers

## When to Use This Skill

Charter-driven timeboxed sessions producing documented findings, not random clicking.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Write charters: 'Explore X with Y focus using Z resources'
2. Timebox 60-90 min sessions; split if unfocused
3. Log notes live: what tried, what observed, questions raised
4. Debrief findings into tickets immediately with repro steps
5. Vary personas/data/environment per session rotation
6. Track charter coverage to expose unexplored corners

## Common Pitfalls

- Exploratory as unplanned filler when automation lags
- Findings lost in prose nobody triages
