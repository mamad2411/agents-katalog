# Run a calm incident response flow

> Roles, comms cadence, and mitigation-first mindset that turns chaos into checklist.

**Track:** ☁️ DevOps & Cloud · **Domain:** Incidents & Edge Deploys · **Level:** intermediate · **~30 min**

**Who this is for:** DevOps Engineers, SREs, Cloud Architects, Platform Engineers

## When to Use This Skill

Roles, comms cadence, and mitigation-first mindset that turns chaos into checklist.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Declare early; assign Incident Commander separate from fixers
2. Mitigate first (rollback, feature-flag off), root-cause later
3. Post status updates every 30 min even when 'still investigating'
4. Log timeline entries with timestamps as decisions happen
5. End with customer-facing summary plus internal blameless retro within 48h
6. Convert every retro action item into tracked issues with owners

## Common Pitfalls

- Hero debugging without comms, stakeholders blind
- Retro actions dying in a doc
