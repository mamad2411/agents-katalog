# Keep controlled drug logs audit-proof

> Dual-signature logging, running balances, and discrepancy response meeting regulatory scrutiny.

**Track:** 🐾 Veterinary Medicine · **Domain:** Practice Operations · **Level:** advanced · **~25 min**

**Who this is for:** Veterinarians, Vet Techs, Practice Managers, Animal Welfare Teams

## When to Use This Skill

Dual-signature logging, running balances, and discrepancy response meeting regulatory scrutiny.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Every in/out entry dual-signed with date, patient, dose, running balance
2. Physical count reconciles against log balance on defined schedule, initialed
3. Any discrepancy reported internally same day and investigated with timeline
4. Access limited to licensed staff; keys/locks accountability assigned
5. Wastage witnessed, recorded, and signed by both parties always
6. Mock inspection annually using your own logs cold

## Common Pitfalls

- Balance column arithmetic errors compounding unnoticed
- Single-person counts normalizing quiet diversion
