# Playbook: Prepare for a GxP inspection

> Documentation, audit trails, and staff narratives inspection-day ready.

**Track:** 🗺️ Biotech & Pharma · **Domain:** Journey Playbooks · **Level:** journey · **~75 min**

**Who this is for:** Bioinformaticians, Lab Scientists, Regulatory Affairs, Genetic Engineers, Clinical Data Managers

## When to Use This Skill

Documentation, audit trails, and staff narratives inspection-day ready.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Practice GxP-grade documentation habits: start with "Record observations contemporaneously; backfilling is a finding"
2. Step 2 — Keep clinical trial data inspection-ready: start with "Configure edit checks at study build, not during enrollment"
3. How it fits together: Rehearse request-to-record retrieval. Speed of retrieval IS the inspection impression.
