# Triage renovations by ROI before spending

> Cost-vs-value ranking separating value-adding work from personal-preference spending.

**Track:** 🏘️ Real Estate · **Domain:** Deal Analysis · **Level:** intermediate · **~30 min**

**Who this is for:** Agents, Investors, Property Managers, Analysts

## When to Use This Skill

Cost-vs-value ranking separating value-adding work from personal-preference spending.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Fix safety/functionality first: they gate every sale regardless of ROI tables
2. Rank cosmetic work by local cost-vs-value report data
3. Get three contractor bids minimum; verify licenses and timelines
4. Hold a 15% contingency on every scope, non-negotiable
5. Stage the two rooms photography sells: kitchen and primary bath decisions
6. Track actuals vs estimate per line for your next deal's calibration

## Common Pitfalls

- Over-improving past neighborhood ceiling price
- Scope creep via 'while we're at it' change orders
