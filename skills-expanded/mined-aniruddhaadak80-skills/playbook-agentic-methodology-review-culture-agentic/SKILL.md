# Playbook: Build review culture into agent workflows

> Requesting AND receiving review handled with evidence on both sides.

**Track:** 🗺️ Agentic Methodology · **Domain:** Journey Playbooks · **Level:** journey · **~40 min**

**Who this is for:** Agent Power Users, AI-Native Engineers, Teams Shipping With Agents, Solo Builders

## When to Use This Skill

Requesting AND receiving review handled with evidence on both sides.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Receive agent code review without ego or obedience: start with "Reproduce or locate every claim before acting; reviewers are fallible too"
2. Step 2 — Verify before claiming done — evidence over claims: start with "Run the actual verification command fresh at claim time, not from memory"
3. How it fits together: Agents that verify before claiming + humans that verify before applying = trustworthy velocity.
