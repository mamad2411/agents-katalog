# Communicate asynchronously like a distributed-native

> Written updates, decision records, and meeting hygiene across timezones.

**Track:** 🧰 Engineering Essentials · **Domain:** Collaboration Workflow · **Level:** intermediate · **~20 min**

**Who this is for:** All Software Engineers

## When to Use This Skill

Written updates, decision records, and meeting hygiene across timezones.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Default to written updates with context links over synchronous asks
2. Structure messages: decision needed / FYI / blocked, upfront
3. Record decisions in ADRs searchable later, not chat scrolls
4. Set response-time expectations per channel explicitly
5. Meetings need agenda + owner + written outcome or get cancelled
6. Over-communicate status during incidents and crunch weeks

## Common Pitfalls

- Decisions living only in someone's DMs
- Meeting-recurrence zombie invites
