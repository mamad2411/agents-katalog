# Write tutorials people actually finish

> Fast first win, verifiable checkpoints, and failure exits keeping momentum.

**Track:** ✍️ Technical Writing · **Domain:** API Reference & Guides · **Level:** intermediate · **~35 min**

**Who this is for:** Technical Writers, Developer Advocates, Engineers Who Document, Content Leads

## When to Use This Skill

Fast first win, verifiable checkpoints, and failure exits keeping momentum.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Promise specific outcome in title; deliver it under 15 minutes
2. Show expected result early with screenshot of finished state
3. Verify-everything: each step includes what user should see
4. Number recovery paths for common failures inline
5. Cut every sentence not moving toward the promised outcome
6. Test with two fresh users watching silently; fix stumbles

## Common Pitfalls

- Prerequisite walls before first success
- 'Simply' doing invisible multi-step things
