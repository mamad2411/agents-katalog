# Run usability tests that reveal truth

> Task-based sessions with neutral scripting, think-aloud discipline, and severity-rated findings.

**Track:** 🧠 UX Research & Design · **Domain:** Research Methods · **Level:** foundation · **~35 min**

**Who this is for:** UX Researchers, Product Designers, Design Leads, Service Designers

## When to Use This Skill

Task-based sessions with neutral scripting, think-aloud discipline, and severity-rated findings.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Write tasks as goals ('pay this invoice'), never UI instructions ('click Billing')
2. Pilot the script on a colleague; fix leading phrases
3. Remind participants their failures are findings, not mistakes
4. Probe silence: 'what are you thinking?' beats helping
5. Rate issues post-session: severity × frequency, quotes attached
6. Deliver top-5 ranked fixes within 48h while fresh

## Common Pitfalls

- Demonstrating the flow 'just to save time' contaminating results
- Testing with teammates who know the product
