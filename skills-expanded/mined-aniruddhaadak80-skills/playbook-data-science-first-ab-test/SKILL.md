## Journey Steps

1. Step 1 — Design an A/B test you can trust: start with "Define one primary metric with minimum detectable effect from business value"
2. Step 2 — Build cohort and funnel analyses that hold up: start with "Define cohorts by first meaningful action, not signup alone"
3. How it fits together: Sample size math BEFORE launch. Peeking destroys more experiments than bugs do.
