# Read unfamiliar codebases strategically

> Entry-point tracing, test-first reading, and boundary mapping building accurate mental models fast.

**Track:** 🧰 Engineering Essentials · **Domain:** Diagnostic Foundations · **Level:** foundation · **~25 min**

**Who this is for:** All Software Engineers

## When to Use This Skill

Entry-point tracing, test-first reading, and boundary mapping building accurate mental models fast.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Run the test suite first — tests are executable documentation of intent
2. Trace one real request end-to-end from entry point outward
3. Map module boundaries by imports; draw what you learn immediately
4. Read git log around files you touch for historical 'why' context
5. Note unknowns as questions; batch-ask humans after self-study attempt
6. Ship a tiny fix early — momentum beats comprehensive understanding first

## Common Pitfalls

- Reading alphabetically instead of along execution paths
- Asking questions answerable by ten minutes of tracing
