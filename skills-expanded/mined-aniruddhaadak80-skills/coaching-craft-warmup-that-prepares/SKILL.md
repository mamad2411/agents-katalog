# Design warm-ups that prepare, not tire

> Progressive raise-activate-mobilize structure specific to the session's demands.

**Track:** 🏆 Sports & Performance · **Domain:** Coaching Craft · **Level:** foundation · **~15 min**

**Who this is for:** Coaches, S&C Specialists, Athletic Trainers, Team Scientists

## When to Use This Skill

Progressive raise-activate-mobilize structure specific to the session's demands.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Raise: 3-5min general pulse elevation appropriate to intensity ahead
2. Activate: target the day's key muscle groups with light loaded work
3. Mobilize: dynamic ranges matching sport positions, not static holding
4. Potentiate: ramp sport-specific intensity ending near working pace
5. Total 10-15 minutes; fatigue is failure, sweat is success
6. Adapt content to session focus — leg day ≠ upper day prep

## Common Pitfalls

- 20 minutes of static stretching before sprint work
- Generic jog-and-stretch ignoring the day's actual demands
