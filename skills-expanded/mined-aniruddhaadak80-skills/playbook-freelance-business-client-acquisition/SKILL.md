# Playbook: Land better clients this quarter

> Niche positioning feeding proposals that close at healthy rates.

**Track:** 🗺️ Freelance & Business · **Domain:** Journey Playbooks · **Level:** journey · **~95 min**

**Who this is for:** Freelancers, Consultants, Agencies, Independent Developers

Niche positioning feeding proposals that close at healthy rates.

## Journey Steps

1. Step 1 — Position into a profitable niche: start with "Fill formula: 'I help [audience] achieve [outcome] through [means]'"
2. Step 2 — Write proposals that close without discounting: start with "Mirror their words for problem statement before any solution talk"
3. Step 3 — Price on value with floor discipline: start with "Compute cost floor: expenses + taxes + non-billable time ÷ billable hours"
4. How it fits together: Positioning precedes pricing. Premium claims need niche proof artifacts.
