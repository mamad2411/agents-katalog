# Underwrite a rental property in one pass

> Income, expense reality, financing, and downside cases producing a defensible go/no-go.

**Track:** 🏘️ Real Estate · **Domain:** Deal Analysis · **Level:** intermediate · **~40 min**

**Who this is for:** Agents, Investors, Property Managers, Analysts

## When to Use This Skill

Income, expense reality, financing, and downside cases producing a defensible go/no-go.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Verify income with leases + market rents, not seller pro-forma
2. Budget expenses honestly: taxes, insurance, capex reserves, vacancy allowance
3. Model financing at TODAY's rates plus 100bps stress
4. Compute cash-flow after ALL costs; ignore appreciation in year-1 math
5. Run downside case: vacancy doubles, major capex hits — survivable?
6. Write investment thesis memo; if you can't defend it, pass

## Common Pitfalls

- Seller pro-formas accepted as underwriting
- Capex 'surprises' that any roof/HVAC inspection predicted
