> Floor math, value anchors, and migration scripts moving existing clients up.

## Journey Steps

1. Step 1 — Price on value with floor discipline: start with "Compute cost floor: expenses + taxes + non-billable time ÷ billable hours"
2. Step 2 — Write proposals that close without discounting: start with "Mirror their words for problem statement before any solution talk"
3. How it fits together: Never discount; rescope. Track effective hourly rate per client quarterly.
