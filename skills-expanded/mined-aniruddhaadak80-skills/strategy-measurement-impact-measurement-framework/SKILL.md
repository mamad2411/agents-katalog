# Measure impact without drowning programs

> Lightweight data collection embedded in delivery producing credible outcome claims.

**Track:** 🌍 Nonprofit & Impact · **Domain:** Strategy & Measurement · **Level:** advanced · **~45 min**

**Who this is for:** Nonprofit Leaders, Program Managers, Fundraisers, Board Members

## When to Use This Skill

Lightweight data collection embedded in delivery producing credible outcome claims.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Pick 5-8 indicators max tied to theory-of-change links
2. Embed collection into existing touchpoints; separate surveys die
3. Baseline before program contact wherever feasible
4. Pair quantitative outcomes with two qualitative depth stories
5. Report negative and null findings honestly — funders trust this
6. Calculate cost-per-outcome once baseline exists; revisit yearly

## Common Pitfalls

- Counting attendance as impact
- Data collected for funders never used by programs
