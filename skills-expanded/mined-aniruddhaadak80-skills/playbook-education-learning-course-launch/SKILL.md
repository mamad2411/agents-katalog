# Playbook: Ship an online course that gets finished

> Objective-aligned modules produced, accountability mechanics live, completion measured.

**Track:** 🗺️ Education & Teaching · **Domain:** Journey Playbooks · **Level:** journey · **~100 min**

**Who this is for:** Teachers, Instructional Designers, Course Creators, Trainers

## When to Use This Skill

Objective-aligned modules produced, accountability mechanics live, completion measured.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Write learning objectives you can actually assess: start with "State who will do what observable action by when"
2. Step 2 — Produce an online course people finish: start with "Promise one transformation in the title; module = milestone toward it"
3. Step 3 — Build rubrics that grade fairly and fast: start with "Derive criteria from objectives, max 5 dimensions"
4. How it fits together: Objectives gate assessments gate modules. Build backwards from the transformation promised.
