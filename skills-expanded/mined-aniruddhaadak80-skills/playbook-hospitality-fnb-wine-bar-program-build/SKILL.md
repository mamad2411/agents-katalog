# Playbook: Build a bar program that survives turnover

> Spec cards, weight-based counts, and responsible service as standard operating system.

**Track:** 🗺️ Beverage & Bar Program · **Domain:** Journey Playbooks · **Level:** journey · **~80 min**

**Who this is for:** Bar Managers, Bartenders, Beverage Directors, Sommeliers

## When to Use This Skill

Spec cards, weight-based counts, and responsible service as standard operating system.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Build cocktail spec cards that survive staff turnover: start with "Spec in ml/oz by weight where possible; batch what you can legally and safely"
2. Step 2 — Control bar inventory against shrinkage honestly: start with "Count by weight (scale) for spirits; eyeball counts hide 20% variance"
3. Step 3 — Run responsible service without killing hospitality: start with "Monitor pace per table/guest as a team responsibility, not one server's burden"
4. How it fits together: Consistency systems protect margin AND licenses simultaneously.
