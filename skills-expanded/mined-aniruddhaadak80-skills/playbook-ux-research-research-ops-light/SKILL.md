# Playbook: Set up lightweight research ops

> Reusable scripts, participant pools, and insight repositories compounding across studies.

**Track:** 🗺️ UX Research & Design · **Domain:** Journey Playbooks · **Level:** journey · **~75 min**

**Who this is for:** UX Researchers, Product Designers, Design Leads, Service Designers

## When to Use This Skill

Reusable scripts, participant pools, and insight repositories compounding across studies.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Run usability tests that reveal truth: start with "Write tasks as goals ('pay this invoice'), never UI instructions ('click Billing')"
2. Step 2 — Synthesize research without bias collapse: start with "Extract observations verbatim onto atomic notes with source refs"
3. How it fits together: Templates + tagged repository = institutional memory most teams never build.
