# Validate computational biology pipelines against wet-lab truth

> Benchmark design, discordance investigation, and acceptance thresholds bridging silico and bench.

**Track:** 🧬 Biotech & Pharma · **Domain:** Computational Validation · **Level:** advanced · **~45 min**

**Who this is for:** Bioinformaticians, Lab Scientists, Regulatory Affairs, Genetic Engineers, Clinical Data Managers

## When to Use This Skill

Benchmark design, discordance investigation, and acceptance thresholds bridging silico and bench.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Define gold-standard comparisons achievable in-house (orthogonal assays)
2. Run pipeline vs assay on shared samples spanning expected difficulty range
3. Investigate every discordance class before adjusting either side
4. Set acceptance thresholds BEFORE seeing comparison results
5. Version reference materials; drift invalidates longitudinal comparisons
6. Publish internal validation reports citable during regulatory interactions

## Common Pitfalls

- Thresholds tuned post-hoc until pipeline looks good
- Single-time-point validations extrapolated to all conditions
