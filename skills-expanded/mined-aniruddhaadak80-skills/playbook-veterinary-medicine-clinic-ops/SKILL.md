# Playbook: Tighten clinic operations and compliance

> Triage flow, consent clarity, controlled-drug rigor, and staff safety as one system.

**Track:** 🗺️ Veterinary Medicine · **Domain:** Journey Playbooks · **Level:** journey · **~75 min**

**Who this is for:** Veterinarians, Vet Techs, Practice Managers, Animal Welfare Teams

## When to Use This Skill

Triage flow, consent clarity, controlled-drug rigor, and staff safety as one system.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Triage patients by urgency, not arrival order: start with "Category 1 immediate: airway/breathing/circulation collapse, toxin ingestion, seizure"
2. Step 2 — Handle cost estimates and consent with clarity: start with "Give ranges with what moves a case between low and high end"
3. Step 3 — Keep controlled drug logs audit-proof: start with "Every in/out entry dual-signed with date, patient, dose, running balance"
4. How it fits together: Compliance systems protect animals, staff, AND license simultaneously.
