# Build records practices for transparency by default

> Classification, retention, and disclosure-ready recordkeeping meeting FOI obligations calmly.

**Track:** 🏛️ Public Sector & GovTech · **Domain:** Digital Services · **Level:** foundation · **~30 min**

**Who this is for:** Civic Technologists, Program Managers, Policy Analysts, Gov IT Teams

## When to Use This Skill

Classification, retention, and disclosure-ready recordkeeping meeting FOI obligations calmly.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Classify records at creation with retention schedules attached
2. Write like you'll be read aloud: no speculation in official channels
3. Keep personal data segregated for redaction-efficient release
4. Log decisions with rationale contemporaneously
5. Practice responding to a records request quarterly end-to-end
6. Proactively publish high-demand record classes where law allows

## Common Pitfalls

- Shadow messaging systems outside records management
- Requests triggering year-long archaeological digs
