# Write learning objectives you can actually assess

> Observable-verb objectives aligned to assessments so teaching, testing, and claims match.

**Track:** 🎓 Education & Teaching · **Domain:** Instructional Design · **Level:** foundation · **~25 min**

**Who this is for:** Teachers, Instructional Designers, Course Creators, Trainers

## When to Use This Skill

Observable-verb objectives aligned to assessments so teaching, testing, and claims match.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. State who will do what observable action by when
2. Use measurable verbs (derive, compare, debug) not fog (understand, appreciate)
3. Set the difficulty level honestly against learner prerequisites
4. Map every objective to at least one assessment item
5. Delete objectives nothing assesses; they waste student attention
6. Sequence objectives so each builds on demonstrated prior mastery

## Common Pitfalls

- 'Students will understand X' — untestable and unteachable
- Assessments measuring reading skill instead of target skill
