# Escalate with judgment, not fear

> Clear severity ladder and warm-handoff standards protecting both customers and engineers.

**Track:** 💬 Customer Support · **Domain:** Support Operations · **Level:** intermediate · **~20 min**

**Who this is for:** Support Engineers, CX Leads, Helpdesk Teams, Technical Account Managers

## When to Use This Skill

Clear severity ladder and warm-handoff standards protecting both customers and engineers.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Severity = customer impact × scope × urgency, written as a matrix
2. Warm handoffs: intro context in channel, stay reachable for 24h
3. Escalate data-loss/security instantly regardless of customer size
4. Set expectations WITH the customer before escalating internally
5. Track escalations back: were they preventable classes?
6. No silent escalations — someone always owns customer comms

## Common Pitfalls

- Escalating everything upward, engineering trust eroding
- Cold ticket tosses losing critical context
