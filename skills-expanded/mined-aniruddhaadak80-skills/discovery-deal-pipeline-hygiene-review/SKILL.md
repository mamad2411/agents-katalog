# Review pipeline with honest hygiene standards

> Stage-exit criteria, next-step currency, and slippage detection keeping forecasts real.

**Track:** 🤝 Sales & Customer Success · **Domain:** Discovery & Deals · **Level:** intermediate · **~25 min**

**Who this is for:** Account Executives, Customer Success Managers, Sales Engineers, Founders Selling

## When to Use This Skill

Stage-exit criteria, next-step currency, and slippage detection keeping forecasts real.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Define exit criteria per stage; deals without them get downgraded automatically
2. Every open deal carries dated next step; no next step = stalled flag
3. Track stage-conversion and cycle-time by segment monthly
4. Flag slipped-close-date deals for win/loss review regardless of outcome
5. Forecast three numbers: commit / best-case / worst-case with rationale
6. Remove wishful deals ruthlessly; clean pipe beats fat pipe

## Common Pitfalls

- Happy-ears stage inflation before quarter end
- Dead deals parked forever muddying conversion metrics
