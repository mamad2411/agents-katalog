# Structure grant proposals reviewers score highly

> Aims aligned to significance, feasibility evidence, and budget logic telling one coherent story.

**Track:** 🔬 Scientific Research · **Domain:** Publication & Grants · **Level:** advanced · **~50 min**

**Who this is for:** Researchers, PhD Students, Postdocs, Research Software Engineers

## When to Use This Skill

Aims aligned to significance, feasibility evidence, and budget logic telling one coherent story.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Frame central question as one sentence a non-specialist grasps
2. 3-4 aims building logically; each independently fundable-worthy
3. Pair every aim with approach + expected outcomes + alternatives
4. Prove feasibility: preliminary data, resources, timeline math
5. Budget narrative mirrors project narrative line by line
6. Circulate to two past reviewers BEFORE the deadline, not after rejection

## Common Pitfalls

- Aims so ambitious reviewers doubt feasibility
- Preliminary data buried instead of leading
