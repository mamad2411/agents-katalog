# Playbook: Mature your escalation practice

> Severity ladder with warm handoffs engineers actually trust.

**Track:** 🗺️ Customer Support · **Domain:** Journey Playbooks · **Level:** journey · **~45 min**

**Who this is for:** Support Engineers, CX Leads, Helpdesk Teams, Technical Account Managers

## When to Use This Skill

Severity ladder with warm handoffs engineers actually trust.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Escalate with judgment, not fear: start with "Severity = customer impact × scope × urgency, written as a matrix"
2. Step 2 — Write support replies that de-escalate: start with "First sentence reflects THEIR stake ('your checkout being down is serious')"
3. How it fits together: Nobody repeats themselves to engineering. Ever.
