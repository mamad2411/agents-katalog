# Triage issues like a sustainable maintainer

> Labels, templates, and response SLAs keeping the queue trustworthy without burnout.

**Track:** 🧭 Engineering Leadership · **Domain:** Open Source Stewardship · **Level:** intermediate · **~30 min**

**Who this is for:** Engineering Managers, Tech Leads, Staff Engineers, CTOs

## When to Use This Skill

Labels, templates, and response SLAs keeping the queue trustworthy without burnout.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Install issue templates forcing repro steps and versions
2. Label within 48h: type, area, priority, good-first-issue
3. Close unreproducible issues politely with a checklist ask
4. Pin a contributing guide with PR conventions and CLA status
5. Batch triage twice weekly; notifications are not a workflow
6. Recruit trusted contributors toward triage permissions

## Common Pitfalls

- Maintainer as single point of failure for every decision
- Issue queue growing unbounded until contributors leave
