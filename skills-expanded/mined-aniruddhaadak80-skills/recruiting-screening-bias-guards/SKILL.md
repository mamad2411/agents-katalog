# Screen resumes with bias guards

> Structured screening rubrics applied blind where feasible, reducing noise-based rejection.

**Track:** 👥 People & HR · **Domain:** Recruiting · **Level:** intermediate · **~25 min**

**Who this is for:** HR Managers, Recruiters, People Ops, Team Leads

## When to Use This Skill

Structured screening rubrics applied blind where feasible, reducing noise-based rejection.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Define rubric criteria tied to job outcomes before viewing resumes
2. Anonymize names/schools/photos during first pass where legal
3. Score independently; discuss only divergent cases
4. Weight demonstrated work over pedigree proxies
5. Log rejection reasons per stage; audit monthly for pattern drift
6. Keep pipeline data for adverse-impact analysis

## Common Pitfalls

- Keyword filters rejecting qualified non-linear careers
- Similarity attraction favoring resume mirrors
