# Price on value with floor discipline

> Rate math from costs + target income, value anchors, and walk-away floors.

**Track:** 💼 Freelance & Business · **Domain:** Client Delivery · **Level:** advanced · **~30 min**

**Who this is for:** Freelancers, Consultants, Agencies, Independent Developers

## When to Use This Skill

Rate math from costs + target income, value anchors, and walk-away floors.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Compute cost floor: expenses + taxes + non-billable time ÷ billable hours
2. Research market band for your niche's outcomes, not hours
3. Anchor to value created: revenue gained or cost removed estimates
4. Raise rates each time pipeline exceeds capacity sustainably
5. Never discount price; reduce scope instead when pressured
6. Track effective hourly rate per project; prune loss leaders

## Common Pitfalls

- Competitor-undercutting spirals to unsustainability
- Senior expertise priced off junior hour tables
