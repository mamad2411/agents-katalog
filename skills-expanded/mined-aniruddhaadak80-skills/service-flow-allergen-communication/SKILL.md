# Handle allergen requests safely end to end

> Server-kitchen-ticket-expo chain of custody making allergy meals trustworthy.

**Track:** 🍽️ Food & Beverage Ops · **Domain:** Service Flow · **Level:** advanced · **~20 min**

**Who this is for:** Chefs, F&B Managers, Restaurant Owners, Catering Leads

## When to Use This Skill

Server-kitchen-ticket-expo chain of custody making allergy meals trustworthy.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Servers capture allergen + severity verbatim, repeat back to guest
2. Verbal handoff PLUS ticket flag to kitchen; expo confirms both
3. Dedicated pans/utensils for severe allergies — cross-contact is the killer
4. Manager spot-verifies allergy plates during service
5. Deliver allergy plates personally with verbal confirmation
6. Log every allergy ticket; near-misses reviewed weekly without blame

## Common Pitfalls

- 'I think it has nuts in it' answers reaching guests
- Same fryer for gluten-free and everything else
