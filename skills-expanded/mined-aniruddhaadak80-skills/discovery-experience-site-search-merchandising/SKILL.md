# Make site search find what merchandisers mean

> Query understanding, synonym control, zero-result recovery, and curated placements.

**Track:** 🛍️ E-commerce & Retail · **Domain:** Discovery Experience · **Level:** intermediate · **~35 min**

**Who this is for:** E-commerce Managers, Merchandisers, Retail Operators, DTC Founders

## When to Use This Skill

Query understanding, synonym control, zero-result recovery, and curated placements.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Analyze top queries with zero results weekly — inventory or synonym gap?
2. Build synonym sets from real customer language including misspellings
3. Curate first-row results for head terms; algorithm alone isn't strategy
4. Show partial matches with honest 'no exact match' messaging
5. Merch seasonal collections into search ahead of campaigns
6. Track search-to-purchase conversion vs browse separately forever

## Common Pitfalls

- Exact-match-only engines losing plural/synonym queries
- Promoted products irrelevant to query training users to ignore results
