# Design controls that actually isolate variables

> Positive/negative controls, randomization, blinding choices matched to bias risks.

**Track:** 🔬 Scientific Research · **Domain:** Study Design · **Level:** intermediate · **~30 min**

**Who this is for:** Researchers, PhD Students, Postdocs, Research Software Engineers

## When to Use This Skill

Positive/negative controls, randomization, blinding choices matched to bias risks.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. List confounders specific to THIS setup, not textbook generics
2. Include negative control answering 'does anything respond?'
3. Include positive control proving assay sensitivity that day
4. Randomize sample placement/handling order where physical effects exist
5. Blind analyzers to condition labels during measurement
6. Pilot blind-unblinding differences once; document what you learned

## Common Pitfalls

- All treated samples run on same day/batch plate
- Analyst guessing conditions from subtle file naming
