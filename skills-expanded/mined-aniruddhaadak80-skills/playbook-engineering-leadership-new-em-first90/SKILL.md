# Playbook: New engineering manager: first 90 days

> Trust built, cadences running, one visible improvement shipped per month.

**Track:** 🗺️ Engineering Leadership · **Domain:** Journey Playbooks · **Level:** journey · **~90 min**

**Who this is for:** Engineering Managers, Tech Leads, Staff Engineers, CTOs

## When to Use This Skill

Trust built, cadences running, one visible improvement shipped per month.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Run one-on-ones that build trust: start with "Their agenda first; status belongs in tools not this meeting"
2. Step 2 — Audit your agile ceremonies ruthlessly: start with "Timebox audit: cost each ceremony × attendees × frequency annually"
3. Step 3 — Manage tech debt as a portfolio: start with "Inventory debts with interest rate: how much slower/costlier per month?"
4. How it fits together: Listen before changing. Ceremony audits in month two land better than in week one.
