# Drive claims from FNOL to fair resolution fast

> Structured intake, coverage verification, documentation, and settlement discipline.

**Track:** ☂️ Insurance Operations · **Domain:** Claims Handling · **Level:** intermediate · **~40 min**

**Who this is for:** Claims Adjusters, Underwriters, Insurance Ops, Brokers

## When to Use This Skill

Structured intake, coverage verification, documentation, and settlement discipline.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Capture FNOL completely: who/what/when/where plus policy number verification
2. Verify coverage BEFORE promising anything; reserve set on facts not optimism
3. Build evidence file: statements, photos, reports, expert inputs as needed
4. Communicate status proactively at defined intervals even when nothing moved
5. Settle on documented valuation; document every deviation from guideline
6. Close-out review: subrogation flags, recovery chances, lesson tags

## Common Pitfalls

- Coverage surprises surfacing after promises made
- Reserves set once and never revisited as facts develop
