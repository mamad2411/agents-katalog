# Keep clinical trial data inspection-ready

> Edit checks, discrepancy management, and lock discipline producing clean analyzable datasets.

**Track:** 🧬 Biotech & Pharma · **Domain:** Regulatory & Clinical Data · **Level:** advanced · **~45 min**

**Who this is for:** Bioinformaticians, Lab Scientists, Regulatory Affairs, Genetic Engineers, Clinical Data Managers

## When to Use This Skill

Edit checks, discrepancy management, and lock discipline producing clean analyzable datasets.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Configure edit checks at study build, not during enrollment
2. Triage discrepancies daily by query aging priority
3. Freeze database sections as they complete; control late changes
4. Document every protocol deviation with impact assessment
5. Run patient-profile reviews before any interim analysis
6. Rehearse the inspection story: request-to-record traceability demo

## Common Pitfalls

- Queries opened months later eroding site trust
- Unblinding incidents through careless report sharing
