# Keep production models honest

> P50/P90 discipline, loss-tree transparency, and as-built model updates protecting projections.

**Track:** 🔋 Energy & Renewables · **Domain:** Project Development · **Level:** advanced · **~35 min**

**Who this is for:** Solar Engineers, Energy Analysts, Project Developers, O&M Teams

## When to Use This Skill

P50/P90 discipline, loss-tree transparency, and as-built model updates protecting projections.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Build loss tree explicitly: soiling, temperature, availability, clipping, line losses
2. Quote P50 for engineering, P90 for financing; never blur them
3. Update models with as-built equipment and measured first-year data
4. Compare predicted vs actual monthly; investigate >5% persistent deviations
5. Document every assumption change between model versions
6. Feed O&M findings back into loss assumptions fleet-wide

## Common Pitfalls

- Cherry-picking sunny months as 'performance proof'
- Models frozen at financial close despite field reality
