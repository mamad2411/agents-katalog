# Write listings buyers actually click

> Lead with lifestyle outcome, structure scannable facts, and never oversell the flaws away.

**Track:** 🏘️ Real Estate · **Domain:** Clients & Listings · **Level:** foundation · **~20 min**

**Who this is for:** Agents, Investors, Property Managers, Analysts

## When to Use This Skill

Lead with lifestyle outcome, structure scannable facts, and never oversell the flaws away.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Headline = strongest verifiable hook (view, lot, layout) not 'stunning'
2. First paragraph paints morning/evening living there specifically
3. Facts block scannable: beds/baths/GLA/year/lot/parking up top
4. Replace adjectives with evidence ('granite' beats 'luxurious')
5. Disclose known issues plainly — trust converts better than surprise
6. Pair every room photo order with matching copy sequence

## Common Pitfalls

- Adjective soup saying nothing checkable
- Hiding flaws that inspections surface anyway, torching deals
