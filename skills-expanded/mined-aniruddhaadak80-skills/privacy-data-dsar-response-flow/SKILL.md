# Answer data subject requests within deadlines

> Intake, verification, retrieval, and response workflow meeting statutory clocks without panic.

**Track:** ⚖️ Legal & Compliance · **Domain:** Privacy & Data Protection · **Level:** intermediate · **~35 min**

**Who this is for:** Legal Ops, Privacy Officers, Compliance Teams, Founders, Engineers

## When to Use This Skill

Intake, verification, retrieval, and response workflow meeting statutory clocks without panic.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Stand up one intake channel logging request date automatically
2. Verify identity proportionate to data sensitivity
3. Search ALL systems from your data map, including backups policies
4. Redact third-party personal data before release
5. Respond within one month (GDPR), documenting extensions if complex
6. Log every request + outcome as audit evidence

## Common Pitfalls

- Email archives forgotten in searches
- Free-form responses creating new compliance issues
