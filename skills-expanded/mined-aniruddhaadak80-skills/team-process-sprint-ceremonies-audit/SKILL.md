# Audit your agile ceremonies ruthlessly

> Keep rituals that produce decisions; delete the rest or shorten them.

**Track:** 🧭 Engineering Leadership · **Domain:** Team Process · **Level:** intermediate · **~30 min**

**Who this is for:** Engineering Managers, Tech Leads, Staff Engineers, CTOs

## When to Use This Skill

Keep rituals that produce decisions; delete the rest or shorten them.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Timebox audit: cost each ceremony × attendees × frequency annually
2. Standups answer three things only: done, next, blocked
3. Planning consumes estimates only where they change decisions
4. Retro produces max two tracked actions with owners
5. Async-first updates replace broadcast meetings
6. Re-audit quarterly; ceremony creep is real

## Common Pitfalls

- Ceremonies performed for process-compliance optics
- Estimation debates longer than implementation
