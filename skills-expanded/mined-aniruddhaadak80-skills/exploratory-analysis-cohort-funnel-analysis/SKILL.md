# Build cohort and funnel analyses that hold up

> Segment users by acquisition period and trace retention/funnels without sampling traps.

**Track:** 📊 Data Science & Analytics · **Domain:** Exploratory Analysis · **Level:** intermediate · **~35 min**

**Who this is for:** Data Scientists, Analysts, Research Scientists, Product Analysts

## When to Use This Skill

Segment users by acquisition period and trace retention/funnels without sampling traps.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Define cohorts by first meaningful action, not signup alone
2. Choose observation windows honestly; censor incomplete periods
3. Normalize funnels per-entry so step conversion is comparable
4. Segment by platform before concluding; mixed traffic misleads
5. Visualize retention curves with cohort overlay to spot shifts
6. Annotate charts with launches/incidents explaining inflections

## Common Pitfalls

- Comparing cohorts with unequal maturity windows
- Counting bots as activated users
