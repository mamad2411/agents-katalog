# Run a solar site feasibility screen

> Resource, interconnection, permitting, and economics screened in order of deal-killer risk.

**Track:** 🔋 Energy & Renewables · **Domain:** Project Development · **Level:** intermediate · **~40 min**

**Who this is for:** Solar Engineers, Energy Analysts, Project Developers, O&M Teams

## When to Use This Skill

Resource, interconnection, permitting, and economics screened in order of deal-killer risk.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Screen interconnection FIRST: queue position, capacity headroom, upgrade cost estimates
2. Assess resource data quality (measured vs modeled) and shading geometry
3. Verify land control options and zoning/permitting pathway realistically
4. Model economics with P50 production, current incentives, and downside tariff cases
5. Rank fatal flaws before nice-to-haves; walk early when screens fail
6. Document assumptions versioned — feasibility memos get re-litigated

## Common Pitfalls

- Falling in love with great sites the grid cannot serve
- Modeled resource accepted without measured validation
