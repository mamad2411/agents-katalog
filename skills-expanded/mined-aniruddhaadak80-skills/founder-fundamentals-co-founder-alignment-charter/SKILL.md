# Align co-founders before conflict finds you

> Written charters covering equity, roles, decisions, exits — awkward conversations as insurance.

**Track:** 🚀 Startup & Founders · **Domain:** Founder Fundamentals · **Level:** foundation · **~40 min**

**Who this is for:** Founders, Indie Hackers, Early Employees, Solopreneurs

## When to Use This Skill

Written charters covering equity, roles, decisions, exits — awkward conversations as insurance.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Document equity split with vesting (4y/1y cliff) via lawyer-drafted agreements
2. Define decision domains: who owns product/fundraising/hiring calls solo
3. Agree deadlock mechanism before deadlock exists
4. Set salary policy explicitly even if 'everyone equal, minimal'
5. Schedule monthly founder retro separate from ops meetings
6. Revisit charter at every major milestone; amend in writing only

## Common Pitfalls

- 50/50 splits with no deadlock breaker freezing companies
- Verbal role assumptions diverging under first real stress
