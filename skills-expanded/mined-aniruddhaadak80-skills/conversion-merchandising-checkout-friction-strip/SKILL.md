# Strip friction from checkout surgically

> Step-by-step abandonment analysis with field-level fixes and measured recovery rates.

**Track:** 🛍️ E-commerce & Retail · **Domain:** Conversion & Merchandising · **Level:** advanced · **~40 min**

**Who this is for:** E-commerce Managers, Merchandisers, Retail Operators, DTC Founders

## When to Use This Skill

Step-by-step abandonment analysis with field-level fixes and measured recovery rates.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Funnel each step; identify the single worst drop-off first
2. Kill every non-essential field; defer account creation to post-purchase
3. Show total cost early; surprise shipping is the #1 killer
4. Express payments (wallet) above manual card entry
5. Error states say exactly what and where, preserving entered data
6. A/B one change at a time with adequate sample before declaring victory

## Common Pitfalls

- Redesigning everything simultaneously, learning nothing
- Guest checkout hidden behind tiny link
