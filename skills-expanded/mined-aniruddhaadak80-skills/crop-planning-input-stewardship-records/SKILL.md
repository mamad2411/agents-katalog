# Steward inputs with application records that protect you

> Label-compliant applications, buffer respect, and complete traceability from purchase to harvest.

**Track:** 🌾 Agriculture & AgTech · **Domain:** Crop Planning · **Level:** foundation · **~25 min**

**Who this is for:** Farm Managers, Agronomists, AgTech Builders, Supply Sustainability Teams

## When to Use This Skill

Label-compliant applications, buffer respect, and complete traceability from purchase to harvest.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Read the label as law: rates, REI/PHI, buffers recorded before purchase fits use
2. Log every application: product, rate, area, conditions, operator, equipment
3. Calibrate sprayers on schedule; keep calibration certificates
4. Respect pre-harvest intervals in scheduling — harvest plan checks PHI automatically
5. Store records ≥ regulatory minimums, backed up offsite
6. Buyer/residue questionnaires answered FROM records, not memory

## Common Pitfalls

- PHI violations discovered by buyers' residue tests
- Records reconstructed 'from memory' before audits
