# Playbook: Run a study from design to archive

> Powered design → controlled execution → reproducible analysis → citable record.

**Track:** 🗺️ Scientific Research · **Domain:** Journey Playbooks · **Level:** journey · **~125 min**

**Who this is for:** Researchers, PhD Students, Postdocs, Research Software Engineers

## When to Use This Skill

Powered design → controlled execution → reproducible analysis → citable record.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Power studies before collecting a single datapoint: start with "Estimate effect size from prior literature or pilot data honestly"
2. Step 2 — Design controls that actually isolate variables: start with "List confounders specific to THIS setup, not textbook generics"
3. Step 3 — Make computational results reproducible: start with "Pin environments: lockfiles plus container image recorded per result"
4. Step 4 — Keep lab notebooks worth citing: start with "Entry per session: goal, exact methods/versions, raw observations"
5. How it fits together: Preregistration and controls cost hours now and save the paper later.
