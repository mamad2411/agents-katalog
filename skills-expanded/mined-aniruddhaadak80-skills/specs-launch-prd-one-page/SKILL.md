# Write a one-page PRD engineers love

> Problem, users, success metrics, scope fences, and open questions on one page.

**Track:** 📋 Product Management · **Domain:** Specs & Launch · **Level:** foundation · **~40 min**

**Who this is for:** Product Managers, Product Owners, Founders, Product Analysts

## When to Use This Skill

Problem, users, success metrics, scope fences, and open questions on one page.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Lead with problem statement and target user's current workaround
2. Define success metrics with baseline numbers and targets
3. List in-scope v1 and explicitly out-of-scope items
4. Specify edge cases and non-functional requirements (perf, a11y, privacy)
5. Keep an open-questions section with owners and due dates
6. Review with engineering before finalizing; incorporate feasibility push-back

## Common Pitfalls

- Solution mockups posing as requirements
- Success metrics undefined until post-launch retro
