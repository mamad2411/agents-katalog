# Recover a slipping construction schedule

> Critical-path truth, look-ahead replanning, and recovery options priced honestly.

**Track:** 🏗️ Construction & Built Environment · **Domain:** Site Execution · **Level:** advanced · **~45 min**

**Who this is for:** Project Engineers, Site Managers, Cost Estimators, Contractors

## When to Use This Skill

Critical-path truth, look-ahead replanning, and recovery options priced honestly.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Rebuild true critical path from field reality, not baseline fiction
2. Quantify delay causes against contract entitlement separately from recovery
3. Look-ahead 3 weeks: every activity has labor, materials, access confirmed
4. Recovery menu: resequence / overtime / additional crew / scope re-phase — each costed
5. Negotiate recovery plan WITH subs who must execute it
6. Weekly variance review with same metrics; kill optimism bias with data

## Common Pitfalls

- Overtime 'solutions' that lower productivity below baseline
- Recovery plans announced to subs instead of built with them
