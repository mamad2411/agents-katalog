# Design AI-use policies students understand

> Assignment-tiered AI permissions, process documentation, and assessment redesign over surveillance.

**Track:** 🎓 Education & Teaching · **Domain:** Modern Classroom · **Level:** intermediate · **~30 min**

**Who this is for:** Teachers, Instructional Designers, Course Creators, Trainers

## When to Use This Skill

Assignment-tiered AI permissions, process documentation, and assessment redesign over surveillance.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Tier every assignment: AI-free / AI-assisted-disclosed / AI-required
2. Teach prompt literacy as course content, not contraband
3. Redesign assessments AI can't shortcut: oral defenses, process portfolios
4. Document disclosure format students use when AI contributed
5. Model good AI use publicly on your own prep materials
6. Revise policy each term as capabilities shift; version it visibly

## Common Pitfalls

- Detection-tool false accusations punishing innocent students
- Bans pushing usage underground where learning never happens
