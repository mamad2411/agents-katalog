# Pull comps that actually justify price

> Comparable selection by similarity and recency, adjusted transparently.

**Track:** 🏘️ Real Estate · **Domain:** Deal Analysis · **Level:** foundation · **~25 min**

**Who this is for:** Agents, Investors, Property Managers, Analysts

## When to Use This Skill

Comparable selection by similarity and recency, adjusted transparently.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Filter to same submarket within 0.5mi and 90 days where inventory allows
2. Match on bed/bath/GLA/lot first; style second
3. Adjust for condition differences with documented per-item estimates
4. Drop outlier sales unexplained by visible factors
5. Weight closest-and-newest heaviest; show the grid
6. State confidence range; thin comp sets widen it honestly

## Common Pitfalls

- Cherry-picked high comps justifying wishful list prices
- Foreclosures mixed silently into arms-length sets
