# Practice GxP-grade documentation habits

> ALCOA+ principles applied daily: attributable, legible, contemporaneous, original, accurate.

**Track:** 🧬 Biotech & Pharma · **Domain:** Regulatory & Clinical Data · **Level:** intermediate · **~30 min**

**Who this is for:** Bioinformaticians, Lab Scientists, Regulatory Affairs, Genetic Engineers, Clinical Data Managers

## When to Use This Skill

ALCOA+ principles applied daily: attributable, legible, contemporaneous, original, accurate.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Record observations contemporaneously; backfilling is a finding
2. Sign/date entries; corrections use single-strike-through with reason
3. Keep raw data untouched; analysis works on labeled copies
4. Timestamps from controlled sources, not local clocks
5. Audit-trail reviews scheduled per system risk tier
6. Train every new team member on ALCOA+ with examples

## Common Pitfalls

- Shared logins destroying attributability
- 'Cleanup' edits deleting raw anomalies
