# Run one-on-ones that build trust

> Weekly direct-report meetings owned by them: growth, blockers, feedback — not status updates.

**Track:** 🧭 Engineering Leadership · **Domain:** People Management · **Level:** foundation · **~25 min**

**Who this is for:** Engineering Managers, Tech Leads, Staff Engineers, CTOs

## When to Use This Skill

Weekly direct-report meetings owned by them: growth, blockers, feedback — not status updates.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Their agenda first; status belongs in tools not this meeting
2. Ask growth questions monthly: what do you want to learn next quarter?
3. Deliver small feedback within 48h of observation, privately
4. Track recurring themes across weeks; patterns need structural fixes
5. Skip-meeting check: if nothing to discuss, cancel honestly
6. Quarterly: review their goals explicitly in the slot

## Common Pitfalls

- 1:1s degraded into sprint demos
- Feedback saved for performance season
