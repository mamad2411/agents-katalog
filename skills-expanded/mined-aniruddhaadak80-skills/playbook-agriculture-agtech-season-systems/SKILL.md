# Playbook: Systemize your season

> Rotation design, compliant input records, and data-driven irrigation in one operating rhythm.

**Track:** 🗺️ Agriculture & AgTech · **Domain:** Journey Playbooks · **Level:** journey · **~90 min**

**Who this is for:** Farm Managers, Agronomists, AgTech Builders, Supply Sustainability Teams

## When to Use This Skill

Rotation design, compliant input records, and data-driven irrigation in one operating rhythm.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Design crop rotations that build, not mine, soil: start with "Map fields with soil test history; group by capability not habit"
2. Step 2 — Steward inputs with application records that protect you: start with "Read the label as law: rates, REI/PHI, buffers recorded before purchase fits use"
3. Step 3 — Schedule irrigation on data instead of habit: start with "Place sensors by zone representativeness and root depth of the crop stage"
4. How it fits together: Records written at application time are worth ten reconstructed after audits.
