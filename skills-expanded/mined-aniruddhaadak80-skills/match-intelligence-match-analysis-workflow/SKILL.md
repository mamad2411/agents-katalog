# Turn match footage into Monday's training

> Question-led coding, opposition tendencies, and session-linked insights coaches actually use.

**Track:** 🏆 Sports & Performance · **Domain:** Match Intelligence · **Level:** intermediate · **~40 min**

**Who this is for:** Coaches, S&C Specialists, Athletic Trainers, Team Scientists

## When to Use This Skill

Question-led coding, opposition tendencies, and session-linked insights coaches actually use.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Define two tactical questions per match BEFORE coding anything
2. Tag events consistently; your codebook outlives any software
3. Clip key moments tagged to the question they answer
4. Present to players with their perspective, not spreadsheets
5. Convert one insight into next week's session design explicitly
6. Archive coded data; patterns emerge across seasons only

## Common Pitfalls

- Highlight reels masquerading as analysis
- Insights presented once then never trained
