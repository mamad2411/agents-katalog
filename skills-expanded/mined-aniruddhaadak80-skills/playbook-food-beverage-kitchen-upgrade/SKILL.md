# Playbook: Upgrade kitchen consistency this quarter

> Weighted specs, safety logs, and menu engineering running as one system.

**Track:** 🗺️ Food & Beverage Ops · **Domain:** Journey Playbooks · **Level:** journey · **~95 min**

**Who this is for:** Chefs, F&B Managers, Restaurant Owners, Catering Leads

## When to Use This Skill

Weighted specs, safety logs, and menu engineering running as one system.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Standardize recipes so dish #1000 equals dish #1: start with "Spec every recipe by WEIGHT, not volume; include yields and waste factors"
2. Step 2 — Run food safety logs inspectors respect: start with "Map critical control points per menu; log temps at defined frequencies"
3. Step 3 — Engineer the menu on data, not vibes: start with "Classify items: stars (high-high), plowhorses (popular-low margin), puzzles, dogs"
4. How it fits together: Specs feed costing feeds the menu matrix. Build in that order.
