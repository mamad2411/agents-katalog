# Write data management plans funders approve

> Collection, storage, sharing, and preservation commitments matching both science and compliance.

**Track:** 🔬 Scientific Research · **Domain:** Data Stewardship · **Level:** intermediate · **~30 min**

**Who this is for:** Researchers, PhD Students, Postdocs, Research Software Engineers

## When to Use This Skill

Collection, storage, sharing, and preservation commitments matching both science and compliance.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Describe data types with realistic volumes and formats at collection stage
2. Specify storage, backup, and security per sensitivity classification
3. Commit to sharing tiers honoring ethics approvals and consent scopes
4. Name repositories with sustainability track records, not personal sites
5. Budget data management costs INTO the grant explicitly
6. Revisit the plan at every milestone; funders increasingly check

## Common Pitfalls

- 'All data will be shared' promises ethics approval forbids
- Plans written post-hoc for grants long spent
