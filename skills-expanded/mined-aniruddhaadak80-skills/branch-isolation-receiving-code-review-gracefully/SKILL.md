# Receive agent code review without ego or obedience

> Verify claims, push back with evidence when wrong, apply instantly when right.

**Track:** 🔄 Agentic Methodology · **Domain:** Branch Isolation · **Level:** foundation · **~20 min**

**Who this is for:** Agent Power Users, AI-Native Engineers, Teams Shipping With Agents, Solo Builders

## When to Use This Skill

Verify claims, push back with evidence when wrong, apply instantly when right.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Reproduce or locate every claim before acting; reviewers are fallible too
2. Push back on incorrect findings with specific evidence, not vibes
3. Apply correct findings immediately even when delivery stings
4. Separate style preferences from correctness issues; route accordingly
5. Thank-and-correct publicly; never argue tone over substance
6. Track which reviewer classes catch what; calibrate future trust

## Common Pitfalls

- Obediently implementing wrong suggestions because review felt authoritative
- Defensive dismissal of valid criticals
