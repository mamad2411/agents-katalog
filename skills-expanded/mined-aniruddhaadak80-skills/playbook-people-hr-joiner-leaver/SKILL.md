# Playbook: Own the full joiner-to-leaver lifecycle

> Day-one productivity and secure, humane exits with zero orphaned access.

**Track:** 🗺️ People & HR · **Domain:** Journey Playbooks · **Level:** journey · **~50 min**

**Who this is for:** HR Managers, Recruiters, People Ops, Team Leads

## When to Use This Skill

Day-one productivity and secure, humane exits with zero orphaned access.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Deliver a first week that converts: start with "Provision accounts/hardware BEFORE day one; verify login day zero"
2. Step 2 — Offboard gracefully and securely: start with "Run exit knowledge-transfer checklist per owned system"
3. How it fits together: Access provisioning and revocation are security events. Treat them with change-management rigor.
