# Playbook: Fill a role with quality and speed

> Inclusive JD → bias-guarded screening → structured loop → great candidate experience.

**Track:** 🗺️ People & HR · **Domain:** Journey Playbooks · **Level:** journey · **~85 min**

**Who this is for:** HR Managers, Recruiters, People Ops, Team Leads

## When to Use This Skill

Inclusive JD → bias-guarded screening → structured loop → great candidate experience.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Write job descriptions candidates actually read: start with "Lead with impact: what will this person own and change in year one?"
2. Step 2 — Screen resumes with bias guards: start with "Define rubric criteria tied to job outcomes before viewing resumes"
3. Step 3 — Deliver a first week that converts: start with "Provision accounts/hardware BEFORE day one; verify login day zero"
4. How it fits together: The pipeline leaks at unstructured stages. Scorecards and rubrics plug them.
