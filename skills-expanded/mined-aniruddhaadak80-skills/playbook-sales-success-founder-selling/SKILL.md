# Playbook: Founder-led selling playbook

> Discovery discipline and honest pipeline from first customer conversations.

**Track:** 🗺️ Sales & Customer Success · **Domain:** Journey Playbooks · **Level:** journey · **~75 min**

**Who this is for:** Account Executives, Customer Success Managers, Sales Engineers, Founders Selling

## When to Use This Skill

Discovery discipline and honest pipeline from first customer conversations.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Run discovery that surfaces real buying motives: start with "Open with agenda contract: their goals, your questions, next-step decision at end"
2. Step 2 — Review pipeline with honest hygiene standards: start with "Define exit criteria per stage; deals without them get downgraded automatically"
3. Step 3 — Handle objections without groveling or dodging: start with "Acknowledge genuinely; defensiveness kills trust instantly"
4. How it fits together: Founders over-demo. Discovery ratios and exit criteria keep deals real.
