# Edit with ruthless pacing discipline

> Structure-first assembly, kill-your-darlings trims, and audio polish before visual candy.

**Track:** 🎬 Media & Video Production · **Domain:** Post & Publishing · **Level:** intermediate · **~40 min**

**Who this is for:** Video Creators, Podcasters, Documentary Makers, Content Studios

## When to Use This Skill

Structure-first assembly, kill-your-darlings trims, and audio polish before visual candy.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Assemble radio-cut (audio only) first; if story works deaf, visuals elevate
2. Trim each clip to its strongest start and end — then trim again
3. Vary rhythm deliberately: pattern breaks hold attention
4. Fix audio quality before color; bad audio reads as amateur instantly
5. Watch full cut on phone speaker AND headphones before sharing
6. Cut your favorite shot if it doesn't serve the story — really

## Common Pitfalls

- Effects compensating for structure problems
- Ten-second intros before value appears
