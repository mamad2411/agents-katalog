# Set up interviews that produce usable answers

> Question design, comfort engineering, and listening technique yielding complete soundbites.

**Track:** 🎬 Media & Video Production · **Domain:** Pre-Production · **Level:** intermediate · **~35 min**

**Who this is for:** Video Creators, Podcasters, Documentary Makers, Content Studios

## When to Use This Skill

Question design, comfort engineering, and listening technique yielding complete soundbites.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Research enough to ask unexpected second questions
2. Open with throwaway comfort questions while checking levels
3. Ask one idea per question ending with open phrasing
4. Embrace silence after answers; the second take is usually gold
5. Request the story, not the opinion ('walk me through that day')
6. Re-ask key answers cleanly once rapport peaks for edit-friendly takes

## Common Pitfalls

- Yes/no questions producing unusable fragments
- Interrupting the pause where real answers live
