# Write papers in the order that works

> Figures first, methods while fresh, results mechanically, intro last — reducing revision churn.

**Track:** 🔬 Scientific Research · **Domain:** Publication & Grants · **Level:** intermediate · **~40 min**

**Who this is for:** Researchers, PhD Students, Postdocs, Research Software Engineers

## When to Use This Skill

Figures first, methods while fresh, results mechanically, intro last — reducing revision churn.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Finalize figure set first; they ARE the story spine
2. Draft methods immediately while details are fresh
3. Write results referencing figures mechanically; interpretation comes later
4. Discussion maps each finding to literature honestly including conflicts
5. Introduction LAST: funnel from broad need to your gap
6. Abstract last-of-all: one sentence per section plus why-it-matters

## Common Pitfalls

- Intro-first writing that changes after results solidify
- Figure legends drafted separately from figures
