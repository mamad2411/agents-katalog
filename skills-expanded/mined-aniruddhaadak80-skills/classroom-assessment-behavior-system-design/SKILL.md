# Design a classroom behavior system that prevents

> Clear expectations, positive ratios, and least-invasive corrections keeping instruction flowing.

**Track:** 🎓 Education & Teaching · **Domain:** Classroom & Assessment · **Level:** intermediate · **~25 min**

**Who this is for:** Teachers, Instructional Designers, Course Creators, Trainers

## When to Use This Skill

Clear expectations, positive ratios, and least-invasive corrections keeping instruction flowing.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Co-create 3-5 positively-phrased expectations with examples of looks-like
2. Narrate desired behavior specifically ('tables quieted in 20 seconds')
3. Aim 4:1 positive-to-corrective interactions minimum, tracked honestly
4. Least-invasive correction ladder: proximity → private → public consequence
5. Never debate mid-class; defer conversations to structured 1:1 time
6. Restart routines after every break like it's week one

## Common Pitfalls

- Public power struggles rewarding the disruption with audience
- Rules existing only as poster decoration
