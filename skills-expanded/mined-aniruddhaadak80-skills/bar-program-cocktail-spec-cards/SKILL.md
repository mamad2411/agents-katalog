# Build cocktail spec cards that survive staff turnover

> Weighted builds, glassware, garnish, and timing specs keeping drinks identical across bartenders.

**Track:** 🍸 Beverage & Bar Program · **Domain:** Bar Program · **Level:** foundation · **~25 min**

**Who this is for:** Bar Managers, Bartenders, Beverage Directors, Sommeliers

## When to Use This Skill

Weighted builds, glassware, garnish, and timing specs keeping drinks identical across bartenders.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Spec in ml/oz by weight where possible; batch what you can legally and safely
2. One card per drink: build order, technique, glass, garnish, target pour time
3. Photo reference of finished drink at service lighting
4. Cost per pour including waste factor; price to target margin band
5. Blind taste across bartenders monthly; recalibrate palates
6. Seasonal menu rotates; core classics stay frozen

## Common Pitfalls

- "A splash" builds drifting per bartender
- Free-pouring without periodic jigger audits
