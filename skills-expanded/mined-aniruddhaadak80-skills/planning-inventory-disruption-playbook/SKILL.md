# Write a disruption playbook before you need it

> Pre-ranked responses to supplier/port/demand shocks with decision authority mapped.

**Track:** 🚚 Supply Chain & Logistics · **Domain:** Planning & Inventory · **Level:** advanced · **~40 min**

**Who this is for:** Supply Planners, Logistics Managers, Procurement, Operations Analysts

## When to Use This Skill

Pre-ranked responses to supplier/port/demand shocks with decision authority mapped.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Map single-source dependencies and their revenue exposure honestly
2. Pre-qualify alternates for critical single-sourced inputs NOW
3. Define trigger thresholds per scenario with named decision owners
4. Rank responses: buffer draw-down → alternate source → allocation → price action
5. Rehearse one scenario annually as tabletop with data available
6. Post-event review updates thresholds and contacts list

## Common Pitfalls

- Contact lists outdated when the port actually closes
- Playbooks written post-crisis and never tested
