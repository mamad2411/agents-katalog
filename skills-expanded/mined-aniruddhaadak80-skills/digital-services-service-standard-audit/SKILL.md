# Audit a government service against digital standards

> User-journey completeness, accessibility, plain language, and assisted-digital pathways.

**Track:** 🏛️ Public Sector & GovTech · **Domain:** Digital Services · **Level:** intermediate · **~40 min**

**Who this is for:** Civic Technologists, Program Managers, Policy Analysts, Gov IT Teams

## When to Use This Skill

User-journey completeness, accessibility, plain language, and assisted-digital pathways.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Walk the FULL journey including offline steps users still face
2. Test with assistive tech; WCAG is the floor, not the target
3. Rewrite key screens at plain-language grade; measure readability
4. Verify assisted-digital route exists and staff can actually help
5. Map every data field collected to a statutory need — delete the rest
6. Publish performance data openly per service standard norms

## Common Pitfalls

- Online forms that print PDFs requiring mail-in anyway
- 'Digital-first' excluding residents without devices or IDs
