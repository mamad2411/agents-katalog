# Sort docs into types readers recognize

> Tutorials vs how-tos vs reference vs explanation — separating modes ends most doc confusion.

**Track:** ✍️ Technical Writing · **Domain:** Documentation Systems · **Level:** foundation · **~30 min**

**Who this is for:** Technical Writers, Developer Advocates, Engineers Who Document, Content Leads

## When to Use This Skill

Tutorials vs how-tos vs reference vs explanation — separating modes ends most doc confusion.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Label every existing page: learning-journey, task-recipe, information-lookup, or theory
2. Flag pages mixing modes; split at natural seams
3. Write one flagship tutorial covering the happy path end-to-end
4. Move edge-case handling into linked how-to recipes
5. Generate reference mechanically from source where possible
6. Add 'which page do I need?' router for newcomers

## Common Pitfalls

- Tutorials stuffed with tangents breaking flow
- Reference prose explaining philosophy nobody asked
