# Playbook: Build an evidence-driven design culture

> Critique rituals and journey maps grounding decisions in user reality.

**Track:** 🗺️ UX Research & Design · **Domain:** Journey Playbooks · **Level:** journey · **~65 min**

**Who this is for:** UX Researchers, Product Designers, Design Leads, Service Designers

## When to Use This Skill

Critique rituals and journey maps grounding decisions in user reality.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Run design reviews that improve work: start with "Designer opens with context, constraint, and specific feedback asks"
2. Step 2 — Map journeys across service touchpoints: start with "Pick ONE persona + scenario with real data behind it"
3. How it fits together: Reviews cite evidence; maps get revisited. Rituals beat posters.
