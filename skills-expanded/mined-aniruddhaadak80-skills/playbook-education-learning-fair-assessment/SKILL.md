# Playbook: Grade fairly at scale

> Rubrics calibrated, blind scoring practiced, distributions analyzed each cycle.

**Track:** 🗺️ Education & Teaching · **Domain:** Journey Playbooks · **Level:** journey · **~55 min**

**Who this is for:** Teachers, Instructional Designers, Course Creators, Trainers

## When to Use This Skill

Rubrics calibrated, blind scoring practiced, distributions analyzed each cycle.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Build rubrics that grade fairly and fast: start with "Derive criteria from objectives, max 5 dimensions"
2. Step 2 — Write learning objectives you can actually assess: start with "State who will do what observable action by when"
3. How it fits together: If a criterion never differentiates, delete it — rubrics are measurement instruments.
