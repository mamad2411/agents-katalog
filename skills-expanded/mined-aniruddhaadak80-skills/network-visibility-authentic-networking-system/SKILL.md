# Network authentically as an introvert-friendly system

> Give-first outreach cadences, public artifact sharing, and relationship CRM habits that compound.

**Track:** 🎯 Career & Job Search · **Domain:** Network & Visibility · **Level:** foundation · **~30 min**

**Who this is for:** Job Seekers, Career Changers, New Grads, Anyone Levelling Up

## When to Use This Skill

Give-first outreach cadences, public artifact sharing, and relationship CRM habits that compound.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Reach out with specific genuine value or question — never naked asks
2. Maintain lightweight CRM: who, context, last touch, next natural reason
3. Reconnect cadence quarterly for warm ties; personalization beats automation
4. Share work-in-public artifacts regularly so opportunities find YOU
5. Attend fewer events but follow up within 48h every time
6. Measure conversations started, not business cards collected

## Common Pitfalls

- Transactional outreach visible from the subject line
- Networking only when desperately job-hunting
