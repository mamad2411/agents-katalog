# Run structured interviews with scorecards

> Same questions, rubric scoring, independent write-ups before debrief — predictive and fair.

**Track:** 🧭 Engineering Leadership · **Domain:** Hiring · **Level:** intermediate · **~40 min**

**Who this is for:** Engineering Managers, Tech Leads, Staff Engineers, CTOs

## When to Use This Skill

Same questions, rubric scoring, independent write-ups before debrief — predictive and fair.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Derive 4-5 competencies from actual job outcomes
2. Write question sets per competency with follow-up probes
3. Score on behavioral anchors (1-5 descriptions) immediately after
4. Interviewers submit written scores before any group discussion
5. Debrief discusses evidence against competencies only
6. Audit funnel quarterly for stage-level drop-off biases

## Common Pitfalls

- Brainteasers measuring trivia tolerance
- Group-think debriefs anchored by loudest voice
