# Run toolbox talks that change behavior

> Five-minute task-specific safety briefings with worker voice and documented attendance.

**Track:** 🏗️ Construction & Built Environment · **Domain:** Site Execution · **Level:** foundation · **~15 min**

**Who this is for:** Project Engineers, Site Managers, Cost Estimators, Contractors

## When to Use This Skill

Five-minute task-specific safety briefings with worker voice and documented attendance.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Topic matches TODAY's actual tasks, not generic monthly themes
2. Two minutes max presentation, three minutes worker input on hazards
3. Name specific controls for the day's top two risks
4. Capture signatures; follow up yesterday's near-miss if any
5. Rotate who leads — supervisors AND trades
6. Track themes quarterly; repeated topics mean systemic fixes needed

## Common Pitfalls

- Read-aloud regulatory scripts with zero engagement
- Attendance sheets as the only deliverable
