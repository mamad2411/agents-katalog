# Control bar inventory against shrinkage honestly

> Counting rhythm, variance thresholds, and systems distinguishing theft from waste from error.

**Track:** 🍸 Beverage & Bar Program · **Domain:** Bar Program · **Level:** intermediate · **~35 min**

**Who this is for:** Bar Managers, Bartenders, Beverage Directors, Sommeliers

## When to Use This Skill

Counting rhythm, variance thresholds, and systems distinguishing theft from waste from error.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Count by weight (scale) for spirits; eyeball counts hide 20% variance
2. Set variance tolerance per category; investigate beyond threshold, not below
3. Track comps/spills/waste separately with signatures — they're not mysteries
4. Reconcile POS pours vs depletion weekly; patterns reveal causes
5. Lock high-value bottles with par-level accountability per shift
6. Never accuse on one cycle; trends plus evidence or nothing

## Common Pitfalls

- Full-inventory counts only quarterly, variance forever mysterious
- Waste logging so punishing it goes underground
