> Just-culture reporting, checklist discipline, and error defenses ported to any high-stakes team.

**Track:** 🗺️ Aviation & Aerospace Ops · **Domain:** Journey Playbooks · **Level:** journey · **~90 min**

**Who this is for:** Pilots, Flight Ops, Safety Managers, Maintenance Engineers, Aviation PMs

## When to Use This Skill

Just-culture reporting, checklist discipline, and error defenses ported to any high-stakes team.

## Journey Steps

1. Step 1 — Operate a just-culture safety reporting flow: start with "Multiple reporting channels including truly anonymous option"
2. Step 2 — Use checklists as culture, not compliance: start with "Execute challenge-response verbally: both pilots verify each item"
3. Step 3 — Defend against maintenance error systematically: start with "Interruption protocol: mark the task, never resume from memory (dirty-finger rule)"
4. How it fits together: Aviation's lesson generalizes: punish recklessness, coach error, and make reporting visible.
