# Turn returns from cost center into signal

> Reason-coded return analysis feeding product fixes, PDP content, and policy tuning.

**Track:** 🛍️ E-commerce & Retail · **Domain:** Inventory & Returns · **Level:** advanced · **~35 min**

**Who this is for:** E-commerce Managers, Merchandisers, Retail Operators, DTC Founders

## When to Use This Skill

Reason-coded return analysis feeding product fixes, PDP content, and policy tuning.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Code every return reason at source; 'changed mind' hides fixable classes
2. Correlate reasons with SKUs: sizing issues mean PDP/chart problem
3. Publish honest sizing guidance from YOUR return data, not vendor charts
4. Test keep-it refunds for low-value items vs reverse logistics cost
5. Watch serial-returner patterns; act fairly but firmly
6. Report prevented-returns value alongside refund costs monthly

## Common Pitfalls

- Returns processed fast but never analyzed
- Free returns marketed without margin math done
