# Playbook: Run a two-week discovery sprint

> Usability findings plus survey baseline synthesized into ranked recommendations.

**Track:** 🗺️ UX Research & Design · **Domain:** Journey Playbooks · **Level:** journey · **~105 min**

**Who this is for:** UX Researchers, Product Designers, Design Leads, Service Designers

## When to Use This Skill

Usability findings plus survey baseline synthesized into ranked recommendations.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Journey Steps

1. Step 1 — Run usability tests that reveal truth: start with "Write tasks as goals ('pay this invoice'), never UI instructions ('click Billing')"
2. Step 2 — Write surveys without garbage-in: start with "Draft research questions first; every item maps to one"
3. Step 3 — Synthesize research without bias collapse: start with "Extract observations verbatim onto atomic notes with source refs"
4. How it fits together: Sequence matters: tests reveal behavior, surveys quantify prevalence, synthesis ties them.
