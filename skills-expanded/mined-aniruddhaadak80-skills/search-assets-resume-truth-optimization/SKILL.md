# Build a resume that is true AND effective

> Achievement-format bullets with honest metrics, ATS-safe structure, and per-role tailoring.

**Track:** 🎯 Career & Job Search · **Domain:** Search Assets · **Level:** foundation · **~40 min**

**Who this is for:** Job Seekers, Career Changers, New Grads, Anyone Levelling Up

## When to Use This Skill

Achievement-format bullets with honest metrics, ATS-safe structure, and per-role tailoring.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Convert duties to outcomes: action verb + what changed + metric where real
2. One page per decade of experience; reverse chronological, standard headers
3. Mirror role-posting language you can honestly claim — never fabricate
4. Quantify selectively; invented precision reads as fake to experts
5. Tailor the top third (summary + first bullets) per application in minutes
6. Test: does every bullet survive a curious interviewer's 'tell me more'?

## Common Pitfalls

- Keyword-stuffed invisible text tricks flagged by modern parsers
- Team achievements claimed as solo work collapsing in interviews
