# Read your cap table like an investor does

> Ownership math through rounds: dilution, option pools, liquidation preferences in plain terms.

**Track:** 🚀 Startup & Founders · **Domain:** Founder Fundamentals · **Level:** intermediate · **~30 min**

**Who this is for:** Founders, Indie Hackers, Early Employees, Solopreneurs

## When to Use This Skill

Ownership math through rounds: dilution, option pools, liquidation preferences in plain terms.
Use it whenever a matching task appears in conversation — the agent loads these instructions on demand.

## Steps

1. Model each round's dilution BEFORE term sheets arrive
2. Understand liquidation preference multiples and participation rights fully
3. Maintain realistic option-pool top-ups inside pre-money negotiation
4. Track 4-year vesting for all founder shares from day one
5. Simulate exit scenarios at various prices; see who actually gets paid
6. Use cap-table software from first SAFE — spreadsheets rot dangerously

## Common Pitfalls

- Participating-preferred surprises consuming common at modest exits
- Option pool expansion discovered post-signing
