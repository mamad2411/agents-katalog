# Codex for Open Source: AI-Vendor Maintainer Support

## Overview
OpenAI's **Codex for Open Source** program (September 2026) supports open-source maintainers with **API credits, six months of ChatGPT Pro with Codex, and conditional access to Codex Security** for core maintainers with write access. Built on the **Codex Open Source Fund ($1 million)** which has supported projects needing API credits — including teams using Codex to power GitHub pull-request workflows. Explicitly tool-agnostic in posture: "Developers should code in the tools they prefer, whether that's Codex, OpenCode, Cline, pi, OpenClaw, or something else."

## When to Use
- Designing or evaluating AI-vendor OSS maintainer support programs
- Applying as a maintainer of a widely used public project
- Benchmarking the AI-era OSS giveback landscape against prior models (endowment, co-op, employment, patron)
- Structuring "AI for the commons" programs at any vendor
- NOT as evidence that vendor credits solve the maintainer-economics problem (this is a product-level subsidy, not structural funding)
- NOT for projects with no AI-assisted workflow need

## Core Process / Workflow
1. **Apply** at developers.openai.com/community/codex-for-oss if you are a core maintainer or run a widely used public project; projects that don't fit stated criteria but play an important ecosystem role can still apply with an explanation.
2. **Receive** (on acceptance):
   - **Six months of ChatGPT Pro with Codex** for day-to-day coding, triage, review, and maintainer workflows
   - **Conditional Codex Security access** for repositories needing deeper security coverage — reviewed case-by-case given GPT-5.4's capabilities
   - **API credits** through the Codex Open Source Fund for PR review, maintainer automation, release workflows, or other core OSS work
3. **Pair with the funding context**: the $1M fund preceded this — it supported API-credit-requiring projects including Codex-powered GitHub PR workflows.
4. **Position the posture**: the program's tool-agnostic framing (supporting Codex, OpenCode, Cline, pi, OpenClaw) is the key differentiator from pure-funnel vendor programs.

## The Broader 2026 OSS-Giveback Wave (context)
This skill sits inside the September 2026 wave of AI-era maintainer support:
- **GitHub**: joined Anthropic, AWS, Google and OpenAI with a combined **$12.5M commitment to the Linux Foundation's Alpha-Omega** initiative; 280,000+ maintainers eligible for free Copilot Pro, Actions, and security capabilities; Secure Open Source Fund added $5.5M in Azure credits and training, plus new partners (Datadog, Open WebUI, Atlantic Council, OWASP).
- **CodeRabbit**: committed **>$10M of actual direct cost** to open source over 12 months (cash sponsorships + free agentic Review/Triage/Change Stack/Security for public repos, counted at cost not list-price) — the direct answer to the agentic-PR-flood thesis.
- **HeroDevs**: a **$20M Open Source Sustainability Fund** for maintainers meeting ecosystem-hygiene criteria (releases/versioning, EOL communication, documentation, deprecation handling, support tiers).
- **Rust MiR / RFMF**: the $350K employment-leg precedent (held by `rust-maintainers-in-residence-2026`).

## A-Tech Alignment
- **Open source**: directly defends the commons; the tool-agnostic posture (supporting OpenCode/Cline/OpenClaw alongside Codex) is the model for any vendor program.
- **Data privacy**: maintainer workflows with AI tooling raise supply-chain questions (what code enters the model context); the program's conditional Security access acknowledges the risk.
- **Financial freedom**: six months of ChatGPT Pro + API credits + Security access is a recurring-income-adjacent support layer for maintainers whose maintenance work earns $0.
- **Practical**: application checklist (core maintainer with write access; explain ecosystem role if criteria unmet) is directly actionable.
