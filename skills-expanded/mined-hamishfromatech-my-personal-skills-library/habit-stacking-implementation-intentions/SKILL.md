# Skill: Habit Stacking & Implementation Intentions

## Summary
Habit stacking (anchoring new behaviors to existing routines) and implementation intentions ("When X happens, I will do Y") are evidence-based behavioral psychology techniques for driving consistent action. They pass behavioral control to environmental cues rather than willpower.

## Core Concepts

### Habit Stacking
Formula: **After [CURRENT HABIT], I will [NEW HABIT]**
- Anchor new behavior to an existing, well-established routine
- Leverages automaticity — the ability to perform behaviors with little conscious thought
- Reduces cognitive load; no decision-making required

### Implementation Intentions
Formula: **When [situation], I will [behavior]**
- Pre-decide action in specific context
- Transfers control from motivation to environment
- Eliminates "I should do that sometime" procrastination

### Combined Formula
**When [situation/trigger], after [current habit], I will [new behavior] in [location]**

## Why It Works
- Humans are "cognitive misers" — we prefer easy, automatic choices
- Willpower is finite; environment design is reliable
- Repetition + context = automaticity
- Implementation intentions increase follow-through by 2-3x vs. goals alone

## A-Tech Alignment
- **Practical implementation**: Directly applicable to product design, onboarding, and user engagement
- **Financial freedom**: Helps users build consistent revenue-generating habits
- **Open-source AI**: Community accountability and shared habit tracking

## Applications
- **A-Coder (IDE)**:
  - Onboarding: "When you open your project each morning, A-Coder will suggest your most important task"
  - Feature: "After every git commit, review AI-suggested improvements" (habit stack)
  - Daily standup integration: auto-generate "what I shipped yesterday" from commit history
  - Streak tracking: "You've shipped code for 12 days straight"
- **Be Practical (Book/Playbooks)**:
  - Each playbook chapter includes "When-Then" implementation intention templates
  - Habit stack recipes for builders: "When I finish breakfast, I review yesterday's metrics"
  - Commitment device worksheets: public declarations with accountability partners
  - Progress tracking designed around streaks and small wins, not just outcomes
- **Open Source AI Builder's Club**:
  - Weekly habit stack challenges: "Ship one AI tool this week" anchored to existing routines
  - Pair accountability: members declare implementation intentions to each other
  - Community dashboard showing collective shipping streaks
  - "When it's Tuesday, I ship my weekly build update" — structured rhythm

## Implementation Steps for Products
1. Identify the user's existing daily/weekly routines
2. Map the desired product engagement behavior
3. Design the anchor: what existing habit can trigger the new one?
4. Reduce friction: make the new behavior as easy as possible
5. Add reinforcement: immediate feedback, progress visualization, social proof
6. Measure automaticity: track consistency over time, not just volume

## Implementation Steps for Individuals
1. Write down one current habit you do daily without fail
2. Choose a small new habit to add (2 minutes or less)
3. Fill in: "After I [current habit], I will [new habit]"
4. Set a specific time and place
5. Track for 66 days (average habit formation time)
6. Stack additional habits once first is automatic

## Key Metrics
- Behavior consistency rate (days in a row / total days)
- Time to automaticity (how many repetitions until behavior feels effortless)
- Friction score (number of steps/clicks to complete desired action)
- Onboarding completion rate
- Feature adoption velocity
- "Streak" participation and retention correlation
