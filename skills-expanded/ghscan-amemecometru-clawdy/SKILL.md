# Brand Book Generator

## Description

Generate a complete brand book from a company name and industry. Produces color palette, typography, logo guidelines, and usage rules compiled into a structured brand document.

## When to activate

Activate this skill when the user asks to create a brand book, brand guidelines, brand identity document, or visual identity system for a company or project.

## Instructions

1. Ask for (or research) the company name, industry, and any existing brand assets.
2. Research the company's industry, competitors, and visual conventions using the browser tool.
3. Generate a color palette with primary, secondary, and accent colors. Include hex codes and usage guidance.
4. Define typography — heading font, body font, and fallbacks. Include sizing scale.
5. Create logo usage guidelines — clear space, minimum sizes, incorrect usage examples.
6. Compile everything into a structured markdown document.

## Output format

Return a markdown document with the following sections:

```
# {Company Name} Brand Book

## 1. Brand Overview
## 2. Color Palette
## 3. Typography
## 4. Logo Usage
## 5. Imagery & Photography
## 6. Voice & Tone
```
