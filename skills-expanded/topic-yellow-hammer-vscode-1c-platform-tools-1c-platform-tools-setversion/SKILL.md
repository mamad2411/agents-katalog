# Установить версию: команды и MCP

Устанавливай версию конфигурации через команду расширения или MCP. **Выполняй команду сам** (Execute Command или MCP), не проси пользователя нажимать палитру.

## Команды расширения

| Задача                         | Command ID                                   |
|--------------------------------|----------------------------------------------|
| Установить версию конфигурации | `1c-platform-tools.cf.setVersion` |

## MCP (mcp-1c-platform-tools)

Если доступны инструменты MCP, используй инструмент для setVersion (имя формируется из command ID).

### Параметр projectPath

Корень проекта 1С (каталог с `packagedef`). Передавай, только если пользователь назвал проект: без параметра команда выполняется в текущем проекте.

## Примеры

- Вызови MCP-инструмент setVersion.
- Выполни команду `1c-platform-tools.cf.setVersion` — откроется выбор версии для текущего проекта.
