# 水墨扁平重构海报（Ink-Wash Flat Poster）

把一张参考图（或一个抽象主题）重构成一幅「米白哑光特种纸质感的水墨扁平插画海报」。

## 何时使用

- 用户给出照片/图片，要求做「水墨」「扁平」「留白」「学术质感」的风格重构
- 用户要从零生成一张带英文标题排版的水墨风海报
- 触发关键词：水墨扁平、块面造型、淡墨晕染、留白构图、特种纸质感、ink wash、flat illustration、negative space

## 工作流

1. **定画幅**：有参考图 → 读原图宽高比并严格保持；无图 → 默认 3:4 竖版（横幅场景可改 16:9）。
2. **定文字**：
   - **英文标题**（首行，优雅衬线手写体）：用户给定则直用；否则从主题提炼 2–4 个词；
   - **英文短句**（第二行，小号无衬线）：用户给定则直用；否则写一句 ≤10 词的意境短句。
3. **组装提示词**：以 [references/prompt-template.md](references/prompt-template.md) 的模板为基底，替换 `{画幅比例}` `{标题}` `{短句}` 三个占位符。图像模型对英文响应更稳时优先用英文版；中文模型用中文版。
4. **生成后自检**（任一不达标即重生成）：
   - [ ] 底色为统一米白哑光纸质，无渐变背景、无边框、无 mockup 投影
   - [ ] 大面积留白（≥40% 画面），主体位于中轴偏上
   - [ ] 块面松弛柔和、轮廓若断若续，无生硬勾线、无细碎纹理与杂物
   - [ ] 光影厚重而整体，明暗归纳为大块面对比，无细碎投影
   - [ ] **边缘渐隐自然**：画面底部及四周的景物必须通过极淡、极宽的透明水墨晕染逐渐溶入纸色，过渡区域要大、几乎不可察觉；严禁出现可见的水平/垂直分界线、矩形色块边缘、硬切边、深色带状底边。天空水彩块不得有矩形边框感，须向边缘变淡消散；底部地景/剪影/植物须稀疏化渐隐，不能齐刷刷截断
   - [ ] 文字恰好两行、底部居中；除文字外无任何装饰元素（印章/水印/边框/角标等）

## 参数

| 占位符 | 说明 | 缺省 |
|---|---|---|
| `{画幅比例}` | 与原图一致 | 3:4 竖版 |
| `{标题}` | 衬线手写体英文主标题 | 从主题提炼 2–4 词 |
| `{短句}` | 无衬线小号英文副句 | ≤10 词意境短句 |

## 快速用法（中文整段版）

> 保持{画幅比例}画幅，将原图重构为一幅米白哑光特种纸质感的水墨扁平插画：保留原图整体色彩调性并柔化过渡；景物简化为松弛柔和的块面造型，只留存原生结构神韵，剔除细碎纹理与杂物；分层平涂为主，间以随性淡墨晕染，轮廓松散自然、若断若续，摒弃生硬勾线；光影厚重而整体，明暗归纳为大块面对比；画面大面积留白，主体置于中轴偏上；**画面底部及四周的景物须以极淡、极宽的透明水墨渐隐溶入纸色，过渡柔和不可察觉，严禁任何可见分界线、矩形色块边缘或硬切底边**；底部居中两行文字——首行「{标题}」优雅衬线手写体，第二行「{短句}」小号无衬线；随性水墨气韵兼具干净克制的学术质感，除文字外不添加任何装饰元素。
