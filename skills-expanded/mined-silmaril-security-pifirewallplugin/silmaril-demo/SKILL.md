# Silmaril Demo

Run `node scripts/open-playground.mjs` from the package root to print the public setup URL. Add `--open` to open it or `--playground` to go directly to the playground. `SILMARIL_DEMO_BASE_URL` may point to a preview build.

Never put the Silmaril API key in a URL, command output, chat, or navigation. This package does not start a proxy, local service, or credential relay.
