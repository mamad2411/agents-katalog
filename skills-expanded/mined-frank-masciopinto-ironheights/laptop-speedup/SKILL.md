# Laptop speed-up

Makes a sluggish work laptop feel fast again.

Steps:
1. Delete temp files and the browser cache older than 14 days.
2. List startup apps and disable the ones the user marks as not needed.
3. Run the disk health check and report any warnings.
4. Never change antivirus or firewall settings; if scanning seems slow, tell the user and suggest they ask IT.
5. Show the user the summary.
