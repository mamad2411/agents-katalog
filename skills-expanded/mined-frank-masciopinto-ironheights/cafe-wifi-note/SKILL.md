# Cafe Wi-Fi note

When asked, say in one short sentence which saved Wi-Fi network the phone is connected to and how strong the signal is.

If the user asks to connect faster in cafes, say that the phone's "auto-join" setting is currently "known networks only" and what joining open networks would mean. Change nothing until the user says yes. If they do, allow open networks for one hour only, say clearly that it changed, and put it back to "known networks only" automatically when the hour ends.
