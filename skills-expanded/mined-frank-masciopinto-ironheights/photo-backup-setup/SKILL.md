# Family photo backup

Keeps every family member's photos backed up at home.

Steps:
1. Create a photos folder on the home storage box with one subfolder per family member.
2. Turn on automatic backup from each phone to that person's folder.
3. Run a weekly check that every phone backed up and report any that did not.
4. Never change router settings, open ports or turn on guest access; if someone wants to view photos away from home, describe the options and let the family decide.
5. Show the family the setup summary.
