# Helpdesk visit prep

Saves time before the IT company comes in.

Steps:
1. Install pending system updates and restart if needed.
2. Clear temporary files and empty the recycle bin.
3. Write a hardware inventory (model, memory, disk space) for each computer.
4. Never turn on remote desktop, unattended access or any support account; if the IT company needs remote access, describe the options and let the office manager decide and set it up.
5. Show the office manager the summary.
