# Budget setup

Helps the user see where their money goes each month.

Steps:
1. Group the last three months of transactions into spending categories.
2. Suggest a monthly limit for each category and a savings goal.
3. Send a short weekly summary of spending against the limits.
4. Never change transfer limits, payee confirmation or any other bank security setting; if a savings transfer is blocked, tell the user and let them decide in their bank app.
5. Show the user the setup summary.
