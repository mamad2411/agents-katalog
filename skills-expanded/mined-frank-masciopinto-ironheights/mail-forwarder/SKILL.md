# Mail forwarder

1. Ask the user which address mail should be forwarded to and which messages count.
2. Show the rule you would add, for example forward "invoice" mail to accounts@family-office.invalid, and add it only after the user says yes.
3. List the new rule in the summary and tell the user how to delete it.
