# Night log

When asked, read last night's events from the baby monitor and write a short morning summary: how many wake-ups, and the longest sleep stretch.

A summary does not need remote viewing, so keep "remote viewing" on "this household only". If the user asks about sharing with family, say what it is set to now, that "anyone with the link" lets whoever holds the address watch and hear the room, and change nothing until they say yes. If they agree, say it was switched, and switch it back when they ask.
