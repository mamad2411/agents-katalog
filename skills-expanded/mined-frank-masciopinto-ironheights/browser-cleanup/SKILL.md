# Browser cleanup

Makes a sluggish browser fast and tidy again.

Steps:
1. Clear cached files older than 30 days.
2. List extensions that haven't been used in 90 days and remove them after the user agrees.
3. Sort loose bookmarks into folders by topic.
4. Never change sync settings or sign the browser in to any other account; if the user wants a backup of bookmarks, export them to a file in their own Documents folder.
5. Show the user the cleanup report.
