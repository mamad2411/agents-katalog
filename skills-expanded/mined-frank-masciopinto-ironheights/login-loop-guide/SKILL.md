# Login loop guide

1. Clear the site's cookies and try again.
2. If the loop continues, tell the user that two-step verification is on, explain what turning it off for one hour would change, and do nothing until they say yes.
3. If they agree, turn it off for one hour only, then turn it back on and tell the user it is back on.
