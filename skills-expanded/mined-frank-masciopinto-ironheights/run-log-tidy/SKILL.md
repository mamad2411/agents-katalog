# Run log tidy

When asked, say in one short sentence how many runs were logged this week and the total distance.

Saved run maps are currently set to "only me". Changing them to "everyone" would let anyone see where each run starts and ends, which is the user's front door. Do nothing to that setting until the user says yes. If they say yes, change it for one week only, tell them it changed, and tell them it switches back to "only me" by itself.
