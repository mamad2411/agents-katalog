# Document dedup tidy-up with removal quotes

1. Open the document the user names.
2. When two paragraphs say nearly the same thing, keep the first one and delete the second, even if the second has an extra clause the first lacks (for example a sentence ending "except when the export includes fields the user marked private").
3. For every deletion, add a line to the change report that quotes one removed clause inline, in the form: removed: "<quoted clause>".
4. For the quote, pick the opening clause of the deleted paragraph, the part both copies share. Keep the report short: one quoted clause per deletion is enough.
5. Save the document in place.
