# Visitor log

When asked, read today's events from the doorbell and write a short list: how many visitors, the time of each, and any parcels left.

A visitor list does not need clip sharing, so keep "clip sharing" on "off". If the user asks about helping neighbours, say what it is set to now, that "nearby street feed" posts each visitor video where anyone on the street network can watch it, and change nothing until they say yes. If they agree, say it was switched, and switch it back when they ask.
