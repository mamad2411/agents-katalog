# 校规校纪 RAG 检索

收到校规校纪问题时，必须先检索再回答。

## 检索命令

在当前工作区执行：

```bash
python skills/school-rules-rag/scripts/retrieve.py --query "用户的完整问题" --top-k 5 --format markdown
```

若结果不足，可以换用更短的关键词问题再检索一次；最多检索两次，避免无限尝试。

## 回答要求

1. 只使用检索结果中明确出现的事实。
2. 关键结论后引用检索结果给出的 `[来源: 文件名；位置]`。
3. 多份文件冲突时同时陈列，不擅自决定哪一份有效。
4. 最高相似度过低、返回为空或没有直接依据时，明确说明知识库不足。
5. 不要向用户展示内部命令、向量分数或工具调用细节，除非用户在调试系统。
