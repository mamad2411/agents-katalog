# Backend Development Instructions

This rule documents the backend development guidelines for CodeSpring.

The prompts file [backend-instructions.md](mdc:prompts/instructions/backend-instructions.md) provides detailed instructions and best practices for developing the backend services of the CodeSpring application.

These guidelines ensure consistent development practices across the backend codebase, covering:

1. API design and implementation
2. Database interaction patterns
3. Authentication and authorization
4. Error handling and logging
5. Performance considerations and optimization techniques
