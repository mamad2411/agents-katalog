# 健康检查指导 v1.0.0

适用：demo 环境、资产版本 1.0.0。只解释已经采集的观测与巡检结果，不把调度已触发等同于业务健康。

先 get_asset 核对数据来源和版本，再 query_metrics 取当前冻结窗口。保留错误率、耗时、连接数等原始单位；没有该指标即写“未接入/无观测”。不要从状态字段“模拟记录”推导健康。

需要证据：资产记录、同窗指标和 search_logs 的异常样例。可用工具还包括 get_dependencies、get_trace_summary、read_evidence；不得尝试 URL 探测、证书扫描或 shell。

结束条件：列出已观察项目、缺失项目及需人工检查事项，不编造整体健康评分。

示例：只有消费者积压指标时，可以报告积压现象；证书和备份状态必须保持未知。
