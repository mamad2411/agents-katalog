# skill-scout 🔍

**מגלה את התוספים הכי טובים ל-Claude Code - ואומר לך כמה הם בטוחים, לפני שאתם מתקינים.**

יש המון סקילים מעולים ברשת. יש גם סקילים מסוכנים - עם באגים, פריצות ודליפות מידע. כל המאגרים
באינטרנט מדרגים **פופולריות** (כוכבים, התקנות), אבל אף אחד לא אומר לכם אם תוסף יקרא את ה-`.env`
שלכם, ירוץ עם פקודות הרס, או ישתנה לזדוני אחרי שסמכתם עליו. skill-scout סוגר בדיוק את הפער הזה:
הוא מוצא את הטובים **וגם בודק אותם**.

הסקיל עובד בכל שפה - אתם מדברים אליו בעברית (או כל שפה), והוא עונה באותה שפה.

## מה הוא עושה

| יכולת | מה זה נותן לכם |
|-------|----------------|
| 🔎 **גילוי** | "מצא לי סקיל ל…" - קורא את הסביבה שלכם, שואל כמה שאלות, וסורק מאגרים אמיתיים. מחזיר טבלה מדורגת עם **ציון 1-100** לכל אופציה |
| 🛡️ **בדיקת בטיחות** | על תוסף נבחר: משכפל את הקוד לארגז-חול, סורק אותו (פקודות הרס, גישה לסודות, הזרקת prompt, exfiltration, obfuscation, hooks), ומחזיר **רמת סיכון 1-5** עם הממצאים הקונקרטיים |
| 📦 **התקנה באישור** | מתקין רק אחרי אישור, עם **נעילת גרסה (SHA)**, ורושם ביומן כדי שאפשר יהיה לבדוק מחדש כשהתוסף מתעדכן |
| 🧩 **כל האקוסיסטם** | Skills, MCP servers, plugins, slash commands |

**שני המספרים:** ציון מוניטין **0-100** (כמה הסיגנלים הציבוריים אומרים שאפשר לסמוך - זה מוניטין,
לא ביקורת קוד) · רמת סיכון **1-5** (מה הסריקה מצאה בקוד עצמו: 1 = נראה בטוח, 5 = אל תתקין).

## עקרון הברזל

זה כלי **תמיכה בהחלטה, לא ערובה**. ניתוח סטטי + מוניטין מנצח כל מאגר שקיים היום, אבל לא תופס כל
התנהגות דינמית ולא חוזה "rug-pull" (תוסף שנקי היום והופך לזדוני בעדכון עתידי). לכן כל התקנה ננעלת
ל-SHA ונרשמת. ההחלטה הסופית תמיד שלכם.

## התקנה

**דרישות:** Python 3.9+ ו-git (ספריית-תקן בלבד, אין `pip install`). `gh CLI` מומלץ אך לא חובה.

הדרך הכי פשוטה - הדביקו את זה ל-Claude Code שלכם:

> התקן לי את הסקיל skill-scout: הרץ
> `git clone https://github.com/Brain-ai-biz/skill-scout ~/.claude/skills/skill-scout`
> ואז ודא שהוא נטען, והרץ בדיקת שפיות:
> `python3 ~/.claude/skills/skill-scout/scripts/scout.py vet https://github.com/anthropics/skills`
> (צריך לחזור band 1 = נראה בטוח).

או ידנית בטרמינל:
```bash
git clone https://github.com/Brain-ai-biz/skill-scout ~/.claude/skills/skill-scout
python3 ~/.claude/skills/skill-scout/scripts/scout.py vet https://github.com/anthropics/skills
```

אחרי זה פשוט בקשו מ-Claude: "מצא לי סקיל ל…" או "האם הסקיל הזה בטוח?".
