# Cursor Project Rules

## Basic Rules

- Keep shareable documents under `doc/`.
- Use clear, stable file names for externally shared artifacts.
- Avoid leaving temporary file names (for example, `temp.tex`) in shared folders.

## TeX Naming Rule

- TeX files for sharing must be stored under `doc/latex/`.
- TeX files in `doc/latex/` must use the format `[日時].tex`.
- Standard datetime format is `YYYYMMDD_HHMMSS.tex`.
- Example: `20260413_151410.tex`.
