## 七层 BP 决策架构（必须按序）

```
L1 哲学   强队即版本 | 三流教练过滤器 | 英雄池先行
L2 赛段   苟分/拓池/季后赛/挑杯 → 定风险偏好
L3 赛制   全局BP消耗 | BO7前六局 | 巅峰对决 | 蓝红方
L4 Ban    拆体系 > 按人 > 防版本 > 保pick链
L5 Pick   选阵容原型 A-F（见下）
L6 执行   池子/训练赛/选手气质/人岗匹配
L7 复盘   不乱总结 | 「阵容没做特别好」
```

**跳过 L6 直接选「秀」的阵容 = 三流教练。**

## L2 · 赛段目标 → 风险偏好

| 赛段 | 风险偏好 | 林教行为 |
|:---|:---|:---|
| 常规赛/卡位 | 中；可拓池 | 「选貂蝉拓展英雄池」；苟胜者组 |
| 季后赛 BO7 | 前六局求终结 | 巅峰对决=保密备牌，非常规退路 |
| 挑杯 BO9 | 全局消耗战 | 5:0 RW；首战巅峰 4:3 胜 AG |

**决策式**：
```
IF 净胜分/名次已稳 AND 季后赛临近 → 求稳，不亮拓池牌
IF 卡位生死 AND 对手弱 → 可拓池但须练过
IF 季后赛 → 前六局终结 > 单场秀
```

## L3 · 赛制层

### 全局 BP
- 英雄跨局消耗；前局骗 ban/拓池影响后局
- BO9 挑杯：阵容**厚度** > 单场最优

### 巅峰对决
- **主流作业（2023）**：沈梦溪+项羽+夏侯惇+戈娅+孙膑（久哲系，多队抄）
- **林教立场**：自研与主流**显著不同**；「最好不要和我们打巅峰对决」
- **已验证**：2025挑杯巅峰胜AG；2025春季后赛巅峰胜狼队
- **保密**：具体五人未公开

### 蓝红方
- WB 2025春蓝方胜率 **70.97%** → 可争蓝
- 红蓝不作失利借口

## L4 · Ban 逻辑

### 优先级
1. **拆 opponent 体系** — 孙膑发动机、朵莉亚联动等
2. **按人 ban** — 对手节奏核心招牌
3. **防版本** — 己方不会的版本强势点
4. **保 pick 链** — 为己方 1/2 选位创造条件

### 对抄作业对手
- Ban 体系关键一环，逼半成品组合
- **不镜像抄**；用破解型思路

### 反模式
- 输一局否定整套打法
- 无 pick 链规划的乱 ban

## L5 · Pick 原型（林教风格谱）

分析时**先判定原型，再填英雄**（非先填英雄再凑理由）。

### A · 水桶消耗 / 多核节奏（偏锋）

- **结构**：前排 + 压制中 + 后勤辅 + 1~2 单体节奏点
- **案例**：2024 Hero G1 — 梦奇/沈梦溪/桑启 + 姬小满/公孙离 vs 朵莉亚敖隐
- **逻辑**：阵容不劣势，需**联动+单点均打出**；Hero 局内未执行 → 输
- **适用**：选手执行力接近狼队水准

### B · 防守运营 / 保核（狼队成熟态）

- **结构**：射辅强势 + 肉边野 + 工具中；局内运营
- **案例**：2024 Hero G2 — 敖隐核 + 曹操 + 杨玉环 + 王昭君
- **逻辑**：学狼队运营；需**五人默契**；Hero 前期崩 → 失败
- **适用**：小胖级野节奏 + 成熟默契（2022-2023 狼队）

### C · 赛点激进变阵

- **结构**：进攻型组合；counter 位（如海月）
- **案例**：2024 Hero G3 — 鲁班父子/兰陵王/亚连/海月
- **逻辑**：防守打不过转激进；**慌乱风险高**
- **复盘点**：边路反打不足则团战胜率低

### D · 拓池型

- **案例**：2025 貂蝉
- **逻辑**：季后赛留选项 > 单场完美；可承认「阵容没做特别好」

### E · 轮换激活体系

- **案例**：2025 WB 听悦+梦溪中辅轮换 → 暖阳回升
- **逻辑**：换人 = 换 BP 组合池

### F · 坦野 / 版本适应

- **案例**：2023 夏侯/狂铁坦野；Fly 猪八戒/廉颇/马超
- **逻辑**：野核思维平滑转坦野；版本变 → 先扩池再 BP

## L6 · 执行校验（最关键一层）

**林教 BP 高度依赖执行人**（2024 腾讯：「剑走偏锋阵容，已无人能执行」）。

### 校验清单（全过才推荐）

- [ ] 五人英雄池交集覆盖阵容
- [ ] 训练赛练过（黎洛：无数 scrim 验证，1~2 赛季平衡）
- [ ] BP 阶段选手气质：主动讨论 ✅ / 全听教练 ❌
- [ ] 核心选手能否主导前期布局（成熟队如小胖）
- [ ] 人岗匹配（JDG 反例：训练赛好赛场差）
- [ ] 轮换状态：状态不对不硬上（Fly/小胖范式）

### 组织模型

| 角色 | BP 职能 |
|:---|:---|
| 林教 | 方向、赛段策略、轮换、心态 |
| 黎洛 | 训练赛验证、巅峰 BP 研究、操作细节 |
| 选手 | 主动提议英雄；成熟野核可定前期布局 |
