# Novel 构思阶段（Phase 1）

## 激活条件

由 `novel-writer-workflow-guide` 路由激活，当用户：
- 说"我想写小说" / "这个题材可以怎么做"
- 讨论主题、人物、世界观、目标读者
- 问"主角应该什么性格" / "反派要不要救赎"

## 这个阶段要产出

**三个核心文档**：

1. **`宪法.md`（constitution）**——创作红线、核心价值、风格锚、不可妥协的原则
2. **`specify`（规格文档，可写在 README 或单独文件）**——一句话钩子、一句话故事、目标读者画像、核心冲突、成功标准
3. **`clarify` 决策记录**——模糊点 5 问 5 答

## 与用户讨论的五大主题

不是一次讨论完，是来回迭代几轮。

### 1. 主题（Theme）

问法：
- "你想让读者看完记住一句话的话，是什么？"
- "这个故事的核心情感是什么？（复仇 / 救赎 / 成长 / 重生 / 归家 / 寻找）"
- "主角最后回答了什么问题？"

**别搞错**：
- 主题不是题材（"重生+鉴宝"是题材，"一个被背叛的人如何重新相信一只手"是主题）
- 主题不是钩子（钩子是吸引读者点开的第一句，主题是读完后留下的那一口气）

### 2. 人物（Characters）

每个关键人物至少回答：
- **名字 + 年龄 + 身份**
- **核心动机**（他/她要什么）
- **阻碍**（什么挡着他/她）
- **弧线**（故事开始时什么样，结束时变成什么样）

**主角**：必须具体，不能用"一个天才"这种抽象词。
**反派**：至少两层——台前执行者 + 幕后主使。两层反派各有各的动机，不能都是"为钱"。
**女主/男配**：CP 戏份要定性——是"主线之一"还是"陪衬点缀"？

### 3. 世界观（Worldview）

不是"奇幻才要世界观"。每一本现代向小说也需要世界观设定：
- **时间地点**：故事发生在 X 年 Y 地
- **圈子规则**：主角所在的行业/圈子有什么行话、潜规则、江湖秩序
- **金手指边界**（如果有）：能力边界、代价、破解方式——这是防外挂失控的关键
- **社会背景**：和真实世界的偏差度（完全写实 / 架空 / 轻穿越）

### 4. 目标读者（Target Audience）

**必须具体到三层**：
- **主读者**：年龄带 + 性别（如果题材偏向明显）+ 平台（番茄/起点/晋江/知乎）+ 对标作品
- **次读者**：补充扩散层
- **第三读者**：改编后的受众（如果有影视化想法，改编后受众可能和原著不一样）

**别搞错**：
- 对标剧/书要选**内核相似**的，不是"都是古装"就能对标
- 男频/女频的内核完全不同（男频：主角带读者碾压对手；女频：主角带读者感同身受成长）

### 5. 核心冲突（Core Conflict）

一句话描述：
- **主角要什么**（目标）
- **谁挡着**（对抗方）
- **赌注是什么**（输了会怎样）
- **主角如何改变才能赢**（内在弧线）

例：主角要替父昭雪（目标），反派集团联合体制内保护伞挡着（对抗方），赌注是家族名声与至亲性命（赌注），主角要从"被动绝境"变成"主动破局"（内在弧线）。

## 讨论引导 prompt 模板

当用户说"我想写一本 X 题材的书"，你可以这样展开：

```
好。X 题材最近的市场一般是 [举 2-3 个对标]，我们先定几件基础的事：

1. 主角的第一幕起点：他/她现在的处境是什么？
2. 主角的终局：这本书结束时，他/她拥有什么了、失去什么了？
3. 反派的台前是谁、幕后是谁？
4. 这本书的一句话钩子（吸引读者点开的那句）是什么？
5. 目标读者画像：谁会读、为什么读、追完什么剧会点这本？

这五个问题的答案，是 constitution 的底。我们一问一答过一遍。
```

## 输出文档模板

### `宪法.md` 最小模板

```markdown
# XX 小说 · 创作宪法

## 核心价值
- [主题句 1，不超过一行]
- [主题句 2，不超过一行]

## 质量底线（绝对不妥协）
- [例：主角"苏淮"始终姓苏，不得误写成林淮]
- [例：心眼有代价，不得全知外挂]
- [例：无超自然解释]
...

## 风格原则
- [例：短句、断行、破折号克制]
- [例：全角引号，无 markdown bold]
- [例：每章末留钩子]

## 内容原则
- [例：反派分两层，幕后大 BOSS Ch X 才揭名]
- [例：CP 线合法靠无血缘，不靠改姓]
...

## 硬约束锁（脚本化可检测项，交给 novel-consistency-guards）
- 姓氏锁：[主角全名]
- 引号类型：中文全角
- 破折号上限：每章 ≤ 7
- Markdown bold：禁用
- Meta "Ch N" 引用：禁用
- 超自然解释：禁用
```

### `specify` 最小模板

```markdown
## 一句话钩子
"[一句能吸引读者的话]"

## 一句话故事
[一句话能说清整本书]

## 目标读者
- **主读者**：[年龄带 + 性别 + 平台 + 对标]
- **次读者**：[扩散层]
- **第三读者**：[改编后受众，如有]

## 核心冲突
- 主角要什么：
- 谁挡着：
- 赌注：
- 内在弧线：

## 成功标准
- 字数：
- 完读率：
- 口碑扩散源：
```

## 完成标准（进入 Phase 2 之前）

用户能脱口答出：

1. 一句话主题（不超过 15 字）
2. 一句话故事（不超过 50 字）
3. 主角的起点 + 终点（各一句）
4. 主要反派（至少两层，台前+幕后）
5. 目标读者的一句话画像

**答不出来不要进 Phase 2**。框架没法搭在沙地上。

## 常见陷阱

### 跳过 clarify

用户经常想"特主题已经定了，直接开始搭大纲"。但构思期留下的模糊点，**在写作期会翻倍成 bug**。至少走一轮 clarify，把 3-5 个关键模糊点澄清掉。

### 主题太散

"我想写一本重生鉴宝+言情+宫斗+现代都市的书"——这种多主题会导致写作期失焦。一个主题是主轴，其他是陪衬。必须排序。

### 目标读者模糊

"年轻人都会喜欢"——不是目标读者画像。必须缩到"25-40 岁男性番茄/起点生态，追《庆余年》类"这种具体。

### 反派扁平化

"反派就是很坏"——这种反派撑不起长篇。反派要有自己的逻辑和动机，甚至要有一点让读者能理解的部分（不认同但能理解）。

### 金手指没边界

"主角开金手指鉴宝无所不知"——这种没代价的金手指读者两章就腻。构思期就要定好边界和代价（心眼有代价 / 每天只能用一次 / 有后遗症 等）。
