# TxGemma hERG Research Project Rules

## Session Startup Protocol
1. ALWAYS read PROJECT_CONTEXT.md first to understand current focus
2. Check TASKS.md for today's priorities before suggesting work
3. Update SCRATCHPAD.md with your reasoning as you work

## File Management Rules
- Update TASKS.md when priorities change
- Log key insights in SCRATCHPAD.md 
- Don't read entire directories without asking
- Prefer reading specific files over broad exploration

## Code Standards
- Use descriptive variable names for SMILES and experimental data
- Comment complex prompt generation logic
- Include docstrings for functions that interface with TxGemma
- Save experimental results in experiments/ with date stamps

## Research Context
- This is a PhD-level ML/biostatistics project on hERG cardiotoxicity
- Focus on behavioral experiments with TxGemma language models
- Prioritize statistical rigor and reproducible experimental design
- Use professional R/Python packages for analysis

## Communication Style
- Be concise but thorough
- Use scientific terminology appropriately
- Provide code examples when suggesting approaches
- Always explain statistical reasoning behind experimental choices
