# SeaLeap 日本站广告利润与预算重分配

先回答哪些 SKU 仍有广告空间，再决定怎样分配流量。将成本压力、日文流量覆盖和高意向消费者测试放进同一份计划。

## 必需输入

- 日本站店铺与广告 profile、SKU/ASIN、售价币种、结算币种、汇率日期。
- 采购、头程、履约、佣金、优惠、预期退货损失及其他实际成本；税费与可抵扣项目分别列示。
- 同窗口总销售、广告销售、花费、点击、订单、库存及补货周期。
- 自动与手动投放报告、搜索词、广告位，以及当前 AMC 与 SP/SB 受众功能资格。

## 工作流

1. 统一币种和成本口径，计算广告前贡献利润。区分单件利润与订单利润，剔除重复计入的广告费；未确认的税费不先当作返还收入。
2. 按广告容错、库存和增长证据给 SKU 标记“可测试、需修复、暂缓扩量”。亏损来源不清时继续列证据缺口，不能直接扩大预算。
3. 对自动与手动投放拆分 CPC、订单 CVR、ACoS，识别不相关搜索词及可验证的日文长尾。自动迁移到精准后重新观察表现，不假定效果复制。
4. 评估加购未买、浏览未买、广告点击未买等受众是否有当前可用模板和足够数据。**SP/SB 的 AMC 受众通常用于竞价调整，不能据此声称只向该受众展示或已经绕过关键词/商品定向。** 独立受众定向应核对支持它的广告产品与账户能力。
5. 选择一个主变量测试：受众加价、关键词结构或 SP/SB 配比三者择一。保留基线预算、流量组成和回退值，按订单利润限制测试成本。
6. 同时观察总销售、广告销售、贡献利润、ACoS、TACoS、库存和退货。TACoS 不能单独证明广告增量，CVR 低也不能直接判定流量不精准。

## 交付

- SKU 成本与广告空间表，含币种、汇率和未知成本。
- 保留、修复、暂缓扩量的 SKU 及证据。
- 预算来源与去向明细，合计不超过用户授权上限。
- 受众定义、实际承接机制、实验主变量、观察窗口与回退方案。
- 无法支持的材料表述、待核对资格和政策。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
