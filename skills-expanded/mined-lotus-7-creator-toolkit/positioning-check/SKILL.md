# Positioning Check (定位校验)

## Overview

校验内容创作定位是否清晰、一致，确保目标受众、核心信息、情感反应三者对齐。

## 校验维度

### 1. 目标受众 (Target Audience)

**检查点：**
- 受众是否清晰？（年龄、性别、职业、兴趣...）
- 受众是否具体？（"所有人" = 没有人）
- 受众与内容是否匹配？

**问题引导：**
```
- 这个内容是给谁看的？
- 他们为什么会对这个话题感兴趣？
- 他们当前对这个话题的认知是什么？
- 他们看完后会有什么改变？
```

**受众画像示例：**
```
模糊: "年轻人"
清晰: "25-30岁职场新人，正在经历加班疲劳，需要共鸣和发泄"

模糊: "宝妈"
清晰: "28-35岁二胎妈妈，焦虑孩子教育，寻找育儿方法"
```

### 2. 核心信息 (Core Message)

**检查点：**
- 想传达什么？（用一句话概括）
- 信息是否聚焦？（不超过3个要点）
- 信息是否与受众相关？

**问题引导：**
```
- 用一句话说出这个内容要传达什么
- 观众记住这句话就够了，你希望是哪句？
- 这个信息对观众有什么价值？
- 是否有更简单的方式表达？
```

**核心信息示例：**
```
模糊: "拖延症不好，要改"
清晰: "拖延症不是懒，是情绪问题，解决情绪才能解决拖延"

模糊: "努力工作"
清晰: "努力不等于高效，选对方向比努力更重要"
```

### 3. 预期情感反应 (Emotional Response)

**检查点：**
- 希望观众看完后有什么情绪？
- 内容是否真的能引发这种情绪？
- 情感是否与核心信息一致？

**问题引导：**
```
- 观众看完后应该有什么感觉？
- 什么画面/台词会引发这种感觉？
- 这种感觉是否符合内容定位？
```

**情感反应示例：**
```
搞笑内容: 观众应该笑，如果没笑就是失败
感人内容: 观众应该有共鸣/泪点，如果无感就是失败
干货内容: 观众应该有收获感，如果没记住就是失败
```

## 输出格式

```
=== 内容定位校验 ===

【当前定位】
目标受众：[当前描述]
核心信息：[当前描述]
预期情感：[当前描述]

【定位分析】
受众清晰度：[清晰/模糊/缺失]
核心信息：[聚焦/分散/不明确]
情感一致：[一致/冲突/无情感]

【问题诊断】
[列出3个以内的问题]

1. [问题描述]
   - 影响：[这个问题会导致什么]
   - 建议：[如何改进]

2. ...

【优化建议】
目标受众：[优化后的描述]
核心信息：[一句话核心]
预期情感：[具体情感描述]

【一致性检查】
✓/✗ 受众与信息是否匹配
✓/✗ 信息与情感是否匹配
✓/✗ 情感与受众是否匹配

【下一步行动】
[1-2个具体建议]
```

## 常见问题及建议

### 问题1：受众模糊

**表现：** "年轻人"、"职场人"、"宝妈"等大群体

**影响：** 内容没有针对性，观众没共鸣

**建议：**
```
缩小范围 + 增加细节
从: "职场人"
到: "25-30岁互联网公司新人，正在经历第一份工作的挫败感"
```

### 问题2：核心信息分散

**表现：** 想说的太多，什么都想说

**影响：** 观众记不住，传播力弱

**建议：**
```
聚焦单一观点
从: "拖延症的原因、危害、解决办法、案例"
到: "拖延症不是懒，是情绪问题"（其他都是支撑）
```

### 问题3：情感与内容冲突

**表现：** 想感人但内容搞笑，想搞笑但内容严肃

**影响：** 观众困惑，不知道该有什么反应

**建议：**
```
统一情感基调
从: "搞笑+感动+干货"（太杂）
到: "用搞笑的方式讲干货"（统一）
```

### 问题4：信息与受众不匹配

**表现：** 信息太深/太浅，不符合受众认知

**影响：** 观众看不懂/不想看

**建议：**
```
调整信息密度
- 受众是小白 → 用类比/案例，少术语
- 受众是专家 → 直接讲观点，快节奏
```

## 校验流程

### Step 1: 收集定位信息

询问用户或从已有内容提取：
- 目标受众是谁？
- 核心信息是什么？
- 希望引发什么情感？

### Step 2: 诊断问题

根据三个维度检查：
- 受众是否清晰具体？
- 信息是否聚焦？
- 情感是否一致？

### Step 3: 给出建议

- 优化后的定位描述
- 具体改进建议
- 下一步行动

## Examples

**Example 1: 定位模糊的内容**

```
输入: "我想做一个关于健身的视频"

当前定位:
目标受众: （未说明）
核心信息: "健身很重要"
预期情感: （未说明）

诊断:
1. 受众模糊 - "所有人" = 没有人
2. 信息太泛 - "健身重要"谁都知道
3. 情感缺失 - 不知道想引发什么情绪

建议:
目标受众: 25-30岁办公室白领，久坐不动，想开始健身但没时间
核心信息: 每天15分钟，在家就能完成的办公室健身
预期情感: 观众觉得"这个我能做到"，有行动冲动
```

**Example 2: 定位冲突的内容**

```
输入: "想做一个搞笑又感人的职场视频"

当前定位:
目标受众: 职场新人
核心信息: 职场不容易
预期情感: 搞笑 + 感人

诊断:
1. 情感冲突 - 搞笑和感人很难同时做到，容易两头不讨好
2. 信息模糊 - "职场不容易"太宽泛

建议:
选择一个方向:
- 搞笑方向: 用夸张表现职场崩溃瞬间，引发共鸣和笑声
- 感人方向: 讲一个真实的职场成长故事，温暖治愈
```

**Example 3: 定位清晰的内容**

```
输入: "拖延症不是懒，是情绪问题"

当前定位:
目标受众: 明明很努力但就是拖延的年轻人
核心信息: 拖延症是情绪问题，不是懒，解决情绪才能解决拖延
预期情感: 观众被理解，有共鸣，有希望

诊断:
✓ 受众清晰 - 有明确痛点的人群
✓ 信息聚焦 - 一个核心观点
✓ 情感一致 - "被理解"的情绪贯穿始终

一致性检查:
✓ 受众与信息匹配 - 有拖延问题的人需要这个观点
✓ 信息与情感匹配 - "不是懒"让人感到被理解
✓ 情感与受众匹配 - 需要被理解的人会共鸣

结论: 定位清晰，可以直接开始创作
```

## 使用时机

### 创作前
- 确定内容方向时
- 有多个想法时，帮助选择

### 创作中
- 写大纲时，检查是否偏离定位
- 写脚本时，检查是否符合定位

### 创作后
- 内容完成后，检查是否达成定位
- 数据不好时，诊断定位问题

## 质量标准

- **三个维度清晰**: 受众、信息、情感都有明确描述
- **三者一致**: 不存在冲突
- **建议可执行**: 给出具体改进方向
- **诊断准确**: 找到真实问题
