# Export Formats (导出格式)

## Overview

将分镜脚本和AI生图提示词导出为不同格式，满足不同使用场景需求。

## 支持格式

### 1. xlsx (Excel表格)

**用途：** 专业分镜表、团队协作、数据管理

**表格列：**
| 镜号 | 景别 | 画面描述 | 台词/旁白 | 时长 | 音效/配乐 | AI生图提示词 |
|------|------|----------|-----------|------|-----------|--------------|

**特点：**
- 结构清晰，易于修改
- 支持筛选、排序
- 可打印、可分享
- 适合摄影团队使用

**使用 xlsx skill 生成**

---

### 2. pptx (PowerPoint演示)

**用途：** 客户汇报、创意提案、团队评审

**每页结构：**
- 标题：镜号 + 景别
- 画面区：画面描述 + AI生图提示词
- 台词区：台词/旁白
- 信息栏：时长、音效/配乐

**可选页面：**
- 封面：项目名称、日期、创作者
- 目录：镜头列表
- 总结：总时长、镜头数、备注

**特点：**
- 视觉化呈现
- 适合演示讲解
- 可插入参考图
- 适合客户沟通

**使用 pptx skill 生成**

---

### 3. Markdown 文档

**用途：** 个人归档、版本管理、在线协作

**结构：**
```markdown
# 分镜脚本：[标题]

## 基本信息
- 主题：[主题]
- 类型：[类型]
- 风格：[风格]
- 总时长：[时长]
- 镜头数：[数量]

## 分镜表

### 镜头1
- 景别：MS
- 画面描述：[描述]
- 台词：[台词]
- 时长：3s
- 音效：[音乐]
- AI提示词：[prompt]
...
```

**特点：**
- 纯文本，易管理
- Git版本控制
- 支持在线协作
- 适合开发者/技术团队

---

### 4. 看板 (Kanban)

**用途：** 项目管理、进度跟踪

**列结构：**
```
待拍摄 | 拍摄中 | 后期中 | 已完成
```

**卡片内容：**
- 镜号 + 景别
- 画面描述
- 负责人
- 截止日期
- 备注

**工具：**
- Trello
- Notion
- 飞书多维表格
- GitHub Projects

**特点：**
- 可视化进度
- 团队协作
- 状态追踪
- 适合项目管理

---

### 5. JSON 数据

**用途：** 程序调用、API集成、批量处理

**结构：**
```json
{
  "project": "项目名称",
  "metadata": {
    "theme": "主题",
    "type": "类型",
    "style": "风格",
    "duration": "30s"
  },
  "shots": [
    {
      "id": 1,
      "shot_type": "MS",
      "description": "画面描述",
      "dialogue": "台词",
      "duration": "3s",
      "music": "音乐",
      "ai_prompt": "提示词"
    }
  ]
}
```

**特点：**
- 结构化数据
- 易于解析
- 可批量处理
- 适合自动化工作流

## 输出格式选择指南

| 使用场景 | 推荐格式 | 理由 |
|----------|----------|------|
| 摄影团队 | xlsx | 专业分镜表，易于现场使用 |
| 客户汇报 | pptx | 视觉化呈现，适合演示 |
| 个人归档 | Markdown | 简洁、可版本控制 |
| 团队协作 | 看板 | 进度可视化，状态追踪 |
| 批量处理 | JSON | 程序化处理，可自动化 |
| 打印输出 | xlsx/pptx | 格式规范，易于打印 |

## 调用其他技能

### 导出为 xlsx

```
使用 xlsx skill:
1. 创建表格，设置列名
2. 填充镜头数据
3. 设置格式（列宽、对齐、样式）
4. 保存为 .xlsx 文件
```

### 导出为 pptx

```
使用 pptx skill:
1. 创建演示文稿
2. 添加封面页
3. 为每个镜头创建一页
4. 设置布局和样式
5. 保存为 .pptx 文件
```

## Examples

**Example 1: 导出为 xlsx**

```
调用: xlsx skill

输入:
- 表格数据：分镜表
- 表头：镜号 | 景别 | 画面描述 | 台词/旁白 | 时长 | 音效/配乐 | AI生图提示词

输出: script_storyboard.xlsx
```

**Example 2: 导出为 pptx**

```
调用: pptx skill

输入:
- 封面：标题、日期
- 每页：镜头信息（画面+台词+时长）

输出: script_presentation.pptx
```

**Example 3: 导出为看板**

```
输出: 看板结构说明

可用工具:
- Trello: 导出为 CSV 格式
- Notion: 导出为 Notion 模板
- 飞书: 导出为飞书多维表格
```
