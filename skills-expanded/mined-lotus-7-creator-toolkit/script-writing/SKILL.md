# Script Writing (视频脚本生成)

## Overview

将故事大纲拆解为可执行的分镜脚本，每个镜头包含完整拍摄信息。

## 输入处理

### 必需输入
- **故事大纲**: 开场-发展-高潮-结尾的完整大纲
- **内容类型**: short-video / medium-video / story / knowledge / vlog
- **时长限制**: 15-60s / 1-3min / 3-10min
- **风格偏好**: funny / touching / suspense / educational / real

### 镜头数量估算

| 类型 | 时长 | 镜头数量 | 平均镜头时长 |
|------|------|----------|--------------|
| short-video | 30秒 | 8-12个 | 2-4秒 |
| short-video | 60秒 | 15-20个 | 2-4秒 |
| medium-video | 1分钟 | 15-25个 | 2-5秒 |
| medium-video | 3分钟 | 40-60个 | 3-5秒 |
| story | 3分钟 | 50-80个 | 2-5秒 |
| story | 10分钟 | 150-250个 | 2-5秒 |
| knowledge | 2分钟 | 25-40个 | 3-5秒 |
| vlog | 2分钟 | 20-30个 | 4-6秒 |

## 输出格式

```
=== 分镜脚本 ===

【基本信息】
主题：[主题]
类型：[类型]
风格：[风格]
总时长：[总时长]
镜头数：[镜头数量]

【分镜表】

| 镜号 | 景别 | 画面描述 | 台词/旁白 | 时长 | 音效/配乐 |
|------|------|----------|-----------|------|-----------|
| 1 | [景别] | [画面] | [台词] | [时长] | [音乐] |
| 2 | [景别] | [画面] | [台词] | [时长] | [音乐] |
...

【节奏分析】
- 快节奏部分：[哪些镜头，为什么快]
- 慢节奏部分：[哪些镜头，为什么慢]
- 情感曲线：[情绪如何变化]

【拍摄要点】
- 场景：[需要哪些场景]
- 道具：[需要准备什么]
- 灯光：[灯光建议]
- 演员：[表演要求]

【后期建议】
- 剪辑节奏：[如何剪辑]
- 转场：[转场方式]
- 调色：[色调风格]
- 字幕：[字幕建议]
```

## 景别使用

| 景别 | 代码 | 说明 | 使用场景 |
|------|------|------|----------|
| 特大特写 | ECU | 局部细节 | 情绪放大、视觉冲击 |
| 特写 | CU | 头部/手部 | 情感表达、重点强调 |
| 近景 | MCU | 胸部以上 | 对话、叙事主体 |
| 中景 | MS | 腰部以上 | 人物互动、日常场景 |
| 全景 | FS | 全身 | 动作展示、场景关系 |
| 远景 | LS | 环境 | 场景建立、转场 |

## 镜头设计原则

### 1. 节奏控制

**快节奏** (2-3秒/镜头)
- 用途：短视频、搞笑、紧张感
- 手段：快速剪辑、多角度、动作连贯
- 示例：搞笑反转、追逐戏

**中节奏** (3-5秒/镜头)
- 用途：中视频、日常叙事
- 手段：正常剪辑、完整表达
- 示例：vlog、知识类

**慢节奏** (5-7秒/镜头)
- 用途：情感表达、vlog
- 手段：长镜头、留白
- 示例：感人场景、思考时刻

### 2. 景别组合

**常用组合**
- 远景 → 全景 → 中景 → 近景 → 特写 (渐进)
- 特写 → 中景 → 全景 (退远)

**避免**
- 连续3个以上相同景别
- 从远景直接跳到特写（除非有特殊目的）

### 3. 运镜方式

| 运镜 | 说明 | 使用场景 |
|------|------|----------|
| 固定 | 机位不动 | 对话、稳定画面 |
| 推镜头 | 逐渐靠近 | 强调情绪、聚焦 |
| 拉镜头 | 逐渐远离 | 展现环境、结束感 |
| 摇镜头 | 左右转动 | 跟随动作、展现场景 |
| 移镜头 | 平移移动 | 跟随角色、平行叙事 |
| 跟镜头 | 跟随移动 | 动作跟随、沉浸感 |
| 手持 | 自然晃动 | vlog、真实感 |

### 4. 画面描述要素

每个画面描述需包含：
- **动作**: 谁在做什么
- **表情**: 什么表情
- **环境**: 在哪里、什么光线
- **运镜**: 什么运镜方式
- **重点**: 观众该看哪里

## 台词/旁白写作

### 原则
1. **口语化**: 像人说话，不要书面语
2. **简洁**: 每句不超过15字，超过就拆分
3. **有节奏**: 长短句交替
4. **有温度**: 用"你""我们"拉近距离

### 台词类型

**对白**: 两个人说话
```
A: 你为什么迟到了？
B: 电梯坏了，我爬上来的
A: 18楼？
B: 别提了...
```

**独白**: 一个人说话（内心或对着镜头）
```
对着镜头: 你们有没有这种经历？明明很努力，但就是看不到结果
```

**旁白**: 画外音解说
```
旁白: 这一天，他终于明白了什么才是真正重要的
```

## 音效/配乐设计

### 配乐类型

| 类型 | 情绪 | 示例场景 |
|------|------|----------|
| 轻快 | 搞笑、日常 | 搞笑视频、vlog开头 |
| 温暖 | 感人、治愈 | 情感故事、温馨时刻 |
| 紧张 | 悬念、冲突 | 悬疑片、冲突场景 |
| 激昂 | 励志、高潮 | 励志片、情感爆发 |
| 舒缓 | 思考、沉淀 | 反思时刻、结尾 |

### 音效使用

| 音效 | 用途 |
|------|------|
| 拍手、笑声 | 搞笑 |
| 心跳、钟表 | 紧张 |
| 风声、雨声 | 情绪氛围 |
| 键盘打字 | 办公场景 |
| 脚步声 | 动作跟随 |

### 音乐节奏匹配
- 剪辑点对音乐节拍
- 高潮配音乐高潮
- 转场用音乐变化

## 质量标准

- **镜头完整**: 每个镜头有完整信息（景别、画面、台词、时长、音乐）
- **节奏合理**: 快慢结合，符合内容类型
- **景别多样**: 避免连续相同景别
- **台词自然**: 口语化、简洁、有节奏
- **时长准确**: 总时长符合限制
- **可执行**: 摄影师能看懂怎么拍
