# Trend Analysis (竞品/爆款分析)

## Overview

分析同类爆款内容的成功元素，找到可以借鉴的点，同时发现差异化机会。

## 分析维度

### 1. 爆款元素拆解

**分析内容：**
- 主题/话题：讲什么？
- 切入角度：怎么切入？
- 结构/节奏：怎么讲故事？
- 画面/风格：什么视觉风格？
- 台词/金句：什么让人记住？
- 互动点：为什么引发评论/转发？

**输出格式：**
```
爆款元素:
- 主题: [什么主题]
- 角度: [什么角度]
- 结构: [什么结构]
- 风格: [什么风格]
- 金句: [什么金句]
- 互动: [为什么互动]
```

### 2. 目标受众分析

**分析内容：**
- 爆款内容是给谁看的？
- 为什么这个群体会喜欢？
- 他们的痛点/需求是什么？

### 3. 可借鉴元素

**可以从爆款学习什么：**
- 结构模板（不是内容）
- 节奏把控
- 互动设计
- 画面风格
- 台词风格

### 4. 差异化机会

**如何找到差异化：**
- 同一主题，不同角度
- 同一角度，不同风格
- 同一风格，不同人群
- 同一人群，不同深度

## 输出格式

```
=== 爆款内容分析 ===

【爆款信息】
标题/主题：[标题]
平台：[抖音/B站/小红书等]
数据：[点赞/评论/转发]

【爆款元素拆解】
1. 主题：[讲什么]
2. 角度：[怎么切入]
3. 结构：[什么结构]
4. 风格：[什么风格]
5. 金句：[什么让人记住]
6. 互动点：[为什么互动]

【受众分析】
目标人群：[给谁看的]
痛点/需求：[他们需要什么]
为什么爆：[满足了什么需求]

【可借鉴元素】
✓ 可以学习的：
- [元素1]：[具体说明]
- [元素2]：[具体说明]

✗ 不适合照搬的：
- [元素1]：[为什么不适合]
- [元素2]：[为什么不适合]

【差异化建议】
方案1：[差异化方向]
- 差异点：[和爆款有什么不同]
- 优势：[为什么这样更好]

方案2：[差异化方向]
...

【创作建议】
- 保留：[从爆款保留什么]
- 改进：[可以怎么改进]
- 创新：[可以加入什么新元素]
```

## 差异化策略

### 策略1: 同主题，不同角度

```
爆款主题: 职场崩溃
爆款角度: 夸张搞笑

差异化角度:
- 感人角度: 崩溃后的温暖瞬间
- 干货角度: 如何应对职场崩溃
- 悬念角度: 崩溃背后的真相
```

### 策略2: 同角度，不同风格

```
爆款角度: 职场新人吐槽
爆款风格: 搞笑夸张

差异化风格:
- 真实风格: 真实记录，不过度表演
- 温暖风格: 用温暖方式讲困境
- 悬疑风格: 用悬念方式讲故事
```

### 策略3: 同风格，不同人群

```
爆款风格: 搞笑吐槽
爆款人群: 互联网公司

差异化人群:
- 传统行业职场人
- 体制内工作人员
- 自由职业者
```

### 策略4: 同人群，不同深度

```
爆款: 浅层吐槽，引发共鸣
差异化: 深层分析，给出解决方案

爆款: 讲现象
差异化: 讲原因和解决办法
```

## 常见爆款模式

### 模式1: 反转类

**结构：** 正常发展 → 意外反转

**关键：** 反转要出人意料但合乎逻辑

**差异化：**
- 反转的方向不同
- 反转的次数不同（多重反转）
- 反转的情感不同（搞笑/感人/悬念）

### 模式2: 共鸣类

**结构：** 描述痛点 → 引发共鸣

**关键：** 痛点要真实，说出大家心里话

**差异化：**
- 痛点的细分人群不同
- 痛点的呈现方式不同
- 痛点的解决方向不同

### 模式3: 干货类

**结构：** 问题 → 分析 → 解决方案

**关键：** 问题精准，方案可执行

**差异化：**
- 问题的角度不同
- 解决方案的独特性
- 讲解方式的不同（用案例/用数据/用故事）

### 模式4: 悬念类

**结构：** 设悬念 → 解谜 → 再反转

**关键：** 悬念要勾人，信息要留白

**差异化：**
- 悬念的类型不同（推理/情感/日常）
- 解谜的方式不同
- 反转的方向不同

## Examples

**Example 1: 分析职场类爆款**

```
爆款: "加班到崩溃的一天"
数据: 抖音100万赞

爆款元素:
- 主题: 职场加班
- 角度: 夸张表现崩溃
- 结构: 正常开始 → 层层加码 → 崩溃爆发
- 风格: 搞笑夸张
- 金句: "我不是在上班，我是在渡劫"
- 互动点: 大家都说"这就是我"

受众: 25-30岁职场新人，正在经历加班疲劳

可借鉴:
✓ 结构: 层层加码的节奏
✓ 金句风格: 自嘲式幽默
✓ 互动设计: 让观众代入

差异化建议:
方案1: 用温暖方式讲加班
- 差异点: 不夸张崩溃，而是讲加班中的温暖瞬间
- 优势: 避开搞笑赛道，差异化竞争

方案2: 给解决方案
- 差异点: 讲崩溃，也讲如何应对
- 优势: 既有共鸣，又有价值
```

**Example 2: 分析知识类爆款**

```
爆款: "拖延症的3个原因"
数据: B站50万播放

爆款元素:
- 主题: 拖延症
- 角度: 心理学角度分析
- 结构: 问题 → 原因 → 解决
- 风格: 专业但易懂
- 金句: "拖延不是懒，是恐惧"
- 互动点: "你中了几条？"

受众: 有拖延问题但不知道为什么的人

可借鉴:
✓ 结构: 问题-原因-解决方案
✓ 金句: 一句话概括核心观点
✓ 互动: 让观众自我对照

差异化建议:
方案1: 从案例切入
- 差异点: 不直接讲理论，先讲真实案例
- 优势: 更有代入感

方案2: 给出可执行工具
- 差异点: 不只讲为什么，更讲怎么做
- 优势: 实用性更强
```

## 使用流程

### Step 1: 收集爆款信息

用户提供：
- 爆款链接/描述
- 或说明想做什么类型，我推荐爆款参考

### Step 2: 拆解爆款元素

分析爆款的6个元素

### Step 3: 找差异化方向

基于爆款，提出3个差异化方案

### Step 4: 给出创作建议

保留什么、改进什么、创新什么

## 质量标准

- **拆解准确**: 找到爆款真正的成功元素
- **差异化可行**: 差异化方向实际可执行
- **建议具体**: 不只是"要不同"，而是"怎么不同"
- **避免抄袭**: 明确说明不能照搬什么
