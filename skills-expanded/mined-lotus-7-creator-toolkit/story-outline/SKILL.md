# Story Outline (故事大纲生成)

## Overview

将用户选择的创作角度展开为完整的故事大纲，根据内容类型适配相应的叙事结构。

## 输入处理

### 必需输入
- **创作角度**: 主题 + 切入点 + 亮点
- **内容类型**: short-video / medium-video / story / knowledge / vlog
- **风格偏好**: funny / touching / suspense / educational / real
- **时长限制**: 15-60s / 1-3min / 3-10min

### 分析步骤

1. **确认结构**: 根据内容类型选择对应结构模板
2. **填充内容**: 将角度内容填充到结构中
3. **适配风格**: 根据风格偏好调整叙事方式
4. **时长匹配**: 确保内容量符合时长限制

## 输出格式

```
=== 故事大纲 ===

【基本信息】
主题：[主题]
类型：[类型]
风格：[风格]
时长：[时长]

【故事结构】
[根据类型展示对应结构]

【详细大纲】

一、开场 ([时长])
- 场景：[在哪里]
- 人物：[谁]
- 发生了什么：[事件描述]
- 情绪：[什么情绪]
- 目的：[这个部分要达成什么]

二、发展 ([时长])
- 场景：[在哪里]
- 事件展开：[发生了什么]
- 冲突/转折：[有什么变化]
- 情绪变化：[从什么情绪到什么情绪]

三、高潮 ([时长])
- 爆发点：[情感/剧情顶点]
- 如何呈现：[用什么方式表达]
- 预期反应：[观众应该有什么反应]

四、结尾 ([时长])
- 收尾方式：[如何结束]
- 核心信息：[传达什么]
- 记忆点：[让观众记住什么]

【关键元素】
- 人物设定：[角色特点]
- 场景规划：[需要哪些场景]
- 道具/素材：[需要准备什么]
- 音乐建议：[什么风格的BGM]

【金句/台词】
[列出3-5个关键台词]
```

## 结构模板

### short-video (短视频 15-60秒)

```
开头 (3-5秒)
├── 目的：抓注意力
├── 方式：视觉冲击/悬念/金句
└── 输出：让观众好奇"什么情况"

发展 (20-40秒)
├── 情节1 (10-15秒)
│   └── 快速推进
├── 情节2 (10-15秒)
│   └── 层层递进
└── 节奏：快，2-3秒一个镜头

结尾 (5-10秒)
├── 目的：反转/金句/行动号召
├── 方式：意外反转/情绪爆发/点题
└── 输出：让观众记住/转发
```

### medium-video (中视频 1-3分钟)

```
开场 (10-20秒)
├── 引入方式：抛出问题/设定场景/制造悬念
└── 目的：让观众想继续看

发展 (30-60秒)
├── 铺垫：背景/情境介绍
├── 展开：情节递进/信息呈现
└── 情绪：开始积累情感

高潮 (20-30秒)
├── 爆发点：情感顶点/核心观点输出
├── 呈现：特写/音乐/台词配合
└── 目的：让观众有强烈反应

结尾 (10-20秒)
├── 收尾：升华/反转/行动号召
├── 金句：总结核心信息
└── 目的：留下余韵
```

### story (剧情类 3-10分钟)

```
开端 (30-60秒)
├── 设定：人物介绍、场景建立、初始状态
├── 钩子：让观众关心角色
└── 目的：建立代入感

发展 (60-180秒)
├── 冲突1 (30-60秒)
│   └── 遇到什么障碍
├── 冲突2 (30-60秒)
│   └── 尝试但失败
├── 冲突3 (30-60秒)
│   └── 转折点出现
└── 人物弧光：角色在过程中发生变化

高潮 (60-120秒)
├── 爆发点：情感/剧情最高点
├── 关键选择：角色做出重要决定
├── 呈现：多角度、多层次展现
└── 目的：情感共鸣

结局 (30-60秒)
├── 新状态：角色变化后的样子
├── 感悟：经历了什么，学到了什么
└── 开放性：留思考空间
```

### knowledge (知识类 1-5分钟)

```
引入 (10-20秒)
├── 痛点："你有没有遇到过..."
├── 问题：抛出要解决的核心问题
└── 目的：让观众觉得"这就是在说我"

观点 (20-60秒)
├── 核心观点：一句话概括
├── 是什么：解释概念（用类比）
├── 为什么：重要原因（1-2个）
└── 目的：让观众理解核心观点

证明 (30-120秒)
├── 案例1 (20-40秒)
│   └── 具体例子/演示
├── 数据/证据 (10-20秒)
│   └── 增强说服力
├── 案例2 (可选)
│   └── 另一个角度的例子
└── 目的：让观众相信观点

总结 (15-30秒)
├── 回顾：记住这几点
├── 行动：具体建议/可执行步骤
└── 目的：让观众能落地执行
```

### vlog (生活记录 1-3分钟)

```
引入 (10-15秒)
├日常：今天要做什么
├ 期待/心情：什么状态
└── 目的：让观众一起经历

过程 (60-120秒)
├── 真实记录：发生了什么
├── 意外：计划外的插曲（增加真实感）
├── 细节：有意思的小瞬间
├── 互动：和镜头/观众的对话
└── 目的：让观众有代入感

感悟 (20-30秒)
├── 真实感受：这件事让我想到什么
├── 不说教：不要升华过度
└── 目的：真诚分享
```

## 风格适配

### funny (搞笑)
- 开头：视觉冲击/荒谬设定
- 发展：夸张推进，层层加码
- 高潮：最荒谬的时刻
- 结尾：反转/自嘲/金句

### touching (感人)
- 开头：日常场景，建立代入感
- 发展：细节积累，情感慢慢升温
- 高潮：情感爆发点，配合音乐
- 结尾：温暖余韵，金句收尾

### suspense (悬念)
- 开头：悬念，让观众好奇
- 发展：线索展开，层层剥茧
- 高潮：第一层真相 → 被推翻
- 结尾：意想不到的最终答案

### educational (干货)
- 开头：痛点问题，引发共鸣
- 发展：观点+解释，逻辑清晰
- 高潮：核心观点输出
- 结尾：行动指南，可执行建议

### real (真实)
- 开头：日常，"今天要..."
- 发展：真实记录，保留意外
- 高潮：真实情感流露
- 结尾：真实感悟，不过度升华

## Examples

**Example 1: 短视频 + 搞笑**
```
输入：
- 主题：加班遇到倒霉事
- 类型：short-video
- 风格：funny
- 时长：30s

输出：
一、开场 (3秒)
- 场景：办公室，深夜
- 画面：主角看手机时间 22:00，准备下班
- 台词：终于可以下班了！

二、发展 (20秒)
- 情节1：到电梯口，看指示灯坏了
- 情节2：爬楼梯，5楼还OK，10楼开始喘
- 情节3：15楼腿软，看到18楼牌子崩溃

三、结尾 (7秒)
- 反转：终于爬到18楼，发现门没锁，可以用
- 金句：所以我为什么要爬楼...
```

**Example 2: 知识类 + 干货**
```
输入：
- 主题：拖延症的3个原因和解决办法
- 类型：knowledge
- 风格：educational
- 时长：3min

输出：
一、引入 (15秒)
- 痛点：你是不是也这样？明知道要做，就是拖着不做
- 问题：为什么会拖延？

二、观点 (45秒)
- 核心观点：拖延不是懒，是情绪问题
- 解释：用"吃饭"类比，不是不知道要吃，是不想吃
- 原因：害怕失败、完美主义、任务模糊

三、证明 (90秒)
- 案例1：害怕失败 - 因为怕做不好，所以不做
- 案例2：完美主义 - 要么做到最好，要么不做
- 案例3：任务模糊 - 不知道从哪开始

四、总结 (30秒)
- 记住这3点：降低期待、拆解任务、5分钟启动法
- 行动：现在就去做那件你拖着的事
```

## 质量标准

- 结构完整：开场-发展-高潮-结尾四段清晰
- 逻辑连贯：各部分之间有因果/递进关系
- 情感曲线：有明显的情绪起伏
- 时长匹配：内容量符合时长限制
- 风格一致：从头到尾保持同一风格
- 记忆点：至少1个可传播的金句/画面
