# Idea Decompose (创作想法拆解)

## Overview

从用户的碎片化输入中提取结构化创作要素，输出多个可执行的创作角度。

## 输入处理

### 输入类型
- 用户的一句话/一段话描述
- 新闻/话题/热点链接
- 生活碎片记录
- 模糊的创作念头

### 提取维度
分析以下维度并输出：

1. **创作角度** (3-5个)
   - 每个角度包含：主题、切入点、亮点
   - 角度之间要差异化，覆盖不同情感/风格

2. **核心主题识别**
   - 这件事的核心是什么？
   - 能引发什么共鸣？

3. **内容类型识别**
   - 根据：时长需求、叙事复杂度、情感深度
   - 输出：short-video / medium-video / story / knowledge / vlog

4. **关键元素提取**
   - 人物：有哪些角色？
   - 场景：在哪里发生？
   - 情感基调：什么情绪？搞笑/感动/悬念/干货/真实
   - 可用素材：真实经历/数据/案例

## 输出格式

```
=== 创作想法拆解 ===

原始输入：[用户输入]

【核心主题】
一句话概括这件事的核心

【内容类型识别】
推荐类型：[类型]
理由：[为什么适合这个类型]

【创作角度】（3-5个）

角度1：[标题]
- 主题：[核心主题]
- 切入点：[从什么角度切入]
- 亮点：[有什么独特之处]
- 风格：[funny/touching/suspense/educational/real]
- 推荐时长：[15-60s / 1-3min / 3-10min]

角度2：[标题]
...

【关键元素】
- 人物：[列出相关角色]
- 场景：[可用场景]
- 情感基调：[什么情绪]
- 可用素材：[真实经历/数据/案例等]

【下一步建议】
推荐选择角度[编号]，因为：[理由]
```

## 分析框架

### 创作角度生成方法

**1. 情感角度法**
同一件事，从不同情感切入：
- 搞笑：夸张/反转/自嘲
- 感人：细节/温暖/共鸣
- 悬念：隐藏/反转/意外

**2. 视角切换法**
- 第一人称：我经历了什么
- 第三人称：旁观者叙述
- 反向视角：对手/配角的角度

**3. 时间线法**
- 事前：预期和准备
- 事中：过程和意外
- 事后：反思和收获

**4. 对比法**
- 预期 vs 实际
- 表面 vs 内心
- 过去 vs 现在

### 内容类型识别规则

| 特征 | short-video | medium-video | story | knowledge | vlog |
|------|-------------|--------------|-------|-----------|------|
| 时长需求 | 15-60秒 | 1-3分钟 | 3-10分钟 | 1-5分钟 | 1-3分钟 |
| 叙事复杂度 | 单场景/快节奏 | 起承转合 | 人物弧光/多冲突 | 问题-观点-证明 | 真实记录 |
| 情感深度 | 反转刺激 | 情感曲线 | 深度情感 | 信息价值 | 真实感 |
| 典型场景 | 日常小趣味 | 生活感悟 | 完整故事 | 知识分享 | 生活记录 |

## Examples

**Example 1: 日常碎片**
```
输入: "今天加班到10点，电梯坏了爬了18层楼"

角度1: 搞笑反转
- 主题: 加班遇上倒霉事
- 切入点: 用夸张表现崩溃，结尾反转发现楼没坏
- 风格: funny
- 时长: 30s

角度2: 职场共鸣
- 主题: 打工人的崩溃瞬间
- 切入点: 真实记录，引发共鸣
- 风格: real
- 时长: 1min

角度3: 励志反转
- 主题: 爬楼也是一种锻炼
- 切入点: 从抱怨到自我激励
- 风格: touching
- 时长: 1min
```

**Example 2: 话题热点**
```
输入: "AI会不会取代人类工作"

角度1: 知识科普
- 主题: AI能做什么，不能做什么
- 切入点: 用具体案例对比AI和人类
- 风格: educational
- 时长: 3min

角度2: 剧情想象
- 主题: AI当老板的一天
- 切入点: 用夸张表现AI的逻辑
- 风格: funny
- 时长: 1min

角度3: 深度思考
- 主题: 人类真正的价值是什么
- 切入点: 从AI局限讲到人类独特性
- 风格: touching
- 时长: 2min
```

**Example 3: 模糊念头**
```
输入: "想做一个关于拖延症的视频"

角度1: 干货科普
- 主题: 拖延症的3个原因和解决办法
- 切入点: 问题引入+方法输出
- 风格: educational
- 时长: 2min

角度2: 搞笑共鸣
- 主题: 拖延症患者的真实一天
- 切入点: 用夸张表现拖延过程
- 风格: funny
- 时长: 1min

角度3: 悬念反转
- 主题: 我终于战胜了拖延症...吗？
- 切入点: 以为战胜了，实际没有
- 风格: suspense
- 时长: 1min
```

## 质量标准

- 每个角度必须：主题明确、切入点清晰、有亮点
- 角度之间要差异化，避免重复
- 内容类型识别要有依据
- 关键元素提取要准确
- 下一步建议要给出明确理由
