# Creator Workflow

## Overview

内容创作工作流主入口，协调 4 个核心技能按顺序执行，将用户的碎片化想法转化为专业的视频脚本分镜表。

## Quick Start

```
用户输入碎片想法 → 选择模式 → 配置参数 → 执行流程 → 输出分镜表
```

**基本用法：**
- "帮我做一个关于[主题]的视频脚本"
- "把这个想法变成脚本：[碎片内容]"
- "创作一个短视频，关于..."

**带参数用法：**
- "用自动模式做一个1分钟的搞笑短视频"
- "步骤确认模式，做一个3分钟的知识类视频"

## Execution Modes

### Auto Mode (全自动模式)

执行流程：idea-decompose → story-outline → script-writing → visual-prompts → 输出 xlsx

每个技能自动执行，不等待用户确认，直接输出最终分镜表。

**触发方式：**
- 默认模式（用户未指定时）
- 用户明确说"自动模式"、"全自动"、"一键生成"

**适用场景：**
- 用户已想清楚，需要快速产出
- 重复性批量创作
- 时间紧迫的场景

### Interactive Mode (步骤确认模式)

执行流程：skill 执行 → 展示结果 → 等待用户确认/修改 → 下一技能

每个技能执行完成后，展示中间结果，等待用户确认或修改后再继续。

**触发方式：**
- 用户明确说"步骤确认"、"交互模式"、"一步一步来"
- 用户说"先看看结果"、"让我确认一下"

**适用场景：**
- 探索性创作，用户需要在过程中调整方向
- 重要内容，需要严格把控质量
- 用户不确定，需要逐步引导

## Configuration Parameters

### 内容类型 (Content Type)

| 类型 | 说明 | 典型时长 | 结构特点 |
|------|------|----------|----------|
| `short-video` | 短视频 | 15-60秒 | 强开头、快节奏、单场景、强反转 |
| `medium-video` | 中视频 | 1-3分钟 | 起承转合、2-3个场景、情感曲线 |
| `story` | 剧情类 | 3-10分钟 | 人物弧光、冲突升级、完整叙事 |
| `knowledge` | 知识类 | 1-5分钟 | 问题引入、核心观点、案例、总结 |
| `vlog` | 生活记录 | 1-3分钟 | 真实感、共鸣点、个人视角 |

**设置方式：**
1. 自动识别：idea-decompose 技能分析后自动识别
2. 用户指定：用户明确说"做一个短视频"、"知识科普类"
3. 参数指定：`--type short-video`

### 时长限制 (Duration)

| 参数 | 说明 |
|------|------|
| `15-60s` | 短视频时长 |
| `1-3min` | 中视频时长 |
| `3-10min` | 长视频时长 |

**设置方式：**
- 用户直接说："做一个30秒的视频"、"1分钟左右"
- 参数指定：`--duration 30s`、`--duration 1min`

### 风格偏好 (Style)

| 风格 | 说明 | 情感基调 |
|------|------|----------|
| `funny` | 搞笑幽默 | 轻松、有趣、反转 |
| `touching` | 感人走心 | 温暖、共鸣、泪点 |
| `suspense` | 悬念反转 | 紧张、好奇、意外 |
| `educational` | 干货科普 | 专业、清晰、实用 |
| `real` | 真实生活 | 自然、接地气、vlog感 |

**设置方式：**
- 用户直接说："搞笑的"、"感人的"、"干货向"
- 参数指定：`--style funny`

## Workflow Execution

### Step 1: Idea Decompose (创作想法拆解)

调用 `idea-decompose` 技能。

**输入：** 用户碎片想法 + 配置参数

**输出：**
- 3-5 个创作角度（每个角度包含：主题、切入点、亮点）
- 核心主题识别
- 内容类型识别
- 关键元素提取（人物、场景、情感基调）

**Interactive Mode 处理：**
展示各角度，让用户选择一个继续，或要求修改。

### Step 2: Story Outline (故事大纲生成)

调用 `story-outline` 技能。

**输入：** 用户选择的角度 + 内容类型

**输出：**
- 完整故事大纲
- 根据内容类型适配的结构
- 包含：开场、发展、高潮、结尾

**Interactive Mode 处理：**
展示大纲，让用户确认或要求调整。

### Step 3: Script Writing (视频脚本生成)

调用 `script-writing` 技能。

**输入：** 故事大纲 + 内容类型 + 时长限制

**输出：**
- 分镜脚本（按镜头拆分）
- 每个镜头包含：镜号、景别、画面描述、台词/旁白、时长、音效/配乐

**Interactive Mode 处理：**
展示脚本预览，让用户确认或要求修改。

### Step 4: Visual Prompts (画面提示词生成)

调用 `visual-prompts` 技能。

**输入：** 分镜脚本

**输出：**
- 每个画面的 AI 生图提示词
- 包含：风格、构图、光影、细节描述

**Interactive Mode 处理：**
展示提示词，让用户确认。

### Step 5: Export Output (导出输出)

调用 `xlsx` 技能生成分镜表。

**输出格式：** xlsx 专业脚本分镜表

表格列：镜号 | 景别 | 画面描述 | 台词/旁白 | 时长 | 音效/配乐 | AI生图提示词

## Optional Skills

以下技能为可选增强功能，用户可按需调用：

- **positioning-check**: 定位校验（目标受众、核心信息、情感反应）
- **trend-analysis**: 竞品/爆款分析（找差异化点）
- **multi-version-gen**: 多版本生成（同一大纲生成3个风格版本）
- **export-formats**: 导出其他格式（pptx、看板等）

## Examples

**Example 1: 全自动短视频创作**
```
用户: "帮我做一个30秒的搞笑短视频，主题是加班"
执行: 自动模式 → idea-decompose → story-outline → script-writing → visual-prompts → 输出 xlsx
```

**Example 2: 交互式中视频创作**
```
用户: "想做一个关于健身的知识类视频，2分钟左右，一步一步来"
执行:
1. idea-decompose → 展示3个角度
2. 用户选择角度
3. story-outline → 展示大纲
4. 用户确认
5. script-writing → 展示脚本
6. 用户确认
7. visual-prompts → 展示提示词
8. 用户确认
9. 输出 xlsx
```

**Example 3: 参数化创作**
```
用户: "做一个剧情类视频，5分钟，感人风格，主题是父爱"
执行: 自动模式 → 按剧情类模板+感人风格 → 输出 xlsx
```
