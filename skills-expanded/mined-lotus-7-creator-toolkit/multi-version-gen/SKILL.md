# Multi-Version Gen (多版本生成)

## Overview

基于同一个故事大纲，生成3个不同风格的脚本版本，帮助用户找到最佳呈现方式。

## 风格变体

### 变体1: 原始风格

**特点：** 按原大纲设定的风格生成

**用途：** 作为基准版本，对比其他变体

### 变体2: 反向风格

**特点：** 与原风格相反

| 原风格 | 反向风格 |
|--------|----------|
| funny | touching |
| touching | funny |
| suspense | real |
| educational | funny |
| real | suspense |

**用途：** 探索完全不同的呈现方式

### 变体3: 混合风格

**特点：** 主风格 + 次风格组合

**常见组合：**
- `funny + touching`: 搞笑但走心
- `suspense + funny`: 悬疑但轻松
- `educational + real`: 干货但真实
- `touching + real`: 感人且真实

**用途：** 丰富内容层次

## 输出格式

```
=== 多版本脚本生成 ===

【原始大纲】
主题：[主题]
原风格：[风格]

【版本1：原风格版本】
风格：[原风格]
特点：[风格特点]

脚本预览：
[展示关键镜头]

---

【版本2：反向风格版本】
风格：[反向风格]
特点：[风格特点]

脚本预览：
[展示关键镜头]

与版本1的差异：
[主要差异点]

---

【版本3：混合风格版本】
风格：[主风格] + [次风格]
特点：[混合特点]

脚本预览：
[展示关键镜头]

与前两个版本的区别：
[主要区别]

【推荐建议】
- 最推荐：版本[X]，因为：[理由]
- 特定场景：版本[X]适合[场景]，因为：[理由]
- 风险提示：版本[X]可能[风险]，因为：[理由]
```

## 风格转换规则

### funny → touching

**转换要点：**
- 节奏：从快到慢
- 表情：从夸张到克制
- 台词：从金句到真诚表达
- 音乐：从轻快到温暖

**示例：**
```
原版(funny):
主角爬楼梯满头大汗，夸张说"我要死了"

改编(touching):
主角爬楼梯，停下来喘气，打电话给家人说"快到了"
```

### touching → funny

**转换要点：**
- 用自嘲替代煽情
- 用反转替代直白
- 用夸张替代克制

**示例：**
```
原版(touching):
父子看日落，温暖时刻

改编(funny):
父子看日落，爸爸感慨"好美啊"，儿子说"爸，你踩到狗屎了"
```

### suspense → real

**转换要点：**
- 去掉夸张的悬念设置
- 用真实细节替代戏剧化
- 用日常感替代紧张感

**示例：**
```
原版(suspense):
半夜听到声音，紧张地开门，发现...

改编(real):
半夜听到声音，开门看了看，是快递
```

### educational → funny

**转换要点：**
- 用搞笑案例替代严肃案例
- 用自嘲替代说教
- 用夸张表达替代平铺直叙

**示例：**
```
原版(educational):
"拖延症有3个原因，第一..."

改编(funny):
"我来说说拖延症，作为拖延症晚期患者，我太有发言权了"
```

## Examples

**Example 1: 职场加班主题**

```
原始大纲:
主题: 加班到崩溃
原风格: funny

版本1 (原风格 - funny):
特点: 夸张表现，快速剪辑
- 主角爬楼梯夸张崩溃
- 电梯坏了的倒霉
- 结尾反转发现门没锁
- 预期: 高互动，高转发

版本2 (反向 - touching):
特点: 克制表达，慢节奏
- 主角爬楼梯，给家人打电话报平安
- 楼梯间遇到同样加班的人，点头示意
- 结尾到家，家人留的灯还亮着
- 预期: 中等互动，深度共鸣

版本3 (混合 - funny + touching):
特点: 前半搞笑，后半走心
- 前半夸张表现崩溃
- 中间收到家人信息
- 后半继续但心态变化
- 结尾温暖收尾
- 预期: 高互动，深度共鸣

推荐: 版本3，既有笑点又有泪点，层次更丰富
```

**Example 2: 拖延症主题**

```
原始大纲:
主题: 拖延症的原因和解决办法
原风格: educational

版本1 (原风格 - educational):
特点: 专业讲解，逻辑清晰
- 问题引入 → 原因分析 → 解决方案
- 用数据和心理学理论支撑
- 预期: 收藏率高，实用性强

版本2 (反向 - funny):
特点: 自嘲式幽默
- 用自己的拖延经历讲故事
- 夸张表现拖延过程
- 解决方案用搞笑方式呈现
- 预期: 高互动，高转发

版本3 (混合 - educational + real):
特点: 干货 + 真实案例
- 先讲自己的真实拖延经历
- 再分析原因和解决方案
- 案例真实，方法可执行
- 预期: 高互动，高收藏

推荐: 版本3，真实经历增加可信度，方法可执行增加实用性
```

## 选择建议

### 什么时候用原风格版本？
- 目标明确，风格确定
- 有明确的受众偏好
- 需要保持账号风格一致

### 什么时候用反向风格版本？
- 想尝试突破
- 原风格效果不好
- 想测试新方向

### 什么时候用混合风格版本？
- 想要内容更丰富
- 受众口味多元
- 想要兼顾传播和深度

## 质量标准

- **风格清晰**: 每个版本有明确风格特点
- **差异明显**: 三个版本有明显区别
- **保持核心**: 所有版本基于同一大纲核心
- **推荐合理**: 推荐建议有依据
