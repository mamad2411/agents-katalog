# design-pdf

做可阅读、可打印、可归档、可追溯的正式 PDF 报告。

载体默认是 A4 浅色版面(HTML + print CSS 生成,最终交付 PDF;若用户要 `.pptx`/网页,转对应 skill)。正式报告走浅色实色,不是暗色屏显风格。

先看 `example/example.html` 的质量水准再开始。它是"规范到什么程度"的标尺,**不是模板**:具体版式和配色按本报告类型与场景自己定,别照抄内容。

## 工作流

1. **只定两件事**:纸张(默认 A4 纵向,宽表/财务明细可横向)和报告类型(决定章节骨架与密度)。受众、周期、密级、来源能从内容推断就推断,真有影响结构或可信度的关键缺口,最多问一个。
2. **先定全篇 token**(下方),一次定好全程不换。
3. 需要章节骨架时从 `references/structure-templates.md` 取对应模板,按用户真实内容增删,不机械凑章。
4. 逐页按下面硬规则排版。
5. 导出 PDF 后逐页自检 → 修问题 → 复查受影响页。

## 报告 Token(先定,后逐页做)

整篇报告共用一套,不要边做边换:

- **页面系统**:纸张方向、页边距、页眉页脚内容与位置、页码规则、目录层级。
- **标题层级**:最多 4 级,每级字号/粗细/编号/间距固定。
- **字体角色**:正文 sans 或 serif、数据 mono、必要的标题字体,最多 3 套。
- **颜色**:主文字、正文背景、1 个强调色、风险/负数色、合计行底色,角色分清。正式报告以浅色实色为主。
- **图表样式**:坐标、网格、配色、图注/来源格式,全篇统一。
- **表格样式**:表头、斑马纹、合计行、对齐规则统一。

## A4 页面系统(硬规则)

- **纸张**:默认 A4 纵向;宽表、财务明细、多列矩阵可用横向。同一份报告不频繁混向;若混向,页码连续。用分页思维设计,不用网页滚动长画布思维。
- **页边距**:正文页上下 18-24mm、左右 18-22mm;装订/归档版内侧再加 3-6mm。图表表格不触安全边距,页眉页脚不挤占正文。
- **页码**:封面可不显示;正文起连续编号,位置全篇固定。9 页以上要能靠页码定位章节;附录若单独编号,在目录说明。
- **页眉页脚**:页眉放报告简称、章节名或周期;页脚放页码、密级、版本或数据日期。文字短,不放长标题、口号、装饰文案。敏感及以上报告每页标密级或分发范围。
- **目录**:1-3 页不做;4-8 页可做简目录;9 页以上必须做;20 页以上目录含二级标题。导出后复核目录页码。
- **标题层级**:最多 4 级(章/主题/证据组/局部)。一级章节通常从新页起,标题不孤立在页底。
- **正文**:中文每行 28-42 字;不两端强拉;单段 2-5 行,超 6 行拆分。大段居中只用于封面或特殊声明。正文页要有真实密度,不放空话;封面/目录/章节页/声明页可低密度,但功能要明确。
- **字号**:正文 10.5-11.5pt、行距 1.45-1.6;一级标题 20-24pt、二级 15-18pt、三级 12-14pt;图注/表注/来源 8-9.5pt、页眉页脚 8-9pt;表格正文 8.5-10pt,低于 8pt 通常不可交付,应拆表、横排或转附录。

## 信息密度与垂直节奏

- 正文页填满版面但不堆满:密度均衡,不上半挤、下半留大块空白。
- 标题→正文、段间、图文间距全篇固定一致,不每页不同。
- 需要撑满高度时让图表、表格自然占位,不靠拉开行距或加装饰线凑高。
- 绝对定位的页眉页脚留出空间,正文不压上去也不被裁切。

## 图形优先于文字

**能用图形表达的就不堆文字。** 每块内容先问:能不能可视化?

- 数据、对比、趋势、构成、占比 → 图表。
- 流程、步骤、归因链、时间顺序 → 流程图、时间线。
- 结构、关系、层级、风险矩阵 → 结构图、矩阵。
- 单一关键结论 → 大数字 + 一句解读。
- 精确对比与归档 → 表格(不是装饰)。

图表/图形(柱线饼、流程、矩阵、KPI 数字、SVG 图标)**自己用代码生成**,可控且可文本化。
文字的角色是结论句 + 图表旁的精炼标注,不是信息主体。
反面:把可对比的数据写成整段句子、把流程写成一二三四行字、为配图而配无关装饰图。

## 渐变、暗色与质感:正式报告比 PPT 更克制

正式报告以**浅色实色**为主版面,渐变和暗色当点缀,不当默认风格。

**可以用(克制):**
- 封面/章节页可用同色系、低饱和的窄幅渐变条或色块定调性。
- 强调色、合计行底色、风险标记用低饱和实色。

**不要(AI 味或损可读性):**
- 暗色铺底正文页(屏显风格,打印发灰、费墨、不像正式报告)。
- 紫蓝/粉紫满屏渐变背景,任何报告长一样。
- 渐变盖到正文、表格、数字上,牺牲对比和打印可读性。
- 每章都套渐变标题条 + 大卡片 + 装饰分割线,造成模板报告感。

## 配图(分两类,用错就 AI 味)

**矢量/程序化**(图表、流程图、矩阵、色块、SVG 图标)→ **自己用代码生成**,这是报告配图主体。

**位图/照片类**(签章、实拍现场、产品照、扫描件)→ **用占位图,不要编造。**
- 放占位框,锁定比例尺寸,框内标注「该放什么:具体内容 + 比例」,可附一句生图 prompt 供替换。
- 占位框风格统一(浅灰底 + 居中说明 + 1px 边界),当成最终图来留白对齐。
- 标具体内容(如"北区门店现场照"),不是"科技感氛围图";不塞无关照片或渐变。

## 图表与表格(看得见的可信)

**图表:**
- 每张图有编号或稳定标题,标题写清对象、指标、时间范围。
- 图下必须有注释和来源;单位出现在轴标题、表头或图注里。
- 不只靠颜色表达差异,黑白打印后仍可区分。
- 柱状比较、折线趋势、散点关系、堆叠结构;饼图只用于少量类别占比,超 5 类改条形。
- 正文点明关键变化,不让读者自己猜图表结论。
- 图注格式(全篇统一):
  - `图 2-1:2026 年 5 月各渠道收入环比变化`
  - `注:收入为不含税金额,剔除退款订单。`
  - `来源:销售系统与财务系统,统计周期 2026-05-01 至 2026-05-31。`

**表格:**
- 表头带单位;数字列右对齐,文本列左对齐;同一指标小数位统一。
- 合计行、关键小计行、风险行有稳定样式,不与表体完全分离。
- 长表跨页必须重复表头;避免单行被分页切开;避免合计行或单行表体孤立到下一页。
- 表格标题、注释、来源不与表格分离到不同页。
- 宽表优先横向页、拆列或分组,不压缩到不可读。

**来源与口径:**
- 图表、表格、关键指标必须有来源,格式全篇统一。
- 人工填报标填报口径和更新时间;估算、假设、待复核必须明示。
- 财务数:币种、单位、四舍五入规则写明;负数/红字/括号表示法统一;合计、小计、差异可复算;未审计数据标注。

## Print / PDF 生成原则

最终交付是 PDF,不是 HTML 页面。

- 优先真实文本:正文、目录、表格、脚注可选择、复制、搜索。图片只用于照片、签章、复杂不可文本化图形;关键标题、页码、表格文字不能变成图片文字。
- 用 print CSS 分页思维:先定纸张、页边距、页眉页脚、分页,再做视觉细节。
- `break-before` 控制章节起页;`break-after: avoid` 防标题悬挂;`break-inside: avoid` 保护图表、表格行、引用块、关键卡片。
- 长表不整体 avoid,允许合理跨页并重复表头。
- 封面可视觉区分,但不破坏 A4 安全边距。
- 不依赖动效、悬停、滚动、折叠、交互说明;链接要有可读文本,不只写"点击这里"。
- 字体用可嵌入、跨平台稳定的字体;导出后查字体替换、缺字、错位、页码。

## 反 AI 味(命中即重做)

- 营销海报式封面:标题巨大、信息不足、空泛副标题(全面赋能高质量发展、数智赋能)。
- 空泛标题不写业务判断;标题应是对象 + 周期 + 主题。
- 摘要只写"整体向好、稳步推进、持续优化",不答发生了什么、为什么重要、下一步做什么。
- 无来源数字、无口径排名、无依据趋势;编造客户、案例、金额、增长率。
- 建议全是套话("持续优化""加强管理"),没有动作、责任方、优先级或时间窗口。
- 图表无标题、单位、注释、来源,只为好看;全彩装饰性图表。
- 每章相同大卡片 + 渐变标题 + 装饰分割线,造成模板报告感;每页不同颜色、卡片、阴影。
- 暗色铺底、品牌色或照片压过正文证据;网页式动效、滚动叙事。
- 把用户原始材料整段搬上页,不提炼;事实、解释、判断、建议混在一起不分层。
- 过度用"闭环、抓手、赋能、生态、矩阵、链路"等泛词。

缺数据时写明缺失项、标注假设、降级为结构占位,不生成伪造数据。

## 导出 QA(交付前必做,查最终 PDF 不只看源文件)

- **文本**:正文可选择/复制/搜索;表格不是整页截图;复制出的中文无大面积乱码;数字、单位、负号、百分号复制后正确。
- **目录页码**:目录页码与正文一致;标题编号不跳号;交叉引用能定位到正确章节/图/表;封面、目录、正文、附录编号规则清楚。
- **打印**:A4 打印不裁切;页眉页脚不被打印机边界裁掉;黑白打印图表仍可区分;细线、浅灰文字、浅色背景仍可读;装订边距足够。
- **分页**:无异常空白页;一级标题不落页底;图表标题与图表不分离;长表跨页重复表头;合计行和关键注释不孤立到下一页。
- **字体与文件**:字体已嵌入或替换不影响版面;中英文、数字、特殊符号无缺字;文件名含报告名、周期、版本或日期;PDF 属性标题/作者/主题符合交付场景;密级、版本、归档日期与正文一致。
- 文件命名示例:`经营分析报告_2026年05月_v1.0_内部.pdf`、`财务报告_2026Q2_v0.9_待审阅.pdf`、`审计整改跟踪报告_2026-06-09_v1.1_机密.pdf`。

发现问题先修再复查。第一轮没找到问题,就换更严格视角再查一遍。
