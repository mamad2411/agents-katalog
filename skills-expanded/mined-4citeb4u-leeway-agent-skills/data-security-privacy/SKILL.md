# LeeWay Data Security & Privacy
Classify data and purpose, minimize collection, govern access, encryption/tokenization, retention/deletion, backup/recovery and disclosure. Cryptographic protection does not replace authorization/privacy governance. Homomorphic/ZK techniques are specialized options, not universal requirements.
