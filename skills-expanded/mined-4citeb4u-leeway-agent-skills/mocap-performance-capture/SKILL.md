# LeeWay 3D Mocap & Performance Capture

Identify capture modality and skeleton/face schema; calibrate; solve/track; clean jitter/dropouts; preserve contacts; retarget to target rig; correct scale/orientation; validate timing and extreme motion. Captured motion is evidence, not automatically production-ready animation.
