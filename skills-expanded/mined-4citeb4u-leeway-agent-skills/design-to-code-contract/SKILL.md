# LeeWay Design-to-Code Contract
Define component anatomy/slots, variants, state machine, tokens, content constraints, events, accessibility semantics and responsive behavior independently of framework. Generate/validate React/SwiftUI/Flutter/etc. implementations against the contract; generated code != verified parity.
