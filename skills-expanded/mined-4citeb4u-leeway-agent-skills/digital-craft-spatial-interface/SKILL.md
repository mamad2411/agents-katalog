# LeeWay Skill House — Digital Craft & Spatial Interface

## Mission
Design and execute high-fidelity, accessible, responsive and performant digital interfaces from tokens through GPU runtime.

## Core departments
DESIGN SYSTEMS & VISUAL ARCHITECTURE; MOTION/SPATIAL DYNAMICS; INTERACTION/STATE ENGINEERING; CREATIVE GRAPHICS ENGINEERING; ACCESSIBILITY; PERFORMANCE/HARDWARE; QA/REGRESSION.

## Standards law
Normative accessibility requirements outrank experimental metrics. Project elite targets may exceed standards but must be labeled as project profiles. Browser/GPU features require capability detection and fallback.

## Anti-silo law
Visual beauty, motion, accessibility and runtime performance are one product state. No shader/motion effect may silently break interaction, readability, focus, reduced-motion preferences, memory, thermal budget or low-end device support.
