# LeeWay 3D Lighting & Render Validation

## Two-stage lighting

First use diagnostic neutral lighting/HDRI or controlled key-fill-rim to expose geometry/material defects. Then apply final art-direction lighting.

## Camera validation

Inspect hero, close, grazing-angle, silhouette and representative gameplay distances. Include problem surfaces/seams.

## Evidence

Before/after renders, camera/lens, lighting environment, render settings, artifact hashes where available. Attractive render != verified geometry.
