# LeeWay Authorized Voice Profile

## Model
Represent voice as editable traits rather than an opaque imitation: vocabulary/register, sentence-length distribution, syntax tendencies, paragraph rhythm, rhetorical devices, directness, humor, figurative language, sensory density, dialogue habits, certainty/hedging, transitions, punctuation habits, emotional modulation and explicit do/don't rules.

## Evidence
Bind each strong trait to interview responses or author-provided writing samples when possible. Distinguish OBSERVED, SELF_REPORTED, INFERRED and AUTHOR_APPROVED.

## Use
Generate drafts that satisfy the profile while remaining responsive to medium/genre. Author approval overrides inferred profile traits.

## Living-writer boundary
For an unconsenting living writer, do not construct a high-fidelity imitation profile intended to pass as that person. Analyze broad craft characteristics and create an original voice instead.
