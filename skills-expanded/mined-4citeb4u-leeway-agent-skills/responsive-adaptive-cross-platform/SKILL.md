# LeeWay Responsive Adaptive Cross-Platform
Preserve component semantics/state/accessibility while adapting interaction, layout, density, navigation and platform idioms. Cross-platform synthesis means shared contracts with platform-appropriate rendering—not forced pixel identity between React, SwiftUI, Flutter or other runtimes.
