# LeeWay 3D Department

## Mission

Turn Creator intent and existing/reference assets into verified 3D deliverables. The LLM owns planning/orchestration; domain skills own craft procedures; providers execute bounded operations.

## Production loop

INGEST → SCENE/ASSET AUDIT → REFERENCE/MEASUREMENT → TARGET STYLE/PLATFORM → GEOMETRY PLAN → MATERIAL/UV PLAN → PARALLEL PRODUCTION LANES → INTEGRATION → PERFORMANCE/QUALITY VALIDATION → VISUAL REVIEW → REPAIR → EXPORT → VERITAS → RECEIPT.

## Department lanes

Geometry/blueprint; reconstruction; topology/retopo; UV/material/texture; lighting/lookdev; rig/animation when needed; collision/gameplay; LOD/performance; environment/scene assembly; QA/visual verification.

## Anti-silo law

A request such as 'improve the skin/wrapping' triggers geometry inspection + UV + PBR material + texture resolution/texel density + normal/tangent validation + lighting + performance + before/after verification. Do not reduce it to 'set a material'.

## Existing-scene law

Before mutation inventory objects, collections, transforms, dimensions, materials, textures, UV maps, modifiers, armatures, lights, cameras, collision, LODs, polycounts and external dependencies. Preserve approved geometry/identity unless the requested repair requires change.

## Style targets

Style labels such as Roblox-like, stylized AAA, realistic open-world, claymation, low-poly, cinematic or mobile are art-direction envelopes, not copyrighted asset-copy instructions. Translate them into measurable geometry/material/lighting/performance characteristics.

## Provider routing

TripoSR seeds image-derived geometry. 3D Engineering Blueprint owns dimensional intent. Blender/CAD/geometry providers perform bounded edits. Creative Rendering owns lookdev physics/color/frame budget. Game Asset Production owns engine-ready constraints.

## Completion

A 3D asset is not complete because it renders. Verify intended shape, scale, materials, UVs, texture integrity, topology, normals/tangents, performance budget, collision/LODs when required, export integrity and visible result.
