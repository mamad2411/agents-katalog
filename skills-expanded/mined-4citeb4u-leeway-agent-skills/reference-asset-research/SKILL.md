# LeeWay 3D Reference & Asset Research

Gather references by purpose: shape/proportion, dimensions, materials, construction, lighting, environment, motion and style. Separate verified measurements from visual inference. Track provenance/licensing for reusable external assets/textures. Build reference boards/data packages that downstream skills can cite rather than repeatedly guessing.
