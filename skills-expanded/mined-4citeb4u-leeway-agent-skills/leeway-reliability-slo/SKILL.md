# LeeWay Reliability SLO

Choose user-centered SLIs with precise numerator, denominator, exclusions, source, and window. Set justified objectives and error-budget policy. Connect alerts to actionable burn rates, ownership, and runbooks. Report missing telemetry as `UNMEASURABLE`, not healthy, and separate availability from correctness and durability.
