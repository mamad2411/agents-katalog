# LeeWay Action & Stunt Choreography
Design action for geography, cause/effect, rhythm, character objective and editorial legibility. Physical stunt execution requires qualified human safety professionals; the skill may plan fictional/virtual choreography but must not substitute for real-world stunt coordination/safety authority.
