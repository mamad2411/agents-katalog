# LeeWay SOC & Detection Engineering
Start from threat hypotheses/assets/trust boundaries; collect fit-for-purpose endpoint, identity, network, cloud and application telemetry. Map detections to ATT&CK techniques where useful. Track coverage, precision/false positives, data quality and detection latency. ATT&CK mapping is taxonomy/context, not proof of actor attribution.
