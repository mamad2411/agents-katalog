# LeeWay Character Psychology
Define conscious objective, underlying need, fear/wound, values, contradictions, tactics, relationships, secrets, competencies and pressure responses. Track positive, flat, negative and mixed arcs. Conflict can arise from goals, information, status, ethics, resources or temperament; ideological distance is useful but identical beliefs do not automatically make dialogue dramatically dead.
