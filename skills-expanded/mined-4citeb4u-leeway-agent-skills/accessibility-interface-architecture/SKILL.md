# LeeWay Accessibility Interface Architecture
Use current normative WCAG requirements as the conformance baseline; WCAG 3 drafts and APCA may inform enhanced profiles but do not replace normative requirements. Validate semantic structure/accessibility tree, names/roles/states, focus order/traps/restoration, keyboard/pointer/touch, contrast, reduced motion, zoom/reflow and dynamic announcements.
