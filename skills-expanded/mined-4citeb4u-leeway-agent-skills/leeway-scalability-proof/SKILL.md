# LeeWay Scalability Proof

State workload shape, concurrency, data size, locality, latency objective, throughput objective, resource ceiling, and failure assumptions. Test representative paths and report percentiles, errors, saturation, recovery, and cost. Extrapolation is a forecast, not proof; label untested ranges and confidence.
