# LeeWay WebGPU Shader Runtime
Build render/compute pipelines with explicit resource lifetime, buffers/bind groups, texture formats, synchronization and measured frame cost. WGSL is the WebGPU shading language; WebGPU/WGSL remain evolving W3C Candidate Recommendation work in 2026, so feature/platform qualification is mandatory. Eikonal |grad f|=1 is a true-SDF property where applicable, not a universal shader gate.
