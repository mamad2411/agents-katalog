# LeeWay Author Revision Behavior

A finished sample hides the process that produced it. Compare drafts, edits and author feedback to model revision operations: compression/expansion, ordering, specificity, emotional intensity, exposition, humor, word replacement, sentence restructuring, continuity correction and protected phrases/ideas.

Use this model after first-draft generation so collaborative writing imitates the author's editing logic rather than only surface style.
