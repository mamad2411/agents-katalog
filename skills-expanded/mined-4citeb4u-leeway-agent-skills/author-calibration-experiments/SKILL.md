# LeeWay Author Calibration Experiments

Use matched prompts so differences are interpretable. Examples: tell the same event to a friend vs employer; describe one event calmly vs while frustrated; explain a technical idea to novice vs expert; write first draft then revise it; choose between alternate phrasings and explain why.

Do not manipulate distress. Emotional prompts may use hypothetical or comfortable scenarios. Record prompt, context, response, author explanation and resulting profile update.
