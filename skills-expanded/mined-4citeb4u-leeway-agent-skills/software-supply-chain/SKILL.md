# LeeWay Software Supply Chain Security
Treat SBOM, provenance, signatures, vulnerability status and policy as distinct evidence. SLSA describes supply-chain integrity levels/tracks; Sigstore can provide signing/verification/transparency mechanisms. Verify source/build/dependency/artifact relationships before promotion. Signed != safe; SBOM-present != verified provenance.
