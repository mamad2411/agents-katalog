# LeeWay Emotional Language Model

Track state-conditioned expression such as calm, urgency, anger, grief, affection, embarrassment, confidence, fear, joy and uncertainty. Measure/describe changes in diction, sentence length, fragmentation, metaphor, directness, repetition, humor, sensory focus and interpersonal distance from actual author evidence.

Emotion is context, not a costume. Avoid reducing a person to fixed mappings such as 'angry = profanity'. Use interview/sample evidence and preserve contradictions.
