# LeeWay Author Perception & Attention

Writing voice begins before words. Model recurring attentional tendencies: people vs objects, systems vs feelings, visual vs auditory vs tactile detail, concrete vs abstract cues, threat/opportunity, status/power, humor/absurdity, spatial detail, chronology, causality and anomaly detection.

Compare multiple prompts/samples so one topic is not mistaken for a stable trait. Classify OBSERVED, SELF_REPORTED, INFERRED and AUTHOR_APPROVED. This is an editable writing model, not a psychological diagnosis.
