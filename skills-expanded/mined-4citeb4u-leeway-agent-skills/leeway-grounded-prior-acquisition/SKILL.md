# LeeWay Grounded Prior Acquisition

When a task requires knowledge not present in the model, acquire it rather than hallucinating it: measurements, files, images, diagrams, telemetry, standards, databases, tool inspection, user clarification or controlled experiments.

Language familiarity with a concept is not equivalent to measured physical knowledge. Priors are typed by source/evidence/confidence and may be revised by observation.
