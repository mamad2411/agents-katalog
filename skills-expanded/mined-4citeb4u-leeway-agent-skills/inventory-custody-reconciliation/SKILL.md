# LeeWay Inventory & Custody Reconciliation
Use transaction/event lineage to reconcile beginning balance + receipts + production/returns/transfers - issues/shipments/scrap = ending balance by item/location/lot/serial as applicable. Adjustments require reason/authority/evidence. Ownership and physical possession are separate dimensions.
