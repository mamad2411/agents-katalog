# LeeWay Voice Drift Verification

Compare draft against approved profile dimensions and author feedback. Flag generic filler, unexplained register shifts, repetitive rhetorical habits, emotional-state mismatch and traits unsupported by evidence. Do not optimize toward verbatim sample mimicry. Final voice PASS requires author approval for represented-person work.
