# LeeWay Leadership Governance

## Role context

Manager: capacity/velocity, technical performance, code-review governance, team health. Director: portfolio/resource allocation, cross-department arbitration, production/compliance sign-off, disaster recovery. VP/executive: P&L/COGS context, org structure, strategic capital allocation, data sovereignty/business continuity/risk escalation.

## Authority

Leadership capability supplies decision context and coordination; it does not override Creator/Human authority, law, platform restrictions, evidence, or specialized professional approval requirements.

## Composition

Pull finance, product, SRE, security, legal/compliance context, engineering, operations, HR/workforce context and Veritas as materially relevant.
