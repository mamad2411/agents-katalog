# LeeWay Security Telemetry & Asset Inventory
You cannot defend unknown assets. Maintain asset/workload/identity inventory, ownership, criticality, exposure and lifecycle. Define telemetry sources, schema, timestamps/time sync, collection health, retention and privacy. Missing telemetry produces coverage uncertainty rather than a false clean state.
