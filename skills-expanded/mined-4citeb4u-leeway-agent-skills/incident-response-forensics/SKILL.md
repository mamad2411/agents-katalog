# LeeWay Incident Response & Forensics
Validate incident → scope → preserve evidence → contain → investigate/root cause → eradicate → recover → monitor → lessons. Automated containment such as token revocation or isolation requires pre-authorized runbooks, bounded scope and recovery path. A lower threat score after containment does not prove eradication.
