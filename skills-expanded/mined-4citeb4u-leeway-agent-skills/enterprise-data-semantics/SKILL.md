# LeeWay Enterprise Data Semantics
Define canonical entities/metrics, units, time windows, IDs, ownership and transformations before aggregating provider data. Reconcile duplicate/conflicting records and preserve source lineage. Same label != same metric. Formula evaluation consumes normalized evidence, not raw provider fields.
