# LeeWay Prototyping & Interaction Validation
Prototype the uncertain/risky interaction at the fidelity needed to answer a question. Test comprehension, task completion, error recovery, focus/keyboard, motion/gesture behavior and technical feasibility. Prototype success is evidence, not production readiness.
