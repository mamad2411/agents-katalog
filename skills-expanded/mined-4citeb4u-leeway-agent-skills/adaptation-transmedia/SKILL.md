# LeeWay Adaptation & Transmedia
Identify invariant story core versus medium-dependent expression. Rebuild pacing, POV, exposition, scene density, visuality/interiority and episode/chapter structure for the target medium. Adaptation is not mechanical format conversion. Track canon changes and rights/edition relationships.
