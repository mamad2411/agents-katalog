# LeeWay Author Cognitive & Rhetorical Model

Model writing-relevant decision patterns: causal explanation, analogy use, abstraction level, chronology vs association, evidence-before-conclusion vs conclusion-first, qualification/hedging, moral framing, humor as relief/attack, rhetorical questions, repetition, escalation, contrast and preferred proof.

Do not infer intelligence, mental health or hidden beliefs. Record only writing-relevant patterns supported by authorized evidence.
