# LeeWay Film Delivery Mastering & QC
Define destination requirements: frame rate, raster/aspect, color/HDR, codec/container, audio layout/loudness, captions/subtitles, metadata and package structure. SMPTE IMF supports versioned professional masters for multiple territories/platforms; D-Cinema uses standardized DCP structures. Validate the actual target profile rather than exporting one universal master.
