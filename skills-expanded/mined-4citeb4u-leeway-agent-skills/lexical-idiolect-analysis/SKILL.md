# LeeWay Lexical & Idiolect Analysis

Analyze vocabulary bands, preferred verbs/adjectives, function/discourse markers, contractions, idioms, slang, taboo/avoided language, collocation tendencies and repetition. Normalize for topic/genre so subject vocabulary is not mistaken for identity.

Store distributions/tendencies rather than a phrase-copy bank. Avoid reproducing distinctive passages from source samples.
