# LeeWay Input & Device Capability
Design actions independently of one input modality. Model hover availability, coarse/fine pointer, touch contact, keyboard/focus, stylus pressure/tilt where supported, gamepad/spatial controls and assistive technology. Feature-detect and provide equivalent access to essential actions.
