# LeeWay Procurement & Vendor Operations
Route need → approved requisition → sourcing/quote → vendor selection → PO → receipt → invoice match → payment authorization. Track price, quality, lead time, concentration, contract/rights and vendor risk. Provider recommendations do not authorize spend.
