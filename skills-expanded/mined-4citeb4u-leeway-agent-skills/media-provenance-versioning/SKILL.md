# LeeWay Film Media Provenance & Versioning
Assign work/scene/shot/take/version identities; preserve source/reference, provider/model/settings where available, hashes, approvals, edit/color/VFX lineage and derived masters. Generated media provenance supports auditability but does not by itself establish ownership/rights.
