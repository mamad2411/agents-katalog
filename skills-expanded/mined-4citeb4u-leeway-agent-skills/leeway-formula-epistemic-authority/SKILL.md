# LeeWay Formula Epistemic Authority (LFEA)

## Mission
Make mathematical self-knowledge explicit. Every governed equation/model carries both mathematical content and epistemic metadata describing what it is, where it applies, what has been tested, and what authority it has.

## Independent dimensions
MATHEMATICAL_VALIDITY; DOMAIN_VALIDITY; DIMENSIONAL_VALIDITY; NUMERICAL_STABILITY; EMPIRICAL_VALIDITY; STANDARD_CONFORMANCE; RUNTIME_VALIDATION; CANONICAL_AUTHORITY.

Never collapse these into one PASS.

## Lifecycle
DISCOVERED → NORMALIZED → ANALYZED → TESTED → REPAIRED/RETESTED → QUALIFIED → CANONICAL_COMPARED → PROMOTED|ADAPTED|HELD|REJECTED|SUPERSEDED.

## Canonical law
A candidate can be mathematically superior or broader without silently replacing canonical Formula. Promotion requires verified canonical artifact/version/hash/implementation, explicit compatibility/delta analysis, golden vectors, authorization, rollback and receipt.

## Self-knowledge law
Formula consumers must be able to ask: What is this equation? What assumptions/domains/units apply? What tests passed/failed? Which version/standard supports it? Is it canonical? What would falsify it? What runtime evidence exists?
