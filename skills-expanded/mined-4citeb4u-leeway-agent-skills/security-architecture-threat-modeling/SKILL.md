# LeeWay Security Architecture & Threat Modeling
Model assets/data, actors, entry points, trust boundaries, flows, privileges, dependencies and abuse cases before choosing controls. Use STRIDE/attack trees/ATT&CK or other methods where appropriate. Record assumptions and residual risk. Architecture review is continuous as system boundaries change.
