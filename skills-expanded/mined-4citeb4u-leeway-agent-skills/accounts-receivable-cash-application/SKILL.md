# LeeWay AR & Cash Application
Match receipt/remittance to customer/open items using deterministic references plus governed matching rules. Support partial/over/under payment, authorized deductions, credit/debit memos and unapplied cash. DSO target follows terms/portfolio strategy; DSO alone does not prove collection quality.
