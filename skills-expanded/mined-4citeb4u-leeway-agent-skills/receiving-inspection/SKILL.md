# LeeWay Receiving & Inspection
Receive against expected PO/shipment while preserving actual observations. Record count, UOM, mass/dimensions where relevant, lot/serial, damage/quality, accepted/rejected/quarantined quantities and discrepancy reason. Never force actual receipt to equal expected data.
