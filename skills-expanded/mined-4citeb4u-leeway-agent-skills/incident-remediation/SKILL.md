# LeeWay Enterprise Incident & Remediation
Breach → validate metric/data → classify impact → identify owning House/skills → parallel diagnosis → remediation options → authority/approval → bounded execution → post-state measurement → Veritas → receipt/learning. If data is wrong, repair evidence pipeline rather than operational state.
