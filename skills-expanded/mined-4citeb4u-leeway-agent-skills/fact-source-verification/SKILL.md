# LeeWay Writing Fact & Source Verification
Classify claims as fictional/canonical, common knowledge, sourced factual, disputed, uncertain or authorial opinion. Verify consequential factual claims against appropriate sources and record citations/evidence separately from manuscript prose. Never fabricate sources or convert uncertainty into fact.
