# LeeWay Operational Metric Provenance & Quality
Every consequential metric binds definition, unit, source, extraction time/window, freshness, transformation, uncertainty and owner. Missing/stale/conflicting evidence yields UNKNOWN/BLOCKED as appropriate, not a fabricated zero. Metric quality can independently block automated decisions.
