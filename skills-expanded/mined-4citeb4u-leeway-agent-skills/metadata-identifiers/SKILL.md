# LeeWay Publishing Metadata & Identifiers
Maintain canonical metadata separately from rendered cover/interior. Validate title/subtitle, contributors/roles, language, description, subjects, dates, publisher/imprint, rights, edition/version and accessibility metadata. ISBN assignment is an external identifier process; do not invent identifiers.
