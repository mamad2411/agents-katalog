# LeeWay Developer Workflow

Preserve the user intent and acceptance criteria, inspect repository authority, isolate changes, protect unrelated work, test the narrowest relevant surface, document risk, and submit reviewable commits. Require traceability from request to code to verification. Never overwrite a dirty worktree or claim tests passed without command evidence.
