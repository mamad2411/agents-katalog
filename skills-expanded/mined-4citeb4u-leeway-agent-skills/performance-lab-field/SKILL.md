# LeeWay Performance Lab & Field
Lab tests diagnose reproducibly; field/RUM measures actual populations. Core Web Vitals use field-oriented percentile thresholds; INP cannot be faithfully replaced by a single lab synthetic metric. Record device/network/browser/version/sample/window and percentile before claims.
