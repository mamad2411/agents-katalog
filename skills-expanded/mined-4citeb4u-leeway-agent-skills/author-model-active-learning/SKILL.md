# LeeWay Author Model Active Learning

Maintain coverage/uncertainty by profile dimension. Select the next evidence request where uncertainty and writing impact are both high. Prefer a small discriminating question/sample over repetitive interviews.

Stop when the profile is sufficient for the requested task and remaining uncertainty is non-consequential; do not collect personal information merely because it is available.
