# LeeWay Design Token Architecture
Define primitive/global → semantic → component/state tokens with stable naming, inheritance, mode/theme overrides, platform transforms and provenance. Prevent raw-value drift. Token coverage is measured against the intended component/state universe, not assumed to be universally 100%.
