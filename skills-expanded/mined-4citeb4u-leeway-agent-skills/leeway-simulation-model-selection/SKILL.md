# LeeWay Simulation Model Selection

Choose representation/model from task physics/semantics: Euclidean geometry for spatial closure; rigid-body/kinematic models for motion; queueing for service systems; state machines for interaction/workflow; graph models for dependencies/security; accounting invariants for ledgers; stochastic models where uncertainty is intrinsic.

Record domain/assumptions/validity. A convenient equation is not authority. If no validated model exists, classify simulation as approximate and require stronger empirical testing.
