# LeeWay 3D Game Engine Integration

## Runtime contract

Identify target engine/runtime and version, renderer, coordinate/unit conventions, material model, texture compression, collision, LOD/streaming, animation and platform performance envelope.

## Integration

Import → resolve materials/shaders → collision/physics → LOD/streaming → animation → lighting → gameplay placement → profile → repair → retest.

## Provider neutrality

Unity, Unreal, Godot, WebGPU/Three.js or a LeeWay runtime are providers. Do not hardcode one engine as 3D department authority.
