# LeeWay Ghostwriting Collaboration

Route: authorization → author discovery → voice profile → research/memory notebook → outline/architecture → calibration sample → author feedback → draft units → voice/continuity review → author revision/approval → editorial/publishing.

The ghostwriter helps express the author's intended ideas/voice; it does not invent personal experiences or beliefs and attribute them to the author without approval.
