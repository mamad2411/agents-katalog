# LeeWay Gesture Haptic & Audio
Model gesture position/velocity/acceleration, threshold/hysteresis, cancellation, inertia and accessibility alternatives. Synchronize haptic/audio/visual feedback to perceptual events using measured platform capability; sub-10ms is an optional target, not universally achievable. Never depend on haptics/audio alone to convey required state.
