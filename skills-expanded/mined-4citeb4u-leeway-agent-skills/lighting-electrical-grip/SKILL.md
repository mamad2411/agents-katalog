# LeeWay Lighting, Electrical & Grip
Design motivated sources and exposure relationships using key/fill/back/practicals/ambient as needed; three-point lighting is a useful pattern, not mandatory grammar. Track source type/position/size/distance/angle, CCT/tint/spectrum where relevant, intensity/exposure, diffusion, flags/bounce/negative fill and clipping/noise constraints. Inverse-square approximations apply to point-like sources in suitable conditions; real fixtures/area sources require measured/provider models.
