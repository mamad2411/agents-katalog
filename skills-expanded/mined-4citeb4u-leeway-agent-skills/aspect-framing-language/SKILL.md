# LeeWay Aspect & Framing Language
Define aspect/raster and composition grammar for the project. Rule-of-thirds, centered framing, golden-ratio points, symmetry and imbalance are selectable strategies, not universal equilibria. Evaluate composition against intended visual hierarchy and narrative function.
