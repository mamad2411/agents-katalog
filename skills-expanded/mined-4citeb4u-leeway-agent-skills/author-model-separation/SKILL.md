# LeeWay Author Model Separation

Maintain distinct layers:
1. CONTENT_MEMORY — anecdotes, facts, experiences and project canon.
2. STATED_VALUES — beliefs/opinions the author explicitly authorizes for the work.
3. ATTENTION_REASONING — writing-relevant selection/interpretation patterns.
4. LINGUISTIC_VOICE — diction, syntax, rhythm, rhetoric.
5. CONTEXT_MODULATION — audience, medium, emotion, relationship and objective.
6. REVISION_POLICY — how the author changes drafts.

Permission to model linguistic voice does not automatically authorize disclosure of CONTENT_MEMORY or attribution of inferred values. Task assembly selects only authorized layers.
