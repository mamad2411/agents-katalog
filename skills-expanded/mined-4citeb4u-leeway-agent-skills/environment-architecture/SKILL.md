# LeeWay 3D Environment & Architecture

## Audit

Map building shell, floors/rooms, doors/windows, circulation, exterior paths, terrain/water, vegetation, props, lighting zones, repeated modules, collision and camera/player traversal.

## Preserve spatial truth

Architectural repairs must preserve approved footprint, openings, circulation and authored landmarks unless redesign is requested. Use Blueprint skill for measured changes.

## Environment production

Modularize repeated structures; use instances for repeated props/vegetation; plan trim sheets/atlases where appropriate; establish material families; maintain believable scale; manage occlusion/culling and LOD zones.

## Library example

A full library scene may weave architecture + paths/boardwalk + landscaping + furniture + books/props + glass/wood/stone materials + interior/exterior lighting + collision + LOD/performance. Treat each as a linked asset family, not one giant mesh.
