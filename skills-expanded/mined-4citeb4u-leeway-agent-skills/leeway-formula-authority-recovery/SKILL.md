# LeeWay Formula Authority Recovery

## Recovery law

`recover proven authority → verify identity/hash → reuse/adapt → create only the missing capability`

Apply `config/portability-contract.md`. A missing machine path does not prove Formula authority is absent. Query configured canonical repositories, package resources, approved artifact stores, authorized services and available local roots through their adapters. Do not scan arbitrary drives or require historical host locations.

Canonical identity: `4citeB4U/Leeway-formula-live`, `LEEWAY-FORMULA-v1.0`. Its `runtime/canonical/leeway-formula/v1` contains the byte-preserved recovered kernel; `runtime/kernel-integrity.json` verifies imported code and specifications before startup. Use the repository's portable deployment documentation. Consumers invoke the central evaluator rather than embedding divergent mathematics.

## Bind and prove

1. Recover repository/version/hash and any applicable prior receipt.
2. Discover the authorized current Formula endpoint or MCP adapter. `LEEWAY_FORMULA_BASE_URL` is an optional HTTP binding; localhost port 4001 is a local compatibility default, never a mandatory remote address.
3. Verify formula identity, pinned implementation and adapter identity.
4. Execute only with an authorized input and verified mapping; preserve source and transformation provenance.
5. Compare actual result and persisted receipt with the expected invariants. Distinguish diagnostic test vectors from task evaluation.
6. Record the current runtime binding, hashes, timestamp, execution scope and remaining gaps.

Canonical routes: `/runtime/formula/v1/health` and `/runtime/formula/v1/evaluate`. Adapters: `raw-base64-v1` and `runtime-state-v1`. Both require the defined 16×6 input shape. MCP tools are `formula_health` and `formula_evaluate` when registered by the host. No verified arbitrary-question-to-matrix mapping is supplied.

## Preservation and evidence

`copy → hash verify → manifest → rebind → health/evaluation/receipt verification → retire old payload only when authorized`

Keep original sources and existing secrets intact. Record original and destination resource identities, source/destination hashes, receipt lineage, runtime-consumed identity and whether each artifact is canonical, candidate, historical or live. A host-specific storage controller is an adapter, not a universal Formula requirement.

Converge `historical receipt == live implementation hash == endpoint identity == execution output == verification == recovery receipt`. If any link is missing, report that link. A healthy evaluator does not prove all ecosystem clients are connected.
