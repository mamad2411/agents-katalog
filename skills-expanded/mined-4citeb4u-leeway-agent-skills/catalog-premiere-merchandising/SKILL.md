# LeeWay Catalog, Premiere & Merchandising
Model Work → Edition → Offer → Placement separately. Support shelves/categories, featured/premiere windows, author pages, samples/previews, availability and outbound purchase/read destinations. Removing placement must not delete the underlying work/edition history. Catalog UI consumes records; books are not hardcoded components.
