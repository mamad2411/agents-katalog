# LeeWay 3D Navigation & Gameplay Spatial

Separate render mesh from navigation/collision/interaction representations. Build/validate walkable areas, agent dimensions, obstacles, doors/links, interaction volumes and occluders. Godot and other engines can generate navigation/occlusion/physics representations during import; provider behavior must be verified for the target runtime.
