# LeeWay EPUB Production
Target the current approved project EPUB profile; W3C EPUB 3.3 is a Recommendation and EPUB 3.4 is evolving in 2026. Build semantic content documents, package metadata, navigation, resources and container structure. Prefer reflowable EPUB for text-centric books unless fixed layout is justified. Validate rather than assuming reading-system interoperability.
