# LeeWay Enterprise Action Governance
Classify actions before execution: READ/MEASURE; RECOMMEND; DRAFT; LOW_RISK_REVERSIBLE_WRITE; CONSEQUENTIAL_WRITE; REGULATED/HUMAN_APPROVAL; BLOCKED. Bind actor, permission, target, expected effect, rollback/compensation and evidence. Metric breach authorizes diagnosis/routing, not automatically the corrective mutation.
