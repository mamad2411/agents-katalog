# LeeWay Edge & Network Defense
Measure legitimate/malicious traffic using labeled/validated evidence rather than assuming distribution shape. Use layered controls: upstream capacity/scrubbing, routing, kernel/host filters, firewall, rate limits, WAF/API controls and origin protection. eBPF/XDP/BGP actions require scoped network authority and safe rollback. Optimize malicious leakage and legitimate false blocks jointly.
