# LeeWay Storyboard Previs & Animatic
Represent shot intent visually/spatially before final generation/capture. Use boards, overhead blocking diagrams, 3D previs and timed animatics as appropriate. Preserve shot IDs so later generated/captured assets map back to plan and editorial timeline.
