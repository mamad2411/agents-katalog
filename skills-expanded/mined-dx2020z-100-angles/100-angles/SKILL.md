# 100 Angles — 书籍百维拆解术 v2.0

对任意书籍执行 **100 个维度的深度认知拆解**，生成结构化分析报告与可视化图谱。

**核心能力：**
- 14 大认知域 × 100 个分析角度（覆盖解剖、翻译、应力测试、网络、时间、生成、对抗、数学、迁移、考古、负空间、多体、涌现、特殊）
- 灵活单选 / 组合 / 全景扫描三种模式
- 输出结构化 Markdown 报告 + 可视化建议（`references/visualization.md`）

## 价值定位：先想清楚「你为什么拆这本书」

本 skill 最强的不是角度多，而是能逼你用**自己绝不会自发采用**的镜头看一本书（负空间、对抗、考古、黑箱）。但角度越多越容易瘫痪——所以**不要从"选角度"开始，从"你要什么"开始**。

本 skill 服务 5 种典型目的，每种都预设了精选角度集（见下方「路由」）：

| 目的 | 你想要的 | 适合人群 |
|------|---------|---------|
| 🅰 提取可行动方法论 | 把书变成能复用的工具/清单 | 实用派、搞钱/自我提升读者 |
| 🅱 批判其论证漏洞 | 找出逻辑裂缝、盲区、时代偏见 |  skeptical 读者、审稿人 |
| 🅲 跨书对比 | 找两本书之间的结构共振/冲突 | 研究者、找规律的人 |
| 🅳 写作/内容素材 | 拆出能二次创作的钩子 | 博主、作者、讲师 |
| 🅴 深度理解/纯粹欣赏 | 只是想把一本书读透 | 深读型读者 |

> 若你只说书名没说目的，**默认按 🅴 深度理解**处理，并在 Step 0 回显让你改。

## Quick Start

**单角度分析（快速切入）：**
> 📖 书名：___  🔍 角度：___（如：骨骼提取、黑箱审计）
> → 输出该角度的完整分析卡片

**组合分析（主题深挖）：**
> 📖 书名：___  🎯 域：___（如：考古、对抗、涌现）
> → 输出该域所有角度的完整分析

**全景扫描（完整透视，注意成本）：**
> 📖 书名：___  🌍 模式：全景扫描
> → 输出 100 维度完整报告（**跑前有一次确认检查点**）

## 输入契约（最小触发条件）

本 skill **拒绝"只给书名就开跑"**。有效触发 = `书名 + 附加条件`。

附加条件至少含三项（缺任一则先追问，不硬拆）：
1. **是否已读**：已读 / 未读但能提供章节或简介 / 完全没读过且无法提供内容
2. **最终目的**：🅰方法论 / 🅱批判 / 🅲对比 / 🅳素材 / 🅴理解 / 其他（请说明）
3. **期望产出**：一页速览 / 深度卡片 / 可行动清单 / 内容脚本 / 对比报告

> 用户只甩书名 → 先回显追问这三项；用户说"随便拆拆" → 默认 🅴+最小可用5角度，但仍要确认是否已读（决定能否引用书中原话）。

## 执行协议（Workflow）

### Step 0：前置适用性筛查（先判断"能不能拆"）

拿到书名先分类，再决定是否继续——**不适合的书必须明确拒绝，不得硬拆**。

| 类型 | 判断 | 处理 |
|------|------|------|
| 论述/方法论/社科/商业/科普/传记（有论点） | 高度适合 | 进入 Step 1 |
| 小说/文学/诗集/教科书（有结构但非显式论点） | 适合，需裁剪 | 标注维度转换（"论点"→"作者意图/叙事策略"），继续 |
| 纯工具书（字典/词典/手册/API文档/菜谱步骤/法条汇编） | 不适合 | **明确拒绝**（见下） |
| 纯数据汇编（年鉴/统计年报/无论述的财报合集） | 不适合 | **明确拒绝**（见下） |
| 图片为主无文字 / 占位空白书 | 不适合 | **明确拒绝**（见下） |

**不适用声明模板**（命中"不适合"时输出，不得硬拆）：

> ⛔ 《书名》属于 [类型]，不适合做 100 角度深度拆解。
> 理由：[一句话说明它为什么没有可拆的论点/结构]。
> 若硬拆会造成这些盲区：
> - **伪洞察**：把参考条目/数据当成"论点"误读，产出大量看似深刻实则无物的结论
> - **低信噪比**：90% 角度用不上，浪费大量 token 与时间
> - **荒谬结论**：对工具书强行找"隐藏前提/负空间"会得出可笑推论
> - **幻觉式理解**：读者误以为"读懂了"，实际是模型在填空
> 替代建议：这类书更适合做 [索引 / 摘录 / 术语表 / 对照表]，而非认知拆解。

### Step 1：明确读者目的与需求（必须问清，不靠猜）

按输入契约确认三项。若用户只给书名，先回显追问：

> 📋 在拆《书名》前，先确认三件事：
> ① 你读过了吗？（已读 / 未读可提供章节 / 完全没读过）
> ② 最终想拿来干嘛？（🅰方法论 / 🅱批判 / 🅲对比 / 🅳素材 / 🅴理解 / 其他）
> ③ 想要什么形式产出？（速览 / 卡片 / 清单 / 脚本 / 对比报告）

回显确认后继续（用户可随时改）。**不允许在目的未知时直接铺开分析。**

### Step 2：目的路由 + 定制（基于需求调整 100 维度的用法与重点）

- 按目的路由精选集（见下"路由表"）。
- **定制层（关键，禁止一套模板通吃）**：根据附加条件调整——
  - **未读 / 仅能提供简介**：所有角度严格基于用户提供的内容范围，**不编造书中原话**；输出标注「基于简介的有限拆解」。
  - **重点诉求偏某方向**：把相关域权重拉高（如"只关心方法论落地"→ 生成域 #43-50 + 解剖 #44 优先），其余域降权或跳过。
  - **期望产出 = 速览**：每角度压到 1-2 句，不做完整卡片。
  - **多本书对比**：路由 🅲，先各自单角度再合「对比小节」。
- 输出开头加一行定制说明，让"为人定制"可见、可追溯：
  > `🎛️ 定制说明：目的=[🅴理解] · 是否已读=[已读] · 重点=[通用] · 角度集=[最小可用5] · 深度=[标准]`

**路由表（5 套精选集）：**
- 🅰 提取方法论：#43 种子句培育、#44 逆工程工具箱、#46 隐喻引擎、#49 操作系统提取、#05 动词骨架、#61 压缩极限
- 🅱 批判漏洞：#21 极端读者攻击、#51 最强反驳、#55 盲区报告、#04 恐惧扫描、#91 断裂点定位、#83 未问的问题
- 🅲 跨书对比：#29 概念图谱、#31 思想谱系、#32 引用网络、#85 三体碰撞、#86 敌意合成、#90 高频词汇解码
- 🅳 写作素材：#47 空白章节、#41 前传生成、#42 续集生成、#79 影子书、#95 书的墓志铭、#97 解毒剂处方
- 🅴 深度理解：#01 骨骼提取、#02 暗物质测绘、#06 矛盾晶体、#57 拓扑分析、#78 沉默目录、#100 黑箱审计

每个角度的具体指令与 Prompt 模板见 `references/domain-XX-*.md`（XX 为域编号）。

### Step 3：执行

对选中的每个角度，加载对应 domain 文件，套用其「指令 + Prompt 模板」，把 `{book}` 替换为实际书名。**严格按模板的步骤输出，不偷步。**

### Step 4：输出格式（统一结构 + 定制痕迹）

- **单角度卡片**：
  ```
  ### [#编号] 角度名
  > 一句话结论：___
  - 核心发现：3-5 点
  - 关键证据/引文：___
  - 可迁移启示：___
  ```
- **域报告**：域概述 + 该域各角度卡片依次展开 + 「域小结」（该域揭示的最强一条洞察）
- **全景报告**：每域一节（标题 `# 第N域·XXX`），域内各角度卡片；末尾加「🌐 全局洞察」汇总（跨域共振 / 最大盲点 / 一句话墓志铭 #95）
- **任何输出都保留 Step 2 的「🎛️ 定制说明」行**，证明这是为**该读者该需求**生成，而非通用套版。

### Step 5：全景扫描检查点（成本护栏）

进入 100 角度前，**必须**先回显范围与篇幅估算，等用户确认：

> `⏸️ 将分析《书名》全部 100 角度，预计输出约 X 千字、耗时较长。确认开始？[回车继续 / 输入角度编号或域名缩小范围]`

未获确认不得自动展开全景。

## ⚠️ 边界与异常处理（fallback）

> 适用性判定见 **Step 0**；读者目的 / 是否已读 / 输入契约见 **Step 1**。以下为其余边界：

| 情况 | 处理 |
|------|------|
| 用户只给书名、无附加条件 | 按 Step 1 先追问「是否已读 / 目的 / 产出」，不硬跑 |
| 未读且无法提供任何内容 | 仅能基于公开已知信息做**有限拆解**，须声明「未读·基于公开信息」，不编造原话 |
| 非书（文章/论文/长文） | 同样适用，把"全书"替换为"该文本" |
| 文本太短（<1000字） | 只跑单/少角度，不做全景扫描 |
| 用户只想看角度目录 | 直接输出下方总表，**不执行分析** |
| 预算/长度受限 | 默认「最小可用 5 角度」，要更多再扩展 |
| 多本书对比需求 | 路由 🅲，先各自单角度再合「对比小节」 |
