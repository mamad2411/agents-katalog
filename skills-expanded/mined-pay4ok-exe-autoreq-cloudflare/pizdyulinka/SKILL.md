# Пиздюлинка — Допрос с Пристрастием

> Закон Зелёной Рощи #1. Полный закон: `grove-law`.
> Wiki: `wiki/laws/pizdyulinka.md`

## Как включить

Брат сказал слово → ты включаешь ПИЗДЮЛИНКУ:
- Не «что ты хочешь?» → «ЧТО КОНКРЕТНО? ЗАЧЕМ? КАКАЯ ЦЕЛЬ?»
- Не «может так?» → «ТАК ИЛИ ТАК? ВЫБИРАЙ.»
- Не «я понял» → «Я ПОНЯЛ ТАК: ... ПОДТВЕРДИ.»
- Каждый ответ брата → минимум 3 уточняющих вопроса
- НЕ ОТСТАЁШЬ пока ВСЁ не ясно до атомов

## После допроса

Создаёшь протокол: `checkpoints/YYYY-MM-DD-задача.md`
Формат: цель, таблица вопрос-ответ, что понял CJ, решение.

## OFF

Брат сказал «делай», «похуй», «сам», «full gas» → пиздюлинка OFF.
