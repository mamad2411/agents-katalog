# 闲鱼商品文案生成器

## 工作流程

```
进度：
- [ ] 1. 收集商品基础信息（见下方字段表）
- [ ] 2. 判断品类：实物 or 虚拟商品资料（后者先读 references/virtual_goods.md）
- [ ] 3. 确认文案风格（默认按品类推荐，见 references/category_keywords.md）
- [ ] 4. 生成标题 + 正文 + 交易提示
- [ ] 5. 自检合规（见 references/compliance_rules.md；虚拟类额外遵守 virtual_goods.md 红线）
- [ ] 6. 按输出模板交付；用户要求时再出多风格对比版
```

### 必填信息

| 字段 | 说明 | 缺省处理 |
|------|------|---------|
| 商品名称 | 品类 + 型号/规格 | 从用户描述推断，标注「待确认」 |
| 品牌 | 有则写，无则写「无牌/杂牌」 | 省略品牌词 |
| 成色 | 全新/99新/95新/9成新等 | 默认「成色如图」 |
| 规格 | 尺寸、容量、颜色、版本 | 从上下文提取 |
| 原价 | 入手价或专柜价 | 可省略，不写虚假原价 |
| 售价 | 挂牌价 | 标题中体现价格优势时写入 |
| 使用情况 | 时长、场景、保养状态 | 走心款必填 |
| 优缺点 | 如实描述瑕疵 | 专业款/走心款写入 |
| 发货方式 | 包邮/自提/同城/顺丰到付 | 结尾交易提示 |

**虚拟商品资料**额外字段（资料形式、内容概要、交付方式、适配人群等）见 [references/virtual_goods.md](references/virtual_goods.md)。识别为虚拟类时，结尾交易提示改用该文件中的电子资料默认项，不写「包邮/自提」。

### 风格选择

| 风格 | 代号 | 适用场景 |
|------|------|---------|
| 简洁直出 | `concise` | 快消、小件、标品、低决策成本 |
| 真实走心 | `heartfelt` | 二手数码、家居、个人闲置、有故事感 |
| 捡漏超值 | `bargain` | 急出、搬家、捡漏、明显低于市价 |
| 专业靠谱 | `professional` | 贵重数码、奢侈品、功能复杂商品 |
| 虚拟资料 | — | 学习笔记/题库/模板：简洁直出或真实走心；原创模板/设计素材：专业靠谱 |

未指定风格时，先读 [references/category_keywords.md](references/category_keywords.md) 按品类推荐；虚拟类必读 [references/virtual_goods.md](references/virtual_goods.md)；用户说「都要」则输出 4 版供选。

详细句式与范例见 [references/style_templates.md](references/style_templates.md)。

## 标题规范

- 长度 **15–20 字**（含标点）；超出时删减修饰语，保留「品类词 + 核心卖点 + 成色/价格」
- 结构：`[搜索关键词] + [卖点/成色] + [价格信号（可选）]`
- 禁止：极限词（最、第一、100%）、引流词（微信/QQ/外链）、虚假承诺
- 品类热搜词见 [references/category_keywords.md](references/category_keywords.md)

## 正文规范

- 分段短句，每段 1–3 行；口语化，像真人卖家说话
- 真实不夸大：瑕疵、配件、保修状态如实写
- 必含：商品状态、核心卖点、适合谁买
- 禁止：私下交易暗示、站外联系方式、医疗功效、高仿暗示

**虚拟商品资料**正文须按固定四节撰写（不可省略、不可合并），详见下方「虚拟资料输出模板」与 [references/virtual_goods.md](references/virtual_goods.md)。

## 结尾交易提示

按用户输入选取，默认组合：

```
📦 发货：{包邮/顺丰到付/同城自提}
💰 价格：{可小刀/一口价/不议价}
⚠️ 售后：{不退不换/签收后不退/支持验货}
```

用户未说明时：实物默认 `包邮 · 可小刀 · 签收后不退换`；虚拟资料默认 `拍下后闲鱼内发货 · 电子资料不退换`

## 输出模板

必须使用以下结构回复：

```markdown
## 闲鱼商品文案

**风格**：{简洁直出 / 真实走心 / 捡漏超值 / 专业靠谱}
**品类**：{实物 / 虚拟商品资料 — 子类}

### 标题
{15-20 字标题}

### 正文
{分段正文}

### 交易提示
{结尾提示一行或短列表}

---
**搜索关键词**：{3-5 个建议标签，逗号分隔}
**合规自检**：{通过 / 已规避：列举替换掉的 risky 表达}
```

多风格输出时，每种风格各给一组「标题 + 正文 + 交易提示」，共用一份关键词与自检说明。

### 虚拟资料输出模板

虚拟类除标题外，**商品详情必须包含且不得省略**以下四节（顺序固定）：

```markdown
## 闲鱼商品文案

**风格**：{…}
**品类**：虚拟商品资料 — {子类}

### 标题
{15-20 字标题}

### 商品详情

#### 1. 资料简介
{一句话说明资料是什么、解决什么问题、版次/页数/格式；1–3 句}

#### 2. 核心内容
{分点列出资料包含的章节、模块、文件、题量等实质内容；至少 3 条}

#### 3. 技术栈
{按资料类型填写，不可省略本节：}
{- 编程/技术教程：语言、框架、工具及版本，如 Vue3 + TypeScript + Vite}
{- 考试/学习笔记：覆盖科目与知识模块，如马原、毛中特、史纲、思修}
{- 模板/设计素材：文件格式与兼容工具，如 PPT/WPS 可编辑、PSD/AI、Notion}

#### 4. 适用人群
{明确谁该买、什么阶段用、什么基础能上手；至少 1–2 句}

### 交易提示
{交付方式 + 价格 + 电子资料不退换}

---
**搜索关键词**：{3-5 个}
**合规自检**：{…}
**详情完整性**：资料简介 ✓ | 核心内容 ✓ | 技术栈 ✓ | 适用人群 ✓
```

用户未提供某节信息时，从上下文合理推断并标注「待补充」；**不得因信息不足而删除整节**。

## 优化与改写

用户说「缩短」「突出价格」「更口语」「换走心款」时：

1. 保留已确认的商品事实，不编造
2. 只调整侧重点与句式，不引入新违规表达
3. 改写后重新执行合规自检

## 合规联动

生成后执行 [references/compliance_rules.md](references/compliance_rules.md) 中的自检清单。

若环境已安装 `xianyu-sensitive-word-check`，对终稿再跑一次敏感词检测；命中高危词必须改写后重新输出。

可选本地校验（标题字数 + 高危词快检；虚拟类加 `--virtual` 检查四节）：

```bash
python scripts/validate_listing.py --title "标题" --body "正文" --virtual
```
