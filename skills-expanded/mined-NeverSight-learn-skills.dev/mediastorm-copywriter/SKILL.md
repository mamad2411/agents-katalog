# 影视飓风口播稿生成器

依据 `analysis/analysis.md`(对影视飓风最新 19 条视频的实证分析)生成模仿其风格的**完整口播稿**。

## 使用流程

### 第 1 步:收集输入(缺失则询问用户,可用合理默认)
- **选题**(必填):这期口播讲什么。
- **内容类型**:深度议题 / 产品评测 / 纪实科普 / 游记vlog / 人物访谈(默认按选题自动判断)。
- **目标时长**:默认 5-8 分钟(约 2500-4500 字,对应样本均值)。
- **合作方/植入**(可选):品牌名 + 卖点;无则跳过植入段。
- **关键信息/素材**:可提供的数据、案例、观点;不足时用 `[待补充: …]` 占位,不要编造具体数字。

### 第 2 步:选骨架
按内容类型套用对应结构(详见 `references/structure.md`):
- 深度/科普/纪实 → **黄金七段式**(钩子→升维→植入→分点主体→转折→升华→CTA)
- 产品评测 → **评测变体**(购买疑问→改框架→逐维度拆解→值不值→CTA)
- 游记vlog → **栏目变体**(栏目IP+仪式开场→互动吐槽+边走边科普→贯穿悬念→情怀升华→CTA)

### 第 3 步:写作(严格执行 10 条硬规则)
逐条对照 `references/style-guide.md` 的硬规则,并调用:
- `references/hooks.md` 选一个开头钩子类型并套用。
- `references/transitions.md` 控制节奏(连接词、自问自答、数据换算、类比)。
- 合作方按 `references/style-guide.md` 的「自然植入」话术嵌入。
- 结尾用 `references/style-guide.md` 的 **CTA 模板**收尾。

### 第 4 步:自检(交付前逐项打勾)
- [ ] 第一句就是钩子,无「大家好」式铺垫
- [ ] 钩子后 2-3 句完成升维,点出更大意义/本期要讲的问题
- [ ] 全程第二人称「你」;平均每 100-150 字有一个设问
- [ ] 主体分点,每点含 现象+数据+类比+例证
- [ ] 所有抽象数据都做了生活化换算;抽象概念都打了比方
- [ ] 至少一次「但是/其实」转折
- [ ] 合作方(若有)自然植入,不生硬
- [ ] 有个人观点、有诚实表达(优缺点都讲)
- [ ] 结尾有升华 + 一句金句
- [ ] 用 CTA 模板收尾,以「那么我们下次再见」结束
- [ ] 未编造未经核实的具体数字/事实(用占位符标注)
