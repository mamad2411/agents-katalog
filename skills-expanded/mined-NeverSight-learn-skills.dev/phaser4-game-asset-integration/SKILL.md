# Phaser 4 美术设计与接入

让视觉资源服务体验，并满足移动端性能和上架权属要求。

快速通道仅读取任务直接相关的资源、代码、规格和验证；标准、发布通道读取 docs/project-profile.yaml、docs/GDD.md、docs/visual-design.md、docs/TDD.md、docs/control-plane.md，美术流从 A1 启动时读取 docs/asset-license-register.md，已有性能计划时再读取 docs/qa-plan.md。视觉方向、生成式资源、授权、预算或发布资格需取舍时，向总控提交决策包，等待其完成决策门禁。

1. 在 `docs/visual-design.md` 冻结风格关键词、色彩、字体、造型、场景、UI、图标、动画、特效、技术约束、禁用方向和代表性基准画面；视觉基线未获人工批准时，不得批量生成正式资源。
2. 新建或重做场景、界面、预制体或成套视觉资源时，完整读取并严格顺序执行 [references/visual-production-pipeline.md](references/visual-production-pipeline.md)；任何人工确认门未通过时，只返工当前阶段，不得提前生成下游产物。
3. 需要适配不同宽高比、消除黑边或制作场景背景时，完整读取 [references/full-bleed-background.md](references/full-bleed-background.md)。在 A2 高保真阶段优先生成无交互满幅背景，完成人工确认后通过统一适配器应用到每个可见场景。
4. 输入是参考截图、录屏、现有界面、运行场景或源代码且需要还原时，完整读取 [references/visual-reconstruction.md](references/visual-reconstruction.md)。要求制作策划和玩法先建立参考功能契约；将固定视口截图、操作轨迹、对象与功能清单以及保留/重构/新生成/删除结论纳入 A1，将代表性样张纳入 A2，随后继续 A3 至 A6，并保留逐状态视觉对比与功能复现证据。
5. 进入单图生成阶段后，完整读取 [references/effect-image-splitting.md](references/effect-image-splitting.md)，只以 A4 已确认的框选效果图和单图清单作为输入；效果图不得直接冒充可接入资源。
6. 在资源登记中为每个背景、重构项和单图维护唯一 ID、输入/来源版本、状态、用途、规格与锚点/焦点、交付路径与纹理键、授权或生成记录、发布资格和 Phaser 验证。开工前先查重；已有有效同规格产物时直接复用。
7. 按已确认的低保真结构、背景规则、资源依赖清单和 TDD 交付通过 A5 的正式资源、资源登记与接入契约，并配合玩法在目标设备验证黑边、输入、尺寸、锚点、焦点、帧序、九宫格、采样和性能问题。美术角色不修改正式场景或预制体的玩法代码。
8. A6 的结构化装配和低保真实现删除由玩法角色独占执行；美术角色只审阅视觉一致性、资源使用与背景覆盖证据，发现资源问题时退回 A5。
9. 标准、发布通道向总控提交视觉基线版本、当前美术门、背景覆盖矩阵、证据或阻断项，由总控更新控制面；快速通道仅在产生未决决策或阻断项时提交。

向架构和玩法提供已批准的视觉基线、背景覆盖规则、低保真结构、框选效果图、单图清单、复用项、规格、锚点/焦点、纹理键和路径约定；向测试提供 A1 至 A5、全场景宽高比、逐状态视觉对比和逐图检查证据，并审阅玩法提交的参考功能复现、A6 正式装配与低保真清理证据；向发布提供权属清单。功能契约、视觉确认门、背景覆盖、正式资源验证、结构化装配或低保真清理任一未完成时，不得标为可交付。
