# Long-Form YouTube Scriptwriting

Write scripts for **multi-minute (roughly 5–15 min) talking-head YouTube
videos**. The creator films themselves talking to camera and lays b-roll over
the monologue stretches, so every script pairs **what they say** with **what's
on screen**.

Long-form retention is won differently from short-form: you must re-win the
viewer *repeatedly* across minutes. Two things dominate every choice — the
**first 30 seconds** (or the average-view-duration collapses) and **sustained
retention** through the body (open loops, re-hooks, pattern interrupts). Optimize
relentlessly for both.

The scripting philosophy here is a deliberate **hybrid**: the cold open and
intro are written **word-for-word** because the opening is too important to wing;
the body is a **beat outline** the creator improvises over so delivery stays
natural. Do not fully script the body.

## Before writing: read the craft reference

On your **first** script in a conversation, read
`references/structure-and-retention.md` in full. It holds the mode structures,
hook formulas, retention tactics, and b-roll vocabulary that keep output quality
high. Don't skip it — it's what makes scripts good rather than generic.

## Step 1 — Read the input and pick the mode

The user may hand you any of: a bare topic, a topic + bullets, a messy
brain-dump or transcript, a rough outline, or a near-finished draft. Handle
whatever you get — invent the angle for bare topics, preserve their points and
voice for drafts.

Then detect the **mode**, which sets the whole body structure (details in the
reference):

- **Explainer** (a common default for informational niches): the viewer should
  *understand* something. Body builds logically.
- **Tutorial / walkthrough**: the viewer should be able to *do* something. Body
  is sequential steps; show the result first.
- **Video essay / opinion / commentary**: the viewer should be *persuaded*. Body
  is an argument arc.
- **Vlog / story / behind-the-scenes**: the viewer should *feel* something. Body
  is a narrative arc; warmer and slower.

If the mode is genuinely ambiguous, make your best call and note it in one line
— don't stall the user with a question unless it's truly unclear.

## Step 2 — Set the tone dial

Default voice: **friendly peer with a spine of authority** — casual and warm on
the surface so it never feels like a lecture, specific and credible underneath.
Shift by mode: explainer = calm and precise; tutorial = brisk and encouraging;
essay = deliberate, lets key lines breathe; vlog = warm, slow, human. If the
user asks for a specific tone, obey that over the default.

## Step 3 — Enforce long-form discipline (non-negotiable)

- **No throat-clearing.** Ban "hey guys," "welcome back," "don't forget to
  like and subscribe" (up front), "in today's video." Start inside the value.
- **One promise, kept late.** The intro makes a specific promise; the body is a
  chain of open loops resolving toward it. Vague topic framing is banned.
- **Guard the valleys.** Every place the video *could* get boring (background,
  definitions, setup) gets compressed and gets a re-hook or pattern interrupt
  right before it.
- **Pattern interrupt every ~40–60s.** The frame never sits static on a talking
  head — cut to b-roll, a graphic, a callout, a location or tonal shift.
- **Sound spoken, not written.** Short sentences, contractions, the way a person
  actually talks — even in the outlined beats.

## Step 4 — Write the output

Produce this exact structure, in this order, every time.

### A) Three cold-open hook options

3 distinct hooks using *different* formulas from the reference. Mark the
recommended pick with ⭐. Each is the verbatim first 1–3 spoken lines.

### B) The script

Written **verbatim for the cold open and intro**, then an **outline for the
body and beyond**. Use this block format (not a table):

```
[COLD OPEN — 0:00–0:15]  (word-for-word)
🎤 SAY: "Exact opening line the creator reads."
🎬 B-ROLL: Concrete shootable visual over this line.
📝 TEXT: "On-screen caption"

[INTRO / PROMISE — 0:15–0:45]  (word-for-word)
🎤 SAY: "Exact lines: the specific promise + one-line credibility + roadmap tease."
🎬 B-ROLL: ...
📝 TEXT: "..."

[BODY — SECTION 1: <label>]  (outline — improvise)
• Beat: the point to make, in a phrase.
• Beat: the next point / the open loop to plant.
🎬 B-ROLL: visual(s) to cover this section.
📝 TEXT: "key phrase / number"
🔁 RE-HOOK: the one-line tease that carries into Section 2.

[BODY — SECTION 2: <label>]  (outline)
...

[CLIMAX / PAYOFF]  (outline)
• The promise is fully delivered here. Callback to the cold-open hook.

[OUTRO + HANDOFF]  (mostly word-for-word, short)
🎤 SAY: "Land the point. One CTA."
🎬 NEXT VIDEO: specific hook teeing up the next watch.
```

Rules:

- `🎤 SAY` in the cold open, intro, and outro is the **exact** spoken line.
  Body sections use `•` beats, not full sentences — the creator improvises.
- `🎬 B-ROLL` is a concrete, shootable instruction ("cursor clicks Settings →
  Privacy"), never a vibe ("show the app"). Every talking stretch gets one.
- `📝 TEXT` reinforces the line (key phrase, number, step label) — not a
  transcript of it.
- `🔁 RE-HOOK` between body sections keeps the viewer moving forward.
- Deliver the promise **before** the outro; tee up a specific next video.

### C) Title + thumbnail idea

- **Title**: a click-worthy YouTube title (curiosity or clear value, not
  clickbait that the video can't cash).
- **Thumbnail text/concept**: the 2–4 word thumbnail phrase + a one-line visual
  concept.

### D) Runtime estimate

Estimate total runtime. Spoken pace ≈ 2.5 words/sec; for outlined body sections,
estimate from beat count (a body section typically runs 45–90s). State it like:
`Estimated runtime: ~7–9 min`. Flag if it's drifting well past ~15 min and offer
to cut a section.

## Step 5 — Offer the next move

In one line, offer the obvious follow-up: fully script a body section, punch up a
different hook, tighten the intro, or spin a cut idea into its own video. Keep it
to one sentence.

## Quality bar

Before delivering, self-check:

- Would the first 15 seconds stop *you* from clicking away? If not, rewrite.
- Does the intro make ONE specific promise, and does the climax keep it?
- Is there an open loop pulling the viewer forward at all times?
- Does every talking stretch have a concrete, shootable b-roll note, and a
  pattern interrupt at least every ~40–60s?
- Does it sound like a person talking, not an essay read aloud?
