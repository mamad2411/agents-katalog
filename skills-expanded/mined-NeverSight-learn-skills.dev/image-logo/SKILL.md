# image-logo

## 开始

- 保留精确的品牌名称、拼写、大小写、语言、已提供定位、既有资产和禁用符号。
- 在选择颜色或展示效果前，先确定一种 Logo 类型和一种识别机制。

## 证据边界

不得编造品牌故事、英文名、缩写、口号、受众、竞品结论、商标状态或注册保证。生成图只是概念研究，不是可生产的矢量文件。

## 选择类型

根据名称、既有识别资产、预期用途和记忆目标，在字标、字母标、具象标、抽象标、吉祥物标或组合标中选择。不要默认采用图形加通用字体。

## 建立识别机制

把概念转化为可见结构：

- 一个主导轮廓；
- 清晰构成方法，例如切割、折叠、连接、重复、交错、共用轮廓或负空间；
- 受控的几何、曲率、角度、比例、线宽和内部划分；
- 有明确字重、字距、字尾和关键笔画改造的字标；
- 图形和字标共用的形式语言。

常见品类符号只有在通过品牌名、独特轮廓、共用负空间或其他具体机制被改造后才能使用。不要在一个标记中堆叠多个隐喻。

## 减法与记忆测试

Logo 的区分度来自一个可复述的形式机制，不来自元素数量。每次都做四个判断：

- 去掉颜色、渐变和材质后，轮廓是否仍能被描述；
- 缩小到图标尺度后，内部结构是否仍然清楚；
- 图形和字标是否各自独立成立，又共享同一节奏；
- 去掉任意一个部件后，识别机制是否反而更清晰。

若一个概念必须靠解释多个隐喻才成立，回到轮廓、负空间或关键笔画，减少而不是继续叠加。

## 结构转译

“适合头像、缩小后仍清楚、可用于包装或长期传播”都是内部判断，不是最终 Prompt 里的口号。把它们改写为结构控制：

- 用完整、稳定的主外轮廓，不依赖碎边或微小纹理；
- 控制内部切分，只留下一个关键负空间或识别关系；
- 用厚实块面、可辨识转角和有依据的对称或不对称建立重心；
- 用中粗字重、受控字距、关键笔画改造和图文共形建立字标；
- 用纯色或低干扰背景呈现主标志，不用摄影场景、包装 Mockup 或复杂装饰替代 Logo 本身。

最终 Prompt 只描述图形如何构成、字形如何处理、颜色和背景如何呈现，不直接写“高级、易传播、适配多场景、小尺寸清晰”等设计要求。

## 结构先于颜色

先用单色检查概念。轮廓、内部空间和字标节奏必须在没有渐变、灯光、纹理或 Mockup 时成立。结构成立后再加入克制的颜色关系。

主概念应正面展示在安静背景上，并留出足够安全边距。除非用户明确要求应用预览，不要用招牌、包装、纸张纹理或复杂 Mockup 掩盖薄弱几何。

颜色通常控制在两到三种关系内，并先保证单色结构成立。文字只出现必要层级；品牌名、英文名和缩写没有明确必要时不要重复堆叠。

## 交接

保留选定方向、结构、字标处理、颜色、展示、禁用俗套、精确名称和品牌控制，直接交给 `image-prompt`。不要创建项目对象。

## 输出

返回：

- 只基于已提供事实的品牌记忆目标；
- 选定的 Logo 类型；
- 一种识别机制及其适配原因；
- 轮廓、几何、负空间和字标处理；
- 克制的颜色和展示方向；
- 受保护与禁用元素。

不要输出最终双语 Prompt 或执行设置。继续交给 `image-prompt`；既有源 Logo 必须保留时使用其编辑分支。

## 检查

- 一种 Logo 类型和一种识别机制明确可见。
- 标记在没有颜色或效果时仍可识别。
- 图形和字标使用同一形式语言。
- 精确品牌文字和禁用符号得到保留。
- 没有作出法律或生产层面的声明。
- 识别机制能在一句话内被复述，而不是依赖效果说明。
