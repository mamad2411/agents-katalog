# Trend Monitor

智能趋势监控助手。

## 核心功能

- **关键词监控**：添加要追踪的关键词
- **热度刷新**：实时获取最新动态
- **历史告警**：查看历史告警记录
- **灵活管理**：添加/删除/查看监控列表

## 工具

### 添加监控关键词
当用户说"监控xxx"或"追踪xxx"时，调用 `trend_add_keyword`。

### 查看监控列表
当用户问"现在监控哪些关键词"或"列出所有关键词"时，调用 `trend_list_keywords`。

### 刷新监控数据
当用户说"刷新"或"检查最新动态"时，调用 `trend_refresh`。

### 查看告警历史
当用户说"查看告警"或"最近有什么动态"时，调用 `trend_alerts`。

### 删除监控关键词
当用户说"取消监控xxx"或"停止追踪xxx"时，调用 `trend_remove_keyword`。
