# 看图学英语

## 🆕 v1.2.6 新特性

### ✨ 核心更新

#### 🎯 search_web 词库获取功能（重点更新）

**问题解决**：
- 脚本内部使用 curl 访问百度/Google，被安全验证拦截
- search_web 工具可用，但脚本无法直接调用

**解决方案**：主 agent 调用 search_web → 将结果传给脚本解析

**新增 API**：

```python
# 1. 获取搜索关键词（供主 agent 使用 search_web）
from generate_cards_batch_v2 import VocabularyListManager
keywords = VocabularyListManager.get_search_keywords("cet4")
# 返回: ["CET4 大学英语四级 词汇表 音标 释义"]

# 2. 主 agent 调用 search_web（在主对话中）
search_results = search_web(keywords)

# 3. 解析搜索结果创建词库
vocab = VocabularyListManager.create_from_search_results(
    vocab_key="cet4",
    search_results=search_results,
    words_count=15
)
# 返回:
# {
#     "key": "cet4",
#     "name": "CET-4 大学英语四级词汇",
#     "level": "beginner",
#     "total_words": 15,
#     "words": [...]
# }
```

**新增静态方法**：

- `VocabularySearcher.get_search_keywords(vocab_name)` - 获取搜索关键词
- `VocabularySearcher.parse_from_search_results(content, count)` - 解析搜索结果
- `VocabularyListManager.create_from_search_results(...)` - 从搜索结果创建词库

**支持的解析格式**：
1. 序号格式：`1. abandon /əˈbændən/ v. 放弃`
2. 横线格式：`ability - /əˈbɪləti/ - n. - 能力`
3. 表格格式：`| word | phonetic | pos | meaning |`
4. 标准格式：`stationary [ˈsteɪʃənri] adj. 固定的`
5. 纯单词列表（备选）

## 🔧 核心工具说明

本技能使用以下工具实现核心功能：

### 1. 单词信息获取
- **Free Dictionary API**：获取音标、词性、英文释义、例句
- **有道词典接口**：获取中文释义
- **search_web**：补充更多例句和用法（可选）

### 2. 图片生成 ⭐ v1.1.1 核心功能

#### image_generate 工具使用

**重要变更**：v1.1.1 版本为每个单词单独生成专属配图，不再使用场景图。

**调用方式**：
```
# AI Agent 在处理单词时自动调用
image_generate(
    prompt="A single, clear illustration of '{word}' for English vocabulary learning. Definition: {definition}. Chinese meaning: {chinese_meaning}. Style: cute cartoon style, colorful, friendly, educational illustration for children, simple and clear. The image should clearly show the object or concept, educational and memorable, suitable for vocabulary flashcard.",
    count=1,
    file_prefix="{word}_card"
)
```

**图片命名规范**：
- 格式：`{word}_card.jpg`
- 示例：`table_card.jpg`, `house_card.jpg`
- 存储路径：`imgs/{YYYY-MM-DD}/`

**支持风格**：
- `cartoon`（默认）：卡通风格，适合教育场景
- `realistic`：写实风格，真实感强
- `artistic`：艺术水彩风格
- `minimalist`：极简设计风格

**缓存机制**：
- 相同单词+风格组合自动使用缓存
- 避免重复生成，节省资源

#### search_images 工具（备用）
- 搜索关键词建议：`{word} concept illustration` 或 `{word} visual representation`
- 选择适合教育场景的图片

## 📖 背景

### 痛点
- **记忆效率低**：传统背单词依赖机械重复，缺乏情境关联，记忆留存率仅10-20%
- **抽象难理解**：抽象词汇（如"perseverance"）难以通过文字定义形成深刻印象
- **学习动力不足**：枯燥的单词表和纯文本学习容易让人失去兴趣
- **遗忘曲线陡峭**：没有科学复习机制，学过的单词很快忘记
- **词根词缀知识缺失**：不了解构词规律，无法举一反三
- **发音缺失**：不知道正确发音，影响听说能力
- **重复劳动**：每次都要重新生成相同单词的卡片和图片

### 后果
- 词汇量增长缓慢，长期停滞在基础水平
- 考试备考周期长，效率低下
- 实际应用时想不起单词，沟通受阻
- 学习自信心受挫，放弃英语学习
- 发音不准，影响口语交流

### 价值
本Skill通过**视觉记忆法**解决以上问题：
- 🎨 **双重编码理论**：图片+文字双通道记忆，留存率提升至65%
- 🖼️ **专属配图**（v1.1.1）：每个单词都有专属配图，记忆更精准
- 🧠 **情境化理解**：图片提供具体情境，加深语义理解
- 📊 **科学复习**：艾宾浩斯曲线自动安排复习节点
- 🔍 **词根拆解**：揭示单词构词规律，举一反三
- 🎯 **个性化计划**：根据目标定制学习路径
- 🎵 **发音辅助**：自动生成发音，提高听说能力
- 💾 **智能缓存**：避免重复生成，节省时间和资源
- 📈 **进度追踪**：记录学习效果，生成错词本

## 🚀 使用方法

### 方法一：创建学习计划（推荐新手）

**触发词**：`背单词`、`制定英语学习计划`、`帮我学英语`

**词库选择**（v1.2.2 新增）：
- **通用词库**：beginner（初级）、intermediate（中级）、advanced（高级）
- **考试词库**：pets4（公共英语4级）、cet4（大学英语四级）、cet6（大学英语六级）
- **自定义词库**：用户可提供单词列表或上传词库文件

**示例对话**：
```
用户：我想学习公共英语4级的词汇
AI：好的！我来为你制定公共英语4级学习计划：
    - 从PETS-4词库中选择单词
    - 每天学习30个新单词
    - 每个单词生成专属配图
    - 自动生成词根分析
    - 自动生成发音
    - 按艾宾浩斯曲线安排复习
    
    [生成学习计划表]
    [为每个单词生成专属配图]
```

**工作流程**：
1. 评估用户水平和目标
2. **根据目标选择词库**（v1.2.2 新增）
   - 用户指定考试类型 → 加载对应考试词库
   - 用户提供单词列表 → 直接处理自定义词库
   - 用户未指定 → 根据水平推荐通用词库
3. 生成每日学习计划（JSON + Markdown）
4. **为每个单词调用 image_generate 生成专属配图** ⭐ v1.1.1
5. 生成艾宾浩斯复习时间表
6. 创建进度追踪文件

## 🔄 AI Agent 工作流程（v1.1.1）

### 单词处理流程

```
用户请求：学习单词 "table"
    ↓
1. 检查缓存
    ↓ (未命中)
2. 调用词典API获取信息
    ├─ 音标：/ˈteɪbl/
    ├─ 词性：noun
    ├─ 英文释义：a piece of furniture
    └─ 中文释义：桌子
    ↓
3. 分析词根词缀
    ↓
4. 生成发音文件（可选）
    ↓
5. 准备图片生成请求 ⭐ v1.1.1
    ├─ prompt: "A single, clear illustration of 'table'..."
    ├─ style: cartoon
    └─ save_path: imgs/{date}/table_card.jpg
    ↓
6. 调用 image_generate 工具 ⭐ v1.1.1
    ↓
7. 生成Markdown卡片
    ↓
8. 保存并缓存
```

### 批量处理流程

```
用户请求：学习 apple, banana, orange
    ↓
1. 批量获取单词信息（并行）
    ↓
2. 批量分析词根词缀
    ↓
3. 检查图片缓存
    ↓
4. 生成批量图片请求 ⭐ v1.1.1
    ↓
5. 保存 batch_image_requests.json
    ↓
6. AI Agent 调用 image_generate 为每个单词生成配图
    ↓
7. 【v1.2.2】验证图片内容是否与单词匹配 ⭐ NEW
    ├─ 使用 read_image 工具检查图片内容
    ├─ 如果图片内容不匹配，重新生成
    └─ 最多重试2次
    ↓
8. 生成学习总结文档
```

### 图片内容验证（v1.2.2 新增）

**问题**：批量生成时，图片内容可能与单词不匹配（如bedroom的图片显示成dining room）

**解决方案**：
1. 生成图片后，使用 `read_image` 工具检查图片内容
2. 验证图片描述中是否包含正确的单词/场景关键词
3. 如果不匹配，重新生成图片（最多重试2次）
4. 验证通过后，更新卡片Markdown

**验证关键词映射**：
```python
WORD_IMAGE_KEYWORDS = {
    'bedroom': ['bed', 'bedroom', '睡眠', '卧室'],
    'kitchen': ['kitchen', 'cook', '厨房', '烹饪'],
    'bathroom': ['bathroom', 'bath', '浴室', '卫生间'],
    'living_room': ['living room', 'sofa', '客厅', '沙发'],
    'dining_room': ['dining room', 'table', '餐厅', '餐桌'],
    # ... 更多映射
}
```

**异常处理**：
- 图片生成失败：记录错误，跳过该单词的图片
- 内容不匹配：自动重试，重试2次后仍失败则标记为需手动检查
- 路径错误：使用 `computer://` 协议确保扣子APP兼容
