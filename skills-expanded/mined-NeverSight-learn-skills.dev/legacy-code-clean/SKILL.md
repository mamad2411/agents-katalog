默认目标是删除无价值的兼容层、fallback 分支与墓碑代码，但**不能无条件删除**。只有在确认不存在真实仓外消费者、持久化/线上迁移约束、当前支持的平台约束，且人类没有明确要求兼容时，才应直接收敛到当前实现。

若无法证明上述约束不存在，应先查证；仍无法确认时，先向人类搭档确认，而不是凭感觉删除。

**痛点**
系统可能为向后兼容留存了很复杂的各种代码,导致系统变复杂, 最简单的方法是直接清理,不留痕迹.

## 方法和步骤

1. 启动 `子智能体(sub_agent)` 安排详细的任务分析当前源码中的过时代码,并列出清理计划.我统一后执行.
2. 根据智能体的分析结果进行进一步确认.
3. 编写最终报告汇总情况, 报告应当包含后续清理计划, 注意优先级.

## 清理指引

1. 默认不保留仅为兼容旧功能而存在的字段、函数、协议字段、旧入口或 fallback 分支；优先收敛到当前实现。
2. 只有在满足以下至少一项时，才允许保留兼容层：存在真实仓外消费者；存在必须迁移的持久化数据或线上实例；存在当前支持的平台/协议矩阵约束；人类明确要求兼容。
3. 若无法证明存在上述约束，优先删除兼容层并同步修正仓内调用方，而不是继续保留旧壳。
4. 功能源码应优先删除无价值考古残留；测试源码、skill 文档、开发文档则应删除误导性旧真相，或在仍有历史参考价值时明确标注“已过期”，而不是机械全删。
5. 正确加载技能, 了解系统详情. 注意有些系统设计的详细是在技能(skill)文档中的.

## 排除目录

有些代码是通过代码生成器生成的, 应当保留代码生成器的结果, 不应当做任何修改,因为就算修改了重新生成也是会被生成结果覆盖的.

packages/mtmsdk/package.json 里面的script 带 `gen:`前缀的都是生成脚本, 生成的目录有(不限于):
- `packages/mtmsdk/src/sbmng/`


## 技巧和提示

1. 使用`subagent-driven-development`, 合理安排子智能体(sub-agent) 完成相关任务, 例如分析,调研,查找,修复等. 但是必须对 sub agent 的结果进行确认, 必须对结果负责.
2. 子智能体结果只能作为候选线索，主智能体必须回到**当前 HEAD** 重新核验目标路径/符号是否仍存在，再决定是否列为可清理项；不要直接照抄较早报告或子智能体结论。
3. 如果子智能体明显混入了其他仓库、旧 worktree、或与当前 `/workspace/gomtm` 不一致的上下文，必须降级为“只供启发”，随后以当前仓源码为准重做人工确认。
4. 对文档类命中项，优先收敛“仍冒充 current truth 的旧块”；对于已经明确标记 superseded / 已过期 的历史材料，不要机械列为 P0 删除对象，优先改成更短的过期说明和当前真相入口。
5. 对测试中的 `legacy` 文案先区分：它可能只是误导性措辞，也可能是 hard-cut 护栏，不等于对应对象本身就可删。

6. **特征** 
  - 当发现 `fallback testing` 是明显的信号.
  - 当使用兼容旧版字段,旧版状态而使用了条件分支时.
  - 当使用了兼容壳,兼容层,兼容封装时, 时明显信号.
  - 当任务历史,git 提交历史 已经决定了新的技术路线,而相关代码还沿用已经弃用的技术路线时.
  - 墓碑字段
  - 双读双写
  - 补丁代码
  - 其他...

## 要求

1. 当涉及到底层,对系统架构可能产生深远影响的变更时**必须先得到用户的确认**后才能进行.
2. 当涉及公开 CLI / API / 协议 / deep link / Activity 入口 / 数据库存量数据 等潜在 breaking change 时，若是否仍有真实消费者不明确，必须先确认再删。
3. 当使用了subagents 派发相关任务, 你必须对其任务结果进行确认, 必须对结果负责.

## 禁止

- 禁止删除标记为软删除的文件, 除非得到人类的明确允许.
- 禁止删除备份文件.

## 默认范围

当人类用户没有指定范围时,默认以下范围
- 数据库端的设计,包括函数和表结构,特别是数据库函数, 使用各种冗长 fallback,各种条件分支的函数, 应当优先清理.
- gomtm server 端, 各种冗长 fallback,各种条件分支的函数, 应当优先清理. 特别是发现 fallback testing 是明显的信号.
- web 前端 和 app 前端, 各种冗长 fallback,各种条件分支的函数, 应当优先清理. 特别是发现 fallback testing 是明显的信号.

## 线索

如果人类搭档没有明确范围,默认使用以下范围.

- 时间段: 最近的任务
