# OPC Growth: 获客 · 转化 · 交付 · 复购

这个 skill 帮新手从“没人认识我”推进到“有人咨询、有人付款、有人复购”。增长不是先追流量，而是先跑通一个可信的咨询到成交闭环。

## 快速诊断

| 卡点 | 当前任务 | 推荐入口 | 合格产出 |
|------|----------|----------|----------|
| 不知道去哪找客户 | 选择1-2个主渠道 | [平台差异化策略](references/platform-strategies.md) | 渠道选择和7天内容计划 |
| 发了内容没咨询 | 明确CTA和私域入口 | [新手5个Prompt](assets/starter-prompts.md) | 10条带转化目标的内容 |
| 有咨询但不成交 | 建立诊断和报价流程 | [转化5阶段](references/conversion-pipeline.md) | 诊断表、三档报价、异议话术 |
| 交付质量不稳 | 标准化启动和验收 | [标准化交付SOP](references/delivery-sop.md) | 启动清单、自检表、交付说明 |
| 客户不复购 | 设计持续价值和推荐机制 | [复购裂变机制](references/retention-referral.md) | 30天跟进节奏和复购方案 |

## 新手增长漏斗

| 阶段 | 目标 | 动作 | 指标 |
|------|------|------|------|
| 内容/触达 | 让目标用户知道你解决什么 | 每周发布5-7条痛点内容，主动触达20人 | 有回复、有收藏、有私信 |
| 私域沉淀 | 把弱关系变成可跟进线索 | 引导领取模板、填写诊断表或预约交流 | 每周≥5个线索 |
| 需求诊断 | 判断是否值得成交 | 问行业、痛点、预算、时间、决策人 | 诊断表完成率>40% |
| 方案报价 | 降低购买阻力 | 给3档方案，不只报一个价格 | 方案到签约>20% |
| 标准交付 | 降低返工 | 启动清单、过程同步、验收标准 | 返工率<10% |
| 复购推荐 | 提升LTV | 交付后7/14/30天跟进 | 复购率>30% |

## 先做一个渠道，不要全平台铺开

| 用户类型 | 优先渠道 | 内容形式 |
|----------|----------|----------|
| 国内中小企业、个体老板 | 微信、公众号、私域、熟人转介绍 | 案例、避坑、清单、前后对比 |
| 消费者和个人成长类 | 小红书、视频号 | 步骤图、结果展示、经验贴 |
| AI/互联网从业者 | 即刻、公众号、社群 | 复盘、工具链、真实数据 |
| 海外或开发者 | X、LinkedIn、GitHub | Build in public、教程、模板 |

新手选择标准：目标用户在哪里，你能不能连续30天低成本发内容和互动。

## 首单成交脚本

1. **确认问题**：你现在最想解决的是获客、转化、效率还是成本？
2. **量化损失**：这个问题每周大概浪费多少时间或多少钱？
3. **展示相似案例**：我可以先用一个小范围方案验证，不承诺夸张结果。
4. **给三档方案**：低价试点、标准交付、深度定制。
5. **设置下一步**：今天确认诊断表，明天给方案，付款后进入项目群。

## 交付后必须做

- 交付时附使用说明，而不是只丢文件。
- 3-7天后问是否达成目标，主动修复问题。
- 14天后发一个额外洞察或优化建议。
- 30天后给续费、升级或转介绍方案。
