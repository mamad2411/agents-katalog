# パラグラフライティング

## 適用範囲

自然言語による回答の散文段落に、この構成規則を適用する。回答の作成だけでなく、編集、要約、レビューでも同じ規則を判断基準として使用する。表と箇条書きには、段落の文数、メッセージ数、先頭文の太字化に関する規則を適用しない。

## 用語

- **メッセージ**: その段落で読み手に伝える一つの主張、結論、判断、指示、または中心的な情報。
- **先頭文**: 段落のメッセージを、それだけで理解できる形で明示する最初の一文。
- **支持文**: 先頭文の根拠、理由、具体例、または意味を正確にするための補足となる二文目以降の文。
- **必要な情報**: 省くとメッセージの意味、根拠、適用条件、または重要な区別が正しく伝わらなくなる情報。

## 不変条件

- **PW-01 一段落一メッセージ**: 各散文段落の中心的なメッセージを一つだけにする。独立した別のメッセージは別段落に分ける。
- **PW-02 要点先行**: 各散文段落のメッセージを先頭文で明示し、その一文全体を Markdown の `**` で太字にする。
- **PW-03 先頭文の連続性**: 各段落の先頭文だけを順に読んでも、回答全体の要点と論理の流れが通じるようにする。
- **PW-04 支持関係**: 二文目以降を、先頭文の根拠、理由、具体例、または必要な補足だけに限定する。先頭文を支持しない文や別のメッセージを含めない。
- **PW-05 段落長**: 各散文段落をおおむね3〜7文にする。ただし、この文数に合わせるためだけの文を加えない。
- **PW-06 必要最小限性**: 書かなくても想定読者の多くが理解、認識、または想起でき、かつ省いても意味が変わらない情報を省く。正確な伝達に必要な情報が3文分に満たない場合は、不要な支持文を足すより短さを優先する。
- **PW-07 例外形式**: 表と箇条書きは PW-01 から PW-06 の段落単位の制約から除外し、その内容に適した構造を使用できるものとする。

## 判断例

次の段落は規則に適合する。

> **移行日は10月1日に変更された。** 外部監査の完了が当初予定より二週間遅れるためである。既存システムは移行完了まで利用できる。

次の状態は規則に違反する。

- 段落の結論が二文目以降まで現れない。
- 一つの段落で、移行日の変更と無関係な予算承認を同列に伝える。
- 先頭文の言い換えだけを追加して3文に水増しする。
- 先頭文だけを読むと、指示対象や結論同士の関係が分からない。
