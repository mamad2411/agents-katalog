# 小红书大师 Skill

精通小红书生态的顶级内容策划工具，生成爆款笔记方案。

## 功能模块

### 1️⃣ 爆款文案生成
基于输入内容生成完整的小红书笔记，包括：
- 标题（2 个 emoji + 数据化结论 + 获得感承诺）
- 正文（场景痛点 + 解决方案 + 模块化方法论）
- 互动问题（经验共享/观点对抗/资源交换）
- CTA 策略（硬转化 + 软引导）
- 话题标签（基础 + 长尾 + 热点）

### 2️⃣ 热点词库分析
SEO 优化专家模式，生成适配当前热点的词库：
- 热搜词捕捉（平台热搜榜前 50）
- 长尾词扩展（人群 + 场景 + 需求）
- 内容关联词（垂类 + 情绪 + 视觉）

### 3️⃣ 违禁词检测
平台合规审查，五级风险扫描：
- 绝对化用语检测
- 医疗/效果宣称检测
- 站外引流检测
- **搞钱/副业/变现检测（高危！）**
- 价值观导向检测

## 使用方法

## 爆款文案生成规则

### 标题公式
```
2 个领域 emoji + 数据化/颠覆性结论 + 获得感承诺
```
示例：💡🔥用学霸不敢说的 3 个野路子｜学渣逆袭真不难｜附工具包

### 正文结构
1. **共鸣建立**：「经历过 XX 的才懂」「你是不是也...」
2. **解决方案**：个人经历 + 权威加持
3. **方法论**：分步骤说明 + 工具推荐 + 行动清单
4. **低门槛呼吁**：「学生党/打工人友好」「零基础适用」

### 标签矩阵
- 基础标签：#用户话题 #干货分享
- 长尾标签：3 个「人群 + 场景」组合
- 热点标签：2 个站内泛领域热词

### 互动问题模板
- 经验共享：「试过第 2 步的扣 111，效果炸裂的举双手🙌」
- 观点对抗：「A 派 VS B 派！用结果说服对方」
- 资源交换：「私藏神器/书单/模板？带图安利抽奖！」

### CTA 策略
- 硬转化：「完整模板评论区扣【秘籍】自动触发」
- 软引导：「下期揭秘 XX 领域潜规则！关注优先推送」

## 风格指令

✅ 用「咱就是说」「一整个拿捏住」等社区化表达
✅ 关键结论添加❗️💥🔥等 emoji 强调
✅ 植入「刷到这篇你在被大数据拯救」等稀缺暗示
✅ 标注「300 人验证」「亲测 3 月有效」增强可信度

## 违禁词检测规则

### 绝对化用语
🚨 禁用：最/第一/国家级/全网首发/顶级/独家/永久/100%/唯一/首选
✅ 替代：「个人觉得」「实测感受」「热门」「精选」

### 医疗/效果宣称
🚨 禁用：根治/疗效/治疗/处方/消炎/抗敏/7 天/月瘦/白 2 度/无效退款/立刻见效
✅ 替代：「帮助」「可见改善」「持续使用」「逐步改善」

### 站外引流
🚨 禁用：微信号/微信/二维码/外链/私信我/加我/VX/公众号/淘宝/拼多多/京东/下单/购买链接
✅ 替代：「评论区」「主页」「收藏夹」「get 同款」

### 搞钱/副业/变现 ⚠️ 高危！
🚨 禁用：搞钱/赚钱/变现/副业/躺赚/暴富/财富自由/日入/月入/年入/被动收入/睡后收入/零成本/无门槛/小白也能赚/带人赚钱/教你赚钱
🚨 禁用：返利/佣金/分销/代理/加盟/投资/理财/股票/基金/币圈/加密货币/刷单/点赞赚钱/挂机赚钱
✅ 替代：「成长」「自我提升」「价值输出」「知识分享」「技能提升」「财务规划」「经验分享」

### 价值观导向
🚨 禁用：body shame/崇洋媚外/炫富/拜金/歧视
✅ 替代：「自信美」「多元审美」「理性消费」「平等尊重」
