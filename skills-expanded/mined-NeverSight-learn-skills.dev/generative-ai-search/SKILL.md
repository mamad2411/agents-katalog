# Generative AI Search

## Overview

Follow Google’s documented guidance—no invented AI-overview hacks.

## When to Use

- AI features / AI-generated content policies questions

**Not for:** Guaranteeing citation in AI Overviews.

## Official sources

- https://developers.google.com/search/docs/appearance/ai-features
- https://developers.google.com/search/docs/fundamentals/using-gen-ai-content

## Process

1. Read current official AI features / gen-AI content guidance (links above).
2. Optimize fundamentals: people-first content, clear structure, accurate info—same as helpful content.
3. For AI-assisted drafts: human review for accuracy, originality, and trust.
4. Do not claim secret “AI Overview SEO” tricks not in Search Central.
5. Prefer structured, cite-worthy explanations with sources on the page.

## Common Rationalizations

| Rationalization | Reality |
|---|---|
| "There are secret AI Overview ranking hacks." | Follow official AI/gen-AI guidance only; no invented tricks. |
| "AI content always ranks." | People-first quality and accuracy still apply. |
| "Skip human review on AI drafts." | Review for factual errors and originality before publish. |

## Red Flags

- Inventing ranking factors not documented by Google
- Skipping verification ("looks fine")
- Advising spammy shortcuts (cloaking, doorways, link schemes)

## Verification

- [ ] Advice cites official AI/gen-AI docs
- [ ] No unverified AI-overview ranking claims
- [ ] Human review plan for AI-assisted content
