# 数据录入系统

将平台真实数据写入数据统计表，自动计算收/赞比和爆款等级。

## 工作流程

### 第一步：收集数据

如果用户消息里已有数字，直接提取；缺少的字段再询问：

```
需要以下数据：
- 视频标题（用于定位表格行）
- 点赞数
- 收藏数
- 观看数
- 涨粉数（没有可不填）
- 完播率（%）
```

### 第二步：定位表格行

Read `03-数据统计/数据统计表.md`，用标题模糊匹配找到对应行。

- 找到且为 `待填入` 状态 → 继续
- 找不到匹配行 → 告知用户确认标题
- 该行已有数据 → 询问是否覆盖

### 第三步：计算指标

**收/赞比** = 收藏 ÷ 点赞（保留2位小数）

**爆款等级**（按点赞数）：
- 5000+：✈️
- 2000-4999：🚗
- 1000-1999：🛵
- 500-999：🚲
- <500：🚶

### 第四步：写入统计表

用 Edit 将对应行替换，格式：
```
| N | YYYY-MM-DD | 标题 | 分类 | [等级] | [点赞] | [收藏] | [收赞比] | [观看] | [涨粉] | [完播率]% |
```

缺失的涨粉数填 `-`。完播率统一存为 `8.1%` 格式。

### 第五步：同步选题记录

Read `01-内容生产/选题管理/00-选题记录.md`，找到对应条目。

若为 `已完成` 状态，更新为：
```
- [x] [标题] - 已发布（YYYY-MM-DD）
```

### 第六步：自动归档文件

在 `01-内容生产/待发布的内容/中短视频/` 里查找 YAML 中 `发布时间` 已填写的文件（非空），逐一执行：

1. **判断分类**（按 CLAUDE.md 分类规则）：
   - AI工具深度考察：工具测评、商单种草、功能介绍类
   - AI应用开发学习：教程、开发经验、技术科普类
   - 一人公司养成记：个人经历、vlog、工作流分享类

2. **移动文件**：
   `01-内容生产/待发布的内容/中短视频/[名].md`
   → `02-已发布内容/短视频/[分类]/[YYYY年MM月]/[名].md`
   目标目录不存在时先创建。

3. **删除深化报告**：在 `01-内容生产/待深化的选题/` 里查找同名深化报告，存在则删除。

每处理一个文件，输出一行归档确认。

### 第七步：输出确认

```
✅ 已同步：[标题]
等级：[图标] · 点赞 X · 收藏 X · 收/赞比 X · 观看 X · 涨粉 X · 完播率 X%
📁 已归档：02-已发布内容/短视频/[分类]/[年月]/[名].md
```

## 批量录入

用户一次提供多条数据时，逐条处理，最后汇总输出所有已更新条目。
