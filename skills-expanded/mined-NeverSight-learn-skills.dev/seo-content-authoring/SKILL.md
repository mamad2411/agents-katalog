# SEO Content Authoring

## Overview

Produce people-first pages that also satisfy technical SEO gates.

## When to Use

- New landing/article/product copy meant to be indexed

**Not for:** Bulk doorway generation (refuse via spam skill).

## Official sources

- https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- https://developers.google.com/search/docs/fundamentals/seo-starter-guide

## Process

1. Start from intent + outline; gather facts/sources.
2. Write with clear H1 and hierarchical headings; unique title/meta.
3. Add byline/dates when appropriate; strengthen trust cues (`eeat-and-trust`).
4. Add JSON-LD if eligible (`structured-data`).
5. Ensure images have dimensions/alt (`images-and-video-seo`).
6. Self-check `references/definition-of-done-seo.md` before handoff to ship.

## Common Rationalizations

| Rationalization | Reality |
|---|---|
| "Publish now; SEO pass later." | Titles, canonicals, and thin content are harder to unwind after indexation. |
| "Doorway pages for each city will win." | Doorways violate spam policies — refuse. |
| "Schema can wait until after writing." | Eligible types should be planned with the page, not bolted on blindly. |

## Red Flags

- Inventing ranking factors not documented by Google
- Skipping verification ("looks fine")
- Advising spammy shortcuts (cloaking, doorways, link schemes)

## Verification

- [ ] Intent satisfied; no stuffing
- [ ] Title/H1/meta present
- [ ] DoD checklist passed
