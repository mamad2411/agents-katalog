# 学术论文标题 / 摘要 / 关键词生成

三步走，每步提供多个选项 + 理由，用户选定后进入下一步。

## 启动：收集必要信息

启动时收集（在 ta-research-AFP 中已有的信息自动复用，不重复询问）：

1. **研究主题与研究问题**
2. **核心发现**：主题汇总表，或简述3–5个主要发现
3. **理论定位**（A/B/C）及使用的主要理论（如有）
4. **目标期刊类型**：C刊 / SSCI

---

## 第一步：标题生成

生成4个候选标题，覆盖不同写作角度，每个附完整分析。

**四种标题角度**：

**A. 现象聚焦型**
- 格式参考：`[研究对象]的[核心经验/行为/过程]：基于[N]位[被访者]的主题分析`
- 特点：前置研究对象和核心现象，方法清晰可见

**B. 理论对话型**
- 格式参考：`[理论概念]视角下[研究对象]的[机制/过程]研究`
- 特点：前置理论贡献，适合理论驱动型（A定位）研究

**C. 问题导向型**
- 格式参考：`[研究对象]如何[行动/应对/经历][研究现象]？——基于[N]位[被访者]的质性研究`
- 特点：直接提出研究问题，读者即刻理解研究意图

**D. 结论导向型**
- 格式参考：`[核心发现/命名]：[研究对象]在[情境]中的[经验/机制]`
- 特点：以核心发现为题眼，最具吸引力，但需要发现足够清晰可命名

**输出格式**：

```

【选项 A】现象聚焦型
标题：[具体标题]
角度：前置[研究对象]和[核心现象]，方法标注清晰
期刊适配：C刊（审稿人易判断研究范围）/ SSCI 均可
优势：[说明]
风险：[说明]

【选项 B】理论对话型
标题：[具体标题]
角度：前置[理论概念]，信号该研究具有理论贡献
期刊适配：更适合 [C刊/SSCI]（理由：[说明]）
优势：[说明]
风险：[说明]

【选项 C】问题导向型
标题：[具体标题]
角度：直接提出研究问题，读者即刻理解研究意图
期刊适配：均可
优势：[说明]
风险：[说明]

【选项 D】结论导向型
标题：[具体标题]

风险：需要发现足够清晰，否则标题会显得空洞

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
请选择一个标题（A/B/C/D），或说明修改方向。
```

⚠️ **硬停止点**：等待用户选定标题后，进入第二步。

## 第二步：摘要生成

基于已选定的标题，生成3个摘要版本，每个附结构说明和适用场景。

**三种摘要结构**：

**版本A：标准顺序结构**
顺序：研究背景 → 研究问题 → 方法 → 核心发现 → 理论贡献
特点：最常见结构，各要素清晰，审稿人易于逐项评估
篇幅：C刊 250–350字；SSCI 150–200词

**版本B：贡献前置结构**
顺序：核心贡献声明 → 如何得出（方法+数据）→ 主要发现 → 理论意义
特点：首句直接陈述研究贡献，吸引力强，适合贡献清晰的研究
篇幅：C刊 250–300字；SSCI 150–200词

**版本C：发现前置结构**
顺序：核心发现 → 研究背景与问题 → 方法 → 理论贡献
特点：以最重要的发现开头，适合发现特别突出、读者最想知道"结论是什么"的研究
篇幅：视期刊要求而定，同版本A

**输出格式**：

```
━━ 候选摘要 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

---

结构：贡献声明 → 如何得出 → 发现 → 意义
适配：SSCI 首选，研究贡献清晰时也适合 C刊
---
[摘要正文]
---

【版本 C】发现前置结构（[字数]字）
结构：发现 → 背景 → 方法 → 贡献
适配：发现特别突出的研究，C刊/SSCI 均可

```

⚠️ **硬停止点**：等待用户选定摘要后，进入第三步。

## 第三步：关键词生成

基于已选定的标题和摘要，生成2组关键词方案，每组5–8个词，每个词附纳入理由。

**两种关键词策略**：

**方案甲：议题检索型**
- 目的：让研究领域内的读者能搜索到本文
- 侧重：研究对象的核心概念、研究情境词、研究现象词
- 适合：C刊投稿，提升被同领域研究者引用的概率

**方案乙：理论+方法型**
- 目的：让关注方法论和理论对话的读者找到本文
- 侧重：理论名称/核心概念、方法名称（主题分析/质性研究）、学科领域词
- 适合：SSCI投稿，吸引方法论对话者和理论研究者

**输出格式**：

```
━━ 候选关键词 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【方案甲】议题检索型（[N]个词）
关键词：[词1] / [词2] / [词3] / [词4] / [词5] / ...

各词纳入理由：
- [词1]：[为什么纳入，检索价值是什么]
- [词2]：[为什么纳入]
- ...

【方案乙】理论+方法型（[N]个词）
关键词：[词1] / [词2] / [词3] / [词4] / [词5] / ...

各词纳入理由：
- [词1]：[为什么纳入，检索价值是什么]
- [词2]：[为什么纳入]
- ...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
请选择一个方案（甲/乙），或说明自定义组合方式。
```

⚠️ **硬停止点**：等待用户选定关键词后，进行保存。

---

## 输出与保存

三步全部完成后，调用 Write 工具保存：

文件命名：`title_abstract_keywords.md`
保存路径：当前项目目录

文件格式：

```markdown
# 标题
[选定的标题]

# 摘要
[选定的摘要正文]

# 关键词
[选定的关键词，以"/"分隔]
```

告知研究者：
> "标题/摘要/关键词已保存至 `title_abstract_keywords.md`。
> 如在 ta-research-AFP 中，请继续下一检查点（全文引用核查）。"

---

## 语言

- 默认中文
- SSCI 期刊：询问是否需要同步生成英文版（标题+摘要+关键词英文对照）
- 关键词英文对照词在保存时一并标注
