# 模板蒸馏

从成品及其佐证材料中重建可复用的决策结构，而不是复刻个案内容。始终让结论强度与证据强度相称。

## 条件式逆向简报

先判断是否需要显式简报。任务简单且边界明确时，不新增独立的前置轮次；直接分析，并把以下四项压缩并入最终蓝图的“用途与证据边界”：

- **主要对象**：要从哪个对象逆向，以及其他材料如何佐证它。
- **用途**：蓝图将支持什么后续产出或判断。
- **证据边界**：已获得、缺失和未验证的材料分别是什么。
- **输出类型**：默认是“推断蓝图”；只有明确规范足以支撑时，才称为“模板契约”。

只有材料复杂、边界不清或风险较高时，才在分析前显式展开这份简报。简报可以写出暂定假设；仍只有歧义会实质改变主要对象、证据解释、输出类型或高风险结论时，才暂停并询问用户，其他情况下记录假设后继续。

## 分清证据角色

围绕一个主要对象工作。空白模板、说明、标准案例、参考成果或同族案例可以共同佐证它；这些材料只需可访问且角色清楚，不要求物理复制或合并。

- 说明及具有明确规范效力的材料，可支持明示约束。
- 空白模板可显示可用结构和槽位；空白字段本身不证明普遍必填。
- 标准案例、完成案例和参考成果主要显示完成实践；只有其规范效力被明确说明时，才把做法视为硬要求。
- 同族案例可显示重复模式、稳定顺序和条件分支，但重复并不自动等于强制。

按材料内容、来源权威和用途分配角色，不要仅凭文件名或格式判断。

## 从观察到蓝图

1. 先记录可观察证据：层级、顺序、标题、重复单元、字段、条件段落、交叉引用，以及承担实际功能的格式安排。
2. 比较材料间的重复、变化、缺失和冲突，判断哪些结构稳定，哪些只属于当前完成方式。
3. 剥离姓名、日期、机构、数值、结论、示例措辞等个案事实。只有当它们揭示槽位功能、来源规则或内容约束时，才保留为抽象说明。
4. 重建语义结构：每一部分为何存在、前后依赖是什么、读者借它完成什么判断。
5. 提取槽位及其作用、出现条件、内容来源和必填性；无法证明必填时，标为推断或未知。
6. 提取篇幅与内容约束，以及真正承载功能的关键格式约束。装饰性外观不进入蓝图。
7. 让每个关键结论都能回指可观察证据，不以“看起来合理”代替证据。

关键项使用以下状态：

- **明示**：内容或规则在材料中被直接说出，或被模板明确标记。
- **推断**：由重复模式、结构依赖或完成实践支持，但没有直接规定。
- **未知**：现有材料不足以判断。
- **冲突**：不同材料给出不兼容信号，且尚无充分依据裁决。

“明示”描述内容是否被直接说出，不等于硬要求。普通案例里的直接陈述仍可标为明示，但其证据角色可能只是完成实践，规范效力未必存在。状态、证据角色与规范效力或约束强度要分别判断。

## 控制推断强度

- 单个完成案例足以生成“推断蓝图”，但不能据此声称存在严格模板契约、普遍必填性、未出现的分支或硬性篇幅限制。
- 空白模板与案例并用时，把显式约束和完成实践分开呈现。案例中出现的内容不自动成为必填项，模板中留出的空间也不自动成为硬要求。
- 多个来源冲突时保留冲突，不静默平均或择一。只有权威关系有证据时，才据此确定优先级。
- 未观察到某项只表示“未见”，不表示“禁止”；一次出现只证明该做法可行，不证明它普遍适用。

## 默认交付

除非用户指定其他形式，输出一个紧凑的 Markdown 蓝图：

```markdown
# [蓝图名称]
## 用途与证据边界
## 语义结构
## 槽位与条件
## 约束
## 不可识别项
## 复用与验证提示
```

在“槽位与条件”中说明槽位作用、出现条件和内容来源；在“约束”中区分内容、篇幅和功能性格式约束；在“不可识别项”中保留未知与冲突；在“复用与验证提示”中指出正式采用前仍需确认什么。

不要只给状态标签。证据标注仅覆盖会改变复用判断或结论强度的关键语义结构、槽位、条件和约束；低影响说明无需逐项标注或建表。每个这类关键项都要就近保留四类证据属性：简短来源锚点、证据角色、规范效力或约束强度，以及明示、推断、未知或冲突状态。

紧凑不等于隐式省略。若一组表格或列表项共享上述四类属性，可在该组紧邻位置写一条明确的继承声明，说明它适用于每一项，行内只标例外；若没有明确继承声明，每个关键项必须带齐上述四类属性。例如：“（见第 2 节；完成案例实践，非强制；明示）”。这只是自然括注，不是固定 schema。

默认不拆出独立 evidence map。仅当材料很长、来源很多、冲突明显或结论风险较高时，增加简短证据映射，连接候选结论、上述属性及其对复用判断的影响，再给出蓝图。

## 忠实性与工具边界

- 默认做忠实蒸馏，不把 AI 的改良意见混进蓝图。用户明确要求建议时，另设“改良建议（非蒸馏结果）”区，并说明其不属于源材料约束。
- 不做 Word 或 PDF 的高保真复制，也不声称保留分页、坐标、精确版式或机器级填充能力。需要格式执行时，把蓝图交给相应的文档、PDF 或表格专用工具。
- 不扩展为 schema、脚本、reference、parser、模板引擎或格式填充器，也不加入领域案例和大而全的检查清单。
- 本 Skill 不实现多模板拼接。目前没有真实需求支撑这项能力；未来遇到真实案例后，应另行设计和验证，不由本 Skill 自动处理。

## 交付前复核

- 主要对象、用途、证据角色和证据边界是否清楚。
- 个案事实是否已剥离，语义功能是否仍然完整。
- 会改变复用判断或结论强度的关键语义结构、槽位、条件和约束，是否逐项携带上述证据属性，或由紧邻且明确适用于每一项的继承声明覆盖；例外是否已在行内标出，是否避免为低影响项建表，且没有越过证据作强断言。
- 最终蓝图是否紧凑、可复用，并把改良建议与蒸馏结果分开。
