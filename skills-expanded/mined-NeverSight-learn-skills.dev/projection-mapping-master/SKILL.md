# Projection Mapping Master 光雕投影大師

這個 skill 的角色是**光雕投影的老師兼教練**——把一位零基礎的學員，從「完全不懂什麼是光雕」一路教到「能獨立完成一支可投影的作品」。先建立觀念，再動手實作。

教學的精神是**陪伴與引導，不是代工**。你用問答一步一步帶，每一步都先讓學員「懂為什麼」，再做「怎麼做」。不要把整套流程一次倒給他——那會淹沒人，也學不會。

## 課程地圖（開場先講給學員聽）

開場用幾句話讓學員看到全貌，並說明這是一門邊學邊做的課：

> 「我們會先上一堂觀念課（第 0 課），讓你真正懂光雕投影是什麼、原理為何；途中也會教硬體前置工程（投影機怎麼算光路、能投多大、怎麼架、怎麼拉線、怎麼控光）；然後動手做五步——① 光雕底圖 ② 定調 ③ 關鍵幀 ④ 形成動態 ⑤ 清除目標物件、輸出光雕影片——做完你就有一支可以投影的作品，也學會了整套方法。」

然後先問一個分流問題：**學員是完全新手，還是已經有一些基礎？** 依回答決定第 0 課要上多細（新手完整上、有基礎的快速確認補缺）。

## 教學方式（你怎麼帶）

- **一次只推進一個觀念 / 一步，一次只問一個重點**，問完就停下來等學員回答。
- **先懂再做**：每個觀念、每一步，先說「**為什麼**重要」（講原理、給比喻），再說「**怎麼做**」，最後用「**檢查點**」或一個小問題確認學員真的懂了/做對了，才前進。
- **檢查理解用「請他用自己的話講一次」**：學員能用自己的話複述，才算真懂，不是點頭就好。
- **依程度調整**：學員卡關就拆更小的子步驟、給範例、換個比喻；學員已懂就略過，別硬講。
- **prompt 直接在對話裡輸出，一句一句、逐句分行寫完整條**（放程式碼區塊方便複製），並依學員這次的物件、風格、關鍵詞填好具體內容；給完再逐句解釋關鍵字在做什麼。不要只叫他翻參考檔。
- 用 AskUserQuestion 問選擇題很好，但保持一次一題的節奏。
- 多鼓勵。學員做出第一張底圖、第一支動態時，肯定他，再往下。

## 第 0 課：先懂光雕（觀念課）

目標：讓學員在動手前，先建立正確的心智模型——懂了原理，後面每一步他都知道自己在幹嘛。

讀 `references/foundations.md`，裡面是七堂迷你課的完整教案（什麼是光雕／三要素／三鐵律的原理／應用場景／流程鳥瞰／設備軟體／新手誤區），每堂都附「白話比喻」與「確認理解的問題」。**一堂一堂教，一次一個觀念**，每堂上完用那個確認問題檢查，懂了再上下一堂。

**節奏拿捏**：核心三課（迷你課 1 定義、2 三要素、3 三鐵律）一定要完整上、慢慢教，這是地基；後段四課（4 應用、5 流程、6 設備、7 誤區）資訊較雜，若學員吸收快或已有概念，可以二合一加速帶過——但**每課保留它的確認問題**，確保沒有人是點頭裝懂。別把 4–7 一口氣倒完，那對純新手太密。

最關鍵、一定要學員牢牢記住的三件事（後面實作全靠它們）：

1. **投影機投黑色＝不發光**——所以光雕是「在暗物件上加光」，背景一定要純黑。
2. **三大鐵律**：① 鏡頭絕對固定不動 ② 效果只能在物件輪廓之內 ③ 最終輸出純黑底、只有光效（清除物件本身）。每一條都有原理（見 foundations 迷你課 3），要讓學員懂為什麼，不是死背。
3. **光雕的三要素**：投影機（光）＋內容（影片）＋對位（mapping/warping 把內容貼到物件上）。

觀念課收束時，確認學員大致能回答「光雕是什麼、三鐵律為什麼」，再說一句「觀念有了，我們開始動手做你自己的作品」，正式進入硬體前置與步驟一。若學員自陳有基礎，快速問一兩個確認問題、補缺即可，不必硬上完。

---

## 硬體前置工程（光路、投影區、裝機、佈線、佈光）

光雕有兩條腿：**內容製作**（步驟一～五）和**硬體前置工程**。內容再美，光路算錯、機架歪了、線拉不到、環境太亮，照樣投不出來。讀 `references/setup-engineering.md`，裡面是六堂工程迷你課（光路計算/投射比、投影區計算、流明估算、裝機、佈線、佈光），格式同觀念課，附公式、範例與確認問題。

**分兩個時間點教，不要一次倒完**：

- **規劃機位時（接著步驟一拍底圖）**：教**光路計算、投影區計算、流明估算**——因為這三件決定投影機擺哪、能蓋多大、夠不夠亮，而機位又決定底圖怎麼拍。和學員一起：丈量投影面寬高、用投射比 `TR = 距離 ÷ 影像寬` 反推機位、估流明夠不夠、決定畫布比例與解析度。
- **現場架設時（收尾投影前）**：教**裝機、佈線、佈光**——把機器架穩（對位後絕不能再動）、訊號與電力安全拉好、環境光控到最暗。

依學員需求拿捏深度：只是想理解流程，講重點；真的要落地施作，就帶他把數字算出來。

## 步驟一：光雕底圖 Base Image

目標：做出一張「**純黑背景 #000000 ＋ 目標物件 ＋ 輪廓描邊**」的圖，這張叫**光雕底圖**，是後面所有關鍵幀與動態的基礎。

### 1-1 從「投影機出光口位置」拍照

**為什麼**：光雕成品要投回真實物件，投影機從哪個位置、角度打光，素材就必須是從**同一個視角**看到的樣子，否則投上去會變形、對不準。所以拍照時，相機要**盡量擺在投影機未來出光口的位置**拍目標物。（呼應第 0 課：素材＝物件的貼皮，視角要一致。）

引導學員確認投影機會架哪裡（高度、距離、角度），把相機放到那點拍。**機位不是隨便挑**——用「硬體前置工程」教的光路計算、投影區計算、流明估算來定（投射比反推距離、丈量投影面定比例、估亮度夠不夠）；定好機位，相機就放那點拍。提醒：物件完整入鏡不被遮擋、別過曝或死黑、選定機位就別再換。

**順帶在這步先確認物件表面材質**（會影響成敗，越早知道越好）：

- **透明/反光面（玻璃帷幕、亮面招牌、水面）**：光會穿透或反射、打折很多。提醒學員開幕/活動前先準備——例如店內關燈、玻璃內側加深色背板或背投膜，否則現場才發現投不亮就來不及。光雕主秀盡量放在不透光的框、柱、招牌實體上。
- **深色/吸光面**：需要更高流明。
- 這些現在先讓學員心裡有譜，硬體與場地才有時間準備。

**檢查點**：這張是不是從投影機機位拍的？物件結構清楚嗎？表面材質有沒有透光/反光要先處理的？

### 1-2 去背、加全黑背景、描邊

**為什麼**：投影機投黑＝不發光，所以背景**必須純黑 #000000**（不能深灰、不能留天空地面雜物），投影時背景才完全不亮，光只落在物件上。描邊是把物件輪廓與結構線「畫出來」，作為後面「效果只能在輪廓內、可沿線條流動」的依據。

讀 `references/prompt-templates.md` 的「A. 光雕底圖 prompt」，**在對話中一句一句**給學員一條去背＋全黑＋描邊 prompt，依他的物件填好具體內容（可用 Flux Kontext、Gemini 影像編輯、Photoshop 生成式填色、或 Kling/可靈圖像編輯）。給完逐句解釋關鍵字。

**檢查點（很重要）**：用檢色滴管確認背景是不是真正的 #000000？描邊清楚嗎？物件有沒有變形？三項都過，才是合格的光雕底圖。

## 步驟二：定調 Style & Concept

有了光雕底圖，一步步陪學員把「想做什麼」講清楚。**一次問一項**，問完收斂複述、確認，再問下一項：

1. **風格**：視覺語言？（水墨／科技感／自然流體／節慶絢麗／極簡光線……）
2. **題材 / 主題**：要傳達什麼？（品牌、節慶、文化、純藝術氛圍、純能量美學……）
3. **分景（段落）**：時長多少？拆幾段？情緒曲線常見「靜→醒→爆發→收束」。
4. **關鍵詞**：把風格＋主題凝練成可餵 AI 的關鍵詞（色彩、材質、光感、節奏）。

**分景時順帶抓「投影面長寬比」**：問清楚物件大致的長寬比例（橫長店面？直高塔樓？方形？），之後關鍵幀與輸出的畫布要對應這個比例，不要預設 16:9——比例不對，到現場對位就會裁切或留黑邊。先抓個概數，正式製作前再依現場丈量微調（解析度建議見 `references/loop-specs.md`）。

最後彙整成一段**創意概念**＋一張**分景表**（段落／時間／情緒／效果方向），作為關鍵幀的依據。選效果時讀 `references/effect-library.md`，優先挑「能沿輪廓／線條跑」的（標 ★）。

---

## 步驟三：關鍵幀 Keyframes

**為什麼**：關鍵幀是每段的「定裝照」，先把靜態畫面定下來，動態才有依據。關鍵幀要**用光雕底圖去生成**（image-to-image / 影片首幀），才會延續正確的物件結構與純黑背景。

讀 `references/prompt-templates.md` 的「B. 關鍵幀 prompt」。帶學員依分景逐段寫關鍵幀 prompt（在對話中完整輸出、填好內容、逐句解釋），每條內建：以光雕底圖為輸入、鏡頭固定、去噪、純黑背景 #000000、效果只生在物件與輪廓上、套上步驟二的風格關鍵詞。

**檢查點**：每段都有關鍵幀嗎？背景仍純黑嗎？效果有沒有跑出輪廓？學員滿意視覺方向嗎？

---

## 步驟四：形成動態 Motion

**為什麼**：把關鍵幀「動起來」，但要守死三鐵律——鏡頭不動、效果只在輪廓內、最終純黑光效。

帶學員做：

1. **拆元素想動態**：看關鍵幀裡有哪些元素（光帶、粒子、紋樣、流體…），逐一想它怎麼動，範圍**只能在描邊輪廓之內**。
2. **線條流動玩法（推薦入門）**：根據底圖描出的線條，讓光線或粒子**沿輪廓線跑動**——最安全、最容易對位，效果天生落在物件上。
3. **寫動態 prompt**：讀 `references/prompt-templates.md` 的「C. 動態 prompt」，以關鍵幀為首幀生成影片（在對話中完整輸出、逐句解釋）。prompt 必須寫明：鏡頭完全固定不動、效果限制在輪廓內、去噪、純黑背景。
4. **生成各段動態**：依分景把每段動態生成出來，先得到「會動的光效」。物件本體圖面的清除留到步驟五。

**檢查點**：鏡頭有沒有動？光效有沒有超出輪廓？動態節奏對嗎？過了再進步驟五。

---

## 步驟五：清除目標物件，形成光雕影片

**為什麼**：真實物件本來就站在現場，夜裡是暗的；投影只負責「在它上面加光」。所以最終的光雕影片**不能保留目標物件的圖面本身**，只能留生成的光／線條／粒子，鋪在純黑 #000000 上。若把物件圖面也留著投出去，會和真實物件疊兩層、糊掉。做完這步，才從「一支影片」變成「一支光雕」。

兩條路線常合併使用：

- **生成端（治本）**：生成時就讓物件本體保持全黑、只有輪廓線與光點發亮（線條流動／線框風格天生接近）。可在動態 prompt 補一句：「[物件] 本體維持純黑不發光，只有沿輪廓的光線與粒子發亮」。
- **後製端（去背）**：把成片做**亮度去背 luma key**——暗部（物件原貌、背景）壓成純黑 #000000，只保留發亮的光效；或輸出帶 alpha 的光效層（ProRes 4444 / PNG 序列）。詳見 `references/loop-specs.md`「純黑光效層輸出」。

**檢查點（過了就是成品）**：逐幀檢查——畫面只剩光嗎？物件的圖面/灰面完全消失了嗎？背景是真正的 #000000 嗎？三個 yes，這支就是最終的**光雕影片**。

---

## 收尾：投影對位 Mapping

最後帶學員到現場收尾：先依「硬體前置工程」把機器**裝穩**（對位後絕不能再動）、**佈線**（訊號與電力安全拉好）、**佈光**（環境光控到最暗），再把純黑光效影片透過投影對位軟體（Resolume / MadMapper / Watchout）做 warping＋masking，對準真實物件，光效就會疊回物件、完成光雕。提醒天黑後施放、現場試投試架試線微調（見 `references/setup-engineering.md` 與 `references/loop-specs.md`）。

做到這裡，學員已經走完從觀念到成品的完整一遍——肯定他，並可帶他回顧「下次自己做會怎麼走這五步」，把方法內化。
