# Psychology Persuasion

## 何时使用

- 需要提升产品的转化率或说服力
- 需要设计引导用户行为的交互
- 需要理解用户决策的心理机制
- 需要设计社会证明、稀缺性等说服元素

## 工作流程

### Step 1: 识别说服目标

明确要引导的用户行为：
- 是注册、购买、分享还是留存？
- 用户当前的决策阻力是什么？
- 用户处于决策的哪个阶段？

### Step 2: 选择说服策略

根据场景选择合适的心理学原理：
- 社会证明：他人也在用
- 稀缺性：限时限量
- 锚定效应：价格/数字参照
- 互惠原则：先给予再索取
- 承诺一致性：小步骤引导大行动

### Step 3: 设计说服机制

将策略融入产品设计：
- 文案措辞、视觉暗示、交互流程
- 确保不越过伦理红线（参考 Skill 32）
- 设计 A/B 测试验证效果

### Step 4: 评估效果

量化说服效果：
- 转化率变化
- 用户反馈/NPS
- 长期留存是否受影响（避免短期套路伤害长期信任）

## 关键原则

| 原则 | 说明 |
|------|------|
| 影响不是操控 | 好的说服是双赢，帮用户做出对他更好的决策 |
| 具体 > 抽象 | "帮你每天省2小时" > "提升效率" |
| 相似性增加信服 | 用户更信任和自己像的人的推荐 |
| 减少决策数量 | 每多一个选项，转化率下降 |
| 预期管理 | 承诺 80 分，交付 100 分，用户记住的是 +20 |

## 落地模板

```markdown
# 转化文案设计：[页面/功能名称]

## 1. 目标
- 转化目标：[让用户做什么——注册/购买/分享/...]
- 当前转化率：[X%]
- 目标转化率：[Y%]

## 2. 用户心理画像
- 用户此刻的心理状态：[犹豫/好奇/焦虑/兴奋]
- 最大顾虑：[怕什么——贵/不好用/浪费时间/隐私]
- 决策动力：[想要什么——效率/认可/安全/省钱]

## 3. 说服策略选择
### 主策略（选1-2个）
- [ ] 社会证明："[具体数字]位[具体人群]已经在用"
- [ ] 框架效应：正面框架 / 损失框架
- [ ] 互惠先行：先给[免费价值]，再请求[转化行为]
- [ ] 门槛递进：先让用户做[低门槛行为]
- [ ] 稀缺性：[时间限制/名额限制]——是否真实？
- [ ] 权威背书：[谁推荐了/什么认证]

### 辅助策略
- [ ] 启动效应：页面视觉/开头文案引导什么情绪？
- [ ] 减少选择：精简到最少几个选项？
- [ ] 默认选项：预选最希望用户选的选项
- [ ] 预期管理：承诺少于能交付的

## 4. 文案设计
### 标题（3秒抓住注意力）
- 方案A：[...]
- 方案B：[...]

### 核心卖点（10秒建立价值）
| 卖点 | 用户语言版本 | 心理效应 |
|------|------------|---------|
| [功能1] | [用户熟悉的说法] | 框架效应/社会证明/... |
| [功能2] | | |

### CTA（行动号召）
- 按钮文案：[不是"提交"，而是"开始免费试用"]
- 辅助文案：[消除最后的顾虑——"无需信用卡"/"随时取消"]

## 5. A/B 测试计划
| 测试 | 变体A | 变体B | 假设 | 样本量 |
|------|-------|-------|------|--------|
| 标题 | [正面框架] | [损失框架] | 损失框架转化更高 | |
| CTA | [低门槛] | [直接转化] | 低门槛先行更好 | |

## 6. 伦理检查
- [ ] 所有社会证明数据真实
- [ ] 稀缺性声明真实
- [ ] 没有利用用户恐惧/焦虑
- [ ] 用户做出决策后不会后悔
```
