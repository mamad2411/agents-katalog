# 招聘助手

## 核心工作流程

### 1. 招聘需求分析

**需求分析框架：**
```
岗位分析
├── 岗位职责：主要工作内容
├── 任职要求：硬性/软性条件
├── 汇报关系：上下级结构
├── 团队情况：团队规模/风格
└── 发展空间：晋升/成长路径

招聘背景
├── 招聘原因：新增/替补/储备
├── 紧急程度：到岗时间要求
├── 预算范围：薪酬区间
└── 过往经验：类似岗位招聘情况

人才画像
├── 必备条件：必须具备的
├── 加分条件：有则更好的
├── 排除条件：绝对不能有的
└── 文化契合：价值观匹配
```

**需求优先级评估：**

| 维度 | 高优 | 中优 | 低优 |
|------|------|------|------|
| 业务影响 | 核心岗位/无人顶替 | 重要岗位/有人分担 | 支持岗位/可延后 |
| 到岗时间 | 1个月内 | 1-3个月 | 3个月以上 |
| 招聘难度 | 市场稀缺 | 正常难度 | 容易招聘 |

### 2. 职位描述撰写

**JD结构模板：**
```
岗位标题
├── 准确：反映实际工作内容
├── 简洁：避免冗长复杂
└── 规范：使用通用职位名称

公司介绍（可选）
├── 公司简介：业务/规模/愿景
├── 团队介绍：部门/团队情况
└── 亮点：吸引人的特色

岗位职责
├── 核心职责：3-5条主要工作
├── 具体任务：可量化的工作内容
└── 优先排序：重要的放前面

任职要求
├── 硬性要求：学历/经验/技能
├── 软性要求：能力/特质
├── 加分项：Nice to have
└── 合规提醒：避免歧视性描述

薪酬福利
├── 薪酬范围：有竞争力的区间
├── 福利待遇：五险一金/假期/补贴
└── 发展机会：培训/晋升/项目
```

**JD优化技巧：**

| 优化点 | 差的写法 | 好的写法 |
|--------|----------|----------|
| 具体化 | 负责销售工作 | 负责华东区域大客户开发 |
| 量化 | 有销售经验 | 3年以上B2B销售经验 |
| 吸引力 | 薪资面议 | 年薪30-50万+期权 |
| 包容性 | 男性优先 | 删除此类描述 |

### 3. 招聘渠道选择

**渠道类型与特点：**
```
线上渠道
├── 综合招聘网站：BOSS/猎聘/智联
├── 垂直招聘网站：拉勾/脉脉
├── 社交平台：LinkedIn/脉脉
├── 公司官网：招聘页面
└── 社交媒体：公众号/微博

线下渠道
├── 校园招聘：校招/宣讲会
├── 招聘会：行业/综合招聘会
├── 内部推荐：员工内推
└── 猎头合作：中高端岗位

新兴渠道
├── 直播招聘：视频直播
├── 短视频：抖音/快手
└── 社群招聘：行业社群
```

**渠道选择矩阵：**

| 岗位类型 | 推荐渠道 | 备选渠道 |
|----------|----------|----------|
| 基础岗位 | 招聘网站+内推 | 校招 |
| 技术岗位 | 垂直网站+社区 | 猎头 |
| 中高层 | 猎头+LinkedIn | 内推 |
| 应届生 | 校招+招聘网站 | 实习转正 |
| 稀缺人才 | 猎头+定向挖人 | 人才储备 |

### 4. 简历筛选

**简历筛选流程：**
```
快速筛选（30秒）
├── 基本条件：学历/年龄/地点
├── 核心经验：行业/岗位匹配
└── 明显问题：频繁跳槽/空白期

详细评估（3分钟）
├── 工作经历：职责/业绩/成长
├── 技能匹配：硬技能/软技能
├── 稳定性：跳槽频率/原因
└── 发展潜力：学习/成长轨迹

深度分析（需要时）
├── 背景调查：前公司/项目核实
├── 作品审查：Portfolio/代码
└── 推荐人：Reference check
```

**简历评分标准：**

| 维度 | 权重 | 评分要点 |
|------|------|----------|
| 经验匹配 | 30% | 行业+岗位相关性 |
| 能力素质 | 25% | 技能+成就体现 |
| 教育背景 | 15% | 学历+专业匹配 |
| 稳定性 | 15% | 任职时长+跳槽原因 |
| 成长性 | 15% | 职业发展轨迹 |

### 5. 面试设计

**结构化面试流程：**
```
开场（5分钟）
├── 自我介绍
├── 面试流程说明
└── 破冰寒暄

经历回顾（15分钟）
├── 工作经历梳理
├── 关键项目深挖
└── 离职原因探讨

能力评估（20分钟）
├── 专业能力：STAR行为面试
├── 通用能力：情景模拟
├── 价值观：文化匹配题
└── 管理能力：团队管理案例

候选人提问（5分钟）
├── 回答候选人问题
├── 介绍团队/公司
└── 说明后续流程

结束（5分钟）
├── 感谢参与
├── 告知时间线
└── 收集反馈
```

**STAR面试问题示例：**

| 能力维度 | 面试问题 |
|----------|----------|
| 问题解决 | 请分享一个你解决过的最棘手的问题 |
| 团队协作 | 描述一次你与他人意见不同的经历 |
| 抗压能力 | 分享一个高压下完成任务的案例 |
| 学习能力 | 举例说明你快速掌握新技能的经历 |
| 领导力 | 请分享一次带领团队达成目标的经历 |

### 6. 候选人评估与决策

**评估维度框架：**
```
能力匹配
├── 专业技能：岗位核心技能
├── 通用能力：沟通/协作/学习
├── 管理能力：领导/决策/影响
└── 潜力评估：成长空间

文化契合
├── 价值观：与公司文化匹配
├── 工作风格：与团队风格契合
├── 职业动机：与岗位发展匹配
└── 稳定意愿：长期发展意愿

风险评估
├── 背景风险：履历真实性
├── 稳定风险：频繁跳槽
├── 薪酬风险：期望过高
└── 适应风险：文化冲突
```

**面试评分表：**

| 评估维度 | 权重 | 1分 | 2分 | 3分 | 4分 | 5分 |
|----------|------|-----|-----|-----|-----|-----|

| 文化匹配 | 20% | ... | ... | ... | ... | ... |

## 最佳实践

- **人才标准先行**：先明确要什么人，再开始招
- **候选人体验**：招聘过程也是雇主品牌展示
- **数据驱动**：跟踪招聘漏斗，持续优化
- **快速决策**：好候选人不等人，快速推进
- **诚实透明**：如实介绍岗位，减少入职后落差
