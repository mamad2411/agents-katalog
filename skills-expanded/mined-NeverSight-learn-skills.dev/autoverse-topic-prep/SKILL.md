# Autoverse Topic Prep

帮助学生把一个宽方向变成可信、可讨论、可继续推进的研究认识。Agent 主导问题拆解、探索、分析和表达；Autoverse 提供结构化论文发现；Agent 的原生网络能力用于补充近期进展和核验官方来源。

## 工作方式

- 先理解用户接下来要做的决定，例如选切口、和导师讨论、安排阅读或准备开题。只有范围差异会明显改变结果时，才集中问一个简短问题；其余使用合理默认继续。
- 把宽方向拆成互补的研究问题，例如概念与边界、主要方法、评价方式、应用、争议和近期变化。分面用于打开不同视角，不是固定数量或同义词替换任务。
- 使用 Autoverse 反复检索、解析和追踪有价值的线索；根据结果调整关键词、扩大或收窄范围，不以调用次数或搜索排名代替研究判断。
- 使用 Agent 原生网络搜索发现新工作、澄清术语，并打开 DOI、出版社、会议、PubMed 或 arXiv 等官方页面核验关键记录。Autoverse 与网络可以交替使用。
- 综合比较论文的研究问题、方法、数据、评价方式、结论与局限，形成领域结构、关键分歧和建议起点，而不是生成一份未经分析的论文列表。

常用调用示例：

```text
autoverse --json --quiet search "<research question>"
autoverse --json --quiet resolve <prefixed-id>
autoverse --json --quiet related <paper-id> --via similar
```

需要示例之外的参数或 CLI 排障时再读取 `autoverse-cli` 或命令帮助，不猜旗标。

## 证据表达

论文身份、标识符和关键结论应能回到实际读取的记录或官方页面；摘要只能支持摘要范围内的判断。网络搜索可以补充发现和核验，但不能自动证明论文之间存在引用关系。方法相关、主题相近和真实引文需要用不同语言或线型表达。

证据不足或来源冲突时把不确定性保留下来。工具暂时不可用时可以继续利用其他可核验来源，但要说明覆盖范围，不把模型记忆包装成检索结果。

## 结果表达

根据内容选择合适组合，例如：

- 领域地图或概念关系；
- 核心论文比较表；
- 方法演进或时间线；
- 建议阅读顺序与入门切口；
- 主要争议、证据空缺和适合与导师确认的问题。

图表用于降低理解成本，而不是作为固定交付数量。默认在对话中给出完整结果；用户要求简报、开题材料、保存或导出时，再生成相应文件。未指定格式时可使用包含必要图表的 Markdown，也可以按需求生成 Word、PDF、表格、CSV 或 BibTeX。正式交付聚焦研究内容和证据边界，不展示命令与技术排障过程。
