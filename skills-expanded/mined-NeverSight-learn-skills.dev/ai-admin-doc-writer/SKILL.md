# AI 친화적 행정문서 작성 (ai-admin-doc-writer)

행정안전부 「AI 시대 행정문서 작성 가이드라인」을 따르는 한국어 행정문서를
작성하고, 한글에서 열리는 **HWPX 파일**로 산출하는 스킬이다.

## 언제 사용하는가

- 계획(안), 보고서, 공문 등 **행정문서를 새로 작성**해 달라는 요청
- "AI 친화적 문서", "가이드라인에 맞게", "서술식으로", "한글 파일로" 등의 요청
- 결과물을 **HWPX(한글) 파일**로 받고 싶어 하는 경우

## 작성 절차

1. **내용 설계**: 사용자의 주제로 문서 구조(제목 → 요약 → 배경 → 주요내용 → 향후계획 등)를 잡는다.
2. **가이드라인 적용**: `guideline.md`의 5대 규칙을 반드시 지켜 본문을 작성한다.
   특히 개조식이 아닌 **서술식(주어+서술어)** 문장으로 쓰고, **문서 맨 앞에 요약**을 둔다.
3. **마크업 작성**: 아래 줄 단위 마크업으로 원고(`.md`)를 만든다.
3. **HWPX 생성**: `build_hwpx.py`로 변환한다.
   ```
   python3 build_hwpx.py 원고.md 결과.hwpx
   ```
   (`template.hwpx`의 함초롬바탕 서식을 자동으로 사용한다.)
4. **결과 전달**: 생성된 `.hwpx` 파일을 사용자에게 제공한다.

## 입력 마크업

| 줄 시작 | 의미 |
|---|---|
| `# 제목` | 문서 제목 |
| `> 문장` | 요약 문단 (문서 앞부분) |
| `1.` / `가.` | 번호 항목(대제목, 굵게) |
| `□` 또는 `[]` | □ 대항목 |
| `○` 또는 `* ` | ○ 중항목 |
| `- ` | - 세부항목 |
| `·` 또는 `. ` | · 세부항목 |
| (그 외 일반 줄) | 서술식 본문 문단 |

특수기호(□ ○ - ·)는 스크립트가 **유니코드 문자로 자동 출력**하므로, 규칙을 자동으로 만족한다.

## 핵심 규칙 요약 (자세한 내용은  참고)

- **서술방식**: 주어·서술어를 명확히 한 서술식. 개조식 지양. 문서 앞에 요약 필수.
- **항목표시**: `Ⅰ. → 1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮` 순서, 특수기호 `□ ○ - ·`.
- **편집·서식**: 함초롬바탕, 자간 0%, 장평 100%, 줄 간격 150%, 문단 위 10pt (템플릿에 반영됨). 제목에 표·박스 금지.
- **표**: 셀 병합·표 안의 표·대각선 금지. 조직도·일정표는 **서술식으로 설명**.
- **그림**: 차트·조직도·인포그래픽은 필요시만, **그림 설명을 본문에 텍스트로** 반드시 포함.

## 구성 파일

- `guideline.md` — 5대 규칙 상세
- `item-numbering.md` — 항목 기호 순서·유니코드 표
- `examples.md` — 개조식→서술식, 표→서술식 변환 예시
- `template.hwpx` — 함초롬바탕 서식 기준 템플릿
- `build_hwpx.py` — HWPX 생성 스크립트
