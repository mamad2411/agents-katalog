# Bounty Hunter Starter Pack

## Overview
Free, open-source OpenClaw skill package for bounty hunters and automation agents.

## Features
- Evidence-first execution rules
- Smart model routing patterns  
- Task freeze and recovery discipline
- Memory management and durable learning

## Installation
```bash
# Clone repository
git clone https://github.com/henrylu884-wq/bounty-hunter-starter-pack.git

# Run install script
cd bounty-hunter-starter-pack
./install.sh
```

## Usage
The skill automatically applies when:
- Starting new bounty tasks
- Managing task state transitions
- Handling evidence submission
- Routing complex reasoning tasks

## Configuration
Edit `config.yaml` to adjust rule behavior:
- Enable/disable specific rules
- Set validation strictness
- Configure model routing preferences
