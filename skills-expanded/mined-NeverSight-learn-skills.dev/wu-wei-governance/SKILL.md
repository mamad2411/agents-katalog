# wu-wei-governance（无为治理模型）

## R — 原文 (Reading)

> “道常无为而无不为，侯王若能守之，万物将自化。”（第37章）
>
> “治大国若烹小鲜。”（第60章）
>
> — 老子，《道德经》

---

## I — 方法论骨架 (Interpretation)

无为治理不是“不作为”，而是“少妄为”。
核心目标是把治理者从“直接操盘者”转为“边界与节奏设计者”。
路径是三段：先减干预，再放自组织，最后达成“无不为”的结果。
“治大国若烹小鲜”要求最小翻动：复杂系统怕频繁搅动。
“我无为而民自化”要求把秩序从外控改为内生。
配套子模型一：最小干预——只动关键杠杆，不做全域高压。
配套子模型二：道德退化诊断——当组织开始堆流程、堆口号、堆仪式，通常说明底层信任在塌。
因此治理重点不在“加规则”，而在“修底层”：恢复信任、降低摩擦、减少私欲性指令。

## A1 — 书中的应用 (Past Application)

### 案例 1: 道常无为而无不为（c31/p46/p73）
- **问题**: 系统效率低，是继续加管控还是减干预？
- **方法论的使用**: 以“无为→自化”重构治理，去掉非必要动作。
- **结论**: 先减法，再观察系统自修复能力。
- **结果**: “无为而民自化”，秩序从强制变为内生。

### 案例 2: 治大国若烹小鲜（f22/p70）
- **问题**: 大系统为何越改越坏？
- **方法论的使用**: 按“少翻动、控火候、稳节奏”治理复杂系统。
- **结论**: 频繁改动本身就是风险源。
- **结果**: 干预频次下降后，系统稳定性提升。

### 案例 3: 道德退化序列（f10/p38）
- **问题**: 为什么组织突然迷恋流程与口号？
- **方法论的使用**: 用“道→德→仁→义→礼”诊断形式化上升是否掩盖底层失衡。
- **结论**: 形式越密，往往越需回修信任与本体秩序。
- **结果**: 治理重点从“继续加码规则”转向“修复根因”。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 团队流程、审批、检查持续增加，但产出下降、内耗上升。
2. 领导频繁发布指令，组织越来越依赖上级拍板。
3. 社区/平台规则越来越细，绕规则与对抗行为同步增长。
4. 组织口号和仪式突然增多，真实协作与信任变差。
5. 大系统频繁改版/改政策后稳定性显著下降。

### 语言信号 (用户的话里出现这些就应激活)

- “为什么我们越管越乱？”
- “我不盯就不动，一盯就更乱，怎么办？”
- “流程越来越多，结果反而更差。”
- “怎样做最小干预，还能把事做成？”

### 与相邻 skill 的区分

- 与 `water-strategy` 的区别: 本 skill 处理内部治理与系统设计；water-strategy 处理外部竞争位势。
- 与 `dialectical-reversal` 的区别: 本 skill 处理治理动作本身；dialectical-reversal 处理趋势反转预判。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **做“干预审计”并删减非必要动作**
   - 动作: 盘点现有规则/审批/汇报，标记“必要/可删/可并/可延后”。
   - 完成标准: 至少删减或合并20%的非关键治理动作，并公布清单。
> ⏸️ **用户确认点**: 将上述分析结果呈现给用户，确认方向正确后再进入下一步。如果用户对分析有异议，返回步骤1调整。

2. **建立“最小干预+自组织”机制**
   - 动作: 只保留关键边界（目标、底线、反馈周期），把执行权下放给一线。
   - 完成标准: 明确3类边界（目标、风险、节奏）与责任人；一线可在边界内自主决策。
   - 判停条件: 若出现红线风险（安全/合规/重大事故），立即退出最小干预模式并启用应急刚性治理。
> ⏸️ **用户确认点**: 将方案呈现给用户审批。用户可选择：✅ 执行 / 🔄 调整方案 / ❌ 放弃。仅在用户确认后进入执行步骤。

3. **运行“道德退化诊断”并修根因**
   - 动作: 每周检查是否出现“口号增多、流程增多、信任下降、绕行增加”四信号；命中即做根因修复。
   - 完成标准: 输出诊断记录与修复动作；至少1个根因被替代为结构性改进（非再加规则）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 处于应急态（事故处置、法律强制、财务舞弊）时，必须先刚性止损。
- 系统尚无基本边界（目标、角色、底线全缺失）时，先建最小规则再谈无为。
- 领导者将“无为”误解为甩手不管或逃避责任时。

### 作者在书中警告的失败模式

- **ce02 强行掌控天下**: 把复杂系统当可随意摆布对象，最终“为者败之，执者失之”。
- **ce06 过度管控与繁法滋乱**: 规则越密，投机与绕行越多。
- **ce07 察察式精细管理**: 过度审查导致表演性合规，组织失血。
- **ce10 以智巧治国**: 套路化治理侵蚀信任，协作成本飙升。

### 作者的盲点 / 时代局限

- 老子框架偏君主制语境，对现代民主治理、复杂监管和科技系统的“必要有为”讨论不足。
- “无为可治”不能覆盖所有公共问题；现代场景常需“有边界的主动干预”。

### 容易混淆的邻近方法论

- 容易与“放任不管”混淆：无为是**不妄为**，不是无边界。
- 容易与“反规则”混淆：本 skill 反对的是规则堆叠，不反对关键规则。
