**重要提示** 当前技能文档处于开发阶段, 如果没有明确允许不要主动执行.

通过 api 提供的基本操作原语完成 android 模拟操作.

## 关键点

- 不是通过 adb 完成操作, 而是通过 **api** 完成操作.
- adb 仅用来完成诊断, 程序安装,调试,等底层的兜底操作.
