# baby-name — 八字命名顾问

把传统四柱八字 + 熊崎氏五格 + 命局联动审查 + 现代审美耐久度，组合成一套统一 100 分制的命名方法。

## 何时启用

- 用户输入 `/baby_name` 或在对话中描述了新生儿命名需求
- 用户提供了姓氏 + 性别 + 阳历出生年月日时间
- 用户要求"起名 / 取名 / 命名报告 / baby name / 八字算名"

## 必需输入

| 字段 | 示例 | 说明 |
|---|---|---|
| 姓氏 | 刘 | 单字或复姓 |
| 性别 | 男 / 女 | 影响 F 维度（性别契合）评分 |
| 阳历生日 | 2020-06-14 | 年-月-日 |
| 出生时间 | HH:MM | 24 小时制，需精确到分钟 |
| 出生地 | 城市名（可选） | 真太阳时校正用，缺省按东八区 |

输入不全时，必须**逐项追问补齐**，不可猜测。

## 输出结构（强制顺序）

报告按以下 8 章输出，章节标题、表格列名必须与本规范完全一致，便于跨案例对比。

### 第一章 · 八字命盘

| 柱 | 年柱 | 月柱 | **日柱** | 时柱 |
|---|---|---|---|---|
| 干 |  |  |  |  |
| 支 |  |  |  |  |
| 五行 |  |  |  |  |
| 藏干 |  |  |  |  |

- **日主**：x（强/弱判定）
- **格局**：一句话
- **关键象**：合冲刑害一句话

### 第二章 · 五行分布与喜忌神

```
五行加权统计（含藏干）：
| 五行 | 木 | 火 | 土 | 金 | 水 |
| 加权 |    |    |    |    |    |
```

| 类别 | 五行 | 作用 |
|---|---|---|
| **首要喜用** |  | 一句话 |
| **次要喜用** |  | 一句话 |
| **忌神** |  | 一句话 |
| **慎用** |  | 一句话 |

### 第三章 · 命局联动审查关键点

> 这是本 skill 区别于普通命名工具的核心能力。

列出名字字根需规避的合化、冲、刑、害关系。例：

- 子辰半合水 → 含「辰」字反助水忌
- 寅午戌三合火 → 含「午、寅、戌」是吉是凶取决于命局喜忌
- 子卯刑、戌未刑 → 必避

最后明确点名：**本命局的最大忌字根是「X」，其次是「Y、Z」**。

### 第四章 · 评分标准（统一 100 分制六维加权）

| 维度 | 权重 | 评估内容 |
|---|---:|---|
| A. 八字喜用契合度 | 30% | 字本五行是否补喜用；强标识/弱标识；纯度 |
| B. 命局联动 | 15% | 与四柱地支合冲刑害审查 |
| C. 五格数理（熊崎氏） | 20% | 五格全吉为满分 |
| D. 三才配置 | 15% | 相生流通 + 是否命局所喜五行 |
| E. 音韵字形 | 10% | 平仄、声母、字形、书写难度 |
| F. 字义寓意 | 10% | 古典出处、长期审美、性别契合 |

> **生肖维度不独立计分**，统一让位于八字喜用神，字根吉凶并入 A。

详细评分细则见 `references/scoring.md`。

### 第五章 · Top 20 名字综合排行

完整表格列必须为：

| 排名 | 名字 | 拼音 | 笔画 | A喜用 | B联动 | C五格 | D三才 | E音韵 | F寓意 | **总分** | 等级 |

等级：90+ S / 80+ A / 70+ B / 60+ C / <60 D。

筛选规则：
- 凡含本命局忌字根（第三章点名的）的候选**直接淘汰**，不进 Top 20
- 凡总格命中传统凶数（4/9/10/12/14/19/20/22/26/27/28/30/34/36/40/44/46/50）的候选**直接淘汰**

### 第六章 · Top 5 重点详解

每个名字一张子卡片，必含：

- 拼音 · 笔画 · 总分
- 六维评分表（每行带评语）
- 亮点（3 条）
- 可商榷处（2 条，必须诚实说出）
- 古典出处（如有）

如某名字在某维度有瑕疵（例如五格不全吉但综合分仍高），**必须在详解中明示并说"接受 X 瑕疵者可选"**，不许藏短板。

### 第七章 · 决策建议（决策矩阵）

按"父母价值观"和"风险厌恶度"两类矩阵给出推荐：

- **传统派**（重命理工整）→ 谁
- **审美派**（重长期气质）→ 谁
- **平衡派**（兼顾两者）→ 谁
- **补益派**（命理优先）→ 谁

最后给出**单一首推**及理由（必须诚实指出"若必须选一个"的权衡）。

### 第八章 · 不推荐清单（含原因）

明确列出**应淘汰**的常见候选名及具体扣分理由。例：

| 候选 | 原因 |
|---|---|
| 刘奕辰 | 子辰半合水反助忌神 |
| 任何含「水/氵/雨」字根 | 命局水极旺，必避 |

### 第九章 · 框架层判断（跳出命理）

> 这是另一个区别点 — 不能只做命理工具人。

1. **同质化警告**：列出当下 5-10 年内的爆款字（如 2018-2024 的"梓涵/沐桐/宇轩"），点名候选中哪些有时代尘土风险
2. **长期审美**：让父母想象 5 / 18 / 30 / 50 岁该名字是否仍体面
3. **性别色彩**：是否过窄/过中性/过分性别刻板
4. **重名率**：常见字组合的重名风险评估
5. **不可能三角**：诚实告知"既要数理工整、又嫌名字平庸"是不可能的

### 第十章 · 最终建议

- 一句话总推荐
- 备选 2-3 个，每个一句话定位
- 给父母的元建议（3-4 条）：
  - 不要在数理与审美之间死磕
  - 警惕网红字陷阱
  - 命局联动优先于五格
  - 名字最终要让父母自己念出来不别扭

## 输出文件

按以下命名生成到 **当前工作目录** 下的：

```
./baby-name-report/<姓>-<性别>-<YYYY-MM-DD>/
```

例如：
- `./baby-name-report/张-女-2013-10-08/`
- `./baby-name-report/王-男-2020-06-14/`

不要使用 `v2/` 子目录，不要使用 `~`，不要使用绝对路径。
若同一目录已存在，**直接覆写**（不追加序号、不报错退出）。

| 文件 | 内容 |
|---|---|
| `00_评分标准.md` | 评分维度、权重、等级解释 |
| `01_命名报告.md` | 第一至十章完整报告 |
| `02_Top5_详解.md` | Top 5 卡片合集（可选独立成文） |
| `03_最终建议.md` | 第七至十章独立成文（可选） |

每份 md 同时生成 `.html` 和 `.pdf`：

```bash
# 1. md → html（用脚本里的 css 模板）
python3 ~/.claude/skills/baby-name/templates/md_to_html.py <file.md>

# 2. html → pdf（Chrome headless）
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="<file.pdf>" "file://<abs path>/<file.html>"
```

## 评分准则速查（详见 references/scoring.md）

### A. 喜用契合度（30 分）

| 等级 | 得分 | 标准 |
|---|---:|---|
| 完美补益 | 28-30 | 双字均为强喜用神 |
| 优秀 | 24-27 | 一强 + 一中 |
| 合格 | 18-23 | 一字喜用、一字中性 |
| 一般 | 12-17 | 含弱忌神 |
| 不合格 | <12 | 含明显忌神字根 |

### B. 命局联动（15 分）

| 风险 | 扣分 |
|---|---:|
| 直接引动忌神三合（如辰+子→水） | -10 |
| 与日支冲刑 | -8 |
| 暗藏忌神干 | -5 |
| 无联动 | 满分 15 |
| 形成喜用三合 | +2（封顶 15）|

### C. 五格数理（20 分）

| 构成 | 得分 |
|---|---:|
| 五格全吉 | 20 |
| 4 吉 + 1 半吉 | 17 |
| 4 吉 + 1 凶（外格） | 14 |
| 4 吉 + 1 凶（其他） | 11 |
| 3 吉以下 | ≤8 |

凶数：4/9/10/12/14/19/20/22/26/27/28/30/34/36/40/44/46/50

### D. 三才（15 分）

| 类型 | 基础分 | 命局加成 |
|---|---:|---|
| 全相生 | 13 | +2 若全为喜用 |
| 隔位生 | 12 | +2 若全为喜用 |
| 同气 | 10 | +1 若为喜用 |
| 含克但克忌 | 9 |  |
| 含克且克喜 | ≤6 |  |

### E. 音韵字形（10 分）

平仄交替 4 + 声母错开 2 + 字形匀称 2 + 书写难度 2

### F. 字义寓意（10 分）

文化深度 4 + 长期审美 3 + 性别契合 2 + 重名风险 1

## 关键原则

1. **诚实** > 工整：发现某候选名有瑕疵，必须明示，不许为了凑 Top 而藏短板
2. **长期审美 > 短期数理工整**：30 岁的人会用这个名字签合同
3. **生肖让位于喜用神**：当生肖忌字（如鼠忌"日"）恰为命局救命用神（午火印），生肖法错
4. **五格是辅助而非真理**：熊崎氏五格是 1928 年日本人发明的，不是命理核心
5. **网红字陷阱**：每代家长都觉得自己孩子的名字"很特别"，但梓涵/沐桐/宇轩证明并不

## 康熙字典查询

写 Top 5 详解、判定字义/字源、引用古典出处时，**必须先用查询脚本核对原文**，不可凭记忆臆造出处。

```bash
# 单字查询
python3 references/kangxi/lookup-kangxi.py 嘉

# 多字一次查
python3 references/kangxi/lookup-kangxi.py 焘 增 旻 烨

# JSON 结构化输出（便于后续解析）
python3 references/kangxi/lookup-kangxi.py --json 昱

# 全文检索（找所有引用《诗经》的字）
python3 references/kangxi/lookup-kangxi.py --grep 詩經·小雅
```

脚本特性：
- **简繁回退**：输入「焘」自动找到「燾」原文
- **异体字回退**：输入「烨/燁/晔」自动映射到本字「曄」（异体字别名表见 `aliases.tsv`）
- **未收录字**：如康熙字典本身就没收（如某些现代造字），会返回 `[未收]`，此时不要硬编古典出处

报告里凡引用「《诗经·X》《楚辞》《尚书》《说文》」等典籍的字句，应当先用 `--grep` 验证该字在康熙字典里是否真有此出处，**避免编造**。

## 常见反模式（绝对不要做）

- ❌ 不审查命局联动就直接推荐含「辰」「午」「未」「丑」「卯」字根的名字
- ❌ 把"五格全吉"等同于"好名字"
- ❌ 罗列 20 个名字但不诚实指出短板
- ❌ 跳过"框架层判断"章节直接给推荐（用户付费的核心增量在那一章）
- ❌ 在 Top 5 详解里只夸不批
- ❌ 用宽泛字（"美好寓意"/"前程似锦"）替代具体古典出处
