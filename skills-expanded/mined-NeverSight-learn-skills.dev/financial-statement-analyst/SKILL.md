# 专业财报解读分析师 (Financial Statement Analyst) v1.6.0

## 目标

基于宏观-中观-微观三层方法论体系，提供专业级财报解读、舞弊识别和价值评估服务，帮助用户快速识别高风险企业、深度分析财务状况、精准发现舞弊痕迹、科学评估企业价值。

## 快速开始

### 使用方式

在 Claude Code 中调用 skill：

```
请使用 financial-statement-analyst skill 分析以下财报：
[粘贴财报数据或企业名称]
```

### 工作原理（混合架构 + 智能三级路由）

本 skill 采用 **混合架构 + 智能三级路由**：

**一级路由**：智能行业识别（多维度识别）
- 方法1：股票代码识别（上市公司）
- 方法2：企业名称关键词识别（所有企业）
- 方法3：经营范围NLP识别（最准确，所有企业）
- 自动加载：核心模块 + 对应行业模块（约15,000 tokens）

**二级路由**：根据分析目标路由
- 快速排雷模式 → 加载舞弊识别模块
- 深度分析模式 → 加载完整方法论模块
- 价值评估模式 → 加载价值投资模块

**三级路由**：按需加载指标详解
- 用户询问某个指标时，动态加载该指标的详解（约1,000-2,000 tokens）
- 包含：定义、计算公式、经济含义、分析方法、行业对比、风险预警、案例分析

## 核心方法论体系（宏观-中观-微观）

### 宏观层面：战略与环境分析

**1. 行业与产业链分析**
- 产业链定位：上游-中游-下游分析
- 产业链议价能力评估
- 行业生命周期判断（导入期/成长期/成熟期/衰退期）
- 宏观经济影响评估

**2. 竞争环境五力分析**
- 供应商议价能力
- 客户议价能力
- 现有竞争者竞争强度
- 替代品威胁
- 新进入者威胁

**3. 商业模式识别**
- 高毛利模式：毛利率>80%，强品牌，定价能力强
- 高周转模式：毛利率<20%，周转率>10次/年
- 高杠杆模式：杠杆>10倍，息差盈利
- 轻资产vs重资产模式识别

**4. 八维战略分析框架**
- 战略分析：行业、竞争、定位
- 资产分析：质量、结构、效率
- 利润分析：核心利润、利润质量、持续性
- 现金流分析：经营性现金流、匹配度
- 成长分析：营收、利润、增长质量
- 风险分析：财务、经营、战略风险
- 价值分析：内在价值、安全边际、投资回报
- 未来分析：行业趋势、公司战略、管理层能力

### 中观层面：报表与指标分析

**1. 核心利润分析体系**
- 核心利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用 - 研发费用 - 财务费用
- 核心利润率 = 核心利润 / 营业收入
- 经营性资产报酬率 = 核心利润 / 经营性资产
- 核心利润获现率 = 经营现金流 / 核心利润（理想值1.2-1.5）

**2. 财务指标体系（200+指标）**
- 盈利能力（30个）：毛利率、核心利润率、净利率、ROE、ROA、ROIC
- 营运能力（25个）：存货周转率、应收账款周转率、总资产周转率、营运周期
- 偿债能力（30个）：流动比率、速动比率、资产负债率、利息保障倍数
- 成长能力（20个）：营收增长率、净利润增长率、总资产增长率
- 现金流（25个）：经营现金流/净利润、销售现金率、自由现金流
- 舞弊预警（70个）：应收异常、存货异常、费用异常、关联交易异常

**3. 现金流量分析法则**
- 经营现金流/净利润 > 1 → 盈利质量好
- 经营现金流/净利润 < 0.5 → 预警信号
- 连续3年为负 → 生存危机
- 利润可以操纵，但现金流难以操纵

### 微观层面：科目与交易分析

**1. 舞弊恒等式与验证**
```
虚增利润 = 虚增资产 / 虚减负债 / 虚减权益

验证方法：
- 净利润增长率 vs 资产增长率
- 净利润增长率 vs 经营现金流增长率
- 利润表与资产负债表勾稽关系检查
```

**2. 七大盈余操纵模式识别**
- 模式1：过早确认收入（应收账款异常、季度收入波动）
- 模式2：确认虚假收入（客户集中度异常、关联交易非关联化）
- 模式3：一次性活动推高利润（营业外收入占比>20%）
- 模式4：将当期费用推迟到以后期间（费用资本化、折旧摊销异常）
- 模式5：使用其他手法隐瞒费用或损失（表外费用、关联方承担）
- 模式6：将当期利润推迟到以后期间（预收账款异常）
- 模式7：将未来费用确认在当期（洗大澡、资产减值异常）

**3. 资产负债表舞弊痕迹识别**
- **资产方异常**：应收账款、存货、固定资产、无形资产异常
- **负债方异常**：银行借款、应付账款异常、表外负债
- **权益方异常**：未分配利润、资本公积异常

## 四大标准分析流程

### 流程1：快速排雷（5分钟）

**目标**：快速识别高风险企业，过滤明显有问题的公司

**步骤**：
1. 基本信息扫描（30秒）：ST标识、审计意见、监管风险、高管变更
2. 核心指标预警（1分钟）：盈利能力、现金流、偿债能力、营运能力
3. 舞弊信号检测（2分钟）：七大盈余操纵模式、舞弊恒等式、资产负债表痕迹
4. 行业对标初筛（1分钟）：毛利率、净利率、ROE、周转率
5. 风险等级评定（30秒）：计算舞弊风险分数，划分风险等级

**输出**：快速排雷报告（风险等级 + 预警清单 + 建议）

### 流程2：深度分析（30分钟）

**目标**：全面分析企业财务状况、盈利能力、成长性、风险和价值

**步骤**：
1. 战略与环境分析（5分钟）：行业环境、商业模式、竞争地位
2. 财务状况分析（10分钟）：资产质量、盈利能力、现金流量、偿债能力
3. 成长性分析（5分钟）：营收增长、利润增长、资产增长、可持续性
4. 舞弊风险深度分析（5分钟）：七大操纵模式深度检测、恒等式验证、痕迹深度检测
5. 价值评估（5分钟）：绝对估值（FCFF、FCFE）、相对估值（PE、PB、PS、EV/EBITDA）

**输出**：深度分析报告（全面分析 + 投资建议）

### 流程3：舞弊识别（针对性调查）

**目标**：针对疑似舞弊企业进行深度调查，提供舞弊证据链

**触发条件**：快速排雷被评为中高风险、深度分析发现多个预警信号、用户主动要求

**步骤**：
1. 舞弊动机分析（1分钟）：融资压力、业绩承诺、退市风险
2. 舞弊机会分析（2分钟）：内控缺陷、公司治理缺陷、复杂交易结构
3. 舞弊手段识别（10分钟）：收入舞弊、费用舞弊、资产舞弊、现金流舞弊
4. 舞弊证据链构建（5分钟）：财务数据异常、勾稽关系异常、非财务信息异常
5. 舞弊风险评估（2分钟）：动机+机会+证据，计算舞弊风险分数

**输出**：舞弊识别报告（舞弊类型 + 证据链 + 风险等级 + 建议）

### 流程4：价值评估（投资决策支持）

**目标**：基于深度分析结果，提供专业级价值评估和投资建议

**步骤**：
1. 排雷（5分钟）：执行快速排雷流程
2. 绝对估值（10分钟）：FCFF模型、FCFE模型
3. 相对估值（10分钟）：PE、PB、PS、EV/EBITDA
4. 价值投资评估（5分钟）：排雷法+选股法+好价格
5. 投资建议：综合评分、投资建议、目标价位、投资策略

**输出**：投资建议报告（估值分析 + 投资建议 + 风险提示）

## 风险预警阈值

### 盈利能力阈值
- 扣非净利润：< 0（风险）
- 净利率：< 3%（微利预警）
- ROE：< 6%（盈利能力弱）

### 现金流阈值
- 经营现金流/净利润：< 0.5（预警）
- 连续3年为负（生存危机）
- 销售现金率：< 70%（收入质量差）

### 偿债能力阈值
- 资产负债率：> 80%（高风险）
- 流动比率：< 1（短期偿债风险）
- 有息负债率：> 60%（财务风险高）

### 舞弊预警阈值
- 应收账款增长率 > 营收增长率 × 1.5（预警）
- 存货增长率 > 营收增长率 × 1.5（预警）
- 前五大客户占比 > 50%（虚假收入风险）
- 研发费用资本化率 > 50%（异常）
- 非经常性损益占比 > 20%（异常）
- 商誉/净资产 > 30%（高风险）
