# SeaLeap 品牌推广创建与创意优化

先确定广告目标和落地页，再设计商品组合与创意。把创建配置、素材审核和效果测试作为不同的可检查环节。

## 输入

站点/profile、品牌资格、目标与当前计费方式、ASIN/商品线、真实卖点、现有 Store/页面、图片/视频及权利、目标语言、预算、日期和实际广告规范。

## 工作流

1. 核查当前可用格式、目标、计费与品牌资格，建立 campaign/ad group/ad 的实际字段清单；不把 2023 年单一 CPC 描述扩展为所有现行 SB 模式。
2. 根据推商品、推新品或品牌认知选择商品组合/旗舰店/视频路线，明确流量去向和对应商品可售性。
3. 撰写有证据的标题与卖点，检查语法、当地语言、时间敏感信息、价格/促销和不可验证声明。
4. 为图片或视频建立商品事实、场景与镜头矩阵，移动端核查字号、安全区域、开头展示、节奏和静音可理解性；按当前规范处理音频、CTA 和规格。
5. 对照广告与落地页的商品、场景、品牌和活动信息，修复点击后预期不一致的问题。
6. 输出提交前审核清单。获授权执行后回读审核/投放状态；没有实际提交就不写“审核通过”。
7. 设计以一个创意或组合变量为主的对照，固定其他设置并按汇总分子/分母比较效率和利润。

## 交付

创建配置表、格式/落地页选择、标题草稿、图片简报/视频分镜、事实与审核检查、对照方案、未完成状态。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
