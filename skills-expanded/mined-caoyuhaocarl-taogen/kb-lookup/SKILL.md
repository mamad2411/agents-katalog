# KB 检索流程

1. **只依据** `demos/p2p-customer-support-skills/kb-manager/knowledge-base.md` 回答，不引入外部知识。
2. 来信里有错误码时，先按错误码精确匹配条目；没有错误码再按症状关键词逐条比对。
3. 每条结论都带条目编号（例如：KB-002）+ 内容要点 + 一句"为什么与本工单相关"。
4. 把**无关条目明确列出来**并说明无关原因（例如蓝牙类条目与 Wi-Fi 故障无关），不要硬凑。
5. 知识库没有覆盖的内容，必须明确标注：「知识库未收录，以下为个人经验推测」。
