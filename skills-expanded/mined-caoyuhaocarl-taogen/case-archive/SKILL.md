# 结案归档流程

1. 严格照填 `demos/p2p-customer-support-skills/kb-manager/case-record-template.md`，不增删模板标题。
2. 客户原话**一字不改**地填入（不许改写、不许润色）。
3. 诊断一栏写成「现象 → KB 编号 → 根因」的链条。
4. Note 末尾附 1 条具体的 FAQ 更新建议：指出这次工单暴露了知识库哪里可以写得更清楚。
5. 来信缺某个字段时，在 Note 里指出缺什么，**不要编造**内容补位。
