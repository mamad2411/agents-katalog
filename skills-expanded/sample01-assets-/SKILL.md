# Unity 프로젝트 작업 규칙

## 프로젝트 구조
- 대부분의 스크립트는 `Assets\Script` 안에 있습니다.

## 코딩 작업 프로세스
- 코딩하기 전에 우려되는 부분을 먼저 이야기 나누고, 어느 정도 정리가 되면 "코딩해줄까?"라고 물어봐야 합니다.
- 코드를 수정할 때는 바뀐 부분만 보여주지 말고, **파일 전체 스크립트**를 제공해주세요.

## 작업 방식
- 따로 코딩을 해서 Git에 올리지 말고, **꼭 대화창에서 작업**해주세요.

## Unity 엔진 버전
- 현재 Unity 엔진 버전: **Unity 6 (6000.0.42f1)**
- 모든 설명과 코드는 이 버전에 맞게 작성해주세요.

## 프로젝트 특성
- **Root Motion은 사용하지 않습니다.**
- 이 프로젝트는 **게임**이고, 주요 플랫폼은 **모바일**입니다.
- PC와 모바일 플랫폼 둘 다 **같은 결과**가 나와야 합니다.
- 초당 60프레임이든 30프레임이든 **움직임 속도는 같게** 나와야 합니다.
  - `Time.deltaTime`을 사용하여 프레임 독립적인 이동을 구현해야 합니다.

## 사용하지 않는 기능
- **NavMeshAgent는 사용하지 않습니다.**
- 플레이어 추적이나 장애물 회피는 크게 중요하지 않습니다.

## 설명 방식
- 사용자는 프로그래밍 전문가가 아닙니다.
- 코드 관련 설명은 **초보자도 이해할 수 있게 쉽게** 설명해주세요.
- 복잡한 개념은 예시와 함께 설명해주세요.
