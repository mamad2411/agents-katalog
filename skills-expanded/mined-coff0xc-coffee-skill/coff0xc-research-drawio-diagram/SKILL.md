# coff0xc-research-drawio-diagram

## Quick Rules (read this first for everyday tasks)
> **[Evidence first]** Locate the paper, official repo, README, code, or experiment material first; unknown structure must not be invented.
> **[Editable figure]** Deliver an editable `.drawio`/diagrams.net structure by default, not just a screenshot or verbal description.
> **[Structure gate]** Nodes, edges, layers, data flows, and training/inference/experiment stages must trace back to source evidence.
> **[Hard boundary]** Confirm first for unpublished papers, private data, patent/submission-sensitive material, and external publication.

Follow this section first for ordinary research/algorithm-figure tasks; expand the full workflow only for paper-level reconstruction, complex system diagrams, or review-grade explanations.

## Capability
Editable draw.io figure generation for papers, algorithms, models, and research workflows. The focus is delivering an editable `.drawio` source file and mapping figure elements to public evidence.

## What It Can Deliver
- Editable `.drawio` files
- Figure-structure JSON/spec or module inventory
- Evidence table: paper passages, formulas, figure numbers, code paths, official docs
- Notes on unconfirmed inferred edges and uncertain items

## What Input It Can Take
- Paper PDFs/arXiv/OpenReview, official GitHub repos, project docs
- Model structure, algorithm pipelines, experiment flows, training/inference notes
- Existing sketches, screenshots, Mermaid, or figure requirements

## Safe-Use Boundaries
- Figures can be organized directly from user material and public sources
- When a paper/repo needs to be looked up online, mark the source and evidence level
- Do not present inferred connections as facts from the paper text
- By default only local, reversible, verifiable low-risk work; confirm first for anything involving production, credentials, payment, remote writes, deletion, publishing, or permission changes.

## Why You Can Trust It
- Generates draw.io editable source files first, not just PNG/Mermaid
- Key modules in the figure must be traceable to evidence
- Training paths, inference paths, and metrics are labeled by layer

## Typical Usage
```text
Use coff0xc-research-drawio-diagram to draw an editable draw.io method figure from the paper and official GitHub repo.
Use coff0xc-research-drawio-diagram to turn the Transformer paper method into a .drawio model-structure figure.
Use coff0xc-research-drawio-diagram to create an editable diagrams.net method figure with evidence notes.
```

## Default Output
- Close with only done, verified, remaining, and next steps; give a path or location for any file/code/rule artifacts.
- Checks not actually run are marked unverified; security/architecture conclusions carry an evidence level.

- Read `references/full-workflow.md` only for deep architecture, complex multi-stage work, quality evaluation, release, formal delivery, or when the current task lacks evidence.
