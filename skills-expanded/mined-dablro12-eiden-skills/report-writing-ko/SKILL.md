# Korean Report Writing Skill

## Purpose

Write structured Korean reports and academic documents that are clear, logical, and ready to submit or revise.

This skill is optimized for university assignments, research reports, paper drafts, class reports, proposal documents, presentation scripts, and reflective writing.

## Default Structure

Use the following structure when appropriate:

## 서론
- Background
- Problem
- Purpose
- Scope

## 본론
- Key argument 1
- Evidence and explanation
- Key argument 2
- Evidence and explanation
- Analysis or comparison
- Implication

## 결론
- Summary
- Main conclusion
- Limitation
- Future direction or personal reflection

## Academic Research Structure

For research-style reports, use:

1. 연구 배경
2. 문제 정의
3. 연구 목적
4. 선행연구 또는 관련 논의
5. 자료 및 방법
6. 분석 결과
7. 해석
8. 한계
9. 결론

## Writing Principles

Always follow these principles:

- Start with a clear thesis.
- Keep paragraphs logically connected.
- Avoid unsupported claims.
- Use evidence when available.
- Explain concepts before evaluating them.
- Avoid excessive repetition.
- Avoid vague transitions.
- Make the writing sound natural in Korean.
- Match the tone to the assignment type.

## Preferred Tone

For academic assignments:

- formal but readable
- clear and analytical
- not overly decorative
- not too casual

Preferred expressions:

- “이 글은 …을 중심으로 논의한다.”
- “이러한 관점에서 …을 해석할 수 있다.”
- “이는 …라는 점에서 의미가 있다.”
- “다만, …라는 한계도 존재한다.”
- “결국 …라고 볼 수 있다.”

## Revision Rules

When revising user-provided writing:

1. Preserve the user’s original argument.
2. Improve structure.
3. Remove repetition.
4. Strengthen transitions.
5. Clarify ambiguous sentences.
6. Improve academic tone.
7. Keep the writing natural.
8. Do not over-polish into an artificial style.

## Report Expansion Rules

When expanding a short draft:

- keep the original thesis
- add explanation and examples
- connect paragraphs logically
- avoid adding unsupported facts
- mark assumptions if needed

## Presentation Script Rules

When writing a script:

- match the slide order
- use natural spoken Korean
- avoid overly written style
- explain technical terms briefly
- fit the requested time limit
- include transitions between slides

## Final Output Standard

The final output should be directly usable as:

- assignment report
- research report paragraph
- paper draft
- proposal section
- presentation script
- reflection paragraph
