# Korean Slide Copy Skill

## Purpose

Create concise, evidence-based Korean slide copy that can be directly used in presentations.

This skill is optimized for business PT, IR decks, research presentations, lecture slides, safety education materials, and class presentations.

## Default Output Format

Use this structure unless the user requests another format:

[섹션 라벨]

[메인 카피]
A conclusion-style headline.
Keep it short, ideally within 30 Korean characters when possible.

[본문 카피]
3–5 short lines.
Each line should be easy to read on a slide.

[출처]
Source, date, URL, paper, report, or “내부 분석”.

[한 줄 코멘트]
Explain what the speaker should emphasize.

## Slide Writing Principles

Always follow these principles:

1. Headline should be a conclusion, not a topic.
2. Main copy should be short and action-oriented.
3. Body copy should use facts, numbers, and clear logic.
4. Use 3–5 concise lines.
5. Avoid vague slogans.
6. Avoid excessive adjectives.
7. Avoid metaphors unless explicitly requested.
8. Avoid emotional exaggeration.
9. Make the slide readable within 5 seconds.
10. Separate what the audience reads from what the speaker says.

## Preferred Style

Prefer:

- “AI 도입은 비용보다 검증 속도를 줄인다”
- “성과 공백은 IP 경쟁력을 약화시켰다”
- “측정 없는 출입은 사고 가능성을 높인다”
- “데이터 누수 차단이 성능보다 먼저다”

Avoid:

- “혁신의 미래를 열다”
- “무한한 가능성”
- “압도적인 경쟁력”
- “새로운 패러다임”
- “세상을 바꾸는 기술”

## Body Copy Rules

Body copy should be:

- short
- factual
- specific
- easy to present
- aligned with the headline

Example:

[본문 카피]
- 기존 IP 출시 간격 장기화
- 대작 의존으로 매출 변동성 확대
- AI 기반 제작 자동화로 검증 비용 절감
- 소규모 실험 후 대형 투자 전환

## Speaker Script

If the user asks for a script, add:

[발표 대본]

The script should be:
- natural for oral delivery
- concise
- connected to the slide headline
- not too formal unless requested
- suitable for the given time limit

## Research / Business Slide Rules

For research slides:

- include research question
- include method
- include metric
- include result
- include limitation

For business slides:

- include market problem
- include why now
- include solution
- include evidence
- include action

For safety education slides:

- include rule
- include risk
- include action
- include on-site question

## Final Output Standard

The result should be ready to paste into PowerPoint or Keynote.
