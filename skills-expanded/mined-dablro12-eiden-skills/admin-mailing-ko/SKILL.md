# Korean Administrative Mailing Skill

## Purpose

Help draft immediately usable Korean administrative messages for professors, students, collaborators, institutions, and external partners.

The output should be clear, polite, concise, and action-oriented.

## Default Style

- Start with the purpose in the first sentence.
- Put deadlines, dates, places, and required actions clearly.
- Avoid unnecessary emotional wording.
- Keep the message professional but not overly rigid.
- Make the final result copy-paste ready.

## Output Structure

Use this structure unless the user requests another format:

[제목]

안녕하세요.

[목적 문장]

[핵심 내용]

[일정 / 장소 / 방식]

[제출물 또는 요청사항]

[마감일]

[확인 요청 문장]

감사합니다.

## Professor Email Rules

For professor emails:

- Use a respectful tone.
- Briefly explain the context.
- State the requested decision, confirmation, or review clearly.
- Avoid overly long background explanation.
- If there is a conflict or issue, summarize it factually.

Preferred structure:

1. 인사
2. 상황 요약
3. 확인 또는 승인 요청
4. 필요한 경우 선택지 제시
5. 감사 인사

## Student Notice Rules

For student notices:

- Be direct and easy to scan.
- Use bullet points.
- Put deadline and required files visibly.
- Include file naming rules if needed.
- Clarify whether the action is required or optional.

Preferred structure:

1. 공지 목적
2. 일정
3. 제출물
4. 제출 방식
5. 마감
6. 유의사항

## External Collaborator Rules

For external collaborators:

- Use a professional tone.
- State the shared project context.
- Clarify responsibility, deadline, and next step.
- Avoid vague requests.

## Decline Email Rules

For refusal or decline emails:

- State the decision clearly.
- Give a short reason.
- Keep the tone polite and positive.
- Avoid overexplaining.

## Revision Rules

When revising user-provided text:

1. Preserve the original intent.
2. Improve clarity and flow.
3. Make the tone suitable for the recipient.
4. Remove repetition.
5. Strengthen the action request.
6. Provide a polished final version.

## Final Output

Always provide the final message first.

If helpful, also provide:

- 더 공손한 버전
- 더 짧은 버전
- 카카오톡/문자용 버전
