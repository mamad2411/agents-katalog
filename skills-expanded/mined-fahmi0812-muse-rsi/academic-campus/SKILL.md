# academic-campus

> College workflow for Indonesian students: thesis lifecycle, citations, campus documents, study planning.

## Guardrails (read first)

- **Writing help only.** Help structure, draft, and revise — never write a whole thesis or paper for the student to submit as their own without their own work and understanding.
- **Never fabricate citations, data, or results.** Every reference must be a real source the student (or the agent) actually found. If a citation cannot be verified, say so — never invent one.
- **No AI-detection evasion.** Requests to hide AI use, lower AI-detection scores, or bypass plagiarism checks are out of scope.
- **Follow campus rules.** If the campus has a format guide (template, citation style, plagiarism limit), follow it and ask for it when it is missing.

## When to use

- Thesis / skripsi / tesis / disertasi: topic → proposal → seminar → sidang → revision.
- Literature search and citation management (Zotero, BibTeX).
- Campus admin documents: surat, laporan magang, laporan praktikum.
- Study planning, exam preparation, and summarising lecture material.

## Workflow

### 1. Thesis lifecycle

| Stage | Output | Check before moving on |
|---|---|---|
| Topic | Problem statement + 3 research questions | Is it researchable in one semester? |
| Proposal (BAB 1–3) | Background, questions, method | Method matches the question; sources are real |
| Seminar proposal | Slides + defence notes | Every claim has a citation |
| Data / analysis | Clean data, reproducible steps | Raw data saved; analysis steps written down |
| Draft (BAB 4–5) | Results, discussion, conclusion | Results match the method; no invented numbers |
| Sidang | Slides + anticipated questions | Rehearse the 10 hardest questions |
| Revision | Change log, revised draft | Every examiner comment answered, one by one |

### 2. Literature search

1. Start with a question, not keywords. Write it down first.
2. Search: Google Scholar, Semantic Scholar, Scopus / Web of Science (campus access), Garuda / SINTA for Indonesian sources.
3. Keep a table: author, year, question, method, finding, relevance (high / medium / low).
4. Save every paper in Zotero with the PDF attached; export BibTeX for LaTeX or Word.

### 3. Citations

- Pick one style (APA 7th is the common default) and use it everywhere.
- Every in-text citation must have a matching reference entry, and vice versa.
- Verify each reference: open the source, check author, year, title, journal. A citation that cannot be opened is not a citation.

### 4. Study planning

- Break a course into weekly goals; one page of notes per lecture, written the same day.
- Exam prep: past questions first, then weak topics, then a timed mock.
- Summaries: one page per topic — definitions, one example, one common mistake.

## Checklist

- [ ] Every citation verified against a real source?
- [ ] No invented data, results, or references?
- [ ] Format follows the campus template?
- [ ] Change log kept for every revision round?
- [ ] Study plan has dates, not just intentions?
