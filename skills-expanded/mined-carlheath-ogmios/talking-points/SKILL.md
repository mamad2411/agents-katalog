# Talking Points specialist

**Role:** oral communication expert.
**Signature:** core message first, memorable imagery, oral rhythm.
**Purpose:** prepare for radio, TV, speeches, and panels.

## Format adaptation

| Format | Time | Structure | Tone |
|--------|------|-----------|------|
| Radio interview | 3-5 min | 3 core messages, fast answers | Accessible, energetic |
| TV interview | 2-4 min | 2-3 messages, visual language | Concise, clear |
| Panel debate | Variable | Opening + 3-4 points | Distinct, pithy |
| Dinner speech | 5-15 min | Narrative arc | Personal, rhetorical |
| Keynote | 15-45 min | Three acts, stories | Visionary, engaging |
| Doorstep interview | 30-60 sec | ONE message | Extremely concise |

## Core structure: radio/TV interview

```
CORE MESSAGES (say first!)
├── Message 1: [One sentence summarising the main point]
├── Message 2: [Supporting point]
└── Message 3: [Forward-looking / solution]

ONE-LINERS WITH DEPTH
├── "Catchy phrasing" (what you say)
│   └── [Explanation if time permits]
└── Repeat × 3-5

QUICK ANSWERS TO COUNTER-ARGUMENTS
├── "Common objection?"
│   → "Short answer that bridges back to the core message"
└── Repeat × 3-4

WORKING IMAGERY
├── Metaphor 1: [description]
├── Metaphor 2: [description]
└── Familiar comparison
```

## Core structure: speech

```
OPENING (catch attention)
├── Greeting (formal if appropriate)
├── Hook: question OR story OR surprising fact
└── Preview of what you'll talk about

BODY (3-act structure)
├── Act 1: the problem/context
│   └── Story that illustrates
├── Act 2: depth/analysis
│   └── Story that illustrates
└── Act 3: solution/way forward
    └── Story that illustrates

CLOSING (memorable)
├── Restate core message
├── Call to action
└── Closing line (callback to opening)
```

## One-liner techniques

### Contrast pairs
```
"Platforms are like walls — protocols are like languages."
"We've chosen to hold our democratic conversation in spaces not designed for it."
```

### Thought experiments
```
"Imagine if you could only call people on the same phone carrier."
"Think of an association meeting — there are speaker lists and time limits for a reason."
```

### Reframing the familiar
```
"We need to distinguish digital fairgrounds from digital town squares."
"With platforms they own your relationships. With protocols you own them."
```

### Historical parallel
```
"In the 20th century we realised we needed public service. Now we need to think the same way about digital spaces."
```

## Bridging techniques

When the interviewer tries to lead you off:

| Technique | Phrase | When |
|-----------|--------|------|
| Pivot | "The important thing here is..." | Return to core message |
| Acknowledge + Bridge | "That's one aspect, but the main question is..." | Acknowledge without getting stuck |
| Reframe | "I'd phrase it differently..." | Reframe the question |
| Flag | "What I really want to emphasise is..." | Signal something important |

## Counter-argument handling

### Structure
```
"[Common objection]?"
→ "[Brief acknowledgment] + [Counter-argument] + [Bridge to core message]"
```

### Examples
```
"But platform X is so cumbersome!"
→ "Email was too at first. We need better interfaces, not to give up on openness."

"Who's going to pay for it?"
→ "We're already paying — with our data and democratic erosion. The question is what's cheapest in the long run."

"Can't ordinary people just choose for themselves?"
→ "Yes, but the choice happens in a structure where algorithms designed for profit decide what you see. That isn't real choice."
```
