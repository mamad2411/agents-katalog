# Academic Paper Reviewer — 多视角学术论文同行评审

模拟完整的国际期刊同行评审流程：自动识别论文学科，动态配置 7 名审稿人，从四个非重叠视角进行评审，最终输出结构化编辑决策和修改路线图。

## 快速开始

```
评审这篇论文：[粘贴论文或提供文件路径]
```

## 6 种评审模式

| 模式 | 适用场景 |
|:---|:---|
| `full` | 投稿前全面评审（默认）|
| `re-review` | 检查修改是否回应了评审意见 |
| `quick` | 快速质量评估（~15 分钟）|
| `methodology-focus` | 只关注方法/统计 |
| `guided` | 苏格拉底式引导评审（学习者模式）|
| `calibration` | 校准模式：测量审稿人 FNR/FPR 再信任评分 |

## Agent 团队（7 个）

| # | Agent | 角色 | 阶段 |
|:--:|:---|:---|:---|
| 1 | 领域分析 Agent | 分析论文学科，动态配置 7 名审稿人身份 | 阶段 0 |
| 2 | EIC Agent | 期刊主编——期刊匹配度、原创性、整体质量、终审决定 | 阶段 1 |
| 3 | 方法论审稿 Agent | 审稿人 1——研究设计、统计有效性、可重复性 | 阶段 1 |
| 4 | 领域审稿 Agent | 审稿人 2——文献覆盖、理论框架、领域贡献 | 阶段 1 |
| 5 | 视角审稿 Agent | 审稿人 3——跨学科联系、实际影响、挑战基本假设 | 阶段 1 |
| 6 | 魔鬼代言 Agent | 挑战核心论点、逻辑谬误检测、最强反论证 | 阶段 1 |
| 7 | 编辑综合 Agent | 综合所有评审、识别共识与分歧、做出编辑决策 | 阶段 2 |

## 3 阶段工作流

```
阶段 0: 领域分析与角色配置
    +-> [领域分析 Agent] → 审稿人配置卡 (×7)
        - 读取完整论文
        - 识别：主学科、辅学科、研究范式、方法论类型、目标期刊级别
        - 动态生成 7 名审稿人身份：
          * EIC: 哪本期刊的编辑，专长领域，审稿偏好
          * 审稿人 1: 方法论专长，重点关注什么
          * 审稿人 2: 领域专长，研究兴趣
          * 审稿人 3: 跨学科视角，独特视角
          * 魔鬼代言: 核心攻击策略

阶段 1: 并行评审
    +-> [5 名审稿人 + 魔鬼代言] 并行评审
        - 每人从不同视角评审
        - 0-100 分质量评分
        - 详细逐条评论

阶段 2: 编辑决策
    +-> [编辑综合 Agent] → 编辑决策信 + 修改路线图
        - 综合所有评审
        - 识别共识和分歧
        - 编辑决定：接受/小修/大修/拒绝
        - 生成结构化修改路线图
```

## 评审维度

| 维度 | 评估内容 |
|:---|:---|
| 原创性 | 研究问题的新颖性、视角的独特性 |
| 严谨性 | 方法论适当性、统计分析正确性 |
| 完整性 | 文献覆盖、讨论的深度 |
| 清晰性 | 写作质量、组织结构、图表质量 |
| 贡献 | 对领域的理论/实践贡献 |

## 魔鬼代言特别任务

- 挑战论文的每个核心论点
- 检测逻辑谬误
- 提出最强替代解释
- 确认偏误检查
- "如果这篇论文的结论是错的，最可能的原因是什么？"

## 再评审模式

用于验证作者是否充分回应了审稿意见：
- 逐条检查原始评审意见
- 评估修改是否解决了问题
- 新的质量问题标记
- 修改充分性评分

## 输出

1. 5 份独立评审报告（每份从不同视角）
2. 1 份魔鬼代言挑战报告
3. 1 份编辑决策信 + 结构化修改路线图
4. 质量评分矩阵
