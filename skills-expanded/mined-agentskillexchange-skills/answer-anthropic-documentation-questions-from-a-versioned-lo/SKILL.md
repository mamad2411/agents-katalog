# Answer Anthropic documentation questions from a versioned local archive

Use Claude Code to investigate one API, Claude Code or MCP question against a local documentation snapshot with paths, provenance and freshness limits.

## Prerequisites

Git; Claude Code; local text search; uv only for optional refreshes

## Installation

Install or set up from the source-backed instructions:

git clone https://github.com/thevibeworks/claude-code-docs; cd claude-code-docs. With Claude Code installed and configured, run claude "show me the MCP spec for tool annotations" or provide your own bounded documentation question. Ask for the checkout commit and exact supporting file paths. No fetcher run is needed for an existing snapshot; optional refresh commands and credentials are documented upstream.
