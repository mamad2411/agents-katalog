# Audit and fix website QA issues with Squirrelscan

Run Squirrelscan from a coding agent to audit SEO, performance, security, accessibility, and agent-experience issues, then feed exact fixes into an agent repair loop.

## Prerequisites

Squirrelscan CLI, MCP-compatible client or coding agent skill support

## Installation

Install or set up from the source-backed instructions:

Install with `npm install -g squirrelscan` or `npx squirrelscan audit example.com`; for agent use, follow `https://docs.squirrelscan.com/agent-setup/prompt` or add the MCP server at `https://mcp.squirrelscan.com/mcp`.
