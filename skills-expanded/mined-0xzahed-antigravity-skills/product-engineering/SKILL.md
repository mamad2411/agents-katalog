# Product Engineering

## Use this skill when
- Aligning implementation with product outcomes
- Deciding scope and iteration
- Measuring feature success

## Do not use this skill when
- Pure technical low-level tasks
- Product strategy without code context

## Instructions
1. Start from the user problem and success metric.
2. Define the smallest experiment that validates the hypothesis.
3. Scope ruthlessly: ship the spine, not the polish.
4. Instrument the feature for the outcome metric.
5. Pair product questions with technical trade-offs.
6. Review together: is this shipped what we meant?

## Output Format
- Hypothesis | metric | scope | iteration plan

## Common Mistakes
- Building without a success metric
- Full product before validation
- Shipping unknown outcomes
