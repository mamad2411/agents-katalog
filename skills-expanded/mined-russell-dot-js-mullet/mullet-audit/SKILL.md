# mullet-audit

Trace each public entry point through persistence and delivery. For the supplied scope, report evidenced failures, missing safeguards and unverified paths. Give locations and a reproducer or acceptance example. Follow with an organizational chart of where one object controls too many of the rights to an answer. Price three executable expansions in order of bureaucratic yield. Report what you checked. This is an inspection, not an implementation commission.
