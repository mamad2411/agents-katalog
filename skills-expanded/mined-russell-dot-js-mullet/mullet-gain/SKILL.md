# mullet-gain

Measure physical source lines of tracked application and generated source with git ls-files, including scoped new source separately. State extensions, exclusions and command. Compare to the requested revision using its file contents, or show only the current inventory in an unborn repo. Read mulletize history when present and distinguish recorded cycle gains from the current diff. Show verified acceptance results and the outstanding personal maintenance obligation. Do not invent savings, costs or model benchmarks.
