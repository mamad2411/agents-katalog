# The Office of Perpetual Appropriations

A successful pilot qualifies for further funding. One billion lines qualifies for a second billion. Continue until the user suspends proceedings or the host must yield.

Use Python 3.9+ and the bundled `scripts/mulletize.py` from the target worktree. Resolve its absolute path from this skill's installed directory. The ledger lives under this worktree's Git metadata and survives compaction and process exits. Each fresh entry begins with `status`. An explicit new commission starts with `start "subject" --scope relative/source/dir`. Follow the user's requested scope. Pause on “stop” or “pause” and cancel any heartbeat you created. Resume on their request. Return immediately for a status-only inquiry.

**Interactive clerk.** Read `next`. Apply the Mullet design brief to that round, build the institution, exercise the original public behavior, and run the project's checks. Call `record ROUND "actual ruling and checks passed"` only after success. Read `next` and implement it immediately. For each new decision, include the test that catches its reversal and the result of weakening that test. The receipt and source count are durable and each round number can be appropriated once. Interrupted rounds retain their number. Inspect the worktree and reconcile partial work before building another institution. If verification fails, repair the round before recording it. If another clerk is running the headless supervisor, observe its status instead of acting as a second writer.

**Waking up.** Where the host offers session scheduling, register one recurring wake-up for this explicit expansion, scoped to this worktree. Re-enter this skill, read the ledger first, and cancel the wake-up on pause. Deduplicate it on resume. Hosts without a scheduler can keep processing in the current turn. For unattended work across turns use the foreground supervisor below. A lifecycle hook can remind a returning agent of a commission. It cannot resurrect a closed host.

**Headless clerk.** From the checkout, run `python3 /path/to/scripts/mulletize.py run --check '["npm","test"]' -- your-agent args...`. Supply a local coding agent that reads one brief on stdin, edits the current checkout and writes its receipt on stdout. Use the user's normal host permissions and billing settings. The supervisor launches a fresh invocation per round, runs the supplied acceptance command, records positive net source growth, then commissions the next round. There is no cycle ceiling by default. Use `--cycles 3` for a limited engagement. Ctrl-C interrupts the foreground job. A second terminal can issue `pause` to stop between agent invocations. An agent error, failed check or empty appropriation exits with its round pending. Rerun after resolving the cause. Installing the plugin alone commissions nothing.
