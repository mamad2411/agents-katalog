# 亲密关系（Intimate Relationships, 6th ed.）

罗兰·米勒的关系心理学教材，基于实证研究（社会心理学/依恋理论/演化心理学），全书14章。完整章节精华笔记见 `references/notes-full.md`。

## 全书一句话
让人结婚的爱（激情）和让人厮守几十年的爱（相伴之爱）不是同一种爱；关系质量取决于"对方听到了什么"而不是"你说了什么"。

## 核心框架速览（引用时直接用）
1. **爱情三角理论（斯腾伯格）**：亲密/激情/承诺 → 无爱/喜欢/迷恋/空爱/浪漫(亲+激)/相伴(亲+承)/愚昧(激+承)/完美(三全)。激情是唯一必然衰减、不可控的成分。
2. **依恋四分类**：忧虑被弃 × 回避亲密 两维度 → 安全/痴迷/疏离/恐惧。安全型在亲密/激情/承诺/关爱全面占优；依恋随伴侣而变，不是人格铁标签。约60%安全型，两年内1/3人实质改变。
3. **相互依赖理论**：结果=奖赏−代价；满意度=结果−CL；**依赖度=结果−CLalt（去留由依赖度决定，不由满意度决定）**。
4. **戈特曼5:1法则**：积极:消极 ≥ 5:1 则多变/确认/逃避型夫妻都能幸福；跌破则敌对型致命。只看冲突开头3分钟预测6年后离婚准确率83%。
5. **浪漫衰减三机制**：幻想破灭（爱情盲目）→ 新奇消失（柯立芝效应）→ 唤醒消退（多巴胺）。结婚2年情爱表达减半，婚后第4年是全球离婚高峰。
6. **持久婚姻密码（15年+夫妻自述）**："配偶是我最好的朋友" + "我喜欢配偶这个人"。相伴之爱（亲密+承诺）是地基。
7. **感知贬值假说**：亲密关系几乎所有痛苦都指向同一件事——感知到自己在对方心中贬值（PRV低于期望）。忽视 ≈ 驱逐，一样伤人。
8. **归因法则**：幸福伴侣把好事归因于对方内在稳定特质、坏事当外部偶然；不幸伴侣相反。善意归因是幸福开关。
9. **知觉即现实**：我们看到的不是伴侣，是自己建构的伴侣；期望会自我实现（怀疑者亲手推走关系）。
10. **关系维持五策略（卡纳里-斯塔福德）**：积极性、开放/自我表露、保证、共享社交网络、共担任务——是"保质期商品"，需持续投入。

## 反直觉结论（反驳/讨论时好用的弹药）
- 结婚时越浪漫恩爱的夫妻，越可能离婚（幻灭落差最大，7年+才离的夫妻新婚时最深情）。
- 男人比女人更浪漫：更快坠入爱河、更信一见钟情、更看重激情——而激情恰是最不稳定的一边。
- 同居不是"试婚"，是"毁婚"：同居越久结婚率越低、离婚风险更高。
- 与朋友相处通常比与配偶相处更有趣；恋爱/婚姻是友谊的杀手（二元退缩）。
- 低自尊者即使被深爱也不信，会躲开赞美自己的伴侣、投向贬低自己的人（自我证实战胜自我提升）。
- "女人来自金星"是错的：两性相似性远大于差异；日均用词量几乎相同（16215 vs 15559）。
- 越亲密越难识破谎言：识谎正确率54%≈掷硬币，FBI也不比常人强。
- 无条件的宽恕有害：对方无悔意时宽恕=纵容，削弱自己的自尊。
- 决定离婚的不是不幸福，而是"别处看起来更好"；人们会留在不幸福的关系里。

## 配套工具（本仓库附带）
- `scripts/chatlog_to_markdown.py`：把微信/QQ/CSV/JSON 导出的聊天记录转成结构化对话稿，纯本地零依赖。
  `python3 scripts/chatlog_to_markdown.py chat.txt --anonymize --stats --chunk 8000`
- 分析聊天记录时：先转换 + 匿名化，再按 `docs/analysis-prompts.md` 的模板提问（互动结构 / 四骑士编码 / CL-CLalt 拆解 / 单方视角缺失项）。
- 用户只丢来一段聊天记录、没说想分析什么时：先按第6章列出可观察的奖赏、代价、依赖线索，再问他要钻哪一层，别直接给结论。

## 使用提示
- 聊到具体场景（分手恢复、争吵、冷淡期、嫉妒、背叛、要不要复合）时，先查 references/notes-full.md 对应章节（第8章爱情/第10章压力/第11章冲突/第13章解体/第14章维持最常用）。
- 引用研究发现时带数字（效应量、百分比）更有说服力。
- 用书中结论反驳"宿命论"爱情观（"真爱天注定""争吵即不爱"），成长信念更适应。
- 注意：书中数据多为美国异性恋样本，涉及男同/女同数据（第9章）或性少数语境时需标注样本局限，不硬套异性恋结论。
