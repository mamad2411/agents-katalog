# Catalex guide

Reference for how the app behaves. Open only the file the question needs; do not read them all.

| Question | File |
| --- | --- |
| What you cannot change, and where the user changes it | `limits.md` |
| Installing LaTeX, opening a project, updates | `docs/getting-started.md` |
| Layout, files, appearance, keyboard shortcuts | `docs/workspace.md` |
| Compiling, the PDF preview, compile errors, Markdown, editing tools | `docs/writing.md` |
| Comments and how they follow the text | `docs/comments.md` |
| Zotero and bibliographies | `docs/references.md` |
| Agents: context, skills, instructions, drafts and review, document tools | `docs/agents.md` |
| Rewind, Git, Overleaf, backups, local data | `docs/sync-and-recovery.md` |

The files in `docs/` are the user guide for this version of the app. Paths are relative to the folder that holds this file.

## Use it this way

- Name a control as the guide names it. Do not guess where a setting is.
- When a problem comes from a setting in `limits.md`, say which setting, what it is set to if a tool reported it, and where the user changes it. Do not work around it in the project files.
- If the guide does not cover the question, say so.
