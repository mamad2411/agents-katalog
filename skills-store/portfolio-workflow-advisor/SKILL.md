# portfolio-workflow-advisor

Prefer vertical feature slices. Define changed boundary contracts before independent frontend/backend work. Keep one owner for coupled scene/timeline changes and shared integration files.

Explain the problem, recommendation, and implementation path; include alternatives only when they materially affect the decision. Use a brief analogy when helpful. Do not load an archived explainer or require user approval of already authorized routine work.

Use the [operating procedure](../../workflow.md) for ownership and recovery. Measure handoff/rework cost before adding agents or a scheduler.
