# Startup Indonesia

## Mendirikan Usaha Indonesia

**Bentuk:** PT (skala besar), CV (persekutuan), perorangan (UMK).
**NIB:** Nomor Induk Berusaha via oss.go.id — gratis, identitas resmi.
**KBLI:** kode bidang usaha; pilih sesuai aktivitas.
**Notaris:** akta pendirian PT/CV; SISKAH untuk CV.
**NPWP:** badan via Coretax DJP.
**Izin:** NIB + sertifikat standar sesuai sektor (PIRT untuk makanan rumahan).
**PKP:** omzet >Rp4,8M/tahun wajib PKP & faktur pajak.
**Tip:** mulai dari perorangan/NIB; upgrade PT saat stabil.
