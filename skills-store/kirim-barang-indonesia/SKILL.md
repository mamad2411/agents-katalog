# Kirim Barang Indonesia

## Kirim Paket Indonesia

**Ekspedisi:** JNE, J&T, Sicepat, SAP, Anteraja, J&T Cargo (berat), TIKI.
**Ongkir:** berat aktual vs volumetrik (P×L×T/6000); cek situs resmi.
**Packing:** bubble wrap pecah belah, kardus tebal, lakban H, fragile sticker.
**Resi:** simpan nomor resi; lacak via situs resmi; screenshot status.
**Klaim:** hilang/rusak → klaim di cabang dengan resi + foto kemasan + nota.
**Pickup:** minta pickup kurir untuk volume besar (lebih murah dari drop point).
**Tip:** kirim sebelum cutoff (±15.00) untuk tiba lebih cepat.
