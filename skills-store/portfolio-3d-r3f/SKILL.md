# portfolio-3d-r3f

Preserve [art direction](../../brain/art_direction.md). Use client-side Canvas boundaries and appropriate loading/error handling for assets. Feature-local scene ownership is supported; do not require a global Canvas without demonstrated need.

Reuse hot-loop vectors/quaternions, control DPR and resource lifecycle, and profile before optimizing. Define camera/transform ownership with GSAP; one writer per property. Test deterministic scene checkpoints, interactions, reduced motion, and cleanup. Separate real-device performance evidence from headless/software rendering.
