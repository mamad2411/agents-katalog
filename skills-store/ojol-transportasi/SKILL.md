# Ojol Transportasi

## Ojol & Transport Online

**Platform:** Gojek, Grab, Maxim, Traveloka, inDrive.
**Tarif:** base + per km + waktu + surge cuaca/peak.
**Jam ramai:** 06-09, 11-13, 16-19, 20-23; weekend mall/terminal/event.
**Driver:** target order/jam; istirahat tiap 2 jam; servis rutin.
**Penumpang:** cek rating driver, share trip, simpan bukti tarif.
**Tip:** cuaca buruk = surge tinggi + risiko; weekend event = order panjang.
