# Fisika Dasar

## Mekanika
- v = s/t · a = Δv/Δt · v = v0 + at · s = v0t + ½at² · v² = v0² + 2as
- F = ma · W = F·s·cosθ · P = W/t = F·v · Ek = ½mv² · Ep = mgh
- p = mv · F = dp/dt · hukum kekekalan momentum Σp awal = Σp akhir
- Torsi τ = r×F · momen inersia I · ω · α

## Termodinamika
- Q = mcΔT · kalor jenis c · kalor lebur/uap L
- Hukum I: ΔU = Q - W · Hukum II: ΔS ≥ 0
- Mesin Carnot: η = 1 - Tc/Th

## Gelombang
- v = f·λ · f dan λ dari medium · gelombang stasioner
- Intensitas bunyi I = P/A · desibel β = 10 log(I/I0)
- Efek Doppler: f' = f (v ± vo)/(v ∓ vs)

## Listrik
- V = IR · P = VI = I²R = V²/R · R seri/parallel
- Hukum Kirchhoff: ΣI masuk = ΣI keluar; ΣV loop = 0
- Kapasitor C = Q/V · energi U = ½CV² · time constant τ = RC
- Induktor L, energi U = ½LI² · XL = 2πfL, XC = 1/(2πfC)

## Optik
- 1/f = 1/so + 1/si · pembesaran M = -si/so · kekuatan lensa P = 1/f
- Hukum Snellius: n1 sinθ1 = n2 sinθ2 · difraksi celah

## Modern
- E = mc² · foton E = hf · de Broglie λ = h/p
- Aturan seleksi transisi · model atom Bohr: En = -13.6/n² eV
