# Otomotif Indonesia

## Administrasi Kendaraan Indonesia

**STNK/TTKN:** perpanjang tahunan / ganjil-genap; diler vs Samsat keliling.
**Pajak:** PKB + BBN + SWDKLLJ; cek denda telat via e-Samsat.
**BPKB:** balik nama saat jual-beli; jangan fotokopi sembarangan.
**SIM:** A (mobil), C (motor); perpanjang online via Digital Korlantas.
**Inspeksi:** uji KIR untuk kendaraan >3 tahun.
**Tilang:** ETLE kamera tilang; cek denda via portal resmi.
**Tip:** SIM hilang → blokir via portal Korlantas; STNK hilang → surat kehilangan polisi.
