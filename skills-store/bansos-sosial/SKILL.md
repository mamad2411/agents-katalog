# Bansos & Bantuan Sosial

## Program utama
- **PKH**: bansos bersyarat (kesehatan+pendidikan) untuk keluarga miskin; cek di cekbansos.kemensos.go.id atau desa.
- **PBI**: Penerima Bantuan Iuran BPJS Kesehatan gratis.
- **BPNT**: Bantuan Pangan Non Tunai — sembako via e-Warong/e-Ritel.
- **BLT/BSU**: Bantuan Langsung Tunai / Subsidi Upah untuk pekerja terdampak.
- **KKS**: Kartu Keluarga Sejahtera untuk e-warong.

## Cek status
- cekbansos.kemensos.go.id: NIK + nama sesuai KTP.
- desa/kelurahan, atau RT setempat — data dihimpun dari Dukcapil.

## Pinjaman produktif
- **KUR**: KUR Mikro (s.d. Rp50jt, tanpa agunan tambahan), KUR Kecil, KUR TKI — via bank penyalur (BRI, Mandiri, BNI, BSI) + koperasi.

## Tip: bansos tidak dipungut biaya pendaftaran; waspada calo.
