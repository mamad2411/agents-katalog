# Event Wedding Indonesia

## Pernikahan & Event Indonesia

**Seserahan:** adat per daerah; checklist: siraman, midodareni, sungkeman, resepsi.
**WO/EO:** wedding organizer vs event organizer; paket full vs ala carte.
**Vendor:** ruko pengantin, dpst, henna, gamelan, dokumentasi; cek portofolio.
**Undangan:** digital (WA blast) vs cetak; QR code RSVP.
**Budget:** 30% venue, 20% katering, 15% dokumentasi, 15% busana, 10% dekorasi, 10% cadangan.
**Musyawarah:** libatkan keluarga; tetapkan budget & deadline.
**Tip:** booking vendor H-6 bulan; kontrak tertulis; DP max 50%.
