# Marketplace Lokal

## Marketplace Indonesia

**Platform:** Tokopedia, Shopee, TikTok Shop, Lazada, Bukalapak.
**Setup:** verifikasi KTP+rekening atas nama sendiri; foto produk bersih + deskripsi keyword.
**Harga:** riset kompetitor; diskon + gratis ongkir (XTRA) untuk ranking.
**Operasional:** update stok harian, balas chat <5 mnt, minta review bintang 5.
**Retur:** pelajari kebijakan; foto barang sebelum kirim = bukti.
**CS:** template balasan cepat untuk tanya stok/ongkir/retur.
**Tip:** produk margin tipis hindari promo besar; fokus repeat order.
