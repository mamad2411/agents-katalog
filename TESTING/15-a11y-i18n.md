# 15 — Aksesibilitas (WCAG 2.2 AA) & i18n/l10n

## 1. Gate a11y (wajib untuk semua UI)
```bash
dcheck <url>                                   # kontras, target sentuh, alt, heading, label, overflow
npx --yes pa11y http://localhost:3000 --standard WCAG2AA --reporter json
npx --yes @axe-core/cli http://localhost:3000 --exit          # 0 violation serius
npx playwright test e2e/a11y.spec.ts           # axe di dalam test e2e
```
Gate: **0 violation serius/kritis**, kontras ≥ 4.5:1 (teks normal), ≥ 3:1 (teks besar/ikon).

## 2. Uji manual yang tidak bisa digantikan alat
| Area | Langkah |
|---|---|
| Keyboard | Tab urut logis, fokus terlihat, tidak ada focus trap, Esc menutup modal, Enter submit |
| Screen reader | VoiceOver (`Cmd+F5`) / NVDA: label terbaca, gambar punya alt, error diumumkan (`aria-live`) |
| Zoom | 200% tanpa horizontal scroll, 320 px width tetap bisa dipakai |
| Motion | `prefers-reduced-motion: reduce` → animasi berhenti |
| Form | Label eksplisit, error terhubung (`aria-describedby`), `aria-invalid`, wajib ditandai |
| Tabel | `<th scope>`, caption, ringkasan untuk tabel kompleks |
| Warna | Status tidak hanya warna (tambah ikon/teks) |
| Media | Caption untuk video, transkrip audio, tidak autoplay bersuara |

## 3. Pola ARIA yang sering salah
- Jangan `role="button"` pada `<div>` tanpa `tabindex` + handler keyboard → pakai `<button>`.
- `aria-hidden="true"` pada elemen yang masih fokusable = bug.
- Modal: `role="dialog" aria-modal="true"`, fokus masuk, fokus kembali ke pemicu saat tutup.
- Live region: `polite` untuk notifikasi, `assertive` hanya untuk error kritis.
- Ikon dekoratif: `aria-hidden="true"`; ikon fungsional: `aria-label`.

## 4. i18n / l10n
| Uji | Contoh |
|---|---|
| Teks panjang | Jerman/Finlandia 1.5× lebih panjang → layout tidak pecah |
| RTL | Arab/Hebrew: `dir="rtl"`, ikon cermin, margin logis (`margin-inline`) |
| Angka | `1.234,56` (id) vs `1,234.56` (en) — pakai `Intl.NumberFormat` |
| Tanggal/waktu | zona waktu pengguna, format lokal, DST, 12/24 jam |
| Mata uang | simbol + kode + pembulatan (IDR tanpa desimal) |
| Pluralisasi | 0/1/2/5 item — ICU MessageFormat, bukan if-else |
| Pencarian/sort | aksen & huruf besar, `localeCompare` |
| Hardcode | tidak ada string UI di kode; semua di katalog terjemahan |
| Fallback | kunci hilang → jelas & tercatat, bukan `undefined` |
| Font | font punya glyph yang dibutuhkan (CJK, Arab, emoji) |

## 5. Test otomatis i18n
```ts
test("format rupiah", () => {
  expect(new Intl.NumberFormat("id-ID", { style: "currency", currency: "IDR" })
    .format(1234.5)).toMatch(/Rp\s?1\.235/)
})
```
Untuk setiap locale: render halaman utama di CI dengan locale itu, ambil screenshot,
pastikan tidak ada overflow (`dcheck` bisa dipakai per locale).

## 6. Konten & copy
- `dcopy <file|url>` — klaim tanpa bukti, buzzword, kalimat kepanjangan.
- Uji: judul halaman unik, hierarki heading (`h1` satu), teks link bermakna,
  pesan error menyebut cara memperbaiki, bahasa konsisten.

## 7. Definition of Done a11y/i18n
- [ ] axe/pa11y 0 violation serius.
- [ ] Bisa diselesaikan penuh dengan keyboard saja (alur kritis).
- [ ] Kontras & target sentuh lulus angka.
- [ ] Locale `id` + 1 locale panjang + 1 RTL diuji tanpa overflow.
- [ ] Tanggal/angka/mata uang diformat lewat API locale, bukan string manual.
